# 《三国演义》第38回 定三分隆中决策　战长江孙氏报仇

底本：<https://zh.wikisource.org/wiki/三國演義/第038回>；读取日期：2026-10-19。

## 情节要点

1. 关羽疑孔明“有虚名而无实学”，张飞扬言“用一条麻绳缚将来”；刘备引齐桓公五反见东郭野人、周文王谒姜子牙，叱止二人，嘱不得失礼。
2. 刘备在离草庐半里外下马步行；孔明正在草堂昼寝，刘备拱立阶下，张飞欲放火被关羽劝住；孔明睡醒吟诗，更衣后出迎。
3. 孔明论曹操不可争锋、孙权可援不可图，主张先取荆州、后取西川，成鼎足之势；命童子取出一轴画挂于中堂，指为西川五十四州之图。
4. 刘备泪沾袍袖，恳请出山，孔明应允；次日三人偕孔明同归新野。
5. 后半回转江东：孙权纳贤，建安八年伐黄祖，徐氏诛媯览、戴员，甘宁来降，孙权举兵征夏口（下回接续）。

## 选定场面

草堂中堂，孔明起身立于挂图旁，一手指向图卷，向刘备讲说三分之势；刘备在席上拱手倾身而听，童子侍立。入画理由：
“隆中对”是本回核心，挂图是现成的视觉焦点，孔明首次出场的样貌可作主体，动作为静态指点，不涉打斗。具名限诸葛亮、
刘备二人，关、张在门外不入画。三处依据：

- 「孔明身长八尺，面如冠玉，头戴纶巾，身披鹤氅，飘飘然有神仙之概。」
- 「命童子取出画一轴，挂于中堂，指谓玄德曰」
- 「将军欲成霸业，北让曹操占天时，南让孙权占地利，将军可占人和。」

羽扇核对：已读毛本第34–61回全文，“羽扇”仅见第52回（“头戴纶巾，身披鹤氅，手执羽扇”）。第37–51回无此物。

## 器物与环境

- 地点：隆中卧龙岗草堂（茅庐），“草堂几席”，中堂有挂图；汉代席地而坐，几榻低矮，不画高背椅与方桌。
- 时令：春。上回末“又早新春”，孔明醒来吟“草堂春睡足，窗外日迟迟”，天气晴和，不画雪。
- 器物：画轴一幅，只画山川水系与州郡轮廓，不写可读文字；茶具（童子献茶）；孔明案头无扇。
- 现实中会动的：① 窗外日影与修竹（上回古风“修竹交加”）微摇；② 茶盏与香炉上升的细烟；③ 门帘、衣袖、鹤氅边缘在微风里轻动。

## 排除项

- 羽扇、四轮车（第52回起）、八卦衣、星冠与道冠等影视造型；不画竹简、沙盘；孔明不处于昼寝中（已醒）。
- 刘备泪湿衣襟、孔明应允、关张献礼在其后；雪景与风雪（第37回）、黄承彦、诸葛均不入画。
- 下半回江东诸事、战场与战船不入画；不在图上写可辨认的长段文字。
