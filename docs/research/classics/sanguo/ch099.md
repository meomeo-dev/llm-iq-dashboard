# 《三国演义》第99回 诸葛亮大破魏兵　司马懿入寇西蜀

底本：<https://zh.wikisource.org/wiki/三國演義/第099回>；读取日期：2026-10-19。

## 情节要点

1. 建兴七年夏四月，孔明屯祁山，分作三寨；司马懿令郭淮、孙礼抄小路救武都、阴平，被孔明四轮车拦在山背后，
   前后夹击大败；张苞追敌连人带马跌入涧中，头破，送回成都养病。
2. 司马懿再令张郃、戴陵夜抄蜀兵之后，二人遇草车堵路、满山火光，被伏兵围住；孔明山上招降，张郃怒骂，
   杀上山不得，冲出重围，又回身救出戴陵。
3. 六月炎热，张郃、戴陵追至半途中伏，王平、张翼截击，姜维、廖化按锦囊袭司马懿营，魏军大败；费祎持诏复
   孔明丞相之职。张苞死讯传来，孔明吐血得病，退回汉中。
4. 秋七月，曹真、司马懿引四十万入寇，陈仓城外大雨三十日，魏主诏二人还朝，孔明不追（下回接续）。

## 选定场面

祁山下蜀寨后路的夜里：张郃、戴陵纵马趋前，见草车横路，刚传令退兵，满山火光齐明、伏兵四出；孔明在祁山上
喊话招降，张郃在马上指孔明而骂。入画的一刻：张郃持枪勒马、怒目仰向山上，戴陵在侧，草车横路，四面火把；
孔明立在山坡高处（姿态原文未写，兜底取立，不乘车）。具名孔明、张郃、戴陵。三处依据：

- 「只见数百辆草车，横截去路。」
- 「只见满山火光齐明，鼓声大震，伏兵四下皆出，把二人围住。」
- 「郃大怒，指孔明而骂曰：“汝乃山野村夫，侵吾大国境界，如何敢发此言！”」

取这一刻的理由：回目上联“诸葛亮大破魏兵”的第二次伏击，夜景火光、山上一人对山下一将，上下对峙，不见
斩杀；有别于第93回日景四轮车阵前。不取四轮车拦郭淮、孙礼：第100、101回也以四轮车为主，连续三回重复。
备选（不入画）：四轮车山背后拦截；陈仓城外淫雨三十日。

先后核对：三更合兵，从蜀兵背后杀来（前）→前军不行，二人纵马视草车，郃曰“此必有准备”→传令退兵，火光齐明、
伏兵四出，把二人围住（入画前一瞬）→孔明在祁山上大叫，劝二人下马早降→郃大怒，指孔明而骂（此刻入画）→
言讫，纵马挺枪杀上山，矢石如雨，冲出重围，翻身救戴陵（后，不画）→孔明叹“张翼德大战张郃”（后，不画）。
此刻矢石未下，张郃尚未催马，枪不前挺。

## 器物与环境

- 地点：祁山下蜀寨与大路之间的山路，孔明立处即“祁山上”。祁山在今甘肃礼县东、西汉水北侧（据摘要）；
  武都在今成县、阴平在今文县（据摘要），均不入画。祁山堡为平川上孤山，本场用寻常山坡，不画孤峰。
- 时令：开头“建兴七年夏四月”，后文六月“十分炎热”，此夜介于其间，推定为夏；时辰“三更时分”；月色、
  阴晴本回未写，兜底不画月亮，不加雾雨。
- 器物：数百辆草车，形制未写，兜底：普通双辕木车，堆草横排断路；本回草车不着火。火把，汉代称苣、炬，
  束苇为之（据摘要）；战鼓、旌旗、战马。
- 现实中会动的：① 满山火把的火焰摇曳、火星上飘；② 战鼓与旌旗；③ 战马刨蹄喷气、鬃尾与盔缨。

## 排除项

- 同回前后几场：四轮车拦郭淮、孙礼，张苞坠涧；张郃杀上山、冲出重围、回身救戴陵，孔明叹张翼德；六月红旗
  伏击与锦囊计；费祎持诏；陈仓淫雨三十日；曹真、司马懿四十万。
- 他回易混：第98回马岱火烧孙礼运粮车（本回草车只堵路，不画着火）；第101回木门道滚木、万弩射杀张郃
  （本回张郃不死，不画弩阵、悬崖、滚木）；第97回陈仓云梯火箭；第100回八卦阵、墨涂面；第103回上方谷。
- 六出祁山逐次（按各回开头纪年与孔明自述推定）：一出第91–96回（建兴六年春，街亭）；二出第97回（陈仓、
  郝昭、王双，费耀中计；第98回孔明自称“吾二出祁山”）；三出第98回后半至本回（建兴七年，取陈仓、散关、
  武都、阴平）——本回属三出；四出第100回（建兴八年秋，箕谷、渭滨斗阵、添灶）；五出第101回（建兴九年春，
  卤城割麦、妆神、木门道）；六出第102–104回（建兴十二年春，北原、木牛流马、上方谷、五丈原）。张郃之死在五出。
- 器物：原文“一声炮响”是信号声，汉末无火药，“砲”本指抛石机（据摘要），不画火炮炮筒；不画马槊、方天
  画戟、丈八蛇矛；不画京剧脸谱、靠旗、翎子，孔明不穿八卦衣。
