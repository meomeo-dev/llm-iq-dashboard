# 《三国演义》第50回 诸葛亮智算华容　关云长义释曹操

底本：<https://zh.wikisource.org/wiki/三國演義/第050回>；读取日期：2026-10-19。

## 情节要点

1. 赤壁火起，曹操由张辽护着奔乌林，沿途遇吕蒙、凌统、赵云、张飞截杀；天明大雨，到葫芦口埋锅造饭时被张飞冲散。
2. 曹操见华容小路山边起烟，以“虚则实之”反走此路；早晨下雨，坑堑积水，马蹄陷泥，令强壮者砍竹木、搬草芦填路，死者无数。
3. 过了险处仅剩三百余骑，曹操在马上大笑周瑜、诸葛亮无谋；一声炮响，关羽引五百校刀手截住去路。
4. 程昱劝曹操以旧恩相告；曹操欠身求情，关羽想起旧恩，勒回马头命众军散开，曹军冲过，又放走张辽。
5. 曹操出谷口时随从只剩二十七骑，入南郡歇息；关羽空手回夏口请死，孔明叱武士推出斩之（下回接续）。

## 选定场面

华容小路上，关羽勒回赤兔马头的一刻：曹操已缓马上前、欠身求情，身后三百余骑衣甲湿透、惶惶欲泣；关羽一手勒缰，
把马头转向路旁，命两边校刀手“四散摆开”。入画理由：一人让路的内心转折全落在马头与神情上，无打斗无血腥；
曹军尚未冲过，众军也尚未下马哭拜。具名限关羽、曹操。三处依据：

- 「两边五百校刀手摆开，为首大将关云长，提青龙刀，跨赤兔马，截住去路」
- 「纵马向前，欠身谓云长曰：将军别来无恙」
- 「于是把马头勒回，谓众军曰：四散摆开」

先后核对：填路、大笑、炮响、程昱进言、曹操欠身求情在先；关羽勒马命散开为所选一刻；曹军冲过、众军下马哭拜、张辽赶到均在其后。

## 器物与环境

- 地点：华容小路，山僻路窄；山边有数处烟起（关羽按孔明令所举，可作远山一两缕直烟）；路旁竹木、草芦已被砍去填路。
- 路面：早晨下雨，积水泥泞；过了险峻处“路稍平坦”，此刻只画湿路沾泥，不画马蹄深陷。
- 时令天气：隆冬严寒（第49回曹操称“冬至一阳生”）；清晨大雨已止，天色未写，兜底：阴天无雨。
- 现实中会动的：① 人马在严寒里呼出的白气（兜底）；② 关羽长髯、战袍下摆与残破旗帜在山风里飘动；③ 远山烟柱缓缓上升。

## 排除项

- 京剧脸谱：关羽红脸油彩、曹操白脸、张飞黑脸；周仓扛刀、关平（第49回随行，本回相遇段未写）。
- 张辽（关羽犹豫时才到）、程昱劝说、许褚徐晃断后；曹操大笑、赵云张飞埋伏均属前一段，不混入。
- 曹军已冲过、众军下马哭拜、关羽放走张辽；曹操跪地或拱手哀求（原文“欠身”）。
- 大雨、马蹄深陷泥中、填路场面，均在相遇之前。

## 现有题面核对

旧题面：`sanguo-050` / `sanguo-anim-050`（`src/core/classics/sanguo.ts`）。场面沿用（勒回马头的一刻合适），改下列细节：

- 有据：隆冬；华容窄路；曹军疲惫、衣甲不整；关羽长须、骑赤兔、持大刀（原文青龙刀）；关羽“把马头勒回”。
- 与原著不符：“拱手哀求”，原文是“欠身”；“几百名残兵”应为“三百余骑”，且多是骑兵；
  “身后一排持刀步兵列阵”，原文是“两边五百校刀手摆开”，在路两侧而非身后；
  “马蹄陷在泥水里”是填路之前，相遇处“路稍平坦”，改湿路沾泥；“盔甲焦黑”仅焦头烂额者，主体是衣甲湿透。
- 神情：“犹豫”在放行之后才有；勒马一刻是“越发心中不忍”，改“不忍”。“红脸”须注明是枣红肤色，非油彩脸谱。
- 动态旧稿：“寒风凄雨”无据，雨在清晨，此刻已止；“枯芦苇倒伏”可保留（路旁有草芦）；“残卒步履摇晃”改为人马疲惫喘息；
  赤兔马头微扬、长髯微扬可沿用，另可加远山烟柱。
