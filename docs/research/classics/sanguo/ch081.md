# 《三国演义》第81回 急兄仇张飞遇害　雪弟恨先主兴兵

底本：<https://zh.wikisource.org/wiki/三國演義/第081回>；读取日期：2026-10-19。

## 情节要点

1. 先主不听赵云之谏，下令伐吴；秦宓谏阻被囚，孔明上表相救；点将毕，择定章武元年七月丙寅日出师。
2. 张飞在阆中限部下三日备白旗白甲，范疆、张达受鞭，夜间行刺，携首投吴（此事不入画）。
3. 先主见大星坠地，接凶信痛哭；张苞、关兴先后白袍银铠入营；青城山李意画图，先主焚之。
4. 张苞、关兴争先锋印，先主命比武：张苞连射三箭中红心，关兴射落飞雁。
5. 二人欲交锋，被先主喝止，结为兄弟，折箭为誓；范疆、张达献首于孙权，孙权遣诸葛瑾求和。

## 选定场面

蜀军营前空地：张苞射毕，百步外旗上三支箭矢并中红心；关兴挽弓在手，仰头指着头顶飞过的一行雁，
说“吾射这飞雁第三只”，箭尚未离弦；先主在旁观看。入画理由：回目“雪弟恨”之后的少年将风采，
一人一弓一行雁即成画，无血腥；不选雁坠之后二人上马欲斗的一刻。三处依据：

- 「朕正要观贤侄武艺，以定优劣。」
- 「苞拈弓取箭，连射三箭，皆中红心。」
- 「吾射这飞雁第三只。」

先后核对：二人争印→先主“朕正要观贤侄武艺”→苞令军士百步外立旗、画红心→苞连射三箭皆中→众称善
→兴挽弓在手，称“射中红心何足为奇”→头上雁过→兴指雁，称“吾射这飞雁第三只”（此刻）→一箭射去，雁应弦而落
→苞大怒，飞身上马→先主喝止。雁坠、上马在后；本场面二人步立，手中无矛无刀。

## 器物与环境

- 地点：蜀军营中开阔处（先主已择期出师，营址与营帐形制本回未写）；百步外另立一面旗。
- 时令：出师期定在七月丙寅日；比武具体日期本回未写。雁行南飞通常九月上旬起，题面只写“一行雁过”，
  不另加落叶、菊花等秋景；天气本回未写。
- 器物：弓与三支箭（汉代钩弦韘多用于先秦，西汉渐衰，不画清式玉扳指）；旗面中心画红心，作布旗靶，
  毛本称“红心”，周代的布侯与鹄不是它的出处；一行雁取一字行列。
- 现实中会动的：① 雁行扇翅向前飞，往复循环；② 百步外的旗面在风中飘，旗上箭杆微颤；③ 先主与官员的衣带、
  营中旌旗随风飘动。

## 排除项

- 张飞遇害：不画；范疆、张达鞭背、行刺、割首，均不入画。
- 雁中箭坠地、张苞怒而上马挺矛、关兴绰刀欲战（后）；先主喝止、折箭为誓（后）；李意画图焚图（前）。
- 青龙偃月刀；关兴画成红脸长髯，张苞画成黑脸虎须；两人骑马射箭。
- 戏曲脸谱与影视造型不取；现代同心圆箭靶；清式扳指与反曲弓。
