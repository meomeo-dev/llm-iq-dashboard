# 《三国演义》第61回 赵云截江夺阿斗　孙权遗书退老瞒

底本：<https://zh.wikisource.org/wiki/三國演義/第061回>；读取日期：2026-10-19。

## 情节要点

1. 庞统、法正劝刘备席间杀刘璋，魏延舞剑、张任等对舞，刘备喝止；刘备赴葭萌关拒张鲁，刘璋令杨怀、高沛守涪水关。
2. 孙权听顾雍议截川口，吴国太喝止；张昭献计，遣周善率五百人扮客商入荆州，诈称国太病危，诓孙夫人带七岁阿斗上船。
3. 赵云只带四五骑沿江追赶，借渔船跳上大船，夺回阿斗；张飞率十余船自油江口截住，斩周善，二人护阿斗过船，放夫人去。
4. 孙权欲取荆州，闻曹操起兵四十万而止，迁建业、筑濡须坞；董昭议曹操为魏公，荀彧受空盒而亡。
5. 曹操攻濡须，孙权致书“足下不死，孤不得安”，曹操班师。

## 选定场面

大船船头、顺水而下：赵云一手抱定阿斗，一手仗剑，吴兵与侍婢不敢近，孙夫人立在船上怒视；下游港内十余只船
一字排出，麾旗擂鼓，头船上张飞手执长矛高声大叫。入画理由：回目“截江夺阿斗”的收束瞬间，夺回、对峙与援兵
同在一景，不必画斩周善。具名赵云、孙夫人、阿斗、张飞四人（周善在后艄挟舵，作小像或略去）。三处依据：

- 「赵云一手抱定阿斗，一手仗剑，人不敢近。」
- 「忽见下流头港内一字儿排出十余只船来，船上麾旗擂鼓。」
- 「当头船上一员大将，手执长矛，高声大叫：『嫂嫂留下侄儿！』」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 赵云 | 身长八尺，浓眉大眼，阔面重颐（第7回）；此刻无马无枪（“弃马执枪”，后“弃枪在小船上”），只持青釭剑（柄上金嵌“青釭”二字）；盔甲本回未写，兜底：铁盔铁甲，外罩征袍；不画白袍银枪 | 第7、41回；第61回“掣所佩青釭剑” |

先后核对：赵云弃马、弃枪，跳上大船，入舱与夫人争执，推倒侍婢夺阿斗、抱出船头，“一手抱定阿斗，一手仗剑”由此持续；
“正在危急”时张飞船队才出现，此刻张飞手执长矛。“提剑跳上吴船”“手起一剑砍倒”周善在其后，不混入。

## 器物与环境

- 地点：荆州沙头镇江边顺流而下，至油江口；周善共五船，扮客商，“风顺水急，望中流而去”。赵云立大船船头，脚下无马。
- 时令：季节与时辰本回未写；兜底：日间、顺风，不写雨雪。
- 器物：青釭剑、长矛、麾旗、战鼓、船头与后艄的舵；东汉船有舵、橹、桨，桅帆无实物依据，不画满帆。
- 现实中会动的：① 江水波纹与船首浪花；② 张飞船队的麾旗与擂鼓的鼓槌；③ 赵云衣带、阿斗衣角与夫人衣袖被顺风带动。

## 排除项

- 周善被斩、提头掷于夫人前、夫人要投江、孔明引船接应，均在此刻之后；张飞提剑跳船不画。
- 白袍白马银枪的赵云；襁褓中的阿斗（襁褓属长坂坡）；周善的“长戈”（戈在东汉已绝迹）不入画。
- 戏曲孙尚香的靠旗与雉尾，凤冠霞帔，影视铠甲；多层楼船与鼓满的大帆。
- 同回濡须口、九锡、荀彧、孙权“碧眼紫髯”均不入画。
