# 《三国演义》第70回 猛张飞智取瓦口隘　老黄忠计夺天荡山

底本：<https://zh.wikisource.org/wiki/三國演義/第070回>；读取日期：2026-10-19。

## 情节要点

1. 张郃分军取巴西，据宕渠、蒙头、荡石三寨；张飞与雷铜夹击后追至宕渠山，张郃据险不战，相拒五十余日。
2. 张飞在山前日日饮酒大骂；诸葛亮笑言此是诱敌之计，送成都佳酿五十瓮，车插黄旗“军前公用美酒”，遣魏延押送。
3. 张郃见张飞帐下饮酒、令二小卒相扑，夜下山劫寨，刺中的是草人，张飞自帐后杀出；魏延、雷铜夺蒙头、荡石二寨，张郃奔瓦口关。
4. 张郃设伏杀雷铜；张飞将计就计，魏延烧车；后得百姓指小路，张飞率五百轻骑绕梓潼山攻关后，张郃弃马逃回南郑。
5. 张郃再取葭萌关，黄忠请缨，白须倒竖、舞大刀折硬弓，与严颜诈败骄敌、火烧天荡山，斩韩浩、夏侯德。

## 选定场面

张郃夜劫张飞大寨、发觉所刺是草人的一刻：中军帐前灯烛通明，草人仍端坐案后；张郃正勒马回头，帐后号炮连响，
张飞睁圆环眼、挺矛跃马拦路，尚未交锋。入画理由：全回“智取”的收束瞬间，计谋与人物一图可读，只取冲出而不取交手。
具名限张飞、张郃二人（草人不算人物）。三处依据：

- 「郃骤马到面前一枪刺到，却是一个草人。」
- 「急勒马回时，帐后连珠炮起。」
- 「一将当先，拦住去路，睁圆环眼，声如巨雷」

先后核对：白天张郃在山顶所见的相扑，在夜袭之前；草人被刺、勒马、炮响、张飞现身紧连；魏延雷铜夺寨、山上火起、
“战到三五十合”都在其后，不画。第一句“一枪刺到”只作背景，画面里枪已收回。

## 器物与环境

- 地点：宕渠山前张飞大寨（离宕渠十里下寨），山下平地、中军帐前；山上是张郃三寨，张郃自山侧下来。
- 时令：夜，“月色微明”；季节、天气未写，兜底：晴夜，不强加雨雪。
- 器物：帐中案、数盏铜灯（汉代以铜灯、油灯照明，蜜烛稀有，不画现代蜡烛）、酒瓮、草人；矛、枪；
  “连珠砲”汉末无火药，只作接连的号炮声，不画炮口火焰；寨中火光、火把。
- 现实中会动的：① 灯火与火把摇曳；② 营旗、帐幕被夜风吹动；③ 受惊勒转的战马鬃毛与张飞虎须、袍角。

## 排除项

- 白天的相扑场面、诸葛亮送酒的黄旗车队不与此刻同框；酒瓮可留在案上。
- 魏延雷铜夺寨、山后火起、两将交手；瓦口关、百姓引路、梓潼山；黄忠、严颜、天荡山：均属其他场面，不入画。
- 张飞并未真醉，不画醉态；不画张飞刺倒张郃或张郃落马。
- 京剧黑十字门蝴蝶脸、黑脸张飞、影视造型一概不用；游戏式巨矛、双矛、火焰矛头不用。
- 草人不画成田间戴草帽的稻草人；汉末无火药，不画大炮与烟火。
- 史载宕渠之战无假醉、草人，张郃是“弃马缘山”仅十余人退走，勿混。
