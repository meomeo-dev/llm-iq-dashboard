# 《三国演义》第75回 关云长刮骨疗毒　吕子明白衣渡江

底本：<https://zh.wikisource.org/wiki/三國演義/第075回>；读取日期：2026-10-19。

## 情节要点

1. 关羽右臂中毒箭，毒入骨，右臂青肿；众将劝回荆州调理，关羽执意不退。
2. 华佗自江东驾小舟来寨；关羽正与马良弈棋，袒臂伸出令看，华佗提议立柱穿环、蒙首，关羽笑拒，设酒席，一面弈棋一面令割（不入画）。
3. 曹操欲迁都，司马懿献计联吴；吕蒙托病，陆逊献计，代守陆口，致书示卑，关羽撤荆州兵赴樊城。
4. 吕蒙点兵，选会水者扮商人、穿白衣摇橹，精兵伏舟中，擒烽火台守军，夜袭荆州；斩取民笠之同乡。
5. 孙权入荆州，虞翻说降傅士仁，傅士仁去南郡招糜芳。

## 选定场面

关羽帐中：右臂袒出伸向前，左手仍在与马良弈棋；华佗尖刀在手、尚未下刀；一名小校捧一只大盆，
空盆托在臂下；帐中众将立于两旁。入画理由：回目前半的前一刻，“伸臂、弈棋、刀在手、盆在臂下”
原文是同一刻，关羽的豪气全靠含笑弈棋显出，不画下刀、刮骨、见血。题面不写“接血”二字，只写空盆。
未选白衣渡江：吕蒙与水手本回无样貌，“白衣”是否白色另有史学解释，画面易起争议；
刮骨前一刻原文细节完整，也是旧题面场面，可校正。具名关羽、华佗、马良。三处依据：

- 「公饮数杯酒毕，一面仍与马良弈棋，伸臂令佗割之。」
- 「佗取尖刀在手，令一小校，捧一大盆于臂下接血。」
- 「佗曰：某便下手，君侯勿惊。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 关羽 | 年近六旬，面如重枣，髯长二尺；坐于帐中，右臂「袒下衣袍」伸出，只画青肿肤色，不画创口、血迹；袍色本回未写，前回末「斜袒着绿袍」，取绿袍；盔甲未写，兜底：帐中不披甲不戴盔；含笑从容；右臂伸出，落子用左手（推断） | 第1、73、74、75回 |
| 华佗 | 「方巾阔服，臂挽青囊」；童颜鹤发（第15回）；右手握尖刀，刀尖朝外未触臂；青囊挂臂 | 第15、75回 |
| 马良 | 本回样貌未写；第52回「眉间有白毛」；兜底：文士，宽袍，对坐棋盘，指间夹棋子 | 第52、75回 |
| 小校 | 一名，捧一只大盆在关羽臂下；盆形制未写，兜底：浅腹大盆，空；军士常服 | 第75回 |

先后核对：华佗入帐时关羽正弈棋→袒臂伸出令看（一刻）→华佗说柱环之法、关羽笑拒「何用柱环」→设酒席→
饮数杯酒毕，弈棋，伸臂令割，佗取刀、小校捧盆（此刻）→下刀、刮骨、掩面（其后）。“伸臂看视”与“伸臂令割”是两刻，取后者。

## 器物与环境

- 地点：樊城前线关羽寨中军帐（原文称“寨”“帐”）；帐形本回未写，兜底：四阿顶方形大帐，门帘半卷。
- 时令：秋（承第74回“八月秋天”），昼夜本回未写。
- 器物：围棋盘（汉代为 17 道方盘，下有四足）与黑白两色棋子（棋色本回未写，兜底）；酒席：食案、耳杯、酒樽；
  尖刀、青囊、空盆；坐处席榻，兜底。
- 现实中会动的：① 帐帘与帐顶幔布随风轻摆；② 关羽长髯与袍袖微动；③ 关羽左手拈子落向棋盘。

## 排除项

- 下刀之后：割开皮肉、刮骨、骨青、血流盈盆、「悉悉有声」、帐上帐下掩面失色、大笑而起、酬金。
- 华佗提出而被关羽拒绝的标柱、大环、绳缚、以被蒙首，不画。
- 同回另场：曹操议迁都、吕蒙托病、陆逊、白衣渡江、虞翻说降；史载为左臂、医者无名，题面按演义右臂、华佗。
- 关羽红脸油彩；华佗道士化、仙气光环；明代硬挺方巾帽。

## 现有题面核对

旧题面：`sanguo-075` / `sanguo-anim-075`（`src/core/classics/sanguo.ts`）。场面保留刮骨疗毒一回，改取下刀前一刻，逐条核对：

- 有据：军帐；袒右臂；与人下棋（对手即马良）；谈笑自若；设酒席；华佗方巾阔服、臂挽青囊；小校捧大盆。
- 无据：「桌」（汉代用几案）；「拈着棋子」「黑子」（棋色未写）；「桌上摆着酒肉」（“饮酒食肉”在刮骨时）；「中军大帐」（原文只称“帐”）。
- 与原著不符：「持小刀刮骨」（原文“尖刀”，刮骨在下刀后）；「小兵捧盆接血」「鲜血滴入盆中」（接血、滴血属血腥画面，且在下刀后，一律删去，盆改空）；
  「帐边将士纷纷掩面」（掩面在“刮骨悉悉有声”之后）；动态稿「细密刮除」同属下刀之后。
- 须防误加：标柱大环（华佗提出、关羽笑拒）；右臂伸出，棋由左手落子（原文未写下棋之手，属推断）。
