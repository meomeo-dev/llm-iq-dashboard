# 《三国演义》第31回 曹操仓亭破本初　玄德荆州依刘表

底本：<https://zh.wikisource.org/wiki/三國演義/第031回>；读取日期：2026-10-19。

## 情节要点

1. 袁绍败回，听逢纪谗言遣使赍剑杀田丰，田丰自刎狱中；袁绍与审配、逢纪、辛评、郭图议立嗣，未决。
2. 袁熙、袁谭、高干各引兵来会，聚四州兵二三十万，屯仓亭；曹操在河上受土人箪食壶浆，下令不得扰民。
3. 仓亭阵前袁尚舞双刀出阵、背射史涣；曹操用程昱“十面埋伏”之计，袁绍大败，吐血回冀州养病。
4. 刘备在汝南得刘辟、龚都，欲袭许都；曹操回军，刘备穰山大败，兵不满千，退至汉江沙滩。
5. 孙乾说动刘表，蔡瑁进谗被叱；刘表出郭三十里迎刘备，分拨院宅居住；曹操因程昱之言还兵许都。

## 选定场面

仓亭下寨之次日，两军隔一片空地各布阵势：袁尚想在父亲面前逞能，舞双刀策马出阵，在两阵之间
来往奔驰；曹操立于己阵前，指着他问左右“此何人”；袁绍立于对阵，注目袁尚。此刻尚未
交锋、无人受伤，动静皆在气势与旗尘。具名限曹操、袁绍、袁尚三人，两边诸将与袁绍另两子一甥作
无名群像。备选：刘备败退汉江沙滩，土人献羊酒聚饮，无杀戮，可作他用。三处依据：

- 「操引诸将出阵，绍亦引三子一甥及文官武将出到阵前」
- 「袁尚欲于父前逞能，便舞双刀，挥马出阵，来往奔驰」
- 「操指问众将曰：此何人」

## 器物与环境

- 地点：仓亭下寨处，黄河（文中称“河上”）近旁的开阔平地；仓亭津为东汉黄河旧渡口，遗址在今山东阳谷县
  一带，具体战场说法不一。
- 时令：本回未写。曹操稍后说“禾稼在田”，兜底：地边可见青禾，晴日，不画雪、不画秋收。
- 器物：两军门旗与军旗；曹操的马鞭（第30回阵前即以鞭指）；战鼓。东汉末高桥鞍已流行，马镫最早实物是
  西晋永宁二年（302年）墓出土的单镫骑俑，三国时通行与否无实证，马不画镫。
- 现实中会动的：① 两军门旗与旌旗迎风翻卷；② 袁尚马蹄后扬起的尘土；③ 战马鬃尾、曹操长髯与战袍衣带。

## 排除项

- 史涣出阵、三合、袁尚拨马背射中其左目坠马：紧随其后，不画箭中目与坠马。
- 十面埋伏、许褚诈劫寨、河上死战、袁绍昏倒吐血：均在其后，不画。
- 袁尚此处用双刀；第32回才“挺枪”战张辽，不画枪。袁绍“幅巾单衣”是败逃时的装束，阵前不画。
- 汝南、穰山、汉江沙滩、荆州迎接属后半回；田丰之死在狱中，殷馗预言属河上父老段，均不混入。
- 不用戏曲脸谱与影视铠甲造型，曹操不画白脸，不画游戏式夸张兵器；不画马镫。
