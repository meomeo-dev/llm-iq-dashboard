# 《三国演义》第48回 宴长江曹操赋诗　锁战船北军用武

底本：<https://zh.wikisource.org/wiki/三國演義/第048回>；读取日期：2026-10-19。

## 情节要点

1. 徐庶认出庞统，求脱身之法；庞统教他散布西凉韩遂、马腾谋反的谣言，徐庶借口请兵守散关，脱身。
2. 十一月十五日（毛本作建安十二年冬）天晴风静，曹操在大船上置酒设乐，月升乌鸦南飞，曹操
   酒酣，以酒奠江，横槊作歌；刘馥言词不吉，被一槊刺死，次日曹操悔泣厚葬。
3. 毛玠、于禁报船只连锁停当；曹操阅水军，程昱提醒火攻，曹操以“隆冬只有西北风”笑之。
4. 焦触、张南请小船夺旗，被韩当、周泰击杀；周瑜山顶观战，见曹营中央黄旗折入江中，
   狂风卷旗角拂面，忽想起一事，大叫吐血倒地（下回接续）。

## 选定场面

月夜江上，曹操立于大船上，以酒奠江，横槊谓诸将，将要作歌；乌鸦自月前向南飞过，
左右侍御与文武众官环列。月色、江面、乌鸦、长槊，一景即把握住“横槊赋诗”的气象，
不画刺死刘馥。具名限曹操一人，其余作群像。三处依据：

- 「东山月上，皎皎如同白日」
- 「忽闻鸦声望南飞鸣而去」
- 「乃取槊立于船上，以酒奠于江中，满饮三爵，横槊谓诸将」

## 器物与环境

- 地点：曹军水寨中央大船，“中央上建‘帅’字旗号，两傍皆列水寨，船上埋伏弓弩千张”；
  曹操四望：东柴桑、西夏口、南樊山、北乌林，南屏山色如画。
- 时令：十一月十五日，“天气晴明，平风静浪”，东山月上，“皎皎如同白日”，“如横素练”；
  起风在次日（“西北风骤起”）。毛本年份作建安十二年，史实为十三年。
- 器物：槊（长于矛的马上长兵，传统标准一丈八尺约4.1米，木杆铁头）；酒器（“满饮三爵”，
  汉代宴饮以樽、勺、耳杯为主，画耳杯或爵均可）；“帅”字旗；大船取楼船式，不画后世福船、帆影重重。
- 现实中会动的：① 月光在微波上闪烁；② 数只乌鸦自画面一侧飞向江对岸，循环往复；
  ③ 旗帜、长髯、衣袍在微风中轻摆，幅度要小，原文“平风静浪”，不画大风。

## 排除项

- 刘馥进言、曹操一槊刺死刘馥、次日悔泣属回中，不画血、不画尸；次日五色旗号阅兵与西北风不混入。
- 焦触、张南、周泰跃船、周瑜吐血属后段；火攻、东风、七星坛（第49回）、诸葛亮、周瑜均不在场。
- 曹操席间说“当娶二乔，置之台上”是对白：不画二乔、女子与铜雀台；杜牧诗句为后人所作，不入画。
- 铁环连锁船只至次日才报“停当”，夜宴不画铁环特写；不画火船与火光。
- 不用戏曲白脸奸相、红袍乌纱，不用影视造型；《短歌行》全诗不写入画面。
