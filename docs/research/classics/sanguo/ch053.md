# 《三国演义》第53回 关云长义释黄汉升　孙仲谋大战张文远

底本：<https://zh.wikisource.org/wiki/三國演義/第053回>；读取日期：2026-10-19。

## 情节要点

1. 张飞取武陵，金旋被城上乱箭射死，鞏志降；关羽请缨取长沙，只带五百校刀手，斩杨龄后与黄忠交战。
2. 第一日战百余合不分胜负；第二日关羽拟用拖刀计，黄忠马失前蹄落地，关羽举刀不杀，命他换马再战。
3. 第三日黄忠想起不杀之恩，两番虚拽弓弦，到吊桥上第三箭射中关羽盔缨根；关羽知其报恩，带箭回寨。
4. 韩玄疑黄忠通敌要斩他，魏延救下黄忠、杀韩玄献城；刘备亲请黄忠降，孔明因反骨欲斩魏延，刘备求免，荆南四郡平定。
5. 后半回孙权大战张辽于合肥，宋谦、太史慈相继身亡；刘琦病亡，鲁肃来吊丧（下回接续）。

## 选定场面

长沙城外吊桥前，第三日清晨：黄忠立于吊桥上，弓弦刚响，一箭射中关羽盔缨根；关羽策赤兔马将近桥头，吃了一惊，
盔缨带箭颤动。入画理由：箭中盔缨是回目“义释”的报恩一笔，物证明确（缨上一箭），无人受伤，不画血。
不取前一日“马失前蹄、举刀饶命”，因倒地者与举刀人同框易被误读为行刑。具名限关羽、黄忠，韩玄可作城楼远景。三处依据：

- 「将近弔桥，黄忠在桥上搭箭开弓，弦响箭到」
- 「正射在云长盔缨根上。前面军齐声喊起」
- 「云长吃了一惊」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 关羽 | 面如重枣（枣红肤色，非油彩），丹凤眼卧蚕眉，髯长二尺（第1回）；外穿绿锦战袍（第25回）；盔有缨，缨色未写，兜底：任画，以箭中缨根为辨认；青龙刀；赤兔马；此刻神情惊诧 | 第1、25、50回；“盔缨根”“吃了一惊” |
| 黄忠 | “年近六旬”（本回），后人诗赞称“白发”，兜底：须发花白；披甲戴盔，未写；“二石力之弓”满开后刚放；刀“带住”，兜底：挂于鞍侧；坐骑：韩玄所赠自乘青马（青白杂毛） | “能开二石力之弓”；“带住刀，把弓虚拽弦响”；“一匹青马” |
| 韩玄（可选远景） | 坐城上观战；平生性急，轻于杀戮；容貌未写，兜底：城楼上一小像 | “玄坐在城上” |

先后核对：杨龄被斩在第一日；马失前蹄、举刀饶命在第二日；第三日先虚拽弓弦两次，再到吊桥上真射一箭；韩玄拿人、魏延救人在其后。

## 器物与环境

- 地点：长沙城外，护城河上的吊桥与城楼；关羽军在桥外，黄忠立桥上。
- 时令天气：第三日“天晓”，清晨；时令与天气本回未写，不强加。
- 器物：弓箭（三棱箭镞、三羽箭）、青龙刀、盔缨；吊桥与城楼（汉代城门吊桥未见确证，画成可升降的木桥即可）。
- 现实中会动的：① 箭杆尾羽与盔缨受冲击颤动；② 黄忠弓弦刚放后的余颤；③ 两匹战马的鬃尾、鼻息与蹄下尘土，关羽长髯随马势后扬。

## 排除项

- 马失前蹄、举刀饶命、拖刀计（只在想法里）、杨龄被斩，均在前一日或前段；虚拽弓弦两次在射箭之前，不画。
- 箭中人身、面门、血迹（金旋一节）；魏延救黄忠、杀韩玄；孙权、张辽、太史慈、宋谦（后半回）。
- 戏曲造型：关羽红脸油彩，黄忠白髯老生；京剧“生平不斩落马之人”的台词不属原文。
- 黄忠用的是弓与刀，不用斧、枪、弩；不画连发或手弩。
