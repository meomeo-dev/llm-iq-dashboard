# 《三国演义》第115回 诏班师后主信谗　托屯田姜维避祸

底本：<https://zh.wikisource.org/wiki/三國演義/第115回>；读取日期：2026-10-19。

## 情节要点

1. 景耀五年冬，姜维第八次伐魏取洮阳，邓艾设空城计，夏侯霸率五百军死于城下（此事不入画）；
   姜维转攻祁山，邓艾固守不出。
2. 后主信宦官黄皓，右将军阎宇欲代姜维，一日三诏召姜维班师；姜维回成都，后主十日不朝，
   秘书郎郤正在东华门道破原委。
3. 次日姜维径入后园，见后主与黄皓宴饮，泣奏请杀黄皓，后主笑而不允，令人唤出黄皓来拜；
   姜维忿而出，转而听从郤正之计，请往沓中屯田种麦避祸，自引兵八万前去。
4. 邓艾在沓中沿路下营四十余座，连络如长蛇；司马昭定伐蜀之计，荀勖荐邓艾、钟会，
   魏景元四年秋七月初三日钟会出师。

## 选定场面

后园亭下，姜维叩头请诛黄皓：后主坐在亭中宴席上，姜维在亭下叩首，黄皓仍躲在湖山一侧，
尚未被唤出。具名姜维、后主、黄皓，近侍可作群像。三处依据：

- 「後主與黃皓在後園宴飲，維引數人逕入。」
- 「皓急避於湖山之側。」
- 「維叩頭奏曰：陛下今日不殺黃皓，禍不遠也。」

取“后主信谗”不取“沓中屯田”：前者是回目上联，三人分处亭中、亭下、假山后，动作各自单一，
构图一眼可辨；屯田一节原文只有“來沓中種麥”，无动作与衣冠可依。

先后核对：姜维入园（皓已先避）→拜后主、泣奏→后主默然→再奏→后主笑称黄皓“趨走小臣”→
姜维叩头（此刻，皓仍在湖山侧）→后主引“愛之欲其生”→令近侍唤出黄皓→皓哭拜（后）。
唤出与哭拜均在后，不画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 姜维 | 大将军，景耀五年约六十岁（生于202年，据史书）；本回未写样貌衣冠，兜底：不披甲，素净袍服，武官冠，须发花白，面有泪痕，双手伏地叩首；史载郤正称其衣服车马只取够用，不加华饰 | 第115回“泣奏”“叩頭奏曰” |
| 后主 | 刘禅，约五十五岁；本回未写衣冠，兜底：汉式交领便袍，头戴帻或小冠，坐席上，神态松弛带笑，不起身 | “笑曰”“愛之欲其生” |
| 黄皓 | 宦官，后主称“趨走小臣”；本回与史书均未写样貌，兜底：中年，深色短袍，帻上小冠，躲在假山石后探出半身，缩肩垂目 | 第115回“急避於湖山之側” |
| 近侍 | 数人，听后主吩咐，兜底：素色短袍束帻，侍立亭侧，不持兵器 | “令近侍” |

## 器物与环境

- 地点：成都宫中后园，园内有亭，亭旁有“湖山”，原文未释义，兜底：一组假山石，不画大湖。
- 时令天气：只写景耀五年冬十月出师，回成都的月份与天气未写，不画雪、不画花。
- 器物：宴席取汉魏席地而坐的樽、杓、耳杯与矮案；亭取方形单层木亭、瓦顶（汉代早期亭形，据摘要）。
- 现实中会动的：① 园中树叶与人物衣带随风轻摆；② 飘落的叶片；③ 姜维脸上泪珠滴落。

## 排除项

- 黄皓被唤出、哭拜姜维，姜维忿出、再见郤正（均在后）；东华门遇郤正、三诏召回（在前）。
- 夏侯霸死于城下、刘琰妻被众军以履撻面（血腥，不入画）；沓中种麦、钟会献图属后文。
- 后世造型：戏曲白脸宦官、拂尘；后主冕旒龙袍、金銮殿龙椅；姜维靠旗、雉鸡翎；明清曲廊亭榭。
- 史实：请杀黄皓、后主不许见于裴注引《华阳国志》，演义铺成；史书只写姜维请往沓中“種麥”。
