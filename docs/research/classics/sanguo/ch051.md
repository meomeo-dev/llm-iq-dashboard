# 《三国演义》第51回 曹仁大战东吴兵　孔明一气周公瑾

底本：<https://zh.wikisource.org/wiki/三國演義/第051回>；读取日期：2026-10-19。

## 情节要点

1. 刘备在油江口与周瑜约定：周瑜先取南郡，取不下再由刘备取；周瑜攻南郡，曹仁两入吴阵救出牛金，甘宁取夷陵被围，周瑜亲救，曹军弃马而逃。
2. 曹仁拆曹操遗计，弃城虚插旌旗；周瑜见城门大开，直入瓮城，先入的兵卒陷入坑中，周瑜被弩箭射中左肋落马。
3. 周瑜卧床后在阵前假装箭疮崩裂，程普举哀，曹仁夜来劫寨，四面伏兵齐出，曹仁大败奔襄阳。
4. 周瑜、程普赶到南郡城下，城上旌旗布满，赵云在敌楼上报称已奉军师令取城；周瑜大怒，命攻城，城上乱箭射下。
5. 探马报张飞袭荆州、关羽袭襄阳，周瑜大叫一声金疮迸裂（下回接续）。

## 选定场面

天明前后的南郡城下：城头旌旗插满，赵云立于敌楼上喊话；周瑜在城下马上仰首，怒而下令攻城，城上乱箭尚未射下。
入画理由：“孔明一气周公瑾”的回目落在这一刻，上下对望、城楼旌旗与马上怒容足以表达，不画血。具名限赵云、周瑜，
程普作马后群像。城中陷坑、周瑜中弩在数日前，假装吐血在前一日，探马报信后的“金疮迸裂”在其后，均不入画。三处依据：

- 「见旌旗布满，敌楼上一将叫曰」
- 「吾奉军师将令，已取城了。吾乃常山赵子龙也」
- 「周瑜大怒，便命攻城」

先后核对：曹仁弃城、周瑜中弩在数日前；诈死、夜袭大败在昨夜；天明城下见赵云为所选一刻；探马报荆襄易手、金疮迸裂在其后。

## 器物与环境

- 地点：南郡（江陵）城外，城门上的敌楼与垛口；汉末城楼为门阙加望楼的形象，兜底：二层木构城楼、土墙垛口，城门紧闭（本回未写）。
- 时令天气：赤壁同年隆冬；经五更混战后“收住众军”，时间为天明前后；天气未写，不强加雨雪。
- 器物：旌旗、长枪、弓；汉代弩可踏张或腰引，此刻不画射击。
- 现实中会动的：① 城头旌旗在晨风里飘；② 周瑜与程普战马的鬃毛、鼻息和蹄下尘土；③ 盔缨、袍带与赵云披风被风带动。

## 排除项

- 周瑜吐血、金疮迸裂、中弩落马、城中陷坑（数日前或探马报后）；城头箭雨（下令之后）。
- 孔明不在城上（他在荆州）；张飞袭荆州、关羽袭襄阳、陈矫被擒，均只是探马口报，不画。
- 戏曲周瑜的雉尾翎与小生白面；赵云白袍银枪；影视造型。
- 曹仁、牛金已退向襄阳，不画；不画“城门大开、直入瓮城”（数日前）。
