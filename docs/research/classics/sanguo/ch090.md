# 《三国演义》第90回 驱巨兽六破蛮兵　烧藤甲七擒孟获

底本：<https://zh.wikisource.org/wiki/三國演義/第090回>；读取日期：2026-10-19。

## 情节要点

1. 孟获败回银坑洞，妻弟带来洞主荐八纳洞木鹿大王；孔明攻取三江城，祝融夫人以飞刀擒张嶷、马忠，后被马岱绊马索擒获，换回二将。
2. 木鹿大王骑白象、手摇蒂钟念咒，驱虎豹毒蛇败赵云、魏延；孔明取随军红油柜车中的木刻彩画巨兽，口吐火焰，吓退真兽，是为六破。
3. 带来洞主缚孟获来降，孔明识破，第六次放回。
4. 孟获借乌戈国兀突骨的藤甲军；孔明令魏延连败十五阵，引入盘蛇谷火烧藤甲军（不入画），第七次擒孟获。
5. 孟获垂泪肉袒拜服，孔明永令他为洞主；班师至泸水，阴云狂风骤起。

## 选定场面

银坑洞前阵地：孔明端坐小车，羽扇一摇，风向吹回蛮阵；蜀阵木制彩画巨兽口吐火焰、鼻出黑烟拥出，
木鹿大王骑白象、手摇蒂钟，面前的虎豹豺狼被吓得不敢前进。入画理由：回目“驱巨兽”的正面，色彩与动势俱足，不画伤亡。三处依据：

- 「孔明将羽扇一摇，其风便回吹彼阵中去了」
- 「蛮洞真兽见蜀阵巨兽口吐火焰，鼻出黑烟，身摇铜铃，张牙舞爪而来」
- 「诸恶兽不敢前进」

先后核对：孟获指“车上坐的便是诸葛亮”→木鹿念咒摇钟，狂风大作，猛兽突出→孔明将羽扇一摇，风回吹蛮阵，蜀阵假兽拥出（此刻）
→真兽见巨兽不敢前进，继而奔回，冲倒蛮兵（后）→孔明驱兵大进，木鹿死于乱军（后，不画）。孟获指认在前，真兽奔逃在后。

## 器物与环境

- 地点：银坑洞口外的开阔地（孔明“布于洞口”）；地形本回未写，兜底：山前平地，远处洞口与山影。
- 时令：承第89回六月炎天；木鹿咒起后“狂风大作”，孔明羽扇后风向反转；时辰未写，兜底：白昼。
- 器物：蒂钟（原文如此，木鹿施法时手摇的钟铃类法器）、铜铃、五色绒线毛衣、钢铁牙爪、红油柜车（十辆，可置阵后）、羽扇、大旗。
- 现实中会动的：① 假兽口中的火焰跳动、黑烟被反向风吹向蛮阵；② 假兽身上的铜铃与五色绒毛摆动，大旗被风吹向同一侧；
  ③ 孔明羽扇与木鹿手中蒂钟小幅往复摇动。

## 排除项

- 前：祝融夫人（背插五口飞刀，手挺丈八长标，骑卷毛赤兔马）擒张嶷、马忠、被马岱绊马索擒获；木鹿首战败赵云、魏延，蜀兵溃退。
  后：木鹿大王死于乱军，维基条目写“被象摔下踩死”与毛本不合，均不画；兀突骨骑象、日月狼须帽、藤甲军；盘蛇谷火烧；
  孟获垂泪、肉袒跪拜。均不入画。
- 易混：木鹿大王骑的是白象；兀突骨“骑象当先”是后半回，戴日月狼须帽、两肋鳞甲，不得与木鹿混画。
  白象不是佛教六牙白象，也不是普贤菩萨坐骑。孟获第87回的紫金冠、卷毛赤兔马，在本场不出现。
- 假兽是木刻彩画而非活物；真兽退走是被吓，不画真兽被烧、被刺；不画蜀兵被兽追逐溃逃。
- 后世造型不取：孔明乘四轮车（本批无此词）、道冠八卦衣游戏造型；木鹿的骷髅法杖、兽皮面具；齿轮蒸汽式机关兽。
