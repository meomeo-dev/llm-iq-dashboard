# 《三国演义》第27回 美髯公千里走单骑　汉寿侯五关斩六将

底本：<https://zh.wikisource.org/wiki/三國演義/第027回>；读取日期：2026-10-19。

## 情节要点

1. 曹操叱退蔡阳，不听程昱追杀之议，命张辽先请住关羽，自带数十骑以路费、征袍相送。
2. 关羽立马桥上，见曹操一行手中无兵器，才放心；婉辞黄金，不下马，用青龙刀尖挑锦袍披身，谢别北去。
3. 关羽寻回被劫的二嫂，廖化献杜远首级请罪，被谢却同行；宿胡华庄，受托带信给其子胡班。
4. 关羽依次过东岭关（斩孔秀）、洛阳（斩孟坦、韩福）、汜水关（斩卞喜）、荥阳（斩王植）、
   黄河渡口（斩秦琪），共五关六将；胡班、普净暗中相助。
5. 孙乾迎告刘备已往汝南；夏侯惇追至（下回接续）。

## 选定场面

许昌城外一座桥上，关羽勒住赤兔马横刀而立，曹操率数十骑赶到，令诸将勒马、左右排开，手中皆无兵器；
一名军官下马，双手捧锦袍递上，关羽恐有变，不下马，以青龙刀尖挑起锦袍。取袍刚被刀尖挑起、
尚未披上的一瞬：一问一答、互相试探，却无一人出手，不涉杀戮。具名限关羽、曹操两人，
捧袍军官与随从不具名。三处依据：

- 「操见关公横刀立马于桥上，令诸将勒住马匹，左右排开」
- 「关公见众人手中皆无军器，方始放心」
- 「用青龙刀尖挑锦袍披于身上，勒马回头称谢」

## 器物与环境

- 地点：许昌城北官道上的一座桥；位置不详，毛本只称“桥”，没有桥名。桥形未写，汉画像石所见多为水平梁桥，
  兜底：平直木梁桥，桥面铺板，低栏，不画拱桥、牌坊。
- 时令：本回未写季节；时辰为日间（后文“约行三十里”“至天晚”才投宿），兜底：晴，不强加雪或花。
- 器物：锦袍一领（色纹未写，兜底：锦纹长袍）；黄金一盘（盘托）；青龙刀；赤兔鞍辔，只画鞍辔，不画足镫。
- 现实中会动的：① 挑在刀尖的锦袍衣摆随风垂荡；② 关羽长髯与赤兔鬃尾随风飘；③ 桥下水面波纹（桥下有水为兜底）。
- 构图提示：关羽居画面右侧桥心，曹操一行排开在画面左侧桥头，中间留出刀尖与锦袍。

## 排除项

- 毛本全文只称“桥”，没有“灞陵桥”之名：不画“灞陵桥”匾额、折柳，不用京剧《灞桥挑袍》的以酒祭刀。
- 五关六将各关均在桥后，次序为东岭关孔秀→洛阳孟坦、韩福→汜水关卞喜→荥阳王植→黄河渡口秦琪；
  本场不画任何关隘、斩将、普净、胡班、廖化、杜远，二嫂车仗已先行，不入画。
- 蔡阳在本回开头被曹操叱退，斩蔡阳在第28回古城；夏侯惇追赶在回末；本场皆不出现。
- “秉烛立于户外，自夜达旦”是第25回驿馆的毛本原文，本回无；荥阳驿馆只写“灯下凭几看书”，
  未称《春秋》，不画“夜读春秋”。
- 曹操不拔剑、许褚不持刀，关羽不下马、刀尖不指向曹操；不用京剧脸谱、影视或游戏造型。
