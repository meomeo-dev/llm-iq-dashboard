# 《三国演义》第91回 祭泸水汉相班师　伐中原武侯上表

底本：<https://zh.wikisource.org/wiki/三國演義/第091回>；读取日期：2026-10-19。

## 情节要点

1. 孔明班师至泸水，九月阴云狂风，兵不能渡；孟获称旧例须以四十九颗人头并牛羊祭猖神，孔明不肯杀人，
   以面塑人头、内裹牛羊肉，名“馒头”，三更金冠鹤氅亲祭，放声大哭，次日风平浪静，全军渡泸。
2. 回成都，后主出郭三十里迎接，下辇立于道旁，孔明伏道请罪，后主扶起，并车而回。
3. 曹丕病死，曹叡即位，司马懿乞守雍、凉；孔明用马谡计散布流言，曹叡削司马懿职，孔明大喜，决意伐魏。
4. 次日早朝，孔明出班上《出师表》；后主恐其劳神，谯周以天象谏阻，孔明不从，留郭攸之、董允、费祎等理内外事。
5. 选定建兴五年春三月丙寅日出师；赵云自请先锋，孔明劝阻不住，遣邓芝同往；夏侯楙请战，王朗谏阻不听。

## 选定场面

成都早朝，后主在上听政，孔明自朝班中走出，把《出师表》呈上，君臣相对，后主尚未开口。入画理由：回目下联
“伐中原武侯上表”的起点，一人出班、一表在手，无打斗，无灾异，构图以孔明与后主一立一坐、百官分列两侧为轴。
不选同回上联的夜祭泸水（金冠鹤氅、四十九盏灯、鬼魂隐现，易混入人头祭品与鬼怪），记为备选。具名孔明、后主。

- 「次日，后主早朝，大会官僚，孔明出班，上《出师表》一道。」

先后核对：司马懿被削职→次日早朝，孔明出班上表（此刻）→后主览表，称“恐劳神思”→谯周出奏天象→孔明不从、
分派官职→赵云请缨。览表与谏阻均在上表之后，不入画。原文只写“早朝”，未写“殿上”，殿宇形制见下。

## 器物与环境

- 地点：成都宫中朝会处，原文只写“早朝”“班部”。汉制殿宇建于夯土高台基，南面敞开、设两阶，殿内帷幄与屏风前
  君臣席地跪坐（据摘要）；兜底：台基上的木构敞殿，御座后设屏风帷帐，不画明清金銮殿、蟠龙金柱。
- 时令：上表在出师（建兴五年春三月丙寅日）之前，季节与天气未写，不强加。
- 器物：《出师表》。三国简牍、帛与纸并用，表的载体原文未写（据摘要）；兜底：卷起的帛书或编连的简册，
  不画折叠的明清奏折、黄绸圣旨。
- 现实中会动的（均为兜底，原文未写）：① 殿中帷帐垂幔随气流微摆；② 灯烛火苗微颤；③ 孔明衣袖与表卷系带轻轻摆动。

## 排除项

- 夜祭泸水：金冠鹤氅、四十九盏灯、“馒头”祭品、鬼魂、愁云怨雾、董厥读祭文；后主出郭迎接、孔明伏道请罪。
- 上表之后的后主览表答话、谯周观天象、孔明分派官员、赵云请缨；之前的马谡献计、曹叡削司马懿。
- 他回人物：赵云、魏延、司马懿、曹叡群臣；孔明四轮车与战阵。
- 清代奏折、朝珠花翎、龙袍、蟠龙金銮殿；“馒头”出自诸葛亮之说见于宋人笔记，属后世附会，本回只写其名。
