# 《三国演义》第10回 勤王室马腾举义　报父雠曹操兴师

底本：<https://zh.wikisource.org/wiki/三國演義/第010回>；读取日期：2026-10-19。

## 情节要点

1. 李傕、郭汜掌朝政；马腾、韩遂勤王，马超十七岁连斩李蒙、王方，终因内应泄密退兵。
2. 朱儁荐曹操破青州黄巾，曹操收降兵编为青州兵，荀彧、荀攸、程昱、郭嘉、典韦、于禁等来投。
3. 曹操派人接父曹嵩，陶谦厚待并遣张闿护送；张闿在华、费间古寺夜杀曹嵩全家，劫财而逃。
4. 曹操要洗荡徐州，陈宫来劝不听；陶谦闻讯痛哭，聚众出迎。
5. 两军对阵：曹军白旗“报雠雪恨”，曹操身穿缟素扬鞭大骂，夏侯惇出阵，曹豹迎战，忽然狂风飞沙，各自收兵。

## 选定场面

徐州城外阵前：曹操身穿缟素，扬鞭指骂；陶谦立马门旗下，欠身辩白；夏侯惇应声拍马欲出。具名三人，
白旗缟素与欠身辩白的反差是回目后半“报父雠曹操兴师”的画面；停在两将交马之前，无血腥。
曹嵩遇害、马超刺将均不取。三处依据：

- 「中军竖起白旗二面，大书「报雠雪恨」四字」
- 「曹操纵马出阵，身穿缟素，扬鞭大骂」
- 「陶谦亦出马于门旗下，欠身施礼」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 曹操 | 身长七尺，细眼长髯（第1回）；本回身穿缟素（白色孝服），骑马扬鞭。盔甲、兵器、马色本回未写，兜底：白色孝服，少量甲片外露，手只执马鞭 | 对阵段；第1回曹操出场段 |
| 陶谦 | 徐州太守，温厚纯笃，年迈（史载卒年六十三）；出马门旗下，欠身施礼，神态是辩白。甲胄未写，兜底：披甲加冠，须鬓花白，不画凶相 | 对阵段；“为人温厚纯笃” |
| 夏侯惇 | 曹操部将，“应声而出”；兵器、甲色未写，兜底：披甲持长枪；两目俱全，失左目在第18回 | 夏侯惇应声段 |

## 器物与环境

- 地点：徐州城外旷野，两军布阵；曹军“如铺霜涌雪”，中军竖白旗二面；陶谦在门旗下，曹豹在侧，不具名。
- 时令天气：曹嵩遇害在夏末秋初；对阵日“狂风大作，飞沙走石”起在两将交马之后，静态场面不画风沙，动态场面可写风势渐起。
- 器物：白旗二面、门旗、马鞭、长枪；旗上只写“报雠雪恨”四字，不扩写檄文。
- 现实中会动的：① 白旗旗面在风中翻卷；② 风起时地面尘沙；③ 曹操白色孝服衣袂与战马鬃尾。

## 排除项

- 曹嵩一家遇害（华、费间古寺、大雨夜、三更动手、放火烧寺），曹操闻讯哭倒于地，均不入画；“尽行屠戮”“发掘坟墓”只是号令与暴行，不画。
- 史书两说：《后汉书》作陶谦派轻骑追杀，《三国志》注引《吴书》作张闿护送时见财杀人；演义取后者，陶谦神态按辩白画，不画凶相。
- 夏侯惇独眼（第18回）、典韦（本回前段旗杆立风中）、陈宫（帐中劝谏，不在阵前）、刘备（第11回才至）均不入此场。
- 马腾、韩遂、马超勤王属前半回，马超枪刺王方、生擒李蒙均不取。
- 不用京剧白脸脸谱与影视造型，曹操只据“细眼长髯”。
