# 《三国演义》第85回 刘先主遗诏托孤儿　诸葛亮安居平五路

底本：<https://zh.wikisource.org/wiki/三國演義/第085回>；读取日期：2026-10-19。

## 情节要点

1. 夷陵败后刘备退居白帝城，改馆驿为永安宫；章武三年夏四月病重，梦见关羽、张飞（不入画），遣使召孔明、李严。
2. 孔明带刘永、刘理到永安宫；刘备请孔明坐于龙榻之侧，托付嗣子，说“君才十倍曹丕”，孔明汗流叩头流血。
3. 刘备请孔明坐于榻上，命鲁王刘永、梁王刘理同拜孔明，以父事之；又嘱赵云与众官，随后驾崩（不入画）。
4. 刘禅即位，改元建兴；曹丕依司马懿策，起五路大兵；孔明称病不出，后主亲到相府，见他在池边观鱼。
5. 孔明说四路已退，只缺说吴之人，荐邓芝使吴。

## 选定场面

永安宫寝殿内：刘备卧于龙榻，孔明坐在榻上，刘永、刘理走到榻前并肩下拜孔明，群臣在后侍立。
入画理由：这是回目“遗诏托孤”的收束，一榻、一坐、二拜即成构图，不画驾崩。三处依据：

- 「先主又请孔明坐于榻上，唤鲁王刘永、梁王刘理近前」
- 「尔兄弟三人，皆以父事丞相，不可怠慢。」
- 「遂命二王同拜孔明。二王拜毕」

| :-- | :-- | :-- |

| 群臣、内侍 | “孔明等泣拜”，诸臣已召入殿；不具名，侍立榻后；李严、赵云、马谡本刻不入画 | 第85回 |

先后核对：夜梦关张（前夜）→孔明到，拜伏榻下→请坐榻侧、抚背→马谡退→写遗诏→孔明泣拜，内侍扶起，先主一手掩泪、一手执其手
→孔明汗流，叩头流血→先主又请孔明坐于榻上，唤二王近前，命二王同拜（此刻）→二王拜毕，孔明答话→先主谓众官、嘱赵云→驾崩。
执手、叩头在前，嘱赵云与驾崩在后；此刻不画执手。

## 器物与环境

- 地点：白帝城永安宫寝殿（馆驿改，第85回）；白帝城临长江瞿塘峡口。榻具形制本回未写，兜底：汉代低矮木榻，
  榻后立屏风、榻上可张帷帐；不画西式高脚床。
- 时令：章武三年夏四月；时辰、天气本回未写，兜底：殿内灯光为主。
- 器物：龙榻、遗诏（已递孔明，此刻手中有无未写，不画）；汉代照明以青铜油灯为主，蜡烛不是主流，不画西式蜡烛烛台。
- 现实中会动的：① 灯焰摇曳；② 帷帐与屏前轻纱随穿堂风微动；③ 殿窗外江面云雾缓缓飘移。

## 排除项

- 前一刻：梦见关羽、张飞，阴风吹灯；孔明叩头流血；先主执孔明手掩泪。后一刻：嘱赵云、谓众官、驾崩、灵柩、开读遗诏。
- 刘禅留守成都，不在场；黄权、曹丕、朱桓、五路兵、孔明观鱼、邓芝均为另场。
- 易混：“白帝城托孤”是俗称，原文地点为永安宫；刘备不是在城楼上，不画城墙与江景全景。
- 后世造型不取：十二旒冕与戏曲蟒袍、刘备长须大耳的影视扮相、夸张的捶胸痛哭；不画死亡瞬间。
