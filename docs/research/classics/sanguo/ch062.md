# 《三国演义》第62回 取涪关杨高授首　攻雒城黄魏争功

底本：<https://zh.wikisource.org/wiki/三國演義/第062回>；读取日期：2026-10-19。

## 情节要点

1. 张昭献计离间刘备与刘璋；刘备依庞统策向刘璋求精兵三四万、粮十万斛，刘璋只拨老弱四千、米一万斛，刘备怒毁回书。
2. 庞统献上、中、下三计，刘备取中计；张松密书被其兄张肃告发，张松全家被斩，刘璋令各关不放荆州一人一骑。
3. 刘备托言回荆州，在涪水之上帐中擒杨怀、高沛，用其二百随从赚开涪水关；次日宴上与庞统言语相忤，次早谢罪。
4. 刘璝、冷苞、张任、邓贤守雒城，途中得紫虚上人偈语；黄忠、魏延帐前争打头功，庞统令各打一寨，魏延抢功中伏，黄忠射杀邓贤救之。
5. 吴懿等援雒城，冷苞谋决涪江水；刘备遣孟达、霍峻守葭萌关；彭羕来访，与法正相识。

## 选定场面

涪水关公厅阶前（得关后，刘备聚众问谁敢建头功）：魏延出列要替黄忠，说“就主公之前，当面比试”；黄忠趋步
走下台阶，口里叫小校取刀，刘备起身急止，伸手拦阻。刀尚未到手，无人拔刀。入画理由：回目“黄魏争功”的最高点，
三人姿态各异，无血腥，足以表现“两虎相斗”。具名黄忠、魏延、刘备，庞统可立刘备侧作第四人。三处依据：

- 「就主公之前，当面比试。」
- 「黄忠遂趋步下阶，便叫小校将刀来。」
- 「玄德急止之曰：『不可。吾今提兵取川，全仗汝二人之力。』」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 黄忠 | 老将（魏延称“年纪高大”）；须发衣甲本回未写，兜底：须发斑白，甲外战袍；兵器是刀（“这口刀，这张弓”），此刻空手下阶，刀未入手；不画马 | 第53、62回 |
| 魏延 | 面如重枣，目若朗星（第53回）；比黄忠年轻；本回他“纵马提刀”，此刻立阶下不拔刀；衣甲未写，兜底：戎装；脑后反骨不入画 | 第53、62回 |
| 刘备 | 身长七尺五寸，两耳垂肩，双手过膝，面如冠玉（第1回）；起身一手拦阻；衣冠未写，兜底：便服袍、巾，不披甲 | 第1、62回“急止之” |
| 庞统（可选） | 浓眉掀鼻，黑面短髯，形容古怪（第57回）；立刘备侧未发言，“汝二人不必相争”在其后；兜底：文士袍、巾 | 第57、62回 |

先后核对：魏延出列请替→黄忠大怒问“敢与我比试武艺么”→魏延提议当面比试→黄忠下阶叫刀→刘备急止（此刻）→庞统令各打一寨。
黄忠打冷苞寨、魏延打邓贤寨、魏延中伏、黄忠射邓贤，都在其后。

## 器物与环境

- 地点：涪水关公厅（前文“设宴于公厅”）阶前，众将与小校在阶下。汉代“堂”是无前檐墙的敞厅，设台阶，席地而坐，坐具为榻与席；
  画敞厅、台阶、席榻，不画椅子。
- 时令：时辰与天气本回未写；兜底：日间，无雨雪，不强加季节。
- 器物：刀（在小校处）、台阶、席与榻；汉末军中常见环首直刀，“凤嘴刀”等名号本回无据。
- 现实中会动的：① 阶前旗幡（兜底）；② 黄忠下阶时的袍摆、须髯，与魏延披风；③ 堂上垂帷幔与刘备衣袖（汉画像石所见堂内垂帷幔，兜底）。

## 排除项

- 拔刀比武、黄忠射杀邓贤、魏延马失前蹄、冷苞被擒，均在此刻之后。
- 同回另场：帐中擒杨怀高沛、“帅”字旗被旋风吹倒、刘封关平、斩杨高、紫虚上人、斩张松。
- 刘备“金甲锦袍”（稍后夺寨时才写）；魏延脑后反骨（第53回孔明所见）。
- 京剧魏延紫色十字门花脸、戏曲靠旗与白髯口；后世刀名；椅子与桌式宴席。
