# 《三国演义》第101回 出陇上诸葛妆神　奔剑阁张郃中计

底本：<https://zh.wikisource.org/wiki/三國演義/第101回>；读取日期：2026-10-19。

## 情节要点

1. 孔明用添灶法退回汉中，入成都问明召回缘由，查实是苟安散布流言，诛妄奏的宦官，责蒋琬、费祎失察。
2. 杨仪议分兵两班、百日一换；建兴九年春二月孔明复出师（五出祁山），司马懿命张郃结营祁山，
   自与郭淮巡天水诸郡，防蜀军割麦。
3. 孔明到卤城，知陇上麦熟，却见司马懿已在陇上；孔明沐浴更衣，备四辆一样妆饰的四轮车，
   二十四人披发仗剑、关兴扮天蓬，诱得魏军疑为神兵，闭门不出，三万蜀军割尽陇上麦。
4. 司马懿与郭淮夜攻卤城，中四角伏兵；换班军不肯归，以逸待劳大破雍、凉兵；李严书告东吴将寇，孔明退军。
5. 张郃力请追击，被魏延、关兴轮番诈败引至木门道，滚木乱箭射死（此事不入画）；李严妄奏被谪，
   孔明练兵三年，建兴十二年再议出师，谯周谏阻。

## 选定场面

陇上，司马懿自出营远望：孔明乘四轮车朝魏营而来，端坐车上；二十四名精壮之士皂衣跣足、披发仗剑，
分列车左右；关兴扮作天蓬模样，步行在车前执旛。具名孔明、关兴、司马懿。三处依据：

- 「只见孔明簪冠鹤氅，手摇羽扇，端坐于车上」
- 「左右二十四人，披发仗剑；前面一人，手执皂旛。」
- 「令关兴结束做天蓬模样，手执七星皂旛，步行于车前。」

入画理由：回目上联“出陇上诸葛妆神”的正题，车、衣冠、人数、旛原文俱全，无打斗。与第93回骂王朗的四轮车
（素衣皂绦）、第100回斗阵的四轮车（手摇羽扇）区分，本回特征在“簪冠鹤氅+二十四人披发仗剑跣足+天蓬扮相+
七星皂旛”。备选（不入画）：木门道张郃中计。

先后核对：前军回报“司马懿引兵在此”→孔明沐浴更衣，备三辆替身车（姜维、马岱、魏延各护一辆）→选二十四人、
关兴扮天蓬，“孔明端坐于上，望魏营而来”→哨探军见之大惊，报司马懿，“懿自出营视之”（此刻入画）→
司马懿遣二千人追（后）→孔明回车缓行，魏兵追三十里不及，起阴风冷雾（后）→推车歇下、再追二十里、回车倒行（后）
→左右两路又现“孔明”（后）。孔明不披发、不仗剑、不下车，不画追赶、回车与倒行。

## 器物与环境

- 地点：陇上，上邽附近，魏营在前方；卤城在今甘肃礼县盐官镇一带（据摘要），画面只取陇上麦地与坡岗。
- 时令：原文先写“建兴九年春二月”出师，又写“陇上麦已熟”，二者冲突；史载割麦先于五月的卤城之战（据摘要），
  麦熟月份页面未写。兜底：熟黄麦田，不画春花、不画雪。昼夜、天气本回未写，兜底晴昼，不画雾
  （“阴风习习，冷雾漫漫”是魏兵追赶时才起，在后）。
- 器物：四轮车（形制本回未写，兜底素木无顶小车，不加华盖；《语林》称“素舆”，据摘要）；七星皂旛（黑色长幡，
  星数七，星色未写，兜底白点）；羽扇；二十四把剑；伺候割麦的三万军（镰刀、驮绳）在画外。
- 现实中会动的：① 皂旛、披散的头发、鹤氅下摆随风摆动；② 孔明手中羽扇往复轻摇；③ 车轮缓转、麦浪起伏。

## 排除项

- 孔明披发仗剑、赤足、八卦衣、戏曲妆神扮相；替身车上所坐之人（原文未写），本刻只画孔明本车。
- 同回前后：回车缓行与倒行、魏兵追三十里、阴风冷雾、“缩地”之说、左右两路又现的“孔明”（均在后）；
  卤城夜战、木门道滚木万弩射杀张郃与“围猎”之语；李严假告急；信砲与炮响是信号声，不画炮筒。
- 他回：第93回素衣皂绦骂王朗；第100回渭滨斗阵、八卦阵；第102回张嶷扮六丁六甲神兵（鬼头兽身，
  五彩涂面，身挂葫芦，也是装神，易混）；第104回孔明木像坐四轮车退司马懿。
- 后世：《西游记》猪八戒的天蓬元帅与钉耙；道教天蓬三头六臂、赤发（《道法会元》，非本回写法）；影视缩地特效。
- 六出祁山逐次：一出第91–96回（建兴六年春，街亭）；二出第97回（陈仓、郝昭、王双，费耀中计）；
  三出第98回后半–第99回（建兴七年，陈仓、散关、武都、阴平，郭淮孙礼、张郃戴陵）；
  四出第100回（建兴八年秋，箕谷、渭滨斗阵、添灶）；五出即本回（建兴九年春二月）；
  六出第102–104回（建兴十二年春二月，北原、木牛流马、上方谷、五丈原）。
- 史实：割麦、卤城之战、张郃中箭死于木门，正史均无妆神；关兴扮天蓬无史料依据（均据摘要）。
