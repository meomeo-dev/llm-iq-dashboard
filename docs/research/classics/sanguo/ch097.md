# 《三国演义》第97回 讨魏国武侯再上表　破曹兵姜维诈献书

底本：<https://zh.wikisource.org/wiki/三國演義/第097回>；读取日期：2026-10-19。

## 情节要点

1. 建兴六年秋九月，曹休石亭大败，忧愤病死；赵云三更病逝，后主追赠大将军、谥顺平侯。
2. 杨仪呈上孔明《后出师表》，后主准其出师；孔明起兵三十万，魏延督前部，直奔陈仓道口。
3. 曹真荐王双为先锋，郝昭守陈仓；鄞祥两次劝降被拒，百乘云梯被火箭焚、冲车被飞石打折，
   二十余日不下；王双斩谢雄、龚起，流星锤伤张嶷，孔明改取斜谷、祁山。
4. 姜维遣心腹向曹真诈献密书，约举火为号；费耀引五万兵接应，遇孔明四轮车诱阵，羽扇一招
   伏兵齐出，费耀自刎；孔明驻兵祁山前。
5. 曹真折将，魏主召司马懿，懿称“已有退诸葛亮之计”（下回接续）。

## 选定场面

曹真营中大帐：被伏路军从山谷捉来的细作跪在帐下，曹真已解其缚、屏退左右，细作从贴肉衣内
取出姜维密书呈上，曹真伸手接书，将拆未拆；不画读信后的大喜，不画费耀。具名曹真（细作无名）。
三处依据：

- 「真乃去其缚，左右暂退。」
- 「某乃姜伯约心腹人也，蒙本官遣送密书。」
- 「其人于贴肉衣内取出呈上，真拆视之」

入画理由：回目下联“姜维诈献书”的核心瞬间，帐内一跪一坐、一封书信，无打斗；上联“再上表”的
朝堂奏表已在第91回用过，不重复。备选（不入画）：陈仓城下郝昭令三千军各执火箭射云梯（在本回），
因第98回的场面同在陈仓城而让出。

先后核对：细作被押入跪帐下→自称“不是奸细”，乞退左右→真去其缚，左右暂退→细作自报“姜伯约
心腹人”→真问“书安在”→细作取出呈上（此刻，真接书）→真拆视，读毕大喜，称“此天使吾成功也”
（后）→真唤费耀商议，耀引兵五万（后）。缚已去，不画绳索；大喜、商议均在后，不入此画。

## 器物与环境

- 地点：曹真营中大帐，营址本回未写（原文只称曹真在“洛口”分调郭淮、孙礼，细作自“山谷中”捉来）；
  兜底：圆顶或覆斗形大帐，帐门半开，帐外立戟盾（同第96回兜底，不强加）。
- 时令昼夜：本回未写（只写到“建兴六年秋九月”曹休死）；史载陈仓围城在建兴六年十二月（据摘要）。
  兜底：不写季节、不写雪；帐内点油灯，帐外天色不强调。
- 器物：案与坐榻；油灯（汉代常见铜、陶油灯，蜡烛汉末仍稀少，据摘要，帐内不用烛）；密书（汉末书信
  纸、帛、简并用，据摘要；兜底：卷起的纸或帛，不画可辨文字）。
- 现实中会动的：① 油灯火苗与灯影晃动；② 帐门帘与帐外旗角随风；③ 帐外巡夜兵士手中的火把。

## 排除项

- 读信后的大喜与重赏来人；费耀进谏、引五万兵出斜谷；孔明四轮车、羽扇一招、马岱张嶷关兴张苞伏兵、
  姜维山坡口拦截、费耀自刎（均在后）；陈仓攻守的云梯、冲车、火箭、鄞祥劝降、流星锤伤张嶷（均在前）。
- 易混：第96回周鲂断发诈降曹休（石亭）是另一桩假降；第93回姜维是真降孔明，本回姜维信中“举火为
  号”是诈计；第91回《出师表》朝堂场面已用，《后出师表》真伪见检索记录，不入画。
- 汉末无火药，凡信号炮响（砲）不画炮筒（本回无此句）；不用戏曲脸谱与影视造型。
- 六出祁山逐次（按各回纪年与孔明自述推定）：一出第91–96回（建兴六年春，街亭）；二出即本回
  （陈仓道口、斜谷、祁山前费耀中计；第98回孔明自称“吾二出祁山”）；三出第98回后半–第99回
  （建兴七年，取陈仓、散关、武都、阴平）；四出第100回（建兴八年秋，箕谷、渭滨斗阵）；五出
  第101回（建兴九年春，卤城割麦、木门道；第102回孔明自称“五出祁山”）；六出第102–104回
  （建兴十二年春，北原、木牛流马、五丈原）。
