# 《三国演义》第73回 玄德进位汉中王　云长攻拔襄阳郡

底本：<https://zh.wikisource.org/wiki/三國演義/第073回>；读取日期：2026-10-19。

## 情节要点

1. 曹操退兵斜谷，被马超、魏延等袭扰，狼狈奔回京兆；刘备遣刘封、孟达取上庸，申耽等降。
2. 诸葛亮劝刘备即帝位，刘备大惊推辞；孔明改请先进位汉中王，张飞大叫被叱，刘备再三推辞后应允。
3. 建安二十四年秋七月，沔阳筑坛，许靖、法正请刘备登坛受冠冕玺绶，受群臣拜贺；立刘禅为世子，封五虎大将军。
4. 曹操闻讯大怒，用司马懿计约孙权袭荆州；诸葛瑾为孙权世子向关羽求亲，被骂回。
5. 关羽受前将军印，用廖化、关平出兵，取襄阳，围樊城，令王甫沿江设烽火台。

## 选定场面

沔阳高坛之上：刘备已受冠冕玺绶，面南端坐；许靖、法正立于坛上两侧，刚呈上冠冕玺绶；
坛下文武按次序排列，向坛上拜贺；坛四周分布五方旌旗仪仗。入画理由：回目前半的收束，
一人端坐、一座高坛、群臣与旌旗即成构图，无打斗无血腥；刘备此前「再三推辞」，神态宜持重，
不作得意笑容。具名刘备、许靖、法正；诸葛亮、张飞在劝进段发言，登坛受玺时原文未点名，不画。三处依据：

- 「筑坛于沔阳，方圆九里，分布五方，各设旌旗仪仗。」
- 「群臣皆依次序排列。」
- 「许靖、法正请玄德登坛，进冠冕玺绶讫，面南而坐，受文武官员拜贺为汉中王。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 刘备 | 身长七尺五寸，两耳垂肩，双手过膝，面如冠玉，唇如涂脂；本回戴「冠冕」，诸王之冠按汉制为远游冠；兜底：深色高冠，不垂帝王冕旒；袍服本回未写，兜底：深色宽袖朝服，腰间垂赤绶；面南端坐榻上 | 第1、73回 |
| 许靖、法正 | 样貌本回未写；兜底：文臣，进贤冠、宽袖袍，立于刘备两侧，一人双手捧龟钮金玺与赤绶 | 第73回「进冠冕玺绶」 |
| 群臣与仪仗 | 文武依次序排列于坛下，向坛上拜贺；旌旗仪仗分布五方；兵士本回未写，不强加 | 第73回 |

先后核对：劝进、张飞大叫、刘备再三推辞→筑坛排班→请登坛→进冠冕玺绶→面南而坐受拜贺（此刻）
→立世子、封太傅尚书令五虎将（其后）。登坛过程在前，颁封在后，不混入。

## 器物与环境

- 地点：沔阳（汉县，故城在今陕西勉县东约三公里旧州铺，坛址已湮没），汉中盆地平野，不在山顶；
  「方圆九里」的尺度不可照画，兜底：一座方形土坛，数级台阶，坛上无屋。
- 时令：建安二十四年秋七月；天气本回未写，兜底：秋日晴天。
- 器物：五方旌旗（五方色东青、南赤、西白、北黑、中黄，原文未写旗色，兜底按此）、龟钮金玺、赤绶、
  榻与屏风（汉代榻前置几、榻后设屏；本回未写，兜底）。
- 现实中会动的：① 五方旌旗在秋风中飘展；② 刘备冠带、绶带与群臣衣袖下摆被风拂动；③ 天边云影缓缓移动。

## 排除项

- 称帝：刘备本回只称王，不戴十二旒帝王冕旒，不着衮服、龙纹；封赏颁诏不画。
- 同回他场：张飞大叫、孔明劝进、上表许都、曹操大怒、司马懿献计、诸葛瑾求亲、费诗授印、关羽取襄阳。
- 后世遗迹：清代「先主初为汉中王设坛处」碑与碑亭不入画；不用戏曲脸谱与影视造型。
