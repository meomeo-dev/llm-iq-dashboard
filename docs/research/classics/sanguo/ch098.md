# 《三国演义》第98回 追汉军王双受诛　袭陈仓武侯取胜

底本：<https://zh.wikisource.org/wiki/三國演義/第098回>；读取日期：2026-10-19。

## 情节要点

1. 司马懿奏请令曹真坚守，待蜀粮尽再击；孙礼诈作运粮车，车上装茅草硫黄；孔明识破，
   使马岱在上风放火烧车，诸将内外夹攻，魏兵大败（备选场面，不入画）。
2. 孔明乘胜退兵，魏延按密计以三十骑伏击，一刀砍王双于马下（斩杀，不入画）；曹真忧病回洛阳。
3. 孙权称帝（夏四月，改黄龙元年），孔明遣使入吴作贺；哨知郝昭病重，遣魏延、姜维三日内
   取陈仓，自己藏在军中倍道先到城下；城内细作放火，郝昭惊死，魏延、姜维到时孔明已现身。
4. 随后取散关、建威，复出祁山，遣姜维取武都、王平取阴平；魏主封司马懿为大都督，引兵往长安。

## 选定场面

陈仓城下，魏延、姜维引五千兵赶到，城上不见旗号、不闻更鼓，二人惊疑不敢攻城；忽然旗帜
四面竖起，孔明纶巾羽扇、鹤氅道袍现身开口。具名孔明、魏延、姜维。三处依据：

- 「二人惊疑，不敢攻城。」
- 「忽听得一声炮响，四面旗帜齐竖。」
- 「只见一人纶巾羽扇，鹤氅道袍，大叫曰：“汝二人来的迟了。”」

入画理由：回目下联“袭陈仓武侯取胜”的取胜点；空城无旗到旗起人现，一静一变，不见斩杀；
孔明衣冠本回原文俱全。与第95回西城区分：那里孔明坐敌楼抚琴、城门大开，本回是旗起与喊话。

先后核对：孔明遣关兴、张苞暗出汉中，自藏军中倍道到城下，细作放火、郝昭惊死、蜀兵入城
（前，不画）→魏延、姜维到城下，无旗号、无打更之人，惊疑不敢攻城→炮响，旗帜竖起，孔明
现身大叫（此刻，二人仍在马上抬头，由后文“慌忙下马”反推）→二人下马拜伏、孔明释计、
令放入城（后，不画）→命二人去袭散关（后）。孔明立处原文只写“见一人”，兜底取城头或城楼。

## 器物与环境

- 地点：陈仓城，即第97回郝昭在陈仓道口所筑之城（深沟高垒、遍排鹿角）；故址在今陕西宝鸡东
  （据摘要）。城墙形制本回未写，兜底：夯土城墙、城楼与垛口，城下一片空地。
- 时令：孙权称帝在夏四月，在此段之前；取陈仓的季节、天气本回未写。魏延、姜维“星夜”赶路，
  “无打更之人”只暗示夜间或将晓；题面兜底取天色微明，此为兜底，非原文。
- 器物：四面旗帜（字样本回未写）、羽扇、战马。“炮响”是号令声，汉末无火药，画面不出现炮筒。
- 现实中会动的：① 四面旗帜依次升起并飘动；② 羽扇、纶巾带与氅衣下摆随风；③ 战马喷气、甩鬃。

## 排除项

- 本回前后：魏延斩王双、马岱放火烧孙礼车仗、孔明连夜退兵；魏延、姜维下马拜伏、袭散关遇张郃；
  城内放火与郝昭之死（先于二人到达，不画火光、尸身）；孙权称帝、遣使入吴。
- 第97回：云梯、冲车、火箭、郝昭立敌楼拈弓、鄞祥劝降、王双流星锤，均不是本回场面。
- 他回孔明装束：四轮车（见第97、99、100、101回）、素衣皂绦（第93回）、披发仗剑妆神（第101回）。
- 第95回西城：琴、童子、洒扫军士、敞开城门、司马懿遥望，不得移入；后世改编：戏曲脸谱与靠旗、
  影视造型、火炮炮筒、游戏魔改兵器。
- 史实：陈仓之战在建兴六年冬围城二十余日不克，粮尽而退，王双追击中伏被杀；“趁郝昭病重取陈仓”
  无史载，郝昭战后病亡于洛阳（据摘要）。
- 六出祁山：一出第91–96回（建兴六年春，街亭）；二出第97回（陈仓道口、祁山前费耀中计），本回前半
  为其收尾；三出自本回后半起至第99回（建兴七年，陈仓、散关、武都、阴平）；四出第100回（建兴八年秋，
  箕谷、渭滨斗阵）；五出第101回（建兴九年春，卤城割麦、妆神、木门道）；六出第102–104回（建兴十二年
  春，北原、木牛流马、上方谷、五丈原）。本回孔明自称“吾二出祁山，未得其利；今又到此”；余按各回纪年
  与第102回孔明自称“五出祁山”推定。
