# 《三国演义》第45回 三江口曹操折兵　群英会蒋干中计

底本：<https://zh.wikisource.org/wiki/三國演義/第045回>；读取日期：2026-10-19。

## 情节要点

1. 周瑜因诸葛瑾之言更想杀孔明，假借断粮之计被孔明回敬；又设宴欲杀赴会的刘备，见关羽按剑立于
   刘备身后而作罢。
2. 周瑜斩曹操来使，三江口水战，甘宁射倒蔡壎，曹军大败；曹操令蔡瑁、张允练水军，沿江设二十四座
   水门，周瑜乘楼船窥寨，决意除掉二人。
3. 蒋干葛巾布袍过江，周瑜大设“群英会”，佯醉与他同榻；蒋干夜起偷看桌上文书，得伪造的蔡、张降书，
   天明携回。
4. 曹操怒斩蔡瑁、张允，随即省悟中计，改命毛玠、于禁为水军都督；周瑜让鲁肃去试探孔明。

## 选定场面

二更鼓后，帐内残灯未灭，周瑜和衣卧倒、鼻息如雷，蒋干下床，在桌上翻看一卷往来书信，
翻到封面写着“蔡瑁张允谨封”的一封。一人假睡、一人偷看，同帐两种心思，不动兵刃，适合入画。
具名限周瑜、蒋干两人；太史慈、群英会宴饮属前段，不入画。三处依据：

- 「瑜和衣卧倒，呕吐狼藉」
- 「看周瑜时，鼻息如雷」
- 「干见帐内桌上，堆着一卷文书，乃起床偷视之」

## 器物与环境

- 地点：三江口南岸周瑜中军帐（“周瑜在中央下寨，岸上依西山结营”）。帐内有放文书的案、
  供二人同睡的床榻。
- 时令：夜间，“军中鼓打二更”，睡至五更天明；十一月前后（孔明言“十一月二十甲子日”），
  天气本回未写，兜底：帐内为主，不强加雪或风。
- 器物：“残灯”——原文“灯烛”，汉代灯多为油灯，东汉才有蜡烛，兜底画灯盏；“桌”为后世用词，
  汉末应为低矮长案；文书“一卷”，载体汉末简牍与纸并行，兜底画卷起的纸卷，不写可辨文字；
  汉代床榻低矮，不画高脚架子床。
- 现实中会动的：① 残灯火苗摇曳，投在帐幔上的影子随之晃动；② 帐门帘被夜风轻拂；
  ③ 周瑜胸口随鼾声微微起伏。

## 排除项

- 群英会宴饮、周瑜舞剑作歌、太史慈监酒属前段；半夜有人入帐唤“都督”属后段，不画第三人。
- 蔡瑁、张允被斩（回末）、曹操震怒不入画；信中文字不写成可辨认长句。
- 孔明识破（第46回）、草船借箭（第46回）、借东风（第49回）不混入。
- 周瑜此时是佯醉：不画真醉瘫倒的丑态，不画睁眼；不画蒋干被发现。
- 不用戏曲造型（蒋干白鼻丑角、周瑜雉尾翎），不用“羽扇纶巾”，不用影视造型；不画现代粗蜡烛。
