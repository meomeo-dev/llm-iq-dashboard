# 《三国演义》第1回 宴桃园豪杰三结义　斩黄巾英雄首立功

底本：<https://zh.wikisource.org/wiki/三國演義/第001回>；读取日期：2026-10-19。

## 情节要点

1. 桓、灵二帝信用宦官，十常侍专权；巨鹿张角兄弟创太平道，中平元年举事，裹黄巾者四五十万。
2. 幽州太守刘焉出榜招义兵。涿县刘备（二十八岁）看榜长叹，先遇张飞，又遇关羽，同到张飞庄上。
3. 次日在庄后桃园备祭礼，三人焚香再拜立誓，拜刘备为兄、关羽次之、张飞为弟。
4. 中山商人张世平、苏双赠良马五十匹与金银镔铁，三人才打造兵器、置办铠甲，聚乡勇五百余人。
5. 随邹靖破程远志、解青州之围，赴广宗助卢植；回末救下董卓，董卓无礼，张飞欲杀。

## 选定场面

沿用已有场面：桃园祭告天地，三人焚香行礼、同声立誓。这是全书开篇的标志场面，三人形貌在本回
首次逐一写明，桃花、祭牲、誓词都有原文。只取祭告瞬间：此时三人尚无兵器、无坐骑。三处依据：

- 「吾庄后有一桃园，花开正盛」
- 「备下乌牛白马祭礼等项」
- 「三人焚香再拜而说誓曰」

## 器物与环境

- 地点：涿县张飞庄后的桃园，“花开正盛”。原文不直写月份，北方桃花多在三月下旬至四月开（检索 8），
  可写春日白昼；天气原文未写，不强加。
- 祭礼：乌牛白马，是两头活牲畜，牵在园中；“复宰牛设酒”在祭后。原文没有“香案”，兜底：一张矮案或平石托香炉。
- 焚香：汉代焚香是在熏炉里烧香料，线香到宋元以后才见，不画成束细香、不写“三炷”；炉中升一缕淡烟即可。
- 誓词只供情节（“不求同年同月同日生，只愿同年同月同日死”），不要求画面里写字。
- 现实中会动的：① 桃花瓣随风飘落；② 香炉升起的淡烟；③ 衣带、长髯与白马鬃尾被风微微吹动。

## 排除项

- 兵器与坐骑晚于祭拜：双股剑、青龙偃月刀、丈八点钢矛在受赠铁与马之后才造，祭拜时三人不持兵器、不骑马。
- 关羽绿袍（本回未写；第5回赞诗才有“鹦鹉战袍”）、赤兔马（第3回属吕布，第25回后才归关羽）、京剧脸谱（关羽红脸、张飞黑脸）。
- 祭后“宰牛设酒，聚乡中勇士三百余人痛饮”与黄巾战事属后一段，不并入画面。
- 三炷线香、铜香炉、香案、跪地磕头是后世画法，原文没有；“再拜”未写跪姿，写成并排俯身行礼即可。

## 现有题面核对

对象：sanguo-001 静态与 sanguo-anim-001。有据：桃园桃花盛开、乌牛白马（黑牛白马）、焚香、三人形貌
（刘备双耳垂肩两臂过膝，关羽最高、面如重枣、髯长，张飞圆眼虎须）。场面合适，沿用桃园祭告一场。
无据或不确之处：

- “香案”（静、动）：原文只写“备下乌牛白马祭礼等项”与“焚香”，没有香案。
- “并排跪拜”（静）、“俯身跪拜盟誓微动”（动）：原文是“焚香再拜”，未写跪，也未写并排。
- “香案摆黑牛白马祭品”（动）：牛、马是整头牲畜，不放在案上；祭后才“宰牛设酒”。
- “铜炉中三炷青香”（动）：铜炉、三炷、青香均无据；汉代无线香，三炷是后世习俗。
- “刘备面白”（静、动）：原文“面如冠玉”，可读作白净，但不是直述面白。
- “诗意粒子动效”（动）：非技术描述，应写成“花瓣随风飘落”；人物俯身微动改为衣带、长髯随风。
- 两版都没写三人此时尚无兵器与坐骑；题面应明写，免得被画成持刀矛的立像。
