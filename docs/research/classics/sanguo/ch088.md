# 《三国演义》第88回 渡泸水再缚番王　识诈降三擒孟获

底本：<https://zh.wikisource.org/wiki/三國演義/第088回>；读取日期：2026-10-19。

## 情节要点

1. 孟获回到泸水南岸，将船筏尽拘南岸，筑土城、设敌楼固守；时值五月，天气酷热。
2. 孔明令吕凯在百里外立四寨避暑；马岱押暑药粮米到，奉命领兵从下游沙口渡泸水，断孟获粮道。
3. 马岱白天渡水，士兵裸衣而过，半渡多中毒；土人说须夜静水冷、饱食再渡。夜间扎木筏渡水，据夹山峪，夺粮百余车。
4. 董荼那等酋长不满孟获，缚孟获献孔明，二擒二纵；孟获遣孟优诈降，孔明识破，孟获劫寨中计，马岱扮蛮兵诱擒，三擒三纵。

## 选定场面

泸水沙口，夜半：马岱领兵坐木筏渡水，土人在前引路，水面平缓，对岸沙口无人把守（沙口两岸地形未写，兜底：低缓河岸与远山暗影）。
入画理由：回目“渡泸水”，人物少、环境清楚，写出“夜静水冷”的渡法，避开白天中毒的惨状。三处依据：

- 「此处水慢，可以扎筏而渡」
- 「须待夜静水冷，毒气不起，饱食渡之，方可无事」
- 「孔明遂令土人引路，又选精壮军五六百，随着马岱」

先后核对：马岱先领三千军到沙口，白天驱兵渡水，士兵裸衣而过、半渡倒毙（前，不画）→回告孔明→土人说夜渡之法→孔明令土人引路，
选精壮军，到沙口扎木筏，半夜渡水，果然无事（此刻）→占夹山峪、立寨柵、截粮（后）。孟获遣阿会喃守沙口在渡后，此刻对岸无守军。

## 器物与环境

- 地点：泸水沙口，在大营下游一百五十里，“水慢，可以扎筏而渡”，马岱亲见“水浅”。泸水所指各家不一，有金沙江、
  怒江等说，题面写“泸水”，不指现代江名。孟获筑土城、设敌楼在上游南岸，不在沙口。
- 时令：五月；白天酷热，毒气日间发作；半夜水冷，毒气不起。月色正文未写，仅后人诗有“月明泸水瘴烟高”，不强加满月，兜底：微明夜空。
- 器物：木筏（原文称“木筏”，不画羊皮筏、竹排），长篙（原文未写撑篙，兜底）；瘴气古指南方湿热的病气，多数情况指疟疾，不画成毒雾骷髅。
- 现实中会动的：① 夜间水波与木筏尾迹；② 水面薄雾缓缓飘移；③ 筏上长篙入水、提起往复，岸边草木微动。

## 排除项

- 前：白天渡水“裸衣而过，半渡皆倒，口鼻出血而死”，不画；孔明与蒋琬、吕凯营中议事；孟获饮酒不理军务。
- 后：夹山峪夺粮、斩忙牙长、董荼那被打、缚孟获献孔明（二擒）；孟优诈降、孔明灌醉蛮兵、马岱扮蛮兵撑船诱擒孟获（三擒）。
- 孟获不入画；孟获衣冠易混：第87回紫金冠、红锦袍，第89回犀皮甲、赤毛牛，本回不出现。
- 易混：沙口白天失利与夜渡成功是同一处的两次渡河；三擒时马岱在泸水岸边扮蛮兵撑船是另一处另一事，不画缚人。
- 不取（原文均未写）：现代竹排漂流式造型、火把通明的偷袭、马岱骑马涉水。
