# 《三国演义》第69回 卜周易管辂知机　讨汉贼五臣死节

底本：<https://zh.wikisource.org/wiki/三國演義/第069回>；读取日期：2026-10-19。

## 情节要点

1. 曹操惊病，太史丞许芝荐管辂，并转述其少年事：貌丑好酒，射覆、卜郭恩兄弟之疾，以及教赵颜备酒脯、向南山弈棋二人求寿。
2. 管辂至邺，断左慈之事“此幻术耳”，曹操病愈；卜“三八纵横，黄猪遇虎，定军之南，伤折一股”，并言东吴亡一大将、来春许都有火灾；辞官不受。
3. 耿纪、韦晃与金祎、吉邈、吉穆歃血为盟，定正月十五夜起事；元宵夜火攻王必营，夏侯惇围许都，五人皆败，宗族被斩，百官在教场分红白旗，三百余人被斩于漳河。
4. 曹洪取汉中，斩任夔；张郃不信管辂之言，请取巴西。

## 选定场面

赵颜在南山大松树下向弈棋二人进酒脯的一刻：赵颜跪在盘石旁，酒脯杯盘陈在二人手边（摆法原文未写），二人低头盯着棋局，
酒已饮尽，赵颜仍跪着，尚未开口。入画理由：全回最有画面感的一段，无刀兵；管辂不在此处（他留在赵颜家中），故不画管辂。
元宵起事必画火攻与厮杀，故不取。具名限赵颜与白袍者、红袍者（后经管辂点明为北斗、南斗）。三处依据：

- 「果有二人于大松树下盘石上奕棋。」
- 「全然不顾，赵颜跪进酒脯。」
- 「二人贪着棋，不觉饮酒已尽。」

先后核对：管辂先教备酒脯，次日赵颜携酒脯杯盘入山，进酒脯，二人饮尽，其后才“哭拜于地而求寿”、白袍者检簿、
红袍者添笔、香风起、二人化白鹤。所选瞬间在哭拜之前，以上一概不画。备选：曹操病榻前管辂答“此幻术耳”，画面平淡，未取。

## 器物与环境

- 地点：南山中，距赵颜家约五六里，大松树下平整盘石上摆着棋局；山势未写，兜底：山坡林地、松根盘结。
- 时令：次日白天；季节、天气未写，兜底：晴，松树常青，不强加花叶季相。
- 器物：围棋局（汉魏棋盘多为纵横十七道，画疏格，不画十九路）、黑白棋子；酒一瓶（汉代盛酒用壶、榼，兜底：陶壶）与耳杯、
  盘；鹿脯一块（干肉，形制检不到，兜底：条状风干肉盛于盘）；大松树。
- 现实中会动的：① 松枝松针随山风摇动，树影光斑晃动；② 袍袖衣角被风带起；③ 弈棋者落子的手臂（局部小动作，躯干不动）。

## 排除项

- 管辂、曹操、许芝不入画；耿纪、韦晃、金祎、吉氏兄弟的元宵起事、火烧五凤楼、斩首、漳河斩百官一概不画。
- 之后的情节不画：赵颜哭拜、检簿添“九”、香风、二白鹤；此刻二人仍是弈棋的凡人形象，不画星君光环、北斗七星图。
- 《搜神记》原型是颜超、大桑树、卯日，无红白袍；演义改为赵颜、大松树、白红二袍，勿混用桑树与颜超。
- 不画道袍太极图、羽衣；棋盘不画十九路；不画现代围棋罐与玻璃酒杯。
