# 《三国演义》第82回 孙权降魏受九锡　先主征吴赏六军

底本：<https://zh.wikisource.org/wiki/三國演義/第082回>；读取日期：2026-10-19。

## 情节要点

1. 章武元年秋八月，先主屯白帝城；诸葛瑾来求和，先主不允，称“不看丞相之面，先斩汝首”。
2. 孙权遣赵咨使魏称臣，赵咨对曹丕应答如流，曹丕封孙权为吴王、加九锡，命邢贞持册往吴。
3. 孙权率百官出城迎接；邢贞入门不下车，张昭厉声斥之，邢贞下车；车后徐盛放声哭，邢贞叹江东将相非久居人下。
4. 孙桓、朱然拒蜀；关兴斩李异救张苞，张苞刺死谢旌，谭雄、崔禹被擒杀（不入画）。
5. 先主斩崔禹，大赏三军（回目作“赏六军”，正文为“大赏三军”）；孙权遣韩当等拒敌；黄忠投吴。

## 选定场面

吴都城门口：孙权率百官立于道旁迎接魏使；邢贞乘车入门，不肯下车；张昭抢步到车前，抬臂厉声质问。
入画理由：回目上半“孙权降魏受九锡”的转折，一车一老臣一君主即成画，无兵刃、无死伤；回目下半“赏三军”
只有一句交代，找不到可画的一刻，黄忠请战在下一回，故改选上半。《三国志·张昭传》亦载此事。
三处依据：

- 「遂率百官出城迎接。」
- 「邢贞自恃上国天使，入门不下车，张昭大怒」
- 「礼无不敬，法无不肃，而君敢自尊大，岂以江南无方寸之刃耶？」

## 器物与环境

- 地点：吴都城门（毛本只写“入门”，未写城名；史载在武昌）。城门形制：夯土城墙，门洞上起木构门楼；
  汉代城门另有阙，题面可不画。门口为迎宾道。
- 时令：毛本此段未写月日天气，不强加；前文“章武元年秋八月”只管先主屯白帝城。
- 器物：马车（汉画像常见无篷、带伞盖的轺车或安车，驾马；毛本称“并车入城”，车上可坐二人）；册书（竹木简册）；
  九锡共九物，城门口不全画；史载持节，汉节为长杆缀三重旄牛尾，可选。
- 现实中会动的：① 驾车马匹甩鬃摆尾；② 车盖流苏与迎宾旌旗在风中飘；③ 张昭的须髯与袍袖、百官衣带微动。

## 排除项

- 邢贞下车、并车入城、徐盛放声哭、邢贞叹语均为后一刻；张昭“满面羞慚”是另场（前文），不入画。
- 赵咨使魏对答曹丕、诸葛瑾使蜀（前）；孙桓、朱然拒蜀，关兴斩李异，先主斩崔禹赏三军（另场）。
- 孙权着王服旒冕、龙袍（尚未受封）；刀剑出鞘（“无方寸之刃”为比喻，不画兵刃）；邢贞与张昭互相推搡。
- 后世戏曲、影视造型不取；画面不写可辨认的长段文字。
