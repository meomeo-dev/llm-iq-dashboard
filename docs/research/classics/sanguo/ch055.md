# 《三国演义》第55回 玄德智激孙夫人　孔明二气周公瑾

底本：<https://zh.wikisource.org/wiki/三國演義/第055回>；读取日期：2026-10-19。

## 情节要点

1. 孙权、周瑜弄假成真，改施软困之计：修东府、增女乐，刘备沉迷声色；赵云拆孔明第二个锦囊，
   谎报曹操起兵，刘备与孙夫人商定正旦以江边祭祖为名离去。
2. 孙权醉后得知，遣陈武、潘璋追赶，又令蒋钦、周泰持佩剑追杀；周瑜早令徐盛、丁奉在柴桑界首扎营拦截。
3. 赵云拆第三个锦囊，刘备泣告孙夫人；夫人叱从人推车直出，卷起车帘喝退徐盛、丁奉，随后喝退陈武、潘璋。
4. 刘郎浦江边孔明以拖篷船接应；周瑜水军追至黄州界首，遭关羽、黄忠、魏延伏击，金疮迸裂倒于船上。

## 选定场面

柴桑界首山脚，徐盛、丁奉引兵拦路。孙夫人叱从人推车直出、卷起车帘，亲喝二将；二将慌忙下马、
弃了兵器，立于车前声喏，夫人接着大骂周瑜。取“二将下马弃兵、夫人在车中叱骂”这一段持续状态，
赵云在侧怒目；不取其后放行，也不取陈武、潘璋再至。入画理由：一人坐车、二将伏低，对比强烈，
无需打斗。具名限孙夫人、徐盛、丁奉、赵云；刘备此刻在何处原文未写，不画。三处依据：

- 「于是叱从人推车直出，卷起车帘，亲喝徐盛、丁奉曰」
- 「徐、丁二将慌忙下马，弃了兵器，声喏于车前曰」
- 「又见赵云十分怒气」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙夫人 | 吴侯之妹，“极其刚勇”（第54回周瑜语）、“美而贤”（吕范语）、“自幼好观武事”；本回坐车中，车帘卷起，“大怒”“正色叱”；衣冠本回未写，兜底：东汉末女子交领襦裙，发挽髻，饰物简素，不披甲、不持兵器、不骑马 | 第54回；第55回 |
| 徐盛、丁奉 | 周瑜部将，率三千军在山脚等候，“各绰兵器”；样貌前文未写；本场面已下马、弃兵器、拱手立于车前；兜底：吴军武将，札甲或两当铠，兜鍪，长兵器（戟或矛）弃置脚边 | 第55回 |
| 赵云 | 身长八尺，浓眉大眼，阔面重颐，威风凛凛（第7回）；本回“十分怒气”；佩青釭剑（第41回所得）；长枪，不写亮银；坐骑未写，兜底：深色马，不用白马；盔甲未细写，兜底：铁盔、战袍 | 第7回；第55回 |

先后核对：二将先“各绰兵器，截住去路”，夫人喝问后才“下马，弃了兵器”；所选取下马之后，
不与“绰兵器”拼在一画。原文写“推车”而不写驾马，兜底：车旁从人扶辕推行，不画驭手扬鞭。

## 器物与环境

- 地点：柴桑界首山脚（“转过前面山脚，一彪军马拦住去路”）；赵云带五百军护卫，刘郎浦江船不入画。
- 时令：建安十五年春正月，出城两三日后；天气未写，兜底：早春，草木初萌，不强加雨雪。
- 器物：车（汉代妇女多乘有盖有帷的辎軿类车，国家博物馆辎车画像砖为椭圆车盖、厢体封闭、
  两侧开窗；本回只取“帘卷起”）；弃置于地的兵器；从人与旗帜（旗上文字未写，不强加）。
- 现实中会动的：① 车帘卷起处的帷边在风中轻摆；② 战马喷鼻、甩尾，蹄下浅尘微扬；
  ③ 赵云战袍与军旗旗角随风飘动。

## 排除项

- 陈武、潘璋、蒋钦、周泰后至，孙权掣剑，周瑜水军，孔明船中接应，黄州伏击与金疮迸裂均在其后，不混入；
  刘备、孔明、关羽、黄忠、魏延不入画。
- 第54回房中刀枪、侍婢佩剑属前段，本场面不画侍婢；孙夫人不画弓箭（“弓腰姬”为后世游戏设定）。
- 不用京剧《龙凤呈祥》的靠旗翎子、刀马旦扮相，不用影视“孙小妹”造型；徐盛、丁奉不用民间“神弹子”掷石。
- 白马白袍、亮银枪的赵云不入画；汉末无实用双镫，不画现代式马镫。
