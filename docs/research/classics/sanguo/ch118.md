# 《三国演义》第118回 哭祖庙一王死孝　入西川二士争功

底本：<https://zh.wikisource.org/wiki/三國演義/第118回>；读取日期：2026-10-19。

## 情节要点

1. 邓艾取绵竹，后主召群臣议：弃成都奔南中、投吴，均被谯周驳回，谯周力劝降魏；北地王刘谌屏风后
   怒斥，后主不听，遣张绍、邓良、谯周献玺请降。
2. 后主择十二月初一日出降；刘谌杀妻子，至昭烈庙哭祖后自刎（不入画）。
3. 次日后主率太子诸王、群臣六十余人面缚舆榇，出北门十里而降，邓艾扶起后主、亲解其缚、
   焚榇，并车入城，拜后主为骠骑将军。
4. 蒋显到剑阁传敕，姜维佯降钟会，结为兄弟；邓艾在绵竹筑台自矜，上书议处置刘禅，
   司马昭疑其有反意，封钟会为司徒，令卫瓘监军。

## 选定场面

成都北门外十里，邓艾扶起后主、亲解其缚：后主双手反缚，被邓艾扶起，舆榇仍停在一旁，
太子诸王与群臣立于其后。具名后主、邓艾，其余为群像。三处依据：

- 「擇十二月初一日，君臣出降。」
- 「後主率太子諸王，及群臣六十餘人，面縛輿櫬，出北門十里而降。」
- 「鄧艾扶起後主，親解其縛」

取“后主出降”不取“哭祖庙”：刘谌一节原文先杀妻子，再“提至昭烈廟中，伏地哭曰”，哭拜时手提
妻首，哭罢自刎，无法只取哭拜一刻而不涉血腥；出降一节人物明确、无死伤。

先后核对：后主率众到城外面缚舆榇（先）→邓艾扶起、亲解其缚（此刻，榇尚在）→焚其舆榇、
并车入城、成都人具香花迎接（后）。焚榇、入城、迎接不画。

## 器物与环境

- 地点：成都北面城外十里；《邓艾传》只写“詣軍門”，《资治通鉴》作城北，北门名称无确载（据摘要）。
- 时令天气：十二月初一日，隆冬；天气未写，不画雪、不画雨。
- 器物：舆榇即车载棺材，兜底：一辆素木车载无饰素棺，停在场边；一截解开的绳索垂落；降旗不入此刻画面。
- 现实中会动的：① 风吹动后主与群臣的衣袍、发带；② 邓艾解下的绳端垂落摆动；
  ③ 魏军战马的鼻息白气与尾鬃摆动。

## 排除项

- 邓艾焚榇、并车入城、成都人具香花迎接、拜后主为骠骑将军（均在后）；张绍、谯周、邓良献玺（前）。
- 刘谌：杀崔夫人、杀三子、提首级、哭昭烈庙、自刎（血腥，不入画）；刘谌已死，不在出降队列。
- 谯周力主降魏、后主入宫、姜维剑阁遍竖降旗（均非本刻）。
- 后世造型：戏曲后主龙袍冕旒、白脸；影视刘禅傻笑；不画衔璧、牵羊（毛本只写面缚舆榇）。
- 史实：《邓艾传》写刘禅至邓艾军门，邓艾“執節解縛焚櫬”；“出北門十里”“扶起”为演义写法。
