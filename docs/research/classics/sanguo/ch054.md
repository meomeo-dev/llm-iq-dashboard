# 《三国演义》第54回 吴国太佛寺看新郎　刘皇叔洞房续佳偶

底本：<https://zh.wikisource.org/wiki/三國演義/第054回>；读取日期：2026-10-19。

## 情节要点

1. 孔明驳得鲁肃无言，刘备立文书“暂借荆州”，鲁肃作保；周瑜见甘夫人去世，定美人计，让吕范来荆州为孙权之妹做媒。
2. 孔明劝刘备应允，授赵云三个锦囊随行；建安十四年冬十月，刘备到南徐，先拜乔国老，五百随从披红买办，满城皆知。
3. 吴国太得知后痛骂周瑜，约次日在甘露寺相见；孙权依吕范之计，令贾华伏三百刀斧手于廊下。
4. 甘露寺方丈，国太见刘备大喜；赵云发现伏兵，刘备跪泣，国太喝退刀斧手。
5. 刘备出殿前拔剑砍石，孙权也劈石；二人观江景、驰马于驻马坡；成亲之夜，洞房里刀枪簇满，侍婢佩剑（下回接续）。

## 选定场面

甘露寺殿前庭下，刘备试剑石：他拔从者所佩之剑，仰天祝罢，一剑落下，剑锋击石迸出火星，石块裂作两段；孙权立在他身后看着。
入画理由：画面核心是剑、石、火星三件物证，仰天后的决绝动作清晰可读，不涉血腥；孙权随后才掣剑，十字纹痕由他的一劈所成，不入画。
不取方丈相亲，因宴坐人多而动作少，戏眼“识破伏兵”要靠对白。具名限刘备、孙权。三处依据：

- 「玄德拔从者所佩之剑，仰天祝曰」
- 「言讫，手起剑落，火光迸溅，砍石为两段」
- 「孙权在后面看见」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 刘备 | 身长七尺五寸，两耳垂肩，双手过膝，面如冠玉，唇如涂脂（第1回）；本回自称“年已半百，鬓发斑白”，鬓角见白，不画老态；赴寺时“内披细铠，外穿锦袍”，“更衣”后装束未写，兜底：锦袍、不披甲；所持是从者的直剑（汉剑），不是自己的双股剑；神情决然 | 第1回；第54回“吾年已半百，鬓发斑白”“从人背剑紧随” |
| 孙权 | 方颐大口，碧眼紫髯（第29、43回）；立于刘备身后，装束未写，兜底：冠袍；剑尚未出鞘；神情暗存疑忌 | 第29、43回；“孙权在后面看见” |
| 从者 | 刘备拔走了他所佩之剑，立于一旁，兜底：军士装束，鞘空 | “拔从者所佩之剑” |

先后核对：刘备更衣出殿、见石、祝告、一剑劈开，孙权在后观看，其后才问话、掣剑祝告并劈石；方丈相亲、赵云告知伏兵在更衣之前。

## 器物与环境

- 地点：甘露寺殿前庭下，一块庭石；殿宇、廊庑为背景，兜底：木构殿宇、台基与廊庑；汉末佛寺形制无实物可考，不画唐宋以后的铁塔、砖塔。
- 时令天气：建安十四年冬十月，初冬；天气未写，兜底：晴，不强加雪雨。
- 器物：汉剑一把；石块一分为二，断面平整，只此一道裂缝。
- 现实中会动的：① 剑击石迸出的火星，一闪即灭；② 刘备袖袍与孙权紫髯、衣带被挥剑带起的气流扰动；③ 殿前香炉青烟随风斜飘（兜底）。

## 排除项

- 孙权劈石（其后）及石上“十字纹痕”（二次劈后才成）；刘备的双股剑；两剑相交。
- 国太、乔国老、赵云、吕范、贾华与刀斧手、孙夫人（均不在殿前），方丈宴席、告知伏兵。
- 驻马坡驰马、“天下第一江山”碑与江上小舟（其后）；洞房侍婢佩刀（下回）。
- 后世造型：京剧《龙凤呈祥》刘备蟒袍、孙权花脸、赵云扎靠；甘露寺铁塔（唐代始建，晚于此事）与明清式殿宇。
