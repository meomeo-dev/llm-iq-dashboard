# 《三国演义》第77回 玉泉山关公显圣　洛阳城曹操感神

底本：<https://zh.wikisource.org/wiki/三國演義/第077回>；读取日期：2026-10-19。

## 情节要点

1. 吕蒙定计只空北门，伏朱然、潘璋；关羽自北门突围，夜遇伏被绊倒擒获，与关平遇害（不入画）。
2. 赤兔马被马忠所获，数日不食草料而死；麦城王甫坠城、周仓自刎（不入画）。
3. 关羽英魂至当阳玉泉山，夜空呼“还我头来”，被老僧普净以因果点化，稽首皈依，后常在玉泉山显圣护民。
4. 孙权庆功，吕蒙被关羽附体，七窍流血而死；孙权依张昭计将首级送曹操，曹操以王侯礼葬于洛阳。
5. 刘备夜梦关羽，次日得马良、伊籍、廖化报信，昏绝于地。

## 选定场面

玉泉山夜：三更之后，山间草庵前，老僧普净仰面望天，手举麈尾击着庵门，问「云长安在」；
云端上关羽骑赤兔、提青龙刀，头颅完好，随一白面将军与一黑脸虬髯者一齐按落云头，将至山顶，
尚未下马。入画理由：回目“显圣”的标志场面，人、马、刀、云同框，无血腥；原文只有“还我头来”
的呼声，没有无首的描写，故画完整头颅，不画无头鬼。具名关羽、普净；两位随从原文未点名。三处依据：

- 「只见空中一人，骑赤兔马，提青龙刀」
- 「左有一白面将军、右有一黑脸虬髯之人相随」
- 「普净认得是关公，遂以手中麈尾击其户曰：云长安在？」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 关羽（英魂） | 面如重枣，髯长二尺（前回称须发已苍白，画花白）；骑赤兔、提青龙刀；头颅完好；衣甲本回未写，兜底：铁盔札甲外罩绿锦战袍；乘云而下，须发袍摆随风 | 第1、76、77回 |
| 白面将军 | 原文不点名，依上下文可推为关平；「白面」指肤色白皙，非脸谱；衣甲兵器未写，兜底：青年将军，铁盔札甲，空手 | 第77回 |
| 黑脸虬髯者 | 原文不点名，依上下文可推为周仓；「黑脸」指肤黑，「虬髯」指蜷曲的络腮须；兜底：魁梧，铁盔札甲，空手 | 第77回 |
| 普净 | 老僧，汜水关镇国寺旧长老、关羽同乡；「结草为庵」，每日坐禅，身边仅一小行者；样貌两回均未写，兜底：瘦削老僧，缁衣光头，立庵门前仰面，手执麈尾 | 第27、77回 |

先后核对：三更后普净默坐→闻空中「还我头来」→仰面见空中一人二将→一齐按落云头至山顶→普净认出，以麈尾击户问话（此刻，
关羽仍在云上骑马）→关羽领悟，下马乘风落于庵前叉手问→普净以颜良、文丑点化，皈依（其后）。

## 器物与环境

- 地点：荆门州当阳县玉泉山（今湖北当阳）；草庵在山间，云气自上方按落；庵形制未写，兜底：茅草顶小屋，柴门。
- 时令：夜，三更已后；底本作「日白风清」，他本作「月白风清」，按月夜画；季节本回未写（关羽遇害在冬十二月），不画雪。
- 器物：草庵、麈尾（汉魏麈尾是树叶形毛扇，毛附柄两侧，与拂尘不同）、青龙刀、赤兔马、云头。
- 现实中会动的：① 云气翻涌，月光在云间时隐时现；② 关羽须发、袍摆与赤兔鬃尾被风拂动；③ 普净衣袖与麈尾毫毛微摆。

## 排除项

- 首级、无头形象、血污（王甫梦中所见「浑身血污」属他场）；被擒、遇害；赤兔绝食而死。
- 同回他场：吕蒙被附体、孙权下拜；曹操开匣见首级；刘备夜梦、孔明听凶信。关羽下马叉手、皈依在后。
- 后世造型：关圣帝君帝王冕旒、龙袍（明代封帝后塑像）；关平捧印、周仓扛刀（庙塑，本回未写兵器）；红脸油彩；麈尾画成道士束毛拂尘。
