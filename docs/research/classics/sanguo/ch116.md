# 《三国演义》第116回 钟会分兵汉中道　武侯显圣定军山

底本：<https://zh.wikisource.org/wiki/三國演義/第116回>；读取日期：2026-10-19。

## 情节要点

1. 司马昭对邵悌说，唯钟会不怯，破蜀必矣；钟会点将，以许仪为先锋，分斜谷、骆谷、子午谷三路
   逢山开路。邓艾梦山上涌泉，邵缓以蹇卦解之，艾遣诸葛绪、王颀、牵弘、杨欣分攻沓中。
2. 姜维上表请守阳平关、阴平桥；后主信黄皓所荐师婆，不发兵，告急表文皆被黄皓隐匿。
3. 许仪抢南郑关，中卢逊十矢连弩；钟会过桥陷马被荀恺救下，斩许仪；傅佥战死阳平关，蒋舒降
   （均不入画）。
4. 魏军宿阳安，两夜闻西南喊声；钟会巡哨至定军山，遇旋风阴兵，失盔；蒋舒告知山上惟有武侯墓，
   次日钟会备太牢祭墓，风止天晴。
5. 当夜钟会帐中梦见孔明，劝其勿妄杀；钟会立白旗书“保國安民”，汉中人民出城拜迎；姜维在沓中
   被围，设计夺阴平桥头，至剑阁关前遇一军把关。

## 选定场面

钟会帐中夜梦孔明：钟会伏几而寝，孔明由清风引入，步入帐中。具名钟会、孔明。三处依据：

- 「是夜鍾會在帳中伏几而寢，忽然一陣清風過處」
- 「只見一人綸巾羽扇，身衣鶴氅，素履皂絛，面如冠玉」
- 「其人步入帳中。」

取“夜见孔明”不取“定军山阴兵”：后者是旋风阴云中的数千骑，无人物可画，且钟会失盔奔逃、
诸将坠马，场面散乱；前者孔明衣冠面貌有整段细写，一人沉睡一人入帐，静与风对比清楚。

先后核对：祭墓毕、风息雨过晴（白天）→魏兵回营→是夜钟会伏几而寝，孔明步入帐中（此刻，会仍
睡着）→会起身迎问“公何人也”→孔明说“萬勿妄殺生靈”→拂袖而去，会欲挽留，惊醒（后）。
起身、问答、挽留、惊醒均在后，不画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孔明 | 头戴纶巾，手执羽扇，身穿鹤氅，素履（白鞋）、皂絛（黑色丝带系腰），面如冠玉，唇若涂朱，眉清目朗，身长八尺（三国一尺约24厘米，约1.9米），飘飘然有神仙之概；步行入帐，不乘车，不加八卦衣 | 第116回“綸巾羽扇，身衣鶴氅，素履皂絛” |
| 钟会 | 镇西将军，景元四年约三十九岁（生于225年；第119回自称“年未四旬”）；本回未写帐中衣冠，兜底：卸甲便袍，头发束在冠或帻内，伏在矮几上，头枕手臂；前日已“失了頭盔”，案边不必画盔 | 第116回“伏几而寢” |

## 器物与环境

- 地点：魏军大营帐中，营在阳平关一带（钟会巡哨后“奔到陽平關”）；帐的形制未写，兜底：
  汉魏平顶或斗形大帐，帐内铺席，设矮几。
- 时令天气：白天祭墓后“清風習習，細雨紛紛”，转晴；夜间只写“一陣清風”，不画雨、雪、月相。
- 器物：弧形矮凭几（伏案之用）、席、铜灯（单盏或连枝灯）、帐帘、羽扇；帐中不置兵器架。
- 现实中会动的：① 清风吹动帐帘与灯焰；② 孔明的衣袖、丝带与羽扇羽毛随风飘拂；
  ③ 钟会伏案熟睡时肩背随呼吸轻微起伏。

## 排除项

- 钟会起身迎问、孔明开口说话、拂袖而去、钟会惊醒（均在后）；太牢祭墓、白旗“保國安民”属前后文。
- 定军山阴云旋风与数千骑、失盔坠马；许仪被斩、卢逊中箭、傅佥战死（血腥，不入画）。
- 后世造型：孔明八卦衣、金光光环、飞升漂浮；钟会戏曲白脸；影视字幕台词不入画。
- 他回器物：四轮车与木刻孔明像属第117回；第93回“素衣皂絛”与本回鹤氅是两种写法，本回用鹤氅。
- 史实：《钟会传》写钟会“遣人祭”诸葛亮墓，《诸葛亮传》写其祭庙、禁军士樵采；亲祭、阴兵与
  梦中相见属演义。
