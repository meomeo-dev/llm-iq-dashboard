# 《三国演义》第66回 关云长单刀赴会　伏皇后为国捐生

底本：<https://zh.wikisource.org/wiki/三國演義/第066回>；读取日期：2026-10-19。

## 情节要点

1. 诸葛瑾奉孙权命入川索荆州，孔明哭求，刘备允还长沙、零陵、桂阳三郡；关羽执剑拒还，三郡官吏被逐，孙权大怒。
2. 鲁肃在陆口寨外临江亭设宴请关羽，藏吕蒙、甘宁伏兵；关羽只带周仓与关西大汉八九人，乘小舟，令关平备快船十只、水军五百于江上等候。
3. 酒至半酣，鲁肃索荆州，周仓插言；关羽夺周仓所执大刀，命周仓去岸口招红旗，右手提刀、左手挽鲁肃，扯至江边，上船而去。
4. 曹操欲封魏王，荀攸忧愤而卒；伏皇后密书泄露，伏氏三族被诛（此事不入画），曹操立女为后。
5. 曹操议取汉中，起兵西征。

## 选定场面

陆口临江亭外至江岸之间：关羽佯作醉态，右手提着从周仓手里夺来的大刀，左手挽住鲁肃的手，把他扯向江边；
鲁肃魂不附体，如痴似呆；岸边吕蒙、甘宁的伏兵见关羽手提大刀、亲握鲁肃，不敢出手；江面关平的快船箭一般驶来，
红旗在风中招飐。入画理由：回目“单刀赴会”的收束，一人一刀一手即可成画，不画刀架鲁肃颈项。具名关羽、鲁肃，
周仓可在岸口作小像。三处依据：

- 「云长右手提刀，左手挽住鲁肃手，佯推醉曰」
- 「鲁肃魂不附体，被云长扯至江边。」
- 「见云长手提大刀，亲握鲁肃，恐肃被伤，遂不敢动。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 关羽 | 身长九尺，髯长二尺，面如重枣，唇如涂脂，丹凤眼，卧蚕眉（第1回）；本回“青巾绿袍”，不戴盔、不披甲；右手提大刀（第1回“青龙偃月刀”，本回称“大刀”，按青龙偃月刀画），无赤兔（乘小舟来）；佯醉，长髯垂胸 | 第1、25、66回 |
| 鲁肃 | 本回未写样貌，称“宽仁长者”“长者之风”（第56、66回）；兜底：文士，宽袍巾冠，不披甲、不佩剑；神情惊惧呆滞 | 第66回“魂不附体”“如痴似呆” |
| 周仓（小像，可选） | 面貌本回未写，黑面长髯属后世造型，不取；关西大汉，已先到岸口招红旗；兜底：常服，腰跨刀，手中无刀（刀已在关羽手） | 第66回“先到岸口，把红旗一招” |
| 吕蒙、甘宁（群像） | 各引本部军欲出，因关羽握着鲁肃而不敢动；伏于岸侧，人不具名 | 第66回 |

先后核对：酒半酣→周仓插言→关羽变色而起、夺刀、立庭中叱周仓→周仓会意，先到岸口招红旗→关平船如箭发→关羽右手提刀、左手挽鲁肃（此刻）
→扯至江边，吕蒙甘宁不敢动→到船边才放手，立于船首作别。酒筵论荆州、周仓插言在前；放手登船在后。

## 器物与环境

- 地点：陆口寨外临江亭与江岸之间（毛本设此亭，史载会面在益阳一带，题面取毛本）；亭形制本回未写，兜底：木构有顶的敞亭，
  汉代亭屋顶形制未检得确证，不画攒尖宝顶与飞檐重楼。
- 时令：关羽船“辰时后”到，酒半酣在日间；季节未写，不强加。
- 器物：大刀、红旗（风中招飐，显出大“关”字）、小舟与关平快船、岸边伏兵的刀斧。
- 现实中会动的：① 江面波纹与快船驶来的尾迹；② 红旗在风中招飐；③ 关羽长髯、绿袍下摆与青巾带在江风中飘动。

## 排除项

- 刀架鲁肃颈项、拔刀相向；筵间论荆州、周仓插言（前）；关羽立船首作别（后）。
- 关羽戴盔披甲、骑赤兔、红袍；周仓黑面扛刀；关平、马良、庭后所伏刀斧手不入画。
- 元杂剧《单刀会》的情节与造型不取；青巾为青色头巾、袍为绿色，不画成鲜绿的方巾帽。
- 同回伏皇后、华歆、曹操、郗虑、许褚等均为另场，伏皇后被害不画。
