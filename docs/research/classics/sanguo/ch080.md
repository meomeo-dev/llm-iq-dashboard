# 《三国演义》第80回 曹丕废帝篡炎刘　汉王正位续大统

底本：<https://zh.wikisource.org/wiki/三國演義/第080回>；读取日期：2026-10-19。

## 情节要点

1. 华歆、李伏、许芝、王朗等逼献帝禅位；曹后斥曹洪、曹休，符宝郎祖弼拒交玉玺被斩（此事不入画）。
2. 曹丕依贾诩计，在繁阳筑受禅台；十月庚午，献帝捧玺授丕，改元黄初，国号大魏，封献帝为山阳公。
3. 成都传闻献帝遇害，汉中王为之挂孝；孔明、许靖等上表劝进，刘备坚辞，孔明托病设计，刘备方允。
4. 孔明令人在成都武担之南筑坛，谯周读祭文，孔明率众官奉上玉玺，汉中王受玺，改元章武，立吴氏为后、刘禅为太子。
5. 次日设朝，先主宣布伐吴为二弟报仇，赵云出班进谏。

## 选定场面

成都武担之南的祭坛上：谯周祭文读罢，诸葛亮率众官恭上玉玺，刘备双手接过，捧于坛上；坛下文武肃立。
入画理由：回目下半“汉王正位续大统”的关键一刻，无血腥，祭坛、玉玺、拜伏的官员都有据；上半受禅台一幕
夹着祖弼被斩、华歆按剑指帝，不取。刘备称帝在成都，称汉中王才在汉中（第73回），不可画成汉中。三处依据：

- 「筑台于成都武担之南」
- 「读罢祭文，孔明率众官恭上玉玺。」
- 「汉中王受了，捧于坛上」

先后核对：谯周高声读祭文→读罢→孔明率众官恭上玉玺→汉中王受了，捧于坛上（此刻）→再三推让，称“备无才德”
→孔明奏“宜即正位”→文武皆呼万岁，拜舞礼毕。祭文在前；推让、呼万岁在后，本场面刘备不开口、众官未呼。

## 器物与环境

- 地点：成都武担之南所筑之坛（《三国志·先主传》同说，武担山在成都西北）。坛的形制本回未写；兜底：夯土圆坛，
  两层，四面设阶（东汉南郊坛为“圆坛八陛、中为重坛”），不画明清天坛的三层白石栏板。
- 时令：祭文记建安二十六年四月丙午朔、越十二日丁巳，即四月十二日，初夏；天气本回未写。
- 器物：玉玺系绶，由孔明双手捧上。汉皇帝六玺为白玉螭虎钮，出土的汉帝后玺印仅二三厘米见方，画成小巧方印，
  不画“方四寸”的巨玺；另有鸾驾仪仗（“多官整设鑾驾”）。
- 现实中会动的：① 冕冠前后的旒珠与玺绶随风轻摆；② 鸾驾仪仗的旌旗在风中飘；③ 孔明的鹤氅下摆与纶巾飘带。

## 排除项

- 受禅台一幕：献帝捧玺授曹丕、祖弼被斩、华歆按剑指帝、怪风吹灭台上火烛，均为本回上半，不入画。
- 汉中；刘备坚辞与孔明托病设计（前）；谯周展卷读祭文（前）；次日设朝、赵云进谏、立后立太子（后）。
- 刘备着明黄龙袍、戏曲脸谱造型；青年刘备；关羽（已遇害）、张飞（尚在阆中）出场。
- 孔明一手执扇一手奉玺；画面不写可辨认的祭文长段文字。
