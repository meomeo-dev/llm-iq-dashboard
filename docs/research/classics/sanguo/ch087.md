# 《三国演义》第87回 征南寇丞相大兴师　抗天兵蛮王初受执

底本：<https://zh.wikisource.org/wiki/三國演義/第087回>；读取日期：2026-10-19。

## 情节要点

1. 建兴三年，孟获率十万蛮兵犯境，雍闿、朱褒、高定响应；孔明奏请亲征，王连苦劝不从，起川兵南行。
2. 孔明用反间使高定杀雍闿、朱褒，三路平定；得吕凯《平蛮指掌图》，马谡献“攻心为上”之言。
3. 孟获遣三洞元帅分三路，被赵云、魏延、王平等击破；金环三结被杀（不入画），董荼那、阿会喃被擒后放回。
4. 孟获亲自出阵，被王平、关索诱败，弃马登山，被魏延伏兵生擒。
5. 孔明先放回被俘蛮兵，再在仪仗森严的帐中问孟获服否；孟获不服，孔明放他回去（一擒一纵）。

## 选定场面

孔明大寨中军帐内：孔明端坐帐上，帐中刀枪剑戟列立，黄金钺斧、曲柄伞盖陈在两旁；孟获被缚，跪于帐下，昂首不服。
入画理由：回目“蛮王初受执”的收束，一问一答、仪仗森严对被缚不屈，不画斩杀。三处依据：

- 「却教帐中排开七重刽子手，刀枪剑戟，灿若霜雪」
- 「前推后拥，缚至帐前。」
- 「吾今擒汝，汝心服否？」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孔明 | 丞相，“端坐于帐上”；本回未写衣冠，兜底同第38、89回：纶巾、鹤氅，手执羽扇；不乘车 | 第38、87、89回 |
| 孟获 | 出阵时：嵌宝紫金冠、缨络红锦袍、碾玉狮子带、鹰嘴抹绿靴，悬两口松纹镶宝剑，骑卷毛赤兔马；面貌本回未写。被擒时马已弃，剑去向未写：画冠、袍、带、靴齐全，不画佩剑与马，双手反缚，跪而昂首，神情倔强，不丑化 | 第87回 |
| 武士与仪仗 | 帐中“七重刽子手”持刀枪剑戟，只立不斩；“御赐黄金钺斧，曲柄伞盖，前后羽葆鼓吹，左右御林军”，不具名；衣甲未写，兜底：汉式武弁、袍铠 | 第87回 |

先后核对：魏延解孟获到大寨→孔明早设仪仗，端坐帐上→先召蛮兵，去缚抚谕，赐酒食米粮遣去（蛮兵已走，帐中不再有）
→武士押孟获，缚至帐前，跪于帐下→孔明问“先帝待汝不薄”，获答“两川之地…”→孔明问“心服否”（此刻），获答“山僻路狭，误遭汝手，如何肯服”
→“吾放汝去”，去缚赐衣食（后）。问话在前，放人在后；此刻孟获仍被缚。

## 器物与环境

- 地点：孔明大寨中军帐（益州南部蛮境内，擒获处在锦带山一带）；帐形制本回未写，兜底：方形大帐，正面敞开，
  汉代军帐形制说法不一，不画蒙古包式圆帐，不画现代帐篷。
- 时令：建兴三年，季节与时辰未写，兜底：白昼，帐内光线明亮。
- 器物：黄金钺斧（斧钺为礼仪兵器）；曲柄伞盖（曲盖仪仗可溯东汉晚期）；羽葆（聚五彩羽毛为幢）；刀枪剑戟；羽扇。
  汉代丞相“假黄钺”之说主要是魏晋制度，此处只当小说仪仗，不画孔明亲自执钺。
- 现实中会动的：① 伞盖流苏、羽葆彩羽与帐前旌旗随风飘动；② 孔明手中羽扇轻摇；③ 帐外宴席灶火的炊烟与热气上升。

## 排除项

- 前：三洞元帅、金环三结被杀、赵云魏延夜袭、魏延伏兵擒孟获（缚前的追逃不画）。后：孔明放孟获、赐衣、给鞍马、送出路。
- 孟获衣冠易混：第87回是紫金冠、红锦袍、卷毛赤兔马；第89回才是犀皮甲、朱红盔、赤毛牛，不得混用。
  “卷毛赤兔”只是毛色名，与吕布、关羽的赤兔马无关联，不画成赤红神骏；本场孟获已弃马，不入画。
- 他场人物：祝融夫人（第90回）、孟优（第88回）、孟节（第89回）均未登场；关索只出现在追击处，不入画。
- 后世造型不取：兽皮、骷髅、獠牙、虎皮披肩等影视游戏扮相；不画孟获被按倒、刀架颈项或斩首场面。
- 蛮兵此刻不在帐中；孔明不在车上，不画乘车。
