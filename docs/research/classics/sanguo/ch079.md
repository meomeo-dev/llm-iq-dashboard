# 《三国演义》第79回 兄逼弟曹植赋诗　侄陷叔刘封伏法

底本：<https://zh.wikisource.org/wiki/三國演義/第079回>；读取日期：2026-10-19。

## 情节要点

1. 曹丕继魏王位，改元延康；曹彰带兵奔丧，经贾逵诘问，叱退左右、单身入内，交出兵马回鄢陵。
2. 曹植与丁仪、丁廙酗酒，怠慢问罪使者；曹丕遣许褚擒人，丁氏兄弟被杀（此事不入画）。
3. 卞太后求情，华歆献议“以才试之”；曹丕在偏殿限曹植行七步成诗，以殿上悬画为题，植七步成诗。
4. 曹丕再令应声作诗，以“兄弟”为题而不许犯字，植口占“煮豆燃豆萁”，丕落泪，卞氏出殿责丕，植贬安乡侯。
5. 刘备欲先伐吴；彭羕谋乱被诛，孟达降魏，刘封兵败回成都被斩（此事不入画）；八月祥瑞迭出，群臣奏请汉帝禅位。

## 选定场面

偏殿之上，曹植在殿中迈步，行至七步将尽、诗已成形之际；曹丕端坐殿上，华歆侍立一侧，群臣分列两旁，
目不转睛；殿上悬着那幅二牛斗墙的画。入画理由：回目“兄逼弟曹植赋诗”的核心动作就是“行七步”，一人行走、
众人注视即可成画，无需画釜与豆。毛本里七步内所成的是“两肉齐道行”一首；“煮豆燃豆萁”是其后应声口占，
并不在七步之内，两刻不可合并。三处依据：

- 「吾今限汝行七步吟诗一首。」
- 「时殿上悬一水墨画，画着两只牛，斗于土墙之下，一牛坠井而亡。」
- 「植行七步，其诗已成。」

先后核对：曹植入见、伏拜请罪→曹丕限七步→植乞题目→殿上悬画，丕指画命题→植行七步，诗成（此刻）
→丕及群臣皆惊→丕再令应声作诗，植口占煮豆诗→丕落泪→卞氏从殿后出。命题指画在前，群臣皆惊、煮豆在后；
本场面里曹丕不再指画，也不落泪，卞氏不出场。

## 器物与环境

- 地点：魏王宫偏殿（“丕出偏殿，召曹植入见”），在邺郡；殿柱、梁枋取汉式木构。时令、天气本回未写，不强加；
  殿内陈设本回只写一幅画，不另加灯火。
- 器物：殿上悬挂的画幅，画面为两牛斗于土墙下、一牛坠井。毛本称“水墨画”，水墨画作为画种唐代才成熟，
  汉代是墨线加设色；题面照原文写“画”，画成黑白墨色的挂轴即可。
- 坐具：汉魏殿上席地跪坐，用榻、几、屏风；胡床东汉后期才传入，高背龙椅更晚，一律不画。
- 现实中会动的：① 曹植的袍袖与衣摆随步摆动；② 殿上悬挂的画幅与帷幔被穿堂风轻拂；③ 群臣的冠缨与袖口微动。

## 排除项

- 煮豆诗一刻：曹植口占、曹丕落泪、卞氏出殿；不画釜、豆萁、燃火。毛本煮豆诗为四句，《世说新语》六句版不取。
- 把七步诗与煮豆诗并成“七步作煮豆诗”：毛本是两首，煮豆诗是应声而作，不画成曹植边走边吟煮豆。
- 许褚擒植、丁仪丁廙被杀、曹彰带兵入城；刘封被斩、孟达降魏等他场情节。
- 曹丕着十二旒冕、龙袍、坐高背龙椅；影视、戏曲中的曹植造型不取；画面不写可辨认的长段诗文。
