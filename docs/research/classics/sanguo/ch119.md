# 《三国演义》第119回 假投降巧计成虚话　再受禅依样画葫芦

底本：<https://zh.wikisource.org/wiki/三國演義/第119回>；读取日期：2026-10-19。

## 情节要点

1. 姜维教钟会先令卫瓘收邓艾；卫瓘发檄招降艾的部将，鸡鸣时突入府中，缚邓艾父子上囚车；
   钟会以鞭击艾首，尽得邓艾军马。
2. 姜维劝钟会“泛舟絕跡”，会决意自立；姜维献计诈称郭太后遗诏讨司马昭；元宵夜钟会、姜维在
   故宫设宴请诸将，执杯大哭，诸将被迫画字，被困宫中。
3. 丘建密报胡烈，胡渊遍示诸营，正月十八日兵变，钟会中箭，姜维心疼发作自刎，邓艾父子被田续
   追杀（均不入画）。
4. 后主迁洛阳，封安乐公，答“此間樂，不思蜀”；司马昭封晋王病死，司马炎嗣位，逼曹奂禅位，
   十二月甲子日受禅台上改国号为晋。

## 选定场面

故宫元宵夜宴上，钟会、姜维执杯大哭，诸将惊问其故：灯火满殿，二人各执酒杯，一人悲声垂泪，
另一人陪哭，诸将坐在两侧案前愕然停杯。具名钟会、姜维，诸将作群像。三处依据：

- 「來日元宵佳節，故宮大張燈火，請諸將飲宴。」
- 「數巡後，執杯大哭。」
- 「諸將驚問其故。」

取这一刻：它是姜维诈称太后遗诏一计付诸实施的开端，灯火、酒杯、泪与愕然的诸将，无死伤。
不取“受禅”：回目称“依样画葫芦”，与第80回曹丕受禅构图雷同，且含张节被乱棍打死。

先后核对：前日姜维献诈称遗诏之计，会定元宵宴（先）→次日宴，数巡后执杯大哭、诸将惊问
（此刻）→钟会宣读“郭太后臨崩有遺詔”→众面面相觑→会拔剑出鞘、“違令者斬”→诸将画字，被困宫中
（后）。遗诏宣读、拔剑、画字、掘坑置大棒均在后，不画；此刻不画诏书卷轴。

## 器物与环境

- 地点：成都蜀旧宫殿内；殿宇样式未写，兜底：汉式木构大殿，梁柱帷幔，不画后世重檐琉璃。
- 时令天气：元宵夜，约正月十五，冬末春初；殿内景，天气不入画。
- 器物：樽、杓、耳杯与低矮漆案，宾主席地跪坐；铜连枝灯与多盏灯火（“大張燈火”）。
- 现实中会动的：① 灯焰摇曳，灯影在人身与帷幔上晃动；② 杯中酒面微颤、泪珠滴落；
  ③ 帷幔与衣袖随殿内气流轻摆。

## 排除项

- 钟会宣读遗诏、拔剑出鞘、诸将画字、宫中掘坑置大棒（均在后）；姜维“暗喜”与献计私谈（在前）。
- 兵变、钟会中箭、姜维自刎并被剖腹见胆、邓艾父子被斩（死伤，不入画）；邓艾被缚属本回前段。
- 他节：后主“此間樂”、司马炎受禅台、张节被打死；第118回姜维献图一节。
- 后世造型：红纸灯笼、花灯、走马灯、兔子灯等后起元宵灯饰；戏曲姜维靠旗、钟会白脸。
- 史实：史载钟会正月十五到成都，十六日在蜀朝堂为郭太后发丧并矫遗命，十八日兵变，
  元宵夜宴为演义写法。
