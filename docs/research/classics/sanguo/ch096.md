# 《三国演义》第96回 孔明挥泪斩马谡　周鲂断发赚曹休

底本：<https://zh.wikisource.org/wiki/三國演義/第096回>；读取日期：2026-10-19。

## 情节要点

1. 曹叡听孙资议，不急伐蜀，分命诸将守险要；孔明回汉中，赵云、邓芝不折一人一骑而还，孔明赠金帛，赵云辞谢。
2. 王平、魏延、高翔、马谡陆续回营；孔明先责王平，再唤马谡，马谡自缚跪于帐前，孔明数其罪，叱左右推出斩之。
3. 马谡泣请“舜帝殛鲧用禹”之义，孔明挥泪相答，左右推出辕门；蒋琬赶到劝阻，孔明流涕仍斩之，哭己不明，马谡年三十九。
4. 孔明上表自贬三等，后主降为右将军行丞相事；孔明对费祎言“病不在兵之多寡，在主将”，减兵省将、明罚思过。
5. 司马懿荐郝昭守陈仓；周鲂断发诈降，陆逊于石亭大败曹休（后半回，另场）。

## 选定场面

汉中大帐内：马谡自缚跪在帐前，低头落泪；孔明坐在帐中，泪下，说“吾与汝义同兄弟，汝之子即吾之子也”；两名武士立在
马谡身旁待命，尚未动手。入画理由：回目上联“孔明挥泪斩马谡”的泪点，法与情同在一帐，只画泪与跪，不画刑场。具名孔明、
马谡。三处依据：

- 「谡自缚跪于帐前。」
- 「孔明挥泪曰：“吾与汝义同兄弟，汝之子即吾之子也，不必多嘱。”」
- 「左右推出马谡于辕门之外，将斩。」

计划拟取“马谡被推出帐”，今取其前一句：原文先“孔明挥泪”，后“左右推出马谡于辕门之外”，两句相邻而不同刻，此刻马谡
仍跪帐前。题面若要推出的动势，须另写成下一刻（武士架起马谡转身，孔明不再开口），不得与挥泪并在一幅。

先后核对：喝退王平→唤马谡，自缚跪帐前→孔明变色数罪，“叱左右推出斩之”→马谡泣陈，言讫大哭→孔明挥泪答（此刻）→
推出辕门，将斩（后）→蒋琬高叫留人（后）→首级献阶下，孔明大哭（后）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孔明 | 丞相；衣冠本回未写，兜底：纶巾鹤氅，坐帐中榻上，案在前，羽扇不持；先“变色”，此刻“挥泪”，泪下而端肃 | 第96回 |
| 马谡 | 参军，年三十九；样貌衣冠本回及全书未写，只写“泣”“大哭”。兜底：布袍或战袍，未戴盔，双手缚于身后，跪，垂首落泪；“自缚”的绑法原文未写 | 第91、96回 |
| 武士 | “左右”“武士”，立在马谡两侧待命。兜底：甲士，戟刀拄地或收于身侧，不举刀斧 | 第96回 |

## 器物与环境

- 地点：汉中大营中军帐，原文称“入帐”“帐前”“阶下”。汉晋大帐中将领端坐榻上，帐外竖戟盾（据魏晋壁画反推，据摘要）；
  兜底：圆顶或覆斗形大帐，帐门敞开，帐外竖戟盾；辕门在帐外，不入画。
- 时令：“建兴六年夏五月”（斩首后的叙述，同日）；兜底：夏季，衣不加裘；时刻与天气未写。
- 器物：绳索、榻与案；案上陈设未写，不强加。
- 现实中会动的：① 帐门与帐幕在风中微动；② 孔明眼角泪珠滑落、衣袖微颤；③ 帐外戟缨与旗尾飘动。

## 排除项

- 斩首：首级献阶下、刀斧高举、血迹；孔明痛哭；蒋琬高叫留人（均在后）。
- 王平受责、赵云受赏、魏延高翔；街亭山上场面（第95回）；后半回周鲂、曹休、陆逊、石亭之战。
- 京剧《斩马谡》：马谡净行脸谱、责打王平四十棍（据摘要）。
- 马良“眉间有白毛”（第52回）是马谡之兄，马谡无白眉。
- 史实：《三国志》既载“戮谡以谢众”，又载马谡下狱“物故”与逃亡；《襄阳记》载孔明“亲自临祭”并流涕，演义“挥泪”
  据此（据摘要）。
