# 《三国演义》第12回 陶恭祖三让徐州　曹孟德大战吕布

底本：<https://zh.wikisource.org/wiki/三國演義/第012回>；读取日期：2026-10-19。

## 情节要点

1. 曹操被吕布追杀，黄昏大雨各自收军；陈宫使濮阳富户田氏送密书，诱曹操夜入濮阳。
2. 曹操入城中计，州衙炮响，四门火起；北门遇吕布，反指“前面骑黄马者是他”；东门火梁打倒战马，曹操手臂须发烧伤，典韦、夏侯渊救出。
3. 曹操诈称身死，在马陵山伏击吕布；蝗灾粮尽，两军罢兵。
4. 陶谦病重，三让徐州，刘备权领州事；曹操听荀彧劝转攻汝、颍，收许褚，复兖州、取濮阳，大败吕布于定陶。

## 选定场面

濮阳北门火光中：曹操识破陷阱欲出北门，迎面撞见吕布挺戟跃马而来，掩面纵马；吕布从后赶上，戟落盔顶，
问“曹操何在”。具名二人，夜、火、城门与追逐成画，戟点到盔顶为止，无血腥；反指黄马是紧接的一瞬，
可作手势。同回三让徐州是病榻对话，且以陶谦之死收束，不取。三处依据：

- 「火光里正撞见吕布挺戟跃马而来」
- 「操以手掩面，加鞭纵马竟过」
- 「吕布从后拍马赶来，将戟于操盔上一击」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 曹操 | 身长七尺，细眼长髯（第1回），须发此刻完好；戴盔（“操盔”）。甲色、袍色未写，兜底：铁盔、深色甲；一手掩面，一手加鞭，无兵器；坐骑未写（“黄马”是别人所骑），兜底：非黄色的寻常战马 | 北门段；第1回 |
| 吕布 | 挺戟跃马。本回未重写装束，沿用第5回：三叉束发紫金冠、西川红锦百花袍、兽面吞头连环铠、勒甲玲珑狮蛮带，弓箭随身，手持画戟；坐骑赤兔马通身火炭般赤，无半根杂毛（兜底） | 北门段；第3、5回 |

## 器物与环境

- 地点：濮阳城内北门附近；州衙一声炮响后四门烈火，街巷无人；城门有吊桥，入城信号是西门吹螺壳。
- 时令天气：夜，约初更，“月光未上”，以火光照明；季节未写，蝗灾在后文，不据此补景。
- 器物：画戟、铁盔、火把、烈火、城门；西门角“义”字白旗是诱饵，不画。
- 现实中会动的：① 烈火与飞溅的火星；② 翻卷的浓烟；③ 战马鬃尾与披风衣带。

## 排除项

- 火梁崩下打倒战马、曹操手臂须发烧伤发生在出东门时，晚于此场：此场曹操须发完好，不画烧焦。
- 史书：吕布骑兵所获不识曹操，问“曹操何在”，答“乘黄马走者是也”；曹操落马，烧伤左手掌，司马楼异扶上马。
- 田氏在《献帝春秋》中是内应，吕布设下诈降是演义情节；画面不出现田氏与密书。
- 典韦（双铁戟、十步五步飞戟）、夏侯渊、乐进、李典是同夜另一段搜救，不入此场。
- 三让徐州（陶谦病榻、以手指心而死）、刘备领州、蝗灾“人相食”不入画。
- 赤兔马此回仍属吕布，第25回后才归关羽；画戟按汉戟画长柄带枝，不加游戏式夸张尖刺。
- 不用京剧脸谱与影视造型，曹操只据“细眼长髯”。
