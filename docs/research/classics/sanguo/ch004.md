# 《三国演义》第4回 废汉帝陈留为皇　谋董贼孟德献刀

底本：<https://zh.wikisource.org/wiki/三國演義/第004回>；读取日期：2026-10-19。

## 情节要点

1. 董卓欲杀袁绍，袁绍悬节东门奔冀州；九月董卓在嘉德殿废少帝为弘农王，立陈留王协，尚书丁管击卓被斩。
2. 董卓为相国，赞拜不名，剑履上殿；李儒奉命鸩杀少帝；伍孚朝服内藏刀刺卓不成被杀。
3. 王允借寿宴哭诉，曹操自荐，向王允借得七星宝刀。
4. 次日曹操佩刀入相府，董卓倒身侧卧，曹操拔刀，被衣镜照见，转称献刀，借试马逃出东门。
5. 曹操逃至中牟被擒，县令陈宫弃官同逃；在成皋吕伯奢家误杀八口，又杀伯奢，陈宫默然。

## 选定场面

取回目“孟德献刀”最紧张的一瞬：相府小阁里董卓侧卧向内，曹操在背后已拔出宝刀，董卓仰面从衣镜里
看见。刀已出鞘握在身侧、尚未举向董卓，不画刺杀；吕布此时已出阁去牵马，不在场，具名人物只有
曹操、董卓两个。三处依据：

- 「卓胖大不耐久坐，遂倒身而卧，转面向内」
- 「急掣宝刀在手」
- 「董卓仰面看衣镜中，照见曹操在背后拔刀」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 曹操 | 身长七尺，细眼长髯（第1回）；本回官骁骑校尉，次日“佩着宝刀”入相府。衣冠本回未写，兜底：武官袍服、巾帻，腰佩刀鞘，不披甲（朝服内披小铠藏刀的是伍孚）。神色紧绷 | 入相府段；第1回 |
| 董卓 | 时为相国；“胖大不耐久坐”，坐于床上后倒身侧卧。衣冠须发本回未写，兜底：宽袍便服，体态肥硕，不戴冠（居内阁）；史载其身躯肥胖 | 相府小阁段 |
| 七星宝刀 | “长尺余，七宝嵌饰，极其锋利”；有鞘（“解鞘付布”）。尺余约23至30厘米，是短刀而非长剑；兜底：环首短刀，柄与鞘镶多色宝石，不必画出七星排列 | 献刀段 |

## 器物与环境

- 地点：董卓相府中的“小阁”；董卓“坐于床上”。汉末的床是低矮的坐卧具，不是后世的架子床；
  折叠的胡床是另一物，灵帝时只有贵族用。
- 衣镜：汉代已有立式衣镜（海昏侯墓孔子衣镜：方形铜镜约长70、宽46厘米，带镜架与镜盖）。
  画成带木框的方形铜镜，立在床侧，镜面映出曹操持刀的身影；不画玻璃镜。
- 时令天气：本回写“次日”，未写季节与天气；兜底：白昼，室内，窗光柔和。
- 现实中会动的：① 阁内帷帐与门帘被气流带动；② 曹操长髯与衣带微动；③ 刀身上的反光与镜中随之晃动的影像。

## 排除项

- 吕布：此刻已去阁外牵马，不入画；“借试一骑”、飞骑出东门属之后。
- 刀被喝破后“持刀跪下曰”的下一瞬，以及曹操逃亡、中牟被擒、成皋杀吕伯奢，不入画面。
- 伍孚朝服内披小铠、藏短刀刺卓是同回前文另一人，不要把铠甲、朝服加在曹操身上。
- 史书出入：《三国志·武帝纪》只记董卓表曹操为骁骑校尉，曹操“变易姓名，间行东归”，不见献刀与七星刀；
  题面写成演义情节，不写成史实。
- 不画刺入、流血；不用戏曲脸谱（曹操白脸等）。
