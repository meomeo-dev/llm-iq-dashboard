# 《三国演义》第107回 魏主归政司马氏　姜维兵败牛头山

底本：<https://zh.wikisource.org/wiki/三國演義/第107回>；读取日期：2026-10-19。

## 情节要点

1. 曹爽陪魏主曹芳出城谒高平陵，司马懿令高柔、王观分据曹爽、曹羲营，自引大军据武库，令司马昭屯兵洛水
   浮桥；曹爽家门楼上潘举放箭拦阻，被劝止。
2. 辛敞、鲁芝斩关出城投爽，桓范诈称太后有诏骗开平昌门出奔；懿遣许允、陈泰、尹大目劝爽，称与蒋济指洛水为誓。
3. 曹爽接表手足失措，桓范劝奉天子幸许都，爽通宵犹豫，终掷剑愿为富家翁，交印回城；懿诛曹爽兄弟与何晏等。
4. 夏侯霸反投汉中，荐钟会、邓艾；姜维不听费祎劝阻，筑麴山二城，被郭淮、陈泰围困，天降大雪。
5. 姜维袭牛头山，郭淮断洮水粮道，维大败奔阳平关，遇司马师（左目下生黑瘤）三合击败；关上连弩齐发。

## 选定场面

曹爽通宵不决的拂晓：行营帐中，曹爽手握出鞘之剑、满面泪痕，桓范掀帐入内催问。具名曹爽、桓范。
取此场而不取“司马懿据武库”或“姜维牛头山”：前者是调兵遣将，唯一成景的潘举门楼射箭拦路一幕带箭击；
后者是战阵混战，兼有矢石与连弩齐射。曹爽一夜的动作、神情纯属人物戏，也无死伤。两处依据：

- 「是夜曹爽意不能决，乃拔剑在手，嗟叹寻思；自黄昏直流涕到晓」
- 「桓范入帐催之曰：“主公思虑一昼夜，何尚不能决？”」

先后核对：接表、手足失措、桓范劝幸许都（前）→是夜拔剑在手、流涕到晓（持续状态）→桓范入帐催问
（此刻，剑仍在手）→爽掷剑而叹“但为富家翁足矣”（后）→桓范大哭出帐，许允、陈泰令爽交印（后）。
常见误写：“曹爽在洛水”。洛水浮桥是司马懿父子屯兵之处，曹爽在城外高平陵一侧的行营中。

## 器物与环境

- 地点：洛阳城外高平陵（魏明帝陵）一带曹爽行营；洛水浮桥在陵与城之间，是司马懿屯兵处。帐内陈设未写，
  兜底：帐中只设一榻一案。
- 时令：原文未写季节与天气，史载事发于正始十年正月初六（249年2月5日）；本场面为次日拂晓，只用天将明的
  冷色晨光，不强加雪景。
- 器物：剑；营帐（汉代大帐多为撑杆式幄帐，魏晋形制资料少）；灯具原文未写，汉魏多用青铜油灯，烛台东汉晚期
  始见；兜底：帐内一盏将尽的油灯，帐缝透入晨光。
- 现实中会动的：① 灯焰摇曳将尽；② 帐帘随桓范入内摆动；③ 帐缝晨光由暗渐亮。

## 排除项

- 后一刻：掷剑、“但为富家翁足矣”；桓范大哭“豚犊”出帐；许允、陈泰劝交印、杨综扯印而哭；爽兄弟被锁宅。
- 前一刻：接表手足失措、几乎落马；曹羲劝自缚；辛敞、鲁芝到；桓范驰马至、劝幸许都；尹大目送蒋济书。
- 他处：司马懿据武库、司马昭屯洛水浮桥、潘举乱箭；桓范骗开平昌门；斩于市曹、灭三族；夏侯霸、钟会、邓艾；
  麴山大雪、牛头山、洮水、司马师黑瘤、连弩。
- 不画：自刎或剑指颈项、洛水指誓、刑场。
- 史实出入：史载曹爽停车伊水南、伐木设鹿角，《资治通鉴》记其“投刀于地”，演义写作“掷剑”；
  维基页面未载其拔剑。
