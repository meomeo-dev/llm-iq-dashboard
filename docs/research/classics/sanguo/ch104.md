# 《三国演义》第104回 陨大星汉丞相归天　见木像魏都督丧胆

底本：<https://zh.wikisource.org/wiki/三國演義/第104回>；读取日期：2026-10-19。

## 情节要点

1. 魏延踏灭灯后，孔明吐血卧床，令魏延出迎夏侯霸；召姜维授兵书二十四篇与连弩法，密嘱马岱、杨仪各一计，
   并向尚书李福交代后事、荐蒋琬费祎。
2. 孔明扶病乘小车遍观各营，叹“再不能临阵讨贼”；手书遗表，嘱杨仪：死后不发丧，尸坐龛中，口含米七粒、
   脚下明灯一盏；退兵时回旗返鼓，推出先前所雕木像，司马懿必惊走。
3. 八月二十三日孔明病逝（此事不入画）；姜维、杨仪秘不发丧，魏延不服断后之令，另起事端（下回接续）。
4. 司马懿见大星坠蜀营，欲追又疑，遣夏侯霸探得蜀兵尽退，遂同二子亲追至五丈原山下，中蜀军回旗返鼓之计，
   见四轮车上“孔明”大惊勒马逃回，奔五十余里，摸头问“我有头否”。
5. 两日后乡民告知车上乃木人；懿叹“吾能料其生，不能料其死”，蜀中谚曰“死诸葛能走生仲达”。
6. 杨仪、姜维退入栈阁道口方发丧，前路忽有火光一彪军拦路。

## 选定场面

五丈原山脚下：蜀军回旗返鼓，中军大旗飘出，众上将拥出四轮车，车上端坐“孔明”，司马懿大惊失色，
急勒战马欲回。具名司马懿、孔明（木像）；姜维大叫在懿转身之后，不画。三处依据：

- 「只见蜀兵俱回旗返鼓，树影中飘出中军大旗」
- 「车上端坐孔明：纶巾羽扇，鹤氅皂绦。」
- 「急勒回马便走」

先后核对：懿奋力追赶，山后一声炮响（前）→蜀兵回旗返鼓、大旗飘出→四轮车被拥出，懿“大惊失色”，
急勒马头（此刻）→背后姜维大叫“你中了我丞相之计”、魏兵弃甲丢盔、自相践踏（后）。
木像写法：遗嘱写“先时所雕木像”，现场只写“车上端坐孔明”，两日后乡民才说“乃木人也”；
画面按懿眼中所见处理，孔明端坐僵直不动，题面可注明“实为木雕像”。

## 器物与环境

- 地点：五丈原山脚下，蜀兵自“山后”树影中出；先前魏军杀入的蜀寨已空。五丈原为渭水南岸黄土台塬，南依秦岭。
- 时令：建兴十二年八月下旬（孔明卒于八月二十三日，追击在其后），秋；时辰与天气未写，兜底：白昼，
  不强加雨雪。
- 器物：四轮车，形制未写，兜底：素木小车（同第93回）；羽扇；中军大旗；战鼓；旌旗。“山后一声砲响”
  是演义的号令声，三国并无火药火炮，不画火炮与烟火。
- 现实中会动的：① 中军大旗与旌旗飘动；② 鼓槌起落、鼓面震动；③ 司马懿战马的鬃尾、缰绳与扬起的尘土。
  木像不动，羽扇不摇。

## 排除项

- 后一刻：姜维“贼将休走”、魏兵魂飞魄散弃甲丢盔、司马懿奔走五十里、夏侯霸夏侯惠扯住马嚼环、摸头问“我有头否”。
- 前一刻与他处：孔明病榻、遗体坐龛、米七粒与脚下明灯、大星陨落、魏延梦生角、蜀军白旗哀声；均不入画。
- 真人孔明：不画孔明挥扇、起身或开口；不画素衣白袍、戏曲八卦衣。
- 其他人物：魏延、杨仪、马岱、夏侯霸、司马师、司马昭不入画。
- 史实：《汉晋春秋》记姜维令杨仪反旗鸣鼓，司马懿退兵，并无木像；木像是演义添加。
