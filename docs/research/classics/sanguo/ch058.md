# 《三国演义》第58回 马孟起兴兵雪恨　曹阿瞒割须弃袍

底本：<https://zh.wikisource.org/wiki/三國演義/第058回>；读取日期：2026-10-19。

## 情节要点

1. 陈群献计，曹操起兵三十万下江南；孔明教刘备致书马超，马超闻马腾被杀，与韩遂合兵二十万攻长安，
   庞德用计夺城。
2. 曹洪、徐晃守潼关，曹洪被激下关中伏而失关；曹操亲临阵前，见马超“面如傅粉，唇若抹朱”，
   于禁、张郃、李通连败，马超一枪刺李通于马下。
3. 西凉兵直入中军捉曹操：喊“穿红袍的是曹操”，操脱红袍；喊“长髯者是曹操”，操拔刀断髯；
   喊“短髯者是曹操”，操扯旗角包颈而逃；马超追至，曹洪拦住，操得脱。
4. 曹操坚守不战，遣徐晃偷渡蒲阪津；渡渭时马超追射，许褚负操上船，丁斐放牛马诱敌；夜里劫寨混战（下回接续）。

## 选定场面

潼关前两军混战，西凉兵直入中军搜捉曹操，有人大叫“长髯者是曹操”。曹操在马上惊慌，红袍已脱下抛在身后
（脱袍在前一刻，只作结果，不再重演），掣出所佩刀割断长髯。取“刀锋触髯、断须飞散”的瞬间，
刀不见血，不画马超刺来。入画理由：回目“割须弃袍”的核心动作，神态与器物一图可见，无需斩杀。
具名限曹操；马超、庞德、马岱“引百余骑直入中军”，可在远景作白袍小像，亦可略去。三处依据：

- 「操就马上急脱下红袍，又听得大叫：『长髯者是曹操！』」
- 「操惊慌，掣所佩刀断其髯」
- 「马超、庞德、马岱引百余骑，直入中军来捉曹操」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 曹操 | 身长七尺，细眼长髯（第1回）；本场面惊慌、败走，红袍已脱，握刀割髯（持刀手未写，兜底：右手），另一手勒缰；甲胄本回未写，兜底：深色札甲或两当铠，戴铁盔或巾帻，不画赤身，不画帢 | 第1回；第58回 |
| 马超（远景，可略） | 面如傅粉，唇若抹朱；腰细膀宽，声雄力猛；白袍银铠，手执长枪（第58回阵前所写）；坐骑毛色未写，兜底：不强调白马；枪名未写，不用“虎头湛金枪” | 第58回 |
| 西凉兵（群像） | “人人勇健，个个英雄”；“西凉之兵，尽使长枪”；兜底：长枪、轻甲，战袍色不统一，张口呼喊 | 第58回 |

先后核对：喊“穿红袍”，脱红袍，喊“长髯”，断髯（所选），有人告知马超，喊“短髯”，扯旗角包颈，
其后马超追及、曹操绕树而走、曹洪拦住。所选只取断髯，不拼“包颈”与“绕树”。

## 器物与环境

- 地点：潼关前两军阵中：“操进兵直抵潼关……杀奔关隘前去，正遇西凉军马”；乱军之中，关楼可作远景或略去。
- 时令：本回未写；史载此战在建安十六年秋，兜底：秋，土地干黄，烟尘蔽日。
- 器物：佩刀（汉代环首刀，直身单刃，柄端有环）；断下的长须；落地红袍；长枪；战马（无实用双镫，不画现代马镫）。
  汉人重须髯，剃人须髯受刑，故断髯是失面子的狼狈。旗上文字本回未写，不强加“魏”字大旗。
- 现实中会动的：① 烟尘与马蹄扬起的尘土；② 断须数缕随风飘散，落地红袍衣角被风掀动；
  ③ 西凉兵长枪缨穗与旗角在风中摆动。

## 排除项

- “扯旗角包颈”“绕树而走”“马鞭坠地”、曹洪救驾均在断髯之后；渡渭、许褚负操上船、马超拈弓射船属后段，不混入。
- 不画赤身、血迹、被刺或斩首；脱袍只作落地结果，曹洪、夏侯渊、许褚不入画。割发代首（第17回）是另一事，不混。
- 史实无割须弃袍（维基《潼关之战》），但以演义为准；不用京剧白脸奸相、蟒袍乌纱，不用影视游戏造型。
- 马超不用戏曲白靠、虎头湛金枪等后世说法；庞德、马岱不具名入画。
