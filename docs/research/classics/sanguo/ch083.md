# 《三国演义》第83回 战猇亭先主得仇人　守江口书生拜大将

底本：<https://zh.wikisource.org/wiki/三國演義/第083回>；读取日期：2026-10-19。

## 情节要点

1. 章武二年春正月，黄忠不服老，独上前线，斩史迹，次日中伏中箭，殁于御营（不入画）。
2. 先主亲征猇亭，分军八路；张苞刺夏恂，关兴斩周平；甘宁中箭死于富池口（不入画）。
3. 关兴夜宿山庄，关公显圣，兴斩潘璋，夺回青龙偃月刀；糜芳、傅士仁杀马忠来降，被先主祭关公（不入画）。
4. 孙权送还张飞首级，范疆、张达被张苞处死（不入画）；先主拒和。
5. 阚泽荐陆逊，张昭等反对；孙权筑坛拜陆逊为大都督，授宝剑印绶；陆逊到猇亭，诸将不服，下令坚守不战；先主移营就凉。

## 选定场面

吴国所筑拜将坛上：陆逊登坛，孙权授以宝剑与印绶，并嘱“阃以内孤主之，阃以外将军制之”；百官环立坛下，
阚泽站在一旁。入画理由：回目“书生拜大将”的收束，礼仪场面，两人一剑一印即可成画，无血腥；本回其余场面
多为斩杀、显圣、凌迟，均不取。三处依据：

- 「请陆逊登坛拜为大都督、右护军镇西将军」
- 「赐以宝剑印绶」
- 「阃以内，孤主之；阃以外，将军制之。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 陆逊 | 身长八尺，面如美玉，官领镇西将军；诸将称其“书生”“黄口孺子”，群臣称“年幼望轻”；年龄本回未写，史载约四十岁，各说不一；须发未写，兜底：面白清俊，薄须；冠服未写，兜底：文士宽袖袍加冠，不披甲、不戴盔，双手恭受宝剑与印绶 | 第83回“身长八尺，面如美玉” |
| 孙权 | 方颐大口，碧眼紫髯（第29回）；已受魏封为吴王（第82回）；冠服未写，兜底：深色宽袖朝服加王者之冠，不画旒冕龙袍，神情凝重 | 第29、82、83回 |
| 阚泽（可选） | 字德润；样貌本回未写；兜底：文臣朝服，立坛侧，进言筑坛并“以全家保之”，此刻不开口 | 第83回“阚泽曰” |
| 百官（群像） | 不具名；张昭、顾雍、步骘曾反对，神情本回未写；兜底：朝服，进贤冠，肃立坛下 | 第83回“大会百官” |

先后核对：孙权召陆逊→拜大都督→逊乞来日会众官→阚泽请筑坛→连夜筑坛，大会百官→请逊登坛，拜大都督，
赐宝剑印绶，授六郡军马→吴王嘱“阃以内……”（此刻）→逊领命下坛，令徐盛、丁奉护卫，即日出师。
此前孙权私下“取所佩剑与之”是另一刻，不与坛上授剑拼合。

## 器物与环境

- 地点：坛址本回未写。拜将筑坛古已有之，《史记》有“择良日，斋戒，设坛场，具礼”；形制本回未写，
  兜底：夯土方坛，两层，台阶，周围旌旗，百官立于坛下。
- 时令：章武二年春，二月中旬以后；“连夜筑坛”，仪式在日间；天气本回未写。
- 器物：宝剑与印绶。汉代佩剑已多属礼仪佩剑，实战多用环首刀；汉制将军金印紫绶、龟钮，镇西将军印绶本回未写，
  印以小方印系绶画出即可。阚泽转述古礼“白旄黄钺”，但授职一句只列宝剑印绶，故白旄黄钺不画。
- 现实中会动的：① 坛四周的旌旗在风中飘；② 孙权的紫髯与袍袖、陆逊的衣袖下摆微动；③ 百官的冠缨与衣带微动。

## 排除项

- 关兴斩潘璋、关公显圣（绿袍金铠、面如重枣）：他场，关羽已遇害，不出现；青龙偃月刀此前已回关兴手中，
  与本场面无关。
- 糜芳、傅士仁被剐，马忠、范疆、张达被杀，黄忠中箭病殁，甘宁死，夏恂、周平被杀。
- 陆逊披甲持戟、白发老将；孙权私下授剑“先斩后奏”（前）；陆逊升帐议事、诸将不服（后）。
- 戏曲小生与影视造型不取；画面不写可辨认的文字。
