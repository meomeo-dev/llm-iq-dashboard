# 《三国演义》第17回 袁公路大起七军　曹孟德会合三将

底本：<https://zh.wikisource.org/wiki/三國演義/第017回>；读取日期：2026-10-19。

## 情节要点

1. 袁术称帝，遣张勳等分七路攻徐州；吕布用陈登计，说动韩暹、杨奉倒戈，袁术败，关羽截杀。
2. 袁术向孙策借兵遭拒；曹操接孙策书南征，在豫章界会合刘备、吕布，围寿春，袁术渡淮。
3. 曹操粮尽，借王垕之头安军心，亲自督攻破寿春；段煨、伍习杀李傕、郭汜，传首许都。
4. 建安三年夏四月曹操再征张绣；行军遇麦熟，立法禁踩麦，马入麦田，割发代首。
5. 张绣出战，曹操围南阳；贾诩看破其声东击西。

## 选定场面

取割发代首的一瞬：夏四月，麦已熟，路旁金黄麦田被惊马踏倒一大块；曹操立于倒伏处，一手
持剑，一手将割下的一缕发掷向地面；郭嘉与主簿在侧，远处将士下马扶麦而行。具名人物：曹操、
郭嘉。理由：全回只有此幕是单一画面，且无兵戈无血腥；全由麦、剑、发、鸠、下马的将士构成，
原文依据齐全。回目的「七军」「会合三将」是群像与会面，无单一场面；袁术阵前一幕又与第14、16
回的吕布重复，不选。不取「欲自刎」一刻。引文三处：

- 「操乘马正行，忽田中惊起一鸠，那马眼生，窜入麦中」
- 「乃以剑割自己之发，掷于地曰：“割发权代首。”」
- 「官军经过麦田，皆下马以手扶麦，递相传送而过」

## 器物与环境

- 地点：曹操自许都出师征张绣的行军道上，麦田夹道；百姓因兵至逃避在外，画面不画百姓。
- 时令：原文「建安三年夏四月」，「一路麦已熟」。北方冬小麦在夏前成熟，与此相合；麦色取熟麦
  金黄。天气本回未写，兜底：晴好。
- 器物：佩剑、麦穗、坐骑（毛色与名号未写）、一只惊起的鸠、行军旗械。
- 现实中会动的：① 麦浪随风起伏；② 惊起的鸠振翅飞离；③ 割下的发缕与袍带飘落。

## 排除项

- 「欲自刎」的剑向颈一刻、王垕被斩悬头、斩两员裨将，均不入画。
- 割发不是髡刑（剃光头发的刑罚）：曹操只断一缕，发髻与头巾完整，不画光头。
- 同回袁术七路、龙凤日月旗与金甲两刀、关羽截杀、攻南阳均不入画；吕布、孙策不出场。
- 曹操不画京剧白脸；战马不写「绝影」等名号（第16回大宛良马已中箭而亡，此马未写名）。
- 不画幞头、乌纱帽：幞头前身是东汉幅巾，北周武帝时才发明。袍服、巾，不画后世官帽。
