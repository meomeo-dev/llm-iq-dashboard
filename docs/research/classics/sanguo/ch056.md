# 《三国演义》第56回 曹操大宴铜雀台　孔明三气周公瑾

底本：<https://zh.wikisource.org/wiki/三國演義/第056回>；读取日期：2026-10-19。

## 情节要点

1. 周瑜箭疮迸裂昏绝；孙权欲兴兵，张昭、顾雍劝以表荐刘备为荆州牧，遣华歆赴许都。
2. 建安十五年春，曹操在邺郡大宴铜雀台；武官分红绿两队射箭争西川红锦战袍，徐晃射断柳条取袍，
   许褚抢袍扯碎，曹操各赐蜀锦一匹。
3. 席间文官献诗，曹操自陈心迹；报华歆表荐刘备，曹操惊得投笔于地，程昱献计表奏周瑜为南郡太守。
4. 周瑜令鲁肃索荆州，刘备痛哭、孔明解劝；周瑜再以“假途灭虢”之计取荆州，被孔明识破，赵云城头拒之，
   四路兵至，周瑜坠马（下回接续）。

## 选定场面

铜雀台下射场，百步外垂杨枝上挂着西川红锦战袍，箭垛红心已攒着五支箭；绿袍队的徐晃催马而出，
说“单取锦袍”，一箭射断柳条，红锦坠地。曹操在台上凭高而坐，文武侍立台下。入画理由：动作单一、
器物清晰，不涉斗殴。取“箭离弦、柳条断、锦袍坠落”的瞬间；徐晃飞身取袍与许褚抢袍是其后，不取。
具名限徐晃、曹操；夏侯渊、曹休等只作红绿袍群像。三处依据：

- 「使近侍将西川红锦战袍一领，挂于垂杨枝上，下设一箭垛，以百步为界」
- 「拈弓搭箭，遥望柳条射去，恰好射断柳条，锦坠地」
- 「曹操头戴嵌宝金冠，身穿绿锦罗袍，玉带珠履，凭高而坐」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 徐晃 | 属绿袍队，穿绿袍，“各带雕弓良箭，跨鞍勒马”；本场面拈弓射柳，射毕弓仍在手；样貌与盔本回未写，兜底：无盔或戴巾帻，袍外不披重甲；不持大斧（斧是第14回战场兵器） | 第56回 |
| 曹操 | 身长七尺，细眼长髯（第1回）；本回“头戴嵌宝金冠，身穿绿锦罗袍，玉带珠履”，坐于台上；此刻神情未写（此前见曹休射中“大喜”），兜底：含笑观望 | 第1回；第56回 |
| 红绿袍群像 | “曹氏宗族俱穿红，其余将士俱穿绿”；曹休、文聘、曹洪、张郃、夏侯渊已射中红心，勒马立于射场两侧，不具名；台下文武侍立 | 第56回 |

先后核对：曹休等五人射中红心在先（“四枝箭齐齐的攒在红心里”，夏侯渊“正在四箭当中”），
其后徐晃射柳，再其后才是“飞取锦袍，披于身上”与许褚抢袍；所选瞬间锦袍仍在坠落，徐晃尚未披袍。

## 器物与环境

- 地点：邺郡漳河畔铜雀台：“其台正临漳河。中央乃铜雀台，左边一座名玉龙台，右边一座名金凤台，
  各高十丈。上横二桥相通”；画面取台前射场，台作背景，二桥相连。
- 时令：建安十五年春；天气未写，兜底：晴，垂杨枝条新绿。
- 器物：红锦战袍挂于垂杨枝，箭垛红心上五支箭，雕弓良箭，金鼓；骑者鞍上无马镫，靠夹马与高桥鞍。
- 现实中会动的：① 柳条被射断后摆荡，断枝与红锦袍向下飘落；② 战马鬃尾、红绿袍角在风中摆动；
  ③ 漳河水面波光与其余垂杨枝条轻摆。

## 排除项

- 徐晃飞取锦袍、披袍声喏，许褚跃出抢袍、两人下马扭打、锦袍扯碎，均在其后，不入画。
- 曹休、文聘、曹洪、张郃、夏侯渊比射在其前；文官献诗、曹操醉后投笔、华歆来使、周瑜索荆州均属后段。
- 台名从毛本写“玉龙台、金凤台”；史实三台为铜雀、金虎、冰井，不画二乔、曹植《铜雀台赋》的后世意象。
- 徐晃不持大斧，不用京剧白脸奸相、蟒袍翎子；“射柳”本是辽金元明习俗，不画擂台、牌楼、圆环靶。
