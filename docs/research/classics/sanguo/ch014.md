# 《三国演义》第14回 曹孟德移驾幸许都　吕奉先乘夜袭徐郡

底本：<https://zh.wikisource.org/wiki/三國演義/第014回>；读取日期：2026-10-19。

## 情节要点

1. 徐晃斩李乐，献帝还洛阳；曹操应诏，夏侯惇、许褚等击溃李傕、郭汜，董昭献策迁驾许都。
2. 满宠说降徐晃，曹操迎驾许都、封官；荀彧献「二虎竞食」「驱虎吞狼」二计，刘备不杀吕布。
3. 刘备奉诏讨袁术，留张飞守徐州并嘱戒酒；关羽在盱眙斩荀正。
4. 张飞宴上醉鞭曹豹；曹豹连夜送信小沛，招吕布乘醉袭城。
5. 吕布四更赚开城门，张飞率十八骑突围，刘备家眷陷于城中。

## 选定场面

取吕布夜袭徐州城下、城门将开的一瞬：吕布领五百骑先到，勒赤兔马立于城门下仰首叫门，
曹豹在城上俯身查看，门扇初开一缝。具名人物：吕布、曹豹。理由：夜、月、城门、骑兵，构图
单纯，无打斗无血腥；同回醉鞭曹豹含暴力，曹操迁都无单一画面，均不选。引文三处：

- 「吕布到城下时，恰才四更，月色澄清，城上更不知觉。」
- 「布到城门边叫曰：“刘使君有机密使人至。”」
- 「豹上城看之，便令军士开门。」

## 器物与环境

- 地点：原著称「徐州」，城门、城上。小沛离徐州只四五十里，「上马便到」。史载被袭之城为下邳，
  题面沿用原著称呼，不写下邳。
- 时令：四更，月色澄清；季节与气温本回未写，不写雪、雨与哈气。夜间光源只写月光，
  原文无火把，不画火把。
- 器物：城门与城墙、赤兔马、画戟、骑兵的弓箭。
- 现实中会动的：① 战袍衣带与赤兔鬃尾（夜风）；② 城门门扇向内缓开；③ 薄云掠过月面（兜底）。

## 排除项

- 张飞此刻醉卧府中；曹豹被张飞追杀、死于河中是后一幕；刘备、关羽在盱眙，均不入画。
- 同回前半的曹操迁都、荀彧二计、满宠说徐晃，不混入。
- 赤兔马第3回由董卓赠吕布，第25回后才归关羽，此时与关羽无涉。
- 铠甲用筒袖铠；骑兵不画马镫（单镫造型实证最早在西晋）。画戟不加原文没有的饰物，
  不用京剧脸谱、影视盔甲与游戏改造的戟形。
