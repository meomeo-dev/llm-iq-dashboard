# 《三国演义》第36回 玄德用计袭樊城　元直走马荐诸葛

底本：<https://zh.wikisource.org/wiki/三國演義/第036回>；读取日期：2026-10-19。

## 情节要点

1. 单福识破曹仁“八门金锁阵”，赵云从东南生门杀入、西门杀出；当夜曹仁劫寨中火计，关羽已取樊城。
2. 刘备在樊城认刘泌之甥寇封为义子，改名刘封，关羽不悦。
3. 程昱识出单福即徐庶，仿徐母笔迹伪造家书；徐母斥曹操，取石砚打他；徐庶得书，向刘备辞行。
4. 刘备不肯强留，与徐庶并马出城，长亭饯别，送了一程又一程；徐庶去后，刘备立马林畔，望其背影，指树林说要尽伐。
5. 徐庶拍马折回，荐隆中诸葛亮；转赴卧龙岗，被孔明作色拒之，赴许昌（下回接续）。

## 选定场面

郭外大路旁的树林边：送过一程又一程之后，徐庶已与从者策马远去，刘备勒马立在林畔，泪眼凝望，
视线被林木隔断，他抬起马鞭指向林子，说要把这片树都砍了。画面以背影与距离取情：近处刘备侧身
举鞭，远处路上徐庶一行缩成小影，半掩在树后；身后诸将作无名群像。具名限刘备、徐庶二人。
三处依据：

- 「玄德立马于林畔，看徐庶乘马与从者匆匆而去」
- 「凝泪而望，却被一树林隔断」
- 「玄德以鞭指曰：吾欲尽伐此处树木」

## 器物与环境

- 地点：新野城郭外大路旁的树林边。饯行的长亭在身后，已“送了一程又一程”，亭可不入画。汉代“十里一亭”
  是基层治安机构，“十里长亭、五里短亭”见庾信赋与《白孔六帖》，汉代无明文，不强写里数。隆中在襄阳城
  外二十里，此刻不在画中。
- 时令：本回未写季节与天气；兜底：日间，天色平和，不强加雪雨。
- 器物：马鞭；马鞍不画镫（马镫最早实物为西晋302年墓出土的单镫俑，三国时通行与否无实证）；路边林木。
- 现实中会动的：① 林梢枝叶在风中摇动；② 徐庶一行马蹄后扬起的尘烟缓缓散开；③ 刘备衣带、袍摆与
  马鬃马尾。

## 排除项

- 八门金锁阵、樊城易手、刘封入嗣属前段；孙乾劝留、刘备称“吾宁死”属前夜，均不画。
- 程昱设计、伪家书、徐母斥曹操打砚，在许昌与他处，不混入；徐母、曹操都不入画。
- 徐庶拍马折回、推荐诸葛亮、孔明在卧龙岗作色拒之：此刻之后，不画诸葛亮、草庐、羽扇纶巾。
- 刘备只是口说伐树，不画斧斫与倒下的树；不画哭倒在地，克制为泪眼与举鞭。
- 不用戏曲官帽翅或影视服饰造型；徐庶不画官服、不画佩剑。
