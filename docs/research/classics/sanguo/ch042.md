# 《三国演义》第42回 张翼德大闹长坂桥　刘豫州败走汉津口

底本：<https://zh.wikisource.org/wiki/三國演義/第042回>；读取日期：2026-10-19。

## 情节要点

1. 赵云刺落钟缙，拔青釭剑砍钟绅，奔至长坂桥，请张飞接应；到刘备处呈上阿斗，刘备把孩子掷在地上，赵云抱起泣拜。
2. 文聘追到桥边，见张飞横矛立马、桥东树林后尘头大起，疑有伏兵，不敢近；曹仁、夏侯惇、张辽、许褚等陆续赶到，一字摆在桥西。
3. 曹操闻报亲自来看，张飞三次大喝，夏侯杰惊倒马下，曹操回马而走，诸军溃退；张飞拆断桥梁，被刘备责“失于计较”。
4. 曹操命搭浮桥追击，至汉津被关羽截住；刘琦、孔明率船接应，刘备与孔明、刘琦共投江夏。
5. 曹操得江陵，檄孙权；鲁肃往江夏吊丧，邀孔明同赴柴桑（下回接续）。

## 选定场面

长坂桥头，曹军列阵未进之时：张飞横矛立马于桥上，面向桥西，倒竖虎须、圆睁环眼，正厉声大喝；他身后桥东树林里
尘头大起，是二十余骑拖树枝所扬；桥西曹军一字摆开，后阵隐隐可见青罗伞盖与旌旗，曹操在伞盖下，张飞只“料得是
曹操”。入画理由：回目“大闹长坂桥”的核心形象，一人一桥一林尘，对峙靠姿态而不靠厮杀。桥未断、无人落马。
具名限张飞、曹操二人，曹操只在伞盖下作小像。三处依据：

- 「张飞倒竖虎须，圆睁环眼，手绰蛇矛，立马桥上」
- 「桥东树林之后，尘头大起，疑有伏兵」
- 「隐隐见后军青罗伞盖、旄钺旌旗来到」

## 器物与环境

- 地点：当阳长坂桥（原文称“桥梁”，材质未写，兜底：木桥）。桥下水流本回未写，史载张飞“据水断桥”，兜底画一条小溪。方位：张飞向西，桥西为曹军，桥东为树林，画面可取左西右东。
- 时令天气：接上回“杀至天明”，白昼；秋末冬初，天气本回未写，不强加雨雪。
- 器物：长矛、桥、树林、尘头；曹军青罗伞盖、旄钺、旌旗；张飞手下“二十余骑”拖在马尾上的树枝，藏在林中不画人。
- 现实中会动的：① 桥东林后翻滚升腾的尘土；② 曹军旌旗、伞盖流苏与旄旗在风中飘动；③ 桥下流水，张飞虎须与马鬃微动。

## 排除项

- 拆断桥梁、夏侯杰惊落马、曹操“冠簪尽落，披发奔逃”均在其后；桥完好，无人落马，不画追杀。
- 赵云过桥（本回开头）、刘备掷阿斗、关羽赤兔截路、刘琦白袍银铠、孔明纶巾道服（均为后段），不混入；不画羽扇。
- 张飞不涂黑脸、不用京剧脸谱与影视造型，不用夸张的魔改巨型矛；曹操不画白脸。
