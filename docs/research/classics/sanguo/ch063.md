# 《三国演义》第63回 诸葛亮痛哭庞统　张翼德义释严颜

底本：<https://zh.wikisource.org/wiki/三國演義/第063回>；读取日期：2026-10-19。

## 情节要点

1. 彭羕献策提防决水；冷苞决江不成，被魏延擒获后遭刘备斩首；孔明来书与庞统占星相左，刘备梦神人击臂，与庞统换乘白马。
2. 张任伏于落凤坡，乱箭射死骑白马的庞统；魏延、黄忠、刘备败回涪关，刘备望西痛哭（庞统之死不入画）。
3. 孔明七夕见星坠，知庞统殁，授关羽印绶，嘱“北拒曹操，东和孙权”，自率兵入川，与张飞分路，约会雒城。
4. 张飞至巴郡，严颜据城不出，叫骂三日无用；张飞假称从小路偷过，严颜设伏，反被张飞生擒。
5. 张飞坐厅上，严颜不肯跪、称“只有断头将军”；张飞转怒为喜，亲解其缚，扶坐拜谢；严颜愿为前部。

## 选定场面

巴郡城中官署厅前：群刀手把严颜推至，张飞坐厅上，严颜不跪；张飞喝“斩来”，见严颜声音雄壮、面不改色，转怒为喜，
走下厅阶，喝退左右刀手，亲手去解严颜身上的绑索，严颜仍昂然直立。入画理由：回目“义释”的转折，动作静而有力，
不涉厮杀与斩首。具名张飞、严颜二人，刀手作退让的群像。解缚在先；“取衣衣之”（披衣）、“扶在正中高坐”、
张飞低头拜谢均在其后，不拼入同一幅。三处依据：

- 「张飞坐于厅上，严颜不肯跪下。」
- 「但有断头将军！无降将军！」
- 「乃回嗔作喜，下阶喝退左右，亲解其缚」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张飞 | 身长八尺，豹头环眼，燕颔虎须（第1回；本回“豹头环眼，燕颔虎须，使丈八矛，骑深乌马”）；此刻下阶解缚，矛不在手；盔甲未写，兜底：铁甲，盔不强加，不裹包巾（包巾是第65回夜战）；神情转怒为喜 | 第1、63回 |
| 严颜 | 老将，“年纪虽高，精力未衰”，诗称“白发居西蜀”；声音雄壮、面不改色；被擒时张飞“扯住勒甲缝”，故披铠甲；“用索绑缚”，绑法未写，兜底：双臂反缚于背；无刀无弓，不跪 | 第63回 |
| 群刀手 | “群刀手把严颜推至”；被张飞喝退，持刀向两侧退让，不动手 | 第63回 |

先后核对：严颜“要砍便砍，何怒也”→张飞“回嗔作喜”→下阶、喝退左右、亲解其缚（此刻）→“取衣衣之”→扶坐正中→低头便拜。

## 器物与环境

- 地点：巴郡城内官署厅堂，有台阶；巴郡为山城，四周“都是乱山”，远景可见山势（兜底）。画厅阶、席与榻，不画椅子。
- 时令：夜里三更擒严颜，入城后出榜安民，解缚推定在天明后；季节为七月初七庞统亡故数日后的初秋（推算）；天气未写，不强加。
- 器物：绑索、厅阶、刀手的刀、铠甲；严颜降前所用大刀与硬弓不在场。
- 现实中会动的：① 张飞虎须与严颜白发、袍摆被风轻带；② 厅前城头的旗幡（兜底）；③ 被解开的绑索末端随手势摆动。

## 排除项

- 落凤坡、庞统中箭、孔明痛哭、七夕星坠均属同回另场；庞统换乘的“白马”，原文只称白马，“的卢”为评论者推断，不入画。
- 严颜割军士耳鼻（前）、张飞夜间设伏擒人（前）、斩首与刀架颈；披衣、扶坐、拜谢（后）。
- 张飞包巾无盔（第65回）；京剧张飞黑十字门蝴蝶脸、严颜花脸；明光铠、凤翅盔。
