# 《三国演义》第93回 姜伯约归降孔明　武乡侯骂死王朗

底本：<https://zh.wikisource.org/wiki/三國演義/第093回>；读取日期：2026-10-19。

## 情节要点

1. 姜维识破诈计，献计马遵，与赵云交战数合而精神倍长；孔明用假姜维攻城、魏延诈取冀城，逼得姜维两头被拒，
   终在林中劫住，姜维无路下马，孔明下车执手，称“今得伯约，得一凤也”。
2. 梁绪、尹赏开城，孔明取天水、上邽，兵出祁山，前军临渭水之西。
3. 魏主以曹真为大都督、郭淮为副、王朗为军师（年七十六）；十一月出师，驻渭水之西，王朗自请阵前说降。
4. 次日祁山之前对阵，孔明乘四轮车出阵痛斥王朗，王朗大叫一声撞死于马下（此事不入画）。
5. 郭淮料孔明乘丧劫寨，孔明将计就计，魏军反中埋伏，曹遵、朱赞大败；郭淮另献一计（下回接续）。

## 选定场面

祁山之前两军对阵：孔明端坐四轮车，被推出阵外，在车上痛斥王朗；王朗骑在马上，听罢骂语，气满胸膛、满面怒容，
尚未大叫，尚未坠马。具名孔明、王朗，关兴、张苞可作两侧小像。三处依据：

- 「门旗影下，中央一辆四轮车，孔明端坐车中，纶巾羽扇，素衣皂绦，飘然而出。」
- 「中央白髯老者，乃军师司徒王朗。」
- 「王朗听罢，气满胸膛」

二选一取“骂王朗”，不取“收姜维”：前者是回目下联，两阵对圆、素衣白髯相对，构图一眼可辨，孔明与王朗的衣冠样貌均有
原文；后者姜维样貌本回只有“少年将军”四字，场面是林中人困马乏的迎降，孔明衣冠另写“鹤氅”，对峙感弱。

先后核对：孔明出阵，拱手、王朗欠身答礼（开口前）→王朗长篇说降→孔明车上大笑，长篇痛骂，终以“老贼速退”→
王朗听罢，气满胸膛（此刻，仍在马上）→大叫一声、撞死于马下→孔明以扇指曹真、回车（后）。欠身已过，不再画。

## 器物与环境

- 地点：祁山之前，两军列阵。魏军前一日于渭水之西下寨，次日列阵祁山前；祁山在今甘肃礼县东、西汉水北（据摘要），
  不画大河。
- 时令：魏军“十一月出师”，冬季；天气未写，不画雪（降雪在下一回十二月终）；前夜令“平明务要队伍整齐”，故为清晨至上午。
- 器物：四轮车，形制未写，兜底：素木小车，不加戏曲式华盖；羽扇、门旗、魏阵三盖、战马。
- 现实中会动的：① 羽扇、纶巾带与衣带随风飘动；② 两阵旌旗与伞盖旗角翻动；③ 战马呼出的白气与摆动的鬃尾。

## 排除项

- 王朗大叫、撞死坠马，孔明回车、以扇指曹真（均在后）；王朗欠身答礼（在前）；孔明大笑之前的拱手。
- 收姜维一节（林中小车、鹤氅、下马投降）及姜维、赵云、魏延；当夜劫寨火光。
- 戏曲影视：孔明八卦衣、王朗白脸花脸，影视台词字幕不入画；雪与羌兵铁车属第94回。
- 史实：王朗病逝于228年十一月，未随军与孔明交锋（据摘要）；《语林》载孔明“乘素舆，着葛巾，持白羽扇”，四轮车属演义设定。
