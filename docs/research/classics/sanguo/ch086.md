# 《三国演义》第86回 难张温秦宓逞天辩　破曹丕徐盛用火攻

底本：<https://zh.wikisource.org/wiki/三國演義/第086回>；读取日期：2026-10-19。

## 情节要点

1. 孙权在殿前设油鼎、列武士试邓芝，邓芝昂然说以唇齿之利，吴蜀连和，张温随邓芝入蜀答礼。
2. 张温在蜀自傲；孔明在城南邮亭设宴饯行，秦宓乘醉入席，与张温问答“天有头、耳、足、姓”，张温无言。
3. 曹丕闻吴蜀连和，不听辛毗劝阻，造龙舟十只，亲率水陆军三十余万伐吴。
4. 孙权以徐盛总镇建业、南徐；徐盛扎芦苇为人，穿青衣执旌旗，立于假城疑楼，一夜连城数百里。
5. 曹丕见之而叹，随后狂风吹龙舟，闻赵云出阳平关，收军；孙韶、丁奉截击，淮河芦苇着火（不入画）。

## 选定场面

广陵江面，天晓雾散：曹丕的龙舟泊在江中，雾气被风吹开，对岸现出一带连城，城头旌旗遍插，曹丕惊愕远望。
入画理由：兵不血刃的“疑城”，江、雾、城、旗层次分明，避开火烧与溺水；不选邮亭论辩，因其以对答为主。三处依据：

- 「须臾风起，雾散云收，望见江南一带皆是连城」
- 「城楼上枪刀耀日，遍城尽插旌旗号带。」
- 「曹丕大惊。」

先后核对：前夜龙舟宿江中，月黑、军士执灯火→天晓大雾迷漫，对面不见→须臾风起，雾散云收，望见连城（此刻）→数次人来报，
曹丕大惊，叹“江南人物，未可图也”→狂风大作，白浪滔天，龙舟将覆（后）。灯火在前夜，狂风在后；此刻无灯火、无风浪。

## 器物与环境

- 地点：广陵附近长江北岸江面；对岸“南徐沿江一带，直至石头城”，数百里连城。城形制本回未写，
  兜底：夯土城墙加城楼、女墙，汉代城楼未检得确证，不画明清砖砌重檐城门。
- 时令：魏黄初五年秋八月起兵，到江边的日期未写，兜底：深秋；清晨大雾转散。史载此行在九月，江水暴涨，演义未写涨水。
- 器物：龙舟十只，长二十余丈，可容二千余人，“船上建龙凤日月五色旌旗，銮仪簇拥”；汉代楼船为多层船楼、四周插旗，
  可作参考；城头旌旗号带、枪刀映日。
- 现实中会动的：① 江雾被风吹散，层层退去；② 龙舟五色旗与城头旌旗号带迎风飘动；③ 江面波纹与近岸芦苇摇动。

## 排除项

- 前：邓芝油鼎、张温入蜀、秦宓邮亭论辩（另场在成都）；徐盛要斩孙韶。后：狂风龙舟将覆、文聘救驾、赵云出阳平关、
  孙韶丁奉截击、淮河芦苇灌鱼油起火、张辽中箭，全部不入画，火攻与溺水不画。
- 史载出入：《三国志·徐盛传》只写围墙、假楼与江中浮船，曹丕望围“愕然”而退，无芦苇人、无雾、无火；题面取毛本。
  黄初六年冬曹丕临江观兵遇冰封，是另一次，不画结冰。
- 易混：龙舟不是端午竞渡的细长龙舟，不画众人划桨；不画西式大帆船；不画曹丕骑马；不画吴军真实列阵。
- 勿把假城画成真兵在城上鏖战；青衣人形只作远景点缀。
