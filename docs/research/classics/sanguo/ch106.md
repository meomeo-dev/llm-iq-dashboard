# 《三国演义》第106回 公孙渊兵败死襄平　司马懿诈病赚曹爽

底本：<https://zh.wikisource.org/wiki/三國演義/第106回>；读取日期：2026-10-19。

## 情节要点

1. 公孙渊自号燕王，杀谏臣贾范、伦直；司马懿率四万兵北征，伏兵济水，夏侯霸阵斩卑衍，围襄平，秋雨一月仍不许移营。
2. 雨止，懿见大星坠襄平东南，下令攻城；公孙渊父子夜遁，被围受戮，懿入城安民。
3. 曹叡病危，召懿托孤太子曹芳（年八岁），卒于景初三年正月；曹爽听何晏之言奏懿为太傅，兵权尽归爽。
4. 懿推病不出。曹爽使新任荆州刺史李胜辞行探病；懿去冠散发、拥被坐床，二婢扶持，把“荆州”听作“并州”，
   进汤时汤流满襟，李胜回报，曹爽大喜。
5. 曹爽请魏主谒高平陵，懿见爽出城，起旧部与二子往谋曹爽（下回接续）。

## 选定场面

太傅府内室：司马懿披发拥被坐在床上，侍婢进汤，他把口凑近碗沿，汤顺嘴角流满前襟，口中作哽噎声；
李胜立在床前观看。具名司马懿、李胜，另有侍婢二人。三处依据：

- 「乃去冠散发，上床拥被而坐；又令二婢扶策，方请李胜入府。」
- 「胜至床前拜曰」
- 「侍婢进汤，懿将口就之，汤流满襟，乃作哽噎之声曰」

先后核对：懿去冠散发、拥被坐床、二婢扶持（自始至终的状态）→李胜床前拜、对答“并州”“青州”（前）→李胜写字、
懿看后笑、以手指口（前）→侍婢进汤，汤流满襟，哽噎（此刻）→“言讫，倒在床上，声嘶气喘”（后）。
易错点：“披发”“汤流满襟”“两婢扶持”不是同一刻的并列动作。“二婢扶策”是入见前的安排，进汤的是
“侍婢”，是否仍是同二人原文未写；兜底为二婢在场，一婢捧碗、一婢在床侧扶持。

## 器物与环境

- 地点：洛阳太傅府内室。床：汉魏床榻兼作坐具与卧具，讲究者设屏、帷帐；兜底：木床一张，侧有屏风，
  帷帐半垂，床前留出站立处。
- 时令：原文未写，不指定季节与天气，按室内光线处理；史载李胜辞行在正始九年冬，演义行文已进入
  “嘉平元年”，二者不必对齐，不强加雪景。
- 器物：汤碗（原文是“汤”，史载为粥；汉魏多用漆耳杯、碗，瓷餐具东汉中晚期才见；兜底：浅碗，婢女双手捧），
  被褥。李胜写字用的纸笔已呈上，此刻不在手中，不画。
- 现实中会动的：① 热汤白气升起，汤汁顺口角、前襟流下滴落；② 散披的头发随头部颤动；③ 婢女捧碗的手微颤、
  汤面起涟漪。

## 排除项

- 后一刻：“倒在床上，声嘶气喘”；李胜辞出、回报曹爽“此老若死，吾无忧矣”；懿起身对二子说“曹爽必不忌我矣”。
- 前一刻：“荆州”听作“并州”“青州”的对答；李胜写字；懿“以手指口”。
- 同回另一场面：襄平围城、秋雨不移营、大星坠地、擒公孙渊；曹叡托孤；何晏问卦、管辂相面；曹爽出城谒陵。
- 史实出入：史载“持衣，衣落”“进粥”，演义改为“汤”并增“去冠散发”；不画衣服掉落，不画粥。
- 影视戏曲：司马懿“鹰视狼顾”、奸笑、白脸；正式朝服；二子侍立。
