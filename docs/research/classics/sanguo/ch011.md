# 《三国演义》第11回 刘皇叔北海救孔融　吕温侯濮阳破曹操

底本：<https://zh.wikisource.org/wiki/三國演義/第011回>；读取日期：2026-10-19。

## 情节要点

1. 陶谦用糜竺之计，遣糜竺赴北海、陈登赴青州求救；孔融欲救，却被黄巾管亥围城，部将宗宝战死。
2. 太史慈单骑杀入城中，又受命突围，赴平原向刘备求救；刘备引关羽、张飞及精兵三千赴北海，关羽斩管亥，内外夹攻解围。
3. 刘备向公孙瓒借兵并借赵云，转赴徐州；陶谦两次让州，刘备不受，驻小沛。曹操因吕布袭兖州答书退兵。
4. 吕布受陈宫之谋袭破兖州、据濮阳；曹操回兵，夜袭西寨被围，典韦飞戟救主，吕布追至。

## 选定场面

北海城外阵前：刘备引关羽、张飞与太史慈并马立于阵前，管亥忿怒出阵，太史慈刚要向前，关羽抢先拍马直取。
具名四人；管亥与黄巾只作对面的群像，不具名。停在两马相交之前，三兄弟与太史慈同框，不画关羽
劈斩管亥。三处依据：

- 「管亥望见救军来到，亲自引兵迎敌」
- 「玄德与关、张、太史慈立马阵前」
- 「太史慈却待向前，云长早出，直取管亥」

## 器物与环境

- 地点：北海郡城外；管亥分兵四面围城，孔融在城上、糜竺在城内，均不入阵前。
- 时令天气：本回未写，兜底：中性日光。
- 器物：青龙刀、丈八矛、铁枪、弓矢、双股剑；“平原刘玄德”红旗白字出现在后文徐州城下，不入此场。
- 现实中会动的：① 关羽长髯与战袍衣角；② 马蹄扬起的尘土；③ 战马鬃尾与黄巾头巾末端。

## 排除项

- 「青龙刀起，劈管亥于马下」是下一瞬，不入画；史书只写刘备三千精兵到而黄巾散去，无管亥被斩的记载。
- 偃月刀的宽刃弯月刀形自宋代才见，原文只给刀名与重量，不加龙形夸张或发光。
- 赤兔马第25回后才归关羽；青釭剑第41回才归赵云。赵云此时在公孙瓒处，刘备随后才借，北海阵前无赵云。
- 太史慈本回只持枪与弓矢，手戟出自后来的神亭之战；他此时不穿东吴服色。
- 糜竺遇火德星君、孔融十岁谒李膺、陶谦让徐州、濮阳夜战、典韦飞戟、吕布，均属别段，不入此场。
- 不用京剧脸谱：“面如重枣”只画红润面色，不勾脸谱；不用影视与游戏式魔改兵器。
