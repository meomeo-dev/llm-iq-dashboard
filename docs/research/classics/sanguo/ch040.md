# 《三国演义》第40回 蔡夫人议献荆州　诸葛亮火烧新野

底本：<https://zh.wikisource.org/wiki/三國演義/第040回>；读取日期：2026-10-19。

## 情节要点

1. 夏侯惇请罪，曹操起大兵五十万南征，杀孔融；刘表病亡，蔡夫人、蔡瑁立刘琮，刘琮采纳傅巽、蒯越、王粲之议，献荆襄降曹。
2. 关羽截获宋忠，刘备得知真情，哭而不忍夺侄之地，决定退往樊城；孔明张榜，令新野百姓同行。
3. 孔明派兵：关羽白河上游布袋堵水，张飞守博陵渡口，赵云分守四门并在民房屋上藏引火物，糜芳、刘封在鹊尾坡设青红旗疑兵。
4. 曹仁、曹洪率前队，许褚开路，在鹊尾坡见玄德、孔明在山顶旗丛、伞盖下对坐饮酒；入新野见四门大开、城中无人，遂入城造饭安歇。
5. 初更后狂风大作，三门火起，曹仁出东门遭赵云、糜芳、刘封截杀，逃到白河又遇水淹，博陵渡口遇张飞（下回接续）。

## 选定场面

新野空城，初更之后狂风大作：城中民房屋顶火起，西、南、北三面火光冲天，唯东门方向暗而无火；曹仁在街心急令
众将上马，曹洪紧随，军士惊慌拥向东门。入画理由：本回标题所指的“火烧新野”，风、火、城池三者同框；与上回
博望坡的野外芦苇火不同，这里是城池民房、四面火光。只画火势与慌乱，不画烧死与溺水。具名限曹仁、曹洪二人。三处依据：

- 「初更已后，狂风大作。」
- 「曹仁急令众将上马时，满县火起，上下通红。」
- 「但看风起，便令西、南、北三门伏军尽将火箭射入城去。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 曹仁 | 为前队主将之一，主张入城歇马；样貌衣甲本回未写，兜底：武将铁盔铁铠、深色战袍，已上马或正上马，神情惊急；不画兵器出手 | “曹仁急令众将上马时” |
| 曹洪 | 同领前队；样貌衣甲同样本回未写，火起时原文未单写其动作，兜底：同在衙内，着相近的武将甲胄，随曹仁上马，神情惊疑 | “曹仁、曹洪就在衙内安歇” |
| 赵云（可不画） | 伏于东门外，本场面他在城外暗处；如画，仅作东门外一面军旗，不具名 | “自领一队伏于东门外” |

## 器物与环境

- 地点：新野县城，县衙，民房土木瓦屋；四门洞开、街巷无人，军士进民房“寻房造饭”，曹仁起初误以为是造饭遗漏之火。
- 时令天气：秋夜（建安十三年七月出师，诗称“九月南征”，具体日期原文未写）；初更后狂风，无雨雪，月色本回未写。
- 器物：火箭（自西、南、北三门射入）、屋上预藏的“硫黄焰硝引火之物”、县衙门楼、曹军旗号与战马；不画火药爆炸。
- 现实中会动的：① 民房屋顶的火舌与火星顺风翻卷；② 浓烟被狂风吹成斜向的长带；③ 曹军旗帜与战马鬃毛、披风被风吹得猎猎作响。

## 排除项

- 白河水淹（关羽布袋放水）、博陵渡口张飞、鹊尾坡青红旗与山顶对坐饮酒、许褚开路，均为同回其他场面，不混入。
- 孔明、刘备此时已退出新野，不入画；不画羽扇（毛本首见第52回）；百姓扶老携幼渡河是第41回，不画。
- 不画被烧死、践踏致死的尸体，也不画溺水；不画火药爆炸、火炮、孔明灯；不与第39回野外芦苇夜火重复。
