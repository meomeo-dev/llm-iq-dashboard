# 《三国演义》第21回 曹操煮酒论英雄　关公赚城斩车胄

底本：<https://zh.wikisource.org/wiki/三國演義/第021回>；读取日期：2026-10-19。

## 情节要点

1. 马腾举荐刘备入衣带诏盟；刘备在下处后园种菜浇灌，以示无大志。
2. 曹操遣许褚、张遼请刘备入府，后园小亭设青梅煮酒；阴云骤雨将至，二人凭栏观龙挂，论天下英雄。
3. 曹操指刘备又自指，说天下英雄惟二人；刘备吃了一惊，匙箸落地，借雷声掩饰；雨住后关、张持剑闯入。
4. 刘备借截击袁术之名领兵出许都，袁术穷途吐血而死；关羽夜扮曹军赚开徐州城，斩车胄，张飞杀其全家。

## 选定场面

沿用旧题面的场面，校正瞬间：曹操以手指刘备、再自指，刘备吃了一惊，手中匙箸脱落；阴云压低，天外龙挂
悬垂，雨尚未下。俯身拾箸是随后一刻，须从容，两个瞬间不混写（动态题面可先落箸、后拾箸）。三处依据：

- 「操以手指玄德，后自指曰」
- 「手中所执匙箸，不觉落于地下」
- 「玄德乃从容俯首拾箸」

关羽、张飞此时在城外射箭，雨住后才闯入；许褚、张遼只是引刘备入府，均不在亭中。

## 器物与环境

- 地点：相府后园小亭，亭有栏（“凭栏观之”），园中梅树枝头结青梅。
- 时令天气：“方今春深”。酒至半酣“阴云漠漠，骤雨将至”，天外有龙挂，雷声大作；雨尚未下（“天雨方住”在其后）。
- 器物：樽俎、盘盛青梅、一樽煮酒（煮酒指加热过的酒，青梅是下酒物，不是用梅煮酒）；匙箸（匙与筷）。
  汉代席地分餐、一人一案，兜底：二人隔案对坐于席，不画石桌石凳；亭栏取镂空横条或菱形栏杆。
- 现实中会动的：① 酒樽上升腾的热气；② 翻涌压低的阴云与悬垂缓动的龙挂云；③ 落下的匙箸与风中梅枝。

## 排除项

- 闪电：原文只有雷声，没有闪电；雨未下，不画雨线。
- 关羽、张飞舞剑、“二樊哙”是雨住后的另一小段；梅林止渴是曹操所述往事，不入画。
- 煮酒不是亭中生火烹煮；“青梅煮酒”一词宋代才见，只作酒与梅两样物件处理。
- 曹操不画白脸；刘备不画夸张大耳；后文出兵、斩车胄不混入。

## 现有题面核对

对象：sanguo-021 静态与 sanguo-anim-021（`src/core/classics/sanguo.ts`）。场面合适，沿用。有据：相府后园小亭、
一盘青梅、一樽煮酒（温热）、阴云低压、天外龙挂、细眼长髯的曹操、以手指人、刘备落箸、仅二人在场。
有误、无据或含后世说法之处：

- “石桌”（静、动）：无据。原文只写“已设樽俎”，汉代席地分餐，宜写案与席。
- “一道闪电划破天空”（静）、“雷电交加闪烁”“惨白裂天闪电连环闪烁”（动）：无据。原文只有“雷声大作”。
- “龙卷状的云”：龙挂词典义为龙卷风或龙形云，有据，但宜保留“龙挂”一词；雨尚未下，题面不应写雨。
- “刘备神色惊慌，正俯身去拾”（静）：两瞬间混写。落箸时是“吃了一惊”，拾箸时是“从容俯首”。
- “筷子跌落桌面颤动”（动）：不确。原文是匙箸“落于地下”，颤动无据。
- “温热白气升腾”（动）：原文未写热气，由“煮酒”推断，属合理增补，可保留。
- 遗漏：园中梅树枝头青梅、亭有栏杆（凭栏观之）、侍从遥指龙挂，均有据，可补；季节“春深”未提。
