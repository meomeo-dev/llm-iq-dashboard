# 《三国演义》第19回 下邳城曹操鏖兵　白门楼吕布殒命

底本：<https://zh.wikisource.org/wiki/三國演義/第019回>；读取日期：2026-10-19。

## 情节要点

1. 吕布袭取小沛，刘备弃家单骑投曹操；陈登父子里应外合，吕布失徐州、小沛，退守下邳。
2. 曹操围下邳，用郭嘉之计决沂、泗之水，只剩东门无水；吕布因酒色伤身下令戒酒，杖责侯成。
3. 侯成盗赤兔马献曹操；宋宪、魏续趁吕布在门楼睡着，先盗走画戟，再将他绳缚，插白旗献城。
4. 曹操退水安民，与刘备同坐白门楼受降；吕布求缓、求情，刘备一言，曹操下令缢杀；陈宫、高顺亦死。
5. 张遼被擒，当面骂曹，曹操拔剑欲杀，有人攀臂劝阻（下回接续）。

## 选定场面

白门楼上，吕布被绳索捆成一团，转头目视刘备；曹操已回到楼上，回头问刘备“何如”，刘备正要作答，
关羽侍立在侧。三道视线汇到刘备身上，一静一缚一问，冲突全在眼神，不画缢杀与枭首。
题面具名限吕布、曹操、刘备、关羽四人，侍立的张飞不具名或不画。三处依据：

- 「与玄德同坐白门楼上，关、张侍立于侧」
- 「吕布虽然长大，却被绳索捆作一团」
- 「公为坐上客，布为阶下囚，何不发一言而相宽乎」

## 器物与环境

- 地点：下邳城白门楼（下邳南门之楼，遗址在今江苏睢宁古邳镇一带，确址未证）；城内决水已退，地面泥湿。
- 时令：“时方冬寒”；具体时刻与天气本回未写，兜底：用冷色与寒风暗示，不强加雪或雨。
- 器物：捆人的粗绳；城头白旗（宋宪、魏续为号所插）与曹军旗号；座具未写（“椅”字只见吕布小憩处），
  兜底：低榻或坐席，不画后世高背椅。
- 现实中会动的：① 城头白旗与曹军旗帜迎寒风翻卷；② 曹操长髯、刘备衣带、吕布散乱衣袍被风吹动；
  ③ 城下退水后残水泛起的水纹。

## 排除项

- 缢杀、枭首、斩高顺、陈宫伸颈就刑一律不画；陈宫已先行下楼，此刻不在楼上。
- 赤兔马前夜被侯成盗献曹操，画戟被宋宪盗掷城下：吕布手中无戟，楼上无赤兔。
- 张遼骂曹、曹操拔剑、刘备攀臂属回末，关羽跪求在下回开头，不混入；貂蝉、严氏不在门楼。
- 水淹已是前情，不画洪水围城；不用戏曲、影视吕布造型，不用明光铠式圆护，曹操不画白脸。
