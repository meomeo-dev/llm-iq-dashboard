# 《三国演义》第23回 祢正平裸衣骂贼　吉太医下毒遭刑

底本：<https://zh.wikisource.org/wiki/三國演義/第023回>；读取日期：2026-10-19。

## 情节要点

1. 曹操欲斩刘岱、王忠，孔融劝免；贾诩劝张绣降曹；孔融上表荐祢衡，表称其“年二十四”。
2. 祢衡见曹操，曹操不命坐，祢衡逐一贬低曹营文武；曹操留他做鼓吏以辱之。
3. 次日省厅大宴，祢衡穿旧衣击鼓《渔阳三挝》，座客动容；被喝令更衣，当面脱衣，数落曹操眼浊、口浊等六浊，孔融打圆场；
   后遣使荆州，被黄祖所杀。
4. 董承病中，太医吉平愿下毒害曹操，被家奴秦庆童告发；下毒败露，吉平受拷骂贼，撞阶而死。
5. 曹操搜出衣带诏与义状，监禁董承全家。

## 选定场面

不取裸衣，也不取酷刑。取更衣之前的击鼓：省厅大宴，祢衡身穿旧衣立在鼓旁，双手执槌挝鼓，曹操坐在上首听鼓，
座客为之动容。人物衣着整齐，鼓声与满座反应就是画面主体，具名人物为祢衡、曹操，另可加孔融。三处依据：

- 「来日，操于省厅上大宴宾客，令鼓吏挝鼓」
- 「衡穿旧衣而入，遂击鼓为《渔阳三挝》，音节殊妙，渊渊有金石声」
- 「坐客听之，莫不慷慨流涕」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 祢衡 | 二十四岁（荐表）；相貌本回未写，兜底：青年士人，神情沉着，不写美丑。“穿旧衣而入”，后文称“旧破衣服”，题面取褪色旧布袍、衣着整齐；荐表有“褐衣”，指粗布衣。不戴岑牟、不着单绞（《后汉书》细节，毛本未写） | 荐表；击鼓段 |
| 曹操 | 细眼长髯，身长七尺（第1回）；坐省厅上首。衣冠未写，兜底：汉末官员常服袍，头戴进贤冠或巾帻，不戴冕旒 | 第1回；省厅宴段 |
| 孔融（可选） | “时孔融在坐”；相貌衣冠未写，兜底：士人袍服，神情担忧 | 打圆场段 |
| 座客与其他鼓吏 | “挝鼓必换新衣”，其他鼓吏着新衣，祢衡独着旧衣；座客不具名 | “旧吏云”句 |

## 器物与环境

- 地点：曹操丞相府省厅（正厅），室内大宴；宾客席地设案。
- 时令：宴会日期与季节本回未写（此前孔融语有“隆冬盛寒”）；兜底：室内灯烛，不画窗外雪景。
- 器物：毛本只写“鼓”。兜底取汉代建鼓：立柱贯鼓、下有鼓座、柱顶饰羽葆流苏；击鼓用桴即鼓槌，双手各执一桴；
  案上酒樽、耳杯。
- 现实中会动的：① 鼓槌起落，鼓面与羽葆流苏随鼓声颤动；② 烛火摇曳；③ 祢衡袍袖、曹操长髯随击鼓微动。

## 排除项

- 脱衣裸身是紧随其后的下一刻，题面须写明衣着整齐，不画袒露与裸体。
- 吉平下毒、拷打、断指割舌属回目后半的酷刑，不画；董承梦杀曹操亦不画。
- 张辽掣剑欲斩是前一日召见时；祢衡出使荆州、黄祖杀祢衡、鹦鹉洲均为别段。
- 京剧《击鼓骂曹》的曹操白脸、翅帽等戏曲造型不用；戏文设元旦，毛本未写宴会日期，不写元旦。
- 岑牟、单绞出自《后汉书》，毛本无，不加；不添建鼓舞者对舞等无据人物。
