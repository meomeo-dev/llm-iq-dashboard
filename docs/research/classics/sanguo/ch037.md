# 《三国演义》第37回 司马徽再荐名士　刘玄德三顾草庐

底本：<https://zh.wikisource.org/wiki/三國演義/第037回>；读取日期：2026-10-19。

## 情节要点

1. 徐庶赶到许昌，被母亲怒斥“弃明投暗”，徐母自缢；曹操因荀彧劝“天寒未可用兵”，引漳水造玄武池练水军。
2. 司马徽访刘备，称孔明可比姜子牙、张子房，叹“卧龙虽得其主，不得其时”；次日刘备同关、张往隆中，头一回不遇。
3. 数日后孔明已归，刘备斥张飞“唤来便了”，遂冒隆冬风雪第二次往访；途中路旁酒店有石广元、孟公威歌饮。
4. 到庄只见诸葛均，孔明外出；刘备留书而归，桥头遇骑驴踏雪的黄承彦，误认为孔明。
5. 回新野后卜吉斋戒，将第三次往访；关、张入谏（下回接续）。

## 选定场面

第二次往访途中：隆冬彤云，朔风卷雪，刘备、关羽、张飞三骑冒雪行在山道，将近卧龙岗。刘备居前，勒马稍回头；
张飞在侧抱怨天寒、劝回新野，刘备坚持前行；关羽沉默随行。孔明不出场。入画理由：色调单纯（雪与云），三骑一线
的构图清楚，神情靠姿态区分，不涉打斗。具名限刘备、关羽、张飞三人。三处依据：

- 「时值隆冬，天气严寒，彤云密布。」
- 「忽然朔风凛凛，瑞雪霏霏；山如玉簇，林似银床。」
- 「死且不怕，岂怕冷乎？但恐哥哥空劳神思。」

## 器物与环境

- 地点：新野往隆中途中；卧龙岗在“岗前疏林内”，“柴门半掩闭茅庐”，有修竹（本回古风）。躬耕地南阳、襄阳之争不影响画面。
- 时令天气：隆冬，彤云密布，朔风，大雪纷飞；山如玉簇，林似银床。第二次访原文只写“关、张亦乘马相随”，未写从人。
- 器物：三匹马，雪覆山道；将近茅庐时“路旁酒店”（酒旗原文未写，不强加）；草庐覆雪。
- 现实中会动的：① 斜飘的雪花随风卷动；② 马鼻呼出的白气与蹄下溅起的雪粉；③ 披风衣带与树枝上簌落的积雪。

## 排除项

- 孔明本回不出场：不画草堂内景、诸葛均、孔明昼寝（第38回）；不画纶巾鹤氅与羽扇。
- 同回稍后的黄承彦骑驴踏雪、石广元与孟公威酒店对饮、崔州平（第一次访）不入画；第三次访在第38回，春日而非雪天。
- 张飞不缩颈畏寒；三人不出兵器、不打斗；不用京剧脸谱、影视造型；不画现代围巾与红斗篷。

## 现有题面核对

旧题面：`sanguo-037` / `sanguo-anim-037`（`src/core/classics/sanguo.ts`）。场面合适，沿用，改下列细节：

- 有据：隆冬阴云、北风夹雪、山林银白（“彤云密布”“山如玉簇，林似银床”）；三人骑马（“关、张亦乘马相随”）。
- 与原著不符：“张飞缩着脖子”。张飞自称“死且不怕，岂怕冷乎”，不耐烦的缘由是“恐哥哥空劳神思”，应画侧身争辩或仰首抱怨。
- 本回未写：“刘备神情恳切”只有对张飞的“吾正欲使孔明知我殷勤之意”可依，改为坚定平静；关羽神情未交代，补“沉稳随行”。
- 推断可留：“山坳深处的覆雪草庐”（茅庐在岗前疏林内，雪大覆顶合理）；刘备居前（出发时他先上马，二人相随）。
- 动态旧稿：风雪与踏雪有据；“旋转狂舞”过度，改斜向飘落；“草庐炊烟”本回未写，仅可作一缕兜底，不作主动效。
