# 《三国演义》第102回 司马懿占北原渭桥　诸葛亮造木牛流马

底本：<https://zh.wikisource.org/wiki/三國演義/第102回>；读取日期：2026-10-19。

## 情节要点

1. 谯周以群鸟投汉水、柏树夜哭谏阻；孔明祭昭烈庙，关兴病亡，仍率三十四万分五路再出祁山。
2. 司马懿在渭水搭九座浮桥、东原筑城；孔明虚攻北原、暗取渭滨，被识破，蜀兵折万余，吴班落水而死。
3. 魏将郑文诈降被孔明识破，孔明将计就计，夜间大破司马懿，秦朗死于乱军。
4. 孔明乘小车踏看渭水，见形如葫芦的上方谷，命杜叡、胡忠率匠作千余人入谷造木牛流马，马岱守谷口。
5. 木牛流马造成，高翔运粮；司马懿夺得数匹、拆开仿造二千余只，孔明将计就计，王平夺魏运粮，神兵惊退郭淮。

## 选定场面

上方谷内造木牛流马：匠作千余人依法制造，杜叡、胡忠监督，孔明立于一具成形的木牛旁指点，谷口远处是
马岱的守兵。具名孔明、杜叡、胡忠、马岱。三处依据：

- 「令唤集随军匠作一千余人，入葫芦谷中，制造“木牛流马”应用」
- 「杜叡等二人在谷中监督匠作，依法制造。」
- 「孔明每日自来指示。」

取“造”不取“运”：对应回目下联的“造”字，孔明在场；动态题面可用锯斧往复、木屑炊烟、旗动，人物与木牛不
整体位移。孔明在谷中的姿态原文未写，兜底立于木牛旁，不乘车。备选（不入画）：高翔驾木牛流马自剑阁运粮；
孔明手书造法、众将环绕而视。

先后核对：孔明乘小车踏看（前）→授杜叡、胡忠密计，唤匠作入谷，令马岱守谷口（前）→杜叡等谷中监督，
孔明每日来指示（此刻，谷中无魏兵）→杨仪告运粮不便，孔明称“尚未完备”，手书造法（后）→数日造成，
高翔运粮，张虎、乐綝夺数匹，司马懿拆开仿造（后）。

## 器物与环境

- 地点：上方谷，又名葫芦谷，“形如葫芦之状”，内可容千余人，另一谷可容四五百人，背后两山环抱，“只可通一
  人一骑”；位置在祁山前渭水一带。后世指为今陕西眉县，属演义地名，无正史依据（据摘要）。
- 时令：本回开头“青龙二年春二月”（即建兴十二年，234年）；造木牛流马一段的季节、天气、昼夜本回未写，
  兜底春季白昼，不画雪、不画火（火烧上方谷在第103回）。
- 木牛：“方腹曲胫，一腹四足。头入领中，舌著于腹”，另有“牛御双辕”。取方腹箱、曲脚四足、牛头缩入颈中、
  舌贴腹下、前有双辕，不加轮。裴注引《诸葛亮集》作“方腹曲头，一脚四足”“牛仰双辕”，与演义字句有别；
  后世复原有单轮车、四足人力机械等说，无定论，画面不取其一。
- 流马：只给肋长、孔位、杠长等尺寸，另有“板方囊二枚”“每枚受米二斛三斗”“前后四脚”“形制如象”，无整体
  描写；汉斛约20升，二斛三斗约46升（据摘要折算）。兜底：流马若出现，只画四脚、两只方形板囊，不加轮。
- 现实中会动的：① 匠人举斧、锯条来回拉动（往复）；② 木屑飘落、炊烟上升；③ 谷口与谷中旗帜随风。

## 排除项

- 六出祁山逐次（按各回纪年与孔明自述推定）：一出第91–96回（建兴六年春，街亭）；二出第97回（陈仓道口，
  郝昭、王双，祁山前费耀中计）；三出第98回后半–第99回（建兴七年，取陈仓、武都、阴平）；四出第100回
  （建兴八年秋，箕谷陈式、渭滨斗阵、添灶）；五出第101回（建兴九年春，卤城割麦、妆神、木门道射张郃）；
  六出第102–104回（建兴十二年春，北原、木牛流马、上方谷、五丈原）。本回孔明祭庙称“五出祁山”，今为第六出。
- 同回他段：北原渭桥战、郑文诈降、遁甲驱云（前）；王平夺粮扭转牛舌、张嶷扮六丁六甲神兵（鬼头兽身、五彩
  涂面、身挂葫芦）惊退郭淮（后）。神兵与第101回妆神易混，不画；本回孔明不披发、不乘四轮车，无推车使者。
- 他回：火烧上方谷、司马懿父子受困，巾帼妇人缟素之服（均第103回，不在第100回）；五丈原禳星、木像退敌
  （第103、104回，四轮车见第104回）；木门道射张郃（第101回）。
- 器物：“砲响”“火砲”是信号声，汉末无火药，不画炮筒；司马懿仿造的二千余只不画；不画齿轮、发条、机器人式
  木牛流马，不画独轮车式复原（复原争议）。
- 史实：木牛见建兴九年、流马见建兴十二年，演义并于同谷同回；督造人《通典》作廖立、杜叡、胡忠（据摘要）。
