# 《三国演义》第113回 丁奉定计斩孙綝　姜维斗阵破邓艾

底本：<https://zh.wikisource.org/wiki/三國演義/第113回>；读取日期：2026-10-19。

## 情节要点

1. 姜维撤兵，邓艾识破后路堆柴草之计，不追。东吴孙綝废孙亮、立孙休，丁奉定计，在腊日宴上
   擒斩孙綝（前半，不入画）。
2. 景耀元年冬，姜维率二十万兵出祁山，谷口下三寨；邓艾预挖地道偷袭左寨，姜维稳住中军，
   魏兵十余次冲击皆被弓弩射回。
3. 次日祁山之前斗阵：姜维布八阵，邓艾布同样阵并变成六十四门；两军入阵相围，姜维把旗一招，
   变“长蛇卷地阵”困住邓艾，司马望从西北角杀入救出。
4. 再斗阵时邓艾暗袭山后，被姜维料中，廖化斩郑伦，邓艾中四箭；党均贿赂黄皓散布流言，
   后主诏召姜维回朝。

## 选定场面

祁山之前，两军入阵相围之时：姜维在阵中把旗一招，蜀军忽然变成“长蛇卷地阵”，层层围住邓艾一军；
邓艾在核心勒马，心中大惊，引众将冲突不出。具名姜维、邓艾，蜀魏士兵为群像。三处依据：

- 「姜维到中间，把旗一招，忽然变成“长蛇卷地阵”，将邓艾困在核心」
- 「艾不知其阵，心中大惊」
- 「蜀兵渐渐逼进，艾引众将冲突不出」

这是回目下联的核心，本回唯一的阵战，两位具名人物、环形包围的构图一眼可辨，不涉伤亡。先后核对：
姜维布八阵→邓艾布同样阵→姜维问对方能否变阵→邓艾变六十四门→姜维邀入阵相围，邓艾应战→两军
入阵、阵法不曾错动（前）→姜维把旗一招、阵变、邓艾大惊被困（此刻）→蜀兵齐声喝降、艾仰天长叹→
西北角司马望杀入救出（后）。蛇头在西北出自司马望事后的话，画面可让蛇头朝左上（含推断）。

## 器物与环境

- 地点：祁山之前的开阔地，祁山在今甘肃礼县东、西汉水北（据摘要）；地面起伏未写，
  兜底：平坦旷野，远处山影。
- 时令：景耀元年冬；斗阵之日的天气、时辰未写，不画雪。
- 器物：姜维手中一面旗（形制、旗色未写）、阵旗、枪；原文只写“八卦”“六十四个门户”“长蛇卷地阵”，
  八卦是布阵格局，不是地面画的卦象。
- 阵形：“长蛇卷地阵”是演义的写法，诸葛亮八阵图今已失传，《三国志》仅一句记载（据摘要）；
  《孙子》“常山之蛇”只是比喻，不是此阵形制，兜底：蜀军盘绕成多重环圈，围住中央的魏军小阵。
- 现实中会动的：① 姜维手中令旗的旗面随风翻卷（持旗手臂不动）；② 阵中旌旗翻动；③ 马蹄下扬尘。

## 排除项

- 前：八阵布好后的方阵、邓艾变六十四门；后：蜀兵齐叫早降、邓艾长叹、司马望杀入解阵之言，
  均不画。
- 次日司马望斗阵、姜维鞭梢一指、廖化斩郑伦、邓艾中四箭、党均反间，均不入画；前夜地道袭左寨
  （王含、蒋斌）、东吴孙綝与孙休之事，也不入画。
- 不画奇门遁甲式的八卦图盘、符箓、烟雾神怪。
- 姜维北伐序次（据第108“一度兴师”、109“再出”、112“五度”、115“八次”自述，含推断）：
  一 第107回出雍州、麴山二城、牛头山，阳平关连弩退司马师；二 第109回出阳平关取南安、
  铁笼山；三 第110回洮水背水破王经、围狄道；四 第111回祁山九寨、武城山、段谷；
  五 第112回骆谷、沈岭、长城；六 第113回祁山谷口三寨、地道、斗阵，被召回（本回）；
  七 第114回三路出兵、王瓘诈降、壇山谷；八 第115回洮阳。
- 史实：维基姜维页列249、253–257、262年各次攻魏，无景耀元年冬祁山斗阵与被召回（据网页），
  斗阵与反间应为演义情节（含推断）。
