# 《三国演义》第9回 除暴凶吕布助司徒　犯长安李傕听贾诩

底本：<https://zh.wikisource.org/wiki/三國演義/第009回>；读取日期：2026-10-19。

## 情节要点

1. 李儒撞倒董卓，劝以貂蝉赐吕布；貂蝉哭诉转圜，董卓决定带她回郿坞，吕布在土冈上望车尘叹息。
2. 王允请吕布入密室，吕布刺臂出血为誓；王允与士孙瑞、黄琬、李肃定计：假称献帝禅位，诱董卓入朝。
3. 李肃到郿坞传“诏”，董卓动身，途中折轮、断辔、狂风昏雾，均被李肃说成吉兆。
4. 次日侵晨，董卓至北掖门，见王允等执剑立于殿门，惊问；王允大呼，吕布奉诏讨贼，董卓被杀。
5. 李傕、郭汜等听贾诩之计起兵犯长安，吕布败走，王允自门楼跳下被杀。

## 选定场面

北掖门前：军兵被挡在门外，李肃手执宝剑扶着董卓的御车进门，董卓遥见王允等执剑立于殿门，惊问，
李肃不应、推车直入。具名三人，吕布藏在车后，不入画；停在王允大呼、武士尚未现身之前，
不画行刺与斩首。回目“除暴凶”的最后一步，构图是车、门、持剑的人。三处依据：

- 「李肃手执宝剑扶车而行」
- 「董卓遥见王允等各执宝剑立于殿门」
- 「肃不应，推车直入」

## 器物与环境

- 地点：长安皇宫北掖门及殿门；军兵止于门外，只有御车和二十余人同入。
- 时令天气：次日侵晨；前两日途中的狂风昏雾、折轮断辔不属本场；本场天气未写，兜底：清晨平光。
- 器物：御车（车型未写，兜底：有盖双轮马车）、宝剑、朝服、仪从旗仗。
- 现实中会动的：① 车盖与仪仗旗旌随晨风飘动；② 马蹄与车轮扬起的尘土；③ 朝服袍袖与佩绶。

## 排除项

- 行刺不入画：「一戟直刺咽喉」「李肃早割头在手」、百余武士持戟挺槊、以火置脐为灯，均不取。史书是李肃以戟刺卓，卓衷甲不入，吕布持矛刺杀；演义改为吕布一戟刺喉。
- 吕布“从车后厉声出”之前藏在车后，不入画，也不画赤兔马与画戟。
- 貂蝉不在此场：她在前半被董卓带往郿坞，在车上掩面望吕布。
- 前半的刺臂出血为誓、折箭为誓、受禅台之说，同日入朝前的青袍道人（长竿悬布，两头各写“口”字）和童谣，均不入此场，也不写可辨文字。
- 王允借给曹操的是七星宝刀（第4回）；此场的是各人所执的“宝剑”。
- 蔡邕伏尸而哭、王允自门楼跳下被杀、李傕郭汜犯长安属后半，不入画。
- 不用京剧脸谱与影视造型，董卓只写“肥胖”。
