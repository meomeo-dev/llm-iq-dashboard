# 《三国演义》第84回 陆逊营烧七百里　孔明巧布八阵图

底本：<https://zh.wikisource.org/wiki/三國演義/第084回>；读取日期：2026-10-19。

## 情节要点

1. 陆逊识破吴班弱兵诱敌，三日后见先主伏兵出谷，诸将叹服；曹丕闻连营七百里，料刘备必败，遣三路袭吴。
2. 马良携营图至成都，孔明称连营七百里为兵家大忌，嘱其速劝改屯；又言入川时已伏兵于鱼腹浦。
3. 陆逊遣淳于丹试攻，再命军士持茅草，乘东南风夜举火烧蜀营；先主败走马鞍山，退入白帝城（死伤不入画）。
4. 陆逊追至夔关前，见江边乱石成堆，入石阵遇狂风，被孔明岳父黄承彦从生门引出。
5. 陆逊叹孔明为“卧龙”，料曹丕乘虚来袭，下令班师；曹仁、曹休、曹真三路魏军果然压境。

## 选定场面

魚腹浦江边沙滩的石阵里：日色将暮，狂风卷起沙石；陆逊骑在马上，勒缰惊疑；一位老者徒步立于马前，含笑
相问，正是黄承彦；身后二三随骑被风沙遮得隐约。入画理由：回目下半“孔明巧布八阵图”，二人一石阵，无死伤；
上半“火烧七百里”的现场是溃逃、践踏与乱军，具名人物多在逃命、阵亡，去掉死伤便无人可画，故不取。
引文取同一段，三处依据：

- 「忽然狂风大作。一霎时，飞沙走石，遮天盖地。」
- 「正惊疑间，忽见一老人立于马前笑曰」
- 「将军欲出此阵乎？」

先后核对：陆逊勒马回顾“前面必有埋伏”→退十余里布阵→三次探视→土人述鱼腹浦→引数十骑登山坡望石阵→
“此乃惑人之术”，引数骑直入阵→部将曰“日暮矣”→狂风大作，飞沙走石→逊惊“吾中诸葛之计也”，欲回无路
→老人立于马前问“将军欲出此阵乎”（此刻）→逊曰“愿长者引出”→老人策杖徐行，径出石阵，送至山坡，逊下马拜谢。

## 器物与环境

- 地点：夔关不远的鱼腹浦，临山傍江的沙滩；乱石八九十堆，土人称诸葛亮“取石排成阵势于沙滩之上”。《水经注》
  记石垒“聚石八行，行间相去二丈”，夏水漂荡后高处仅二三尺（汉尺约23厘米），故石堆画成成行的低矮石丛，
  风沙里显得高耸即可。毛本写阵中“怪石嵯峨，横沙立土，重叠如山”，是风沙中所见。
- 时令：日将西沉，黄昏；季节本回未写。江边沙碛夏被水淹、冬季出露，画面取沙滩露出，江水退在后方。
- 器物：乱石堆、沙滩、竹杖、战马；八门名称不写字；江声“浪涌，有如剑鼓之声”。
- 现实中会动的：① 风卷沙粒斜向横飞，循环往复；② 江面浪涌翻白、拍岸后退；③ 陆逊与黄承彦的衣袍、须发
  和马鬃被风吹起，随骑的盔缨飘动。

## 排除项

- 火烧连营：夜里东南风举火、先主逃马鞍山、傅彤断后、程畿自刎、孙夫人投江，均为本回另一半，不入画。
- 黄承彦引路出阵：策杖徐行、送至山坡、陆逊下马拜谢、陆逊叹“孔明真卧龙”（后）；陆逊笑“惑人之术”（前）。
- 诸葛亮本人不在场；孔明所说“十万兵在鱼腹浦”指石阵（黄承彦称“可比十万精兵”），哨马回报“并无一人一骑”，
  故不画列阵士兵、旗号、鼓角。
- 后世的八卦图、太极图与奇门光效；八门文字；黄承彦着冬日裘帽骑驴；成都另有“旱八阵”，与本回无关。
- 影视、游戏、戏曲造型不取；画面不写可辨认的长段文字。
