# 《三国演义》第108回 丁奉雪中奋短兵　孙峻席间施密计

底本：<https://zh.wikisource.org/wiki/三國演義/第108回>；读取日期：2026-10-19。

## 情节要点

1. 姜维以连弩（药箭）射退司马师；麴山句安降魏；嘉平三年八月司马懿病逝，师为大将军，昭为骠骑上将军。
2. 孙权崩，诸葛恪辅孙亮；司马师议伐吴，三路各十万兵，司马昭为大都督，冬十月至东吴边界。
3. 胡遵搭浮桥取东兴大堤，攻左右二城不下；诸葛恪令丁奉率三千水兵，分三十船往东兴。
4. 时值严寒大雪，胡遵设席高会；丁奉令军士脱衣甲、卸头盔，止带短刀，魏兵见之大笑；连珠砲三响，丁奉当先
   一跃上岸，砍入魏寨，浮桥断，魏军大败。
5. 诸葛恪攻新城不下，中箭，军士多病，回朝；孙峻、滕胤席间斩恪（此事不入画），恪全家被诛。

## 选定场面

东兴大堤外水面：三十只吴船一字排开靠岸，大雪纷飞；连珠砲响三声，丁奉不披甲、不戴盔，手扯短刀，
从船头当先跃向堤岸，众军同样无甲无盔，拔出短刀随后。具名丁奉；魏寨在堤上，营帐旗帜作背景，不画接战。
三处依据：

- 「时值严寒，天降大雪，胡遵与众将设席高会」
- 「遂令众军脱去衣甲，卸了头盔，不用长枪大戟，止带短刀。」
- 「忽然连珠砲响了三声，丁奉扯刀当先，一跃上岸。」

取“一跃上岸”而不取“脱甲对笑”：回目的“奋”落在出手一刻，只有丁奉一人具名，且尚未接敌；“魏兵见之大笑”
发生在砲响之前，不与此刻并列。先后核对：设席高会、船傍岸、胡遵出寨视之后回帐饮酒（前）→丁奉抛船、
令脱甲卸盔、魏兵大笑（前）→砲响三声，丁奉扯刀当先上岸，众军拔刀随之（此刻）→砍入魏寨、韩综被砍、
桓嘉中刀、浮桥断（后）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 丁奉 | 演义称平北将军（史载字承渊）；已脱衣甲、卸头盔，不戴盔不披甲，一手扯短刀，自船头跃出。严寒中仍着单薄布衣（“衣甲”按甲胄理解，不画赤膊，属推断）；发束髻或裹巾；面貌未写，兜底：壮年武将 | 第108回“脱去衣甲，卸了头盔”“扯刀当先” |
| 吴兵三千 | 分三十船，每船约百人；与丁奉同样无甲无盔，止带短刀，不持长枪大戟；原文未写盾，不画盾；拔刀随丁奉上岸 | 第108回“皆拔短刀，随奉上岸” |
| 魏军 | 胡遵在帐中饮酒，不画；魏兵披甲，持长枪大戟（韩综有“帐前大戟”），在堤上寨中，此刻措手不及，作背景小像 | 第108回 |
| 韩综、桓嘉 | 后一刻被砍中，不画 | 第108回 |

## 器物与环境

- 地点：东兴（今安徽含山西南濡须水一带），吴筑大堤，左右各一城，魏军搭浮桥上堤、驻营堤上。原文“胡遵在徐州
  下寨”，与史载的徐塘不合，题面不写“徐州”。
- 时令：严寒大雪；原文作“冬十月”，史载交战约在十二月前后，题面只写“严冬大雪”。堤岸与魏寨可有积雪。
- 器物：三十艘战船，形制未写，兜底：狭长木船，一字排开，船头靠堤；短刀（三国刀为环首刀，吴刀长短说法
  不一，不写尺寸）；“连珠砲”是号令声，不画火炮；魏方浮桥此刻完好，后一刻才断。
- 现实中会动的：① 雪片斜落；② 船头水波与船身起伏；③ 魏寨旌旗，及人呼出的白气。

## 排除项

- 后一刻：砍入魏寨、韩综被砍倒、桓嘉中刀、胡遵上马逃、浮桥断落水、雪地死者。
- 前一刻：魏兵大笑、胡遵出寨视船又回帐饮酒、丁奉“大丈夫立功名”的训话。
- 同回他场：姜维连弩、司马懿病逝、孙权崩；诸葛恪的白虹、新城中箭、血臭黄犬；孙峻席间杀恪（不画）。
- 史实出入：史载丁奉部“解铠著胄”，保留头盔、持刀盾，是否赤身说法不一；演义写卸头盔、止带短刀，本题按演义。
- 后世造型：丁奉粉红老脸、“神弹子”手飞石传说；游戏造型；楼船与火炮。
