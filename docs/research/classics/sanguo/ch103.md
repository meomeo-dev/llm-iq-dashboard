# 《三国演义》第103回 上方谷司马受困　五丈原诸葛禳星

底本：<https://zh.wikisource.org/wiki/三國演義/第103回>；读取日期：2026-10-19。

## 情节要点

1. 廖化、张翼杀败司马懿，懿弃金盔、反向西走脱身；廖化献盔得头功，魏延不悦，后持此盔去魏寨骂战。
2. 孔明令马岱封葫芦谷后路、谷中伏柴雷，昼举七星旗、夜设七盏明灯，作魏延诱敌入谷的暗号；司马懿父子
   追入上方谷遇火，懿下马抱二子大哭，狂风霹雳、骤雨浇灭谷火，父子突围；孔明叹“谋事在人，成事在天”。
3. 孔明屯五丈原，送巾帼素衣激懿，懿受之不战；使者言孔明“食少事烦”；费祎报吴军无功而还，孔明昏倒。
4. 八月中秋夜，孔明令姜维率四十九甲士守帐，自在帐中设灯祈禳北斗，约定七日内主灯不灭可增寿一纪。
5. 第六夜，孔明见主灯明亮；魏延飞步入帐急报魏兵至，踏灭主灯，孔明弃剑而叹，姜维拔剑欲杀魏延。

## 选定场面

五丈原禳星第六夜：孔明在帐中披发仗剑、踏罡步斗，灯阵中主灯明亮，姜维刚入帐便看见。具名孔明、
姜维；魏延尚未闯入，不画。三处依据：

- 「孔明在帐中祈禳已及六夜，见主灯明亮，心中甚喜。」
- 「姜维入帐，正见孔明披发仗剑，踏罡步斗，压镇将星。」
- 「地上分布七盏大灯，外布四十九盏小灯，内安本命灯一盏。」

二选一取“五丈原禳星”，不取“上方谷大雨”：前者是回目下联，灯数、布置、孔明披发仗剑的样貌均有原文可核；
后者要同时画烈焰、骤雨与三个人物，火势与雨势是先后两态，孔明又只在山上远望，不是画面主角。

先后核对：首夜设灯、拜祝、俯伏（前）→第六夜孔明见主灯明亮→姜维入帐，见孔明披发仗剑踏罡步斗（此刻）
→寨外吶喊，魏延飞步入报，撞灭主灯（后）→孔明弃剑而叹、姜维拔剑（后）。吶喊与灯灭均在后，不画。

## 器物与环境

- 地点：五丈原蜀军大营，孔明帐中。五丈原在今陕西岐山县南约20公里，黄土台塬高约120米，南依秦岭、北临渭水；
  帐内场面不需画地形。
- 时令：“八月中秋”，夜；首夜写景为“银河耿耿，玉露零零；旌旗不动，刁斗无声”，第六夜未另写，沿用为夜景基调。
  月相本回未写，不强画满月。刁斗为军中有柄铜器，昼炊夜击，此处“无声”，可不画。
- 灯阵：地上七盏大灯，外圈四十九盏小灯，最内一盏本命灯，合五十七盏；七盏大灯的排列原文只写“分布”，
  排成北斗之形属推断（因祈禳北斗）。“主灯”原文未指明是哪一盏，通俗解读多视作本命灯；题面可写
  “中央一盏最亮的主灯”，不把它数进七盏。另有香花祭物。
- 现实中会动的：① 灯焰轻微摇曳、主灯最亮；② 香烟升起；③ 孔明披散的头发与衣袖随步伐摆动。
  旌旗原文“不动”，不让旗帜飘动。

## 排除项

- 魏延闯入、踏灭主灯、孔明弃剑、姜维拔剑欲杀、寨外吶喊、夏侯霸探营（均在后）；首夜拜祝俯伏（在前）。
- 上方谷火海、骤雨、抱二子大哭、地雷与柴草；“七星旗”“七盏明灯”是引魏延入谷的暗号，不是禳星灯。
- 纶巾、羽扇、四轮车（此刻披发仗剑，不坐车不持扇）；戏曲八卦衣、影视“续命灯”造型。
- 后世习俗：中秋赏月、月饼等；演义只写时令“八月中秋”，中秋节在宋代才成型。
- 史实：孔明病逝于五丈原，史书无禳星；此为演义情节。
