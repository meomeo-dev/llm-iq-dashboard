# 《三国演义》第2回 张翼德怒鞭督邮　何国舅谋诛宦竖

底本：<https://zh.wikisource.org/wiki/三國演義/第002回>；读取日期：2026-10-19。

## 情节要点

1. 董卓怠慢刘备，张飞要杀，三人转投朱儁；破张宝妖法（泼猪羊狗血），刘备箭中张宝左臂；破宛城，孙坚登场。
2. 论功不赏，刘备只得中山府安喜县尉。到县未及四月，朝廷下诏沙汰军功长吏，督邮行部至县，借机索贿。
3. 督邮扣押县吏，拒不见刘备。张飞饮闷酒，见五六十个老人在馆驿门前痛哭，径入后堂。
4. 张飞把督邮扯出馆驿，缚在县前马桩上，扳柳条鞭打；刘备赶来喝止，关羽劝弃官，刘备解印绶挂在督邮颈上，三人离去。
5. 后半回转入朝廷：十常侍弄权，灵帝崩，何进听袁绍计发檄召外兵，回末曹操笑陈琳之谏。

## 选定场面

取回目所标的“怒鞭督邮”，定在刘备赶到、尚未喝止的一瞬：督邮被缚在县前马桩上，张飞扳下柳条、
举臂欲抽，刘备疾步赶来，关羽从旁转出。只画鞭未落之时，不画抽打、伤痕与血迹。具名人物恰为
四个（张飞、督邮、刘备、关羽），旁可加围观老人与县吏作群像。三处依据：

- 「扳下柳条，去督邮两腿上着力鞭打」
- 「直到县前马桩上缚住」
- 「急喝张飞住手」

## 器物与环境

- 地点：定州中山府安喜县县前，设有拴马的“马桩”（《三国志》作“马枊”）；馆驿即汉代的传舍，是督邮行部止宿之处。
- 柳条：“一连打折柳条十数枝”，可画县前一株垂柳，地上已有折断的枝条。原文不写季节与天气，
  兜底：白昼，不强加雨雪。
- 缚人：以绳缚于马桩，原文不写镣铐，不画刑具。
- 现实中会动的：① 垂柳枝条随风摆动、折枝落地；② 张飞、刘备的衣袖衣带与关羽长髯被风带起；③ 县前扬起的尘土与老人的衣角。

## 排除项

- 史书出入：《三国志·先主传》写刘备本人“杖二百”并系督邮颈于马枊，演义改由张飞鞭打；题面按演义，鞭打者是张飞。
- “解印绶挂督邮颈”“弃官而去”在鞭打之后，不并入画面；督邮不画成已被打得伤痕累累。
- 本回前半的董卓怠慢、张宝妖法、宛城战，后半的十常侍、何进、袁绍、曹操，不入画面；孙坚此回出场，不入画。
- 关羽绿锦战袍（本回未写；第5回赞诗才有“鹦鹉战袍”）、赤兔马（第25回后才归关羽）、戏曲脸谱与丑角扮相的督邮不用。
