# 《三国演义》第16回 吕奉先射戟辕门　曹孟德败师淯水

底本：<https://zh.wikisource.org/wiki/三國演義/第016回>；读取日期：2026-10-19。

## 情节要点

1. 袁术遣纪灵攻小沛，刘备求救；吕布在营中请二人赴宴，立画戟于辕门外，射中戟小枝，两家罢兵。
2. 袁术求亲，陈宫、陈珪先后进言，吕布追回女儿、囚韩胤；张飞劫马，吕布攻小沛，刘备投曹操。
3. 曹操征张绣，宛城受降，纳邹氏；张绣与贾诩夜袭，典韦战死，曹昂、曹安民亦亡。
4. 于禁整军退敌，曹操祭典韦；吕布杀袁术使者，陈登往返于吕布与曹操之间。

## 选定场面

取吕布开弓将发的一瞬：中军帐前，吕布挽起袍袖、扯满弓；刘备、纪灵分坐帐中，刘备暗祝，
刘备身后二将按剑；远处辕门外画戟插定，在画面里只是一条细杆。具名人物：吕布、刘备、纪灵。
理由：全回最单纯的一幕，无打斗无血腥，人物关系与悬念一目了然。宛城之战含典韦战死、乱箭
射杀，不选。只取箭未中戟之前。引文三处：

- 「吕布挽起袍袖，搭上箭，扯满弓，叫一声“着！”」
- 「辕门离中军一百五十步，吾若一箭射中戟上小枝，你两家罢兵」
- 「令左右接过画戟，去辕门外远远插定」

## 器物与环境

- 地点：吕布营在沛县西南一里，中军帐内外。辕门即军营之门（汉典：古时军营的门或官署的
  外门）。原著称辕门离中军一百五十步；史载只写「营门中举一只戟」，无步数。
- 时令：本回未写时辰与天气。赞诗「弓开如秋月行天」「落日果然欺后羿」是比喻，不是实景。
  兜底：白昼晴好，季节不写。
- 器物：画戟（汉典：饰有彩画的戟；戟小枝即旁出的枝刃，方天戟尖头两旁有一对月牙形戈身）、
  弓箭、酒与大觥、坐席、营帐。
- 现实中会动的：① 吕布袍袖与拉满后微颤的弓弦；② 离弦飞向辕门的箭；③ 帐帘与营旗一角。

## 排除项

- 射中后的「掷弓于地，呵呵大笑」与众将喝采是下一刻，不画；箭尚未中戟。
- 同回后半的曹操宛城之战（邹氏、典韦、淯水、曹昂之死）不混入。
- 吕布此刻不在马上，赤兔不入帐，手中无戟（戟已远插）；张飞拔剑叱喝是此前一幕，
  此时只按剑；纪灵的三尖刀不在手。
- 原文只称「画戟」，「方天」二字见第3回；戟不加饰物。不用京剧脸谱、影视盔甲、游戏改造兵器，
  不画滑轮弓或现代反曲弓。
