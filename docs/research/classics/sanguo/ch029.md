# 《三国演义》第29回 小霸王怒斩于吉　碧眼儿坐领江东

底本：<https://zh.wikisource.org/wiki/三國演義/第029回>；读取日期：2026-10-19。

## 情节要点

1. 孙策先杀许贡；许贡的三个门客在西山射猎时伏击孙策，孙策面颊中箭，程普救回，医者嘱静养百日。
2. 孙策在城楼宴请袁绍使者陈震，见诸将下楼拜道人于吉，怒而下狱；吴太夫人与众官苦谏。
3. 吕范荐于吉祈雨赎罪；于吉自缚烈日下登坛，午时风起云合，柴堆起火，雷电大雨；孙策仍令斩于吉。
4. 于吉屡屡显形，孙策金疮迸裂，临终以印绶授孙权，嘱张昭、周瑜辅佐；孙权受谒，周瑜荐鲁肃，鲁肃再荐诸葛瑾。
5. 曹操封孙权为将军，袁绍起兵七十余万再攻许昌（下回接续）。

## 选定场面

吴郡街市旁的求雨坛前，大雨刚过，“街市成河”，云收雨住、复见太阳；官民在积水中罗拜，
众人把于吉从柴堆上扶下、解去绳索，孙策立于坛上，见官民拜于水中，勃然变色，手按佩剑而未出鞘。
取这一刻：风雨雷电的神异与孙策的怒意同在，不画点火焚人，也不画斩首。具名限孙策、于吉两人，
众官（可含张昭）、百姓作群像。三处依据：

- 「顷刻之间，街市成河，溪涧皆满」
- 「众官及百姓，共将于吉扶下柴堆，解去绳索，再拜称谢」
- 「孙策见官民俱罗拜于水中，不顾衣服，乃勃然大怒」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙策 | 《三国志》称“美姿颜，好笑语，性阔达”；毛本本回只写他“性急”。面颊中箭，用刀割袍裹伤，之后“不待疮愈”，兜底：一侧面颊缠素帛，不画血迹（左右未写）；衣冠未写，兜底：武将常服加袍，戴冠或巾帻，腰间佩剑；神情愤怒 | “正中孙策面颊”；“以刀割袍，裹其伤处” |
| 于吉 | 初见“身披鹤氅，手携藜杖”；祈雨时“沐浴更衣，取绳自缚”，被扶下后“解去绳索”；年纪未写。兜底：素色长衣，被雨淋湿，发束髻，不持杖，神态平静 | “身披鹤氅，手携藜杖”；“即沐浴更衣，取绳自缚” |
| 众官与百姓 | 群像，“不顾衣服”拜于水中；官员兜底：进贤冠或巾帻，宽袖袍；百姓：布衣，被雨打湿 | “官民俱罗拜于水中” |

## 器物与环境

- 地点：吴郡郡城内街市旁的求雨坛（“令登坛求雨”“百姓观者，填街塞巷”）；坛形未写，
  《春秋繁露》载汉代求雨坛为方形，兜底：方形土台，台边立旗，不强加东门外四通之坛。
- 时令天气：“方今天旱”；午时前“狂风骤起，四下阴云渐合”，继而雷电大雨，后“云收雨住，复见太阳”；
  季节未写。本场取雨后初晴：地面积水，云缝透出日光。
- 器物：已被雨淋的乾柴堆，残烟未散；散落的绳索；坛上旗幡；孙策佩剑（原佩剑在西山折断，此剑另配，形制未写）。
- 现实中会动的：① 湿柴堆残烟袅袅上升；② 积水被脚步与檐角、柴垛滴落的水珠扰出涟漪；
  ③ 坛上旗幡与官员衣带在余风中飘动。

## 排除项

- 一刀斩头落地、号令于市、尸首不见一律不画；点火烧人亦不画，柴堆只作被雨淋透的残堆。
- 于吉化青气、现身镜中、立于火光或屋顶、坐于香烟华盖之上等显灵段落是后文，本场不画。
- 西山遇刺、吴太夫人劝谏、孙策临终授印绶、孙权“碧眼紫髯”坐领江东均在本回别段，不混入；孙权不入画。
- 于吉不画太极八卦道袍、道冠、拂尘等后世道士造型（鹤氅一名魏晋文献才见，早期近披肩羽衣，
  不画清代氅衣或戏曲鹤氅）；不画光环、龙王等仙术特效。
- 《搜神记》“于吉随军被曝晒求雨”是异说，本场依毛本：城中登坛求雨。孙策不用影视白袍银甲、双戟的“小霸王”造型。
