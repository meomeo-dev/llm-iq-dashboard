# 《三国演义》第3回 议温明董卓叱丁原　馈金珠李肃说吕布

底本：<https://zh.wikisource.org/wiki/三國演義/第003回>；读取日期：2026-10-19。

## 情节要点

1. 曹操谏何进勿召外兵不听；董卓奉诏进兵，上表请除十常侍。何进被张让伏兵所杀，袁绍、曹操杀入宫中诛宦官。
2. 张让劫少帝与陈留王夜奔北邙，被崔毅收留，闵贡护送还都，路遇董卓迎驾；董卓屯兵城外，横行街市。
3. 董卓在温明园聚百官议废立，丁原推案反对，董卓拔剑，见丁原背后吕布执方天画戟怒视，被李儒劝住。
4. 丁原出战，吕布挺戟直杀，董卓败退。李肃自荐去说吕布，带赤兔马、黄金千两、明珠数十颗、玉带一条，入寨献马。
5. 吕布夜入帐杀丁原，次日持首级见董卓，拜为义父；董卓欲定废立，筵上袁绍拔剑相对。

## 选定场面

取回目“馈金珠李肃说吕布”的头一段：李肃带赤兔马来到吕布营寨，入见之后吕布在寨中帐前“令牵过来看”，见马大喜。
赤兔马在本回首次登场，原文有尺寸与毛色的细描；具名人物只有李肃与吕布，画面是赠马而非厮杀。
金珠玉带是进帐、屏退左右后才摆出的，丁原被杀在当夜帐中，二者不并入画面。三处依据：

- 「浑身上下，火炭般赤，无半根杂毛」
- 「从头至尾，长一丈；从蹄至项，高八尺」
- 「布见了此马，大喜」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 吕布 | 器宇轩昂，威风凛凛；战阵装束：顶束发金冠，披百花战袍，擐唐猊铠甲，系狮蛮宝带，纵马挺戟；温明园“手执方天画戟”。献马时衣着未写，兜底：取战阵装束，戟立在身侧 | 温明园段；对阵段 |
| 李肃 | 虎贲中郎将，与吕布同乡；外貌衣冠本回未写。兜底：武官袍服，头戴武冠（虎贲中郎将冠鹖尾），不披重甲，以使者身份来 | 献计段；寨中段 |
| 赤兔马 | 浑身火炭般赤，无半根杂毛；长一丈、高八尺（汉尺约23厘米，折2.3米长、1.8米高，远高于汉代实马，画得高大雄骏即可）；“嘶喊咆哮，有腾空入海之状”。鞍辔未写，兜底：寻常鞍辔，由军士牵来 | 献马段 |
| 伏路军士 | “伏路军人围住”李肃，入寨报信；衣着未写，兜底：普通甲士，群像 | 入寨段 |

## 器物与环境

- 地点：吕布寨中帐前（李肃“投吕布寨来”，入见后吕布“令牵过来看”）。时令天气本回未写，兜底：白昼，不强加季节雨雪。
- 方天画戟：戟头两侧各带月牙形小枝；宋元以后小说多见，历史上多为仪仗之物，原文只称“方天画戟”。
- 现实中会动的：① 赤兔马鬃尾随嘶鸣甩动、前蹄刨地、鼻息喷出；② 营寨旗幡与戟缨被风吹动；③ 吕布战袍下摆与宝带垂饰。

## 排除项

- 温明园拔剑、吕布执戟怒视（同回前段）与吕布夜入帐斩丁原（当夜，血腥）不入画面；董卓赐金甲锦袍、拜义父在其后。
- 赤兔马此时属吕布；关羽得赤兔是第25回曹操所赠，本题不出现关羽，也不写“赤兔属关羽”。
- 第5回详写的三叉紫金冠、西川红锦百花袍、兽面吞头连环铠、弓箭随身，不写入本回；戏曲雉尾翎也不用。
- 李肃不用《三国志平话》的银盔、银锁甲、白袍、倒须钩枪造型；赤兔不画火焰、翅膀，毛色单一赤红。
