# 《三国演义》第43回 诸葛亮舌战群儒　鲁子敬力排众议

底本：<https://zh.wikisource.org/wiki/三國演義/第043回>；读取日期：2026-10-19。

## 情节要点

1. 鲁肃、孔明辞别刘备、刘琦，乘舟到柴桑。孙权拿着曹操檄文议事，张昭率谋士主降，孙权沉吟；
   鲁肃趁孙权更衣劝他不可降，并荐孔明。
2. 次日幕下，张昭、顾雍等二十余人峨冠博带端坐。孔明坐于客位，先后答张昭、虞翻、步骘、
   薛综、陆绩、严畯、程德枢，众人无言以对；黄盖入内制止，引孔明见孙权。
3. 孔明故说曹兵百余万，以言激孙权；孙权拂衣退入后堂，经鲁肃点破转怒为喜，后堂置酒，
   听孔明说破曹形势，决意联刘。
4. 张昭、顾雍再谏，孙权又犹豫；吴国太提起孙策遗言（下回接续）。

## 选定场面

幕下舌战：谋士分坐两侧，孔明坐于客位，听完张昭的长篇诘问后“哑然而笑”，抬手作答；
虞翻在座中抗声质问。一人对众人，冲突全在对坐的姿态与神情，不动兵刃。具名限诸葛亮、张昭、
虞翻三人，其余谋士作群像，鲁肃、孙权、黄盖不入画。原文孔明是“坐于客位”，不是立姿。
三处依据：

- 「二十余人，峨冠博带，整衣端坐」
- 「施礼已毕，坐于客位」
- 「孔明听罢，哑然而笑曰」

## 器物与环境

- 地点：柴桑孙权“帐下”“幕下”，室内幕帐，宾主两列相对，孔明居客位。柴桑在今九江西南，
  孙吴时治所确址未定。
- 时令：曹操南征之冬（下回周瑜称“时值隆冬盛寒”）；本回未写天气，兜底：以室内为主，不强加雪景。
- 器物：高冠、宽袖袍服；席与低矮榻几，人物跪坐；不画高背椅、高脚桌。
- 现实中会动的：① 幕帐帷幔被穿堂风轻拂；② 孔明与诸人的宽袖、冠带随手势微动；
  ③ 案前一缕香炉青烟（原文未写香炉，属兜底，可不用）。

## 排除项

- 孙权、后堂说破曹、拂衣而起，黄盖与诸葛瑾中门叙话属本回后段；孙权不在幕下，不画。
- 周瑜、铜雀台赋与二乔（第44回）、草船借箭（第46回）、借东风（第49回）不混入。
- 不画孔明立于众谋士之间，不画羽扇与鹤氅（影视造型）；群儒不戴戏曲乌纱翅帽，不着明代补服。
- 不画争吵动手、拍案拔剑：原文只有言辞交锋。“献茶”在孙权堂上，幕下不画茶具。
