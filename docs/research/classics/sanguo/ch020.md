# 《三国演义》第20回 曹阿瞒许田打围　董国舅内阁受诏

底本：<https://zh.wikisource.org/wiki/三國演義/第020回>；读取日期：2026-10-19。

## 情节要点

1. 刘备、关羽保下张遼，曹操掷剑释缚；张遼、臧霸相继归降；回许都后刘备被引见献帝，宗谱排下来是献帝之叔，拜左将军，人称刘皇叔。
2. 曹操诬陷杨彪、杀议郎赵彦，程昱劝其行王霸之事，曹操决定请天子田猎，观望动静。
3. 许田围猎：献帝连射三箭不中大鹿，曹操讨过宝雕弓、金鈚箭一箭射中；群臣见金鈚箭，以为天子射中而呼万岁，
   曹操纵马遮于天子之前受贺；关羽欲斩曹操，刘备摇手制止。
4. 献帝泣告伏皇后，伏完献计；帝咬破指尖血书密诏，缝入玉带紫锦衬，在功臣阁赐董承。
5. 董承灯花烧破玉带见血诏，与王子服、种辑、吴硕、吴子兰、马腾结盟，马腾提议再请刘备。

## 选定场面

许田围场上，曹操射中大鹿后策马挡在献帝之前，受群臣欢呼；刘备身后的关羽怒起，提刀拍马欲出，
刘备慌忙摇手送目，关羽止住。曹操、献帝、刘备、关羽四人同框，冲突全在眼神与手势，没有出手与流血；
弓、鹿、马、旗都是现成画面元素，鹿只画伏在草中。三处依据：

- 「曹操纵马直出，遮于天子之前以迎受之」
- 「云长大怒，剔起卧蚕眉，睁开丹凤眼，提刀拍马便出」
- 「玄德见了，慌忙摇手送目」

## 器物与环境

- 地点：许田围场“周广二百余里”，草中起兔，土坡转过，荆棘中赶出大鹿；许田为许昌古地名，射鹿台是后世传说遗迹。
- 时令：本回未写季节；回末密诏落款“建安四年春三月”，打围在其前。兜底：浅草与枯草相间，不强加花、雪、落叶。
- 器物：宝雕弓（雕饰之弓）、金鈚箭（鈚指箭头宽薄的箭，“金”字未释，兜底：金饰箭镞配雕翎）；
  掩心甲（护胸甲，兜底：胸前一片护甲，不画明光铠圆护）；备有的良马、名鹰、俊犬；伏在草中的鹿。
- 现实中会动的：① 风吹草浪与旗旛、袍带；② 战马扬鬃、喷息、踏蹄；③ 猎鹰盘旋振翅（原文备有名鹰）。

## 排除项

- 关羽不出手：只是“提刀拍马便出”即被止，不画挥刀砍曹操；刘备不出声，只摇手送目。
- 曹操是“讨”来天子弓而射，射后“竟不献还”，不画夺弓；刘备射中的是兔，欢呼的对象是鹿，不混。
- 爪黄飞电的“白身黄蹄”是后世百科说法，原文只有马名，不强加毛色；曹操不画白脸。
- 回后半功臣阁、血诏、玉带、董承、马腾结盟属另一场面，不入画；献帝不戴冕旒。
