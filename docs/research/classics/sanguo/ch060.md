# 《三国演义》第60回 张永年反难杨修　庞士元议取西蜀

底本：<https://zh.wikisource.org/wiki/三國演義/第060回>；读取日期：2026-10-19。

## 情节要点

1. 张松形貌短陋，奉刘璋之命，暗画四川地理图本藏之，赴许都；曹操傲慢冷遇，张松言语冲撞，被逐。
2. 杨修与张松辩难，张松过目诵出《孟德新书》，说是战国无名氏所作；曹操令烧书，次日西教场阅兵，
   张松揭曹操败绩，几被斩，乱棒打出。
3. 张松改道荆州，赵云、关羽接待，刘备率孔明、庞统出迎，宴饮三日不提川事；十里长亭送行时，
   张松劝取西川，袖中取出地图献刘备，并荐法正、孟达。
4. 张松回益州劝刘璋遣法正、孟达结好刘备，黄权、王累力谏不听；刘备听庞统“逆取顺守”之议，
   留孔明等守荆州，自与庞统西行；涪城会刘璋，庞统献席间杀璋之计，刘备不从（下回接续）。

## 选定场面

荆州城外十里长亭，刘备设宴送别张松。张松劝取西川之后，从袖中取出一图递给刘备，刘备接图略展开观看，
图上山川险要、府库钱粮一一载明。取“接图略展”的瞬间：地图是“西蜀”的象征，貌陋的使者与身长七尺五寸的
主公形成对比，无需打斗。具名限张松、刘备；孔明在场（作别后“孔明命云长等护送”），庞统同席与否原文未写；为突出二人，均不画。三处依据：

- 「玄德于十里长亭，设宴送行」
- 「松于袖中取出一图，递与玄德曰」
- 「玄德略展视之，上面尽写着地理行程」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张松 | 益州别驾；“额钁头尖，鼻偃齿露，身短不满五尺，言语有若铜钟”（身高不及刘备七尺五寸的三分之二）；此时已决意投刘备，“披沥肝胆”；衣冠本回未写，兜底：宽袖袍服、巾帻，袖口宽大可藏折叠之图，不画明清官帽与补子；递图的手伸向刘备 | 第60回 |
| 刘备 | 身长七尺五寸，两耳垂肩，双手过膝，目能自顾其耳，面如冠玉，唇如涂脂（第1回）；本回约年过五十（第54回自称“年已半百，鬓发斑白”）；须本回未写，史载无须，兜底：少须或无须，不画长髯；衣冠未写，兜底：深色宽袍、巾帻，双手接图，不佩甲、不戴冠冕 | 第1、54、60回 |
| 随从（群像，可略） | 本回只写“设宴送行”；兜底：数名仆从与马匹立于亭外，不具名 | 第60回 |

先后核对：宴上举酒、刘备潸然泪下，张松劝取川、刘备推辞再三，问“用何良策”，张松取图递上，刘备略展视之，
张松荐法正、孟达，孔明命云长等护送。所选取“展视”一刻，不拼“荐法正、孟达”与护送。

## 器物与环境

- 地点：荆州城外十里长亭（汉制十里一亭，亭为治安邮传设施，早期为四方木构，屋面直坡，四阿或攒尖顶）；
  取一座路旁方亭，席地设宴，矮案上陈酒樽、耳杯（原文“举酒酌松”）。
- 时令：本回未写，兜底：不强加季节与天气，不画雪。
- 地图：“于袖中取出”，说明可折叠；汉代地图实物为帛，黑、红、青三色绘制，折叠存放；本回形制未写，
  兜底：折叠的帛或纸，展开一角，以山形、河流与朱墨标记示意，不写可辨认长文，
  不画经纬线、等高线、比例尺与指北针。
- 现实中会动的：① 地图展开的一角与宽袖、衣摆随风轻颤；② 亭外马匹甩尾、踏蹄、喷鼻；
  ③ 远处道路上尘土缓缓升起（兜底）。

## 排除项

- 杨修、《孟德新书》、曹操、西教场阅兵、乱棒打出属前半回；赵云迎于郢州界口、关羽驿馆接待在此前数日，不画。
- 法正、孟达、黄权、王累、刘璋、涪城会均在其后；孔明、庞统不入画。
- 不用京剧丑角勾脸、小丑扮相表现张松，不用影视夸张歪嘴；刘备不画双股剑、长髯与帝王冕旒。
- 不画现代地图元素（经纬线、图例、指北针）；地图不画成大幅卷轴挂图，亦不从袖中抽出巨幅长卷。
