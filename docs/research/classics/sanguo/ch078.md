# 《三国演义》第78回 治风疾神医身死　传遗命奸雄数终

底本：<https://zh.wikisource.org/wiki/三國演義/第078回>；读取日期：2026-10-19。

## 情节要点

1. 刘备闻关羽遇害，哭绝于地；孔明劝其按兵不动，先为关羽发丧，川中大小将士挂孝。
2. 曹操葬关羽后夜夜梦见关羽；欲起建始殿，伐跃龙祠梨树，剑下血溅满身，夜梦梨树神欲杀他。
3. 曹操头痛，华佗献议开颅取风涎，曹操疑其为关羽报仇，下狱；华佗将《青囊书》赠狱卒，书后被狱卒之妻焚毁。
4. 曹操病中屡见伏皇后等幽魂，孙权上书劝其称帝，曹操不允，封孙权为骠骑将军。
5. 曹操召曹洪、陈群、贾诩、司马懿榻前托付后事，嘱立曹丕，又分香、卖履、设疑冢；建安二十五年春正月病逝，寿六十六。
6. 曹丕嗣魏王位，闻曹彰领兵而来，使人往见（下回接续）。

## 选定场面

洛阳别宫卧榻前：曹操病中半倚榻上，目不见物，向榻前伏地聆听的曹洪、贾诩、司马懿（陈群同在）
口授后事，托付诸子，说「惟长子曹丕，笃厚恭谨，可继我业」。入画理由：回目“传遗命”的核心，
一榻数人即成构图，诸子不在场，靠言语托付，不必画死亡与幽魂。不画其后的分香卖履（对诸侍妾）。
具名曹操、曹洪、贾诩、司马懿；陈群与近侍为群像。三处依据：

- 「操召曹洪、陈群、贾诩、司马懿等，同至卧榻前，嘱以后事。」
- 「孤今病危，不能再与卿等相叙，特以家事相托。」
- 「惟长子曹丕，笃厚恭谨，可继我业。」

先后核对：召四人至榻前→曹洪等顿首「善保玉体」→曹操托付诸子「卿等宜辅佐之」（此刻，曹洪等伏听）
→曹洪等涕泣领命而出→令近侍取名香分赐诸侍妾、嘱卖丝履→设祭铜雀台、疑冢→气绝。涕泣出门、分香、气绝均在后。

## 器物与环境

- 地点：洛阳别宫（曹操受梨树神惊后“迁于别宫养病”）；建始殿未建成，非此处。殿内一榻，榻后屏风、榻侧垂帷帐，
  榻前置几（本回未写，兜底，依汉代坐具）。
- 时令：建安二十五年春正月；室内，天气不画；时辰未写，兜底：灯火照明。
- 器物：汉代铜灯（雁鱼灯式或连枝灯）、榻、屏风、帷帐、几；名香、香炉属其后分香一刻，此刻可省。
- 现实中会动的：① 灯焰摇曳，灯影在屏风与帷帐上晃动；② 帷帐下摆与伏地者的袖角微动；③ 曹操长髯随喘息微微起伏。

## 排除项

- 之后情节：涕泣出门；分香卖履、铜雀台设祭、疑冢七十二；气绝；曹丕即位、曹彰来朝。
- 同回他场：梨树神披发仗剑；伏皇后、董贵人、二皇子、伏完、董承等血污立于愁云；夏侯惇昏倒；
  华佗献议开颅、下狱、《青囊书》；孙权上书；“三马同槽”之梦；刘备哭绝。
- 诸子曹丕、曹彰、曹植、曹熊不在场（曹操气绝后才遣人报丧），不画。
- 造型：曹操白脸等戏曲脸谱、帝王衮冕、龙纹；影视剧宫室与服饰。
