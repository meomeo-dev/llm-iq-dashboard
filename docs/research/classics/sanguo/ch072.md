# 《三国演义》第72回 诸葛亮智取汉中　曹阿瞒兵退斜谷

底本：<https://zh.wikisource.org/wiki/三國演義/第072回>；读取日期：2026-10-19。

## 情节要点

1. 徐晃渡汉水败于黄忠、赵云，王平投赵云；诸葛亮令赵云夜间鼓角惊扰，曹操三夜惊疑退三十里；刘备背水结营、弃马匹军器诱敌，曹操疑而收军，魏延、张飞先夺南郑。
2. 曹操退守阳平关；许褚醉后护粮，被张飞一矛刺中肩膀；刘备四门放火擂鼓，曹操弃关；曹彰赶到助战，又被马超、吴兰所阻。
3. 曹操屯斜谷界口，进退两难；庖官进鸡汤，碗中见鸡肋，夏侯惇入帐请夜间口号，曹操说“鸡肋”；杨修令军士收拾行装，曹操以惑乱军心为由斩杨修。
4. 追叙杨修数犯曹操之忌：门上添“活”字、“一合酥”、梦中杀人、替曹植作答教。
5. 次日魏延射中曹操人中，折门牙两个；曹操厚葬杨修，下令班师，庞德断后。

## 选定场面

斜谷界口曹军中军帐内的夜里：曹操低头看汤碗里的鸡肋，沉吟不语；夏侯惇刚掀帐入内，躬身禀请夜间口号，曹操
尚未开口。入画理由：全回“鸡肋”典故的起点，碗、人、神情即可表达；杨修被斩是其后果且涉杀戮，不画。具名限曹操、
夏侯惇二人。三处依据：

- 「适庖官进鸡汤。」
- 「操见碗中有鸡肋，因而有感于怀。」
- 「正沉吟间，夏侯惇入帐，禀请夜间口号。」

先后核对：随后才有“操随口曰：鸡肋！鸡肋！”、杨修令军士收拾行装、夏侯惇也收拾；当夜曹操心乱，“手提钢斧，
绕寨私行”，撞见军士整理行装，才召杨修并下令斩之。以上皆晚于所选瞬间。庖官是否仍在帐中未写，可不画。

## 器物与环境

- 地点：斜谷界口曹军大寨中军帐内；帐外营寨与巡逻军士，山谷狭长（斜谷为褒斜道北口一带）。
- 时令：夜（“夜间口号”）；季节、天气未写，兜底：不写季节景物，史载曹操三月出斜谷、五月还长安。
- 器物：矮案、汤碗（材质未写，兜底：朴素陶碗或漆碗，不用青花瓷）、碗中一段带少许肉的肋骨（毛本称“食之无肉，弃之有味”）、
  铜灯、帷帐、席或榻（汉代席地跪坐，不画高背椅；胡床东汉末才传入，可作兜底坐具）；军中夜间击刁斗巡更，帐外可闻，不必画出。
- 现实中会动的：① 灯火摇曳与汤碗热气升腾；② 夏侯惇掀入的帐帘与被夜风鼓动的帐幕；③ 帐外营火火星、旗角。

## 排除项

- 杨修及其被斩一概不画；钢斧、刀斧手、辕门悬首、曹操绕寨私行皆在其后。
- 次日魏延射中曹操、折门牙，以及曹彰、魏延、马超、庞德，均不入画；不画战场与拔剑。
- 史载“鸡肋”出自裴注引《九州春秋》，杨修只是据此推断撤军；杨修被杀的史载罪名是泄露言教、交结诸侯，勿把演义因果搬进画面。
- 戏曲白脸曹操、影视造型不用；夏侯惇黑眼罩是后世造型；不画整只鸡、鸡腿与现代砂锅。
