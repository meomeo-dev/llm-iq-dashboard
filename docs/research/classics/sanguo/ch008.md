# 《三国演义》第8回 王司徒巧使连环计　董太师大闹凤仪亭

底本：<https://zh.wikisource.org/wiki/三國演義/第008回>；读取日期：2026-10-19。

## 情节要点

1. 孙坚已死，董卓自号尚父，建郿坞；席上杀降卒、斩张温。王允回府，月夜在后园垂泪。
2. 王允撞见歌伎貂蝉长叹，说出连环计：先许嫁吕布，再献董卓，使父子反目。
3. 王允先宴吕布并许婚，再宴董卓，貂蝉帘外起舞，当晚被送入相府；吕布路上质问，被王允以“太师亲取”搪塞。
4. 貂蝉在相府借窗影、帘内眼神、床后指心撩拨吕布，董卓起疑，逐吕布出堂。
5. 吕布趁董卓上朝提戟入府，在凤仪亭与貂蝉相会；董卓回府撞见，抢戟追赶，掷戟刺布不中，出园门撞倒在地。

## 选定场面

凤仪亭董卓抢戟追赶：吕布见董卓大喝，回身便走，画戟已被抢去；貂蝉立在亭畔曲栏旁。具名三人，
一追一逃一立；回目后半所指即此事。停在董卓挺戟追赶、尚未掷出之前，无血腥，掷戟不中是下一瞬。
三处依据：

- 「正见吕布和貂蝉在凤仪亭下共语，画戟倚在一边」
- 「卓抢了画戟，挺着赶来」
- 「吕布走得快，卓肥胖赶不上」

## 器物与环境

- 地点：董卓相府后园，凤仪亭下有曲栏，近荷花池；貂蝉“分花拂柳而来”，园内有花有柳。
- 时令天气：本回未写，白昼（董卓刚在朝）；“荷花池”“看花”只表明有花有池，勿据此定季节。
- 器物：吕布的画戟（第3回称方天画戟）；吕布的马系在府前，不入园，赤兔马第3回由董卓所赠。
- 现实中会动的：① 荷花池水面的波纹与荷叶；② 垂柳枝条与落花随风；③ 董卓袍袖与貂蝉衣带随奔走飘动。

## 排除项

- 本回无“貂蝉拜月”：原文只写王允月夜见貂蝉在牡丹亭畔“长吁短叹”，全回无“拜月”“焚香”。“闭月”是后世传说。
- 连环计中，宴吕布、帘外起舞、送入相府、凤仪亭都在本回；刺臂出血为誓、李肃假诏、北掖门诛卓在第9回。
- 王允借七星宝刀给曹操在第4回，与本回无关；凤仪亭一场王允不在场。
- 掷戟：原文是“掷戟刺布，布打戟落地”，园门外撞倒董卓的是李儒（第9回揭晓）；京剧《凤仪亭》（《梳妆掷戟》）的次序与行头不取，不用戏曲头面。
- 画戟按汉戟画长柄带枝；方天戟形制晚至宋代，不加游戏式夸张尖刺、火焰纹。
- 貂蝉与吕布此处是互诉衷情、相拥，原文没有轻薄动作；董卓不画拔剑，不画血。
