# 《三国演义》第33回 曹丕乘乱纳甄氏　郭嘉遗计定辽东

底本：<https://zh.wikisource.org/wiki/三國演義/第033回>；读取日期：2026-10-19。

## 情节要点

1. 曹丕入袁府纳甄氏；曹操入冀州，许攸呼“阿瞒”，后被许褚拔剑所杀；曹操祭袁绍墓，免河北当年租赋。
2. 曹操破袁谭于南皮，袁谭死于曹洪刀下，王修哭谭首获赦；高干败死，袁熙、袁尚奔乌桓。
3. 曹操听郭嘉“兵贵神速”之言北征乌桓，郭嘉病于车中，留易州；田畴引路，白狼山张辽斩蹋顿。
4. 回易州，郭嘉已死数日；曹操大哭致祭，取其遗书，众人不知其意；数日后公孙康送二袁首级至。
5. 曹操示遗书，众官叹服；回冀州宿城东角楼，见地下金光（下回接续）。

## 选定场面

易州公廨，郭嘉灵前。曹操祭罢大哭，郭嘉身边的人捧上他临终亲笔封好的书信，曹操拆开细看，点头
嗟叹，堂中诸人不解其意。画面集中在一纸书与曹操的神情上，没有兵戈；不画遗体与开棺，灵柩可只
现一角或以帷幔遮去。具名限曹操一人，呈书者与堂下官佐作无名群像。三处依据：

- 「丞相若从书中所言，辽东事定矣」
- 「操拆书视之，点头嗟叹」
- 「诸人皆不知其意」

## 器物与环境

- 地点：易州公廨（官署厅堂）。“易州”是隋开皇后的地名，东汉末此地属涿郡故安一带，地名为演义所用，
  画面不必标地名。
- 时令：本回只写回军途中“天气寒且旱”，到易州后未写；兜底：室内为主，冷色调，不画雪。
- 器物：灵前陈设取汉式：席地、低矮几案、灯盏或烛；书信本回称“书”，东汉末简牍与纸并用，私人书信
  已用纸，兜底：折叠或卷起的纸书，封口已拆；题面不要求可辨文字。
- 现实中会动的：① 灯火焰摇曳；② 堂内帷幔、素幡随风微摆；③ 书信纸边微颤，曹操长髯与衣袖轻动。

## 排除项

- 夏侯惇次日请兵征辽东、公孙康伏刀斧手杀二袁并送首、曹操当众出示遗书：均在其后，不画，书中内容不写出。
- 曹丕纳甄氏、许攸被杀、崔琰受聘、王修哭谭首、南皮之战、白狼山斩蹋顿、冀州角楼金光：他段，不混入。
- 不画郭嘉遗体、开棺与血；不画纸钱、挽联等后世灵堂陈设，不画现代信封。
- 不用戏曲脸谱与影视造型，曹操不画白脸；易州与公孙康的地名、杀人场面一律不入画。
