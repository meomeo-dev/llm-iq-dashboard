# 《三国演义》第65回 马超大战葭萌关　刘备自领益州牧

底本：<https://zh.wikisource.org/wiki/三國演義/第065回>；读取日期：2026-10-19。

## 情节要点

1. 马超受张鲁二万兵攻葭萌关；孔明用黄忠诈败，擒李严，李严、费观相继降。
2. 孔明激张飞为先锋，魏延先行中箭，张飞下关救之；次日关下，刘备见马超“狮盔兽带，银甲白袍”，叹“锦马超”。
3. 张飞、马超日间两度各战百余合；天晚，张飞要夜战，两军点起千百火把；二十余合后马超诈败，掣铜锤打张飞，张飞闪过并回射。
4. 孔明遣孙乾买通杨松，杨松谗马超，李恢说降，马超杀杨柏上关降刘备；赵云斩刘晙、马汉。
5. 马超城下劝降，刘璋出降，刘备入成都自领益州牧；关羽欲入川比武，孔明作书劝止；孙权议索荆州。

## 选定场面

葭萌关前，天色已晚：张飞日间与马超战百余合两回不分胜负，刘备劝退，张飞不肯，喊“可多点火把，安排夜战”；
两军点起千百火把，列于阵前两侧，“照耀如白日”；张飞、马超各换了马，两骑对冲，二枪并举，战在阵前。入画理由：
回目“大战葭萌关”最具辨识度的一景，火光与枪影足以表现夜战，不必画铜锤暗袭与回射。具名张飞、马超，刘备可在阵前作小像。
二十余合后马超诈败、掣铜锤、张飞闪过并回射均在其后，不同幅。三处依据：

- 「飞曰：『可多点火把，安排夜战！』」
- 「张飞性起，向玄德换了坐下马，抢出阵来」
- 「两军吶喊，点起千百火把，照耀如白日。」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张飞 | 豹头环眼，燕颔虎须（第1、63回）；夜战时“不用头盔，只裹包巾上马”（日间第二次出阵起，原文未再写戴回），头裹包巾，色未写，兜底：深色巾；兵器本回称“枪”，按丈八矛画（第1回“丈八蛇矛”、第63回“丈八矛”）；坐骑是向刘备换来的“坐下马”，毛色未写；铠甲未写，兜底：铁甲 | 第65回；第1、63回 |
| 马超 | 面如傅粉，唇若抹朱，腰细膀宽，声雄力猛（第58回）；本回“狮盔兽带，银甲白袍”，戴狮盔（狮首造型，据解释），手执长枪；“亦换了马”，毛色未写，不强加白马；铜锤此刻未出手 | 第58、65回 |
| 刘备（小像） | 两耳垂肩，面如冠玉（第1回）；日间已“披挂下关，直至阵前”，此刻立阵前观战，披甲 | 第1、65回 |

先后核对：日间战百余合两回→天晚，刘备劝退→张飞“可多点火把”→马超换马、张飞换刘备的马→两军点火把→二十余合→马超诈败掣铜锤→
张飞闪过、回射→刘备“收兵歇息”。所选瞬间在二十合内。

## 器物与环境

- 地点：葭萌关（本回作“葭明关”）关下阵前；关上有门旗；关在嘉陵江与白龙江交汇处，三面环山（远景，兜底）。
- 时令：日暮至夜，季节未写，不强加；火光照亮两阵，远处关城与山色偏暗。
- 器物：火把（木杆一端缚易燃物浸油脂；汉代烛以苇为芯、布缠、灌饴蜜，据此火把画成木杆裹缠物燃烧即可）、枪、盔与包巾。
- 现实中会动的：① 火把火焰与火星，使人影忽明忽暗；② 双方旗幡、马鬃、张飞虎须与马超白袍披风；③ 马蹄扬起的尘土。

## 排除项

- 张飞戴盔（夜战无盔）；京剧张飞黑十字门蝴蝶脸，戏曲靠旗与雉鸡翎；凤翅盔。
- 铜锤、回射、孙乾、杨松、李恢、成都受降，均在此刻之后；黄忠、赵云、孔明不入画。
- 双镫：汉末以高桥鞍为主，单镫最早见于三国东吴墓、仅作上马辅助，不画现代式马镫；“虎头湛金枪”为后世枪名。
- 昼战场景：日间第一、二战不画，只取夜战。
