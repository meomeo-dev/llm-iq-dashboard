# 《三国演义》第117回 邓士载偷度阴平　诸葛瞻战死绵竹

底本：<https://zh.wikisource.org/wiki/三國演義/第117回>；读取日期：2026-10-19。

## 情节要点

1. 姜维退入剑阁，与董厥合守，杀退诸葛绪；钟会用囚车押送诸葛绪、收其兵；邓艾向钟会献计
   从阴平小路出德阳亭取成都，钟会笑其庸才，邓艾当夜拔寨，离剑阁七百里下寨。
2. 邓艾选兵三万，各带干粮绳索，令邓忠率五千精兵不穿衣甲、执斧凿开山造桥；十月自阴平进兵，
   二十余日行七百余里，沿途下寨，到摩天岭时只剩二千人马。
3. 摩天岭西背峻壁巅崖无法开凿，邓艾先令抛下军器，取毡裹身先滚下，副将有毡衫者裹身滚下，
   无毡衫者以绳束腰、攀木挂树，魚貫而进；过岭见武侯石碣。
4. 邓艾率二千余人倍道抢江油，马邈降、其妻李氏自缢；破涪城后，诸葛瞻率七万出成都，子诸葛尚
   为先锋；绵竹之战，诸葛瞻拒降书，中伏自刎，诸葛尚等战死（不入画）。

## 选定场面

摩天岭上邓艾裹毡先滚下：军器已抛下山，邓艾已把毡裹在身上，沿西背陡坡滚下；邓忠与二千军士
仍在崖顶，副将尚未动身。具名邓艾，邓忠为崖顶小像。三处依据：

- 「前至一嶺，名摩天嶺。馬不堪行，艾步行上嶺」
- 「艾令先將軍器攛將下去。」
- 「艾取氈自裹其身，先滾下去。」

取此瞬间：它是回目上联“偷度陰平”的转折，一身毡筒、一面绝壁，构图单纯，无死伤。

先后核对：邓忠与开路军士哭泣（前）→艾言“不入虎穴”、众应→令先抛军器→艾裹毡先滚下（此刻）→
副将有毡衫者裹身滚下、无毡衫者束绳攀木（后）→艾、忠并二千军渡岭，见石碣（后）。后三段不画。

## 器物与环境

- 地点：阴平小路上的摩天岭，西背为峻壁巅崖，不能开凿；岭上无人烟，原文称“巔崖峻谷之中”“皆是無人之地”。
  今摩天岭在甘肃文县与四川青川县交界，北坡较缓、南面峭壁，邓艾是否经此仅见传说（据摘要）。
- 时令天气：十月自阴平进兵、行二十余日，约十月末至十一月初；天气未写，不画雪、雨。
- 器物：擀制毛毡（汉代由北方传入中原，据摘要）、绳索、斧、凿；先抛下山的军器散落坡底。
- 现实中会动的：① 碎石与尘土顺坡滚落；② 云雾缓缓飘过谷底；③ 绳索、树枝与衣角随山风摆动。
  毡筒的滚动只取原位小幅转动，不做整体平移。

## 排除项

- 副将裹毡或攀木下岭、二千军渡岭、武侯石碣（均在后）；邓忠与军士哭泣、令艾“不入虎穴”之言（前）。
- 江油马邈夫妇、涪城、绵竹之战：诸葛瞻、诸葛尚战死不画；四轮车上木刻孔明像是同回另一场面。
- 不画战马，不画交战；不画邓艾口吃台词，不画影视邓艾披大氅、持长枪的造型。
- 史实：《邓艾传》作“艾以氈自裹，推轉而下”，将士“皆攀木緣崖，魚貫而進”，不写副将用毡；
  摩天岭与史书路线是否吻合存疑。
