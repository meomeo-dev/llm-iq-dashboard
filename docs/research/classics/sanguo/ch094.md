# 《三国演义》第94回 诸葛亮乘雪破羌兵　司马懿克日擒孟达

底本：<https://zh.wikisource.org/wiki/三國演義/第094回>；读取日期：2026-10-19。

## 情节要点

1. 郭淮献计向西羌求救，羌王遣雅丹丞相、越吉元帅率十五万羌兵，另有“铁车兵”，直扣西平关。
2. 关兴、张苞、马岱迎战，铁车首尾相连如城，关兴被围，越吉追击，关公显圣救之（此事不入画）。
3. 孔明见天色“彤云密布，朔风紧急”，令姜维诱敌、关张设伏；十二月终大雪，羌兵追入雪地，坑堑忽陷，铁车自相践踏，
   越吉被斩，雅丹被擒，孔明礼送雅丹与羌兵回国。
4. 魏延、赵云斩曹遵、朱赞；曹叡经钟繇保举，复用司马懿。
5. 孟达欲反，孔明修书提醒；司马懿一日行两日之路，申耽、申仪内应，孟达被杀；司马懿觐见曹叡，荐张郃为先锋。

## 选定场面

马岱寨外雪原：羌军追赶姜维的诱兵，雪面下的坑堑忽然塌陷，前列骡马与铁车失足前倾，后面的铁车仍在冲来、一时收不住；
越吉、雅丹在队中催兵，刚觉出不对；远处姜维的人马在雪地里退走。入画理由：“乘雪破羌兵”的转折点，雪、铁车、陷坑
三项原文同现，不需画斩杀；只画塌陷与车马倾斜，不画坠坑后的死伤。具名越吉、雅丹、姜维。三处依据：

- 「山路被雪漫盖，一望平坦。」
- 「忽然一声响，如山崩地陷，羌兵俱落于坑堑之中；」
- 「背后铁车正行得紧溜，急难收止」

先后核对：孔明令姜维诱敌、孔明携琴入寨后转入林中（空寨）→羌兵追过山口，见蜀兵在雪地奔走→越吉怒追、雅丹催兵→
一声响，坑堑塌陷（此刻，孔明已不在场）→张苞、关兴两军冲出，万弩齐发→越吉被斩、雅丹被擒（后）。

## 器物与环境

- 地点：马岱寨外的山路与山口（羌兵直扣西平关，孔明“亲自来到马岱寨中歇定”，破羌后才“投祁山大寨”），具体地名未写；两侧山坡，山路被雪盖平。
- 时令天气：“十二月终，果然天降大雪”，此前“朔风紧急”；此刻仍在飘雪与否未写，兜底：雪花稀落，北风。天水一带冬季
  气温在冰点上下，降雪积雪约数厘米（现代气象，据摘要），雪不画齐腰深。
- 器物：铁车、驼与骡马、坑堑。塌陷范围“如山崩地陷”，坑内有无木桩未写，兜底：雪面成片裂陷，露出黄土坑壁，不画尖桩。
- 现实中会动的：① 飘落的雪花与被风卷起的雪粉；② 骆驼骡马呼出的白气、摆动的鬃尾，转动的车轮；③ 塌陷边缘簌簌滑落的
  雪块与朔风中的旌旗。

## 排除项

- 关公显圣（绿袍金铠、赤兔，云雾中）；孔明空寨鼓琴（与第95回空城计重复，不入画）；孔明本人此刻不在场。
- 越吉被关兴砍死、雅丹被马岱活捉、羌兵坠坑后的死伤与自相践踏、万弩齐发。
- 魏延斩曹遵、赵云刺朱赞，孟达、司马懿、徐晃等他场。
- 后世造型：重甲具装骑兵、现代羌族羊皮褂与包头帕、毡帐、西式战车。
- 彻里吉、雅丹、越吉与铁车兵皆为演义虚构（据摘要），不据史书补充。
