# 《三国演义》第6回 焚金阙董卓行凶　匿玉玺孙坚背约

底本：<https://zh.wikisource.org/wiki/三國演義/第006回>；读取日期：2026-10-19。

## 情节要点

1. 孙坚拒董卓结亲；董卓迁都长安，抄没洛阳富户，驱民西行，焚宫庙、发陵寝。
2. 孙坚入洛阳扑灭宫火，设帐于建章殿基；曹操追董卓，在荥阳兵败，曹洪负操渡河。
3. 夜里孙坚按剑露坐，军士指殿南井中有五色豪光；下井捞起宫装妇人尸首，项下锦囊内有朱红小匣，匣中是玉玺。
4. 程普辨出是传国玺，劝孙坚回江东；军士告密，袁绍索玺，孙坚对天发誓而去，袁绍写信令刘表截击。
5. 孙坚在荆州界被刘表、蒯越、蔡瑁围困（回末）。

## 选定场面

取回目“匿玉玺”的前半，也是拾玺一刻：夜里孙坚在建章殿基旁的井边，取开军士从井中捞出的锦囊，
启开金锁朱红小匣，见到玉玺；程普走近辨认。具名人物为孙坚、程普两个，另有举火把的军士群像。
同时捞起的宫装妇人尸首不画。“五色豪光”是下井之前的事，原文未写取出后是否仍在，不画。三处依据：

- 「是夜星日交辉，乃按剑露坐，仰观天文」
- 「内有朱红小匣，用金锁锁着」
- 「方圆四寸。上镌五龙交纽；傍缺一角，以黄金镶之」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙坚 | 吴郡富春人，广额阔面，虎体熊腰（第2回）；夜里“按剑露坐”，佩剑。披挂本回未写；第5回他披烂银铠、裹赤帻，但赤帻已给祖茂并被华雄取走，本回不再戴；兜底：银色铠甲，头戴盔或裹巾 | 露坐段；第2、5回 |
| 程普 | 右北平土垠人，字德谋，使铁脊蛇矛（第5回）；本回在孙坚身侧辨认玉玺。外貌衣冠未写，兜底：披甲武将，蛇矛立在身侧或不持 | 问程普段；第5回 |
| 军士 | “点起火把，下井打捞”；衣着未写，兜底：寻常甲士，头裹巾，群像 | 打捞段 |
| 玉玺与匣 | 锦囊内朱红小匣，金锁；玉玺方圆四寸（汉尺约9厘米见方），上镌五龙交纽，旁缺一角以黄金镶补，篆文八字“受命于天，既寿永昌”；匣的尺寸未写，兜底：手掌大小的朱漆小匣，锁已开 | 取匣段 |

## 器物与环境

- 地点：董卓焚毁后的洛阳，孙坚“设帐于建章殿基上”，令军士“扫除宫殿瓦砾”；殿南有井。画面：残墙断柱、
  瓦砾与一口井；火已被孙坚“救灭”，只留余烬。
- 时令天气：夜，星光，“紫微垣中白气漫漫”（紫微垣在北天极一带，写成北方夜空一片白气，不写在头顶或殿南）；季节本回未写。
- 火把：汉代火把用束苇等制成（“束苣”），画成缠束苇秆的火把，不画手电或蜡烛。
- 现实中会动的：① 火把的火焰、火星与青烟；② 北方夜空缓缓流动的白气与闪烁的星光；③ 孙坚披风衣带与军士衣角被夜风吹动。

## 排除项

- 妇人尸首（项下带锦囊）与下井打捞的过程，不入画面。
- 史书出入：《吴书》载井在洛阳城南甄官井，“旦有五色气”，是清晨而非夜里，无尸首、锦囊、朱匣；建章宫在西汉长安，
  原文却置于洛阳。题面按演义写“建章殿旧基”。
- 玉玺形制按演义“五龙交纽”；螭虎钮之说不用。玉玺不画光芒、龙形显灵；篆文不要求画出可辨认的字。
- 程普之后的情节（劝回江东、军士告密、袁绍索玺、对天发誓、刘表截击）与曹操荥阳兵败、曹洪救主，不入画面。
- 孙坚此时无赤帻；花鬃马、古锭刀是第5回物件，不用。
