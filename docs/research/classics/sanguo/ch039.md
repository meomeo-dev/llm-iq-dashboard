# 《三国演义》第39回 荆州城公子三求计　博望坡军师初用兵

底本：<https://zh.wikisource.org/wiki/三國演義/第039回>；读取日期：2026-10-19。

## 情节要点

1. 孙权破夏口，甘宁背射黄祖；凌统在庆功宴上拔剑欲报父仇，孙权遣甘宁镇夏口。
2. 刘表请刘备到荆州，欲让荆州，刘备不受；刘琦三次求计，孔明在撤去楼梯的小楼上教以申生、重耳之事，刘琦请守江夏。
3. 曹操命夏侯惇率十万兵、于禁、李典等为副将进逼博望；关、张不服孔明，孔明借剑印，分派关羽、张飞、关平、刘封埋伏，令赵云诈败。
4. 夏侯惇追至博望坡窄路，两旁尽是芦苇，于禁、李典劝防火攻，话未完火已四起；曹军自相践踏，关羽、张飞烧粮草、截杀。
5. 孔明乘小车收军，关、张下马拜伏；孔明又言曹操必亲统大军，下回献计。

## 选定场面

博望坡窄路，夜，浓云无月，狂风助火：夏侯惇正追敌，背后火光骤起，两侧芦苇接连着火；于禁自后军驰至陈说火攻，李典
勒马大叫“后军慢行”，夏侯惇猛然勒回马头。入画理由：火攻是孔明“初用兵”的标志，也是本回最具视觉冲击的瞬间；
同回的刘琦上楼求计是室内对话，视觉较弱。取火起一刻，不画厮杀与死伤。具名限夏侯惇、于禁、李典三人。三处依据：

- 「浓云密布，又无月色；昼风既起，夜风愈大。」
- 「南道路狭，山川相逼，树木丛杂，倘彼用火攻，奈何？」
- 「早望见一派火光烧着；随后两边芦苇亦着。」

## 器物与环境

- 地点：博望坡，“南道路狭，山川相逼”，两旁芦苇，树木丛杂；后有粮车（“其余尽护粮车而行”）。博望在今河南方城县博望镇一带。
- 时令天气：秋（原文“时当秋月，商飙徐起”），傍晚转夜，约初更；浓云无月；风向本回未写，火焰向一侧倾斜即可。
- 器物：芦苇、引火之物（关平、刘封“预备引火之物”）、辎重粮车、曹军旗号；汉末无火炮，原文“一声炮响”不据以画炮。
- 现实中会动的：① 芦苇丛中火舌摇曳、火星飞腾；② 浓烟随风翻卷；③ 战马惊跳、旗帜与披风被风吹动。

## 排除项

- 孔明本回不在阵前：他在新野县中，战后乘“小车”（不是四轮车）；不画羽扇（毛本首见第52回）。
- 关羽豫山、张飞安林、赵云诈败、刘备后援不入画；张飞枪刺夏侯兰、“尸横遍野，血流成河”不画。
- 刘琦上楼（同回另一场面）、甘宁射黄祖不混入；不画火药爆炸、大炮与孔明灯；不画夏侯惇已被烧伤。
