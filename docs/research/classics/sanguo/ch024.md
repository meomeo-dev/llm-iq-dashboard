# 《三国演义》第24回 国贼行凶杀贵妃　皇叔败走投袁绍

底本：<https://zh.wikisource.org/wiki/三國演義/第024回>；读取日期：2026-10-19。

## 情节要点

1. 曹操欲废献帝，程昱劝止；董承等五人及全家七百余口被押往各门处斩。
2. 曹操带剑入宫，勒死怀孕五月的董贵妃，并以曹洪统御林军防察。
3. 曹操起二十万大军分五路东征；刘备遣孙乾求袁绍，袁绍因幼子生疮不肯发兵，田丰顿足长叹。
4. 行军中东南风吹折牙旗，荀彧、毛玠断定当夜刘备劫寨；曹操分九队，只留一队虚扎营寨，余八面埋伏。
5. 张飞、刘备分两路劫寨，中计大败，失小沛；张飞逃往芒砀山，刘备匹马投青州袁谭，转至平原，袁绍出邺郡三十里相迎。

## 选定场面

张飞劫寨中计的一刻：夜里月色微明，张飞带轻骑突入曹营，只见寨中零落、没有多少人马，四边火光骤起；
他刚勒住马、横矛，认出中计，尚未突围。具名人物只有张飞，曹军留守兵作群像，火光与月色是画面主体，
没有杀戮。备选：曹操行军途中牙旗被风吹折、荀彧占风，也无杀戮，可作他用。三处依据：

- 「是夜月色微明」
- 「领轻骑在前，突入操寨，但见零零落落，无多人马」
- 「四边火光大起，喊声齐举」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张飞 | 身长八尺，豹头环眼，燕颔虎须，声若巨雷，势如奔马（第1回）；肤色原文未写；兵器丈八点钢矛（第1回造，本回称“枪”）；甲袍本回未写，兜底：战袍铠甲，不强加黑甲；坐骑未写，不用后世马名 | 第1回；劫寨段 |
| 曹军留守兵 | 数量很少、零落分布的守寨兵；八路伏兵（张辽、许褚等）尚在寨外，不入画 | “零零落落，无多人马” |

张飞所领兵原是曹操旧军，劫寨时尚随他入寨；曹操、刘备都不在这一画面中。

## 器物与环境

- 地点：小沛城外曹军虚扎的营寨（“向前虚扎营寨”）；寨内形制未写，兜底：寨门、栅栏与稀疏帐幕，不画整齐大营。
- 时令天气：夜，月色微明；季节本回未写（前回末为“建安五年正月”），不强加雪、花、落叶。
  白天东南风吹折牙旗，夜间风向未写。
- 器物：丈八点钢矛、营帐、残存旗旛、火把与大火；牙旗（青红二色，主将旗）被风折在白天，不属本场面。
- 现实中会动的：① 四边蹿起的火舌、火星与浓烟；② 张飞战袍、马鬃与营中旗旛被热风吹动；③ 受惊战马嘶鸣扬蹄。

## 排除项

- 张飞不画戏曲黑脸，不用乌骓、乌云踏雪等后世马名；肤色按“未写”处理，不强加。
- 八路伏兵杀出、张飞杀血路突围、数十骑奔芒砀山是下一刻；刘备被夏侯惇、夏侯渊截击、小沛火起属同夜另一路。
- 董贵妃被勒死、曹操带剑入宫是杀戮，不画；刘备投袁绍、袁绍抱病是别的场面，不混入。
- 荀彧占风、牙旗折属白天行军，不画在夜营里；曹操不在此营。
