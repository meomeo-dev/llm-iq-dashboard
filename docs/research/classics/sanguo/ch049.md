# 《三国演义》第49回 七星坛诸葛祭风　三江口周瑜纵火

底本：<https://zh.wikisource.org/wiki/三國演義/第049回>；读取日期：2026-10-19。

## 情节要点

1. 周瑜望北岸急怒吐血；孔明密书“欲破曹公，宜用火攻；万事俱备，只欠东风”，答应在南屏山筑七星坛借风。
2. 坛用东南方赤土筑成，三层共九尺：下层二十八宿旗，二层黄旗六十四面，上层四人侍立；十一月二十日孔明登坛，白日三上三下不见风。
3. 近三更风声大作，东南风起；周瑜惊惧，遣丁奉、徐盛去杀孔明，坛上已空，孔明已乘船由赵云接走。
4. 孔明回夏口分派伏兵，关羽立军令状守华容道；黄盖火船乘风冲入曹军水寨，黄盖被张辽射落水（下回接续）。

## 选定场面

三更风起的一刻，南屏山七星坛最上一层：孔明披发赤足、身披道衣，仰天暗祝；各层旗帜、上层侍者手中的鸡羽竿与七星带
一齐被风扯向同一侧。入画理由：坛的层数、旗色、风信器原文数据齐全，“风起”靠旗向即可表现，无打斗；具名人物仅孔明。
原文未直写风起时孔明在坛上；丁奉到时守坛将士答“恰才下坛去了”，据此取他刚下坛之前仍在坛上的一刻。三处依据：

- 「身披道衣，跣足散发，来到坛前」
- 「将近三更时分，忽听风声响，旗旛转动」
- 「旗脚竟飘西北，霎时间东南风大起」

后两句记周瑜在自己帐前所见；坛上旗向取同一风向，原文只写丁奉到时守坛将士“当风而立”。

## 器物与环境

- 地点：南屏山，东南方赤土筑的矮阔土台，方圆二十四丈，三层每层仅高三尺，是土台而非高塔；坛色为赤褐土色。
- 层次：下层四方各七面共二十八面星宿旗（东青、北皂、西白、南红）；二层黄旗六十四面（六十四卦，分八位）；上层四人。
- 时令天气：隆冬十一月二十日夜；起风前“天色清明，微风不动”，三更起东南风（旗向西北）。
- 现实中会动的：① 各层旗帜与仪仗旌旗翻卷；② 鸡羽葆与七星带被风扯平；③ 香炉香烟、孔明散发与道衣下摆。

## 排除项

- 仗剑、踏罡步斗、八卦衣、京剧黑蓬头与法衣；羽扇纶巾鹤氅（那是第38、52回的造型）。
- 把坛画成高塔或寺庙；把二层六十四面黄旗当作星宿旗；香炉“烈火”；龙虎显形、雷电等神怪渲染。
- 周瑜吐血与帐中议事、丁奉徐盛追杀、赵云接船、黄盖火船与烧曹营，均在其前或其后，不混入。

## 现有题面核对

旧题面：`sanguo-049` / `sanguo-anim-049`（`src/core/classics/sanguo.ts`）。场面沿用，改下列细节：

- 有据：冬夜；南屏山；三层坛；青、皂（黑）、白、红四色星宿旗与黄色卦旗；披发、赤足、道袍、仰天祝；东南风起、旗向西北。
- 须改：“三层高坛”易画成高塔，原文每层仅高三尺；“坛边插满”应分层写明（下层二十八面四色、二层六十四面黄旗、上层四人）；
  “香炉前”的香炉由上层一人捧着；方位用画面左右（“旗帜一齐飘向画面左侧”），不写“西北”；道袍颜色未写。
- 无据：“山下江面连成一片的战船”原文无此景，水寨在周瑜、曹操处，可删或作极远小点。
- 动态旧稿不符：“仗剑”（宝剑在侍者手中）；“六十四面星宿旗”（星宿旗二十八面，六十四面是二层黄旗）；
  “香炉烈火”（原文只“焚香”）；“江面战船连天”无据；“黑发”发色未写。动效改为旗面翻卷、鸡羽葆与七星带飘平、香烟与散发道衣随风。
