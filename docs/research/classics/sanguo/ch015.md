# 《三国演义》第15回 太史慈酣斗小霸王　孙伯符大战严白虎

底本：<https://zh.wikisource.org/wiki/三國演義/第015回>；读取日期：2026-10-19。

## 情节要点

1. 刘备乘雨撤出盱眙，吕布与袁术失信相隙，刘备仍回小沛。
2. 孙策以传国玉玺为质向袁术借兵三千，渡江，得周瑜、张昭、张纮，破牛渚，蒋钦、周泰来投。
3. 神亭岭：孙策率十三骑上岭祭光武庙，太史慈单骑追下，两人交马五十合，下马揪打，夺戟夺盔。
4. 擒太史慈，解缚相待，约日中回，慈如期而至；孙策又大战严白虎，取吴郡、会稽。
5. 周泰宣城救孙权；华佗医治；孙策向袁术索玉玺，袁术不还，欲先伐刘备。

## 选定场面

取神亭岭下两马将交未交的一瞬：太史慈自岭上纵马横枪直冲而下，孙策横枪立马于岭下相待，
身后十二骑摆开。具名人物：孙策、太史慈，另有程普等从骑群像。理由：回目所指的核心对阵，
有地形（岭、岭上光武庙）、双方兵器与从骑，白昼，无血腥。只取交马前，不画下马揪打。
引文三处：

- 「策将十三骑一齐摆开。」
- 「策横枪立马于岭下待之。」
- 「纵马横枪，直取孙策。」

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙策 | 面貌本回未写，《三国志》称「美姿颜，好笑语」。披挂、绰枪、头戴兜鍪（后文被夺）。兜底：青年将领，筒袖铠，面容年轻端正 | 「披挂绰枪上马」；「掣了策头上的兜鍪」 |

## 器物与环境

- 地点：神亭岭，刘繇营在岭南，孙策营在岭北，岭上有汉光武庙。属曲阿一带（东汉曲阿属吴郡，
  今江苏丹阳）；神亭岭无确指现址，不写现代地名。
- 时令：交手时的季节与天气本回未写；战后才写「时近黄昏，风雨暴至」，不提前画风雨。
  兜底：晴好午后。
- 器物：两杆长枪、太史慈背上短戟、孙策兜鍪、战马；岭上光武庙，山林道路。无马镫。
- 现实中会动的：① 两骑冲下岭坡扬起的尘土；② 枪缨、盔缨与战袍下摆；③ 岭上林木随风摆动。

## 排除项

- 下马揪打、夺短戟、夺兜鍪、战袍扯碎，是交手后一幕；《三国志》写孙策刺马夺手戟，与原著
  不同，以原著为准，且本幅不画。
- 「小霸王」得名于后文喝死樊能，此刻孙策尚无此称，题面不写成现成称号。
- 周瑜、张昭、陈武、严白虎、王朗、华佗等后文人物不出场；太史慈阊门射穿敌将左手属后文。
- 铠甲用筒袖铠；不画马镫；不用京剧脸谱、影视盔甲与游戏改造的兵器。
