# 《三国演义》第34回 蔡夫人隔屏听密语　刘皇叔跃马过檀溪

底本：<https://zh.wikisource.org/wiki/三國演義/第034回>；读取日期：2026-10-19。

## 情节要点

1. 曹操在冀州掘得铜雀，建铜雀台；刘备在荆州平江夏张武、陈孙，得张武所骑骏马，转赠刘表。
2. 蒯越相马，称其眼下有泪槽、额边生白点，名的卢，骑则妨主；刘表还马，伊籍在新野路上劝刘备勿乘，刘备不信。
3. 刘备劝刘表勿废长立幼，蔡夫人屏后偷听；刘备如厕见髀肉复生而流泪，酒后失口说“备若有基本”。
4. 蔡瑁诬刘备题反诗，刘表削去；襄阳大会，蔡瑁三面设兵，伊籍暗报，刘备骑的卢走西门。
5. 檀溪拦路，追兵将至，的卢跃过西岸；蔡瑁追至溪东，赵云引兵赶来（下回接续）。

## 选定场面

檀溪边，刘备匹马逃出襄阳西门，溪阻去路，追兵已近。取马身自水中腾起、刘备前倾加鞭大呼的一瞬：
的卢前蹄陷水后猛然涌身而起，凌空飞向对岸，刘备袍摆已被溪水浸湿，水花与浪沫四溅；追兵只在
身后远处现尘头，不具名。具名限刘备一人（的卢是马名）。三处依据：

- 「那檀溪阔数丈，水通襄江，其波甚紧」
- 「玄德乃加鞭大呼曰：的卢，的卢！今日妨吾」
- 「那马忽从水中涌身而起，一跃三丈，飞上西岸」

## 器物与环境

- 地点：襄阳城西门外，檀溪。《水经注》记檀溪水出县西柳子山下，东为鸭湖，“曝则成陆，潦则成湖”。
  本回写溪“阔数丈”，水通襄江，“其波甚紧”；一跃三丈，汉尺约23厘米，约合7米。
- 时令：正文未写季节与天气（附诗写春暮斜阳，是后人诗句，不作叙述依据）；兜底：日间，不强加雪雨。
- 器物：马鞭、溪岸。东汉末高桥鞍已流行，马镫最早实物是西晋302年墓出土的单镫骑俑，三国时通行与否
  无实证，马不画镫。
- 现实中会动的：① 溪水飞溅的水花与涟漪；② 的卢鬃毛、尾毛与刘备袍摆衣带；③ 岸边草叶与远处追兵扬起的
  尘头。

## 排除项

- 的卢来历：本回前段赵云刺落张武、牵马回阵，与檀溪无关，不画赵云与张武；傅玄《乘舆马赋序》另载
  来历（刘备自曹操马厩选得），本题只取演义写法。
- 伊籍后园报信、解马开后园门、门吏拦问、蔡瑁溪边“拈弓取箭”、赵云引三百军赶到：前后事，不画。
- “妨主”只是蒯越、伊籍之说，刘备此刻口中“今日妨吾”是呼马之语；不画龙形，附诗“双龙飞”是比喻。
- 不画马溺水挣扎的惨状，不画刘备出鞘兵器；不套用戏曲、影视的坐骑造型；不画现代马镫与西式马鞍。
