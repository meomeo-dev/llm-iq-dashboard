# 《三国演义》第32回 夺冀州袁尚争锋　决漳河许攸献计

底本：<https://zh.wikisource.org/wiki/三國演義/第032回>；读取日期：2026-10-19。

## 情节要点

1. 袁尚出黎阳战张辽大败；袁绍闻败旧病复发吐血而死，审配、逢纪立袁尚为主，袁谭不服，兄弟相攻。
2. 袁谭遣辛毗向曹操请降，曹操听荀攸之议转攻冀州，以女许袁谭；袁尚、袁熙、高干屡败，退守冀州。
3. 曹操筑土山、掘地道，冯礼降而引三百壮士入突门，被审配以巨石封门尽死；袁尚来救，被击溃后逃往中山。
4. 许攸献“决漳河之水”之计；曹军夜里添十倍军士掘堑，天明广深二丈，漳水灌入城中。
5. 审荣开西门献城，审配被擒，面北就刑；曹丕入袁府拔剑见二妇（下回接续）。

## 选定场面

天刚亮，曹军夜里赶挖的围堑已成，漳河水从堑口涌入，灌向冀州城墙脚下。画面一侧堑岸上，许攸立于
曹操身旁，抬手指水；另一侧城头上，审配前一天还笑堑掘得浅，此刻低头望水。画面以水势为主，没有
战斗与死伤，掘堑的曹军作无名群像。具名限曹操、许攸、审配三人，审配可作城头远景小像。三处依据：

- 「何不决漳河之水以渰之」
- 「审配在城上见操军在城外掘堑，却掘得甚浅」
- 「比及天明，广深二丈，引漳水灌入城中，水深数尺」

## 器物与环境

- 地点：冀州城（即邺，遗址在今河北临漳）外的围堑。堑“周围四十里”，天明时“广深二丈”，汉尺约23厘米，
  二丈合4.6米左右；水深数尺，是漫入城脚的浅水，不是吞城巨浪。城墙取夯土为主，不画明清砖砌城垛。
- 时令：本回未写季节与天气；兜底：拂晓微光，不强加雪雨。夜里发掘留下的火把残火本回未写，可作点缀。
- 器物：铁锸、竹筐、堑边堆起的新土；曹军旗帜；城头守兵的旗号。
- 现实中会动的：① 漳水涌入堑口，水面波纹与白沫向城脚推进；② 堑岸曹军旗帜与曹操长髯、许攸衣袖迎风；
  ③ 残余火把的火焰与升起的烟。

## 排除项

- 土山、地道、冯礼三百壮士死于突门闸下：是前事，且《三国志·武帝纪》记“毁土山、地道，作围堑”，画面不留。
- 审荣开西门、曹兵入城、审配被擒骂辛毗、面北就刑、斩辛毗家属八十余口：后事，不画；城中饿死者不画。
- 本回前段袁尚战张辽、袁谭失势、曹操盔中箭、袁尚大败，均不混入；许攸在下回被许褚所杀，此处不画。
- 辛毗用枪挑袁尚印绶衣服招降属灌城之后，不画；不画漂尸、坍塌城墙、洪水吞城。
- 不用戏曲脸谱与影视铠甲造型，曹操不画白脸。
