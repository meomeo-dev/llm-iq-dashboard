# 《三国演义》第89回 武乡侯四番用计　南蛮王五次遭擒

底本：<https://zh.wikisource.org/wiki/三國演義/第089回>；读取日期：2026-10-19。

## 情节要点

1. 孔明在西洱河伐竹搭桥，营于河北；孟获骑赤毛牛来战，孔明弃寨诱敌，趁风火夹攻，孟获落陷坑被擒（四擒四纵）。
2. 孟获投秃龙洞朵思大王；六月炎天，蜀军先锋王平带兵误饮哑泉，皆不能言。
3. 孔明在马援庙祈祷，得老叟（山神）指引；次日携信香礼物，带王平与哑军入山，访万安溪隐者孟节。
4. 孟节自称孟获之兄，指点安乐泉、薤叶芸香；孔明掘井焚香告天，得甘泉。
5. 杨锋父子在席上擒孟获、孟优、朵思，献孔明（五擒五纵）。

## 选定场面

万安溪畔草庵前：孔明携礼到庄前扣户，小童开门，隐者孟节竹冠草履出迎，发问“来者莫非汉丞相否”，王平与哑军在篱外静候。
入画理由：回目后半的转折，山野清幽，人物少，避开毒泉、病状与战斗，也避开孟节自报身份之后的情节。三处依据：

- 「但见长松大柏，茂竹奇花，环绕一庄；篱落之中，有数间茅屋」
- 「早有一人，竹冠草履，白袍皂绦，碧眼黄发，忻然出曰」
- 「来者莫非汉丞相否？」

先后核对：马援庙祈祷、遇老叟（前一日）→次日备信香礼物，引王平与众哑军入山，行二十余里→见松柏茂竹，到庄前扣户→
小童出，孔明方欲通姓名→隐者早出，问“来者莫非汉丞相否”（此刻）→邀入草堂，童子引哑军到溪边饮水（后）→孟节自报姓名请罪（后）。
此刻哑军还未饮安乐泉，仍不能说话。

## 器物与环境

- 地点：万安溪畔，老叟所指“正西数里山谷，入内行二十里”；一庄环绕长松大柏、茂竹奇花，篱笆内数间茅屋，“馨香喷鼻”。
  庵后的安乐泉、庵前的薤叶芸香是后文才写，此刻不画泉与草。
- 时令：六月炎天（第89回前文）；到达时刻未写（原文“连夜”赶路），兜底：晨间，便于看清松竹。
- 器物：孔明备的信香、礼物；竹冠、草履；茅屋、篱笆。汉代有竹皮冠（又称刘氏冠、长冠），竹质，高七寸广三寸，
  本回“竹冠”未必指此冠，兜底：竹编简冠。
- 现实中会动的：① 松枝竹叶随风摇动；② 万安溪流水；③ 茅屋炊烟与信香的烟缕上升。

## 排除项

- 前：西洱河竹桥、孟获骑赤毛牛、犀皮甲、朱红盔、左牌右刀（四擒）；朵思介绍四毒泉；王平饮哑泉；马援庙与老叟（山神）。
- 后：孟节自报“孟获之兄”、请罪，孔明欲奏立他为王，赠金帛；军士饮安乐泉吐涎、入万安溪沐浴、口含薤叶；
  孔明掘井焚香告天；杨锋擒孟获。均不入画。
- 孟节是演义虚构人物，不画成道士、神仙或山神；山神是前一日的老叟，另有其人；孟节不戴王冠、不穿缨络，不似孟获孟优。
- 孔明车乘：本回写“驷马车”“小车”，没有“四轮车”（该词见于第52、64、93回等，不在本批），此处乘具未写，山径兜底步行，不画车。
- 后世造型不取：影视里的孟节扮相、哑泉的骷髅或荧光毒水渲染；不画任何蜀军吐涎、痛苦倒地的病态。
