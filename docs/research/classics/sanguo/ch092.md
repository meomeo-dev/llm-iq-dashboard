# 《三国演义》第92回 赵子龙力斩五将　诸葛亮智取三城

底本：<https://zh.wikisource.org/wiki/三國演義/第092回>；读取日期：2026-10-19。

## 情节要点

1. 孔明至沔县祭马超墓；魏延献子午谷奇计，孔明以“非万全之计”不用，令赵云进兵。
2. 夏侯楙在长安聚兵，西凉大将韩德引西羌兵八万为先锋，与四子在凤鸣山迎战赵云；赵云匹马单枪连败韩氏诸子，
   次战又刺死韩德，夏侯楙退兵。
3. 夏侯楙用程武计设伏，赵云被围垓心，自辰时杀至酉时；张苞、关兴先后赶到接应，夏侯楙逃入南安城。
4. 孔明乘小车到南安城下，遣人假扮裴绪赚崔谅，魏延诈取安定，王平生擒夏侯楙，南安、安定入手。
5. 天水郡中郎将姜维识破裴绪之诈，向马遵献计（下回接续）。

## 选定场面

凤鸣山前两阵对圆：赵云居中，韩瑶挥刀、韩琼挺方天戟、韩琪抡两口日月刀三面围住，老将一人一枪迎战，神色不乱。
入画理由：“年登七十”的老将出马，正是回目主角；一人对三，构图自成三向合围；取交手之时，不画刺中。具名赵云、
韩瑶、韩琼、韩琪。三处依据：

- 「次子韩瑶见之，纵马挥刀来战。」
- 「三子韩琼，急挺方天戟骤马前来夹攻。」
- 「云在中央独战三将。」

先后核对：韩德出马、四子列两边→赵云单搦韩德，长子韩瑛迎战被刺死→韩瑶、韩琼、韩琪先后围上，赵云居中独战
三将（此刻）→少时韩琪中枪落马→韩琼放箭被拨落，反中一箭落马→韩瑶砍来，赵云弃枪于地、生擒之（后）。韩瑛已死
在先，不入画。

## 器物与环境

- 地点：凤鸣山前，两阵对圆；山名取自演义，未检得确址。兜底：山脚旷地，远处矮山。
- 时令天气：未写；第91回定于春三月丙寅日出师，战事在其后，不画雪与落叶；日间。
- 器物：枪、方天戟、日月刀、弓箭、门旗。东汉末已有高桥鞍，无成熟军用马镫（据摘要），骑者双脚不踏现代式双镫。
- 现实中会动的：① 战马鼻息、鬃尾与蹄下扬起的尘土；② 赵云的盔缨、战袍下摆与枪缨；③ 两阵旌旗、门旗在风中飘动。

## 排除项

- 白马、银枪、白袍：后世评书戏曲造型，演义无；白马属夏侯楙（“坐白马”，在后一场）；“龙胆亮银枪”“涯角枪”。
- 战果：韩瑛刺死、韩琪落马、韩琼中箭、韩瑶被擒、韩德被刺，均在此刻前后，不画尸体与血。
- 韩德（开山大斧）此刻在本阵前，构图取舍不画。
- 他场：夏侯楙（金盔、白马、大砍刀）；赵云被困垓心卸甲而坐；张苞、关兴接应；魏延献计；祭马超；
  孔明乘小车攻南安。
- 韩氏父子为演义虚构（据摘要）。回目“五将”按韩德父子五人（斩四擒一）理解，诗与邓芝却称“四将”，不据数字作画。
