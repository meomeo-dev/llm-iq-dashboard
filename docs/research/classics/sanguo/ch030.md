# 《三国演义》第30回 战官渡本初败绩　劫乌巢孟德烧粮

底本：<https://zh.wikisource.org/wiki/三國演義/第030回>；读取日期：2026-10-19。

## 情节要点

1. 袁绍七十万临官渡，曹操七万迎敌，初战败退；袁军筑土山射箭，曹军造发石车（霹雳车）还击，袁军又掘地道，曹军掘堑拦截。
2. 曹操自八月起守官渡至九月终，粮尽欲退，荀彧来书劝守；徐晃烧韩猛的粮车。
3. 袁绍遣淳于琼守乌巢屯粮；许攸被审配所劾，投奔曹操，献袭乌巢烧粮之计。
4. 曹操亲率五千人，打袁军旗号，束草负薪，人衔枚、马勒口，夜到乌巢，四更举火，淳于琼醉卧被擒。
5. 袁绍分兵救援不成；张郃、高览降曹，袁军大溃，沮授被杀（下回接续）。

## 选定场面

乌巢袁军粮屯外，夜四更将尽，曹操勒马居中，军士把随身束草围着粮屯一圈点起，火焰四起，烟迷太空；
张辽、许褚在前，后队衔枚负草未至。粮屯里的淳于琼尚在醉卧，双方未交刃。取火起的一瞬：夜色与火光的明暗
对比强烈，是官渡之战的转折，且不涉伤亡。具名限曹操、张辽、许褚三人，军士作群像。三处依据：

- 「打着袁军旗号，军士皆束草负薪，人衔枚，马勒口」
- 「操教军士将束草周围举火，众将校鼓噪直入」
- 「一霎时，火焰四起，烟迷太空」

## 器物与环境

- 地点：乌巢，袁绍屯粮之所（今河南延津县僧固乡东史固村一带，旧说在封丘西，确址未证）；
  毛本称“屯上火起”，兜底：营寨篱栅围着成排圆形草顶粮囤与粮包堆垛（汉代“圆曰囷，方曰仓”）。
- 时令：夜，“四更已尽”；前一夜“星光满天”。毛本写曹操守官渡“自八月起，至九月终”，其后才有乌巢；
  正史在十月。季节未明写，兜底：深秋夜，微寒，不画雪。
- 器物：束草（火把由束草点起，原文无火箭、火炮）；袁军旗号，颜色未写；衔枚是横衔口中的小木棍，
  约筷子粗细，两端有带系颈；“马勒口”即约束马口，使其不嘶鸣。
- 现实中会动的：① 粮囤与束草上的火焰向上蹿动、明暗不定；② 浓烟滚滚升起，遮住部分星空；
  ③ 袁军旗号与曹操马鬃被热气流吹动，火星飘落。

## 排除项

- 淳于琼被挠钩拖翻、割去耳鼻手指、纵放回营，眭元进与赵叡被杀，蒋奇被张辽斩，一律不画。
- 许攸夜投曹寨、曹操“跣足出迎”是前一场；徐晃烧韩猛粮车是另一处山谷之火；
  袁军土山、霹雳车、掘子军、沮授观天象均在官渡，不在乌巢，不混入。
- 曹军此刻只“打着袁军旗号”，“尽夺其衣甲旗帜”在后文伪装蒋奇处，不画曹军穿袁军衣甲。
- 不画火药、爆炸、火箭齐发等后世火攻；不用京剧白脸曹操、影视或游戏造型。
