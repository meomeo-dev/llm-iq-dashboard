# 《三国演义》第64回 孔明定计捉张任　杨阜借兵破马超

底本：<https://zh.wikisource.org/wiki/三國演義/第064回>；读取日期：2026-10-19。

## 情节要点

1. 严颜为前部招降沿途关隘；张飞抢先到雒城，救下被张任追赶的刘备；赵云救出被围的张飞，孔明随后抵达。
2. 吴懿被擒而降，说出城东金雁桥；孔明勘察后布置：魏延、黄忠伏芦苇，张飞伏山东小路，赵云伏桥北。
3. 孔明乘四轮车过桥与张任对阵，诱其追过桥；桥拆、芦苇伏兵齐起，张飞活捉张任；张任不降被斩，葬于金雁桥侧。
4. 张翼斩刘璝开城投降，法正劝降书被刘璋撕毁，刘璋遣费观、李严守绵竹，董和献议向张鲁借兵。
5. 马超兵败入羌，冀城杨阜与姜叙、赵昂起兵，夏侯淵来援，马超失妻子，投张鲁；黄权说张鲁，马超请缨。

## 选定场面

金雁桥头两军对阵：孔明引一队“不整不齐”的军马过桥，乘四轮车，纶巾羽扇，两边百余骑簇拥，抬手遥指对面的张任；
张任横枪立马，见军伍不齐，冷笑。桥在孔明车后。入画理由：孔明“示弱诱敌”的核心瞬间，羽扇、纶巾、四轮车一眼可辨，
不必画张任被擒。具名孔明、张任二人，其余作群像。问答与冷笑同在对阵之时，“把枪一招”“弃车上马”在其后。三处依据：

- 「孔明引一队不整不齐军，过金雁桥来，与张任对阵。」
- 「孔明乘四轮车，纶巾羽扇而出，两边百余骑簇拥，摇指张任曰」
- 「张任看见孔明军伍不齐，在马上冷笑曰」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孔明 | 身长八尺，面如冠玉（第38回）；头戴纶巾，手执羽扇（本回“纶巾羽扇”，羽扇首见第52回）；端坐四轮车（第52回“推出一辆四轮车”）；身披鹤氅（第38、52回，本回未写，兜底）；此刻未弃车、未上马 | 第38、52、64回 |
| 张任 | 样貌本回未写，史书与演义均无记载；兜底：壮年武将，铁盔铁甲，不强加须髯；持枪（此刻横持或竖持，尚未“把枪一招”）；骑马，毛色未写，兜底：深色马；神情冷笑 | 第64回“在马上冷笑”“把枪一招” |
| 随行（群像） | 孔明一队“不整不齐”：旗枪歪斜，队列松散；两边骑兵百余簇拥，画六至八骑即可 | 第64回 |

先后核对：过桥对阵→孔明乘车而出、摇指问话（此刻）→张任看出军伍不齐而冷笑→“把枪一招”冲来→孔明弃车上马退走过桥→
张任追过桥→刘备军在左、严颜军在右杀出→桥拆。所选瞬间在“把枪一招”之前。

## 器物与环境

- 地点：雒城之东的金雁桥（“城东这座桥”），桥下为雁江（今鸭子河）；孔明“过桥来”对阵，故桥在孔明车后。桥的形制本回未写，
  兜底：木梁平桥（秦汉桥多为木桥），桥面完整，不画拆断。芦苇伏兵地在“桥南五六里”，对阵处不画芦苇丛。
- 时令：七月二十日起程，到雒城约在七月下旬至八月，初秋（推算）；时辰天气未写，兜底：日间。
- 器物：四轮车（形制未写，明代版画也未精画四轮；兜底：木制小车，不画现代轮椅）、羽扇、旗、枪。
- 现实中会动的：① 雁江水波；② 双方军旗与骑兵缨饰；③ 孔明羽扇的羽毛、纶巾带与衣袖，张任的马鬃马尾。

## 排除项

- 芦苇中魏延长枪刺马、黄忠砍马蹄，张飞活捉张任，赵云伏桥北，拆桥，斩张任，葬金雁桥侧，均在此刻之后。
- 孔明弃车上马（后）；孔明白衣皂绦（第93回骂王朗）；扇面八卦、道士冠；木牛流马。
- 张任落凤坡射死庞统（前回）；京剧张任；杨阜、马超、姜叙诸事为同回另场。
