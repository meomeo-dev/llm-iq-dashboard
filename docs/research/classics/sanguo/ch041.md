# 《三国演义》第41回 刘玄德携民渡江　赵子龙单骑救主

底本：<https://zh.wikisource.org/wiki/三國演義/第041回>；读取日期：2026-10-19。

## 情节要点

1. 关羽放水、张飞会合刘备后同渡白河；曹操填河进兵，遣徐庶招降，徐庶劝刘备速走，誓不为曹设一谋。
2. 刘备弃樊城，十余万军民号泣渡江；襄阳蔡瑁、张允拒之，魏延开城被文聘所阻，刘备改奔江陵，日行十余里。
3. 曹操以五千铁骑一日一夜追及，当阳景山夜宿，四更曹兵杀至；糜芳报“赵云反投曹操”，张飞在长坂桥设疑兵。
4. 赵云寻主母：刺死夏侯恩夺青釭剑，糜夫人交付阿斗后投井，赵云推墙掩井，护阿斗于怀上马；连遇晏明、张郃等拦路，终拔青釭剑杀出。
5. 曹操在景山顶望见，下令生擒；赵云杀透重围，前有钟缙、钟绅（下回接续）。

## 选定场面

天明后的长坂，烧毁人家的土墙边：赵云把井口土墙推倒掩好，解开勒甲绦、放下掩心镜，把阿斗护抱在胸前，一手绰枪，
正上马冲出；身边已无一名从骑，青釭剑已插在身上。入画理由：这是回目“单骑救主”的核心动作，神情与姿态足以表现，
无需画斩杀或投井。旧稿沿用此场面。具名限赵云、阿斗二人，景山顶上的曹操只作远景小像。三处依据：

- 「解开勒甲绦，放下掩心镜，将阿斗抱护在怀，绰枪上马。」
- 「云插剑提枪，复杀入重围；回顾手下从骑，已没一人，只剩得孤身。」
- 「曹操在景山顶上，望见一将，所到之处，威不可当」

先后核对：夺青釭剑（刺死夏侯恩）在先，其后才遇糜夫人、阿斗、掩井上马，之后晏明、张郃、四将围攻，
赵云才“拔青釭剑乱砍”。曹操在景山顶望见赵云，是杀透重围的末段，晚于所选瞬间，远景小像仅作环境交代。

## 器物与环境

- 地点：当阳长坂；被火烧坏的土墙，推倒后成土堆，盖住枯井，画面不见井口；远处可有零星逃难的百姓（兜底）。
- 时令：秋末冬初（“凉风透骨”）；时间为四更厮杀至天明之后，晨光；天气本回未写，不强加雨雪。
- 器物：枪、青釭剑、掩心镜与勒甲绦、盔、征袍；远景景山。
- 现实中会动的：① 地面升起的火烟与烟尘；② 马蹄踏起的尘土；③ 征袍下摆、勒甲绦与阿斗襁褓一角被气流带动。

## 排除项

- 糜夫人、投井、枯井口不画；刘备摔阿斗（第42回）、张飞据桥不入画。
- 白袍白马银枪、亮银枪、梨花枪法、浴血、满身血染、斩首与尸堆；赵云不脱甲，不披露阿斗全身。
- 张郃红光陷坑、晏明、马延张顗、焦触张南、钟缙钟绅均为此刻之后，不混入；不画拔剑乱砍。

## 现有题面核对

旧题面：`sanguo-041` / `sanguo-anim-041`（`src/core/classics/sanguo.ts`）。场面沿用，改下列细节：

- 有据：当阳长坂；浓眉大眼；阿斗护于胸前、一手持枪；宝剑在身；晨光；烧坏的土墙。
- 与原著不符：“解开铠甲”，应为“解开勒甲绦、放下掩心镜”；“硝烟”，汉末无火药，改烟尘、火烟；“一口枯井”，井已被推倒的土墙掩盖，画面不见井口。
- 过头：“战袍被血染红”，“血满征袍”在杀透重围之后且渲染血腥；改征袍沾尘，不写血染。
- 本回未写：襁褓；剑的佩挂位置（夏侯恩“背着”，赵云“插剑”）；“远处山头立马观望者”实为景山顶的曹操，原文无“立马”，应点明或略去。
- 动态旧稿：“白袍浴血”“白龙马”“亮银枪”“梨花突刺”“剑穗”均无据，一手抱婴也无法连续突刺；改烟尘、马蹄尘土、征袍与勒甲绦飘动。
