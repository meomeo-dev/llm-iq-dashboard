# 《三国演义》第52回 诸葛亮智辞鲁肃　赵子龙计取桂阳

底本：<https://zh.wikisource.org/wiki/三國演義/第052回>；读取日期：2026-10-19。

## 情节要点

1. 周瑜闻南郡、荆襄被袭，气发箭疮；鲁肃劝止，亲赴荆州索地，孔明命人扶出病弱的刘琦，答以“公子在一日，守一日”。
2. 刘备得荆襄后用马良之策，先取荆南四郡；以张飞为先锋、赵云合后，兵临零陵。
3. 零陵将邢道荣出战，孔明坐四轮车到阵前招降，被追杀时转回阵中；张飞、赵云两路伏兵擒他，夜里劫寨计又使刘贤被擒，刘度投降。
4. 赵云领三千兵取桂阳，接住陈应掷来的飞叉回掷，趁其躲闪将其生擒；赵范降并结拜，欲以寡嫂相配，赵云拒绝；陈应、鲍隆诈降被识破，赵云夺城。
5. 张飞不服，要去取武陵（下回接续）。

## 选定场面

零陵城外的两军阵前：邢道荣出马，手使开山大斧，高声叫阵；对阵门旗开处，一簇黄旗间推出一辆四轮车，孔明端坐车中，
头戴纶巾、身披鹤氅、手执羽扇，以扇招邢道荣劝降。取孔明开口招降、道荣尚未冲杀的一刻。入画理由：本回孔明的衣冠器物
写得最全（羽扇首见于此），四轮车与黄旗一眼可辨，对峙不涉血腥；回目两件事，辞鲁肃是室内对谈，取桂阳须靠诈降与美人计
才讲得清，都难成一画，故取同回此段。具名限孔明、邢道荣。三处依据：

- 「一簇黄旗。门旗开处，推出一辆四轮车」
- 「车中端坐一人，头戴纶巾，身披鹤氅，手执羽扇，用扇招邢道荣曰」
- 「道荣出马，手使开山大斧，厉声高叫」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 诸葛亮 | 身长八尺，面如冠玉（第38回）；头戴纶巾，身披鹤氅，手执羽扇，端坐车中；鹤氅颜色未写，兜底：素白或淡色；神态从容含笑，以扇招；不披发、不持剑 | 第38回；第42回“纶巾道服”；第52回“手执羽扇” |
| 邢道荣 | 零陵将，“力敌万人”；手使开山大斧，斧一手持而未挥；容貌衣甲坐骑本回未写，兜底：壮汉，披甲戴盔，骑马，神态傲慢 | “手使开山大斧，厉声高叫” |
| 推车军士（群像） | 数人推车，立于车后或车旁；衣甲未写，兜底：军服步卒 | “推出一辆四轮车” |

四轮车本回只写“四轮”，其余未写，兜底：木制敞车，四轮，车上设一座，无篷。先后核对：邢道荣叫阵在先，孔明车出、招降在后；
道荣“大笑”“轮大斧竟奔孔明”、孔明回车入阵，均在其后，不画。

## 器物与环境

- 地点：零陵城外，两军对圆；刘贤、邢道荣在离城三十里“依山靠水”处下寨，兜底：平地阵前，远处山脚与水岸。
- 阵势：对阵中一簇黄旗，门旗两开；黄旗居中，军阵里是中军之色。
- 时令天气：本回未写时令，承上回为赤壁后的同一年；白昼，天气未写，兜底：晴，不强加雨雪。
- 现实中会动的：① 黄旗与门旗被风吹动；② 孔明手中羽扇轻摇、鹤氅衣袖；③ 邢道荣坐骑的鬃尾、鼻息与蹄下尘土。

## 排除项

- 孔明披发跣足、道袍仗剑（第49回形象）、八卦衣、京剧黑三髯与法衣；孔明不乘“轮椅”式小车，也不立于车上。
- 邢道荣冲杀、孔明回车、张飞赵云伏兵、夜里劫寨、道荣被刺，均在其后，不画。
- 同回他段人物：鲁肃、刘琦、马良、刘度、刘贤、陈应、鲍隆、赵范与樊氏。
- 孔明手中是羽扇，不是令旗、拂尘；白羽扇通行画法可用，不必写“鹤羽”。
