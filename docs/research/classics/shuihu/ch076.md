# 《水浒传》第76回 吴加亮布四斗五方旗　宋公明排九宫八卦阵

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第076回>；读取日期：2026-10-20。

## 情节要点

1. 童贯受天子统军大元帅之职，调八路军州各一万、御营二万守中军，酆美、毕胜为左右羽翼；新曹门外短亭，高、杨二太尉饯行。
2. 大军到济州，张叔夜劝他用谋，童贯怒斥；次日在梁山泊附近下寨。宋江、吴用早已定好计策。
3. 张清三次哨探；李逵、樊瑞、项充、李衮引五百步军露面，童贯用玉麈尾一招冲击，四人退入山后。
4. 童贯在平川列阵，中军立攒木将台，两名法官招飐摆成四门斗底阵；山后炮响，梁山军从山东、山西涌出，占住中央，布成九宫八卦阵。
5. 童贯上将台观阵，惊得魂飞魄散；随后陈翥出阵被秦明打下马，董平、索超冲阵，童贯勒马回走（接下回）。

## 选定场面

近梁山泊的平川旷野上，童贯站在官军中军的攒木将台上，定睛望着对面刚布成的梁山九宫八卦阵：红、青、白、黑四色大阵分居四方，
四隅是两色相间的小阵，正中一圈杏黄旗，五方旗色分明；他惊得魂飞魄散。具名只写童贯一人，阵中诸将作色块不点名，另有台上
两名法官。选它是因为全回只有这一刻同时呈现统帅的惊惧与整座阵的色彩方位，且阵中诸将“手搭兵器，立于阵前”，无人交手。三处依据：

- 「童贯中军立起攒木将台，令拨法官二员上去，左招右飐，一起一伏」
- 「枢密使童贯在阵中将台上，定睛看了梁山泊兵马」
- 「去那八阵中央，只见团团一遭，都是杏黄旗」

先后核对：张清哨探、李逵等诱敌、童贯冲击（前）→官军摆四门斗底阵、炮响、梁山军涌出（前）→童贯令左右拢住战马、自己上将台看
（此刻起）→梁山军占住中央、布成九宫八卦阵，童贯惊惧（此刻）→童贯下将台上马，问谁敢出战（后）→陈翥出阵，将台上红旗招展，
秦明打杀陈翥（后）→董平、索超冲阵（后）。此刻童贯的战马在台下，红旗尚未招展，陈翥未出现，不画交战。

## 器物与环境

- 地点：出济州后、梁山泊附近的“一派平川旷野之地”。将台形制未写，兜底：木柱绑扎的方台，有扶栏与梯，高于全阵。《营造法式》
  望火楼为四柱木构（据摘要），仅作旁证。官军摆的是四门斗底阵，不画细节。
- 时令天气：本回未写，第75回为四月，第78回称“炎热”，兜底：初夏晴日，草色青绿，不画雪雨。
- 梁山阵方位：正南秦明是“先锋大将”，出阵迎陈翥；东南董平、西南索超随后冲阵捉童贯；正北呼延灼是“合后大将”；
  正东关胜称“左军”、正西林冲称“右军”。故阵面朝南，童贯在阵南、面朝正北望阵。兜底：画面近处（下方，近将台）
  为南，远处（上方）为北，左西右东；四隅小阵的旗甲两色取相邻两方之色（下表按画面排布）：

| 西北：白旗黑甲，飞虎（杨志） | 正北：皂旗黑甲，玄武（呼延灼） | 东北：皂旗青甲，飞豹（史进） |
| :-- | :-- | :-- |
| 正西：白旗白甲，白虎（林冲） | 中央：杏黄旗，六十四面长脚旗，黄袍铜甲黄马（朱仝、雷横） | 正东：青旗青甲，青龙（关胜） |
| 西南：红旗白甲，飞熊（索超） | 正南：红旗红甲，朱雀（秦明） | 东南：青旗红甲，飞龙（董平） |

- 四斗五方旗：引军旗上金线绣南斗六星、东斗四星、西斗五星、北斗七星，下绣四象神兽（第71回列有“四斗五方旗”）。中军另有鹅黄帅字旗
  （堆绒绣、真珠圈边、脚缀金铃、顶插雉尾）与二十八面宿旗，远景可略。
- 现实中会动的：① 各色旗面随风同向飘动；② 帅字旗顶的雉尾、盔缨和马鬃摆动；③ 阵边远处尘烟缓缓上升。童贯与将台不位移。

## 排除项

- 后拍：童贯下台上马、陈翥出阵、将台上红旗招展、秦明打杀陈翥、董平索超冲阵。前拍：张清哨探、李逵等五百步军、童贯执玉麈尾冲击。
- 四隅小阵是“旗色+甲色”两色（如青旗红甲），不画成单色；中央是黄，不是红；阵中交战、落马、断旗一概不画。
- 方位不倒置：红阵在近将台一侧，皂阵在远端，白阵在画面左、青阵在画面右；不画成童贯站在阵北。
- 吴用的羽扇纶巾属阵中中军，远景不画成诸葛亮；不画八卦符号铺地、太极图、魔方式方格；不画诸葛亮八阵图石阵。
- 戏曲：不用龙套、靠旗、翎子；童贯此刻不骑马。
