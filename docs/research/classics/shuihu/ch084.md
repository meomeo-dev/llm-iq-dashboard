# 《水浒传》第84回 宋公明兵打蓟州城　卢俊义大战玉田县

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第084回>；读取日期：2026-10-20。

## 情节要点

1. 宋江入檀州安民，朝廷派赵安抚督军。宋江分兵两路攻蓟州：自率左军到平峪县，卢俊义率右军
   三万到玉田县。
2. 玉田县外辽军摆阵，御弟大王耶律得重与四子出阵；关胜等四对厮杀，张清被辽将天山勇冷箭射中
   咽喉受伤，宋阵被冲散。傍晚卢俊义单骑力战四员辽将，夜里与呼延灼、关胜会合。
3. 辽军围玉田县，燕青射伤耶律宗云；宋江援军赶到解围，卢俊义追击。
4. 时迁、石秀混入蓟州。宋江与卢俊义合兵围城，林冲、徐宁、索超、史进连败辽将；宝严寺塔、州衙
   起火，宋军夺城，耶律得重弃城逃往燕京。

## 选定场面

夏日白昼，玉田县外平原，黄沙漫漫。两军阵前对峙，尚未交手：画面左侧宋军右军阵前，卢俊义披甲骑马
立于队首，右手握枪斜指向上，侧身发问；画面右侧辽军黑色雕旗下，门旗开处，御弟大王耶律得重策马
出阵，四员年轻辽将分列两侧，披挂相同。两阵之间是一片空地和扬起的黄沙。具名卢俊义、耶律得重。
选它是因两军阵容、旗号、衣冠在此刻最完整，且无任何动手。三处依据：

- 「门旗开处，那御弟大王，亲自出马，四个孩儿分在左右」
- 「两军临敌，那个英雄当先出战？」
- 「人人衣襟左掩，个个发搭齐肩」

先后核对：辽兵盖地而来（前）→朱武上云梯看阵，再上将台招动号旗，宋军摆“鲲化为鹏阵”（前）→辽阵
鼓响，门旗开处，御弟大王与四子出阵（此刻）→卢俊义发问（此刻）→关胜舞青龙偃月刀出马，耶律宗云
迎战，随后四对厮杀（后）→张清中弩箭（后）→傍晚卢俊义单骑力战四将（更后）。此刻无人交手，关胜
尚未出马；宋江不在此地（在平峪县）；刺落马下、割首级是傍晚以后的事，不画。

## 器物与环境

- 地点：玉田县外平原；玉田县在辽属蓟州，隶南京道析津府，今河北玉田（据摘要）。原文“黄沙漫漫，黑雾
  浓浓”，兜底：地面扬起浅黄沙尘，天空发白。
- 时令天气：本回后文“即目炎天”“即日炎暑”，兜底：夏日白昼，不画雪、秋叶。阵前时辰未写，傍晚是后文，
  此刻不画落日。
- 阵势与旗：宋军“鲲化为鹏阵”，原文称远看近看只是小阵，兜底：宋阵画得紧凑；辽军“皂雕旗”，兜底：黑底雕图旗，
  不写字（辽军旗色形制未检得，仅依原文）；辽阵“门旗”；宋阵将台号旗可入远景。
- 乐器：辽军“铜羯鼓军前打，芦叶胡笳马上吹”，可作小件，不必画。
- 现实中会动的：① 辽阵黑旗在风中飘动；② 黄沙尘幕缓缓飘移；③ 马匹鬃毛、盔上黑缨球、枪缨随呼吸
  摆动。人物与马匹不整体位移。

## 排除项

- 后拍：关胜出战耶律宗云、四对厮杀；张清咽喉中弩箭；卢俊义夜战四将、刺落宗霖、割首；围玉田县，
  燕青射箭；蓟州：林冲矛刺宝密圣、徐宁搠天山勇、索超劈咬儿惟康、史进砍楚明玉曹明济，时迁石秀
  放火，宝严寺塔火起。前拍：檀州战（第83回）。
- 称“辽将”“辽兵”，不沿用原文贬称；不画“碧眼黄须”“黑面皮”等种族化或丑化面貌；不画成蒙古、金或清代
  装束（无辫发、无元代皮帽）。
- “拐子马”是宋金战争用语（据摘要），辽代无连环相系的马队，不画三马相连；呼延灼连环马（第55–57回）不混。
- 戏曲：京剧番邦将帅插雉翎、挂狐尾（程式，据摘要），不画翎子、狐尾、靠旗、勾脸。
- 宋江、张清、朱武特写不入画。
