# 《水浒传》第79回 刘唐放火烧战船　宋江两败高太尉

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第079回>；读取日期：2026-10-20。

## 情节要点

1. 高俅水路受惊退回济州；韩存保与呼延灼溪中扭打，被张清擒获，宋江礼送放回。经韩家一系
   疏通，蔡京松口，天子再降招安诏，命闻焕章同天使赴济州。
2. 牛邦喜拘来大小船一千五百余只，高俅令三只一排钉住、铺板、船尾铁环锁定，操练半月。
   吴用定计：刘唐掌管水路，水军头领备火船，凌振放炮，公孙胜祭风，旱路三队接应。
3. 官军船队深入金沙滩，渔船、牧童诱敌登岸，秦明、呼延灼伏兵截杀；公孙胜祭风，芦苇荷花
   丛中小船钻入大船队，火把齐举，官船尽烧，刘梦龙、牛邦喜被擒。
4. 索超、林冲等轮番追击，石秀、杨雄夜里放火壮声势，高俅折兵大半。老吏王瑾献计，把诏书
   “除宋江”断句诱杀宋江；闻焕章劝阻不听。宋江不疑，率众下山赴济州听诏。

## 选定场面

白昼，梁山泊金沙滩外荷花荡水面，风已大作、天色转暗。芦苇与荷花丛中，火船从画面左侧小港棹出：
船头钉铁叶，舱里堆芦苇干柴，柴中灌硫黄焰硝；船上水军头领举着刚点燃的火把，刘唐立在头船船头；
画面右侧是铁环锁成排、铺着木板的官军船队，兵士慌乱回棹。火把已着，柴草未着。具名刘唐，其余
作群像。选它是因“火船逼近、火未燃起”一眼可认，且无人受伤。三处依据：

- 「芦苇丛中，藕花深处，小港狭汊，都棹出小船来，钻入大船队里」
- 「鼓声响处，一齐点着火把」
- 「船舱里装载芦苇干柴，柴中灌着硫黄焰硝引火之物」

先后核对：官船三只一排钉住、铺板（前）→前阵登岸被秦明、呼延灼截杀（前）→山顶炮响，公孙胜
披发仗剑祭风，狂风大作（前，风势持续到火起）→芦苇荷花丛中小船棹出，钻入大船队（此刻）→鼓响，
一齐点着火把（此刻）→霎时大火竟起、官船尽着（后）→刘梦龙、牛邦喜落水被擒（后）。此刻无火焰
烧船、无人落水；火船是人力棹入，船上有人，不画无人空船顺流漂来。风向原文未写，兜底：自画面
左向右吹。刘唐在火起时的位置原文未写（只写吴用唤他受计、掌管水路建功），其立于头船属构图安排。

## 器物与环境

- 地点：梁山泊金沙滩外荷花荡。官船是沿途拘来的民间大小船，不是第80回的海鳅船：无踏车、弩楼、
  竹笆；“每三只一排钉住，上用板铺，船尾用铁环锁定”，船上载步军，旌旗金鼓。
- 时令天气：本回无月日；“荷花荡”“藕花深处”“细柳”“绿莎草”，兜底盛夏（荷花花期6–9月）。
  风起时“黑云覆地，红日无光”，天色发暗，云压得低；不画夜景。
- 火船：小船船头排钉铁叶，舱载芦苇干柴，柴中灌硫黄焰硝；火把为手持，未写灯笼、火箭、火炮。
- 现实中会动的：① 荷叶、芦苇、船上旗旛同向被风吹弯；② 火把火苗顺风拉长摇曳；③ 水波起伏，
  火船随浪小幅颠簸、桨叶划水。船与人物不整体漂移。

## 排除项

- 后拍：满港烈焰、官船起火、人落水与被擒；李俊擒刘梦龙、张横拖牛邦喜下水；索超、林冲、杨志、
  朱仝追击；石秀杨雄放火；王瑾献计。前拍：渔船拍手、牧童倒骑黄牛吹笛、秦明红甲军与呼延灼黑甲军伏击。
- 公孙胜山顶祭风不入画，只以风势表现；宋江、吴用不在场。
- 不套《三国演义》赤壁：无诸葛亮坛、东南风、曹操铁索连环、黄盖诈降；本回官船是“三只一排”，原文未写风向。
- 刘唐不画红发（红发多见影视）；不画京剧脸谱；不画火炮齐射（凌振炮在山头作信号）。
