# 《水浒传》第21回 虔婆醉打唐牛儿　宋江怒杀阎婆惜

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第021回>；读取日期：2026-10-19。

## 情节要点

1. 宋江别刘唐后遇阎婆，被扯住衣袖强拉回家；婆惜见是宋江，翻身上楼不理，阎婆推宋江上楼，反搭房门下楼备酒。
2. 阎婆劝酒后自己也吃醉；唐牛儿赌输来寻宋江，上楼谎称知县相召替他解围，被阎婆识破，劈脖一叉推下楼，又
   打两掌赶出门外。
3. 宋江宿在婆惜脚后，五更起身；鸾带（上有解衣刀与招文袋）忘在床头栏干；县前遇卖汤药的王公，想起袋内晁盖
   书信，赶回。
4. 婆惜已抖出金子与书，提三件事要挟；争夺中宋江抢到压衣刀，怒杀婆惜（此事不入画），烧信。
5. 阎婆在县前喊“杀人贼”，唐牛儿打脱宋江，反被一并拖进县衙（下回接续）。

## 选定场面

阎婆家楼下堂前、胡梯脚边：唐牛儿刚被阎婆一叉推下楼，又钻到她面前叫“你打！”，阎婆乘着酒兴叉开五指，
掌还没落。具名阎婆、唐牛儿；宋江、婆惜在楼上，不入画。三处依据：

- 「一径奔到阎婆门前，见里面灯明，门却不关。」
- 「唐牛儿钻将过来道：“你打！”」
- 「这婆子乘着酒兴，叉开五指」

不取讨要招文袋的僵持：争夺在卧房床上，婆惜已“袒开胸前”，且以杀人收场，须避开。取“虔婆醉打唐牛儿”：
回目上联，场景在楼下堂前，灯、胡梯、门帘俱全，两人动作单纯，无死伤。

先后核对：唐牛儿闪入、唱三喏→宋江努嘴，牛儿谎称知县相召→阎婆识破，跳起身，劈脖子一叉，踉跄叉下楼→牛儿
“你做甚么便叉我”→阎婆喝骂→牛儿钻过来叫“你打”（此刻）→阎婆叉开五指，脸上连打两掌，攧出帘外（后）→
阎婆扯帘、关门上拴（后）→牛儿门外拍胸大骂（后）。

## 器物与环境

- 地点：宋江在县西巷内为母女租下的楼房（第20回）；此刻在楼下堂前，胡梯脚边，近前门。“堂前琉璃灯却明亮”；
  前门两扇，门外有帘子，可上栓；楼上春台、锡灯台、床不入画。
- 时令天气：八月半夜，宋江别刘唐时“月色满街”（第21回开头）；此刻是更鼓前的晚间，室内灯火，窗间月上在
  稍后；天气未写，兜底：晴。
- 器物：胡梯是宋元对楼梯的叫法（据摘要）；门帘、木门栓；琉璃灯形制未写（宋代日常灯以油灯为主，据摘要，不强加）。
- 现实中会动的：① 灯焰摇曳，墙上人影随之晃动；② 敞开的门外夜风吹动帘角；③ 阎婆衣襟与唐牛儿衣角随身体
  前倾微摆。

## 排除项

- 前后拍：唱喏、努嘴、叉下楼（前）；连打两掌、攧出帘外、扯帘关门、门外拍胸大骂、阎婆再上楼（后）。
- 招文袋、鸾带、压衣刀（均在楼上卧房，不入画）：宋江解下鸾带（上有解衣刀与招文袋）挂床栏→五更忘取→婆惜铺被时
  提起招文袋抖出金子与书→宋江折回，婆惜裹进被里→争夺中拽出“压衣刀子”→杀人。“解衣刀”“压衣刀”应是同一把
  随身短刀（据摘要）。婆惜此时“解了裙子，袒开胸前”，不画。
- 次日清晨县前：唐牛儿托糟姜盘子打脱宋江、被拖进县衙；今夜唐牛儿手无托盘。
- 张文远、王婆、刘唐不入画。
- 戏曲：京剧《乌龙院》由老生宋江、花旦阎惜姣、老旦阎母、丑角张文远演，唐牛儿不在主要角色表（据摘要）；
  不画戏曲扮相与水袖。
