# 《水浒传》第34回 镇三山大闹青州道　霹雳火夜走瓦砾场

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第034回>；读取日期：2026-10-20。

## 情节要点

1. 黄信、刘高押宋江、花荣的囚车走三四十里，在林子里被燕顺、王英、郑天寿截住；黄信败走，刘高被擒，
   囚车被劫，众人回清风山，刘高被处死。
2. 黄信逃回清风镇告急，青州慕容知府请来兵马总管秦明；秦明点五百人马全副披挂，出城受赏，奔清风山。
3. 次日五更，秦明在山下与下山的花荣对阵，斗四五十合，花荣诈败回马，一箭射落秦明盔上红缨；秦明追不
   上山，被引着东西乱奔，夜间人马陷水、陷坑，被擒。
4. 秦明被礼待释放，回青州见城外烧成瓦砾场，知府在城上骂他造反，示其妻首级；宋江等说明是冒他旗号
   所为，秦明归顺，宋江做媒将花荣之妹许配给他。
5. 秦明独骑去清风镇叫开柵门劝黄信入夥，此时两路人马杀到镇上（下回接续）。

## 选定场面

清风山下空阔处，次日五更之后，秦明与花荣两阵对圆、尚未交手的一刻：花荣在马上擎铁枪向秦明唱喏，秦明勒
住马、横着狼牙棒怒目而视，花荣身后小喽啰列成阵势。具名花荣、秦明，另有小喽啰群像。三处依据：

- 「秦明勒住马，横着狼牙棒，睁着眼看时」
- 「花荣在马上擎着铁枪，朝秦明声个喏。」
- 「会事的下马受缚，免得腥手污脚。」

取对阵而不取射缨：射缨在后一拍，且与第35回花荣射雁同属拽弓；对阵能同框写全秦明盔甲与花荣枪马。
先后核对：秦明离山十里下寨，次日五更造饭、放信炮（前）→摆开人马擂鼓，山上锣响，小喽啰簇拥花荣下山
（前）→花荣到山坡前，一声锣响列阵，擎铁枪唱喏（此刻）→秦明大喝，花荣陪笑答话（此刻之后）→秦明掄动
狼牙棒直奔花荣，二人交手四五十合（后）→花荣诈败，把枪挂在事环，拽弓射落红缨（后）。此刻盔上红缨完好，
弓箭挂身未取，枪在手，两件兵器尚未相碰。

## 器物与环境

- 地点：清风山下，秦明“拣空阔去处摆开人马”，离山十里下寨，山坡前；山高险峻，古怪乔松、瀑布（第32回
  赞词）；山上擂木炮石、灰瓶金汁在后拍，不画。
- 时令天气：秦明“次日五更造饭”，放信炮后到山下，此刻为清晨；天气未写，兜底：晨光、薄雾，不画雪。
- 器物：狼牙棒（《武经总要》称坚重木制、长四五尺、棒头钉如狼牙，原文“密嵌铜钉”，画成木柄、枣核形
  钉头）；铁枪、枪缨；盔上红缨；铜锣；红旗，旗上大书“兵马总管秦统制领兵起行”（出城时）。
- 现实中会动的：① 盔缨、枪缨和红旗在风中飘动；② 两匹战马的鬃毛、尾巴摆动，马头小幅点动；③ 山坡
  前的晨雾缓缓移动（雾为兜底，可省）。人物与阵列不整体移动。

## 排除项

- 后拍：掄棒直奔花荣、交手、诈败、枪挂事环、拽弓射落红缨；山上擂木炮石；水淹、陷坑、秦明被擒；瓦砾场、
  妻首级。前拍：林中拦路、囚车被劫、刘高被处死、知府犒军、秦明出城。
- 他回：第35回花荣射雁与对影山射断绒绦；第33回花荣射门神骨朵头与盔缨。
- 獬豸只是比喻，马是普通战马，不画独角神兽；狼牙棒不画成带钉铁球、流星锤或全铁长棒。
- 戏曲与影视：靠旗、雉翎、扎靠、脸谱等不取（未检得秦明京剧脸谱资料）；黄信不入画。
- 秦明红缨此刻完好，不画成已被射落；花荣此刻不持弓开射。
