# 《水浒传》第65回 托塔天王梦中显圣　浪里白条水上报冤

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第065回>；读取日期：2026-10-20。

## 情节要点

1. 索超被擒归降；宋江连攻北京不下，夜里梦见晁盖显圣，劝他早收兵（有百日血光之灾，须江南地灵星可治）；醒后背生
   痈疽，张顺愿往建康府请神医安道全。
2. 吴用下令回山。张顺冬尽冒雪赶到扬子江边，被艄公张旺与瘦后生孙五在船上劫金、缚住抛入江中；张顺咬断绳索游到
   南岸，得酒店王定六父子相救。
3. 张顺在建康府说动安道全，却在妓家出了人命，用血书逼安道全离城；次日在江心水上擒杀张旺（后两拍不画）。
4. 戴宗接应，安道全神行赶到梁山，十日内医好宋江背疮；吴用定要再取北京。

## 选定场面

傍晚，扬子江北岸渡口，大雪：张顺独自背着包裹来到江边，渡口一只船也没有，他循岸边走，见败苇折芦丛里冒烟，开口喊
“艄公，快把渡船来载我”；苇丛里走出一个头戴箬笠、身披蓑衣的艄公，隔着风雪问他往哪里去。具名张顺（艄公此刻未具名，
不称张旺）。选它是因风雪、枯苇、渡口、孤雁等景物集中（原文有整首《西江月》写景），人物之间只是问答，杀机未显，且
避开本回的杀人、妓家与宋江背疮。三处依据：

- 「是日北风大作，冻云低垂，飞飞扬扬，下一天大雪」
- 「绕着这江边走，只见败苇折芦里面，有些烟起」
- 「走出一个人来，头戴箬笠，身披蓑衣，问道」

未选晁盖托梦：本回只写晁盖“欲进不进”“阳气逼人”，衣貌未写，第14回也无外貌；宋江当时卧榻、身在梦中，易画成床帏与
鬼怪造型。先后核对：宋江梦晁盖，次日背疮（前）→张顺背包裹赶路，行十多日，无雨具（前）→到江边，北风大雪，渡口无船
（前）→绕江边走，见苇中有烟，喊艄公（前）→苇中走出箬笠蓑衣的人，问去哪里（此刻）→艄公说今日晚，四更风静月明再渡，
两人同入苇丛（后）→船篷下瘦后生向火，张顺脱湿衣、吃饭睡去（后）→初更后被缚抛江（后，不画）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张顺 | “浪里白条”。样貌见第38回：“六尺五六身材，三十二三年纪，三柳掩口黑髯，头裹青纱万字巾，掩映穿心红一点髾儿”，肤白。本回冬行只写“背上包裹”“不曾带得雨具”，包裹内有绵被、衣物与一百两黄金；兜底：冬季旅人，头裹万字巾，绵布袍或绵短袄（宋代平民冬衣多为丝绵填充，据摘要），腰系搭膊，麻鞋，肩头与头巾落雪；不戴笠、不披蓑，不露金子，不裸身，不画水裈 | 第38、65回 |
| 艄公（后知为张旺） | “头戴箬笠，身披蓑衣”；相貌未写；兜底：中年船夫，立在苇丛边，双手空垂，神色平常；板刀在船梢舱板下，此刻不持刀，不画凶相或斜眼 | 第65回 |
| 瘦后生（孙五） | 在船篷下向火，此刻不现身，不入画 | 第65回 |

## 器物与环境

- 地点：扬子江（长江）北岸渡口。渡口无船，岸边是败苇折芦，苇丛里有烟；《西江月》写景：冻云孤雁、枯木寒鸦、雪压桥边酒旆、
  银铺渡口鱼艖、前村隐隐两三家。后文张顺泅到南岸，故此岸为北岸。
- 时令天气：“时值冬尽，无雨即雪”；此刻北风大作，冻云低垂，一天大雪，傍晚（艄公说“今日晚了”，词写“江上晚来堪画”）。
- 器物：包裹；箬笠（箬叶或竹篾编）；蓑衣（莎草编成片状下垂，据摘要）。宋代长江小渡船的篷与橹未检得专条，兜底：
  只露一角苇席篷顶与一缕炊烟，船不入画。
- 现实中会动的：① 雪片被北风斜吹；② 败苇随风摇摆，苇间炊烟升起后被风吹散；③ 孤雁掠过冻云，枯木上寒鸦盘旋。人物不整体位移。

## 排除项

- 后拍：同入苇丛、船篷下向火、脱湿衣睡下、被缚、板刀、抛入江中；张旺杀孙五；王定六酒店；建康府安道全；李巧奴妓家；
  张顺杀人血书；江心擒杀张旺；戴宗神行。前拍：晁盖阴魂入宋江帐、宋江背疮、吴用买绿豆粉；第64回雪中陷坑。
- 不画晁盖、宋江、金子、板刀、绳索、血迹；张顺此刻没有下水，不戴笠不披蓑。
- 戏曲影视中的蓑衣反派渔夫造型不画。
