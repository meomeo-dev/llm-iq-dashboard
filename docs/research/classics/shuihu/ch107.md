# 《水浒传》第107回 宋江大胜纪山军　朱武打破六花阵

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第107回>；读取日期：2026-10-20。

## 情节要点

1. 宋江军到荆南以北的纪山，贼将李懹据山。袁朗的双挝厉害，宋军折了金鼎、黄钺；吴用定计，鲁智深等十四头领
   带凌振绕到山后夺山寨，与山下宋军前后夹击，大破纪山军。
2. 王庆得报，遣杜壆救西京、谢宇救荆南。
3. 卢俊义一路到西京城南三十里的伊阙山，贼将龚端与统军奚胜镇守；宋军先布“循环八卦阵”，
   奚胜另摆一阵来斗。
4. 朱武认出那是李靖的六花阵，说用八阵图法可破；他在将台上招展号旗变阵，杨志、孙安、卞祥领披甲马军
   冲入贼阵西方，贼兵大败。杨志等追奚胜入山，被伏兵拦住（回末悬念）。

## 选定场面

伊阙山南平坦处：朱武立在宋军将台上，手执号旗左招右展，把“循环八卦阵”变为八阵图法；台下阵中兵马旗号随之
变动，对面是奚胜的六花阵。具名朱武，另有旗手、鼓手与阵中兵马群像。选它因回目“朱武打破六花阵”，
人物动作单一，阵势可用旗色与方圆队形表达，不涉伤亡。三处依据：

- 「卢俊义入阵，朱武在将台上，将号旗左招右展，变成八阵图法」
- 「结三人为小队，合三小队为一中队，合五中队为一大队，外方而内圆」
- 「中一队是红旗，左一队是青旗」

先后核对：宋军在山南平坦处先排“循环八卦阵”（前）→贼兵分三队而来，奚胜令青红二军分在左右扎营，在自己
阵中竖将台、用两把号旗招展列阵，下台上马到阵前挑话（前，这是贼方将台）→卢俊义同朱武上云梯观望，
朱武认出是李药师六花阵（前，在云梯上）→卢俊义出阵喝话并入阵，朱武在宋军将台上招展号旗变阵（此刻）→
杨志、孙安、卞祥领马军千人冲杀，荡开贼将西方门旗（后）→追奚胜入山被伏兵拦住（更后）。画面只画宋军
将台一座；“识破”在前一刻，不与招旗合成同一站位。

## 器物与环境

- 地点：伊阙山（龙门山别称，在洛阳城南，小说称西京城南三十里，据摘要）山南平坦处；宋军在近处布阵，
  贼军在对面。
- 贼阵：原文写作“结三人为小队，合三小队为一中队，合五中队为一大队，外方而内圆，大阵包小阵”；
  《李卫公问对》所载六花阵也是外方内圆、大阵包小阵（据摘要）。字面“六花”易被画成六瓣花，
  兜底：从高处看，外轮廓为方形、内层为环形的队列色块，不画花瓣。
- 旗色：贼军“中一队红旗，左一队青旗：右一队红旗”，后文又说青红二军分在左右；“右一队”与“中一队”
  同为红旗，疑文字有误，题面只写青红两色旗，不分左右。宋军旗色本回未写。
- 将台：木构高台，台上可立一人挥旗（形制本回未写，兜底：方形木台，四柱，带踏阶与栏杆）。
  《武经总要》的云梯是攻城器具（据摘要），小说里用作登高观望的台（第88回“云梯将台”连称），
  本回“云梯”与“将台”是否同台未明。
- 时令天气：第108回写“此时已是深秋天气”，本场面时辰天气未写，兜底：秋日白昼，晴。
- 现实中会动的：① 朱武手中号旗左招右展（往复）；② 阵中与贼阵的旗幡随山风飘动；
  ③ 朱武的衣袖与长须微动。台下兵马队形只作小幅整体涌动，不冲阵。

## 排除项

- 后拍：杨志孙安卞祥冲阵、荡开西方门旗、马灵金砖术、追奚胜被伏兵围困；
  前拍：纪山战（袁朗双挝、金鼎被打死、黄钺被擒、琼英飞石）、鲁智深等夺山寨、王庆与段娘娘吵闹。
- 不画诸葛亮八阵图的石堆迷阵、风云幻象；不画地面上的八卦图案与太极图；不画六瓣花形阵。
- 不画朱武持鹅毛扇或双刀，不画红脸谱；奚胜不画被擒或被杀；卢俊义、杨志不入画。
- 贼军不画成异族或丑化形象。
