# 《水浒传》第93回 李逵梦闹天池　宋江兵分两路

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第093回>；读取日期：2026-10-20。

## 情节要点

1. 钮文忠出北门逃走，被李逵、鲁智深截住；宋江入盖州救火安民。元旦宋江率众望阙朝贺，
   众头领换穿红锦战袍。立春之夜降大雪，萧让论雪花六出，李逵鼻气冲灭雪花。
2. 宜春圃雨香亭夜宴，宋江追论往日落难，潸然泪下；李逵醉后伏桌睡去，梦中出城到天池岭，
   遇秀士，闯庄院，到文德殿见帝，秀士授十字要诀“要夷田虎族，须谐琼矢镞”。
3. 梦末李逵在林中见到老娘，抱住哭诉，林中跳出猛虎，李逵挥斧劈空，扑在酒桌上惊醒。
4. 次日雪霁，宋江与卢俊义、吴用议定兵分东西两路，开列将佐，抓阄定路。

## 选定场面

梦中，天池岭山脚下的林子里：李逵见秀士已不见，抢入林中，看到一位老婆婆闭着眼端坐在青石
上，认出是自己的老娘，上前抱住，哭着说铁牛已受招安、要背娘进城。具名李逵、李母。选它是因
为全回唯一不涉杀戮、又最贴回目“梦闹天池”的一刻，且母子相认情绪鲜明、构图简单。三处依据：

- 「抢入林子来，果然有个婆子坐着。」
- 「却原来是铁牛的老娘，呆呆地闭着眼，坐在青石上。」
- 「李逵向前抱住道：「娘呀！你一向在那里吃苦？」」

先后核对：秀士授十字要诀并指林中有婆婆（前）→李逵转身，秀士已不见（前）→抢入林子，见婆子
闭目坐青石上，近前认出，向前抱住（此刻）→母子对话，李逵哭着说受了招安（此刻）→林中一声
响，跳出斑斓猛虎，李逵挥斧劈空，扑在桌上惊醒（后）。此刻秀士不在，猛虎未出，不画斧举过头。
原文只有“天池岭”，没有水池，不画池水。梦中无雪（原文：“原来无雪”）。

## 器物与环境

- 地点：天池岭山脚林子。第94回宋江实见此山：“万叠流岚鳞次密，数峰连峙雁成行；岭巅崖石如
  城郭，插天云木绕苍苍”，梦中景物与之相同（李逵语）。兜底：背景远山叠嶂，近处松与杂木，
  一块大青石，地面不画积雪。
- 时令天气：现实中是立春前后大雪（原文）；梦中无雪，时辰与天色未写；兜底：无雪的晴天，
  不画花叶（早春）。
- 器物：青石；板斧（宋军制式大斧为长柄，李逵短柄板斧不同类，刃形有平刃与半圆刃两说，据
  摘要），题面只写“腰间插着两把板斧”。
- 现实中会动的：① 林梢枝叶与松针随风轻摆；② 山腰流岚缓缓飘移；③ 李逵肩背随抽泣小幅起伏，
  衣带与袍角轻晃。李母与青石不动。

## 排除项

- 后拍：猛虎扑出、挥斧劈空、扑倒酒桌惊醒；前拍：折角头巾、淡黄道袍的秀士授诀、庄院里打杀
  强人、踢翻桌子、文德殿上杀四奸臣（均不画）。梦外：雨香亭夜宴、大雪、萧让论雪、鼻气冲雪、
  兵分两路与抓阄。
- 第43回李母被虎所食的情节（虎窝、残骨、血迹）不画；不画皇帝、官员、虎。
- 李逵须色按原著画赤黄须；不画卷发、异族面貌，不用京剧黑脸程式；李母不画成鬼魅。
- 不画池水、龙潭（原文无）。
