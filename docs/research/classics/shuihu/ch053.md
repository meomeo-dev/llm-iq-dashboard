# 《水浒传》第53回 戴宗智取公孙胜　李逵斧劈罗真人

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第053回>；读取日期：2026-10-20。

## 情节要点

1. 吴用请戴宗去蓟州寻公孙胜，李逵同行；戴宗给李逵拴甲马，李逵偷吃牛肉，两腿停不下来，吃足苦头后答应吃素。
2. 蓟州素面店里，一位老丈说起九宫县二仙山的清道人，即公孙胜；李逵挥斧吓倒公孙胜的母亲，逼出公孙胜。
3. 三人上山拜见罗真人，真人不允；李逵夜里翻墙入观，砍了“真人”和一个青衣童子（不画）。
4. 次日真人安然坐在云床上，用红、青、白三条手帕试他们；李逵被吹到蓟州，挨打下狱，五日后由黄巾力士带回。
5. 罗真人许公孙胜下山（下回接续传法）。

## 选定场面

次日白天，二仙山紫虚观门外石岩上：罗真人已用红手帕、青手帕把公孙胜、戴宗各化作一片云送上半空，云如芦席大，在天上
打转；他又把白手帕铺在石上，李逵站了上去，仰头看那两片云。具名罗真人、李逵、公孙胜、戴宗。不选斧劈，选这场：
三色手帕与云都有原文，无人受伤。三处依据：

- 「罗真人却把一个白手帕铺在石上，唤李逵踏上」
- 「那两片青红二云，如芦席大，起在天上转，李逵看得呆了」
- 「李逵立在手帕上」

先后核对：真人唤道童取三个手帕（前）→到观门外石岩，红手帕铺石，公孙胜踏上，袖一拂“起”，红云升到离山二十余丈，
喝“住”（前）→青手帕铺下，戴宗踏上，青云起在半空（前）→二云在天上转，李逵看呆；白手帕铺石，唤李逵踏上（此刻）
→李逵笑说“若跌下来，好个大疙瘩”，真人问“你见二人么”，李逵立在手帕上（此刻）→真人说“起”，白云飞起，李逵叫
放下（后）→招手落下红青二云，质问夜来斧劈，一阵恶风吹李逵去蓟州（后）。故此刻白手帕仍平铺在石上、李逵脚踏其上，
没有离地；红青二云在空中，公孙胜、戴宗各在云上。

## 器物与环境

- 地点：蓟州九宫县二仙山紫虚观。九宫县、二仙山为小说虚构，蓟州在今天津蓟州区（据摘要）。观门“硃红牌额，上写三个
  金字”，门外有石岩；山上“青松郁郁，翠柏森森”，一群白鹤。观内松鹤轩、云床此刻不入画。
- 时令天气：“秋残冬初时分，日短夜长”（上山当日）；此刻为次日白天，兜底：晴冷，松柏常绿，石上枯草。
- 器物：三条手帕：红（公孙胜）、青（戴宗）、白（李逵）；“帕”为方形小巾（据摘要），尺寸原文未写，兜底：一尺见方的素色
  丝帕，青色取深青偏蓝绿；两片云“如芦席大”，约一领席子大；道童取手帕，可不入画。
- 现实中会动的：① 红、青两片云在半空缓缓盘转，云上人的衣袂随之飘；② 松枝与道袍衣角在山风里摆动；③ 一两只白鹤
  在松间盘旋（石岩与李逵不动）。

## 排除项

- 后拍：白云载李逵升空、一阵恶风吹到蓟州、府衙泼狗血尿屎、黄巾力士取人。前拍：李逵夜入松鹤轩斧劈、素面店、甲马、
  挥斧吓婆婆、公孙胜家净室。
- 不画斧劈、白血、断头、童子被杀；李逵不握斧；罗真人不乘鹤，不持拂尘与剑（原文未写）；公孙胜不佩剑。
- 手帕只有三条：红、青、白各一，不增条、不改色；白手帕此刻不化云。
- 他回他书：第54回传法与下山、黄巾力士；二仙山“大仙二仙”两峰景点是后人附会（据摘要），不照画。
- 影视：罗真人、公孙胜的影视道袍造型未检得依据，不采用。
