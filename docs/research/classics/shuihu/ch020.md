# 《水浒传》第20回 梁山泊义士尊晁盖　郓城县月夜走刘唐

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第020回>；读取日期：2026-10-19。

## 情节要点

1. 林冲推晁盖坐头把交椅，吴用、公孙胜、林冲依次落座，连同杜迁、宋万、朱贵共十一位头领；林冲遣人往东京
   接妻，得报娘子自缢、张教头已故。
2. 团练使黄安率千余人来攻，吴用分派三阮、林冲、杜迁宋万与刘唐设伏，黄安被刘唐活捉；朱贵报讯，山寨又截下
   旱路客商二十余车财物，不伤人命。
3. 晁盖念宋江、朱仝救命之恩，欲遣人送金；济州新太守到任，宋江奉公文立案；宋江为阎婆施棺，应王婆撮合
   置办楼房安顿阎婆惜，婆惜与张文远私通（此段不入画）。
4. 一日傍晚宋江在县前茶房见刘唐，同上僻静酒楼：刘唐呈书与黄金一百两，宋江只把一条金子连书收进招文袋，
   余金仍由刘唐包回，另写回书交他带走。
5. 月夜巷口宋江携手送别，刘唐望西路连夜回山；宋江独行，被背后的阎婆叫住（下回接续）。

## 选定场面

傍晚郓城县僻静小巷口，宋江携住刘唐的手叮嘱，月轮刚升；刘唐背着大包、提着朴刀，还没迈步。具名宋江、刘唐。
三处依据：

- 「离了酒楼，出到巷口，天色昏黄，是八月半天气，月轮上来。」
- 「宋江携住刘唐的手，吩咐道：“贤弟保重，再不可来。”」
- 「刘唐背上包裹，拿了朴刀，跟着宋江下楼来。」

不取聚义厅排座次与擒黄安：前者人多厅满，后者是水上杀伐。取月夜话别：回目下联“郓城县月夜走刘唐”所指，
两人对站、月色、地点单纯，衣冠原文写得最足。

先后核对：酒楼内刘唐呈书、取出金子→宋江把书与一条金子包入招文袋，叫他余金包回→刘唐欲取桌上金子，被
拦→宋江写回书，刘唐收入包内，金子依前包了→刘唐背包、拿朴刀，随宋江下楼，出到巷口（此刻）→宋江携手叮嘱
（此刻）→刘唐“拽开脚步，望西路便走”（后）→宋江独行回头，阎婆叫住（后）。此刻金子在刘唐包里，宋江招文
袋里只有一条金子和晁盖的书，且被前襟遮住。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 宋江 | 郓城县押司，“年及三旬”，面黑身矮，人称“黑宋江”；眼如丹凤、眉似卧蚕，两耳垂珠，唇方口正，额阔顶平（韵文另写“身躯六尺”，画面取矮于刘唐，刘唐是“偌大一条大汉”）。本夜外穿褶子（长外衣，取物时“拽起褶子前襟”，第21回同一件称“背子”“上盖衣裳”），腰系鸾带，挂招文袋与解衣刀，头裹巾帻，脚穿丝鞋净袜（后三项见第21回同夜）；无马、不持腰刀朴刀 | 第20回；第18、21回 |
| 刘唐 | “赤发鬼”之名来自鬓边一搭朱砂记，并非红发；紫黑阔脸，朱砂记上生一片黑黄毛。本夜头戴白范阳毡笠儿，身穿黑绿罗袄，下着腿绷护膝、八搭麻鞋，腰跨腰刀，背大包，手提朴刀；初见时“走得汗雨通流，气急喘促”，此刻酒后话别 | 第20回；第14回 |

## 器物与环境

- 地点：郓城县县前，二人自“僻静小巷”里的酒楼出来，站在巷口；刘唐去向“西路”。酒楼内景、篦头铺不入画。
- 时令天气：八月半（中秋），傍晚“天色昏黄”，“月轮上来”，随后“月色明朗”；满月傍晚自东方升起（据摘要），
  月轮低悬东方；天气本回未写，兜底：晴，可有薄云。
- 器物：朴刀（长柄刀，宋代形制不详，据摘要；兜底：窄刃长柄刀）、腰刀、大包裹；招文袋是挂在腰带上的文书袋
  （据摘要），此刻被前襟遮住；回书在刘唐包内，不外露。
- 现实中会动的：① 薄云缓缓掠过月轮；② 二人袍襟与刘唐包裹的系带随夜风微摆；③ 月光在屋瓦与路面上的明暗
  轻微起伏。

## 排除项

- 酒楼内取金、拦阻、写回书（前）；刘唐迈步西行、宋江独行遇阎婆（后）；阎婆、阎婆惜、张文远、王婆不入画。
- 金子：不画金锭摊在桌上或抱在宋江怀里；黄金一百两仍在刘唐包里，宋江只留一条。
- 刘唐红发红须：京剧刘唐有专用红色髯口（据摘要），原文是朱砂记；不画红发，不画脸谱。
- 他回人物器物：晁盖、吴用、林冲、黄安与水战（前半回）；宋江的压衣刀拔出、招文袋被抖开（第21回）。
- 衣冠错置：押司是吏不是官（据摘要），不画官员公服与直脚幞头；本回只写“八月半天气”，不添中秋应节物。
