# 《水浒传》第54回 入云龙斗法破高廉　黑旋风探穴救柴进

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第054回>；读取日期：2026-10-20。

## 情节要点

1. 罗真人传公孙胜“五雷天心正法”，嘱“逢幽而止，遇汴而还”；公孙胜、李逵下山，路上李逵结识打铁的汤隆，同回高唐州。
2. 次日两军阵前：花荣射落薛元辉；高廉敲聚兽铜牌放出黄砂怪兽，公孙胜举松纹古锭剑一喝，兽虫落地，原是白纸剪的虎豹。
3. 夜里公孙胜在高处作法，三百神兵在空寨中遇霹雳火，几乎全灭；高廉出城求援不成，被公孙胜破法后由雷横杀死（不画）。
4. 破城后搜牢找柴进，节级藺仁说已推入后牢枯井；李逵脱衣坐箩筐下井，把柴进抱上来（李逵“脱得赤条条”，不画）。
5. 高俅举荐呼延灼征梁山（下回接续）。

## 选定场面

两军阵前，白天：宋江、吴用、公孙胜三骑居中；对面高廉从马鞍前取下聚兽铜牌，用剑去击，黄砂里豺狼虎豹冲出；公孙胜
在马上拔出松纹古锭剑，指向敌军，口中念咒，正要喝“疾”。具名公孙胜、高廉、宋江。不选李逵下井，因为原文写他“脱得
赤条条的”。三处依据：

- 「急去马鞍鞽前，取下那面聚兽铜牌，把剑去击」
- 「豺狼虎豹，怪兽毒虫，就这黄砂内卷将出来」
- 「公孙胜在马上，早掣出那一把松纹古锭剑，指着敌军」

先后核对：宋江阵前三骑，高廉出阵叫骂（前）→花荣一箭射薛元辉落马（前，不画）→高廉大怒，取铜牌敲三下，黄砂罩得
天昏地暗，兽虫卷出，众军待逃（此刻）→公孙胜掣剑指敌念咒，喝“疾”（此刻）→一道金光射去，兽虫乱坠阵前，原是白纸
剪的虎豹，黄砂散尽（后）→宋江鞭梢一指，三军掩杀，高廉退入城（后）。故此刻怪兽仍是扑来的兽形黑影，尚未变纸；金光
尚未射出。

## 器物与环境

- 地点：高唐州城外阵前，城壕吊桥已放下，宋江军“直抵高唐州城壕，下寨已定”。宋江阵“十骑雁翅般摆开在两边”，花荣、
  朱仝等在列。高唐州为元代地名移用，不画真实地标。
- 时令天气：前回二仙山为“秋残冬初”；此日早晨五更造饭后到阵前，兜底：初冬晴晨，被黄砂遮得“天昏地暗，日色无光”。
- 器物：聚兽铜牌；松纹古锭剑；高廉的剑（第52回名“太阿宝剑”）；花腔鼍鼓、杂彩绣旗（宋代旗用漆竿、旗脚作火焰形，
  据摘要）；神兵队里皂旗。
- 现实中会动的：① 黄砂如烟尘翻卷，遮住神兵队列；② 旗帜、披发、盔缨在风里飘；③ 战马鬃尾摆动、前蹄刨地。

## 排除项

- 后拍：金光射出、兽虫坠地变纸；宋江鞭指掩杀；夜里劫寨与霹雳火；高廉被杀；藺仁说井；李逵坐箩筐下井、救柴进。
  前拍：花荣射薛元辉，罗真人传法，路上结识汤隆。
- 不画李逵下井（赤身），不画柴进伤情与血；怪兽此刻不画成纸片；公孙胜不乘云，“疾”字不写在画面上。
- 汤隆、戴宗、李逵、呼延灼不入画；不画影视特效式火球、飞剑，不画京剧靠旗、翎子。
- 铜牌只有一面，不画成两面；聚兽铜牌不画成道士令牌或腰牌。
