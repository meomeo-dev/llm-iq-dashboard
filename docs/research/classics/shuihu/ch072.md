# 《水浒传》第72回 柴进簪花入禁院　李逵元夜闹东京

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第072回>；读取日期：2026-10-20。

## 情节要点

1. 宋江要去东京看灯，分四路出发；李逵硬要同去，扮伴当，燕青作伴。原文补述：宋江脸上刺字已由安道全上山后点去，起红疤，再涂金玉末磨去。
2. 正月十一日到东京万寿门外客店。次日柴进、燕青进城，在酒楼上见班直簪翠叶花，燕青骗来王班直，柴进灌倒他，换穿其锦袄花帽。
3. 柴进入东华门，经紫宸殿、文德殿、凝晖殿，到睿思殿，在屏风后见御书“四大寇”姓名，拔暗器刻下“山东宋江”四字，出宫还衣。
4. 十四日夜宋江一行到李师师家，官家驾到被辞出，樊楼遇史进、穆弘；十五日夜李逵在李师师家打杨太尉、放火，梁山人马接应，李逵独自去打城（引出下回）。

## 选定场面

正月十二日白天，东京大内睿思殿内。柴进扮作王班直，头戴花帽、帽侧簪翠叶金花，穿宫花锦袄，转到正面画屏之后，
面对素白屏风上御书的四个名字，手探向身边，正抽出暗器，要刻“山东宋江”四字，暗器尖尚未触到屏风。具名柴进。
殿内未写有人，不涉暴力与血腥。三处依据：

- 「转过屏风后面，但见素白屏风上御书四大寇姓名」
- 「山东宋江　淮西王庆　河北田虎　江南方腊」
- 「便去身边拔出暗器」

同句下半“把‘山东宋江’那四个字刻将下来”是下一拍，不画。先后核对：酒楼上王班直说翠叶金花、金牌“与民同乐”、宫花锦袄能入内
（前）→班直倒下，柴进换装（前）→过东华门，经紫宸、文德（门锁）、凝晖，入睿思殿偏殿，看御座、几案、书架、前屏风（前）→
转到屏风后见四个名字，心中暗忖（前）→拔暗器（此刻）→刻下四字，慌忙出殿（后）→回酒楼还衣（后）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 柴进 | 小旋风；龙眉凤目，皓齿朱唇，三牙掩口髭须（第9回，当时三十四五岁）；本回脱下自己的巾帻衣靴，换王班直的“锦袄、踢串、鞋胯”，戴花帽；班直“头边各簪翠叶花一朵”，每人赐“翠叶金花一枝，上有小小金牌一个，凿着‘与民同乐’四字”。踢串（单一词表释为束腰带类）、鞋胯形制未写，兜底：宫花锦袄，系腰带，穿靴；执色（手持仪仗器物）入殿时在不在手未写，兜底：不持；暗器形制未写，兜底：一握长的小尖利金属刻具 | 第9、72回 |

## 器物与环境

- 地点：东京大内偏殿，牌上金书“睿思殿”，“此是官家看书之处”；侧首开一扇朱红门。殿内：正面铺御座；两边几案放象管、花笺、
  龙墨、端砚；书架群书各插牙签；正面屏风“堆青叠绿画着山河社稷混一之图”；转过去是素白屏风，御书四行名字，原文排成一行，
  竖写横写未写，兜底：四名并列，山东宋江居首。睿思殿确是北宋殿名，神宗熙宁八年建（据摘要）；屏风与四大寇是小说设定。
- 时令天气：正月十二日白天（十一日到店，“次日”入城）；天气未写，兜底：殿内明亮，不画雪雨。
- 器物：屏风两面，御座，文房四宝，牙签书架，翠叶金花花帽，暗器；南宋有御座后政区屏风的记载（据摘要），睿思殿屏风仍按原文画。
- 现实中会动的：① 窗格透入的日光里，浮尘缓缓飘动；② 柴进帽侧翠叶金花与小金牌随动作轻颤；③ 拔暗器是一次性动作，定格，不作动效。

## 排除项

- 后拍：刻下“山东宋江”四字、屏风上留下缺口、慌忙出殿、“随后早有人来”；回酒楼还衣；次日各门盘诘。前拍：酒楼灌倒王班直、
  换装；东华门、紫宸殿、文德殿、凝晖殿。
- 殿内不画皇帝、内侍、宿卫；不画燕青、王班直、宋江。
- 下一段不入画：李师师家（茶坊、客位）、樊楼、宋江题词、李逵打杨太尉烧画、元夜大闹；不画调情或妓院场面。
- 他回装束：第9回柴进的皂纱转角簇花巾、紫绣团胸袍、弓箭；第71回忠义堂杏黄旗。不用戏曲脸谱、影视造型。
