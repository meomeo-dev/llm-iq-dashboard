# 《水浒传》第116回 卢俊义分兵歙州道　宋公明大战乌龙岭

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第116回>；读取日期：2026-10-20。

## 情节要点

1. 张横闻张顺死讯昏厥；宋江论功，李俊、石秀擒吴值，三员女将擒张道原；阮小七报侯健、段景住溺亡；宋江在涌金门外为张顺建“金华太保”庙。
2. 天使与刘光世到杭州，赐御酒、锦衣三十五领；宋江与卢俊义抓阄分兵：宋江取睦州乌龙岭，卢俊义取歙州昱岭关；六员病将留杭州。
3. 柴进、燕青诈称“柯引”投奔方腊，被招为驸马。
4. 宋江取富阳、桐庐，击退石宝；到乌龙岭下，李逵等探路被擂木炮石所阻；阮小二、孟康水战中火排阵亡。
5. 解珍、解宝扮猎户夜攀乌龙岭欲放火，被钩搭、石块弩箭所杀，尸首风化岭上；宋江夜袭夺尸，陷入石宝、邓元觉的伏击。

## 选定场面

乌龙岭下的夜里：解珍、解宝穿虎皮套袄，腰跨快刀，钢叉拴在臂膊上拖在背后，攀藤揽葛爬在陡壁上，岭顶关寨灯光闪闪，月光如昼。
具名解珍、解宝。选它因岭险月明、纵向构图清楚，两名猎户出身的好汉有鲜明装束（虎皮套袄），全程无人交手。其后的被钩、坠崖、
中弩一概不画。三处依据：

- 「解珍、解宝便去拴束，穿了虎皮套袄，腰里各跨一口快刀，提了钢叉。」
- 「是夜月光明朗，如同白日。」
- 「两个只顾爬上去，手脚都不闲，却把膊拴住钢叉，拖在背后。」

先后核对：吴用劝阻，两人请缨扮猎户，穿虎皮套袄、跨快刀、提钢叉辞别（前）→一更出发，路上杀两名伏路小军（前）→二更到岭下，
听寨内更鼓，不走大路，攀藤揽葛上岭（前）→爬到三分之二处望见岭上灯光，伏在岭门边听，更鼓已四更，说“夜又短”（前）→又攀援上去，
到岩壁崎岖处，钢叉拴在臂上拖在背后，刮得竹藤乱响（此刻）→岭上有人喝“著！”，钩搭解珍头髻（后）→解珍砍断钩坠崖，解宝被石块弩箭射死（后）。
此刻钢叉不在手里而在背后，钩未到，无人受伤。

## 器物与环境

- 地点：乌龙岭，“正靠长江，山峻水急，上立关防，下排战舰”，岭下是方腊水寨；史实乌龙岭在今建德梅城东北，为马鞍形山岭、旧驿道（据摘要）。
  攀登处为悬崖岩壁，长满竹藤；兜底：岩壁陡立，竹藤垂挂，岭顶木栅寨楼挂灯，远处江面反光。
- 时间：更鼓已四更（约凌晨一至三点，据摘要），月光明朗；时令初夏（第116回开头“四月尽间”，其后“早过了数十日”，且“夜又短”）。
- 器物：快刀一口；钢叉，兜底：三股叉，叉头山字形，木柄较长（叉的通行形制，据摘要），用绳拴在背后；竹藤，岩壁。
- 构图：二人侧身贴壁，脸转向画外，面容可见，背后钢叉露出，避免贴壁攀爬画成背影。
- 现实中会动的：① 竹藤枝叶随山风轻摇；② 岭顶灯笼火光闪烁；③ 薄云掠过月面，江面月光碎闪。攀岩二人姿势固定，不整体上移。

## 排除项

- 后拍：钩搭头髻、砍断钩、坠崖、狼牙乱石、石块与短弩、尸首风化、竹竿挑尸、树上刮皮写字“宋江早晚也号令在此处”；宋江夜袭夺尸被围。
- 前拍：杀两个伏路小军；阮小二、孟康水战火排；李逵等探路遇擂木炮石；吴用劝阻。
- 他回他地：登州山上猎虎（第49回）、豹皮裤、蒲叶尖刀；昱岭关；不画老虎。
- 不画黑色紧身夜行衣、蒙面，不画现代攀岩绳扣与安全绳；岭上守军不入画；不画月黑，原文是月明如昼。
