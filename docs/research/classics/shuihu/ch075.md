# 《水浒传》第75回 活阎罗倒船偷御酒　黑旋风扯诏骂钦差

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第075回>；读取日期：2026-10-20。

## 情节要点

1. 陈宗善领诏，蔡京派张干办、高俅派李虞候随行，十瓶御酒装在龙凤担内，前插黄旗；济州太守张叔夜劝他对梁山多用好言。
2. 宋江设宴迎诏。萧让、裴宣、吕方、郭盛在二十里外伏道迎接，张干办、李虞候出言不逊；陈太尉等登阮小七监管的船，
   李虞候用藤条打唱歌的水手，水手跳水；阮小七拔榍子喊“船漏了”，众人换乘快船先走，诏书御酒留在船上。
3. 阮小七叫水手上船舀水，取御酒来尝，一连喝了四瓶，余下六瓶分给水手，换成十瓶村醪白酒，原封缚好，赶到金沙滩。
4. 四月间，忠义堂上萧让读诏，诏中“龆龀不留”等语激怒众人，李逵从梁上跳下夺诏扯碎；鲁智深等发作，宋江送陈太尉下山。
5. 陈太尉回京禀告，童贯请命出师，被拜为大元帅。

## 选定场面

梁山泊水面，阮小七的船：陈太尉一行已乘快船离去，水手上船舀净了水，一名水手从龙凤担中取出一瓶御酒、解了封头，
递给坐在船艄的阮小七；他双手接过，凑近瓶口闻香，尚未入口。船头放着龙凤担与诏书匣。具名阮小七，另有三四名水手。
选它是因为全回只有这一刻无人动手、无首级、无殴打，器物（御酒、龙凤担、诏匣）、船、水泊与人物神态都齐全。三处依据：

- 「你且掇一瓶御酒过来，我先尝一尝滋味」
- 「一个水手便去担中取一瓶酒出来，解了封头，递与阮小七」
- 「阮小七接过来，闻得喷鼻馨香」

先后核对：水手唱歌、李虞候打人、水手跳水、拔榍子喊船漏、陈太尉等换快船（前）→“哪里来顾御酒诏书”（前）→水手上船舀水、
拭抹船板（前）→取酒、解封、递上（此刻前一拍）→阮小七接过闻香（此刻）→“和瓶便呷，一饮而尽”，连吃四瓶（后）→
六瓶分与水手、换村醪白酒（后）→金沙滩迎诏（后）。此刻船上没有陈太尉、张干办、李虞候，水手衣裤带水迹，
龙凤担里已少一瓶（余九瓶），舱底水已舀净，不画漏水。题面不写“毒”字（原文“只怕有毒”是下一拍的玩笑话）。

## 器物与环境

- 地点：梁山泊水面，往金沙滩去的途中。船为战船之一，“坐在中间”“船梢”“船头”“舱”均见原文，未写篷；兜底：平底木船，敞舱，
  舷边设桨位，船头平整。宋代河船有双橹船、平底漕船与尾舵（据摘要）；原文写“棹船”，取桨。
- 龙凤担与御酒：十瓶装龙凤担内，“前插黄旗”。形制未写，兜底：彩绘龙凤纹的木抬架，前端插一面小黄旗。宋代官酿酒用黄纸或
  黄罗封瓶口，称“黄封”（据摘要）；酒瓶兜底：小口、短颈、丰肩的瓷瓶（宋代酒瓶形，称经瓶或梅瓶，据摘要），瓶口黄纸已解开，
  一手可握；不画现代玻璃瓶、软木塞、酒坛。诏书匣兜底：小木匣，外裹黄绸，放在船头，不展开。
- 时令天气：诏书落款“宣和三年孟夏四月”，堂上“四月间天气”；天色未写，兜底：初夏晴日白昼。水泊岸边芦苇、蒲草
  （梁山泊宋时蒲苇丛生，据摘要）；四月株高未检得，兜底：近岸稀疏青绿，不画芦花。
- 现实中会动的：① 水面波纹和船身随波轻晃；② 担上小黄旗与岸边芦苇随风摆动；③ 一名水手手中的桨叶在水里缓慢往复划动。
  阮小七与船不整体位移。

## 排除项

- 后拍：阮小七喝酒（尤其连饮四瓶）、白酒桶、换成村醪、金沙滩迎诏、忠义堂萧让读诏、李逵从梁上跳下夺诏扯碎、揪打陈太尉与
  李虞候、倒出村醪、鲁智深等发作。前拍：水手唱歌、藤条打水手、水手跳水、拔榍子、换快船。
- 陈太尉、张干办、李虞候不在船上；不画船进水、人落水、殴打；诏书未展开也未扯碎。
- 阮小七不穿龙袍（招安之后的情节）；不用京剧《打渔杀家》萧恩扮相；不用影视造型；御酒不画成青花大坛或金杯。
