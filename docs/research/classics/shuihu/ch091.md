# 《水浒传》第91回 宋公明兵渡黄河　卢俊义赚城黑夜

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第091回>；读取日期：2026-10-20。

## 情节要点

1. 戴宗、石秀在酒店听公人说田虎破盖州、将攻卫州；宋江经宿太尉保奏，天子封宋江为平北
   正先锋、卢俊义为副先锋，赐御酒、金带、锦袍、金甲，限期出师。
2. 水军先自汴河入黄河，到原武县界等候；大军出陈桥驿，县官出郊迎接，宋江传令李俊水兵
   分哨左右，另拘本地船只载马匹车仗，大军次第渡到北岸，前部在卫州屯扎。
3. 卢俊义领军取陵川：花荣射董澄，李逵、鲁智深抢门；燕青献许贯忠所赠三晋山川图。
4. 卢俊义用降将耿恭赚高平，黄昏扮陵川军卒入城，连克二城；宋江分五路兵向盖州。

## 选定场面

冬日白天，原武县界黄河南岸渡口，宋军渡河：两哨水军战船分泊河面左右，当中几只征来的本地船
只载着战马与车仗，宋江随大军乘船渡向北岸，李俊立在战船船头调度。具名宋江、李俊。选它是因
本回其余场面都是攻城夺门、杀人与夜袭，只有渡河既是回目首句，又无厮杀。三处依据：

- 「宋江传令李俊等领水兵六百，分为两哨，分哨左右。」
- 「再拘聚些当地船只，装载马匹车仗。」
- 「宋江等大兵，次第渡过黄河北岸」

先后核对：水军先自汴河入黄河，候于原武（前）→大军到，县官出郊迎接，哨报船只已在河滨
（前）→宋江传令水兵分哨左右、拘聚本地船只装载马匹车仗，大军次第渡河（此刻）→李俊统战船
前往卫州卫河，前部到卫州屯扎（后）。“次第渡”是一个过程，画面取河心已有船、岸边仍有船
等候的一刻，不画全军登岸。宋江所乘船只与站位、李俊的位置本回未写，下文均为兜底。

## 器物与环境

- 地点：原武县界黄河南岸渡口。原武县在今河南原阳西南，北宋时位于黄河南侧（据摘要）；渡口名、
  河面宽窄、水势本回未写。
- 时令天气：本回未写。第89回为“严冬之月”，第93回称取下盖州时“腊月将终”，上推为冬季（推断）；
  兜底：晴冷白天，岸边枯草，河面开阔，不画雪与冰排。
- 船只：战船由水军头领整顿后自汴河入黄河（原文）；形制未写，兜底：长身多桨内河战船，舷侧
  列桨，船首低；本地船只宽平，设木栏防马惊，载马与双轮车（宋代内河大船圆短如屋，据摘要）。
- 现实中会动的：① 战船两舷桨叶往复划水，船身不整体位移；② 河面水纹与旗帜随风起伏；
  ③ 船上战马甩头、摆尾，鬃毛抖动。

## 排除项

- 前拍：宿太尉府保奏、披香殿受封。后拍：卫州屯扎、陵川攻城、花荣射董澄、李逵鲁智深抢门、
  耿恭赚高平夜袭、燕青献图、五路攻盖州。厮杀、尸体、首级一概不画。
- 不画浮桥、铁桥、蒸汽轮船与帆樯海船；不画雪与冰排（冬季为推断，原文未写）。
- 宋江不画戏曲靠旗、翎子；李俊不画红脸谱，不持托叉（第37回他回器物）。
- 影视无造型可套：央视版已删去征田虎（据摘要）。
