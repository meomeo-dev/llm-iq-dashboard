# 《水浒传》第22回 阎婆大闹郓城县　朱仝义释宋公明

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第022回>；读取日期：2026-10-19。

## 情节要点

1. 唐牛儿被解到县，知县有意开脱宋江，只拷问牛儿；仵作验尸，现场遗有宋江的压衣刀；张文远唆使阎婆上堂，
   知县差人勾追宋太公，太公出示三年前告官“出籍”的执凭。
2. 阎婆再闹，知县差朱仝、雷横带土兵四十余人搜宋家庄；雷横前后搜遍不见，朱仝称放心不下，亲自再搜。
3. 朱仝闩门入佛堂，拖开供床、揭起地板，拽索头，铜铃响，宋江自地窨子钻出；朱仝说明来意，劝他速走，宋江
   再入窖；朱仝盖板压床，出门说“真个没在庄里”，雷横顺水做人情。
4. 知县出千贯赏钱行海捕文书，朱仝出钱抚平阎婆，唐牛儿被判“故纵凶身在逃”，脊杖二十，刺配五百里。
5. 宋江与宋清当夜四更动身，投横海郡柴进东庄；宋江醉后踩了廊下病汉的火锨柄，两人冲突（下回接续：武松）。

## 选定场面

宋家庄佛堂里：朱仝进庄时已把朴刀倚在进门处壁边、闩上门，空手走入佛堂，拖开供床、掀开地板，一拽索头，
铜铃一响，宋江正从地窨子口钻出，吃了一惊。朴刀留在佛堂外，不入画。具名朱仝、宋江；雷横与土兵在庄前、
宋太公在草堂，不入画。三处依据：

- 「朱仝自进庄里，把朴刀倚在壁边，把门来拴了。」
- 「走入佛堂内去，把供床拖在一边，揭起那片地板来。」
- 「将索子头只一拽，铜铃一声响，宋江从地窨子里钻将出来。」

不取阎婆披发大闹公堂：人多、争吵，难成一图。不取柴进庄踩火锨：那是下回开端，且是冲突。取此刻：回目下联
“朱仝义释宋公明”的关键一幕，室内两人，供床、地板、索头、铜铃原文俱全，无打斗。

先后核对：朱仝进庄→倚朴刀于进门处壁边、拴门→空手入佛堂，拖供床，揭地板→拽索头，铜铃响，宋江钻出，吃惊（此刻）→朱仝
开口“公明哥哥，休怪小弟今来捉你”并转述宋江旧话（后）→宋江答话，再入窖（后）→朱仝盖板、压床、开门取朴刀
出（后）。佛座、供床、地板的写法有两层：朱仝转述宋江旧话为“佛座底下有个地窨子，上面放着三世佛，佛堂内有片
地板盖着，上面设着供床”；动手顺序则是拖供床→揭地板→拽索头。题面写“佛堂地板下的暗窖口，供床已拖开”，佛像
立在后方，不写窖与佛座的精确位置。

## 器物与环境

- 地点：郓城县宋家村宋太公庄上的佛堂；前门已被朱仝从里面拴上。堂内有三世佛、佛座、供床、一片可掀的地板、
  地窨子，板下系索头，索头连铜铃。供床形制未写，兜底：矮长条供案，可拖动。
- 时令天气：搜庄在宋江当晚离家之前的日间；时辰、天气本回未写（第22回路程诗写“秋末冬初”，指后几日行路），
  兜底：日间，佛堂内光线偏暗，不画雨雪。
- 器物：朴刀（长柄刀，宋代形制不详，据摘要）倚在进门处壁边，在佛堂外，不入画；三世佛造像（竖三世与横三世两式，宋代形制未检得，不强加
  手印与胁侍，只作三尊坐佛）；铜铃、索头、地板。
- 现实中会动的：① 铜铃随索头晃动；② 地板口扬起的灰尘在光里漂浮；③ 朱仝虎须髯随动作微摆。

## 排除项

- 后拍：朱仝说明来意、转述旧话，宋江重入窖，朱仝盖板压床，出门对雷横称“没在庄里”（均在后）；
  前拍：雷横先搜、公堂阎婆大闹、验尸。
- 他回人物器物：杀阎婆惜的卧房（第21回）；柴进、武松（第22回末与第23回）；朱仝日后的雷横、小衙内一段（后文）。
- 衣冠错置：宋江的白范阳毡笠、白缎衫、梅红绦是当夜动身时的装束；朱仝不披甲、不骑马、不持朴刀（已倚在进门处壁边）；佛堂内不画朴刀。
- 形制：窖口不画成铁梯或现代暗门，只作木地板掀起露出的洞口。
- 戏曲影视：髯须只取原文“长一尺五寸”，不夸成垂腰长髯，不画脸谱（京剧、影视朱仝造型本次未检得依据，仅作防范）。
