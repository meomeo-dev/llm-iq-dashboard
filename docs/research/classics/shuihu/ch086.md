# 《水浒传》第86回 宋公明大战独鹿山　卢俊义兵陷青石峪

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第086回>；读取日期：2026-10-20。

## 情节要点

1. 辽副统军贺重宝向辽主献计：让两个兄弟佯败，把宋军引进幽州境内的青石峪，那里“只一条路入去，四面尽是高山”。
2. 宋江不听吴用、朱武“恐是诱敌”的劝，进军幽州，追贺统军四五十里，被辽军伏兵分作两段；天昏地暗，黑雾遮天。
3. 卢俊义领徐宁、索超等十二员头领、五千军马死命冲杀，循銮铃声闯进一处山口，狂风过后已陷四面高山的山谷。
4. 公孙胜在宋江一路舞剑破黑雾；解珍、解宝扮猎户从刘氏兄弟处探得青石峪方位，白胜裹在毡衫里从山顶滚下报信。
5. 宋军次日杀到峪口，林冲、李逵先后击杀贺拆、贺云，公孙胜破贺统军妖法，扒开辽兵用青石填塞的峪口，救出卢俊义；
   宋江随后取幽州，兀颜统军受命领兵，引出下回。

## 选定场面

二更前后，青石峪谷底。黑雾狂风刚散，星斗重现，卢俊义勒马立在谷底，仰看四面高崖，徐宁、索超在侧，五千疲惫军士
在后；卢俊义说就地歇一宵，明日再寻归路。具名卢俊义、徐宁、索超。选它是因地形（四面悬崖、一线星空）与“被困”
的处境一眼可见，不需要画任何伤亡。三处依据：

- 「约莫二更前后，方才风静云开，复见一天星斗。」
- 「四面尽是高山，左右是悬崖峭壁」
- 「且就这里权歇一宵，暂停战马，明日却寻归路。」

先后核对：宋江追贺统军被截成两段（前）→天昏地暗、黑雾遮天，卢俊义急引一支军马杀出（前）→闻前面銮铃声，
入山口，狂风走石（前）→二更前后风静云开，复见星斗，众人见四面高山（此刻）→卢俊义下令就地歇一宵（此刻）
→白胜被派从山顶滚下报信（后）→宋江点军不见卢俊义，派解珍、解宝探路（另一条线，后）→次日宋军攻峪口，
峪口原来被辽兵用大块青石塞住（更后）。此刻黑雾与狂风已散，仅可留几缕残云；卢俊义一军不知峪口被封，
也没有解珍、解宝、刘氏兄弟、两株大柏树和白胜。

## 器物与环境

- 地点：青石峪，“只有一条路入去，四面尽是悬崖峻壑的高山”；谷底宽度本回未写，兜底：足容五千军马歇息的一片
  平地（解珍说“也得好一片地来排陷他”）。史实上无此地名，一说由《读史方舆纪要》的“青石岭”改写（据摘要），按原文画。
- 时令天气：前文七月半后留军避暑，时令本回未写，兜底：初秋晴夜。刚散的黑雾只留崖顶几缕残云，满天星斗，不画月。
- 器物：战马、枪、斧、钩镰枪、铁盔铁甲。宋代步人甲为兜鍪、披膊、身甲、吊腿的札甲（据摘要）；高桥鞍与双镫沿用
  （宋代鞍具专条未检得）。
- 现实中会动的：① 星光闪烁；② 战马鬃毛、尾巴摆动，马头轻点；③ 崖顶残云缓慢飘散。人物不整体位移。

## 排除项

- 后拍：白胜裹毡衫滚下山、解珍解宝披虎皮袍探路、刘二刘三兄弟煮獐子肉、宋江取玄女课、青石峪口两株大柏树与
  青石封路、林冲刺贺拆、李逵砍贺云、公孙胜破妖法、贺统军战死。前拍：黑雾狂风、辽军伏兵、宋江与贺统军阵前交锋。
- 独鹿山是宋江屯军处（平地可厮杀），不是困卢俊义的地方，不画成山顶对峙；崖顶不画辽兵（原文未写）。
- 不画夜间篝火营地（原文无）；不画影视铠甲和戏曲靠旗；辽军仅在文字中出现，画面不出现辽人。
