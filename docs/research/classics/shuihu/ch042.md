# 《水浒传》第42回 还道村受三卷天书　宋公明遇九天玄女

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第042回>；读取日期：2026-10-20。

## 情节要点

1. 宋江要回家接父亲，晁盖劝不住；宋江只身戴毡笠，提短棒、佩利刃下山，回宋家村，宋清说官府已派赵能、赵得
   盯住，宋江连夜逃走，被追到还道村。
2. 宋江躲进荒庙神厨，赵能、赵得带土兵举火把搜庙，神厨前卷起阴风吹灭火把，殿后又起怪风，土兵惊退。
3. 两个青衣女童来请“星主”，引宋江过石桥、棂星门入后宫；玄女殿上赐三杯酒、三枚枣，授三卷天书和四句天言，
   命他“替天行道”，嘱“功成之后便可焚之”。
4. 宋江醒来仍在神厨，手里三枚枣核，袖里有天书，庙额是“玄女之庙”。
5. 天明，李逵等杀散土兵，宋江与晁盖会合，接回宋太公；公孙胜辞行，李逵哭着要接母亲（下回接续）。

## 选定场面

夜，玄女殿上：九天玄女坐在殿正中七宝九龙床上，珠帘卷起，龙灯凤烛；宋江在阶前再拜，低头不敢直视；一个青衣
螺髻女童双手捧玉盘，盘中黄罗袱子包着三卷天书，递到宋江面前；殿两边青衣女童持笏捧圭、执旌擎扇。酒已饮毕，
宋江手里握着三枚枣核。具名九天玄女、宋江。三处依据：

- 「青衣去屏风背后，玉盘中托出黄罗袱子，包着三卷天书，度与宋江」
- 「正中七宝九龙床上，坐着那个娘娘」
- 「宋江看时，可长五寸，阔三寸，厚三寸，不敢开看」

先后核对：神厨躲藏、阴风灭火把（前）→青衣女童请“星主”，过青石桥、朱红棂星门入殿（前）→饮三杯酒、食三枚
枣，“怀核在手”（前）→宋江辞酒，娘娘命取天书（紧邻之前）→青衣从屏风后托出天书，度与宋江（此刻）→宋江
“再拜祗受，藏于袖中”（紧随，不画）→四句天言与嘱咐（后）→石桥看二龙戏水，被推落，醒在神厨（后）。

## 器物与环境

- 地点：还道村“团团都是高山峻岭，山下一遭涧水，中间单单只一条路”；荒败的玄女庙是现实层，蛛网、折臂小鬼、
  无幞头判官。题面画梦中宫殿：青石桥朱栏杆，朱红棂星门，龙墀月台，殿“金钉朱户，碧瓦雕檐”“窗横龟背，帘卷虾须，
  皓月团团悬紫绮”，殿上“金碧交辉”，两边朱亭柱挂绣帘。棂星门形如乌头门，宋代用于祠庙（据摘要）。
- 时令天气：夜；入村时月色朦胧，后“风扫薄云，现出那轮明月”；醒时“月影正午，料是三更”。月份未写，兜底：夜景，
  不画雪与落叶。
- 器物：七宝九龙床、屏风、珠帘金钩、锦墩、龙灯凤烛、玉杯宝瓶、仙枣盘、笏圭旌扇、玉盘、黄罗袱子。
- 现实中会动的：① 龙灯凤烛火焰摇曳；② 珠帘、旌旗与女童“带飞真紫”的衣带轻摆；③ 窗纱在“香风冉冉”中微动。

## 排除项

- 后拍：四句天言、二龙戏水、被推落、醒在神厨摸出天书；赵能被杀、李逵赤膊双斧。前拍：赵氏兄弟搜庙、阴风灭火把、
  青衣在神厨外相请。
- 荒庙（蛛网、泥塑小鬼）与梦中宫殿不同层，不同画；玄女只有一位，殿上不加他神。
- 玄女不画人首鸟身、凤冠霞帔、手持宝剑；青衣不画男童；宋江不戴枷、不持棒。
- 天书不展开，不画线装册页，不画满页可读文字。
