# 《水浒传》第55回 高太尉大兴三路兵　呼延灼摆布连环马

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第055回>；读取日期：2026-10-20。

## 情节要点

1. 高俅听呼延灼举荐，调陈州团练韩滔（枣木槊）、颍州团练彭玘（三尖两刃刀）为先后锋；在甲仗库领铁甲三千副、
   熟皮马甲五千副，三路兵马自汝宁州出发，直奔梁山泊。
2. 宋江分五阵轮战：秦明、林冲、花荣、扈三娘、孙立；扈三娘用红锦套索擒彭玘；呼延灼与孙立双鞭对斗三十余合。
3. 官军收队时才显出“连环马官军”：人披铁铠、马披甲，箭射不入，宋江鸣金收军。呼延灼夜议：三千马军每三十匹
   一连，用铁环连锁，分一百队，三面冲阵；次日梁山军大溃，宋江由水军接应上船，中箭者六人。
4. 呼延灼求炮手凌振，凌振在水边架炮，被李俊、张横诱上船，阮小二水底擒住，上山入伙。
5. 汤隆献计，说须一种军器和他的哥哥才能破连环马（下回接续）。

## 选定场面

次日清晨，梁山泊外平原旷野，呼延灼阵中：约一千步军在前擂鼓呐喊，其后三千甲马按每三十匹一连、铁环连锁，
一字摆开；人披铁铠只露双眼，马披熟皮重甲带朱缨只露四蹄；呼延灼骑踢雪乌骓，与韩滔立在马队之后“押后掠阵”，
双鞭垂握，连环马尚未放出。具名呼延灼、韩滔（韩滔作侧影）。该刻能同时交代连环马的连锁与甲式，无人受伤。
三处依据：

- 「每三十匹一连，却把铁环连锁」
- 「马带甲，只露得四蹄悬地；人披铠，只露着一对眼睛」
- 「明日休得挑战，我和你押后掠阵」

先后核对：首日呼延灼与孙立斗鞭，收军后才点明连环马（前，不画）→夜议“每三十匹一连”（前）→次日宋江见对阵约一千
步军擂鼓发喊、无人出马（此刻）→连珠炮响，步军分两下，放出三面连环马直冲（后）→宋江逃至水边（后）。此刻呼延灼
在队后，不在冲锋行列；第二日原文未写鞭在手或挂鞍，兜底垂握，不抡不击。

## 器物与环境

- 地点：梁山泊外“平原旷野之处”，近山坡（第55回）；不画水泊内景。
- 时令：“此时虽是冬天，却喜和暖”；次日天晓列阵。兜底：冬晨，天色晴和，不画雪。
- 器物：铁环（锁连环马，环形制未写，兜底：粗铁环链相扣马具）；朱缨、铜铃、弓袋（“飞鱼袋”）、雕翎箭；红旌旗。
- 现实中会动的：① 前列步军手臂擂鼓、鼓槌起落；② 红旌旗在风中飘；③ 马缨、马尾、鬃毛与铜铃轻摆。

## 排除项

- 后拍：连珠炮响、步军分开、连环马冲阵、宋江逃走、乱箭；不画冲撞与受伤。前拍：首日秦明、林冲、花荣、
  扈三娘擒彭玘、孙立对斗。
- 孙立的装束不要混入：交角铁幞头、大红罗抹额、百花点翠皂罗袍、竹节虎眼鞭、乌骓；呼延灼是冲天角、黄抹额、
  八棱水磨鞭。梁山军的甲马“只是红缨面具、铜铃雉尾”，不是披甲，勿画雉尾于官军马上。
- 他回：钩镰枪（第56、57回）、凌振火炮、第57回败逃。
- 与史实：金军“拐子马”三马相连之说出自岳珂、汪若海一系，有争议；本回为“每三十匹一连”，不改成三匹。
- 不用京剧呼延灼脸谱与戏曲扎靠，不套用影视剧造型；不把鞭画成竹节鞭。
