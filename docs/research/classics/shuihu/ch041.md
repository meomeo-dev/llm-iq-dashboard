# 《水浒传》第41回 宋江智取无为军　张顺活捉黄文炳

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第041回>；读取日期：2026-10-20。

## 情节要点

1. 白龙庙众好汉击退追兵，乘船回穆弘庄上；宋江要报黄文炳之仇，晁盖主张回山，宋江坚持；薛永带来在黄家做
   裁缝的侯健，探明无为军路径。
2. 宋江定计：备沙土袋、芦柴、大小船只，白胜、侯健、薛永先潜入城内，石勇、杜迁扮丐者守城门；黄文炳之兄
   黄文烨是善人，不可侵害，也不得扰百姓。
3. 七月尽夜，船到无为军江岸，沙土袋、芦柴堆上城墙；侯健开菜园门，薛永放火，众人杀入黄宅，不见黄文炳。
4. 黄文炳在江州见火起，乘官船回无为军；李俊乘小船搭钩上船，张顺从水中擒住黄文炳，解到穆庄（后接绑树
   割肉，不画）。
5. 众人分五起赴梁山，途经黄门山收欧鹏等四人，上山后宋江说起要下山办一件大事（下回接续）。

## 选定场面

夜，江心，无为军北门方向火光映红江面：黄文炳乘的官船被一只小船直撞过来，船上李俊手拿挠钩搭住官船
船舷、正跳过来；黄文炳听到“正烧着哩”，已奔到船梢，要踊身入江；艄公与从人惊慌；水面下张顺
的白影正从水底钻来，尚未碰到黄文炳。具名黄文炳、李俊、张顺。三处依据：

- 「那汉听了，一挠钩搭住了船，便跳过来」
- 「便奔船梢后走，望江里踊身便跳」
- 「水底下早钻过一个人」

同句下半“把黄文炳劈腰抱住”是下一拍，不画。先后核对：黄文炳在江州见火辞知府、乘官船（前）→到江心，
一只小船摇过，另一只直撞来，李俊自称“去江州报失火的船”（前）→黄文炳失口叫苦（前）→李俊搭钩跳过船，
黄文炳奔船梢欲跳，水底下早有人钻来（此刻）→张顺劈腰抱住，揪起扯上船，麻索绑缚（后）→李俊放官船走（后）。

## 器物与环境

- 地点：江州与无为军之间的江面。小说写两地隔江相望；实地无为军在今安徽无为县，与九江相距约250公里
  （据摘要），不画真实地标。江北岸城中北门里火起，“蒸天价红”。
- 时令天气：“七月尽天气，夜凉风静，月白江清”（出发时）；初更前后到无为岸边，二更放火；火起后“映得江面上都红”。
  兜底：夜，火光倒映江面，岸上远处浓烟，天上有月。
- 器物：官船（知府所派，比小船大，艄公摇船）；两只小船；挠钩；麻索（后）。
- 现实中会动的：① 火光倒影随波起伏；② 挠钩搭住后官船微晃、船尾水波；③ 远处城头火焰与浓烟升腾。

## 排除项

- 后拍：张顺劈腰抱住、扯上船、麻索绑缚；解到穆庄、绑柳树、李逵割肉炙烤（血腥）；放火杀黄家四五十口。前拍：
  穆庄议事、叉袋芦柴上城、侯健开菜园门。
- 张顺不掀翻官船（原文无此情节），不持叉、刀；黄文炳此刻不在水中、不被绑。
- 李逵、宋江、晁盖不在此船；无为军城内杀人场面不画。
- 他回装束：第38回张顺的竹篙渔船与白布衫，第40回张顺的五股叉，第42回宋江的毡笠短棒。
