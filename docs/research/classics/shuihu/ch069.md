# 《水浒传》第69回 东平府误陷九纹龙　宋公明义释双枪将

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第069回>；读取日期：2026-10-20。

## 情节要点

1. 宋江与卢俊义拈阄，宋江取东平府，卢俊义取东昌府；三月初一下山，宋江驻军安山镇，派郁保四、王定六下战书，被都监董平打回。
2. 史进自愿进城做细作，被李瑞兰家出首擒获；吴用遣顾大嫂扮乞婆入牢传信，史进误记月尽夜，二十九日夜提前越狱闹牢。
3. 董平四更出城袭宋江寨，天明两军列阵；董平先后迎战韩滔、徐宁，与徐宁斗五十合不分胜负，追入阵中被围，杀到申牌才冲出。
4. 程太守不肯许女，董平心中有隙；他追宋江到寿春县界的村镇，中绊马索被擒，宋江亲解其缚、脱锦袍相披，董平归降。
5. 董平赚开城门，杀程太守一家、夺其女；宋江开牢救出史进，取府库钱粮（杀人处不画）；白胜来报东昌府战事。

## 选定场面

三月末天色方明，安山镇外两军列阵。董平出马立于阵前，骑战马，头戴白色水磨凤翅盔，穿锼银铁铠、
青色锦绣麒麟战袄，箭壶里插一面小旗，上写“英雄双枪将，风流万户侯”；宋江在对阵门旗下望见，一见便喜。尚未交手，
具名董平、宋江（远处）。出马时双枪是否在手原文未写，兜底：双手各持一杆，枪尖朝上。三处依据：

- 「两下摆开阵势，董平出马」
- 「宋江在阵前看了董平这表人品，一见便喜」
- 「又见他箭壶中插一面小旗，上写一联道：“英雄双枪将，风流万户侯。”」

先后核对：董平四更上马，奔宋江寨（前）→天色方明，两下摆开阵势，董平出马（此刻）→宋江看人品，见箭壶小旗（此刻）→
宋江遣韩滔出马，董平双枪迎战（后）→徐宁替回，五十合不分胜负（后）。联句写在箭壶里的小旗上，不在背后大旗上。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 董平 | 河东上党郡人，东平府兵马都监，号“风流双枪将”，通音律。赞诗：“两面旗牌耀日明，锼银铁铠似霜凝。水磨凤翅头盔白，锦绣麒麟战袄青。一对白龙争上下，两条银蟒递飞腾”（后两句指双枪或衣甲纹饰，原文未明说，兜底：枪杆缠银色龙蟒纹）；箭壶中一面小旗，旗色本回未写，兜底：小黄旗金字（第78回写作两面小黄旗各五字）。双枪长短、坐骑毛色、年岁、面貌本回未写，兜底：枪长常规；坐骑深色单色马，不用白马；青壮年，面容端正 | 第69回 |
| 宋江 | 黑矮；脸上刺字（“金印”指刺在面颊上的字，不是金色印章；同回董平骂“文面小吏”）；衣着未写，兜底：战袍、头巾，在门旗下勒马，只作远景 | 第68、69回 |

## 器物与环境

- 地点：东平府城外四十里的安山镇一带。东平府由北宋郓州于宣和元年升格，治所在今山东东平县（据摘要）；小说写法
  与史实基本相合，不画真实地标。
- 时令天气：三月（农历，暮春），出发时“日暖风和，草青沙软”；此刻是史进越狱当夜之后的黎明（三月二十九夜至三十日晨），“天色方明”。兜底：晨光微亮，草地，
  无雨无雪。
- 器物：双枪（原文“双枪”“铁枪”，影视多用短枪，明代插图无一致画法，据摘要）；水磨凤翅盔（宋代凤翅盔两侧展翅、顶有缨，
  据摘要）；锼银铁铠；两面旗牌；箭壶与小旗；宋江一侧门旗与鼓。
- 现实中会动的：① 箭壶小旗与两面旗牌随风飘动；② 盔缨与枪缨摆动，马鬃马尾飘；③ 晨光中的薄雾缓缓流动，马蹄下尘土。

## 排除项

- 后拍：韩滔、徐宁出战；董平追入阵被围；绊马索擒获；宋江脱袍亲解其缚；赚城门、杀程太守一家、夺其女（杀人处不画）。
  前拍：郁保四、王定六被打；史进进城、李瑞兰（妓家）告发、被擒、越狱、顾大嫂入牢。
- 不画史进、李瑞兰、程太守之女；此刻董平没有被擒、没有穿宋江的锦袍。
- 他回：第78回董平在箭壶旁插“两面小黄旗”、各五个金字，本回只一面写整联；第70回董平提双枪斗张清。
- 不用京剧《东平府》（据摘要）的勾脸、扎靠；不用影视短枪造型。
