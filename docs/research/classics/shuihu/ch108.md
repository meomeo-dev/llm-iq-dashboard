# 《水浒传》第108回 乔道清兴雾取城　小旋风藏炮击贼

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第108回>；读取日期：2026-10-20。

## 情节要点

1. 杨志、孙安、卞祥追奚胜深入，被伏兵赶进鞍豂谾谷中围困；次日解宝、邹渊、邹润寻到谷口，搬开木石救出。
2. 卢俊义败杜壆；贼将寇烕（“毒焰鬼王”）用妖火烧宋军，乔道清以三昧神水破之。夜里乔道清起雾，
   宋兵乘雾攀城夺西京，龚端、奚胜被杀。
3. 宋江在荆南病倒；萧让、裴宣、金大坚被守将梁永擒获，本城书生萧嘉穗写揭帖聚民，杀梁永，
   开城迎吴用，救出三人后离去。
4. 宋江大军到南丰地界。先一日，柴进、李应护粮草到龙门山南麓村庄，得知縻貹夜里来劫粮，柴进用柴薪车与火炮
   设伏，縻貹一万人马大败。

## 选定场面

龙门山南麓村庄的草房边，黄昏，东北风大作、浓云如墨：柴进（“小旋风”）站在村中空地上指点军士，
把柴薪车摆到西南下风头的草房茅檐边，再把火炮藏进车中的粮米与干柴底下。具名柴进，军士为群像。
选它因回目“小旋风藏炮击贼”，且点火、爆炸与伤亡都在后面，此刻只有布置，没有火。“小旋风”是柴进的绰号
（原文“小旋风柴进”），不是李逵（黑旋风）。同回的乔道清兴雾取城是另一可选场面，未选，避免与第105回
的乔道清作法重复。三处依据：

- 「是晚，东北风大作，浓云泼墨」
- 「却留下百十辆柴薪车，四散列于西南下风头草房茅檐边」
- 「各处藏下火炮，及铺放硫黄焰硝灌过的干柴」

先后核对：柴进、李应到村庄，天色已暮，拆门扇把粮车推进屋里（前）→薛永捉奸细来报，縻貹二更来劫粮（前）→
柴进定计，李应领兵三千护真粮车，黄昏时出土冈向南先行，柴进留下柴薪车与空车，藏炮铺柴（此刻）→
施恩等埋东路口，单廷珪守南路口，柴进与魏定国领三百人带火种上山林埋伏（紧后）→二更縻貹入庄，山上射下火箭火把，
柴车草房着火，火炮炸响（后）。此刻李应与真粮车已离开，没有火，没有贼兵。

## 器物与环境

- 地点：龙门山南麓下傍山的一座村庄，四围高泥冈子如土城，三面有路出入，居民避兵迁走，空下草瓦房数百间；
  龙门山两崖对峙如门，树木丛密。宋代乡村土围布局未检得，兜底：村中土路，数座茅顶草房，村口有土冈缺口，
  远处两山对峙。
- 时令天气：本回上文写“此时已是深秋天气”；黄昏，东北风大作，浓云泼墨，军士恐下雨沾湿粮草，但未下雨。
  兜底：天色将暮，暗云低压，不画雨，不画月。构图约定：上北下南，东北风自画面右上吹向左下，
  草房与柴车在画面左下方。
- 车辆：柴薪车百十辆，空车百十辆、五六处结队、上面略放些粮米。宋代载货大车有双轮“太平车”“平头车”
  （据摘要），军用辎重车形制未检得，兜底：双轮木板车，车厢无盖，柴束堆高，空车上放几袋粮米。
- 火炮：形制本回未写。宋代火药武器有纸壳霹雳炮、铁壳震天雷、火球，均需药线引爆（据摘要）；兜底：
  拳头至人头大的球形纸壳或陶壳火药包，外缠麻绳，露出一小段药线，半埋在柴束与粮袋之间。
  “硫黄焰硝灌过的干柴”画成色泽略黄的柴束。
- 现实中会动的：① 浓云与茅檐草屑顺东北风向画面左下流动；② 军士搬柴束、抬火炮入车的往复动作；
  ③ 柴进的袍摆与巾带随风飘动。人物不整体位移。

## 排除项

- 后拍：縻貹来劫、山上火箭火把、柴车草房着火、火炮炸响、縻貹之死；前拍：薛永捉奸细、李应请战、
  拆门扇把粮车推进屋里。同回其他场面不画：鞍豂谾救杨志、寇烕妖火与三昧神水、乔道清兴雾取西京、
  萧嘉穗聚民救萧让。
- 此刻不画点燃的火把、火焰、爆炸、烟、贼兵与尸体；不画李应、魏定国、单廷珪、薛永、施恩（已先行或另有部署）。
- “小旋风”不画成旋风或龙卷风；柴进不画成李逵（黑旋风），不持斧，不画黑脸。
- 火炮不画成明清铜铁管炮、现代炸药包或地雷。
