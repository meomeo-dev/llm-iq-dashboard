# 《水浒传》第2回 王教头私走延安府 九纹龙大闹史家村

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第002回>；读取日期：2026-10-19。

## 情节要点

1. 高俅发迹为殿帅府太尉，记旧仇，要治禁军教头王进；王进携母夜走延安府，途中借宿史家庄。
2. 王进指出庄主之子史进的棒法“有破绽”，比棒时一绞绞落史进之棒，史进倒地拜师，学艺半年，王进辞去。
3. 史太公亡故后，史进闻少华山朱武、陈达、杨春聚众，约庄户闻梆相救。
4. 陈达率百余喽啰下山，史进披挂上马迎于村北路口，二人马上对答，交马后史进把陈达挟下马擒回；
   朱武、杨春来请死，史进义释三人，从此往来。
5. 中秋之约被猎户李吉告发，华阴县尉围庄（下回接续）。

## 选定场面

村北路口，史进与陈达两马相对，刀矛未交：史进说“你问得我手里这口刀肯，便放你去”，陈达大怒，
史进尚未抡刀骤马。具名史进、陈达，身后可有庄户、喽啰群像。理由：回目下联“九纹龙大闹史家村”
的正面一幕，两人披挂、兵器、坐骑原文写得最全，无人受伤。不取王进教棒：史进当时赤膊。

- 「小喽啰两势下呐喊，二员将就马上相见。」
- 「你问得我手里这口刀肯，便放你去。」
- 「陈达大怒道：『赶人不要赶上，休得要逞精神！』」

先后核对：陈达摆开人马→二将马上相见→陈达欠身施礼（开口前）→对答→史进说“这口刀肯”→陈达大怒
（此刻）→史进抡刀骤马，陈达拍马挺枪，交马（后）→史进卖破绽，挟陈达下马（后）。欠身已过，不再画。

## 器物与环境

- 地点：华阴县少华山下史家村北路口，陈达人马飞奔到“山坡下”摆开；庄上以梆子召集庄户。
- 时令：日期未写；承接李吉六月中旬报信（“炎天正热”）之后不久，按夏季处理（推断）；白昼，天气未写。
- 器物：三尖两刃四窍八环刀，是刀不是枪；丈八点钢矛；弓箭；比棒一节王进取“枪架上”的棒，史进用自己的棒，
  均为木棒，此刻不画。
- 现实中会动的：① 战马鬃尾与喷出的鼻息；② 头巾带、膊带与衣襟；③ 后列庄户枪棒晃动与脚下扬尘。

## 排除项

- 后一刻：抡刀骤马、交马；史进卖破绽、挟陈达下马、绑缚；欠身施礼（前）。
- 同回他场面：王进教棒（史进赤膊）；高俅蹴鞠；朱武、杨春步行下跪（史进下马）；围庄火把（回末）。
- 他人他回：朱武（棕叶道服、鹿皮云冠、双刀）、杨春（大杆刀）此时在山寨；第3回史进行装（白范阳毡大帽、
  雁翎刀、朴刀）；第5回周通同样“干红凹面巾”、骑白马，但绿罗袍、红搭膊、插花不可混入陈达。
- 兵器：不画朴刀、戟或枪；不画成二郎神式三尖刀；戏曲靠旗、武生扮相不取。
