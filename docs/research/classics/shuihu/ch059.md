# 《水浒传》第59回 吴用赚金铃吊挂　宋江闹西岳华山

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第059回>；读取日期：2026-10-20。

## 情节要点

1. 鲁智深被贺太守拿下，戴宗报到梁山，宋江点三队七千人马到少华山；探华州城，见城高壕深，无计可施。
2. 得知殿司太尉宿元景捧御赐“金铃吊挂”从黄河入渭河，去西岳降香；吴用定计，李俊、张顺在渭河口夺船，花荣等伏岸，
   宋江、吴用下船拦住官船，请太尉上山，借御香、仪从和金铃吊挂。
3. 小喽啰扮太尉，宋江、吴用扮客帐司；到西岳庙，吴用给推官看金铃吊挂，赚贺太守入庙，解珍、解宝动手，庙内杀人，
   梁山军入华州救出史进、鲁智深（后拍，不画）。
4. 少华山四人入伙；朱贵报芒砀山樊瑞等欲吞梁山，史进请战，败于项充、李衮的蛮牌；宋江、公孙胜领兵赶到（下回接续）。

## 选定场面

渭河渡口，次日天明：宋江一方的大船当港截住宿太尉的官船，宿太尉被迫出到船头椅上坐定，宋江手执骨朵，在自己船头
躬身唱喏；吴用立在船头，朱仝、李应各执长枪立在二人背后，岸上花荣等引马军搭弓列队，艄公已钻入舱，虞候二十余人
立在官船上。具名宋江、吴用、宿太尉。双方剑拔弩张而未动手，无人落水。三处依据：

- 「宿太尉只得出到船头上坐定」
- 「宋江执着骨朵，躬身声喏」
- 「朱仝、李应各执长枪，立在宋江、吴用背后」

先后核对：夺船，花荣等伏岸，宋江、吴用、朱仝、李应下船，李俊、张顺、杨春把船藏在滩头（前）→天明，三只官船到，
黄旗，被当港截住；虞候喝问，吴用立船头答话（前）→朱仝招动枪上小号旗，岸上马军搭弓列队，艄公钻舱，客帐司入禀（前）→宿太尉
出到船头坐定，宋江躬身唱喏（此刻）→宋江请太尉上岸，太尉拒绝（紧接）→李应一招，李俊、张顺撑船出来，掣刀跳过船，
把两个虞候颠下水（后）。此刻李俊、张顺及其船仍藏在滩头，不入画。

## 器物与环境

- 地点：渭河渡口（太尉“从黄河入渭河而来”）；官船三只，艄公；宋江一方在河口夺下十余只大船。
- 时令：前一日在华州城外是“二月中旬”“月华如昼”；此刻次日天明。兜底：早春清晨，河面微雾，岸边芦苇与柳，不画花。
- 器物：官船上插一面黄旗，旗上书“钦奉圣旨西岳降香太尉宿元景”（旗字不要求画出）；骨朵，宋代《武经总要》载有蒺藜、
  蒜头两种铁头骨朵（据摘要），兜底：短柄蒜头铁骨朵；长枪与小号旗；弓箭。
- 金铃吊挂：此刻在船舱，不入画。原文形制备后用：一对，“浑金打就，五彩妆成”，双悬缨络金铃，上挂珠玑宝盖，黄罗
  密布，中间八爪玉龙盘，紫带低垂，外壁双飞金凤，对嵌珊瑚玛瑙，围琥珀珍珠，碧琉璃掩映绛纱灯，中点碗红纱灯笼，
  是圣帝殿上正中所挂。
- 现实中会动的：① 河面水波与船舷拍浪；② 黄旗与小号旗随风飘；③ 岸边芦苇、柳条摆动。

## 排除项

- 后拍：李应招枪、李俊张顺撑船露刃跳船、虞候落水、请太尉上岸上山、假太尉与金铃吊挂入庙、贺太守被杀、庙内杀人
  （均不画）。前拍：少华山看华州城、夜望西岳。
- 此刻不拔刀，不射箭，无人落水；李俊、张顺不入画；金铃吊挂不入画。
- 他回人物：鲁智深、史进（在狱中）；朱武等三人（在山上）；戴宗、石秀、武松（庙内）。
- 宿太尉不画戏曲官衣、髯口与玉带朝冠；吴用不画羽扇纶巾（诸葛亮式）。
- 西岳庙现存建筑多属明清（据摘要），题面不画；也不画华山全景。
