# 《水浒传》第44回 锦豹子小径逢戴宗　病关索长街遇石秀

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第044回>；读取日期：2026-10-20。

## 情节要点

1. 李逵与李云在路旁斗了五七合，朱富劝住；李云随朱贵、朱富上梁山入伙，李逵归还板斧。
2. 宋江遣戴宗扮承局去蓟州寻公孙胜，路上遇“锦豹子”杨林，同到饮马川，结识邓飞、孟康、裴宣，三人愿入伙。
3. 蓟州街上杨雄行刑回来，众人拦路把盏，军汉踢杀羊张保一伙抢走花红缎匹、揪住杨雄；挑柴的石秀路见不平，
   打翻张保一伙；戴宗、杨林请石秀饮酒，赠银十两。
4. 杨雄带人寻来，两人结拜（杨雄二十九岁，石秀二十八岁）；杨雄丈人潘公请石秀开肉铺，杨雄之妻潘巧云出见。
5. 两个多月后“秋残冬到”，石秀买猪回来，见铺面收了，疑心嫂嫂说话，结账要辞行（下回接续）。

## 选定场面

蓟州大街路口：杨雄刚从市曹行刑回来，被道贺的人拦路把盏，张保一伙抢了花红缎匹，张保劈胸揪住他，背后两个军汉
拖住他的双手，他动弹不得；挑着一担柴的石秀走来，放下柴担，分开众人上前劝话，还没出手。具名杨雄、石秀、
张保。两位后来的结义兄弟在此同框，杨雄的花绣、簪花、背心有原文可画，冲突止于出手之前，无血。三处依据：

- 「杨雄被张保并两个军汉逼住了，施展不得，只得忍气，解拆不开。」
- 「那大汉看了，路见不平，便放下柴担，分开众人，前来劝道」
- 「被张保劈胸带住，背后又是两个来拖住了手」

先后核对：市心决刑回，被挂红道贺、拦路把盏（前）→张保从侧首小路撞出，借钱，争吵（前）→一哄抢走花红缎子
（前）→杨雄欲打抢物者，被张保劈胸带住，背后两人拖手，小牢子各自回避（此刻之前）→石秀放下柴担，分开众人劝
“你们因甚打这节级”（此刻）→张保骂“饿不死冻不杀的乞丐”（后）→石秀劈头一提，一拳一个，杨雄脱身（后）。

## 器物与环境

- 地点：蓟州城内大街路口，侧首有小路通小巷。蓟州在北宋属辽，小说照宋内地写（据摘要），不画辽人装束。
- 时令：本回未写；石秀入杨雄家两个多月后才“秋残冬到”，故此时约在秋季。兜底：晴日白天，不画雪。
- 器物：花红缎匹（红彩与缎子，已被抢）；柴担（担子两头柴捆，放在地上）；杨雄鬓边簪花（宋代男子簪花成风，
  据摘要）；背心上“刽”字；青罗伞、鼓乐、鬼头靶法刀属迎送一拍，此刻不画。
- 现实中会动的：① 被抢夺拉扯的红绸、缎匹随手飘动；② 杨雄鬓边芙蓉与衣摆随拉扯晃动；③ 脚下尘土被踩起。

## 排除项

- 后拍：石秀劈头一提、一拳一个、杨雄追打；戴宗、杨林邀入酒店；结拜；潘巧云出见。前拍：行刑、鼓乐迎送。
- 戴宗、杨林是路边旁观者，不入画；小牢子已回避，不画。
- 杨雄不画成红脸或黑脸的戏曲花脸扮相，不留长髯；石秀不穿戏曲箭衣、软罗帽、对门坎肩（据摘要）。
- 红衣刽子手、鬼头刀多来自戏剧，宋代服制无专门记载（据摘要），故只取原文的红衫与“刽”字背心。
- 他回物件：石秀的解腕尖刀（第45回）、肉案作坊、新衣，不画。
