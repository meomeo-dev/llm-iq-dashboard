# 《水浒传》第67回 宋江赏马步三军　关胜降水火二将

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第067回>；读取日期：2026-10-20。

## 情节要点

1. 梁山军押李固、贾氏回山，宋江要让位卢俊义，众将不允；宋江大排筵宴犒赏马步水三军（后接堂上处死二人，不画）。
2. 梁中书求援，蔡京举荐凌州团练使单廷珪（“聖水将军”，善水浸兵法）与魏定国（“神火将军”，精熟火攻）；关胜自请带五千兵
   与宣赞、郝思文先赴凌州，林冲、杨志、孙立、黄信随后接应。
3. 李逵私自下山，杀韩伯龙，遇焦挺，二人投枯树山找鲍旭。
4. 关胜与单、魏两军阵前相会；宣赞、郝思文追敌入阵，被黑旗黑甲、红旗红甲步军用挠钩套索擒走，李逵等在途中劫下陷车。
5. 次日单廷珪被关胜用刀背拍落马，投降；魏定国放火兵火车败关胜，后凌州被李逵等攻破，关胜单骑入中陵县招降魏定国。
6. 回到金沙滩，段景住来报失马，引出下回。

## 选定场面

凌州城外，两军“旗鼓相望”。关胜在自家门旗下勒马开口；对阵“聖水将军”单廷珪（黑）与“神火将军”魏定国（红）各打
本方大旗，一齐出到阵前，大笑，伸手指着关胜骂。具名关胜、单廷珪、魏定国。二将一黑一红、旗号各七个银字，原文用“但见”
韵文逐件交代装束，且双方尚未动手，适合入画。三处依据：

- 「两员虎将一齐出到阵前。」
- 「关胜见了，在马上说道：“二位将军，别来久矣！”」
- 「单廷珪、魏定国大笑，指着关胜骂道」

先后核对：两军相近，关胜出马（前）→单廷珪出马，前打皂纛旗（前）→魏定国出马，前打红绣旗（前）→二将出到阵前，关胜说
“别来久矣”，二将大笑指骂（此刻）→关胜劝降，二将“骤马齐出”，宣赞、郝思文出阵对杀（后）→二将佯败，黑旗黑甲、红旗红甲
步军以挠钩、套索擒人（后）。故此刻背景步军只作队列，不举挠钩套索；火兵、火车、铁葫芦要到第三次交战才出现，此刻没有。

## 器物与环境

- 地点：凌州城外两军阵前，有门旗、战鼓、魏定国马上鸾铃。凌州宋元明清无此建置，多疑为“陵州”之误，一说在今山东德州
  陵县一带（据摘要），不画真实地标。
- 时令天气：本回未写；第68回开头吴用说“即日春暖”，仅作旁证。兜底：晴天平川，不强调季节。
- 器物：皂纛旗（宋代纛旗黑底、黑火焰脚、朱红枪杆，据摘要）与红绣旗；关胜门旗；单廷珪弓箭与黑杆枪，魏定国熟铜刀与雕弓。
- 现实中会动的：① 皂纛旗、红绣旗与门旗在风中飘动；② 盔顶黑缨、赤缨和关胜的长髯随风摆动；③ 马蹄下尘土与鼻息。

## 排除项

- 后拍：关胜劝降、宣赞郝思文出阵、挠钩套索擒人、关胜刀背拍落单廷珪、第三次交战的五百火兵、火车、铁葫芦、凌州城中起火。
  前拍：李逵杀韩伯龙、劫陷车。
- 此刻双方都没有火器、没有火烧伤人；黑旗黑甲军与红旗红甲军不混色，单廷珪的红衣红马是后文换阵时的事（据摘要），不画。
- 他回人物：林冲、杨志、孙立、黄信（接应，不在阵前）；李逵、焦挺、鲍旭（赞诗“狰狞丑脸如锅底”，易丑化，不画）。
- 不用京剧脸谱、门神画、影视剧造型；不画二将同色。
