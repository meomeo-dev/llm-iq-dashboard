# 《水浒传》第99回 花和尚解脱缘缠井　混江龙水灌太原城

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第099回>；读取日期：2026-10-20。

## 情节要点

1. 田虎得叶清申文，封“全羽”为郡马；宋江在昭德佯装怯战，各路将佐与水军头领陆续会集。
2. 卢俊义在汾阳被马灵（神驹子，金砖法，脚踏风火二轮）困住；公孙胜、乔道清来援，
   公孙胜破金砖法，马灵腾风火二轮逃走。
3. 鲁智深半路一禅杖打翻马灵，向戴宗讲述：在襄垣阵前坠入草丛中一穴，穴下别有天地，
   遇草庵和尚指点出路；他觉得才一会儿，外面已由二月下旬到了三月下旬。
4. 田虎亲征，卞祥与花荣等相持；连日大雨，李俊献策决智伯渠、晋水灌城。四月上旬，
   太原守将张雄登敌楼，见洪波怒涛飞至，回末。

## 选定场面

鲁智深在穴下异境的旷野里行了多时，见一座草庵，听得庵中木鱼声，走进去，看见一个与他一般的
和尚盘膝坐地念经。他尚未开口。具名鲁智深，另有无名和尚。选它是因全回唯一的静景，与回目
“解脱缘缠井”直接相扣，且只有一人一僧一庵，无杀伐。三处依据：

- 「只见一个草庵，听的庵中木鱼咯咯地响」
- 「洒家走进去看时」
- 「与洒家一般的一个和尚，盘膝坐地念经」

先后核对：襄垣阵前追琼英，不防草丛中有一穴，坠下；穴底旁又有一穴透出亮光（前）→ 经过有
村庄房舍的地方，人民见他都笑（前）→ 过了人烟辏集处，前面静悄悄的旷野，行了多时（前）→ 见草庵，
闻木鱼声，走进去，见和尚盘膝念经（此刻）→ 问出路，和尚答“来从来处来，去从去处去”，智深焦躁，
和尚讲三界之理，智深唱喏，和尚说“缘缠井”并领他出庵，指“前去可得神驹”，回头已不见（后）→
打翻马灵（后）。此刻没有对话、唱喏，也没有出庵。注意：原文是草丛中的“一穴”，“缘缠井”是
和尚的比喻，不是实物井；原文也未写和尚年老，“老僧”只是俗称。

## 器物与环境

- 地点：穴下异境，“一般有天有月，亦有村庄房舍”。村舍与人民在身后，前面是“静悄悄的旷野，
  无人居住”，草庵孤立在旷野上；背景可有远处村舍的小影。
- 草庵：“庵”本指茅草小屋（据摘要），宋代禅庵形制未检得；兜底：茅顶木柱土墙小屋，门洞敞开，
  门前一小块空地。
- 木鱼：唐诗已见“木鱼”，早期为长条鱼形，圆形木鱼出现时间说法不一（据摘要）；兜底：小型
  中空木鱼，配木槌。
- 时令天气：“有天有月”，昼夜未写，季节未写（“桃李只有恁般大叶”是出穴后汾阳城外的三月下旬）；
  兜底：天空澄净，一轮淡月，光线柔和，草地青绿，不画花，不画日轮。
- 现实中会动的：① 和尚持槌敲木鱼，木槌小幅往复（“木鱼咯咯地响”）；② 旷野草叶随风摆动；
  ③ 薄云缓缓掠过月面，智深直裰下摆轻晃。人物不整体位移。

## 排除项

- 后拍：和尚领出庵、指路、消失；打翻马灵；与戴宗同回汾阳；盘问时间差。前拍：坠穴、
  村舍里人民皆笑、阵上追琼英。同回他景：公孙胜破金砖法、马灵逃走、董平、花荣阵斩、
  李俊水灌太原、张横张顺杀张雄，均不画。
- 不画井口、辘轳；不画地狱、天堂、轮回的图像；不画神驹；不画和尚凭空消失。
- 鲁智深不画成醉态，不裸背，不披袈裟，不持戒刀杀人。
