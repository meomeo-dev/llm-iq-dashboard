# 《水浒传》第38回 及时雨会神行太保　黑旋风斗浪里白条

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第038回>；读取日期：2026-10-20。

## 情节要点

1. 宋江在点视厅见到索常例钱的节级，报出吴学究，节级便是戴宗；二人入城酒楼叙话，宋江交出吴用的书信。
2. 李逵来借银，宋江给十两，李逵拿去赌输，抢赌客银两，被戴宗、宋江截住；三人到琵琶亭饮酒，宋江想喝鲜鱼汤，
   李逵去江边讨活鱼。
3. 李逵拔竹篾放走渔船活鱼、打渔人；鱼牙主人张顺赶来，岸边初斗不分胜负；张顺脱衣撑船诱李逵上船，踏翻船
   底，二人落水，在江心相斗，李逵被浸得眼白。
4. 戴宗喊出张横家书，张顺放手，把李逵托上岸；四人在琵琶亭相认。回末李逵点倒卖唱女（下回接续）。

## 选定场面

傍晚，江州江边：船已翻扣在水里，张顺在江心把李逵提出水面、将要再按下去，两人腰以上露在清波外，水线处
可见张顺的水裩与李逵腰间的布巾；宋江、戴宗站在岸边叫苦；三五百人挤在岸边柳阴下观看。具名张顺、李逵、
宋江、戴宗。三处依据：

- 「只见江面开处，那人把李逵提将起来，又渰将下去」
- 「一个显浑身黑肉，一个露遍体霜肤」
- 「江岸边早拥上三五百人，在柳阴树下看」

先后核对：李逵脱布衫，“单系着一条棋子布手巾儿”，拿折竹篙赶打行贩（前）→拾布衫搭肩而走（前）→张顺脱去
衣巾，“匾扎起一条水儿”，撑渔船追骂（前）→李逵“撇了布衫”跳上船（前）→张顺点篙蹬脚，船射向江心，撇篙
拿住李逵臂膀，晃翻船底，两人落水（前）→宋江、戴宗赶到岸边，船已翻，“两个只在岸上叫苦”（紧邻此刻）→
江心提起、淹下（此刻）→戴宗喊出家书，张顺放手上岸，再下水托李逵上岸（后）→二人各讨回布衫穿上（后）。
两件布衫此刻都留在岸上；渔人已把船撑开离岸，不在水里。

## 器物与环境

- 地点：江州城外江边，琵琶亭“一边靠着浔阳江”；渔船原“一字排着，约有八九十只，都缆系在绿杨树下”，后被渔人
  撑开；岸边绿杨、柳阴。被踏翻的渔船船底朝天漂在江面；竹篙、折竹篙已弃，不入画。
- 时令天气：“五月半天气，一轮红日，将及沉西”，琵琶亭景写“拂拂凉风吹水面”。兜底：夏日傍晚，斜阳暖光，柳叶青绿。
- 现实中会动的：① 两人搅起的浪花与涟漪向外扩散；② 翻扣的渔船随波起伏微转；③ 岸边柳枝在凉风里摆动。

## 排除项

- 后拍：张顺托李逵上岸、李逵吐白水、二人穿布衫、琵琶亭相认、李逵点倒卖唱女。前拍：酒楼见节级、赌场抢银、
  琵琶亭鱼汤、竹篙乱打渔人、陆上初斗（张顺穿白布衫提行秤）。
- 李逵不持板斧（板斧、赤膊劫法场是第40回），不画第41回割肉；张顺不持叉、不衔刀（浮世绘有此画法，非原著）。
- 两人不全裸；戴宗不拴甲马、不画驾云神行；宋江不戴枷。
- 戏曲：李逵黑脸谱、白眼窝一类扮相不用。
