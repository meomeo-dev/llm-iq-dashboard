# 《水浒传》第78回 十节度议取梁山泊　宋公明一败高太尉

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第078回>；读取日期：2026-10-20。

## 情节要点

1. 戴宗、刘唐下山去东京探听；童贯败回，与高俅同见蔡京，议定谎称“炎热罢战”，高俅请为帅，要造船、水陆并进；酆美回京，
   说宋江放还被俘者。
2. 次日早朝，蔡京奏罢战，高俅自荐，天子赐锦袍金甲；高俅调十节度使各领兵一万到济州，又调江南水军统制刘梦龙、拘船的牛邦喜，
   帐下有党世英、党世雄，共十三万。
3. 戴宗、刘唐回报；吴用定计先惊他一阵，派张清、董平各带一千马军到济州近处截杀，水军准备夺船。
4. 高俅带歌儿舞女三十余人出师，初秋长亭饯别；王文德军在凤尾坡遇董平、张清，盔顶被石子打中，杨温救应。
5. 十路军到济州，高俅以州衙为帅府分兵；梁山军下山迎战，王焕出阵与宋江对话，林冲、呼延灼、董平先后交手；水路上刘梦龙水军
   被芦苇中的小船冲断，党世雄被张横活捉，高俅傍晚遇四面炮响。

## 选定场面

梁山泊下山不远的开阔地，两军对圆：官军先锋、河南河北节度使王焕在马上持长枪高叫；宋江在对阵绣旗开处亲自出马，
向王焕声喏，劝他年纪大了不要逞强、回去换年轻人来。具名宋江、王焕，另有两军阵列群像。选它是因为全回只有这一刻两位主将
隔阵相对、礼数与老少对比都在画面上，且双方都未动手。三处依据：

- 「只见先锋王焕出阵，使一条长枪，在马上厉声高叫」
- 「对阵绣旗开处，宋江亲自出马，与王焕声喏道」
- 「王节度，你年纪高大了，不堪与国家出力」

先后核对：高俅出师、凤尾坡截击、十路军会济州、帅府分兵（前）→宋江下山，两边拒定人马（前）→王焕出阵高叫（此刻前一拍）→
宋江出马声喏、劝退（此刻）→王焕大怒，骂“文面俗吏”，挺枪戳来（后）→宋江马后林冲鸾铃响出阵，战七八十合（后）→高俅
“自临阵前，勒住马看”（后）→荆忠、项元镇出战（更后）。此刻林冲未出，高俅未入画，王焕枪未刺出，宋江不持兵器。

## 器物与环境

- 地点：梁山泊下山不远的开阔地（原文：宋江“下山不远，早见官军到来”），远处隐约水泊与芦苇。
- 时令天气：高俅出京“时值初秋天气”，到济州后又过数日；天色未写，兜底：初秋晴昼，草木仍青，芦苇青绿（芦花多在深秋，据摘要推断）。
- 枪：《武经总要》的骑兵枪有单钩枪、双钩枪、环子枪，杆上系牛皮提绳（据摘要）；本回只写“长枪”，兜底：长杆枪，枪头下红缨，
  不画戏曲式挑枪亮相。
- 礼：宋代日常行揖礼、叉手礼，唱喏是揖礼配口中应声（据摘要）；马上行礼未检得，兜底：一手勒缰一手抱拳。
- 官制：宋代节度使多为虚衔（据摘要），小说中为带兵大将，不入画。
- 现实中会动的：① 两军旗帜随风飘动；② 两匹战马原地喷鼻、甩头、前蹄轻刨，鬃尾摆动；③ 枪头红缨、盔缨颤动，远处芦苇摇摆。
  人物与阵列不整体位移。

## 排除项

- 后拍：王焕挺枪来刺、林冲与王焕大战、高俅临阵、荆忠被呼延灼打死、项元镇背射董平、水路芦苇伏击、党世雄被擒、四面炮响。
  前拍：济州帅府议事与十节度名单、凤尾坡董平和张清截击（石子打盔）、高俅长亭饯别与歌儿舞女。
- 不画高俅、林冲、其余九位节度使；不画交战、落马、血迹；不画宋江刺字。
- 戏曲：靠旗、翎子、大靠、亮相造型不用；影视造型不套用。
