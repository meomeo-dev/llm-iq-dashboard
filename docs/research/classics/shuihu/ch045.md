# 《水浒传》第45回 杨雄醉骂潘巧云　石秀智杀裴如海

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第045回>；读取日期：2026-10-20。

## 情节要点

1. 石秀回家见收了店面要辞行，潘公说明歇业是为女儿做亡夫王押司二周年道场；道场当日，年轻和尚裴如海以“师兄”
   身份送礼上门，石秀在布帘后看出两人眉目有私。
2. 做道场时众僧见了潘巧云都失态；次日潘巧云到报恩寺还愿，被裴如海灌酒引入僧房，二人私通。
3. 二人约定杨雄当牢上宿时在后门外摆香桌为号，裴如海买通报晓头陀胡道，五更敲木鱼叫佛催他出后门。
4. 十一月中旬石秀从门缝窥见人影，告知杨雄；杨雄醉后骂潘巧云，潘巧云反诬石秀调戏，杨雄收了肉铺，石秀辞出，
   另赁客店。
5. 石秀探得杨雄当牢上宿的日子，跨解腕尖刀，四更起身伏在后门巷内，截住头陀问出实情，杀头陀后穿他的衣服，
   敲木鱼诱出裴如海杀之（下回官司接续）。

## 选定场面

十一月中旬后数日的五更，杨雄宅后门外那条断路小巷，天未亮：石秀已搬出杨雄家，这夜四更起身，跨着解腕尖刀，
伏在巷内黑影里；报晓头陀胡道挟着木鱼走到巷口，探头探脑，还没敲响，也没发觉石秀。具名石秀、胡道。选这一刻是
为避开通奸、杀人与裸身：擒人、拔刀、杀人、剥衣都在“一闪”之后，此刻只有暗巷里一伏一探，两人、一道墙、一只木鱼、
一口挂在腰间的刀。三处依据：

- 「悄悄地开了店门，迳踅到杨雄后门头巷内，伏在黑影里张时」
- 「只见那个头陀挟着木鱼，来巷口探头探脑。」
- 「跨了这口防身解腕尖刀」

先后核对：在店住两日，探得杨雄当牢，见小牢子取铺盖出去（前）→夜里睡到四更，起来跨刀（前）→开店门，踅进后门巷
伏黑影里张，恰好五更，头陀挟木鱼探头（此刻）→石秀“一闪，闪在头陀背后”，一手扯住，一手把刀搁在脖子上（后，刀此时才
出鞘）→头陀交代香桌为号，石秀剥衣夺木鱼（后）→一勒杀倒，石秀穿上直裰、护膝敲木鱼入巷（后）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 石秀 | 二十八岁，金陵建康府人，“生得上下相等”（第44回）；这夜衣冠未写，兜底：深色旧短衣、头巾、麻鞋，不披甲，不穿头陀衣（穿在后）；只写“跨了防身解腕尖刀”（无护手的尖头短刀，据摘要），挂腰间未出鞘；此刻手无包裹、杆棒，不握刀，兜底：一手扶墙 | 第45回；第44回 |
| 头陀胡道 | 又称胡头陀、胡道人，住寺后退居小庵，每日五更起来敲木鱼报晓、劝人念佛，天明收斋饭；此刻“挟着木鱼”；年纪相貌未写；衣冠未写，后文石秀“穿上直裰、护膝”，兜底：直裰（宽大长衣，后背中缝直通到底，据摘要）、护膝；头部兜底：光头无巾；木鱼形制未写，兜底：手掌大小的圆形木鱼，木槌夹在手中 | 第45回 |

## 器物与环境

- 地点：蓟州城内杨雄宅后门外的断路小巷（“这条巷是条死巷”）；石秀伏在巷内黑影，头陀在巷口；后门开关未写，兜底：关着。
- 时令天气：十一月中旬后数日，五更（寅时约3至5时，据摘要）；天未明，原文只写“黑影”，天气未写。兜底：冬晨，
  天色墨青，东方未白，不画雪与月。
- 器物：木鱼；解腕尖刀；头陀直裰。《东京梦华录》载“每日交五更，诸寺院行者打铁牌子或木鱼，循门报晓”（据摘要），
  报晓头陀是宋代市井常见的人。
- 现实中会动的：① 两人呼出的白气；② 巷口天色由墨青渐渐泛白；③ 墙头枯草在晨风里微摆。

## 排除项

- 后拍：刀架颈、喝问、剥衣、杀头陀、穿头陀衣敲木鱼、裴如海出后门被按倒杀死；不画血、尸体、裸身。
- 通奸线：道场、僧房、佛牙、香桌、潘巧云、迎儿、裴如海、杨雄，均不入画；裴如海的“黄烘烘直裰”“九缕丝绦”
  “山根鞋履”（初见一拍）不给头陀。
- 此刻石秀不穿头陀衣，手不握刀，不敲木鱼；头陀尚未敲响，不画敲击。
- 戏曲：石秀的软罗帽、侉衣、对门坎肩（据摘要）不画；头陀不画丑角扮相。蓟州属辽（见第44回笔记），不画辽人装束。
