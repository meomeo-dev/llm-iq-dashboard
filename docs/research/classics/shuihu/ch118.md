# 《水浒传》第118回 卢俊义大战昱岭关　宋公明智取清溪洞

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第118回>；读取日期：2026-10-20。

## 情节要点

1. 关胜等夺乌龙岭，童贯军自西岭杀上，石宝自刎，睦州俱陷；水军总管成贵、谢福被擒。
2. 卢俊义取昱岭关，守将庞万春、雷炯、计稷以箭弩射死史进、石秀、陈达、杨春、李忠、薛永六将。
3. 时迁得草庵老僧指点，夜随小行者翻石壁，伏在关上大树顶；宋军放火烧林逼近，他溜下树在关后放火放炮，守军大乱，卢军破关，继取歙州，卢俊义杀方垕。
4. 宋江进兵清溪，李俊等扮献粮诈降；方杰、杜微出战，秦明阵亡；方腊御驾出阵，闻歙州失守退回，李俊在清溪放火，宋军破清溪大内，方腊退入帮源洞。
5. 宋江、卢俊义围帮源洞；方腊殿前一大臣自请领兵出战（即柴进，见下回）。擒方腊的是鲁智深，事在第119回，不在本回。

## 选定场面

夜里昱岭关前：时迁伏在关旁一株大树顶的密叶间，俯看庞万春与两员副将带弓弩伏在关前；关外山林被宋军放火，火光映红半边天，
林冲、呼延灼立马关下大骂，守将正“待要放箭”，没有发现树上的时迁。具名时迁、庞万春、林冲、呼延灼，另有两员副将的群像。
选它因“智取”全在此刻：一人暗伏，火光、关楼、骑将、弓手层次分明，箭未离弦，无人受伤。三处依据：

- 「爬在一株大树顶头，伏在枝叶稠密处。」
- 「看那庞万春，雷炯，计稷，都将弓箭踏弩，伏在关前伺候。」
- 「中间林冲，呼延灼立马在关下，大骂：“贼将安敢抗拒天兵？”」

先后核对：时迁访草庵，夜随小行者翻过石壁，望见“林木之间，半天价都红满了”（前）→庞万春得知宋军放火烧林，说“只牢守此关”，
望见宋兵渐近，带雷炯、计稷到关前守护（前）→时迁摸到关上，爬在大树顶，宋兵一派价把火烧来，林冲、呼延灼立马关下大骂，
庞万春等“却待要放箭射时，不提防时迁已在关上”（此刻）→时迁溜下树，转到关后点两堆柴草、放火炮（后）→关上自乱，南兵弃甲奔走，
时迁在屋脊上叫“已有一万宋兵先过关”（后）。此刻火炮未点，无人放箭，时迁不在屋脊。

## 器物与环境

- 地点：昱岭关，“歙州第一处紧要墙壁”；史实昱岭关在浙皖交界，块石砌筑、券形门洞（现存关隘，建造年代说法不一，据摘要）。原文有“关屋”“屋脊”，
  关后两堆柴草，关两边“松树林”，关上曾“竖着一面彩绣白旗”。兜底：山口夹两山，关楼前有垛墙，白旗一面，关前路两侧松林，一株高大古树靠近关楼。
- 时间：夜里；月色微明，林火映红夜空。季节未写，不强加。
- 器物：踏弩（脚踏张弦的强弩，据摘要）；复合弓；蒺藜骨朵；时迁背上的“大炮”，宋代“火炮”多指抛石机射出的火球类（据摘要），小说所指未明，不画具体炮形。
- 现实中会动的：① 林火火舌与火星向上飘，循环闪动；② 浓烟缓缓上升，火光在关楼与叶间闪烁；③ 关上白旗与树叶随风摆动。人物与关楼不整体位移。

## 排除项

- 后拍：时迁溜下树点柴草、放火炮、屋脊大叫；南兵弃甲奔走；孙立擒雷炯、魏定国擒计稷；庞万春走脱；割腹取心祭奠；歙州陷坑、卢俊义杀方垕。
- 前拍：庞万春一箭射史进，六将被弩箭射死（不画箭与尸）；草庵老僧与小行者；夜翻石壁。
- 他处：李俊献粮诈降、方杰与杜微、秦明之死、方腊出阵的“金瓜密布”仪仗；鲁智深擒方腊（第119回）。
- 不画箭已离弦、火球爆炸、时迁飞天或影视武打；不画外来现代烟花。
