# 《水浒传》第103回 张管营因妾弟丧身　范节级为表兄医脸

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第103回>；读取日期：2026-10-20。

## 情节要点

1. 王庆在龚家村教龚端兄弟拳棒，东村黄达闯来辱骂动手，被龚端等人打伤；龚端送五十两银子，
   王庆随公人到陕州牢城。
2. 张管营（张世开）收了龚正的贿赂，起初宽待；两个月后借买角弓、缎匹百般刁难，前后打了三百余棒。
   王庆得知管营小夫人的兄弟庞元，就是邙东镇被他打败的人。
3. 王庆夜入内宅，杀死张世开与庞元，越城逃走，陕州悬赏一千贯缉拿（本回前半，不入画）。
4. 王庆在六七十里外的镇上遇见母姨表兄、房州两院押牢节级范全；范全带他回房州，改名“李德”，
   藏在城外定山堡东自家的草房里。
5. 范全曾结交神医安道全，学得疗金印的法子，二月有余去尽王庆脸上的刺字。百余日后已是宣和元年仲春，
   王庆听说定山堡有粉头说唱，前去观看。

## 选定场面

定山堡东范全的草房里：王庆脸上两行刺字已被药点去，面颊只剩浅红的疤，范全坐在他对面，用细末为他涂搽。
具名王庆、范全。选它因回目“范节级为表兄医脸”只此一处，画面安静，脸上有疤、案上有药即可辨认，无任何动手。
原文对这段只作概述，没写二人的位置、手势与用具，由题面按兜底画法补充。三处依据：

- 「却将毒药与王庆点去了，后用好药调治，起了红疤」
- 「再将金玉细末，涂搽调治，二月有余，那疤痕也消磨了。」
- 「范全思想王庆脸上金印不稳」

先后核对：范全见王庆脸上“两行金印”（前）→改姓李德，藏草房（前）→毒药点去刺字，好药调治起红疤（前）→
涂金玉细末，历二月有余（此刻）→疤痕消尽，百余日后宣和元年仲春，王庆出外（后）。刺字在面颊（第102回
“刺了面颊”）。此刻字迹已无，只留未褪尽的红疤；行枷早在陕州除去，血衣已弃，解手尖刀藏在身边，不入画。

## 器物与环境

- 地点：房州城外定山堡东的几间草房（范全前年买下，另有二十余亩田，由庄客耕种）。内景兜底：土墙、茅顶、
  格眼窗透入日光，一张方桌、两只方凳（宋代已用高桌椅）。
- 时令：王庆逃出时“仲冬将近，叶落草枯”，疗治二月有余，至仲春前结束，此刻是冬日；天气本回未写，
  兜底：冬日白昼，窗外枯草，不画雪。
- 药物：原文为“金玉细末”（第72回写作“良金美玉碾为细末”）；兜底：桌上一只小瓷碟盛浅金白色细粉，
  一支竹片，一只小石钵，一只药匣；毒药不入画。
- 现实中会动的：① 窗格透入的日光里浮尘缓缓飘动，窗外枯草轻摆；② 屋角炭盆（兜底，原文未写）火光明灭、
  一缕细烟；③ 范全持竹片的手小幅往复涂抹。人物不整体位移。

## 排除项

- 前拍：龚家村打黄达、买角弓与缎匹、三百余棒、夜入内宅杀张世开与庞元、越城、客店相认；
  后拍：定山堡戏台、段三娘与成亲。
- 不画清晰可读的刺字，不画王庆戴枷，不画解手尖刀、血衣、人头；不画安道全（他在第72回，
  此处范全只是学得其法）；不画毒药腐蚀脸皮的过程。
- 王庆脸上不留墨黑的字迹；不画成京剧脸谱式的白脸红斑，不画影视中的囚犯造型。
