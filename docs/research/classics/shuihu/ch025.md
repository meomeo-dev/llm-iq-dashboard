# 《水浒传》第25回 王婆计啜西门庆　淫妇药鸩武大郎

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第025回>；读取日期：2026-10-20。

## 情节要点

1. 郓哥挨了王婆的打，提着雪梨篮在街上遇见武大，用话激他，在小酒店里说出奸情，二人约定次日在紫石街巷口
   接应。
2. 次日郓哥在茶坊顶住王婆，武大闯到房门前，被西门庆一脚踢中心窝，吐血卧床五日。
3. 武大向潘金莲撂下“武二归来不肯干休”的话；王婆献计，西门庆送砒霜，潘金莲在三更把药灌给武大（不入画）。
4. 王婆与潘金莲收拾尸身；西门庆拦住团头何九叔，送十两银子；何九叔入殓时见尸身异状，大叫一声倒地吐血。

## 选定场面

阳谷县街上，白天：郓哥提着雪梨篮从王婆茶坊出来，转过两条街，迎面见武大挑着炊饼担走来，立住脚发问，武大
歇下担儿答话。两人还没吵起，武大没扯住郓哥，也没领他进酒店。具名郓哥、武大。三处依据：

- 「提了雪梨篮儿，一迳奔来街上，直来寻武大郎。」
- 「只见武大挑着炊饼担儿，正从那条街上来。」
- 「武大歇下担儿道：『我只是这般模样，有甚么吃得肥处？』」

回目的情节核心是茶坊与毒杀，通奸、踢打、下药、尸身均不可画；街头相遇是这一串事的起点，一个少年提篮、一个
矮个汉子歇担，手里物件（梨篮、炊饼担）都有原文，无暴力。不取茶坊顶住王婆（孩童头撞老妇小腹，西门庆躲
床下，武大被踢吐血）；不取次日巷口（篮内货物同，但已是定计之后，构图重复）。

先后核对：郓哥被王婆揪打赶出、梨滚满街（第24回末，前）→提了篮儿奔街上寻武大（前）→转两条街，见武大挑担
来（紧邻此刻之前）→郓哥立住脚，看着武大发问；武大歇下担儿答话（此刻）→郓哥拿“麦稃”“鸭”调笑，武大扯住
他（后）→武大挑担领他进小酒店，买肉请酒（后）→郓哥让他摸头上肐瘩，说出奸情（后）。此刻篮在郓哥手里，
担子刚落地。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 郓哥 | 姓乔，“年方十五六岁”，生得“乖觉”，家中只有老爹，在县前酒店间卖时新果品；头上挨了王婆“大栗暴”，有肐瘩（本回他自述）。衣冠两回均未写；兜底：窄袖短褐、裹头巾或束小髻、麻鞋，一手提雪梨篮，神情机灵带气，是少年身量，不画幼童 | 第24、25回 |
| 武大郎 | 清河县人，“身不满五尺，面目丑陋，头脑可笑”，绰号“三寸丁谷树皮”；每日挑炊饼担出卖；此刻担子已歇下。衣冠未写；兜底：粗布短衣、头巾、麻鞋，不穿长衫；矮小而五官丑拙，不画驼背（原文未写） | 第24、25回 |
| 王婆、何九叔等 | 不在此刻。王婆自称“活了六七十岁”，开茶坊，样貌未写；何九叔是地方团头（管殓葬），被写作“精细”，样貌未写；兜底均为布衣老者 | 第24、25回 |

## 器物与环境

- 地点：阳谷县街市，街名未写（郓哥“转了两条街”；王婆茶坊在紫石街）。兜底：沿街木构平房与店面，行人稀。
  今阳谷县景区的“紫石街”“武大郎家”是复建，不作原著依据。
- 时令天气：本回未写。第26回郓哥自述“今年正月十三日，提得一篮儿雪梨”，故为正月十三，冬末春初。兜底：
  阴冷微寒，枯枝，不画雪，不画花。
- 器物：炊饼担——炊饼是蒸饼，无馅的面食，装在蒸笼里，按“扇”计（武大“做三两扇炊饼”），扁担两头挑；雪梨篮——
  篮的形制原文未写，兜底：竹编圆提篮，单提梁，盛浅黄绿色的圆梨，数量不强调（前回梨曾滚落满街）。
- 现实中会动的：① 蒸笼缝里冒出的热气（原文未写，属炊饼担常见景）；② 郓哥提篮的手与篮梁轻晃；③ 风吹动
  两人的衣角与头巾带。

## 排除项

- 后拍：酒店吃肉饮酒、摸头上肐瘩、次日巷口丢篮、顶住王婆、西门庆踢武大、病床、王婆献计、砒霜与药、尸身
  与入殓、何九叔倒地吐血，均不画。前拍：茶坊里王婆揪打郓哥，不画茶坊内景。
- 武大不画影视中的驼背、丑角妆、戏曲彩脸；炊饼不画成烧饼、油条或现代馒头堆。
- 他回：武松（此时在东京，不在场）；第24回的叉竿打头巾、雪梨滚满街、潘金莲与西门庆。
