# 《水浒传》第19回 林冲水寨大并火　晁盖梁山小夺泊

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第019回>；读取日期：2026-10-19。

## 情节要点

1. 济州何观察带五百官兵入石碣村；阮小五、阮小七诱敌入芦苇港汊，阮小二、阮小七擒何涛；初更起怪风，
   火船顺风冲进官船，公孙胜执剑立船头，岸上众好汉杀尽官兵，只割何涛双耳放回（此事不入画）。
2. 晁盖七人经李家道口朱贵酒店上梁山；王伦席间推托，吴用看出其变色，林冲次日清早来客馆陪话。
3. 辰牌后宋万骑马相请，七人乘山轿到山南水寨水亭赴宴；王伦献五锭大银，称“粮少房稀”，要打发众人下山。
4. 林冲发难，踢桌掣刀，吴用摸须为号，晁盖、刘唐上亭虚拦王伦，三阮各自帮住杜迁、宋万、朱贵；林冲杀王伦
   并割首级（此事不入画）。
5. 杜迁等三人跪降，吴用请林冲坐头把交椅，林冲不受，称另有话说（下回接续：推晁盖为寨主）。

## 选定场面

山南水寨的水亭上，王伦奉银逐客之后：林冲一脚踢开桌子、抢起身来，衣襟底下的刀已掣出，尚未近王伦；
吴用抬手摸须为号。王伦此前起身把盏，立在主位前；客席七人此前已起身要下亭子，均站立。具名林冲、王伦、
吴用；晁盖、刘唐、公孙胜、三阮及杜迁、宋万、朱贵作群像。三处依据：

- 「林冲把桌子只一脚，踢在一边，抢起身来」
- 「衣襟底下掣出一把明晃晃刀来」
- 「吴用便把手将髭须一摸」

座次：王伦与杜迁、宋万、林冲、朱贵坐左边主位，晁盖与吴用、公孙胜、刘唐、三阮坐右边客席（原文按主客分左右，
画面左右由构图定）；林冲“侧坐交椅上”。

不取石碣村火船夜战：官兵被杀、尸横烂泥，难避杀人与血腥。取水亭一刻：回目上联“林冲水寨大并火”的发难点，
宾主两排席位、一人跃起，刀出鞘而未伤人，人物衣冠与亭景原文都有写。

先后核对：王伦起身把盏奉银，晁盖谢绝→林冲坐在交椅上大喝→“晁盖等七人便起身，要下亭子”→王伦“且请席
终了去”→林冲踢桌、抢起身、掣刀（此刻）→吴用摸须（紧随，并入此刻）→晁盖、刘唐上亭虚拦，三阮帮住
三头领（后）→林冲拿住王伦痛骂、一刀搠倒、割首级（后）。

## 器物与环境

- 地点：梁山泊山南水寨的寨后水亭，晁盖等“直到寨后水亭子前下了轿”。韵文写亭：“四面水帘高卷，周回花压朱栏”，
  亭外“万朵芙蓉铺绿水”“千枝荷叶绕芳塘”，檐外柳荫，窗前松声。回末预告语称“断金亭”，本回只写“水亭子”。
- 时令天气：宴在午后（“饮酒至午后”）；“芙蓉铺绿水”与“荷叶绕芳塘”对举，芙蓉指水面荷花，不画木芙蓉，
  取夏日荷塘景色；天气本回未写，兜底：晴，不画雨雪。
- 器物：交椅（林冲“侧坐交椅上”）、被踢开的桌子、酒盏盘馔；王伦所献大盘五锭银，踢桌时去向本回未写，可略；
  栏杆朱色，形制未写（宋画水榭常见鹅颈勾栏，据摘要，不强加）。
- 现实中会动的：① 荷叶、荷花与亭外柳枝在风中摆动；② 水面波纹与亭子倒影晃动；③ 吴用长须与林冲衣襟微摆。

## 排除项

- 动手：林冲拿住王伦、搠倒、割首级，杜迁等跪降（后）；晁盖、刘唐上亭虚拦，三阮帮住三头领（后）；不画血与首级。
- 前半回：石碣村芦苇火船夜战、何涛被割耳；次日林冲客馆陪话；晁盖等登山后的聚义厅筵席。
- 兵器：丈八蛇矛见于第48回赞诗（据摘要），本回只有刀；王伦本回未写兵器，不画佩刀。
- 戏曲影视：京剧《野猪林》林冲着白色武生花褶、戴武生巾，形象清秀儒雅（据摘要），与原著“豹头环眼”不同；
  不画脸谱、靠旗、翎子。
