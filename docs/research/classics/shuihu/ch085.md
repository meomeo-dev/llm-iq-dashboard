# 《水浒传》第85回 宋公明夜度益津关　吴学究智取文安县

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第085回>；读取日期：2026-10-20。

## 情节要点

1. 辽国欧阳侍郎劝辽主招降宋江，兀颜统军反对；欧阳侍郎持敕命到蓟州劝降，宋江与吴用商定将计就计，
   并借口暑热留军，随后同公孙胜上二仙山拜谒罗真人，得八句法语。
2. 七月半后，宋江对欧阳侍郎假称部下一半人不愿归顺，要先带心腹躲到霸州；吴用、朱武与卢俊义暗中布置接应。
3. 宋江率林冲、花荣、李逵等十五员头领、一万来军校，当夜出城，欧阳侍郎引数十骑领路，三更到益津关，过关入霸州。
4. 吴用扮秀才、鲁智深与武松扮行脚僧和行者，混在百姓中奔益津关，趁开关夺下关口，卢俊义大队随后杀入文安县。
5. 卢俊义阵前叫骂，林冲等诈败诱入城内，里应外合取下霸州，辽国舅与三位侍郎被遣回；贺统军之计留待下回。

## 选定场面

夜里三更，益津关关前。欧阳侍郎勒马当先，高声叫开关门，关门仍闭；宋江引着衔枚的一队人马静立在后。
具名宋江、欧阳侍郎，另有辽兵守关与宋军骑队群像。选它是因“悄无声息的夜行”与“假降”的反差都集中在
这一刻，无人动手，一队人马的静默易于入画。三处依据：

- 「都教马摘銮铃，军卒衔枚疾走，当晚便行。」
- 「当时已是三更左侧，前面已是益津关隘口。」
- 「欧阳侍郎大喝一声：“开门！”」

先后核对：黄昏左侧开城西门，欧阳侍郎引数十骑在前领路（前）→行二十余里，宋江马上失声叫“苦也”，
想起未等吴用（前）→三更左侧到益津关隘口，欧阳侍郎喝开门（此刻）→把关军将开放关口，军马尽数度关（后）
→天将晓到霸州见国舅（后）→吴用与僧、行者奔关、鲁智深武松夺关（另一条线，更后）。此刻关门未开，吴用、
鲁智深、武松、解珍等一概不在场，也没有“尘头蔽日”的追兵。

## 器物与环境

- 地点：益津关，“两边都是险峻高山，中间只一条驿路”，是霸州的“两扇大门”之一。史实上益津关在今河北霸州市区，
  唐代建关，宋初为霸州治所（据摘要），当地是平原，山峡是小说设定，画面按原文画两山夹一条土路。
- 时令天气：七月半后，前文写“盛暑炎天”；夜里天气、月相未写，兜底：无云星夜，不画月。
- 器物：关门与关楼本回只写“开门”“关口”；兜底：一座城楼夹于两山，门洞木门紧闭，楼檐挂一盏灯笼。
  衔枚是形如筷子的木棍，两端有带，横衔口中、带子系在颈间（据摘要）；摘銮铃是取下马颈铃，画面马匹不挂铃。
- 现实中会动的：① 关楼灯笼烛光明灭、灯笼微摆；② 马匹的鬃毛与尾巴摆动、马头轻点；③ 夜空星光闪烁。
  队伍整体不位移。

## 排除项

- 后拍：关门洞开、军马度关；入霸州见定安国舅；吴用、僧人、行者混入关；鲁智深禅杖、武松双戒刀杀入；
  卢俊义夺文安县、阵前叫骂。前拍：蓟州见欧阳侍郎；二仙山罗真人及八句法语；宋江半路喊“苦也”。
- 吴用、鲁智深、武松、解珍等扮百姓的一伙不入画；不画追兵扬尘；不画夜袭常见的成排火把（原文只有“摘铃衔枚”）。
- 史实：不画宋代真实益津关的平原城关，不套后世影视铠甲和戏曲靠旗；辽人称“辽官”“辽兵”，不沿用“番”。
