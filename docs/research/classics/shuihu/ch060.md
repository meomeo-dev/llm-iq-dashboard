# 《水浒传》第60回 公孙胜芒砀山降魔　晁天王曾头市中箭

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第060回>；读取日期：2026-10-20。

## 情节要点

1. 公孙胜献“诸葛孔明摆石为阵”的八阵图：分八八六十四队，中间大将居之，变长蛇之势，掘陷坑，埋伏挠钩手；八员猛将
   守阵，陈达磨七星号旗。
2. 巳牌时分，樊瑞、项充、李衮下山；樊瑞施法起风，项充、李衮带五百滚刀手冲阵，阵变长蛇，二人坠陷马坑被擒；宋江
   亲解其缚，放回；樊瑞率众来降，拜公孙胜为师。
3. 回梁山，段景住在泊边拜见，说他盗的照夜玉狮子马被曾头市曾家五虎夺去；戴宗探知曾家与史文恭的情形。
4. 晁盖不听劝阻，亲率二十头领攻曾头市，风折认旗；夜中计被伏，史文恭一箭射中晁盖面颊，晁盖遗言“捉得射死我者
   为梁山泊主”，宋江暂居主位；吴用献计赚卢俊义（下回接续）。

## 选定场面

春日巳牌，芒砀山下平川：梁山军依八阵图摆开，樊瑞、项充、李衮率三千余人下山列阵。樊瑞骑一匹黑马立阵前，左手挽着
流星铜锤，右手执混世魔王宝剑，正口中念咒、将喝“疾”；项充、李衮分列两侧（构图兜底：项充在画面左，李衮在画面右），
各执团牌、挺兵器步行待命；风还没起。具名樊瑞、项充、李衮。双方尚未交锋，不涉伤人。三处依据：

- 「樊瑞骑一匹黑马，立于阵前」
- 「左手挽定流星铜锤，右手仗着混世魔王宝剑」
- 「各执定蛮牌，挺着标枪飞剑，只等樊瑞作用」

先后核对：公孙胜献阵图，宋江布置八员守阵（前）→巳牌，梁山军近山摆开阵势，搦战（前）→芒砀山锣响，三个头领下山，
樊瑞立阵前，项、李在左右，樊瑞念咒（此刻）→“喝声疾”，狂风四起，飞沙走石，项、李带滚刀手杀入（后）→陈达招七星
号旗，阵变长蛇，公孙胜拔松纹古锭剑念咒（后）→二人坠陷马坑（后）。故此刻无风沙，公孙胜尚未拔剑，樊瑞的锤也不
在抡动。

## 器物与环境

- 地点：徐州沛县一带芒砀山（原文称汉高祖斩蛇处；今河南永城，海拔约157米，据摘要）；山下平川，梁山军依八阵图摆开
  “四面八方”阵势。山寨以青色灯笼为记（夜间，不入画）。
- 时令时辰：巳牌（上午约九至十一点）；春（后文晁盖云“趁此春暖之时”）；兜底：晴，微风，不画沙尘。
- 器物：流星锤，宋代无专条，公开资料称锤头系绳、锤如鸭卵，质铜或铁（据摘要），兜底：铜球形锤头连一根长绳，握在
  左手；团牌即圆盾，宋代蛮牌形制未检得，明清藤牌（圆形、中央拱起）不等同；认军旗（旗字不求画出）；五百滚刀手作
  群像。小说“八八六十四队”与《武经总要》所记夔州石阵八行不同，以小说为准。
- 现实中会动的：① 阵前战旗与认军旗随风飘；② 樊瑞披散的头发与黑马鬃尾；③ 铜锤垂绳微摆（挽握未抡）。

## 排除项

- 后拍：狂风飞沙、天昏地暗、项李杀入、坠陷马坑、挠钩手擒人、陈达招七星号旗、阵变长蛇、公孙胜拔剑念咒、宋江亲解
  缚、樊瑞拜师。前拍：史进等四人被蛮牌滚入阵中（第59回末）。
- 他段：段景住拜见（他没带马，马已被曾家夺去；其“赤发黄须”“焦黄头发髭须卷”易画成异族，建议不画）、曾头市、
  晁盖中箭、宋江坐寨主，均不画。
- 不画樊瑞挥锤，也不画成链球或西洋锤；不画项充掷飞刀、李衮掷标枪。
- 项充用飞刀、李衮用标枪，二者别互换；不画京剧脸谱、戏曲靠旗，不画道士冠巾（樊瑞披发）。
