# 《水浒传》第109回 王庆渡江被捉　宋江剿寇成功

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第109回>；读取日期：2026-10-20。

## 情节要点

1. 宋江排九宫八卦阵，林冲、黄信阵前连杀柳元、潘忠，卢俊义自后夹击，公孙胜作法使李助的剑脱手，李助被擒，王庆大军溃败。
2. 孙安袭南丰中了陷坑，张清、琼英入东门，宋江破南丰；王庆领数百骑突围，奔云安。
3. 王庆见云安城头已是宋军旗号，卸下金幞头、蟒袍、玉带，换巾帻便服，绕路奔东川，随从陆续逃散，剩三十余骑。
4. 傍晚到开州清江，孟冬晴和；李俊、童威扮作渔人，把王庆按倒擒获，三十余随从尽被擒；李俊解王庆到宋江帐前，推荐降将胡俊。

## 选定场面

清江北岸傍晚：李俊、童威扮的小渔艇从对岸摇来，刚拢岸，李俊立船头，一手执竹篙，另一手空着，把岸上的王庆从头看到脚；
童威在船尾摇橹；王庆刚被近侍扶下马，站在水边，一身便服，疲惫地打量渔人，身后有三五骑随从。远处对岸芦滩边停着一簇渔船。
具名王庆、李俊、童威。选它是因为一船一岸、两人对视，是全回唯一不涉战斗的瞬间，正处识破之前。注意：原文王庆没有扮渔人
或客商，只是更衣换服；扮渔人的是李俊一伙。三处依据：

- 「此时是孟冬时候，天气晴和，只见数十只渔船，捕鱼的捕鱼，晒网的晒网。」
- 「船头上渔人，向船旁拿根竹篙撑船拢岸，定睛把王庆从头上直看至脚下」
- 「近侍扶王庆下马。」

先后核对：随从散去六七十人，王庆领三十余骑走到傍晚才到清江（前）→ 近侍指“南涯”渔船，高叫渔人撑船来渡，
两个渔人放下酒碗摇艇近岸（前）→ 竹篙撑船拢岸，渔人打量王庆，说“上船上船”，近侍扶王庆下马，王庆看渔人（此刻）→
渔人一手执篙、一手扶王庆上船，篙一点船离岸丈余（后）→ 劈胸扭住按倒，童威放橹跳来协力，三十余随从被擒（后，不画）。
此刻王庆未上船，李俊的手没碰到他，无人被按倒或捆绑。“南涯”在对岸，由此推知王庆一行在北岸（推断）。

## 器物与环境

- 地点：开州清江（云安属下），“源出自达州万顷池，江水最是澄清”；对岸“南涯疏芦落雁处”有一簇渔船。小说的云安、开州在今川渝，
  与“淮西”不合，史实对应未检得；题面只写江岸、芦滩。
- 时令天气：孟冬，天气晴和；王庆走了一天，到晚方至；兜底：傍晚斜阳，天晴，芦苇苍黄带白花（芦花深秋至初冬最盛，据摘要）。
- 器物：一只小渔艇（兜底：窄长木船，一橹一篙）；竹篙；可在船上挂蓑衣斗笠（宋代渔父常见，据摘要；原文未写）。
- 现实中会动的：① 江面细波，小艇随波轻晃；② 芦苇与芦花随风摆；③ 晒网船上的渔网与远处渔船缓缓飘动。人物不整体位移。

## 排除项

- 后拍：篙一点船离岸、劈胸扭住、按倒、捆绑、随从被擒、解往云安与宋江帐前；前拍：九宫八卦阵、柳元与潘忠阵亡、李助被擒、
  南丰陷坑、段三娘被擒、云安城头宋军旗号。后文第110回的王庆处决不画。
- 王庆不扮渔人、客商，不戴金幞头、不穿蟒袍；渔人是李俊、童威，不画成王庆同伙；张横、张顺、三阮、胡俊此刻不在江边。
- 不画落雁（避免与第110回混淆），不画戏曲脸谱与影视造型。
