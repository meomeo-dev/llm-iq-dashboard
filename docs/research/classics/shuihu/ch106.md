# 《水浒传》第106回 书生谈笑却强敌　水军汨没破坚城

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第106回>；读取日期：2026-10-20。

## 情节要点

1. 宋江分水陆三路进军山南军，前队在隆中山北破王庆军，折了文仲容、崔埜；吴用、朱武看过城形，
   认为城坚难攻。
2. 山南守将段二听参军左谋之计，遣縻貹等率二万兵袭宛州，并约均州、巩州两路同时出兵。
3. 宛州只有陈瓘、侯蒙、罗戬三位文官与宣赞、郝思文及一万老弱兵。书生萧让献计：伏兵西门内，旗幡一律放倒，
   三位官员与一位秀才上城楼摆酒笑谈，大开城门。贼将季三思、倪慴疑惧欲退，炮响伏兵杀出，贼兵大败。
4. 夜里宋军粮船被段二的水军拖进山南城水门，船中暗藏的步军头领杀出，夺门破城，擒段二。宋江听说
   萧让之计，担心被识破，说“终是秀才见识”。宋江分兵，卢俊义取西京，自己攻荆南。

## 选定场面

宛州西门城楼上：三位官员与一位秀才围桌饮酒笑谈，城门大开，城垣上不见一面旗，城下远处贼将季三思、
倪慴勒马迟疑，不敢上前。选这一刻因回目“书生谈笑却强敌”指的正是它，全场面无打斗。具名陈瓘、侯蒙、罗戬、
萧让。原文写的是“三个官员，一个秀才”，官员依上文为陈瓘、侯蒙、罗戬，秀才依“书生”与献计者推定为萧让
（原文没写萧让上楼）。号召百姓杀贼守城的是第108回的萧嘉穗，不是本回。三处依据：

- 「陈瓘，侯蒙，罗戬，随即上城楼，笑谈剧饮」
- 「望见城门大开，三个官员，一个秀才，于城楼上花堆锦簇」
- 「四面城垣上，旗幡影儿，也不见一个。」

先后核对：萧让献计，宣赞、郝思文伏西门内，老弱军士掩倒旗幡，只在城内走动（前）→酒馔抬上西门城楼，
三官上楼笑谈剧饮，城门大开（前）→季三思、倪慴领十余偏将到城下，望见城门大开、官员秀才吃酒、城垣无旗，
季三思疑讶不敢上前（此刻）→倪慴劝退，季三思急令退军（紧后）→城楼一声炮响，旌旗涌现，宣赞、郝思文杀出（后）。
此刻炮未响、旗未举、伏兵不可见。

## 器物与环境

- 地点：宛州西门（小说所称，地望据摘要为今南阳）。城楼兜底：木构两层城门楼，朱柱，歇山顶；原文“于城楼上”
  饮酒，酒桌摆在楼前城墙顶平台；城门洞敞开，门内空街；城楼与城垛上一面旗也不见；宋代城门外常设瓮城（据摘要），本回未写，可不画。
- 陈设：酒桌铺锦、果碟、注子与注碗（宋代温酒组合）、酒盏，兜底：桌边设方凳；“大吹大擂”未写乐器与乐人，
  城楼乐人构图不画，不画乐师与歌妓。
- 时令天气：宋江八月初旬离宛州，此场面在秋季，天气时辰本回未写，兜底：秋日白昼，晴，不画夜。
- 现实中会动的：① 城下贼军旗幡与马鬃、马尾随风摆动，战马不安踏步（兜底）；② 注子口一缕温酒热气（兜底）；
  ③ 官员笑谈时抬袖举盏、衣袖与幞头带微动。人物不整体位移。

## 排除项

- 后拍：炮响、旌旗涌现、宣赞郝思文杀出、季三思倪慴被杀；夜里山南水军诈城、段二被擒；
  前拍：隆中山阵战、縻貹杀文仲容与崔埜。
- 不套用《三国演义》空城计：不画琴、焚香、童子、羽扇、鹤氅纶巾、扫街百姓；萧让不扮诸葛亮。
- 不画萧嘉穗的揭帖与起事（第108回）；不画萧让提笔书写；不画宋江、吴用。
- 贼将与士卒不画成异族或丑化形象。
