# 《水浒传》第119回 鲁智深浙江坐化　宋公明衣锦还乡

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第119回>；读取日期：2026-10-20。

## 情节要点

1. 柴进（“柯引”）阵前与花荣等假意交战，趁方杰出阵将其杀死；宋军杀入帮源洞，阮小七穿方腊衮龙袍戏耍被喝下剥衣；洞中宫殿焚毁。
2. 方腊脱赭黄袍逃入深山，在草庵前被鲁智深一禅杖打翻擒获，解往睦州，后押京。
3. 宋江做醮超度亡将，祭乌龙神庙，回杭州；宋江屯六和塔，诸将住六和寺。
4. 八月十五夜，鲁智深听潮声以为战鼓，经众僧指点悟“听潮而圆，见信而寂”，沐浴更衣，书颂，法堂坐化；径山大惠禅师下火；武松出家六和寺；林冲风瘫。
5. 燕青辞卢俊义去，李俊诈病入海；宋江等二十七人朝觐受封，方腊在东京受刑，宋江还乡，戴宗来访。

## 选定场面

杭州六和寺，中秋夜三更：鲁智深在僧房里睡到半夜，听见江上潮声雷响，以为战鼓，摸了禅杖大喝着抢出来；众僧赶来相问，
笑他听错，推开窗，指着江上潮头叫他看。具名鲁智深，另有数名僧人群像。选它因“听潮”一刻最贴回目，寺、月、江、潮、禅杖
同框，人物表情由惊到悟，无任何交手，坐化在其后，不画遗体。三处依据：

- 「是夜月白风清，水天共碧。」
- 「跳将起来，摸了禅杖，大喝着便抢出来。」
- 「寺内众僧推开窗，指着那潮头叫鲁智深看。」

先后核对：宋江屯六和塔，诸将住六和寺，鲁智深与武松在寺中歇马（前）→月白风清，睡至半夜，听潮声，以为战鼓，摸禅杖抢出，
众僧来问，他说“待要出去厮杀”（前）→众僧笑说是钱塘江潮信，推开窗指潮头叫他看，说今朝八月十五、合当三更子时潮来（此刻）→
智深大悟拍掌，想起师父偈言，问何谓“圆寂”（后）→烧汤沐浴，换御赐僧衣，写颂，法堂坐禅椅坐化（后）。此刻他已抢出僧房，
仍握禅杖，未沐浴、未更衣、未写颂；武松留在僧房，原文此刻未提，不画。

## 器物与环境

- 地点：杭州六和寺，宋江“屯兵在六和塔驻扎”，诸将“在六和寺安歇”；寺塔在钱塘江北岸月轮山（据摘要）。窗：宋代窗多为直棂窗、方格眼窗，可开启的扇窗南宋后才普及（据摘要）；
  兜底：智深已抢出僧房，场面取寺中临江廊屋；木格窗扇在画面右侧向外推开，窗外是江景；智深侧身望潮，面容可见。
- 塔：六和塔始建于开宝三年（970），九级，塔身挂灯可作江上航标；宣和三年（1121）毁于方腊之乱（曹勋《重建塔记》，据摘要）；小说写塔仍在，
  兜底：远景月下一座多层楼阁式砖木塔，可见数点塔灯，不作主体，不画现存十三层外观。
- 潮：八月十五夜三更子时（约23点至1点）；周密《观潮》记钱塘潮八月十六至十八最盛，潮头如一线银白，近时声如雷霆（南宋，据摘要）。
  兜底：远处江面一道横贯的白色潮线推来，近岸浪花翻起，月光洒在水面。
- 月色：“月白风清，水天共碧”，兜底：圆月，薄云。廊屋内一盏陶瓷油灯（宋代日常照明，据摘要）。
- 现实中会动的：① 潮线向前推进，近岸浪花起伏，循环；② 月光在江面碎闪；③ 灯焰与塔灯火苗微晃，衣袖随风轻摆。人物与建筑不整体位移。

## 排除项

- 后拍：智深拍掌大悟、问“圆寂”、烧汤沐浴、换御赐僧衣、写颂、法堂禅椅叠足坐化、焚香；宋江来看；大惠禅师下火、龛子、塔院安葬。不画遗体。
- 前拍：松树后一禅杖擒方腊；阮小七穿龙袍；帮源洞焚毁。同回他拍：武松出家、林冲风瘫、燕青辞主、李俊诈病、朝觐封赏。
- 他回他地：五台山醉打山门（第4回）、倒拔垂杨柳（第7回）；不画戒刀、袈裟、佛珠、莲座、佛光。
- 不画现代观潮景：海宁盐官观潮亭、护堤、观潮人群；不画红脸大和尚的戏曲扮相和影视造型。
