# 《水浒传》第40回 梁山泊好汉劫法场　白龙庙英雄小聚义

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第040回>；读取日期：2026-10-20。

## 情节要点

1. 戴宗带假回书回江州，黄文炳看出蔡京图书的破绽；蔡九拷问，戴宗招认书是假的，与宋江同被判斩。
2. 黄孔目说明国忌日、七月十五中元不可行刑，行刑推迟到第六日；巳牌，宋江、戴宗被押到十字路口法场。
3. 午时三刻，梁山好汉扮作弄蛇丐者、卖药人、脚夫、客商，听锣响动手；李逵从茶坊楼上跳下，众人背起宋江、
   戴宗，随李逵杀出城。
4. 到江边，李逵砍开白龙庙；张顺、张横、李俊、穆弘等乘三只船赶到，两路好汉聚会，共二十九人。
5. 官军追来，李逵提斧先出，众人迎战（下回接续）。

## 选定场面

江州十字路口法场，午时三刻，小锣响起、四面发作的一刻：宋江面南、戴宗面北，背对背被捆坐在法场中央，各插
红纸花，刽子手执刀立在身后，刀未落；法场北边的客商立在车上，一人从怀里取出小锣敲响；东、西、南三面扮作
丐者、卖药人、脚夫的好汉正亮出尖刀、枪棒、扁担；茶坊楼上的李逵赤膊双斧，已跃在半空，尚未落地；蔡九知府
勒马在场边观刑。无人受伤。具名宋江、戴宗、李逵、蔡九知府。三处依据：

- 「把宋江面南背北，将戴宗面北背南，个个纳坐下」
- 「取出一面小锣儿，立在车子上当当地敲得两三声」
- 「大吼一声，却似半天起个霹雳，从半空中跳将下来」

先后核对：胶水刷发、插花、长休饭永别酒（前）→押到十字路口纳坐，读犯由牌，四伙陆续挨进法场（前）→报
“午时三刻”，监斩官说“斩讫报来”，刀棒刽子“便去开枷”、行刑人“执定法刀在手”（紧邻此刻之前）→客人敲
小锣，“四下里一齐动手”，又见李逵从茶坊楼上跃下（此刻）→“手起斧落，早砍翻了两个行刑的刽子”（后，不画）
→丐者掣尖刀、两个客商背起宋江戴宗（后）。枷是否已落地原文未写，兜底：画枷已卸，两人仍被绳捆。

## 器物与环境

- 地点：江州府十字路口市曹：犯由牌高立，皂纛旗，看客一二千人“压肩叠背”；十字路口的茶坊是二层木楼（宋代茶肆
  多二层，据摘要）；车子形制未写，兜底：小型板车。
- 时令天气：先过国忌日、七月十五中元，再隔数日，约七月十八九日；午时三刻（约正午）。韵文“愁云荏苒……日色无光，
  悲风乱吼”。兜底：阴沉天色，风大。
- 现实中会动的：① 皂纛旗、缨枪红缨在风里飘；② 犯人头上的纸花被风吹动；③ 客人手中的小锣随敲击颤动。

## 排除项

- 后拍：手起斧落砍翻刽子、血、背走宋江戴宗、杀出城、白龙庙聚会、张顺的五股叉与白绢水裈。前拍：假信败露、
  拷打、押出牢门、长休饭永别酒。
- 李逵不落地、不砍人、不画血，不全裸；宋江、戴宗不画血，不戴枷。
- 红衣刽子、鬼头刀、背后插亡命牌与令箭（戏曲与后世印象，宋代无直接史料）不用。
- 犯由牌文字不要求可辨认；扮装好汉不点名，只画群像。
