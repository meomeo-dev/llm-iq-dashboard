# 《水浒传》第16回 杨志押送金银担　吴用智取生辰纲

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第016回>；读取日期：2026-10-19。

## 情节要点

1. 晁盖、吴用、公孙胜、刘唐、三阮在庄上定计：公孙胜探得生辰纲必走黄泥冈，白胜家为安身处，三阮领银回石碣村。
2. 梁中书派杨志押送十万贯生辰纲；杨志要求扮客商、改十一担挑担，老谢都管与两个虞候同行，十一名厢禁军扮脚夫。
3. 五月半出发，杨志逼赶、棒打军汉；六月初四日，一行十五人在酷热中上黄泥冈，杨志喝止众人歇凉。
4. 松林里七个贩枣客人（七辆江州车）与白胜挑来的白酒：客人先买一桶吃了，另一桶经白胜“争酒”后军汉、都管买吃。
5. 杨志只吃半瓢，众人随即软倒，七人装车推下冈；杨志醒后愤而欲跳冈（下回接续）。

## 选定场面

六月初四日正午，黄泥冈松林：杨志坐在松荫下，手里拿着椰瓢，将吃半瓢；老谢都管与军汉已饮尽一桶，聚在
空酒桶边；白胜手拄扁担立在一旁，两虞候随老都管立；七个贩枣客人立在对面松林边，七辆江州车一字摆开。无人倒地。具名杨志、
老谢都管、白胜；七客人不具名。三处依据：

- 「看看日色当午，那石头上热了，脚疼走不得。」
- 「杨志见众人吃了无事，自本不吃，一者天气甚热，二乃口渴难熬」
- 「拿起来只吃了一半，枣子分几个吃了。」

取此刻不取“军汉买酒”与“众人软倒”：买酒是争吵，软倒已有人倒地；杨志吃半瓢时药已入桶，各方同在场上，
松荫、酷热、江州车、担桶、椰瓢俱全，无人受伤。先后核对：杨志追入松林盘问、朴刀插地坐歇（前）→白胜上
冈、军汉要买、杨志用朴刀杆打人（前）→七客吃尽第一桶，吴用将药抖进瓢，白胜夺瓢倾入第二桶（前）→
军汉、都管、虞候吃尽第二桶（紧邻此刻之前）→杨志吃半瓢（此刻）→白胜收半贯钱，挑空桶下冈（后）→七客喊
“倒也”、众人软倒（后）。

## 器物与环境

- 地点：黄泥冈，“顶上万株绿树，根头一派黄沙”，山边茅草、满地石头；军汉歇在一片松荫下，七辆江州车在对面
  松林里；冈下七八里没有人家。
- 时令：六月初四日，晴，“没半点云彩”，日头当午，酷热；石头烫脚。
- 器物：江州车（独轮手推车，无前辕）；担桶（木桶带盖）；椰瓢（椰壳剖半）；干枣（色未写，兜底：红枣）；
  金珠担子十一副；朴刀、藤条；酒是乡野白酒，宋代指浊酒，乳白色，不画蒸馏酒瓶。
- 现实中会动的：① 地面与石面的热气蒸腾、远处景物晃动；② 松枝松针在热风里微摆，树影缓移；③ 椰瓢里的
  酒面随手微漾。

## 排除项

- 后：七客喊“倒也”、众人软倒、装车推下冈、杨志醒来欲跳冈、白胜下冈；前：杨志追入松林、朴刀杆打军汉、
  下药手法（幕后，不画药粉）。
- 吴用铜链、公孙胜道袍与古铜剑、三阮渔民装束不入画；七客此刻只作贩枣客，只有刘唐的朱砂记可见。
- 杨志的范阳毡笠、白缎征衫（第12回）与军官披挂（第13回）不用；不画脸谱，青记画成胎记。
- 原文设定盛夏贩枣，实际枣秋熟，作画从原文，不改季节、不去枣；黄泥冈今址为传说，不画现代标牌。
