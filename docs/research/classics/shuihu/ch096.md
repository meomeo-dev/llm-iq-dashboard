# 《水浒传》第96回 幻魔君术窘五龙山　入云龙兵围百谷岭

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第096回>；读取日期：2026-10-20。

## 情节要点

1. 破乔道清妖术的先生是公孙胜；二月初八日戊午，戊属土，他请天干神将克壬癸水，现出青天白日，
   与宋江并马到阵前，布置徐宁、索超、王英、孙新截住乔道清进城之路。
2. 五龙山前斗法：乔道清使费珍的枪飞出，公孙胜使秦明的狼牙棒迎击；乔道清招黑、青、白、赤四龙，
   公孙胜招黄龙，五龙空中乱舞；公孙胜掷麈尾化大鹏，击碎泥龙，乔道清败走。
3. 林冲、汤隆杀倪麟、雷震，索超、张清、徐宁大败北军；公孙胜述罗真人“遇德魔降”法旨，领兵
   追击，乔道清退入百谷岭神农庙，被四面围住。
4. 宋江围昭德两日不下，吴用说“只消用几张纸”，此城唾手可得。

## 选定场面

白天，昭德城南五龙山前，两阵之间的上空：公孙胜与乔道清各立马阵前，五条龙（青、黄、赤、黑、
白）从山凹与山顶飞出，在空中盘舞，狂风吹得两阵旗帜歪斜；公孙胜左手握剑，右手把麈尾向空中
掷出，麈尾翻滚，刚化成鸿雁大小的一只鸟起飞，尚未变大；乔道清仗剑立马，仰头望着空中的五龙。宋江与
公孙胜并马，宋江居中，公孙胜在其左手侧。具名公孙胜、乔道清、宋江。选它是因本回斗法最醒目、而不涉杀伤的一刻，
且“五龙”“麈尾化鸟”不同于第54回公孙胜的黄沙纸兽。三处依据：

- 「五条龙向空中乱舞，正按着金、木、水、火、土五行」
- 「公孙胜左手仗剑，右手把麈尾望空一掷」
- 「那麈尾在空中打个滚，化成鸿雁般一只鸟飞起去」

先后核对：枪与狼牙棒在空中相斗（前）→乔道清招黑龙、公孙胜招黄龙迎住，再添青龙、
白龙、赤龙（前）→五龙乱舞，狂风卷倒旗手，公孙胜掷麈尾，化鸿雁般的鸟（此刻）→鸟渐高渐大成
大鹏，扑击五龙，泥龙碎裂落下，打伤北军，龙尾击乔道清冠（后）→五雷正法，金甲神人（后）。
此刻鸟尚小，无泥块落下，乔道清冠端正，不画枪与破鼓。

## 器物与环境

- 地点：昭德城南五龙山前，北军寨在山下；山凹里有龙王庙，泥塑金装彩画的青黄赤黑白五龙盘柱（事后
  才交代，此刻不画庙）。五龙分别自山凹、山顶飞出，黑龙自黑云中现，黄龙“半云半雾”。
- 时令天气：二月初八日（原文）；公孙胜破水法后“现出青天白日”，此刻在巳牌之后、申牌之前，
  兜底：早春晴昼，山色未青，空中一抹黑云，风急。
- 五色依五行：青属木、白属金、黑属水、赤属火、黄属土（东青南赤西白北黑中黄，据摘要）。龙形
  兜底：长身无翼的中式龙，张鳞鼓鬣，不画西式有翼龙。
- 现实中会动的：① 旗帜与袍袖被狂风吹得猎猎摆动；② 坐骑甩头、鬃尾摆动；③ 五龙沿各自轨道
  盘旋（法术形象，闭合轨迹循环，人物与坐骑不整体位移）。

## 排除项

- 后拍：大鹏变大、泥龙碎落、泥块伤北军、龙尾击冠、“五雷正法”金甲神人喝“乔冽下马受缚”、
  林冲杀倪麟、汤隆杀雷震、百谷岭神农庙围困。前拍：枪与狼牙棒空中相斗（枪倒插战鼓）、
  第95回的黑气与黄袍神将。血与尸体一概不画。
- 与第54回公孙胜斗高廉区分：那回是黄沙、纸剪虎豹走兽，剑“背上悬”，坐骑为分鬃昂首黄花马；
  本回无黄沙、无走兽、无神兵，剑在手，坐骑为黄鬃昂首马。不画后土与白浪（第95回）。
- 公孙胜不持拂尘；剑握在手，不背在身后（第54回样式）；不画戏曲道士勾脸与飘带程式。
- 大鹏此刻只是鸿雁大小，不可画成遮天巨鸟。
