# 《水浒传》第17回 花和尚单打二龙山　青面兽双夺宝珠寺

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第017回>；读取日期：2026-10-19。

## 情节要点

1. 杨志失纲后离冈南行，盘缠尽，在曹正酒店赊吃、打倒后生，与曹正交手；曹正是林冲的徒弟，认出杨志，指点青州
   二龙山宝珠寺（金眼虎邓龙占据）。
2. 杨志投二龙山，傍晚入林，撞见赤条条乘凉的鲁智深，二人林中斗四五十合，鲁智深喝住，互报姓名；鲁智深说起
   被邓龙闭关拒入。
3. 二人回曹正酒店，曹正定计：杨志、曹正扮庄家，把鲁智深绑作醉和尚献与邓龙。
4. 次日午后上山，过三重关到宝珠寺佛殿，鲁智深拽脱活结头，一禅杖打死邓龙，杨志搠翻几名小喽啰，二人据二龙山。
5. 老都管等回北京诬杨志通贼；济州何涛领公文，何清说出贩枣客人的线索（下回接续）。

## 选定场面

次日午后，二龙山宝珠寺佛殿前：杨志、曹正扮庄家，押着用活结头绑住的鲁智深立在殿阶下；殿内佛像已抬走，
中间一把虎皮交椅，两个小喽啰扶出邓龙坐下，邓龙开口痛骂“前日点翻了我”。鲁智深尚未大喝，庄家尚未拽
索头，邓龙未被打。具名杨志、鲁智深、曹正、邓龙。三处依据：

- 「押到佛殿看时，殿上都把佛来抬去了，中间放着一把虎皮交椅」
- 「少刻，只见两个小喽啰扶出邓龙来，坐在交椅上。」
- 「你那厮秃驴，前日点翻了我，伤了小腹，至今青肿未消。」

二选一取此场，不取“曹正酒店交手”：酒店是路边争斗，只有杨志与曹正两个具名人物，背景平淡，且是兵刃将交；
佛殿一刻四人同框，山寨关隘、殿阶、交椅俱有原文，气氛紧绷而无人出手。林中赤条条乘凉的一幕为全裸，不选。
先后核对：林中脱衣、活结头绑缚（前）→山下答话、过三重关、山门下小喽啰辱骂（前）→押到佛殿，邓龙被扶出坐定
（紧邻此刻之前）→邓龙开口骂（此刻）→鲁智深睁眼大喝，庄家拽脱活结头，接禅杖，杨志撇笠提刀（后）→一禅杖
打死邓龙（后）。

## 器物与环境

- 地点：二龙山，“两下里山环绕将来，包住这座寺”，只一条路上关；三重关上擂木炮石、硬弩强弓、苦竹枪密攒；
  过关到寺前，三座殿门前一段“镜面也似平地”，周遭木栅为城；佛殿佛像已抬走，中间虎皮交椅，阶下为押人处。
- 时令：晌午后在林中绑缚，再到山下答话、上山，取午后；约六月初七（自六月初四失纲逐日推算），天气未写。
- 器物：活结头索子；水磨浑铁禅杖（六十二斤，光面铁杖）；朴刀；杆棒；虎皮交椅（交椅为交叉腿可折叠的椅，宋已有，
  座面皮或绳编；虎皮铺陈本回未细写）；关上灰瓶、擂木、炮石、强弩。
- 现实中会动的：① 木栅与枪尖上的枪缨、幡角在风中摆动（寨中常见物，原文未写）；② 牵索庄家手中的索子末端
  微微晃动，人物本体不动；③ 殿前日光里的尘土缓缓浮动。

## 排除项

- 林中赤条条乘凉（全裸，不选）、林中相斗；曹正酒店交手：均在本场之前，不入画。
- 后：鲁智深睁眼大喝“撮鸟休走”、拽脱活结头、接禅杖；一禅杖劈死邓龙（血腥）、杨志搠翻小喽啰、五六百人归降。
- 邓龙不画金色眼睛；鲁智深的皂直裰、戒刀、月牙铲（清代以来的形象）；杨志蓝脸谱；曹正的杆棒不举起（举起在后）。
- 曹正、小舅等扮庄家者不穿戏曲短打；寨门不画现代景区牌坊（二龙山今址有数说）。
