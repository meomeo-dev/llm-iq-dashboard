# 《水浒传》第64回 呼延灼月夜赚关胜　宋公明雪天擒索超

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第064回>；读取日期：2026-10-20。

## 情节要点

1. 关胜统一万五千人马出东京；宋江军在北京城外佯退，花荣、林冲、呼延灼在飞虎峪设伏，击溃李成、闻达追兵，回军至
   梁山泊附近，遇宣赞拦路。
2. 张横夜劫关胜寨被擒，阮氏兄弟与张顺再劫寨，阮小七被擒；次日关胜与宋江阵前相见，宋江拦下林冲、秦明，不愿伤关胜。
3. 呼延灼单骑夜访关胜，诈称宋江有归顺之意；次日阵前打落黄信，夜里引关胜偷营，关胜中伏被挠钩拖下马，宣赞、郝思文
   也被擒，三人归顺梁山。
4. 宋江带关胜等再攻北京；仲冬降雪，吴用夜里在城外河边狭路掘陷坑，平明积雪二尺，索超出城追赶李俊、张顺（下回
   接续坠坑被擒）。

## 选定场面

仲冬平明，北京城外靠山边河的狭路，夜雪后积雪约二尺：索超骑马，手中金蘸斧，飞马追来；李俊已弃马跳入路旁的
涧里（涧深未写，兜底：只露头肩），朝前喊“宋公明哥哥快走”；张顺在更前方催马奔逃；雪面平整，陷坑藏在雪下，
山背后的炮尚未响。具名索超、李俊、张顺。选它是因疾驰追击与平静雪面的反差，最能说清“诱敌”，且画在坠坑之前，
无人受伤。三处依据：

- 「是夜雪急风严，平明看时，约有二尺深雪」
- 「李俊弃马，跳入涧中去了，向着前面，口里叫道」
- 「索超听了，不顾身体，飞马抢过阵来」

先后核对：前夜彤云四合、纷纷雪下，吴用暗差步军在河边狭路掘陷坑，上用土盖（前）→夜里雪急风严，平明积雪二尺（前）
→索超点三百军马追出城，宋军四散奔走（前）→李俊、张顺勒马横枪迎敌，才交马即弃枪便走，引索超到坑边（前）→李俊弃马
跳涧，叫宋公明快走（此刻）→索超飞马抢过阵来（此刻）→山背后一声炮响，索超连人带马坠下（后，不画）。索超左臂箭疮
（第63回）此刻已愈（本回写他“起病饮酒”“今番且复此仇”），不画绷带。

## 器物与环境

- 地点：北京大名府城外，“靠山边河路狭处”，“一边是路，一边是涧”；城头在远处。
- 时令天气：“正是仲冬天气，时候正冷，连日彤云密布，朔风乱吼”；前夜“雪急风严”，平明积雪约二尺；此刻是否仍落雪未写，
  兜底：灰云低垂，风卷细雪。两宋河北冬季严寒（据摘要），大名具体降雪未检得。
- 器物：金蘸斧；李俊、张顺弃在雪中的枪；陷坑本回只写“掘成陷坑，上用土盖”，宋代陷马坑长五尺、阔三尺、深四尺，坑内植尖木，
  上覆草土（据摘要），画面雪面平整，不画坑口与坑内。
- 现实中会动的：① 风卷雪粒、细雪斜飘；② 索超的盔缨、袍摆与马鬃马尾被风吹动，马蹄带起雪沫；③ 涧边枯草茎随风颤动。
  人物与马不整体位移。

## 排除项

- 后拍：山背后炮响、索超连人带马坠坑、伏兵齐起、被擒、宋江解缚（第65回开头）；不画落坑受伤。前拍：吴用掘坑过程；
  月夜呼延灼赚关胜（红灯、月色如昼）；张横、阮小七劫寨；关胜被挠钩拖下马。
- 他回：第13回校场比武与雪白马；第63回索超左臂中箭、撇斧回马；关胜点灯看书。
- 后世：戏曲索超勾脸与靠旗（京剧有《收关胜》等剧目，据摘要）、影视明式盔甲与金属板甲不画。
