# 《水浒传》第15回 吴学究说三阮撞筹　公孙胜应七星聚义

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第015回>；读取日期：2026-10-19。

## 情节要点

1. 吴用向晁盖举荐石碣村打鱼的阮氏三兄弟，当夜三更动身，次日晌午到石碣村。
2. 吴用假称替财主买金色鲤鱼，与阮小二、阮小七、阮小五在湖上会合，三船同到水阁酒店饮酒；席间三阮说出
   梁山泊被王伦占据、不容打鱼，抱怨无路可走。
3. 当夜宿阮小二家，吴用点明北京生辰纲，三阮慨然愿往；次日到东溪村与晁盖、刘唐会合，翌日六人焚香设誓。
4. 散福饮酒时，一清道人（公孙胜）在庄外打倒十来个庄客，自称送十万贯来见晁盖；晁盖引入阁中，有人自阁外
   闯入揪住公孙胜（下回揭晓是吴用）。

## 选定场面

石碣湖荷花荡，水阁酒店前：三只小船并缆在水亭下，阮小二扶吴用上岸，尚未入店；阮小五、阮小七各在自己
船上（此刻位置原文未写，取留船）。具名吴用、阮小二、阮小五、阮小七。三处依据：

- 「当下三只船撑到水亭下荷花荡中，三只船都缆了。」
- 「扶吴学究上了岸，入酒店里来，都到水阁内拣一副红油桌凳。」
- 「数十株槐柳绿如烟，一两荡荷花红照水。」

取此刻不取庄外打庄客、六人盟誓：前者是斗殴且已是回末，后者超过四个具名人物；水阁前三阮同框，出场与
衣冠样貌原文逐人写足，无冲突。先后核对：小二引吴用上船、小七自芦苇摇船出（前）→往小五家无果、小五在
独木桥边解船（前）→三船并行划到水阁（前）→三船缆定、扶吴用上岸（此刻）→入阁坐红油桌凳、叫酒切牛肉
（后）。

## 器物与环境

- 地点：石碣村湖荡，紧靠梁山泊。水阁酒店“前临湖泊，后映波心”，凉亭窗开碧槛，水阁中朱帘，红油桌凳；
  船泊在水亭下的荷花荡里。村口枯桩缆小渔船，疏篱晒破鱼网。
- 时令：五月初（“如今却是五月初头”）；吴用晌午到村，三船又划半个时辰，取午后；天气未写。原文荷花已开
  （北方荷花常在六月后开，据搜索摘要），依原文画花。
- 器物：小渔船三只，各一人划桨；桦木桨；缆绳与木桩；红油桌凳。
- 现实中会动的：① 荷叶、荷花与槐柳枝条随风摇；② 船舷周围水波圈纹扩散、船身随波轻晃；③ 水阁朱帘被风
  吹动（原文“风动朱帘”）。

## 排除项

- 前：吴用在阮小二家门前问鱼、阮小五赌钱输钱；后：当夜后水亭饮酒、说梁山泊王伦、盟誓、公孙胜打庄客。
- 他回：三阮日后的水军头领装束与官军厮杀；公孙胜、晁盖、刘唐不在湖上；吴用铜链。
- 阮小五青豹只在胸前，不画成满身花绣或龙纹；阮小七不画脸谱黑脸；石榴花只一朵在鬓边。
- 石碣村今址有东平石庙村、梁山县石庙村、影视基地数说，不画现代景点与牌坊。
