# 《水浒传》第48回 一丈青单捉王矮虎　宋公明两打祝家庄

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第048回>；读取日期：2026-10-20。

## 情节要点

1. 前夜宋江军陷在盘陀路，石秀赶到传令“只看白杨树转弯”，花荣一箭射落树影里的红灯，伏兵大乱；天明少了黄信，
   他被挠钩搭去。
2. 宋江到李家庄求见李应，李应称病不见；杜兴告知：西边扈家庄有女将一丈青扈三娘，白杨树已被砍伐，只宜白日进兵。
3. 宋江亲领马麟、邓飞、欧鹏、王矮虎做先锋，两打祝家庄；在庄后遇扈三娘引三五百庄客从西面杀来，王矮虎出战，
   斗十余合被她活捉。
4. 欧鹏、马麟与她相斗；栾廷玉飞锤打伤欧鹏，秦明、邓飞中绊马索被擒；扈三娘追宋江，林冲赶到，将她活捉，宋江
   令送上梁山交宋太公。
5. 吴用带阮氏三雄、吕方、郭盛来援，称祝家庄旦夕可破（下回接续）。

## 选定场面

白日，祝家庄后侧山坡下：扈三娘引二三十骑庄客从正西杀来，王矮虎听说是女将，喊一声骤马向前、挺枪迎敌；两人刚在
马上交上手，扈三娘拍马舞双刀，王英单枪架隔，胜负未分。具名扈三娘、王英；宋江在马上观战，可作远景。取这一刻，
因“提离雕鞍”擒人在后，此刻只有双刀对单枪的马上相斗，无血。三处依据：

- 「抡两口日月双刀，引着三五百庄客」
- 「一个双刀的熟闲，一个单枪的出众。」
- 「连环铠甲衬红纱，绣带柳腰端跨。」

先后核对：宋江转到庄后，见铜墙铁壁（前）→正西一彪马军杀来，山坡下二三十骑簇拥一员女将（前）→宋江留马麟、邓飞把后门，
自带欧鹏、王矮虎迎接（前）→王矮虎“指望一合便捉得过来”，骤马挺枪出迎（紧邻前）→扈三娘拍马舞刀来战（此刻）→斗十数合，
王英枪法架隔不住，手颤脚麻（后）→扈三娘直上直下砍入，王英拨马欲走（后）→被赶上，“把右手刀挂了”，轻舒猿臂提离雕鞍（后）。
故此刻两刀都在扈三娘手里，王英枪在手，未现颓势。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 扈三娘 | 扈家庄女将，绰号一丈青（含义无定论：刺青、蛇、发簪等说，据摘要，不据此画文身）；“天然美貌海棠花”；“蝉鬓金钗双压，凤鞋宝镫斜踏。连环铠甲衬红纱，绣带柳腰端跨”：两支金钗压着蝉鬓（蝉鬓是鬓发梳得薄如蝉翼，据摘要），盔、翎诗中未写，兜底：不戴盔、不插翎；连环甲里衬红纱，腰束绣带，凤鞋踏宝镫。坐骑“青鬃马”（底本作“青騣马”；“青骢”是青白相杂毛色，另一词，不据此定毛色，兜底：青灰色马）。两手各一口日月双刀（宋代无定型“日月刀”，据摘要，兜底：两口弯背单手刀，刀身短阔）。年纪本回未写 | 第48回 |
| 王矮虎（王英） | 两淮人，绰号矮脚虎，“五短身材，一双光眼”（第32回）；本回“好色之徒”，挺枪架隔（“单枪”指一条枪，与扈三娘的双刀相对，不指单手持枪），坐骑雕鞍；战袍盔甲本回未写（第32回清风山“天青衲袄锦绣补”不是战装，不取），兜底：战袄外罩短甲，不戴金盔；马色未写 | 第48回；第32回 |
| 群像 | 扈家庄庄客，随扈三娘二三十骑（庄客总数“三五百”）；衣着未写，兜底：短衣包头，持枪棒 | 第48回 |

## 器物与环境

- 地点：独龙岗后祝家庄后侧山坡下；庄后“铜墙铁壁”，庄前绕岗一带长流水、遍植垂杨（诗）；扈三娘军从“直西”来。
- 时令：白日（杜兴：“只宜白日进兵”；“宋江见天色晚了”在后）；季节未写。兜底：晴日，黄土山坡，不画雪。
- 器物：日月双刀；单枪；雕鞍、宝镫；连环甲。红锦套索第55回才写，本回无。
- 现实中会动的：① 马蹄踏起的尘土；② 枪缨、马鬃马尾随奔势飘动；③ 扈三娘腰间绣带与铠下红纱随风摆。

## 排除项

- 后拍：王英手颤脚麻、回马欲逃、被提离雕鞍活捉、庄客拖走；欧鹏、马麟、秦明、邓飞相战，绊马索、挠钩；扈三娘追宋江、
  林冲活捉她。前拍：夜战盘陀路、花荣射灯、李应不见客。
- 红锦套索：第55回“袍底下取出红锦套索，上有二十四个金钩”，本回擒人是徒手提，不画套索；影视里甩绳套的造型
  （据摘要）不取。
- 戏曲刀马旦：红女甲、红福巾、双雉鸡翎、木跷（据摘要）不画；不戴盔、不插翎、不全身红衣（红只在铠下），不画文身。
- 他拍人物：祝彪（第48回另一刻骑劣马使长枪）、祝龙、栾廷玉飞锤、林冲蛇矛、李逵板斧、宋江红帅字旗；王英不画猥亵表情。
