# 《水浒传》第1回 张天师祈禳瘟疫 洪太尉误走妖魔

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第001回>；读取日期：2026-10-19。

## 情节要点

1. 嘉祐三年三月三日，京师瘟疫，仁宗依范仲淹之奏，遣殿前太尉洪信持丹诏、御香赴信州龙虎山，
   宣嗣汉天师张真人入京设罗天大醮。
2. 洪信依住持真人之言布衣步行上山，半山遇吊睛白额虎、雪花大蛇，又遇倒骑黄牛吹铁笛的道童，
   道童即天师，洪信不知，下山。
3. 次日游山，右廊后见封皮重叠、铜汁灌锁的“伏魔之殿”；洪信不听真人三番五次劝阻，逼令开殿。
4. 殿内火把照见中央石碑，碑后凿“遇洪而开”；洪信命人放倒石碑、掘起石龟、再掘见大青石板，
   众人扛起石板，穴中一声响亮，黑气滚起，散作百十道金光，众人惊走。
5. 住持真人将说出缘由，一百单八魔君之说在下回交代。

## 选定场面

伏魔殿内，青石板已被众人扛起，地穴刚露，穴中一声响亮，黑气正从穴口滚起（尚未冲顶、殿角未塌、
金光未散）。具名洪太尉，另有住持真人、火工道人与从人群像。理由：这是回目“误走妖魔”的转折一刻，
黑气、火把、躺倒的石碑和掀开的石板自成构图，无人受伤。

- 「众人只得把石板一齐扛起。」
- 「只见穴内刮喇喇一声响亮。」
- 「那一声响亮过处，只见一道黑气，从穴里滚将起来」

先后核对：揭封、砸锁、推门→火把照碑→“先把石碑放倒”→掘起石龟→掘下三四尺见石板→扛起石板→
一声响亮、黑气滚起（此刻）→黑气冲半天、掀塌半个殿角、散作金光，众人发声喊都走了（后）。
故画面中碑已躺倒、龟已掘出，石碑不能仍立在穴上；众人尚未奔逃。

## 器物与环境

- 地点：龙虎山上清宫右廊后“伏魔之殿”，椒红泥墙，朱红隔子两扇，檐前朱漆金字牌额；门锁（铜汁灌铸）、
  十数道封皮已去。殿内黑洞洞，数百年不见日光，四边并无一物，只中央一座石碑。
- 石碑：高五六尺，下为石龟趺坐、大半陷泥；前面龙章凤篆、天书符箓（人皆不识），后面四个真字
  “遇洪而开”。此刻碑已放倒，龟已掘出，坑深三四尺，大青石板“可方丈围”被扛起，下为“万丈深浅地穴”。
- 时令：途中“风和日暖”“奇花绽锦绣”，为春；开殿在抵山第三日早膳后，殿内全靠十数火把，天气未写。
- 现实中会动的：① 火把火焰与烟；② 黑气自穴口翻滚上升；③ 袍袖衣摆与尘土被穴中气流带动。

## 排除项

- 后一刻：黑气冲半天、掀塌殿角、散作百十道金光；众人奔逃，洪太尉面色如土，真人叫苦。
- 前面场面：朝堂；吊睛白额虎、雪花大蛇；骑黄牛吹铁笛的道童（天师）；上山的布衣、草鞋、银手炉。
- 石碑不是“石碣”：“石碣受天文”在第71回；不画一百单八个名字、星宿图或人形魔君，一百单八之数
  下回才由真人说出；碑不画立着，黑气不画成红色或人形。
- 后世改编：影视把魔君具象化的造型不取；98版央视剧对此段“点到为止”，新版由公孙胜转述（据摘要）。
- 史实：嘉祐三年瘟疫、范仲淹荐天师不见史载，虚靖天师张继先属徽宗朝，洪信为小说人物（据摘要）。
