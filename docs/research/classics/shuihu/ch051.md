# 《水浒传》第51回 插翅虎枷打白秀英　美髯公误失小衙内

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第051回>；读取日期：2026-10-20。

## 情节要点

1. 雷横离开梁山回郓城，在勾栏看白秀英说唱，因没带钱打赏，与白玉乔争吵、动手打人；白秀英向知县哭诉，雷横
   被枷号示众。
2. 雷横母亲送饭，被白秀英掌掴，雷横抡枷梢打死白秀英（不画）；朱仝解送途中私放雷横，自己刺配沧州。
3. 沧州知府见朱仝美髯，留在府中使唤；四岁小衙内爱扯他的长髯，朱仝每日抱他上街玩耍。
4. 七月十五盂兰盆夜，朱仝抱小衙内去地藏寺看放河灯；雷横、吴用现身请他上山，朱仝拒绝，转身时小衙内不见了。
5. 李逵杀害小衙内（不画）；朱仝追到柴进庄上，才知是吴用之计，朱仝说要依他一件事才肯上山（下回接续）。

## 选定场面

七月十五盂兰盆夜，初更，沧州地藏寺水陆堂前放生池边：朱仝把四岁的小衙内扛在肩背上，立在池边栏杆旁看放河灯；小衙内
伏在栏杆上笑，池里莲花灯一盏盏漂着。雷横此刻还没出现。具名朱仝（另有小衙内，无名）。一个刺配的粗汉小心驮着知府的
独子看灯，气氛温和，全程无人动手，后事只作伏笔不入画。三处依据：

- 「那小衙内穿一领绿纱衫儿，头上角儿拴两条珠子头须」
- 「朱仝肩背着小衙内，绕寺看了一遭」
- 「那小衙内爬在栏杆上，看了笑耍」

先后核对：朱仝入府听用，小衙内扯髯要抱（前）→七月十五天晚，侍婢传夫人话叫抱去看河灯（前）→小衙内穿绿纱衫，朱仝
拖在肩头上，往地藏寺（前）→绕寺一遭，到水陆堂放生池边，小衙内爬在栏杆上笑耍（此刻）→背后有人拽袖，是雷横，朱仝
说“小衙内且下来，坐在这里”，可知此前他在朱仝肩上（后）→朱仝转身说话，小衙内不见（后）。故此刻朱仝未回头、未买糖、
未与人说话。

## 器物与环境

- 地点：沧州地藏寺水陆堂前放生池。沧州在河北东路，小说作“横海郡”，宋时实为横海军（据摘要）；地藏寺原文外无出处。
  寺内“钟声杳霭，幡影招摇，炉中焚百和名香……莲花池内放明灯”；池上有桥（小衙内后说“去桥上看河灯”），池边有栏杆。
- 时令天气：七月十五，初更；稍后“月色明朗”，兜底：满月初升，夜空清朗，暑热已退，不画雨雪。
- 器物：河灯（原文只写“放河灯”“莲花池内放明灯”，形制未写；兜底：莲花形小灯，灯盏点烛，浮在水面；南宋《梦粱录》
  有七月十五放江灯记载，据摘要）；经幡；香炉；纱衫用轻薄罗纱，是宋人夏衫常用料（据摘要）。
- 现实中会动的：① 河灯随水缓漂、烛火摇晃，水面碎光；② 经幡在夜风里飘；③ 香炉青烟缓缓上升。

## 排除项

- 后拍：雷横拽袖、吴用现身；朱仝买糖、过桥；李逵抱走小衙内；林中遇害；追到柴进庄。前拍：雷横梁山作别、勾栏打
  白玉乔、枷打白秀英、私放雷横、刺配上路；小衙内扯髯、街上买糖。
- 不画雷横、吴用、李逵、白秀英、知府；不画任何死亡或血迹。
- 朱仝此刻不戴枷、不提刀，不拉小衙内手离开栏杆；小衙内不改穿他色。
- 戏曲影视：红脸勾画、关公戏装不入画；不画塑料或电子河灯。
