# 《水浒传》第97回 陈瓘谏官升安抚　琼英处女做先锋

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第097回>；读取日期：2026-10-20。

## 情节要点

1. 宋江依吴用之计，把晓谕缚在箭上射入昭德城；守城偏将金鼎、黄钺杀死副将叶声等，竖降旗，
   放出李逵、鲁智深等八人。宋江入城安民。
2. 戴宗报卢俊义已克晋宁，带降将孙安来见。孙安单骑上百谷岭，以“遇德魔降”的法语说服乔道清，
   同到公孙胜军前；公孙胜以宾礼相待，席间乔道清拜公孙胜为师。
3. 戴宗赴东京报捷。宿太尉奏陈瓘《尊尧录》无罪，天子加陈瓘枢密院同知、任安抚，
   领御营军二万往宋江军前督战并犒赏。
4. 田虎闻昭德危急，邬梨荐女儿琼英（梦神人授艺，飞石百发百中，号“琼矢镞”）为先锋，
   田虎封她郡主；邬梨、琼英领兵奔昭德。琼英本回只被提到，没有出阵。

## 选定场面

昭德城东北百谷岭，平明。乔道清出神农庙，登高崖瞭望，见城外围兵已撤、城门内宋军出入；
此时一位樵叟腰插柯斧，以扁担作拐杖，沿崖畔走上崖来，口唱六句樵歌。乔道清立在崖边听歌，
心中恍然。具名乔道清，另有无名樵叟。选它是因全回少有的不涉兵戈、又扣住“劝降”主线的静景：
崖、庙、远城三层，构图简单，歌词“预为下山谋”暗示乔道清将归顺。三处依据：

- 「腰插柯斧，将扁担做个拐杖」
- 「一步步捉脚儿走上崖来」
- 「乔道清听了这六句樵歌，心中颇觉恍然」

先后核对：乔道清败走，屯神农庙数日（前，第96回）→ 城中呐喊，出庙登崖，见宋兵入城（前）→
樵叟走出崖畔树林，上崖唱歌，乔道清听歌（此刻）→ 问城中消息，樵叟答金鼎黄钺献城，转过石崖
离去（后）→ 孙安单骑上岭，同入庙叙话（后）。此刻孙安未到，费珍、薛灿与十余军士留在庙里，
樵叟尚未答话也未离去。

## 器物与环境

- 地点：昭德城东北百谷岭，相传神农尝百谷处，岭中有神农庙（第96回）。庙在崖下，庙里只有三个道人；
  崖畔有树林，樵叟从林中走出。远处山下是昭德城，“四门竖起降旗”，旗色未写。
- 现实参照：长治东北百谷山（今老顶山）有神农庙，北齐建（据摘要），与岭、庙的方位相合。
- 时令天气：第96回为二月初八，围城数日，约二月中旬；“平明”见城内呐喊；天气未写，兜底：
  初春清晨，薄雾，晴；树木刚发新芽，不画满树繁花，不画雪。
- 器物：崖石，岭上松与杂树，柯斧（柴斧，非军用长柄战斧），扁担。
- 现实中会动的：① 崖边松枝与新叶随风轻摆；② 山谷薄雾缓缓飘移（兜底，原文未写）；
  ③ 乔道清鹤氅下摆与丝绦、樵叟衣角与须发随风飘动。人物不整体位移。

## 排除项

- 后拍：孙安单骑上岭、二人入庙叙话、乔道清拜伏公孙胜、宋江置酒。前拍：第95、96回的斗法，
  五条泥龙、金甲神人、黑气黄砂、道冠被泥龙尾打瘪的一击。
- 琼英、邬梨、田虎朝堂、宿太尉、陈瓘、戴宗赴京均不入画；琼英的飞石出阵在第98回。
- 乔道清不施法、不拔剑、不披发，不画戏曲道士扮相；公孙胜不在崖上；樵叟不画成神仙。
- 费珍、薛灿不上崖；不画宋军攻城与杀伤；不画樵叟担柴。
