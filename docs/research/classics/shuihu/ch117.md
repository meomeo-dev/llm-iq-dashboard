# 《水浒传》第117回 睦州城箭射邓元觉　乌龙岭神助宋公明

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第117回>；读取日期：2026-10-20。

## 情节要点

1. 宋江夜袭乌龙岭中伏，关胜、花荣抵住，李逵、鲁智深、武松等分路救出，退回桐庐。
2. 邓元觉赴清溪求援，方腊不发御林军；童贯、王禀、赵谭到桐庐；宋江得老农指路，率十二将走小路到东管；花荣在宋江身侧满弓一箭射杀邓元觉。
3. 方腊遣郑彪、包道乙来救，郑彪使黑气金甲神，王英、扈三娘死；黑雾蔽天，宋江迷路，梦中得秀才邵俊相救。
4. 武松左臂被混天剑所伤，自割断；鲁智深追夏侯成入深山；项充、李衮溪边阵亡。
5. 宋江与吴用在松林里寻到乌龙神庙，龙君像与梦中所见相同；夜里再梦邵龙君；关胜斩郑彪，凌振炮击包道乙，破睦州；马麟、燕顺战死。

## 选定场面

东管一带的松林里：郑彪的妖法使天地黑暗，宋江被一圈金甲大汉围住，惊倒在地，口称“乞赐早死”；风雨过后，刀不砍来，
一个秀才上前搀扶，是邵俊。具名宋江、邵俊，另有伏地的军士。选它因“神助”二字全在这一刻，且无人动手：一圈金甲巨汉、
白衣秀才、俯首的宋江，层次分明；“花荣满月射邓元觉”留在前一拍，不画。三处依据：

- 「看见一周遭都是金甲大汉，团团围住。」
- 「宋江抬头仰脸看时，只见面前一个秀才来扶。」
- 「头裹乌纱软角唐巾，身穿白罗圆领凉衫，腰系乌犀金鞓束带，足穿四缝乾早朝靴。」

先后核对：花荣射杀邓元觉（前）→郑彪黑气中现金甲神，王英、一丈青死；宋江与李逵、项充、李衮迎战（前）→黑云罩合，白昼如夜，
军兵自乱，宋江叹“莫非吾当死于此地矣”（前）→“从巳时直至未牌，方才黑雾消散，微有些光亮”，一圈金甲大汉围住，宋江惊倒，
军士伏地受死（前）→风雨过处，刀不砍来，邵俊来搀，口称“请起”，宋江抬头（此刻）→邵俊自报姓名，说方十三气数将尽，
邵俊把手一推，宋江惊醒，大汉原来都是松树（后）。此刻金甲大汉仍在，天色微亮，风雨刚过；金甲大汉不是郑彪法术里手持降魔杵的金甲神。

## 器物与环境

- 地点：东管一带的松林。原文：“撞到一个去处，黑漫漫不见一物”，醒后“一周遭大汉，却原来都是松树”，林中“未及半箭之地”有乌龙神庙。
  兜底：林中空地，松干高大，树皮红褐色、鳞状深裂（马尾松形态，据摘要），地面潮湿。
- 时间：黑雾从巳时到未牌方散，“微有些光亮”，风雨刚过；季节未写，第116回起已过数十日，桐庐又驻二十余日，兜底：初夏。
- 现实中会动的：① 松枝松针、枝头水珠随余风轻摇滴落；② 残雾缓缓散开，光线渐亮；③ 邵俊的巾角与衣袖随风轻摆。人物与松树不整体位移。

## 排除项

- 后拍：邵俊“把手一推”惊醒；乌龙神庙、龙君像、祭祀；夜间再梦“邵龙君”；武松左臂被砍、自割断；鲁智深追夏侯成；项充、李衮溪边阵亡；
  樊瑞作法、关胜斩郑彪、包道乙被炮击碎、破睦州；马麟、燕顺战死。
- 前拍：花荣满弓一箭射邓元觉（不画弓弦与中箭）；郑彪头顶黑气中的金甲神与降魔杵；王英、扈三娘死；黑云白昼如夜。
- 邵俊不画龙王冕服、龙鳞、龙角、仙气飘带与光环；不画戏曲或影视里的“神仙”扮相；金甲大汉不画成巨人怪兽。
- 不画吴用、花荣、关胜等不在此刻的人；不画乌龙神庙牌额。
