# 《水浒传》第92回 振军威小李广神箭　打盖郡智多星密筹

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第092回>；读取日期：2026-10-20。

## 情节要点

1. 盖州守将钮文忠（枢密使）有四威将、十六偏将、兵三万；方琼出东门迎战，花荣先后两箭射落
   方琼与张翔，宋军前队得胜。
2. 一阵怪风，吴用料贼兵夜来劫寨，三路设伏；安士荣劫寨中计，败回城中。
3. 攻城六七日不下；宋江、卢俊义、吴用到南门城下督战，城楼上杨端放箭，花荣接箭回射。
4. 吴用调时迁、石秀混入城放火，其余各营擂鼓放炮疑敌；解珍、解宝攀飞楼夺城，钮文忠出北门逃走。

## 选定场面

白天，盖州南门城下。杨端在城楼上向花荣放冷箭，花荣仰身接住来箭咬在口中，起身把枪挂在鞍上
的了事环，左手持弓，右手取箭搭上弦，觑定杨端：取箭已搭弦、弓将满未发的一刻，射的是人，不画
中箭。具名花荣、杨端；于玉麟、郭信在城楼上，花荣身后的游骑与远处的宋江等只作群像。选它是
因本回花荣三次射箭，只有这一次有咬箭、挂枪、搭箭的连贯动作可画。三处依据：

- 「杨端望见花荣渐近城楼」
- 「顺手只一绰，绰了那枝箭，咬在口里」
- 「起身把枪带在了事环上，左手捻弓，右手就取那枝箭，搭上弦」

先后核对：杨端搭箭射花荣前心（前）→花荣闻弦响仰身后倒，绰住来箭咬在口里（前）→起身，枪挂
了事环，左手持弓，右手取箭搭弦（此刻）→一箭中杨端咽喉，杨端倒下，军士滚下楼（后）→花荣冷
笑称“神箭将军”（后）。此刻口中无箭，枪不在手，杨端仍站在城楼垛口后、手里握弓，花荣骑在马上。

## 器物与环境

- 地点：盖州南门城下。盖州即北宋泽州（今山西晋城一带），书中地名与史实有出入（据摘要），
  题面只写“盖州城”。《武经总要》守城制度：城外凿壕、壕上设吊桥（钓桥），城上设女墙，十步及
  马面处设敌楼（据摘要）。本回只写“城楼”“城垣”，形制未写；兜底：夯土包砖城墙，墙头垛口，
  单层木构城楼，灰瓦；城下一道壕沟，吊桥收起。
- 时令天气：本回未写时辰与节令；第93回紧接“腊月将终”，推为冬末（推断）；兜底：晴日白天，
  枯草，不画雪（第93回雪在立春之后）。
- 器物：弓、雕翎箭、点钢枪、了事环（鞍上挂枪的环，据第34回、第92回两处用例推断，辞书专条
  未检得）。
- 现实中会动的：① 城头旗帜随风飘动；② 花荣坐骑摆尾、甩头，盔缨与袍角随风轻摆；
  ③ 垛口后军士探头又缩回。弓与箭保持搭弦状态，不放箭。

## 排除项

- 后拍：箭中杨端咽喉、杨端倒地、军士滚下城楼；时迁、石秀杀道人纵火；解珍、解宝夺城；钮文忠
  被李逵、鲁智深截住。前拍：射方琼、射张翔（前两箭）、张翔射孙立战马。血与尸体一概不画。
- 他回花荣射箭不混入：第33回射门神骨朵与头盔红缨，第34回射秦明盔缨，第54回射薛元辉。
- 花荣用弓，不画神臂弓（踏张弩，脚蹬张弦，据摘要），“神臂将”只是绰号。
- 不画白袍银甲与翎子（戏曲白袍小将、金盔银甲是艺术夸张，据摘要）；不画瞄准镜式的现代造型。
