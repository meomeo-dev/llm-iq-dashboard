# 《水浒传》第31回 张都监血溅鸳鸯楼　武行者夜走蜈蚣岭

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第031回>；读取日期：2026-10-20。

## 情节要点

1. 武松飞云浦杀尽四人后折回孟州，一更四点杀马院后槽，换上施恩送的新衣，翻墙入张都监府，在鸳鸯楼杀
   张、张、蒋三人及随从家眷，蘸血在粉壁写“杀人者，打虎武松也”，四更三点涉城濠出城。
2. 天将明武松困倦，在林中小庙睡下，被张青的四名火家用挠钩、绳索绑到十字坡草屋；张青、孙二娘认出，
   解缚款待，武松细说前情。
3. 孟州悬赏三千贯、画影图形缉捕；孙二娘提议扮行者，取出头陀遗物；张青替武松剪发，武松把银酒器留给
   张青，换成散碎金银。
4. 武松辞别张青夫妇出门，夫妻喝采“果然好个行者”；当晚离十字坡，十月月夜上高岭（蜈蚣岭）。
5. 岭上见墓庵窗前先生搂妇人看月，武松拔戒刀试刀，杀道童，与先生双刀对双剑斗十数合（下回接续）。

## 选定场面

十字坡张青酒店门前，十月傍晚（日短），武松辞行出门的一刻：行者衣物已全部上身，张青、孙二娘在旁
目送喝采（站位未写，兜底：立在门边）。具名武松、张青、孙二娘。三处依据：

- 「武松辞了出门，插起双袖，摇摆着便行。」
- 「张青夫妻看了，喝采道：『果然好个行者！』」
- 「前面发掩映齐眉，后面发参差际颈。」

取此刻而不取孙二娘取衣、武松试穿一刻：换装时头发尚未剪（先“解开头发，折叠起来，将界箍儿箍起”，照镜
大笑后才剪发），戒刀、度牒、缠袋也是辞行前才上身；出门时各件到位，且赞词紧随，可逐项核对。不取蜈蚣岭
试刀：先生搂妇人窗前看月，随后杀道童，均不入画。
先后核对：孙二娘列头陀遗物（前）→取包裹，教武松里外穿→着皂直裰、系绦、除毡笠、箍界箍、挂数珠（前）→
照镜大笑，张青剪发前后（前）→换银两拴缠袋系腰→饱食拜辞，腰里跨两口戒刀→度牒缝锦袋挂胸前（前）→
出门，夫妻喝采，赞词（此刻）→当晚离十字坡、见月上岭（后）→林中试刀杀道童（后）。“插起双袖”未检得注
释，袖姿兜底为双手拢袖，题面可只写迈步出门。

## 器物与环境

- 地点：“大树十字坡”，大树“四五个人抱不交”、枯藤缠绕，酒店为傍溪十数间草屋、柳树上挑酒帘（第27回）。
  本回只写张青“店面作坊，却有几处”，取店门前一处。
- 时令：“十月间天气，日正短，转眼便晚了”，说在出门之后；出门时辰未写，取日色偏低的傍晚，天空未写，
  不画雪、不画月（月出在上岭时）。
- 器物：皂直裰、杂色绦、铁界箍、数珠、沙鱼皮鞘、缠袋、锦袋度牒；剪刀已用完，不入画。
- 现实中会动的：① 酒帘与大树枯藤、柳条在晚风里摆动；② 直裰下摆与绦穗随迈步轻摆（人物原地迈步，
  不整体平移）；③ 胸前数珠随步微晃。

## 排除项

- 前后拍：鸳鸯楼杀人与血书、挠钩绑缚与梁上人腿；换装一刻（尚未剪发）；蜈蚣岭试刀、道士搂妇人、杀道童。
- 头发不画成披头散发或光头；金印不画成金色印章，脸上字不写可辨文字；界箍不画孙悟空式金箍、月牙箍、
  牛角箍（赞词“火眼金睛”只是比喻）。
- 戏曲：京剧《蜈蚣岭》武松戴道箍、蓬头小辫、加僧坎肩、持云帚（据已打开页面），不取。
- 他回：景阳冈红袄毡笠（第23回）、鹦哥绿紵丝衲袄（第24回）、孟州囚衣与枷；禅杖、月牙铲、朴刀不入手；
  孙二娘不敞胸，不画人肉作坊、人皮、人腿。
