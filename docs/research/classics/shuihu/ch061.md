# 《水浒传》第61回 吴用智赚玉麒麟　张顺夜闹金沙渡

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第061回>；读取日期：2026-10-20。

## 情节要点

1. 龙华寺僧人说出卢俊义；吴用要去北京说他上山，李逵自荐，宋江不允；吴用约法三章：戒酒、扮道童随行、
   一路不说话。次日二人下山，宋江等在金沙滩送行。
2. 途中李逵在店里打得店小二吐血，吴用赔钱。入城前约定暗号：吴用摇头，李逵便不动。南门军士说道童“鸟眼
   象贼”，吴用答称又聋又哑。
3. 吴用摇铃杵念口号，小儿跟着笑，来到卢员外解库门首；卢俊义请入后堂，吴用用铁算子推出“百日血光之灾”，
   劝他往东南千里外避祸，并留卦歌四句（藏“卢俊义反”）写在白粉壁上。
4. 卢俊义不听李固、燕青劝阻，带十辆车子赴泰安州，沿途被梁山诸将轮番引入圈套，黄昏逼到鸭嘴滩；芦苇中
   渔人（李俊）与阮氏三兄弟围船，张顺从水底掀翻了船。

## 选定场面

上午，北京大名府街市，卢员外解库门首：吴用手摇铜铃，口念卦语，李逵跟在身后，肩担木拐棒，棒头挑着写
“讲命谈天，卦金一两”的纸招儿，几个小儿跟着看笑。具名吴用、李逵，另有群像小儿。选它是因两人的伪装全在
此刻：道装、铃杵、招牌、哑道童，一眼可认，且无任何动手。三处依据：

- 「吴用手中摇着铃杵，口里念四句口号道」
- 「却好转到卢员外解库门首，自歌自笑，去了复又回来」
- 「挑着个纸招儿，上写着：‘讲命谈天，卦金一两。’」

先后核对：店中换装（前）→南门盘问、吴用摇头李逵低头（前）→吴用摇铃杵念口号，小儿五六十个跟着笑（前）→
转到解库门首，自歌自笑，去了复又回来（此刻）→卢俊义在厅前听见喧闹，叫当直请先生（后）→吴用与道童进厅，
李逵在鹅项椅上坐定（后）。此刻卢俊义在厅内未露面，李逵立着而非坐着，也未入厅，不画卢俊义。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 吴用 | 化名“张用”，号“谈天口”。头戴乌绉纱抹眉头巾，身穿皂沿边白绢道服，系杂彩吕公绦，脚穿方头青布履，手拿“赛黄金熟铜铃杵”。相貌本回未写，沿第14回“眉清目秀，面白须长”；兜底：中年文士，白面长须，黑纱头巾，白袍黑边；铃杵形制未写，兜底：一手摇小铜铃，一手持短铜杵，色如黄铜 | 第61回；第14回 |
| 李逵 | 扮哑道童：“髼松黄发”绾两个丫髻（兜底：发丝蓬松，梳成两个丫髻，发色用深褐，不画金黄或卷发），粗布短褐袍，系杂色短须绦，穿“蹬山透土靴”；肩担“过头木拐棒”，棒头挑纸招儿。面貌写汉人壮汉相貌，面皮深古铜色、粗糙，身粗腰壮；不写“黑凛凛”，不画异族面貌；闭口，不持板斧 | 第61回 |
| 小儿群像 | 原文只写“五六十个”跟着看笑；兜底：画五六个，梳双丫髻或留一绺（宋代常见儿童发式，据摘要），粗布短衣，拍手指点，不追打 | 第61回 |

## 器物与环境

- 地点：北京大名府（北宋四京之一，据摘要）街市。解库即当铺（宋代称质库、解库，据摘要），门面本回只写“门首”“厅前”；
  兜底：临街木构铺面，门前挂一块木刻“解”字招牌，不画明清当铺的“当”字幌子。
- 时令天气：本回未写时令；第62回称卢俊义“离北京是五月的话”，兜底：初夏晴日上午（卢俊义说“过午了去”，尚未过午）。
- 器物：铜铃杵；纸招儿（挑在拐棒头，字句见上）。假文引、铁算子、白粉壁是前后拍的器物，不画。
- 现实中会动的：① 纸招儿随步伐在拐棒头上轻晃；② 吴用持铃的手腕小幅往复摇动；③ 跟着的小儿原地跳动拍手。
  吴用与李逵不整体位移。

## 排除项

- 后拍：入厅、揭帘、后堂铁算子、壁上写卦歌、卢俊义出行、白绢旗、林中李逵红巾铁甲双斧（第61回后半）、鸭嘴滩与张顺
  掀船。前拍：城门盘问假文引、店中打店小二。
- 李逵此刻无板斧，不开口、不坐；吴用不持羽扇、不戴九纶巾、不穿素罗袍（第54回军中装束，据原文），不画诸葛式纶巾羽扇。
- 戏曲：京剧李逵黑十字门脸（据摘要）不画；吴用不画成戏曲文丑扮相。
