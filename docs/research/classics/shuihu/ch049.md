# 《水浒传》第49回 解珍解宝双越狱　孙立孙新大劫牢

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第049回>；读取日期：2026-10-20。

## 情节要点

1. 登州知府限猎户三日内交虎；解珍、解宝兄弟带窝弓药箭上山，守了两夜无果，第三夜四更药箭射中一虎，
   虎带箭滚下山，落在毛太公庄后园。
2. 兄弟到庄上讨虎，毛太公设饭拖延、开园寻不见；兄弟砸了厅上桌椅，被毛仲义带来的做公人绑了，诬为抢劫，
   枷入大牢（不画）。
3. 小牢子乐和同情兄弟，到十里牌向顾大嫂报信；孙新、顾大嫂请来邹渊、邹润，又逼孙立入伙，定下劫牢计。
4. 顾大嫂扮送饭妇人入牢，里应外合劫出兄弟，随后血洗毛家、火烧庄院（不画）；众人奔梁山，路上在石勇
   店里献计打祝家庄（下回接续）。

## 选定场面

第三夜四更，登州山西山边：解珍、解宝背靠背坐在窝弓旁，困倦，却还没合眼；钢叉放在伸手可及处。窝弓已下好，
虎尚未出现，全程无血。具名解珍、解宝。两个猎户披虎皮豹皮、守夜等虎，造型鲜明，又避开中箭的虎。三处依据：

- 「穿了豹皮裤、虎皮套体，拿了铁叉」
- 「伏至四更时分，不觉身体困倦」
- 「两个背厮靠着且睡，未曾合眼」

先后核对：领杖限文书，回家整顿窝弓药箭、弩子鎲叉，穿上豹皮裤、虎皮套体（前）→头一日白天树上等了一日，收窝弓下
山（前）→第二日傍晚下窝弓、爬上树，等到五更无动静，移窝弓到西山边，坐到天明（前）→第三日夜伏至四更，困倦，背靠
背且睡、未曾合眼（此刻）→忽听窝弓发响，两人跳起来拿钢叉，见虎中箭在地上滚（后）→虎带箭逃，滚下山（后）。故此刻
钢叉不在手上，虎未到，窝弓未发。窝弓放处原文未写，按承上文推在西山边。

## 器物与环境

- 地点：登州城外山上，山名未写；登州在山东半岛东端，北宋属京东东路（据读取页面）。毛太公庄在山下，不入画。
- 时令天气：夜，四更（约凌晨1至3点，据读取页面）；季节、月色、天气本回未写，兜底：深夜疏星，不雨不雪。
- 器物：窝弓是猎人设在草丛里的伏弩，虎触机括即发箭（据摘要，宋代机括与绊线专条未检得；兜底：弓身固定在地，
  箭槽对着小径，一根细绳横过路面）；药箭，涂乌头一类毒药是古有的做法（据摘要），只画箭，不画毒液。
- 现实中会动的：① 夜风里草叶与树枝摇摆；② 山坡上薄雾缓缓飘移；③ 星光闪烁，二人胸口随呼吸微微起伏
  （人物位置不动）。

## 排除项

- 后拍：窝弓发响、药箭射虎、虎滚下山；毛太公庄讨虎、被绑、剥衣、押解；牢中乐和、顾大嫂、孙立。前拍：领杖限
  文书、前两日树上守候。
- 虎此刻不出现，不画虎、虎尸、血路；解珍、解宝不裸身，解宝腿上刺青不露。
- 他书他回：景阳冈武松、哨棒、吊睛白额虎；李逵杀虎（第43回）。
- 戏曲与现代：京剧《登州府》《猎虎记》一类的扮相不入画；不画猎枪、猎犬、火把（原文均未写）。
