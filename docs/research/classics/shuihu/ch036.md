# 《水浒传》第36回 梁山泊吴用举戴宗　揭阳岭宋江逢李俊

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第036回>；读取日期：2026-10-20。

## 情节要点

1. 赵能、赵得围庄，宋江自首；知县时文彬免上长枷，济州府判脊杖二十、刺配江州，戴行枷，由公人张千、
   李万押解；宋太公叮嘱路过梁山不可入伙。
2. 路上刘唐拦截，吴用、花荣赶到，劝宋江上山；宋江见晁盖后坚辞，吴用写信，举荐江州两院押牢节级戴宗。
3. 半个多月后宋江三人过揭阳岭，入李立酒店，酒肉里被下蒙汗药，三人倒地，被拖进人肉作房。
4. 李俊带童威、童猛上岭，查公文知是宋江，开枷灌解药救醒；李俊、李立下拜；宋江随李俊回家结拜。
5. 宋江辞行，在揭阳镇赏卖膏药的薛永五两银子，人丛里一大汉喝骂要打（下回接续）。

## 选定场面

揭阳岭下李立酒店前面的客位，暖日午后：宋江刚被解药救醒，枷已卸去，被两名汉子扶住，茫然不识众人；
李俊纳头便拜，李立也随后跪拜。具名宋江、李俊、李立，另有扶持宋江的汉子两名（童威、童猛，此刻尚未通名，
作群像）。三处依据：

- 「那大汉教两个兄弟扶住了宋江，纳头便拜。」
- 「宋江问道：『是谁？我不是梦中么？』」
- 「只见卖酒的那人也拜。」

这一刻正是回目“宋江逢李俊”的相会，地点在客位而非人肉作房，无刀无血。不取李立出来唱喏一拍（李俊未到）、
药酒倒地、揭阳镇卖膏药。
先后核对：宋江入店坐定，李立出来唱喏，先交钱后吃酒（前）→药酒麻倒，拖进作房（前，不画）→李俊三人上岭，
与李立说话，进作房看公文（前）→开枷，灌解药，四人扛宋江出前面客位，李俊扶住（前）→宋江渐醒，光着眼不
认得→李俊叫两个兄弟扶住，纳头便拜→宋江发问→李立也拜（此刻；李俊、李立同时跪着，宋江答礼“请起”在后）
→李俊通名（后）→救醒两公人（后）。枷已在作房开去，次日辞行才“再带上行枷”。

## 器物与环境

- 地点：揭阳岭脚边的酒店，“背靠颠崖，门临怪树，前后都是草房”，树荫下挑出酒旆；前面设客位桌凳，
  两根水火棍曾靠在壁上。揭阳岭属江州辖境，是小说地名，与广东揭阳无对应（据摘要）。
- 时令天气：宋江说“天色暄暖，趁早走过嶺去”，行半日方过岭头，此刻为午后（推算）；兜底：暖日、浓荫，
  不画雪。
- 器物：酒旆（宋代酒旗多为青白条布，据摘要，村店挑在檐下或树上）；桌凳、大碗、箸、熟牛肉与白酒碗碟
  （桌上残留为推断）；水火棍；宋江的包裹位置未写，不画；行枷留在作房，不入画。
- 现实中会动的：① 酒旆在风中飘动；② 怪树枝叶摇动，地上光斑随之晃动；③ 门外岭坡草叶随风起伏。五个人
  物仅姿态不变，不整体移动。

## 排除项

- 前拍：李立出来唱喏、药酒、倒地、拖进人肉作房、剥人凳、翻看包裹与公文；刘唐拦路、宋江自刎未遂、
  梁山上的聚义厅宴席。后拍：李俊通名、救醒公人、李俊家结拜、揭阳镇赏薛永、穆春喝骂。
- 作房里不画剥人凳、尖刀、人腿、人皮；两名公人不入画；宋江此刻不戴枷。
- 戴宗只被提及，不画；李俊不画戏曲脸谱；第37回浔阳江夜船与张横不入画。
- 金印指脸上刺字，不是金色印章；李立露两臂的背心不画成赤膊。
