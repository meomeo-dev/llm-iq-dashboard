# 《水浒传》第6回 九纹龙剪径赤松林 鲁智深火烧瓦罐寺

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第006回>；读取日期：2026-10-19。

## 情节要点

1. 智深进败落的瓦罐寺，老和尚说寺被崔道成（“生铁佛”）、丘小乙（“飞天夜叉”）占了；智深
   与崔道成斗了十四五合，丘小乙从背后助战，智深饥饿不敌，退走，包裹留在寺内。
2. 赤松林中，智深与剪径的史进拿杖握刀相斗，十数合后各通姓名，认出旧识。
3. 史进给干肉烧饼，二人回寺，合力杀死崔、丘（此事不入画）；老和尚已吊死，被掳妇人投井。
4. 二人取回包裹，放火烧寺，走一夜，次日在村店吃饭后分手；智深八九日后进东京，被派去管菜园。

## 选定场面

赤松林边，刀杖未交：智深提禅杖抢到林边喝叫，史进从林中拿朴刀跳出，智深抡起禅杖扑上，史进捻刀
“恰待向前”，二人还未通名。具名鲁智深、史进。理由：回目上联“九纹龙剪径赤松林”，二人兵器、
装束对照鲜明，赤松林红干成景，此一刻无伤亡；不取火烧瓦罐寺，因其前后是杀人、吊死、投井。

- 「提了禅杖，迳抢到松林边，喝一声：『兀那林子里的撮鸟快出来！』」
- 「就从林子里拿著朴刀，背翻身跳出来」
- 「那汉撚著朴刀来斗和尚，恰待向前」

先后核对：智深逃出数里，见赤松林→林中人探头吐唾、闪入→智深抢到林边喝叫→史进持朴刀跳出骂“秃驴”
→智深“教你认的洒家”，抡杖扑上，史进捻刀恰待向前（此刻，刀杖未交）→史进觉“声音好熟”发问→
智深答“斗三百合，却说姓名”→史进大怒迎杖，斗十数合（后）→叫少歇、通名、剪拂（后）。

## 器物与环境

- 地点：瓦罐寺外数里，赤松林一条山路；诗赞树干如“赤脚老龙”“红鳞巨蟒”，树顶如“朱砂铺树顶”。
  赤松实有其树，树皮橘红或红褐，中国天然分布在东北与山东（据摘要）。
- 时令：节令未写，紧接第5回（按初春推断），题面不指定；智深“从早晨直走到午后”，到寺后争斗再逃，此刻为午后偏晚（推断），
  林中有树影。
- 器物：禅杖；朴刀（刀装长杆，可拆装，宋代民间持有情况说法不一，无实物传世）；笠帽。
- 现实中会动的：① 两人衣摆与绦带随前冲摆动；② 脚下扬起的尘土与松针；③ 松枝晃动。

## 排除项

- 后一刻：交手十数合、撇朴刀剪拂；回寺杀崔、丘，尸体，吊死老僧，投井妇人，火烧瓦罐寺的火光。
- 前一刻：抢粥，槐树下吃酒的妇人，老僧；崔、丘用朴刀围攻。
- 他回：东京相国寺、菜园、泼皮（第7回）；第4回醉闹；第5回桃花山、周通。
- 兵器：朴刀不是大刀、青龙刀；禅杖杖头原文未写，不画月牙铲，写“粗铁禅杖”；史进此刻不用第2回的
  三尖两刃刀，不骑火炭赤马，不披朱红甲。
- 戏曲影视：脸谱、勾脸、靠旗不取。
- 地理：瓦罐寺无公认现实原型，与南京瓦官寺无关（据摘要）。
