# 《水浒传》第8回 林教头刺配沧州道 鲁智深大闹野猪林

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第008回>；读取日期：2026-10-19。袁本把禅杖救人一节
放在第9回开头，另读 <https://zh.wikisource.org/wiki/水滸傳_(120回本)/第009回>。

## 情节要点

1. 高俅在节堂要斩林冲，转送开封府；孙孔目周旋，判脊杖二十、刺面，配沧州，钉七斤半团头铁叶护身枷，
   差董超、薛霸防送。
2. 州桥下酒店，林冲当着张教头与邻舍立下休书，娘子哭倒；林冲拜辞，随公人上路。
3. 陆谦在酒店用十两金子买通董超、薛霸，要他们在僻静处结果林冲，带回脸上金印作凭据。
4. 六月炎暑，林冲棒疮发作；薛霸用滚汤烫伤他的脚，次日逼他穿新草鞋，脚泡磨破，五更入野猪林。
5. 两公人借口要睡，把林冲连手带脚和枷绑在树上，薛霸举棍欲劈；本回止于举棍，智深现身在下回开头。

## 选定场面

野猪林中：林冲连枷绑在松树根上，薛霸双手举着水火棍，松树背后飞来的铁禅杖正撞在棍上，棍被隔偏、尚未
飞出的一刻。具名林冲、薛霸、董超、鲁智深（此刻只见禅杖，人在松树后）。三处依据：

- 「把林冲连手带脚和枷紧紧的绑在树上」（第8回）
- 「薛霸的棍恰举起来，只见松树背后雷鸣也似一声」（第9回开头）
- 「那条铁禅杖飞将来，把这水火棍一隔」（同上）

取这一刻而不取“智深跳出、抡杖要打”：棍与杖同发于“说时迟，那时快”，是回目“大闹”的起点，公人尚未挨打，
不见血。先后核对：董超薛霸各拿水火棍→薛霸双手举棍→松后一声响、禅杖飞来隔棍（此刻）→棍丢去九霄云外，
跳出胖大和尚→智深抡杖欲打公人→林冲睁眼认出，喊“师兄不可下手”→割断绳索（均在后）。此刻林冲仍绑在树根，
闭目待死（“方才闪开眼看时”在后，闭目为推断）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 林冲 | 戴七斤半团头铁叶护身枷（枷上贴有封皮）；面颊刺字，即“金印”：原文自注“只唤做打金印”，是墨刺的字，不是金色印章，左右颊未写；背受二十脊杖、棒疮未愈；双脚被滚汤烫起泡，又被新草鞋（麻编耳）磨破渗血；豹头环眼，三十四五岁；靠树根坐，索子连手带脚和枷绑在树上。衣着本回未写，兜底：囚徒粗布衣，包裹已解下搁在树根头 | 第8回；第7回 |

| 董超 | 同押林冲；转身拿起水火棍立在一旁，未动手；衣着、面貌未写，兜底同薛霸 | 第8回 |

## 器物与环境

- 地点：东京去沧州路上第一个险峻去处野猪林，韵文“枯蔓层层如雨脚，乔枝郁郁似云头”；第9回写“松树”
  “松林”，题面写松树；行李包裹堆在树根头。
- 时令：六月炎暑；五更出店，又走了数里才入林，应在清晨，林中明暗未写，兜底：晨光稀薄。
- 器物：薛霸腰间解下的索子，水火棍两根，包裹，护身枷。水火棍形制未写，兜底：齐眉长的圆木棍，下端红、
  余黑（据摘要）。
- 现实中会动的：① 禅杖飞来、水火棍被撞偏旋出；② 林间枯藤、松枝摇晃，松针碎叶震落；
  ③ 树根下尘土被气流扬起。

## 排除项

- 后一刻：智深跳出、抡杖、割索，林冲劝止；棍劈中、见血、首级；一棍打折松树、送到沧州（第9回）。
- 前一刻：开封府审问、州桥下立休书、陆谦行贿、烫脚。
- 林冲无枷、面无字、金色圆印、骑马、持枪（枪是第10回）；脸谱化的黑白花脸。
- 后世造型：京剧《野猪林》的脸谱与戏台身段、月牙铲式禅杖、红袈裟。
