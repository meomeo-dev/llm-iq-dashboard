# 《水浒传》第114回 宁海军宋江吊孝　涌金门张顺归神

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第114回>；读取日期：2026-10-20。

## 情节要点

1. 费保劝李俊趁早寻退路，李俊约定日后来投；宋江取秀州，降将段恺献城，安道全被召回京；柴进、燕青潜入方腊腹地。
2. 杭州由方腊太子方天定守，有二十八将；宋军分三路进兵，花荣射王仁、秦明击凤仪；徐宁中毒箭而死，郝思文被害。
3. 张顺夜里从西湖潜近涌金门，扯水帘铃响，爬城时被射死；当夜宋江梦张顺来辞别，次日得报，决意亲到湖边吊孝。
4. 宋江经西山小路到灵隐寺，次夜在西陵桥设祭，李逵等预先伏在暗处；祭奠中伏兵一齐起。

## 选定场面

夜里近一更，西湖边西陵桥上：宋江身挂白袍，金盔外蒙一层孝绢，立在祭案正中，仰天朝涌金门方向哭，亲手举杯浇奠；
戴宗立在侧边，手持祭文宣读；五七个僧人立在祭案一侧，铃已停摇；桥上陈着黑猪白羊、金银祭物、灯烛与香；水边插一面白幡。
具名宋江、戴宗，另有僧人与军校群像。选它因为回目点名“宋江吊孝”，白幡香案构图庄重，不涉张顺中箭，也不画伏兵。三处依据：

- 「宋江挂了白袍，金盔上盖着一层孝绢」
- 「军校已都列下黑猪白羊，金银祭物，点起灯烛荧煌，焚起香来。」
- 「次后戴宗宣读祭文，宋江亲自把酒浇奠，仰天望东而哭。」

先后核对：午后得报张顺被射死、首级挑在城上；宋江暗从西山小路到李俊寨，在灵隐寺方丈歇下，请僧诵经追荐（前，次日以前）→
次日天晚，小军去湖边插白幡，桥上排祭物，李逵埋伏北山路口，樊瑞、马麟、石秀左右埋伏（前）→ 近一更，宋江、戴宗并五七个僧人
从小行山转到西陵桥，军校已列好祭物、点烛焚香（前）→ 宋江居中朝涌金门哭奠，僧人先摇铃诵咒、招魂坠神幡，随后戴宗宣读祭文，
宋江浇奠、仰天望东而哭（此刻）→ 桥下两边一声喊，南北两山鼓响，两彪军马来拿宋江（后，不画）。僧人诵咒在读祭文之前，
所以此刻僧人手中的铃不摇。伏兵都在暗处，不入画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 宋江 | 汉人相貌，面色紫棠、身矮，不画刺字（第72回已点去）。“挂了白袍，金盔上盖着一层孝绢”：白袍披在身上，金盔外蒙白色孝绢（里面是否披甲未写，兜底：白袍下露出革带，不画甲片）。哀容含泪，仰面向上，一手持杯倾洒；不佩刀、不持兵器；站在祭案正中，面朝画面右侧（东，涌金门方向） | 第114、36、72回 |
| 戴宗 | 神行太保。第38回：“面阔唇方神眼突，瘦长清秀人材”，转述为脸宽口方、目光有神（不画凸眼）、身形瘦长。本回衣着未写，兜底：深色长衫扎腰，皂纱巾（不插花），双手展开祭文卷宣读，立在宋江侧边；甲马此刻不画 | 第114、38回 |
| 僧人 | “五七个僧人”，“摇铃诵咒”；僧衣色未写，兜底：灰褐僧袍、褐色袈裟，光头，手持小铃垂于身侧或合十，立祭案一侧，不超过六人 | 第114回 |
| 军校 | 已列祭物的军校数人，头巾战袄，立桥边暗处；其余伏兵不入画 | 第114回 |

## 器物与环境

- 地点：西陵桥即今西泠桥，在孤山西端、西湖北侧，北山路与孤山之间，今为石拱桥（维基已读）；宋以前此处为渡口，宋代桥形未检得。
  兜底：湖边一座低栏石桥，桥面平台摆祭案；湖对岸东面是城墙与涌金门剪影（涌金门吴越时始建，临西湖，南宋改称丰豫门，据摘要），
  城头不画挑起的人头。
- 祭物：“黑猪白羊，金银祭物，灯烛荧煌，焚起香”，香烛数量原文未写。宋代祭牲羊、豕合称少牢（据摘要）。兜底：长案上猪、羊各一
  （熟牲，已洗净，摆在盘中，不见血），案前香炉一只、烛台数对、纸锭一叠、酒壶与杯。白幡一面插水边，旁人手持的神幡不画，
  幡上字“亡弟正将张顺之魂”不画可辨。
- 时令天气：前一夜写“时当春暖，西湖水色拖蓝，四面山光叠翠”“月色微明”；次夜月色未写。兜底：春夜，薄云微月，灯烛为主光源，
  湖面深蓝。
- 现实中会动的：① 香烟袅袅上升、烛火摇曳；② 白幡、孝绢与白袍下摆随风轻摆；③ 湖面细波映着烛光闪动。僧人不摇铃，
  宋江只做小幅倾杯，人物不位移。

## 排除项

- 后拍：桥下喊声、南北两山鼓响、两彪军马；李逵、樊瑞、马麟、石秀伏兵；前拍：张顺潜近涌金门、扯水帘铃响、城上掷土石、被射死、
  首级挑竹竿；宋江梦张顺、血污魂影；灵隐寺方丈内诵经；徐宁中箭、郝思文被害。
- 不画张顺的形象、鬼魂、血污，不画牌位（原文无）；不画人头。
- 宋江不穿麻衣、不披麻绳、不戴麻冠（原文只写白袍与孝绢）；不画戏曲孝服与影视造型。
