# 《水浒传》第62回 放冷箭燕青救主　劫法场石秀跳楼

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第062回>；读取日期：2026-10-20。

## 情节要点

1. 张顺水底擒住卢俊义，梁山上下以礼相待；吴用在金沙滩骗李固说卢已坐第二把交椅，壁上四句诗暗藏“卢俊义反”。
   卢俊义被留两个多月，中秋前才得辞归。
2. 卢俊义在城外遇见被逐的燕青，不信，入城即被擒；梁中书以反诗定罪，杖打后上铁叶盘头枷。李固、柴进两头行贿，
   蔡福兄弟周旋，判脊杖四十、刺配沙门岛，差董超、薛霸押送。
3. 李固重贿董、薛在路上结果卢俊义；林中薛霸举棒时，燕青在树上放箭救主，卢俊义随后又被官差捉回。
4. 燕青路遇杨雄、石秀，同上梁山报信；石秀独自入城，听说次日午时三刻在市曹斩卢，便在十字路口酒楼上等候。
5. 法场上石秀应声大叫，从楼上跳下，砍翻十数人，拖住卢俊义便走；梁中书下令关闭四门（下回接续）。

## 选定场面

正午，大名府市曹十字路口，酒楼下围成的法场：卢俊义跪在楼前，枷已开去，两手被缚；酒楼窗口，石秀握腰刀
纵身跃出，人在半空，刀举过头、尚未落下；蔡福、蔡庆已撇下卢俊义，转身退走；四周是刀棒刽子、公人、皂纛旗和
闭户的街市。具名石秀、卢俊义、蔡福、蔡庆。选它是因楼上楼下的高度对比、法场阵仗一眼可辨，画的是出手前一刻，
无人受伤。三处依据：

- 「石秀只就那一声和里，掣着腰刀在手，应声大叫」
- 「蔡福、蔡庆撇了卢员外，扯了绳索先走。」
- 「石秀从楼上跳将下来，手举钢刀」

同句下半“杀人似砍瓜切菜”是下一拍，不画。先后核对：押到楼前跪下（前）→蔡庆说五圣堂已安排坐位（前）→“午时三刻
到了”，开枷，蔡庆拿住头，蔡福掣出法刀（前）→孔目读罢犯由牌，众人齐和（前）→石秀掣腰刀大叫，蔡福、蔡庆撇下
卢俊义先走（此刻）→石秀跳下（此刻，半空）→落地砍杀、拖卢便走（后）。此刻枷已开；“扯了绳索先走”对绳去向含混，
兜底：卢俊义双手仍反缚，不画绳索拉扯。

## 人物造型

| :-- | :-- | :-- |
| 石秀 | 拚命三郎；身材匀称（“好个壮士，生得上下相等”），此刻睁圆双眼，已吃过酒肉。入城前装束：茶褐攒线袖衫，腰系绯红缠袋，脚穿踢土皮鞋，跨腰刀；范阳遮尘笠与短棒此刻放处未写，兜底：不戴笠，头裹巾，不持棒；包裹已交燕青，不背包；脸上无刺字 | 第62回；第44回 |
| 卢俊义 | 三十二岁，“身躯九尺”“威风凛凛”；杖打后皮开肉绽；囚衣未写，兜底：粗布旧袍，发髻松乱，跪姿。枷：刺配时换二十斤铁叶盘头枷，林中被燕青劈碎，法场“蔡庆扶着枷梢”后“开枷”，此刻枷在身旁地上；刺字：判词为“刺配”，李固称要“揭取脸上金印”，但原文至第66回始终未写刺面，兜底：脸上不画刺字 | 第61、62、63、66回 |

| 刽子手、公人 | “十数对刀棒刽子，前排后拥”，仗刃公人，高头马上的监斩官；衣着未写，兜底：公人戴无脚幞头、短衣束带（宋代公差服式，据摘要），不穿红背心 | 第62回 |

## 器物与环境

- 地点：大名府市曹十字路口。石秀“临街占个阁儿”，在楼窗外看；法场“周回围住”，人家闭户关门。宋代大酒楼二至三层，
  门首彩楼欢门，楼上分阁子，阁子配吊窗花竹（据摘要）；楼高、栏杆本回未写，兜底：二层木构酒楼，临街窗前一道木栏。
- 时令天气：卢俊义五月离北京，中秋将近时辞山，行十日回城，此刻已入晚秋（押送一节写“晚秋天气”）；当日天气未写，
  兜底：晴，正午，日影短。
- 器物：犯由牌；皂纛旗、柳叶枪；白混棍；法刀；已开之枷；破鼓碎锣（“两声破鼓响，一棒碎锣鸣”）。“午时三刻”出自小说，
  宋制决囚在未申之间（据摘要），题面从小说。
- 现实中会动的：① 皂纛旗与枪缨随风飘动；② 石秀衣摆与腰间缠袋下垂的穗在下落中飘起；③ 鼓槌小幅往复敲击，人群中
  尘土微扬。石秀保持半空姿态，不做整体位移；其余人物也不整体移动。

## 排除项

- 后拍：石秀落地砍翻十数人；拖卢便走；梁中书关四门；两人被挠钩套索擒（第63回开头）。前拍：读犯由牌、蔡庆拿头、
  蔡福举刀；林中燕青树上放箭射薛霸、董超；薛霸举水火棍；村店烫脚；燕青射喜鹊遇杨雄、石秀。
- 不画砍首、血、尸体、中箭、刀得手；李固、贾氏、梁中书、燕青（正在山上报信）此刻都不在场，燕青的花绣与弩不画。
- 戏曲：红背心刽子手、鬼头大刀、插在背后的“斩”字亡命牌（原文只写犯由牌与法刀）不画。
