# 《水浒传》第77回 梁山泊十面埋伏　宋公明两赢童贯

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第077回>；读取日期：2026-10-20。

## 情节要点

1. 童贯在阵前输了一场，退三十里；三日后依酆美、毕胜之计摆长蛇阵，进到水泊边，只见隔水芦苇茫茫，山顶一面杏黄旗招飐。
2. 芦苇小船上有个渔人斜倚着船钓鱼，箭射箬笠蓑衣皆落水；会水军士下水去捉，被渔人（张顺）一一打下水。
3. 山顶黄旗磨动，哨马出哨时芦苇中炮响，朱仝、雷横的黄旗军杀出，诈败；童贯追到山脚，山顶画角齐鸣、两炮飞起，杏黄旗闪出，
   宋江带吴用等现身，鼓乐喧天，众好汉大笑。
4. 此后西、东、刺斜里的伏兵相继杀出：秦明、关胜，呼延灼、林冲，鲁智深、武松，解珍、解宝，董平、索超，杨志、史进，
   卢俊义活捉酆美，李逵、张清截杀，童贯连夜逃回东京；八路军官多人战死。
5. 宋江不肯追尽，放回酆美；吴用的“十面埋伏”大胜，宋江派人去东京探听消息。

## 选定场面

梁山泊水边的山脚：童贯在马上仰望山顶，山顶杂彩绣旗开处，宋江现身，“替天行道”杏黄旗立在他身侧偏后（相对位置未写，兜底），
吴用、公孙胜、花荣、徐宁与金枪手、银枪手列在身后，鼓乐喧天，众好汉大笑；官军分两路正要上山，童贯咬牙大怒。具名童贯、宋江，另有两员将官、官军群像
与山顶头领群像。选它是因为全回只有这一刻能同时看见“中计”的官军与有备的山寨，而无人动手。三处依据：

- 「只见山顶上闪出那面杏黄旗来，上面绣着‘替天行道’四字」
- 「背后便是军师吴用、公孙胜、花荣、徐宁，金枪手，银枪手，众多好汉」
- 「大军人马，分为两路，却待上山，只听得山顶上鼓乐喧天，众好汉都笑」

先后核对：渔人钓鱼、下水（前）→黄旗军杀出诈败（前）→山顶画角、两炮飞起、杏黄旗闪出（前）→童贯踅过山那边，宋江现身，
鼓乐喧天，众好汉笑（此刻）→童贯怒喝，酆美谏阻（后）→后军告急，西边伏兵杀出（后）→东边红、青旗（后）→刺斜里黑、白旗（后）。
“四面伏兵旗号齐起”在原文里是先后出现，不是同一刻：此刻只有山顶的杏黄旗与杂彩旗，朱仝、雷横的黄旗军已退到山后，
西、东、黑白各路都未出现，不可把各色旗拼进同一幅。

## 器物与环境

- 地点：梁山泊水边的山脚与山坡，近处隔水可见芦苇；山顶“杏黄旗”“杂彩绣旗”。梁山主峰高约198米（据摘要），不画雄山峻岭。
- 时令天气：本回未写；三日后的白昼，第78回蔡京称“炎热”，兜底：夏日晴昼，水边芦苇青绿，不画雪雨。
- 声响与烟：画角齐鸣，两炮“直飞起来”。宋代火药兵器是霹雳炮、震天雷一类，由抛石机抛射，并无近代炮管（据摘要）；
  兜底：空中两道火光烟迹，不画金属炮管。画角为彩绘细长号角（宋代形制未检得）；山顶另有大鼓与吹乐。
- 旗：杏黄旗上“绣”着“替天行道”四字，旗杆颜色不写；杂彩绣旗数面。不得套用景区朱红旗杆、黑字的杏黄旗（据摘要）。
- 现实中会动的：① 杏黄旗与杂彩绣旗在山风里飘动；② 山顶人物衣袍、盔缨与官军旗帜随风摆动；③ 空中两道烟迹缓缓扩散，水边芦苇摇摆。
  童贯、宋江及山体不整体位移。

## 排除项

- 后拍：酆美谏阻；后军告急；秦明、关胜红青旗；呼延灼、林冲黑白旗；鲁智深、武松；解珍、解宝；董平、索超；杨志、史进；
  卢俊义活捉酆美；李逵、鲍旭砍杀；张清飞石；夜间突围。前拍：张顺扮渔人，箭射箬笠蓑衣，五百军下水；朱仝、雷横与酆美、毕胜交锋。
- 不画斩将、落马、血水、溺水军士、童贯狼狈逃命；不把各路伏兵旗色拼进此刻。
- “十面埋伏”本是垓下之战与琵琶曲的典故（据摘要），项羽、韩信、汉楚军旗不入画；吴用不画成诸葛亮；不用戏曲龙套与靠旗。
