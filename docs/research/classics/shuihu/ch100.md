# 《水浒传》第100回 张清琼英双建功　陈瓘宋江同奏捷

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第100回>；读取日期：2026-10-20。

## 情节要点

1. 李俊约期决智伯渠、晋水灌太原城，张雄等被杀，城中军民死伤极多；卢俊义入城。
2. 田虎十万军在铜鞮山被宋军三路击溃；“全羽”率军假意救驾，引田虎到襄垣，城中伏兵，
   田虎坠马被张清、叶清擒住，张清自报真名。
3. 琼英依吴用密计，率五千人马打北军旗号，以南军兵卒扮作田虎，骗开威胜南门，擒田豹、田彪；
   卢俊义破沁源后入城，田定自刎。
4. 宋江与陈瓘在威胜会合，陈瓘遣人先送表章奏凯，戴宗赴东京；琼英请命去寻母亲遗骸。
   回末预告蔡京在武学谈兵，引出罗戬。

## 选定场面

威胜南城外，同日傍晚（据文意）。琼英率北军旗号的人马到城下，在马前高声叫门；城楼上，田豹、田彪闻报
赶来观看，只见赭黄伞下白马上坐着“大王”，马前一员女将。城门尚未开，无人被擒。具名琼英、
田豹、田彪，另有扮作田虎的南军兵卒（原文事后交代是假扮，并非真田虎）。选它是因全回大半是
厮杀，此刻是少有的不见兵刃的一刻，暮霞、新月、黄伞、白马色彩鲜明，又是回目“琼英建功”的
核心计谋。三处依据：

- 「暮霞敛彩，新月垂钩」
- 「果见赭黄伞下，那匹雕鞍银鬃白马上，坐着大王」
- 「旗上大书“郡主琼英”」

先后核对：琼英奉吴用密计，率五千人打北军旗号伏于石盘山侧，闻田虎与宋兵厮杀，星夜驰到威胜
城下（前）→ 天晚，琼英叫门；守门军卒飞报，田豹、田彪上马驰到南城，上城楼观看；琼英高声说
“保护大王到此”（此刻）→ 田豹等令开城门、出城迎接，“大王”喝拿下二贼，军士绑人（后）→
城上察觉，出城抢夺，琼英飞石打伤守门将士，夺南门（后）。真田虎已被擒在襄垣，张清不在场。

## 器物与环境

- 地点：威胜州（小说自注即沁州，北宋威胜军，据摘要）南城。原文只写“南城”“城楼”“开了城门”；
  宋代城制有城楼、敌楼、门外壕上吊桥（《武经总要》，据摘要）；兜底：城门洞上重檐歇山顶城楼，
  城墙垛口，门外护城壕，吊桥拉起。
- 器物：赭黄伞（宋代黄伞为皇帝专用，据摘要；原文称田虎出阵“九曲飞龙赭黄伞”）；兜底：曲柄
  赭黄伞，伞缘垂流苏。雕鞍银鬃白马，“郡主琼英”大旗，北军旗号。
- 时令天气：“暮霞敛彩，新月垂钩”，当日白天雨霁（原文“次日雨霁”）。日期未写，约四月（推算）；
  新月为农历初三前后傍晚西方低空的细月牙，亮面朝向落日，日落后很快落下（据摘要）；兜底：
  西边天际残霞，细月牙在低空，不画满月、半月。
- 现实中会动的：① 城楼与队伍的旗帜随风飘动；② 赭黄伞缘流苏与马鬃；③ 天边暮霞云带缓缓漂移。
  人物不整体位移。

## 排除项

- 后拍：假大王喝令拿人、军士绑田豹田彪、琼英飞石打人、夺南门、宋军入城、田定自刎、割首支解。
  前拍：张清全羽跪奏救驾、田虎坠马被擒、风中现出女子、唐昌被飞石打中、胡英陷坑。
- 他回：太原灌城、张横张顺斩张雄、陈瓘宋江迎见、戴宗赴京、凌迟田虎，均不画。
- 真田虎、张清、范美人、田定不入画；不画尸体、鲜血、陷坑；不画王宫燃烧。
- 琼英不画凤冠霞帔、戏曲靠旗，不用影视剧造型。
