# 《水浒传》第120回 宋公明神聚蓼儿洼　徽宗帝梦游梁山泊

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第120回>；读取日期：2026-10-20。

## 情节要点

1. 戴宗纳还官诰，出家泰安州岳庙；阮小七被夺官为民；柴进、李应推病纳诰；关胜醉落马死，呼延灼阵亡；诸将各赴任。
2. 高俅、杨戬与蔡京、童贯设计，诬告卢俊义造反，召至京赐御膳，暗置水银；卢俊义归途酒后落淮河而死。
3. 朝廷赐御酒，酒中下药；宋江中毒后召李逵至楚州，以药酒相送，嘱死后葬蓼儿洼；二人先后死；吴用、花荣梦中得讯，到墓前同缢，楚州百姓立祠。
4. 徽宗微行，倦极入梦，见戴宗引路，乘马登山，过三重关，宋江等在忠义堂前诉冤；李逵持斧奔来，帝惊醒。
5. 次日宿太尉也梦见宋江；遣人查实，徽宗敕封宋江“忠烈义济灵应侯”，在梁山泊建“靖忠之庙”。

## 选定场面

梦中梁山泊忠义堂：道君皇帝到堂前下马，上堂坐定，堂下烟雾中拜伏着许多人，宋江上阶跪膝，垂泪启奏。具名徽宗、宋江，
另有堂下俯伏的众将群像。选它因“梦游”二字全在这一刻：帝居堂上，宋江跪阶，众将伏于雾中，礼仪构图一眼可认，无任何动手。
饮毒酒、李逵持斧奔来、惊醒均不画。三处依据：

- 「上皇到忠义堂前下马，上堂坐定，看堂下时，烟雾中拜伏着许多人。」
- 「只见为首的宋江上阶，跪膝向前，垂泪启奏。」
- 「为头一个，凤翅金盔，锦袍金甲，向前奏道。」

先后核对：戴宗引上皇乘马登山，沿途“漫漫烟水……红瑟瑟满目蓼花”（前）→过三重关道，至第三座关前，见上百人俯伏，皆金盔金甲，
为首宋江自报姓名，请到忠义堂（前）→到忠义堂前下马，上堂坐定，堂下烟雾中拜伏众人；宋江上阶跪膝垂泪（此刻）→宋江诉冤、君臣问答，
上皇下堂，回首见牌额“忠义堂”三字（后）→李逵手握双斧奔来，帝惊醒（后）。此刻帝已下马、在堂上坐定，斧未现，牌额尚未被提及。

## 器物与环境

- 地点：梦中的梁山泊忠义堂前。第71回立“忠义堂”牌额、堂前设红旗两面、山顶立杏黄旗“替天行道”，本回梦中均未写，不画旗。
  兜底：宋式厅堂三间，朱漆柱，歇山顶（“厦两头”即歇山，据摘要），台基前有踏道，堂内正中设椅，堂前雾气弥漫，远处水港芦荡与关寨。
- 梦境景物：入山途中“漫漫烟水，隐隐云山……红瑟瑟满目蓼花，绿依依一洲芦叶……霜枫簇簇……淡月寒星长夜景，凉风冷露九秋天”。红蓼生水边湿地，
  花穗下垂，色紫红或淡红（据摘要）。兜底：堂外水边红蓼、芦苇、残荷，一弯淡月，数点寒星；时令深秋夜。
- 器物：椅，原文未写形制，兜底：漆木扶手椅，不雕龙纹（《宋太祖像》所坐为四出头扶手椅，据摘要）；无他物。
- 现实中会动的：① 堂前烟雾缓缓流动；② 水边蓼花、芦叶、疏柳随凉风摇摆；③ 薄云掠过淡月。人物与堂不整体位移。

## 排除项

- 后拍：宋江诉冤的对话；上皇下堂回望牌额；李逵手持双斧厉声奔来；皇帝惊醒、李师师在侧。
- 前拍：李师师宅中的地道、卧房、酒肴与灯烛；戴宗穿黄衫引路、乘马如云似雾；第三座关前上百人俯伏。
- 同回他拍：饮毒酒、水银御膳、宋江召李逵饮药酒、卢俊义落淮河、吴用花荣自缢、蓼儿洼坟冢与祠堂、宿太尉之梦、靖忠之庙与神像。
- 不画冕旒龙椅、金銮殿、戏曲蟒袍与脸谱；不画鬼魂特效；不画道冠道服的徽宗。
