# 《水浒传》第94回 关胜义降三将　李逵莽陷众人

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第094回>；读取日期：2026-10-20。

## 情节要点

1. 初六日宋江、卢俊义分兵东西两路；宋江东路途中见天池岭，李逵称与梦中所见无异。
2. 宋军在壶关南五里下寨；守将山士奇与林冲、张清、索超交战，折两将；关胜自卫州寄密信，
   说抱犊山寨主唐斌、文仲容、崔埜愿归顺，关胜曾单骑随唐斌上抱犊山。
3. 唐斌入关假意与山士奇约定接应，暗用绢帛缠箭射出密约；次日宋军内外夹击，唐斌在关门下夺关，
   山士奇败走，宋军入壶关，唐斌下马参见宋江，文仲容、崔埜随后入关参拜。
4. 田虎遣国师乔道清、殿帅孙安出兵；乔道清在昭德城北阵前挥剑作法，黑气罩住冲上去的李逵
   等五百人（后事见第95回）。

## 选定场面

壶关关门内外，宋军夺关之后的早晨：宋江率大军入关，唐斌下马，在宋江面前躬身下拜，宋江
还礼不迭，伸手去扶。具名宋江、唐斌；周围宋军与降兵作群像。此回回目“关胜义降三将”，
关胜本人不在壶关，三将归顺靠的是他的密信，所以不画“关胜阵前劝降”；唐斌下拜是原文里
“降”最直接的一刻，不涉厮杀。文仲容、崔埜此刻屯在关外，后来才进关，不同框。三处依据：

- 「须臾，宋先锋等大兵次第入关，唐斌下马，拜见宋江」
- 「宋江答礼不迭，慌忙扶起」
- 「宋某回朝，保奏天子，自当优叙」

先后核对：唐斌横矛立马于关门外喊话、戳死竺敬（前）→林冲、张清杀上关，李逵等抢上关放号炮，
夺了壶关（前）→宋江大军次第入关，唐斌下马拜见，又拜，宋江答礼扶起（此刻）→孙立等与文仲容、
崔埜屯关外，宋江传令二人入关参拜（后）→摆宴、遣唐斌打昭德（后）。此刻唐斌已下马，手中
无矛（矛放在何处原文未写，兜底：随从牵马并执矛立在其后）。

## 器物与环境

- 地点：壶关。原文：“壶关原在山之东麓，山形似壶，汉时始置关于此”“正在两山之中”，山东有
  抱犊山。今壶关县的古关在两山夹一“壶口”处（据摘要）。关楼形制本回未写，宋代关楼专条未检得；
  兜底：夯土砖包关墙，拱券门洞，洞上木构关楼，两侧山坡裸岩，不画明代长城式烽火台。
- 时令天气：本回未写；宋军初六日自盖州出发，围关半月余，加上等待又十余日，至第95回
  “二月初八日”前不久，推为早春（推断）；兜底：早春晴晨，山色青灰，树枝未发芽，不画雪与花。
- 器物：关楼旗帜（旗号未写，不写字）、战马、矛。
- 现实中会动的：① 关楼与关前旗帜随风飘动；② 战马甩头、摆尾，鬃毛抖动；③ 山腰流岚缓缓
  飘移。宋江与唐斌的姿势保持不变。

## 排除项

- 关胜不在场，不画关胜、青龙刀、红脸关公式造型；文仲容、崔埜不同框，不画“三将下马”同框。
- 前拍：山士奇与林冲、张清、索超交战，张清飞石打竺敬鼻凹见血，林冲刺伍肃，索超砍吴成，
  唐斌射绢帛箭，唐斌喊话并戳死竺敬；关外“杀死二千余人”的尸骸不画。
- 后拍：摆宴、唐斌打昭德、乔道清出场与黑气罩李逵（第94回末、第95回）。天池岭在盖州东三十余里，
  不属此刻。
- 不用戏曲翎子与靠旗；不画他版本中的开山大斧、绰号“拔山力士”（简本，据摘要）。
