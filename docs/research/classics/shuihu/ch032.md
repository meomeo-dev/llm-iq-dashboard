# 《水浒传》第32回 武行者醉打孔亮　锦毛虎义释宋江

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第032回>；读取日期：2026-10-20。

## 情节要点

1. 武松在蜈蚣岭杀“飞天蜈蚣”王道人、放火烧庵，向青州行去；沿途榜文处处，因已扮行者，无人盘问。
2. 十一月，武松在白虎山下村酒店连饮四角酒，酒家无肉可卖，又见孔亮自带青花瓮酒和熟鸡，一掌打肿店主，
   把孔亮打二三十拳后丢进溪里，吃去八分酒肉。
3. 醉后沿溪而走，被土墙里的黄狗追吠，拔刀追狗，一刀砍空，翻筋斗跌进溪里；孔明引庄客拿下，剥衣绑在柳树
   上用藤条抽打。
4. 庄上出来的宋江认出武松，解缚叙旧；孔太公设宴，十余日后宋江与武松在瑞龙镇三岔路口分手，武松往二龙山。
5. 宋江东投清风山，被绊索擒住绑上将军柱，临剜心时报出名字，燕顺、王英、郑天寿下拜赔罪；宋江劝下王英，放走
   清风寨知寨的恭人（下回接续）。

## 选定场面

白虎山下村酒店往前约四五里的溪岸，十一月，北风：醉醺醺的武松沿溪走着，旁边土墙里蹿出一只大黄狗追着他
叫；他左手从鞘里拔出一口戒刀，大步追狗，狗绕着溪岸叫，刀尚未挥出，人尚未跌倒。具名武松，另有黄狗一只。
三处依据：

- 「把直裰袖结在背上，便出店门，沿溪而走。」
- 「便将左手鞘里掣出一口戒刀来，大踏步赶。」
- 「那只黄狗绕着溪岸叫。」

此景单人单狗，不涉伤人，行者装束最全，“左手拔刀”可核对。不取打孔亮（拳打后丢入溪）、绑柳树抽打（剥衣）、
清风山绑将军柱（剜心）；瑞龙镇分别可作备选。
先后核对：蜈蚣岭杀人放火（前）→入酒店饮四角酒，打店主、打孔亮丢入溪，吃去八分酒肉（前）→醉饱，结袖出店，
沿溪而走，北风卷起、脚步不稳（前）→离店不到四五里，土墙里走出黄狗吠叫→左手鞘里掣出一口戒刀，大步追，
狗绕溪岸叫（此刻）→一刀砍空、头重脚轻、翻筋斗倒撞下溪，戒刀浸溪（后）→孔明引人到（后）。拔出的是一口，
另一口仍在鞘内；右手持物未写，兜底空手。

## 器物与环境

- 地点：白虎山下，酒店门前一道清溪，屋后乱石山；离店四五里的溪岸旁有土墙，墙边转过去即孔家庄（庄院
  “高墙粉壁，垂柳乔松”）。取溪岸、土墙、枯柳（枯柳为兜底）。
- 时令天气：“十一月间，天色好生严寒”，“朔风”“北风卷将起来”；“冬月天道，溪水正涸”，水深一二尺。
  兜底：枯草、落叶柳树，不画雪、不画冰。
- 器物：雪花镔铁戒刀，出鞘一口在左手；直裰结袖；溪水浅而寒。佛教律典里的戒刀是几指长的随身小刀，小说
  里的戒刀是长刀兵器（据摘要），本回按小说，兜底画成腰刀长度的单刃刀。
- 现实中会动的：① 溪水细波缓缓流动；② 北风吹动直裰下摆、绦穗和岸边枯草、柳条；③ 黄狗在岸边小范围
  往复奔绕、尾巴摆动（人物仅身体前倾摇晃，不整体平移）。

## 排除项

- 后拍：一刀砍空翻进溪里、戒刀沉水、孔明带人拿下、绑柳树抽打、宋江认出；前拍：打店主、打孔亮丢进溪里、
  青花瓮酒与熟鸡、黄狗从土墙里走出（此刻狗已绕着溪岸叫，土墙只作背景）。
- 不画刀斫中狗、狗受伤；不画孔亮、孔明、庄客入画；黄狗只一只。
- 武松此刻不持哨棒、朴刀（行者无棍），不戴毡笠，不剃光头，不披散成蓬头；金印不画金色印章。
- 他回/他处：第31回的十字坡换装与蜈蚣岭月夜；清风山木栅、将军柱、虎皮交椅与剜心；瑞龙镇三岔路口。
- 戏曲：京剧蓬头小辫、道箍、僧坎肩与云帚不取。
