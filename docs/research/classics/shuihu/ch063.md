# 《水浒传》第63回 宋江兵打北京城　关胜议取梁山泊

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第063回>；读取日期：2026-10-20。

## 情节要点

1. 石秀、卢俊义被擒后各上大枷，关入死囚牢，蔡福暗中照看；梁山撒“没头帖子”，梁中书与王太守议定留二人性命，
   李成、索超出城下寨，在飞虎峪、槐树坡布防并掘陷坑。
2. 宋江点兵下山，在庾家击败李成、索超；秦明与索超斗二十余合，韩滔一箭射中索超左臂；闻达飞虎峪夜里遭火攻，
   宋江围住北京东西北三面。
3. 梁中书派王定到东京求救；蔡京召集群官，宣赞举荐旧识关胜，蔡京定下“围魏救赵”之计。
4. 宣赞到蒲东巡检司礼请关胜；关胜带郝思文赴京，蔡京任关胜为领兵指挥使，郝思文先锋、宣赞合后，兵发梁山泊。

## 选定场面

白天（时令按兜底取初冬），蒲东巡检司门前：宣赞刚下马，身后跟着三五个从人和备好的鞍马、礼物；关胜与郝思文
听说东京来了使命，从衙内迎出，三人拱手施礼。具名关胜、郝思文、宣赞。选它是因三位日后一同上梁山的人物此刻
首次同框，场面平静、人物关系清楚，全无打斗。三处依据：

- 「当日关胜正和郝思文在衙内论说古今兴废之事」
- 「闻说东京有使命至，关胜忙与郝思文出来迎接」
- 「来到蒲东巡检司前下马」

先后核对：宣赞领文书、带三五个从人上马（前）→到巡检司前下马（前）→关胜与郝思文在衙内论说古今兴废，无读书
（前，室内）→听说使命，关胜忙与郝思文出来迎接（此刻）→各施礼罢，请到厅上坐地（后）→宣赞道明来意，关胜允诺
（后）。本回没有夜读：关胜“点灯看书”“坐看兵书”在第64回中军帐（张横劫寨），不在此刻，不画书。

## 器物与环境

- 地点：蒲东巡检司。蒲东在河东蒲州一带，近关羽故里（据摘要）；巡检司是宋代县以下的基层治安机构（据摘要）。衙署形制本回未写，
  兜底：瓦顶木构门屋，门内小院，正面一间厅堂，不挂带字旗幡。
- 时令天气：本回未写蒲东天气；北京围城一节是“秋末冬初”，宣赞出发在其后，兜底：初冬晴日，树叶半枯，人着袍外加披风，不画雪。
- 器物：太师文书、彩币、鞍马。
- 现实中会动的：① 马鬃与马尾随风甩动，马蹄轻刨；② 披风与袍摆被风吹起；③ 院中枯叶飘落一两片。

## 排除项

- 后拍：厅上叙话、关胜喜允；赴京见蔡京的节堂对话与“围魏救赵”；调兵起程。前拍：东京太师府宣赞举荐、童贯等众官；
  北京城下交战。
- 第64回的关胜：点灯看书、金甲绿袍、赤兔马、陷车擒张横、被呼延灼赚入埋伏；第66回“赤兔马、青龙刀”出阵，都不入此刻。
- 后世：整脸涂红的戏曲关公脸谱、卧蚕眉丹凤眼夸张、绿靠绿袍、五缕长髯、周仓捧刀、关帝像造型；“浦东”误写（应作蒲东）。
- 宣赞不画番人面貌、卷发、赤须；郝思文不画“井木犴”兽形。
