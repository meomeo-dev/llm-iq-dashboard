# 《水浒传》第105回 宋公明避暑疗军兵　乔道清回风烧贼寇

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第105回>；读取日期：2026-10-20。

## 情节要点

1. 王庆杀廖立占房山，趁房州兵变夺了州城，聚众二万；李助为军师后，王庆自称“楚王”，在南丰建宫立官，
   至宣和五年已占八座军州。宋江平定河北后奉诏南征。
2. 宋江军冒暑到阳翟，屯方城山林荫处避暑：安道全医治中暑军士，皇甫端调治马匹，公孙胜作法送凉风；
   宋江密授乔道清计策，让他到山棚去，又令张清、琼英、孙安、卞祥分伏东西山麓。
3. 七月中旬，宛州守将刘敏带火兵五千、火车二千辆夜袭。三更他乘南风放火，风忽转北，乔道清回风返火，
   火反烧向贼阵；宋军杀出，刘敏败回宛州。
4. 宋军围攻宛州，击退救兵，用囊土筑垒、飞桥登城克城，擒刘敏。八月初旬暑退，宋江分兵取山南军。

## 选定场面

方城山高冈上，乔道清立在小山棚前作法：夜里三更，山下贼军的火箭、火炬和点着的火车射向山林与山麓粮草，
南风忽转北风，漫山火光折回，朝南边贼阵飞去。选这一刻因“回风返火”正是回目所指，火势转向一眼可认，
且不必画人被烧。具名乔道清；山下贼军只作远处小黑影，火焰为主体。三处依据：

- 「又听得山上霹雳般一声响亮」
- 「那些火箭，火炬，都向南边贼阵里飞将来」
- 「却似千万条金蛇火龙」

先后核对：宋江令乔道清到山棚（前）→刘敏薄暮出城，遇南风大作（前）→三更到山南二里外，雾气弥漫山谷，
火箭火炮火炬射山林，火车点着推向山麓粮草（前）→南风忽转北风，山上霹雳一声，乔道清使回风返火（此刻）→
火箭火炬飞向贼阵，贼兵焦头烂额（紧后，不画）→凌振放号炮，张清、琼英、孙安、卞祥杀出（后）。此刻号炮未响，
伏兵未出，宋军山林与粮草未着火。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 乔道清 | 已降宋的前田虎国师。第94回：“头戴紫金嵌宝鱼尾道冠，身穿皂沿边烈火锦鹤氅，腰系杂色彩丝绦，足穿云头方赤舄，仗一口锟铻铁古剑”，“八字眉碧眼落肥胡，四方口”。“碧眼”改为中性画法：汉人相貌，眼睛画寻常黑色，八字眉、方口、须髯浓密。本回只写“使了回风返火的法”，姿势兜底取第95回“披发仗剑，捏诀念咒”：披发（去冠），鹤氅，一手持古剑指向山下南方，一手捏诀；年纪本回未写 | 第94、95、105回 |
| 山下贼军 | 刘敏所率火兵与推车军士；装束本回未写，兜底：远处小轮廓，铁盔甲，只见火把与车影，不画面孔，不画伤亡 | 第105回 |

## 器物与环境

- 地点：方城山（小说用名；真实方城山在今河南方城县，据摘要）。宋军屯在山上林荫深处，粮草堆在山南平麓；
  乔道清所在的山棚在“高冈凉荫树下”，用竹篷茅草搭成（原文作“出棚”，疑为“山棚”之误）。
- 时令天气：七月中旬新秋，三更；起初雾气弥漫山谷，南风正猛，随后转北风。月亮本回未写，不画月，
  以火光为主光源。构图约定：山在画面上方，南边贼阵在下方，火流自山向下方飞去。
- 器物：火箭（箭头附火药，弓弩通用，据摘要）、火炮、火炬；火车为战车二千辆，装芦苇干柴与硫黄焰硝，
  每车四人推，形制本回未写，兜底：木轮方车，堆苇束，被风吹偏的火苗盖住车身，推车人小到不可辨。
- 现实中会动的：① 火焰与火星顺风由山向南流动（循环）；② 山谷雾气与棚前树枝在风转时摆向另一侧；
  ③ 乔道清的披发、衣带与鹤氅下摆随风飘动。人物不整体位移。

## 排除项

- 后拍：贼兵被火烧、凌振号炮、张清琼英孙安卞祥杀出、鲁成、郑捷等贼将被杀与首级、宛州攻城；
  前拍：公孙胜作法送凉风、安道全医军士、皇甫端调马、宋江商议用火。
- 不画人被烧、死伤、首级；不画宋军山林着火。
- 乔道清不画成田虎时期的妖术场面（三昧神水黑气、神兵、冰雹、昭德阵前），不画道士脸谱；
  不画成赤壁借东风的祭坛、令旗、七星坛。
- 贼军不画成异族或丑化形象；公孙胜、宋江、吴用不入画。
