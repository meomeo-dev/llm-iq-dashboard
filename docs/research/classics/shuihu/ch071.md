# 《水浒传》第71回 忠义堂石碣受天文　梁山泊英雄排座次

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第071回>；读取日期：2026-10-20。

## 情节要点

1. 梁山聚满一百单八人，宋江要建罗天大醮，四月十五日起七昼夜；忠义堂前挂长幡，堂上扎三层高台，公孙胜主醮，道众连他共四十九人。
2. 第七日三更，西北天门开，一块火滚下虚皇坛，绕坛一周钻入正南地下；众人掘地不到三尺，得一石碣。
3. 平明，何道士（何玄通）辨认蝌蚪文：侧面刻“替天行道”“忠义双全”，前列三十六天罡、后列七十二地煞；萧让誊录，宋江赠金。
4. 宋江重排寨栅，山顶立杏黄旗“替天行道”，堂前立两面绣字红旗，颁兵符印信，众人歃血盟誓。
5. 重阳菊花会上宋江作《满江红》，李逵踢翻桌子被监；岁末宋江执意去东京看灯，引出下回。

## 选定场面

夜里三更，梁山泊忠义堂上，罗天大醮第七夜。西北方天空“如裂帛”一声，一个竖立的两头尖、中间阔的光洞（天门）打开，霞彩
缭绕，一块如栲栳大小的火球从中卷出，正向虚皇坛滚来，尚在半空，未触地。公孙胜居坛上高功位（三层高低原文未写，取最高），
众道士在下一层，宋江等头领在更下一层，仰面望天。具名公孙胜、宋江。三处依据：

- 「是夜三更时候，只听得天上一声响，如裂帛相似，正是西北乾方天门上。」
- 「里面毫光射人眼目，霞彩缭绕，从中间卷出一块火来，如栲栳之形，直滚下虚皇坛来。」
- 「公孙胜在虚皇坛第一层，众道士在第二层，宋江等众头领在第三层」

先后核对：首日撚香、公孙胜关发文书（前）→第七日三更，众人拜求报应（前）→天门开，火块滚下（此刻）→火块绕坛一周，
钻入正南地下，天眼已合，众道士下坛（后）→掘土得石碣（后）→平明取碣，何道士辨蝌蚪文（后）→择日立杏黄旗（更后）。
故此刻地上没有土坑、石碣，没有杏黄旗，火块也未落地；火球落地、石碣露出、杏黄旗立起在原文里是三个不同时刻，不可同画。

## 器物与环境

- 地点：忠义堂上（堂前敞开，可见夜空），“忠义堂前挂起长幡四首，堂上扎缚三层高台”，堂内七宝三清圣像、二十八宿、十二宫辰，堂外监坛崔卢邓窦
  神将；一千条画烛、数百盏银灯、羽盖幢幡（醮筵韵文）。北宋已有罗天大醮，神位一千二百（据摘要），此处七昼夜、道众
  四十九人是小说设定。
- 时令天气：宣和二年四月十五日起（榜文却署“宣和二年四月初一日”，原文前后不合，不采）；首日“天和气朗，月白风清”，第七夜
  天气、月相未写，兜底：晴夜星空，不画月。
- 天象：西北乾方为后天八卦的天门（据摘要），故光洞放画面上方偏左；“直竖金盘，两头尖，中间阔”；火块如栲栳（柳条编的斗形
  圆筐，直径约四五十厘米，据摘要）。
- 现实中会动的：① 火球定格在半空，周身光晕明灭（下坠是一次性动作，不作循环）；② 烛火、银灯摇曳，长幡幢幡飘动；③ 天门边缘的霞彩与云气流动。

## 排除项

- 后拍：火块绕坛一周钻入地下；众道士下坛；掘土取碣；石碣上的蝌蚪文、何道士辨读、萧让誊黄纸；赠何道士黄金五十两。
  前拍：首日撚香、公孙胜表奏。更后：杏黄旗“替天行道”（立在山顶，不在坛前）、堂前绣字红旗、菊花会、李逵踢桌。
- 石碣、蝌蚪文、土坑、杏黄旗、何道士不入此刻画面；监坛神将、三清像不画成特写。
- 影视和景区的杏黄旗（朱红旗杆、黑字，据摘要）不套用；不用戏曲道士扮相；不画“惊恶梦”（七十回本情节）。
