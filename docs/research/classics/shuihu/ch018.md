# 《水浒传》第18回 美髯公智稳插翅虎　宋公明私放晁天王

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第018回>；读取日期：2026-10-19。

## 情节要点

1. 何清出示抄录的客店簿子，指认晁盖；白胜被捉招供，济州府遣何涛持公文赴郓城。
2. 何涛在郓城县对门茶坊遇押司宋江；宋江借口回下处，飞马到东溪村报信，晁盖等收拾金银，吴用、刘唐先挑担去石碣村。
3. 宋江回茶坊稳住何涛，引他当厅投下公文；知县遣朱仝、雷横点马步弓手土兵一百余人，夜赴东溪村。
4. 朱仝主张分路：自己带三十人去后门，赚雷横随县尉去打前门；晁家庄起火，晁盖与公孙胜率庄客自后门杀出，
   朱仝叫住，虚闪一闪放开一条路，叮嘱“只除梁山泊可以安身”，又假称失足闪了左腿。
5. 雷横也有心放人；官军只拿到邻舍，两名庄客供出吴用、公孙胜、刘唐与三阮，何涛奉命去石碣村缉捕（下回接续）。

## 选定场面

一更夜，晁家庄后门：庄内中堂已起火，晁盖与公孙胜率庄客挺朴刀自后门冲出，晁盖大喝；朱仝立在门外黑影里，
朴刀在手（姿态原文未写，取垂持），叫住晁盖，尚未让路。画面中火光与黑影分界：晁盖在前、公孙胜在后（火光侧），朱仝在画面另一侧暗
处，长髯垂胸。具名朱仝、晁盖、公孙胜。三处依据：

- 「呐着喊，挺起朴刀，从后门杀将出来，大喝道：“当吾者死！避吾者生！”」
- 「朱仝在黑影里叫道：“保正休走！朱仝在这里等你多时。”」
- 「原来朱仝有心要放晁盖，故意赚雷横去打前门。」

取此刻不取“宋江飞马报信”：夜火、明暗对峙与朱仝的髯、面色是本回独有的构图，人物本体可保持站立；飞马
是整体位移，宋江的坐骑原文只写“马”。先后核对：分路议定、赚雷横（前）→晁盖叫庄客放火，率人后门杀出，
大喝（此刻）→朱仝黑影里叫住（此刻）→晁盖不顾、舍命冲出（紧随其后）→朱仝虚闪放路、叮嘱、假跌（后）。

## 器物与环境

- 地点：东溪村晁家庄，“前后两条路”，后门外通野田；中堂起火，前后门四面八方三四十处火起，黑烟遍地，红焰飞空。
- 时令：六月初旬（劫纲在六月初四日，具体日期原文未写）；一更，月黑；夏夜，火场热。
- 器物：朴刀、腰刀、弓箭；庄后门；火把（土兵“明晃晃照着三二十个火把”，在庄前）。
- 现实中会动的：① 火焰摇曳、火星与黑烟上升；② 火光在人物衣袍与地面上明暗跳动；③ 朱仝长髯与公孙胜袍角
  随热风微摆（人物不整体位移）。

## 排除项

- 前：宋江飞马报信、茶坊稳住何涛；后：朱仝虚闪放路、叮嘱梁山泊、假跌闪腿，雷横回转追赶，晁盖远去不见。
- 同夜但不入画：雷横打前门、县尉骑马、土兵举火把、吴用刘唐挑担去石碣村。
- 后文：朱仝任“当牢节级”、误失小衙内（第51回）；公孙胜呼风唤雨、驾雾腾云不在此夜。
- 戏曲影视：红脸花脸、关公式青龙偃月刀（朱仝此夜持朴刀）；晁盖影视里的大胡子（原著无）；宋江不入画。
