# 《水浒传》第104回 段家庄重招新女婿　房山寨双并旧强人

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第104回>；读取日期：2026-10-20。

## 情节要点

1. 王庆闯到定山堡，戏台搭在堡东麦地上，台下四面都是赌桌；他与人掷骰赢钱，输家动手，被他用跌法放翻，
   同伙抢了钱就走。
2. 段三娘（绰号“大虫窝”）站出来与王庆相扑，被王庆扭住放倒；范全赶到劝开，三娘交还原银。
3. 段太公来相看，算命先生李助（“金剑先生”，王庆旧识）做媒，招王庆为三娘的女婿，范全替他主婚，
   二十二日草草成亲。
4. 黄达告到房州，州尹派兵来捉；范全报信，李助劝众人投房山寨。途中王庆杀都头与黄达，
   在山下与寨主廖立动手，回末胜负未分。

## 选定场面

定山堡东麦地上，王庆与段三娘对阵、尚未交手的一刻：三娘已脱下外衫丢在身旁一张空桌上，踏步上前，右拳提起；
王庆见她起拳有破绽，有意逗她，拽双拳摆开门户。具名王庆、段三娘；后方戏台，台下原有三四十张赌桌，构图只画
几张空桌凳；三娘从“人丛里”闪出，围观村民只作远处小轮廓。
选它因这是全回唯一不涉血腥与闺房的对峙，二人衣着与架势在原文中写得最具体。它是一场街头打闹式的相扑，
不是正式比试；地点是戏台旁的麦地，不是第103回的龚家村打麦场。三处依据：

- 「那戏台却在堡东麦地上。」
- 「里面是箭杆小袖紧身，鹦哥绿短袄，下穿一条大档紫夹绸裤儿」
- 「也拽双拳吐个门户，摆开解数，与那女子相扑」

先后核对：王庆赢钱，与输家对打，放翻输家（前）→放囊者抢钱而去，王庆弃了地上的汉子大步追赶（前）→
人丛里闪出一个女子大喝“那厮不得无礼”（前）→三娘脱外衫卷成一团丢桌上，踏步上前，提拳打来；王庆拽双拳
摆开门户（此刻）→相扑数合，粉头已上台，众人走拢把两人围在圈中（后）→三娘使“黑虎偷心势”打空，被王庆
扭住放倒又抱起（后）→范全劝开（后）。此刻围观者尚未合成圈，无人倒地，粉头不入画。

## 器物与环境

- 地点：定山堡东的麦地（堡有五六百人家），临时戏台搭在麦地上，台下四面摆着桌凳，
  青麦已被踏光十数亩。戏台形制本回未写，兜底：木板矮台，台口挂布幔，不画台上人。
- 时令：宣和元年仲春（第103回）；天气、时辰本回未写，兜底：春日白昼，晴。原文“把那青青的麦地，踏光了
  十数亩”：戏台前打斗处麦苗已踏光，露出黄土；远处田垄仍是青麦。
- 器物：外衫（卷成一团丢在身旁一张空桌上，色未写）；桌凳；赌具与钱贯不作主体，可不画。
- 现实中会动的：① 远处田垄青麦随春风起伏；② 戏台口布幔与幡子轻摆（兜底）；③ 三娘头上钗环与腕镯微颤，
  王庆衣角随呼吸起伏。两人只在原地摆架，不整体位移。

## 排除项

- 后拍：相扑交手（“黑虎偷心势”“虎抱头”）、范全劝开、段太公相看、李助说媒、成亲与洞房、窥听、
  火烧段家庄、杀都头与黄达、房山寨、廖立。前拍：掷骰攧钱、放翻输家、抢钱追赶。
- 不画三娘倒地或被抱起，不画她卸钗脱衫、袒露胸腹；不画王庆持刀、戴枷、有刺字。
- 三娘不画成肥胖丑怪或凶相，村民不画成丑化形象；不画粉头表演（装束原文未写）。
- 不画影视或戏曲中的“女霸王”扮相。
