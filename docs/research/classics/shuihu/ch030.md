# 《水浒传》第30回 施恩三入死囚牢　武松大闹飞云浦

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第030回>；读取日期：2026-10-20。

## 情节要点

1. 武松踏住蒋门神，逼他交还酒店、请人陪话、连夜离开孟州；施恩重霸快活林，留武松同住。
2. 一个多月后，张都监差人取武松做亲随；中秋夜在鸳鸯楼设宴，随后以失窃陷害，知府屈打成招，上长枷押入死囚牢，
   脚匣、手钉木钮；施恩托康节级，三次入牢探视，后来刑具放宽。
3. 六十日限满，武松脊杖二十，刺配恩州，钉七斤半铁叶盘头枷；施恩在城外路边相送，给包裹和两只熟鹅。
4. 行至飞云浦板桥，两个公人与蒋门神的两个徒弟合谋要害武松；武松扭断枷，杀死四人，念头一转，提朴刀回孟州城
   （下回接续）。

## 选定场面

飞云浦的阔板桥上，午后：武松站住，说“我要净手则个”；他戴着七斤半铁叶盘头枷，右手钉在枷上，左手散着，腰里
拴着包裹，两只熟鹅早已吃完；桥边牌楼的牌额写着“飞云浦”；两个公人在他身后，两个提朴刀、腰挎腰刀的汉子走近
一步，刀未举。具名武松（公人与汉子无名）。三处依据：

- 「五个人行至浦边一条阔板桥，一座牌楼上有牌额写着道『飞云浦』三字。」
- 「武松站住道：『我要净手则个。』」
- 「那两个提朴刀的走近一步」

回目“大闹”之前是这一口蓄势：四人围一人，枷、桥、水、刀都有原文，没有人出手。不取“下去”一脚踢人落水、折枷、
追杀、夺朴刀（出手与杀人）；不取吃鹅一段（路上，无桥无水）。

先后核对：施恩把两只熟鹅挂在枷上（前）→行数里，公人低语“不见那两个来”（前）→右手钉在枷上，左手取鹅吃，两
只吃尽（前）→离城八九里，路边两人提朴刀、跨腰刀等候，随行，与公人使眼色（前）→行至板桥，武松假意问地名，
公人答“你又不眼瞎”（紧邻此刻之前）→武松站住说净手，朴刀汉走近一步（此刻）→叫声“下去”，飞脚踢人下水（后）→
把枷一扭折成两半，赶下桥（后）。故此刻枷完好，枷上无鹅，包裹仍在腰里。

## 器物与环境

- 地点：离孟州城约八九里，“济济荡荡鱼浦，四面都是野港阔河”；浦边一条阔板桥，桥边一座牌楼，牌额“飞云浦”三字。
  桥面与护栏未写，兜底：木桩木梁平桥，桥面铺宽板，桥头小牌楼，水面开阔，岸边芦苇。飞云浦无确址，有说离孟州城十几
  二十里（据摘要）。
- 时令天气：天气未写。自八月十五夜陷害起算，限满六十日，约十月中旬（推算），农历十月为初冬；回城“早是黄昏”
  （第31回），故此刻在午后偏晚。兜底：初冬斜阳，天微阴，苇草枯黄，水面平，不画雪。
- 器物：行枷；朴刀——刀头装长木柄的长柄刀，可拆装，宋代腰刀较短（据摘要）；包裹里的“绵衣”是絮丝绵的衣
  （宋代棉花未普及，据摘要）；封皮前两回有、本回未写，不画。
- 现实中会动的：① 水面波纹与野港边的苇草摇动；② 武松衣角与腰间包裹的结带随风；③ 水鸟掠过水面（原文未写，
  属环境常见物）。

## 排除项

- 后拍：“下去”踢人落水、折枷、赶下桥、打翻、夺朴刀搠杀、砍倒、揪住逼问、手起刀落、尸首撺进浦里、再奔回孟州。
  前拍：施恩路旁相送、熟鹅挂枷、边走边吃鹅、鸳鸯楼陷害、玉兰唱曲、过堂、死囚牢与康节级，均不画。
- 枷不画成双手锁（原文只钉右手）、方枷或写有大字的枷；此刻枷未折；不画手铐脚镣；不画血、尸首、落水者。
- 他回：第27回团头护身枷与封皮、第28回无枷、第29回万字头巾与红搭膊；第31回回城持朴刀与行者装。
- 影视：二创的打斗与心理戏不入（据摘要）；戏曲罗帽、箭衣不画；公人与汉子不穿衙役号服、不戴官帽。
