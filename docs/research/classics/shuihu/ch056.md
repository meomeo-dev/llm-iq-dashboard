# 《水浒传》第56回 吴用使时迁盗甲　汤隆赚徐宁上山

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第056回>；读取日期：2026-10-20。

## 情节要点

1. 汤隆献钩镰枪画样，说会使的只有姑舅哥哥金枪班教师徐宁；徐家镇家之宝“雁翎砌就圈金甲”，号“赛唐猊”，用皮匣盛着
   挂在卧房梁上。吴用遣时迁盗甲，汤隆负责赚人；另派人取彭玘、凌振家眷。
2. 时迁到东京踩点，初更前后爬上班门里的大柏树，翻进后院，伏在膊风板边看徐宁夫妇向火；二更后吹灭窗内碗灯。
3. 四更徐宁起身，去龙符宫随驾；时迁待他出门，上楼伏到梁上，等两个丫鬟睡熟，吹灯、解皮匣，学老鼠叫瞒过惊醒的娘
   子，混在开锁的班门人群里出城；戴宗在四十里外接甲，先回山寨。
4. 徐宁发觉失甲，汤隆登门，借白圈路标和假装脚伤的时迁引他一路追赶；乐和扮李荣，车上下蒙汗药，把徐宁载到金沙滩。
5. 徐宁见妻子也被汤隆赚来，只得留下；晁盖、宋江请他教钩镰枪（下回接续）。

## 选定场面

四更过后、五更之前，徐宁家楼上卧房：徐宁已背金枪出门，时迁伏在屋梁上，梁上拴着那只红羊皮大匣；他听得两个丫鬟睡着，
举起芦管对准桌上的碗灯，将吹未吹。具名仅时迁；徐宁、娘子、丫鬟不入画，床榻不入画（画面只截梁、匣、灯与门边器物）。
时迁此刻面向下方，一手扶梁，一手持芦管，匣不动。三处依据：

- 「梁上果然有个大皮匣拴在上面」
- 「房里桌上，却点着碗灯」
- 「时迁听那两个梅香睡着了，在梁上把那芦管儿指灯一吹，那灯又早灭了」

先后核对：初更时迁在膊风板边窥看夫妇向火（前，不在梁上）→二更后隔窗吹灭碗灯（前）→四更徐宁起身，丫鬟取火再点灯
（前）→徐宁背金枪出门，两丫鬟送出（前）→时迁出厨桌下，上楼伏到梁上，丫鬟关门后上楼睡倒（前）→丫鬟睡着，时迁在
梁上指灯欲吹（此刻）→灯灭，解匣，娘子惊醒问“梁上甚么响”，时迁学鼠叫（后）。旧版“主人夫妇在床帐后熟睡”有误：此刻
徐宁已不在家；睡着的只有娘子和丫鬟。

## 器物与环境

- 地点：东京金枪班班门里，靠东第五家黑角子门；小院、厨房、“两间小巧楼屋”，卧房在楼上，梁上拴皮匣，房门口挂
  一副弓箭和一口腰刀，衣架挂各色衣服，桌上有碗灯。
- 皮匣：“红羊皮匣子”，里面用香绵裹住；汤隆称匣面“白线刺着绿云头如意，中间有狮子滚绣球”（徐宁未否认）。匣内
  是雁翎锁子甲，轻而稳，刀箭不易透；尺寸未写，兜底：长方皮匣，绳索拴在梁上，不画甲外露。
- 灯：“碗灯”，宋代常见小碗盛油的简易油灯（据摘要）；芦管儿即细芦苇管。
- 时令时辰：“寒冬天色，却无月光”“云寒星斗无光，露散霜花渐白”（均初更）；此刻在四更后至五更前，兜底：屋内昏暗，
  仅灯火微光，窗外天未亮。
- 现实中会动的：① 碗灯火苗被气流压向一侧、复位，往复，不熄；② 皮匣垂绳随梁轻微摆动；③ 冬夜里时迁呼出的白气。

## 排除项

- 后拍：灯灭、解匣、娘子问“梁上甚么响”、学鼠叫、背匣下楼、混入班门人群、戴宗接甲、汤隆登门。前拍：膊风板边窥看、
  隔窗吹灯、土地庙后柏树。
- 不画床帐里的人，不画脱衣；不画徐宁在家。
- 不画时迁在屋脊或屋顶；京剧《时迁盗甲》把甲箱放在高处屋脊（据摘要），原著是卧房梁上。
- 他回：徐宁教枪（第57回）、乐和扮李荣、时迁偷鸡（第46回）；钩镰枪不入画。
- 不画武丑白鼻梁、戏曲短打与影视造型。
