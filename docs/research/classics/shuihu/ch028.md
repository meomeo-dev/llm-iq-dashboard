# 《水浒传》第28回 武松威镇安平寨　施恩义夺快活林

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第028回>；读取日期：2026-10-20。

## 情节要点

1. 张青劝武松落草，武松不肯害两个公人，要他救醒；留住三日后结拜张青为兄，重新戴枷投孟州，发到安平寨牢城营。
2. 武松在单身房与众囚徒、差拨顶撞；点视厅上管营喝令除枷，施恩在旁耳语，杀威棒被“寄下”。
3. 武松被换到干净房里，天天好酒好食、洗浴篦头，不知缘由；施恩出面，说要等他养足气力再托事。
4. 武松要看天王堂前的石墩，脱下上半截衣裳拴在腰里，抱起石墩撇进地里，再提起抛上空中接住，放回原处；
   施恩请他到私宅，将说快活林之事（下回接续）。

## 选定场面

安平寨牢城营天王堂前，五六月炎天的晌午：武松刚把青石墩撇进地里一尺来深，又用右手从地里提起，望空一掷，石墩
离地一丈来高；武松已把上半截衣裳脱下拴在腰里，仰面张开双手待接。施恩与众囚徒已照他的话躲开，站在近处看。
具名武松、施恩，另有众囚徒。三处依据：

- 「你众人且躲开，看武松拿一拿。」
- 「武松再把右手去地里一提，提将起来，望空只一掷」
- 「掷起去离地一丈来高；武松双手只一接」

回目“威镇”落在这一掷：全是力气，无血无伤，人群围观，动静分明，适合做动态。不取“略摇一摇说拔不动”（试探，
石墩不动）；不取接住放回与施恩下拜（石墩已落手，动势没了）。

先后核对：武松略摇石墩，说拔不动（前）→叫众人躲开（前）→脱衣拴腰，抱起石墩，双手一撇，打进地里一尺来深，
众囚徒骇然（前）→右手去地里提起，望空一掷，离地一丈来高（此刻，石墩在空中，尚未入手）→双手一接，轻轻放回
原处（后）→面不红、心不跳、口不喘；施恩抱住便拜，众囚徒齐拜“真神人”（后）。

## 器物与环境

- 地点：孟州安平寨牢城营（牌额“安平寨”）。天王堂前，纸炉边一个青石墩，“有个关眼，是缚竿脚的，好块大石”。
  天王堂是营中供天王像之处（牢城属厢军，据摘要）；形制未写，兜底：一间小殿，门前石阶。
- 石墩：旗杆石有方有圆，像大石础，中间一孔插旗杆（据摘要）；兜底：青灰色方墩，高及膝，顶面一个圆孔，一人能抱住。
  施恩估重“四五百斤”，后又说“三五百斤”，均是人物估计；宋斤约625至640克，折合约190至320公斤（据摘要）。
  撇下处地面陷出一个一尺来深的坑，提起时土屑崩起；“一丈”按宋尺约3.1米，画面只取远高于人头。
- 时令天气：五六月炎天，晴日头，晌午；兜底：日光直射，地面发白，石阶与人物短影。
- 现实中会动的：① 空中的石墩（上升或下落，是全场唯一整体位移的物件）；② 坑口崩起的尘土碎屑；③ 武松腰间
  拴着的衣袖与施恩衣角随动势摆动。

## 排除项

- 后拍：双手接住、轻放原处、面不红心不跳、施恩抱拜、众囚徒拜“真神人”、私宅堂上说蒋门神。前拍：略摇石墩说拔不动、
  撇石墩入地、点视厅杀威棒、差拨发话、盆吊与土布袋之说、洗浴与新房间、张青夫妇与十字坡。
- 不画武松戴枷；不画全裸；“金印”是面颊上的刺字，不是金色印章；不画重量数字、神光、天神；石墩不画成现代
  石锁、石担，不画碎裂或地裂。
- 他回：第27回的行枷、封皮与公人；第29回的万字头巾、土色布衫、红绢搭膊；第30回的陷害与鸳鸯楼。
- 戏曲：京剧武松的软罗帽、箭衣（据摘要）不画。
