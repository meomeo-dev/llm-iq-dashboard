# 《水浒传》第50回 吴学究双掌连环计　宋公明三打祝家庄

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第050回>；读取日期：2026-10-20。

## 情节要点

1. 吴用派戴宗回山取裴宣、萧让、侯健、金大坚；扈成牵牛担酒求放扈三娘，宋江叫他今后不得救祝家庄、来投者须缚送。
2. 孙立把旗号改作“登州兵马提辖孙立”，领一行人到祝家庄后门；栾廷玉出庄迎接，孙立说奉调守郓州、顺路来访，
   被留下款待，祝氏三杰不疑。
3. 第三、四日两阵对敌：花荣、林冲等与祝家子弟交锋；孙立出阵故意“擒”了石秀，庄上愈加信他。
4. 第五日里应外合：邹渊、邹润砍翻监门、放出七人，顾大嫂杀庄内妇人，石秀杀祝朝奉，祝龙、祝虎、祝彪被杀，
   李逵又杀扈家一门，两庄起火（杀伐，不画）。
5. 宋江赦钟离老人、得粮五十万石回山；李应被官面诓上山，王英与扈三娘成亲；有郓城县人到朱贵酒店求见（下回接续）。

## 选定场面

白天，祝家庄后门前：吊桥已放下，栾廷玉带二十来人迎出桥头；孙立一行刚下马，与栾廷玉互相行礼，身后插着写
“登州”的旗号，车仗在队尾。同门师兄弟重逢，一个真心迎接，一个暗藏内应，反差在神态上，无人动手，不涉血腥。
具名孙立、栾廷玉。三处依据：

- 「孙立却把旗号上改唤作登州兵马提辖孙立」
- 「带了二十余人马，开了庄门，放下吊桥，出来迎接」
- 「孙立一行人都下了马」

先后核对：吴用在石勇店议定计（前）→孙立改旗号，到祝家庄后门，墙里望见登州旗号，报入庄（前）→栾廷玉告知三杰
“孙提辖是我弟兄”，开庄门、放吊桥出迎（前）→孙立一行都下了马，众人讲礼（此刻）→栾廷玉问“如何到此”，孙立编
对调郓州的话（后）→进庄，拽起吊桥、关庄门（后）→安顿车仗、更换衣裳，到前厅见祝朝奉（后）。故此刻吊桥放着，
孙立一行仍着旅途衣装，未披甲。

## 器物与环境

- 地点：郓州独龙冈祝家庄后门。“有三层城墙，都是顽石垒砌的，约高二丈。前后两座庄门，两条吊桥。墙里四边，都盖
  窝铺”，门楼上排着战鼓铜锣，庄四周一圈阔港（第47回）。祝家庄位置小说作郓州，民间说法不一，无定论
  （据摘要），不画真实地标。
- 时令天气：时辰、季节、天气本回未写；兜底：白天，晴，不雨不雪。
- 器物：登州旗号（宋代旗杆漆竿、旗脚作火焰形，据摘要；官职与旗号的对应未检得，旗面只写“登州”二字，字数不求
  可辨）；吊桥与护庄港；带篷车仗（乐大娘子在车中，不露面）；马匹。孙立、栾廷玉用叉手或拱手作揖（宋人男子行礼
  称“唱喏”，据摘要；叉手时手离胸二三寸，据读取页面）。
- 现实中会动的：① 旗帜在风里飘，火焰形旗脚起伏；② 吊桥链索微晃，护庄港水面起波纹；③ 马尾摆动、马喷鼻气。

## 排除项

- 后拍：栾廷玉问话、拽起吊桥、前厅见祝朝奉、花荣与祝彪对阵、孙立擒石秀、第五日内应开杀、石秀杀祝朝奉、李逵
  屠扈家、火烧庄院。前拍：第49回劫牢杀人，石勇店献计。
- 孙立不披战甲、不骑出战，钢鞭不举，长枪不指人；栾廷玉不执铁锤、不上马交锋；宋江、吴用、李逵、石秀不入画。
- 登州旗号不写成梁山旗号，不出现“替天行道”。
- 戏曲：京剧《三打祝家庄》里孙立以武老生或武生应工（据摘要），髯口、靠旗一类扮相不入画。
