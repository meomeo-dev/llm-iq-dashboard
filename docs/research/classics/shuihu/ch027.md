# 《水浒传》第27回 母夜叉孟州道卖人肉　武都头十字坡遇张青

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第027回>；读取日期：2026-10-20。

## 情节要点

1. 武松祭奠后到县自首，解东平府；府尹陈文昭周全，刑部定“脊杖四十，刺配二千里外”：开长枷，杖四十，
   只有五七下着肉，钉七斤半铁叶团头护身枷，脸上刺两行“金印”，迭配孟州；王婆被剐（不入画）。
2. 武松与两个防送公人六月前后上路，走了二十余日，巳牌时分上岭，到孟州道十字坡。
3. 路边酒店的女主人孙二娘迎客，用蒙汗药酒麻翻两个公人；武松把酒泼了，假装中毒倒地，孙二娘来提他时反被
   他抱住按倒。
4. 张青挑柴归来喝住，两人通名拜识；张青讲店里的来历与三不杀的规矩，武松说明刺配缘由，并请张青救起两个公人
   （下回接续）。

## 选定场面

十字坡酒店门前，六月某日巳牌，晴热：酒店是溪边土坡下的草屋，柳树上挑出酒帘儿；孙二娘从窗槛边起身，倚门招呼
进店；武松与两个公人刚到门前，武松仍戴着枷，背着包裹，面颊刺着两行金印，公人手提棍棒、腰缠缠袋。具名孙二娘、
武松，另有两个公人。三处依据：

- 「傍着溪边柳树上挑出个酒帘儿。」
- 「见武松同两个公人来到门前，那妇人便走起身来迎接。」
- 「那妇人倚门迎接说道：『客官歇脚了去。』」

回目上联“母夜叉”要在她出场时立住形象；此刻她招呼热络而韵文写眉横杀气、眼露凶光，三人未进店，没有酒肉，没有药。不取假醉倒地
（孙二娘随后脱衫解裙，赤膊提人）；不取作坊（人皮、人腿、剥人凳）。

先后核对：巳牌上岭，樵夫指路十字坡（前）→大树，酒店，窗槛边一妇人露出绿纱衫儿（前）→妇人起身，倚门迎客
（此刻）→入店，公人倚棍棒、解缠袋，武松才解包裹、搭膊，脱布衫（后）→公人为武松除枷，放桌下（后）→取酒、
馒头，问“人肉的狗肉的”（后）→药酒，倒（后）。故此刻枷在颈，包裹在背。

## 器物与环境

- 地点：孟州道岭下十字坡。“为头一株大树，四五个人抱不交，上面都是枯藤缠着”；土坡下约十数间草屋；溪边柳树
  上挑酒帘儿；门前有窗槛；屋里一副柏木桌凳座头。十字坡今址有河南孟州、山东莘县、范县等说，无定论，不画景区牌坊。
- 时令天气：六月前后，“炎炎火日当天，烁石流金”，公人“趁早凉而行”，巳牌时分，晴热，树荫浓。
- 器物：酒帘（宋代称酒望、望子，布制；本回只称“酒帘儿”，颜色与字未写，兜底：青白布一幅，不写字）；七斤半
  行枷（圆头，木板钉铁叶，约4.7公斤，以宋斤625至640克计）；包裹、缠袋、棍棒。
- 现实中会动的：① 溪边柳枝与酒帘随风摆动；② 大树上的枯藤与树叶；③ 草屋灶间的一缕炊烟（原文只写有灶，
  烟为推测）。

## 排除项

- 后拍：入店、除枷、酒馒头、“人肉的狗肉的”之问、蒙汗药、麻翻公人、武松假醉倒地、孙二娘脱衫解裙赤膊、按倒、
  人肉作坊、人皮人腿、剥人凳、张青叉手拜、头陀遗物（数珠、戒刀）。前拍：东平府审案、王婆凌迟、刺面过程。
- 不画人肉、馒头特写、肉案、骷髅、血迹；孙二娘不赤膊、不露胸；酒帘不写“黑店”字样。
- 他回：开枷后的武松（第28回点视厅）、头陀装（第31回）、鲁智深的禅杖（只在张青转述里）。
- 戏曲与影视：《十字坡》杂剧里孙二娘年轻俏丽、鬓插海棠（据摘要），与原著的粗悍不同，不画；影视有红绿上下
  对调的（据摘要），原文是绿纱衫、红绢裙；武松不戴罗帽、不穿箭衣。
