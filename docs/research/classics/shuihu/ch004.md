# 《水浒传》第4回 赵员外重修文殊院 鲁智深大闹五台山

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第004回>；读取日期：2026-10-19。

## 情节要点

1. 金老拖鲁达避开榜文，引见赵员外；鲁达在七宝村住数日，风声渐紧，赵员外荐他去五台山文殊院出家。
2. 智真长老入定后力排众议为其剃度，赐名智深；智深在禅堂睡卧无状，四五个月后初冬抢酒担、醉后褪膊
   上山，打门子、闹藏殿，长老容忍。
3. 三四个月后二月里，智深下山，在铁匠铺订打六十二斤水磨禅杖与一口戒刀，诸家酒店皆不肯卖酒，
   终在村店吃了狗肉、两桶酒。
4. 回山路上在半山亭醉后使拳，一膀子搧折亭柱；到山门打金刚，闯僧堂，吐狗肉，打伤数十僧，卷堂大散。
5. 长老写书荐智深去东京大相国寺，赠偈在下回。

## 选定场面

半山亭下，智深酒意上涌，离开亭子，两手攥着袖子，上下左右使拳，只一膀子尚未搧出，亭柱完好。
具名只有鲁智深。理由：亭柱一节是“大闹”里不伤人的动作，一人一亭，构图简洁，酒意与力道可由
袖摆、步法表现；不取初冬醉归一节，那次他褪膊露背，赤膊不入画。

- 「智深走到半山亭子上，坐了一回，酒却涌上来，跳起身」
- 「俺好些时不曾拽拳使脚，觉道身体都困倦了，洒家且使几路看。」
- 「下得亭子，把两只袖子搙在手里，上下左右，使了一回。」

先后核对：买酒吃狗肉，剩一只狗腿揣怀里→走到亭子坐一回→酒涌上来、跳起身说“且使几路看”→下得
亭子、攥袖使拳（此刻）→“使得力发，只一膀子，搧在亭子柱上”、柱折亭坍半边（后）→山门关、擂门、
打金刚（后）。故亭柱仍完好，不画金刚。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 鲁智深 | 剃度已逾半年，头光，腮边刚剃又冒短须（铁匠所见“腮边新剃，暴长短须”）；身长八尺（第3回），韵文称“八九尺猛兽身躯”。衣冠：直裰系绦，僧鞋；初冬那次明写“皂布直裰，鸦青绦”，二月这次未另写，兜底：皂色直裰、鸦青绦；怀里揣一只狗腿（可不画）；两手攥袖；酒意上脸（推断）；不赤膊，不赤脚，无袈裟、念珠、头巾。禅杖戒刀此时只是订打，未到手，也不带包裹 | 第4回；第5回 |

## 器物与环境

- 地点：五台山文殊院山门外半山亭子。亭以木柱支顶，细部未写，兜底：四柱小亭，素瓦，无彩绘；初冬那次
  亭内有“鹅项懒凳”（带弯曲外探靠栏的座凳），此刻不入画。
- 时令：“天气暴暖，是二月间天气”，初春；山下村店在“杏花深处”，亭边花木未写；白昼，酒后，具体时辰未写。
- 器物：禅杖戒刀的时序：第4回二月在山下铁匠铺订打（六十二斤水磨禅杖，戒刀用好铁，五两银子），
  第5回他在客店等数日才取到，戒刀入鞘、禅杖漆裹。第4回全篇他手中无杖无刀。
- 现实中会动的：① 攥在手里的袖子与直裰下摆随拳势摆动；② 山风中松枝或杏枝晃动（背景花木按兜底）；
  ③ 脚下尘土与落叶随步伐扬起。

## 排除项

- 后一刻：一膀子搧折亭柱、亭坍半边；山门前擂门；拔栅刺、拿折木打金刚、金刚倒撞；僧堂塞狗肉、
  扯断绦带、折桌腿、卷堂大散。
- 前一刻：铁匠铺订杖刀；各家酒店不卖；村店吃狗肉饮酒。
- 另一次醉：初冬抢酒担、踢汉子、褪膊缠袖、露脊背花绣、打门子——此刻是第二次醉，衣冠完整。
- 他回器物：禅杖、戒刀、背包裹（第5回）；“鹭鸶腿紧系脚絣”（第5回）；第3回的头巾战袍和短棒。
- 后世造型：月牙铲式禅杖（本回无杖）；戏曲脸谱；袈裟、念珠、僧帽此刻穿戴原文均未写，不加。
- 地理：五台山在小说中属代州雁门县境，带虚构成分（据摘要）。
