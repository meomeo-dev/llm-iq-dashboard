# 《水浒传》第98回 张清缘配琼英　吴用计鸩邬梨

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第098回>；读取日期：2026-10-20。

## 情节要点

1. 琼英本姓仇，父仇申被田虎所杀，母宋氏被掳后撞崖而死；琼英被邬梨掳去养大，梦神人授武艺。
   宣和四年季冬又梦秀士引绿袍少年将军教她飞石，称此人是宿世姻缘。
2. 二月将尽，琼英在襄垣城外阵前戟刺王英，飞石打中扈三娘、孙新、林冲、李逵、解珍；解珍、
   解宝被擒，邬梨中药箭。
3. 总管叶清潜入宋营述琼英身世；安道全证实张清也有同梦。吴用定计，张清改名全羽、
   安道全改名全灵，混入襄垣。
4. 教场演武厅上，全羽与琼英以飞石相认，三月十六日成亲，随后里应外合鸩杀邬梨、杀徐威，
   襄垣归宋。同时索超等攻克潞城。

## 选定场面

襄垣教场，演武厅前。琼英与全羽（张清改名）交手五十余合后，琼英忽然回马，朝演武厅方向走，
全羽催马紧追；琼英在马上扭身，右手从袋中取出石子，眼盯全羽肋下空处，石子尚未掷出，
全羽尚未接石。具名琼英、全羽。选它是因这是回目“张清缘配琼英”的相识一刻，飞石对飞石是
两人共有的绝技，姿势有张力而不伤人。三处依据：

- 「琼英霍地回马，望演武厅上便走，全羽就势里赶将来」
- 「琼英捻取石子，回身觑定全羽肋下空处」
- 「梦中教我飞石的，正是这个面庞」

先后核对：叶清与全羽比武四五十合不分胜负；琼英在旁认出全羽面庞像梦中教她飞石之人（前）→
琼英捻戟骤马，将画戟隔开二人，与全羽再斗五十余合（前）→ 琼英回马，全羽赶来，琼英取石
回身觑定（此刻）→ 一石飞来，全羽右手接住；琼英再取第二石，全羽以接得之石掷出，空中两石
相击（后）→ 邬梨赐衣甲马匹，令全羽领兵出城（后）。此刻没有接石、没有两石相撞，叶清已被
隔开不入画。原文只有“演武厅前”，没有阵前对垒。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 琼英 | 年方十六，“少年美貌的女将”。阵前“但见”：金钗插凤，掩映乌云；铠甲披银；踏宝镫鞋翘尖红，提画戟；柳腰，叠胜带紫色飘摇；挑绣袍红霞笼罩；脸堆三月桃花，眉扫初春柳叶；锦袋暗藏打将石；坐银鬃马。原文未写头盔，不画盔。演武厅一场装束未重写，兜底沿用；戟是“方天画戟”，左手带戟与缰，右手捏一枚鸡卵大圆石（试掷鸱尾所用）；端正，不丑化 | 第98回 |
| 全羽（张清） | 张清化名，邬梨见他“一表非俗”。梦中为“绿袍年少将军”；第100回全羽“头戴青巾帻，身穿绿战袍，手执梨花枪”；第70回旧貌“头巾掩映茜红缨，狼腰猿臂体彪形”。此刻装束未写，兜底：青巾、绿战袍、手握长枪（本回作“挺枪”）、白马（第100回为白马） | 第70、98、100回 |
| 邬梨 | 国舅，使五十斤泼风大刀；此时箭伤初愈，据文意在教场主持比武，面貌未写；建议不画，或只作厅上小人影 | 第97、98回 |

## 器物与环境

- 地点：襄垣城内教场。“邬梨带领琼英入教场”，全羽“上演武厅禀”，厅在场边，是将官发令处。
  宋代演武厅形制未检得，现存多为明清所建（据摘要）；兜底：三开间木构敞厅，台基抬高，
  厅前是开阔夯土场，立旗杆。
- 时令天气：叶清来营后全灵疗伤三日、五日，又过四日，三月十六日成亲，故约三月上旬（推算）。
  天气未写，兜底：晴，白昼，场边柳树新叶。
- 器物：方天画戟（宋代的“戟刀”演变而来，据摘要）、长枪、鸡卵大石子、锦袋、旗。
- 现实中会动的：① 厅前与场边旗帜随风飘动；② 琼英紫色叠胜带、红绣袍下摆与马鬃马尾；
  ③ 马蹄扬起的细尘。人物不整体位移。

## 排除项

- 后拍：全羽接石、两石空中相击、赐衣甲、拜堂洞房、鸩邬梨、杀徐威。前拍：阵前戟刺王英、飞石
  打中扈三娘、孙新、林冲、李逵、解珍，鲁智深坠穴，邬梨中箭，叶清假意比武，梦中折角巾秀士。
- 不画血与伤者；不画琼英凤冠霞帔，不画戏曲刀马旦靠旗翎子，不用影视剧造型；不画王英色相。
- 全羽此刻不说破“张清”，不画他的锦袋；石子不画成飞镖、飞刀。
- 叶清、徐威、安氏均不入画。
