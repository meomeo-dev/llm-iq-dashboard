# 《水浒传》第3回 史大郎夜走华阴县 鲁提辖拳打镇关西

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第003回>；读取日期：2026-10-19。

## 情节要点

1. 史进杀王四、李吉，与朱武等放火冲出重围上少华山，数日后辞山往延安府寻师，半月后到渭州。
2. 渭州茶坊遇经略府提辖鲁达，同到州桥潘家酒楼，遇史进的开手师父李忠；隔阁金翠莲父女啼哭，
   诉被“镇关西”郑屠强占。
3. 鲁达凑十五两银子，次晨送金老父女出城，在客店坐两个时辰拦住追兵，再到状元桥郑屠肉铺。
4. 鲁达三次要郑屠切臊子（精肉、肥肉、寸金软骨）以消遣他；郑屠怒，抢尖刀跳下；三拳打死郑屠
   （此事不入画）。
5. 鲁达提短棒出南门，渭州海捕出赏钱；他逃到雁门县看榜，被人拖走（下回接续）。

## 选定场面

状元桥下郑屠肉铺前：鲁达从凳上跳起，手里拿着两包荷叶裹的臊子，睁眼盯着郑屠，说“洒家特地要消遣你”，
臊子尚未掷出。具名鲁达、郑屠，另有刀手、店小二远立群像。理由：这是第一拳之前最紧的一刻，铺面陈设
原文写得具体，郑屠笑意未收、尚未发怒，无人受伤。

- 「郑屠开著两间门面，两副肉案，悬挂著三五片猪肉。」
- 「鲁达听罢，跳起身来，拿著那两包臊子在手里，睁眼看著郑屠」
- 「洒家特地要消遣你。」

先后核对：鲁达叫“郑屠”，郑屠出柜唱喏、令副手掇凳→鲁达坐下，要精肉臊子，郑屠自切半个时辰→
再要肥肉臊子→再要寸金软骨臊子，郑屠笑说“特地来消遣我”→鲁达跳起，臊子在手（此刻）→劈面打去、
郑屠大怒、从案上抢剔骨尖刀跳下（后）→踢小腹、踏胸脯、三拳（后）。故此刻尖刀仍在案上，郑屠手中
无刀（切肉所用刀具原文未写，兜底：案上放着，不握在手）。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 鲁达（鲁提辖） | 渭州经略府提辖，军官模样：头裹芝麻罗万字顶头巾，脑后两个太原府扭丝金环，上穿鹦哥绿纻丝战袍，腰系文武双股鸦青绦，足穿鹰爪皮四缝干黄靴；面圆耳大，鼻直口方，腮边一部貉胡须，身长八尺，腰阔十围。次日打郑屠未另写衣着，沿用茶坊一节（推断）；有发有须，无僧衣；不带兵器（逃走时才提短棒） | 第3回 |
| 郑屠 | “镇关西”，状元桥下卖肉屠户，开两间门面、两副肉案，坐门前柜身内看十来个刀手卖肉；衣冠面貌未写，兜底：壮实屠户，粗布短衣，头裹巾，不披甲；此刻笑意未收 | 第3回 |
| 刀手、店小二 | 十来个刀手在案上卖肉；店小二被鲁达打伤，手帕包头，远远立在房檐下望 | 第3回 |

## 器物与环境

- 地点：渭州状元桥下肉铺，两间门面，两副肉案，悬挂三五片猪肉，门前有柜身；鲁达坐副手掇来的凳子，
  在肉案门边；臊子用荷叶包，案上放剔骨尖刀。
- 时令：鲁达五更起，在客店坐两个时辰才来，郑屠切肉半个时辰，再“整弄了一早辰”，正是饭罢时候，
  为上午；季节、天气未写，不强加。
- 现实中会动的：① 悬挂的猪肉随风微摆；② 案后刀手起落的切肉刀；③ 荷叶包边与鲁达衣襟、头巾带。

## 排除项

- 后一刻：臊子劈面打去、郑屠抢刀跳下、鲁达退到当街；踢小腹、踏胸、三拳、鼻眼迸血、尸体；
  鲁达弃旧衣、提短棒出南门。
- 前一刻：客店打小二；酒楼赠银；金老父女（已离城），李忠、史进不在场。
- 他回装束：鲁达剃度后的光头、皂直裰、禅杖、戒刀（第4–5回）；第3回的短棒只在逃走时出现。
- 戏曲影视：脸谱勾脸、戏装不取；郑屠外形原著未写，不另加刺青、凶恶面相。
- 易混：鲁达官职是“提辖”，不是教头、都头；此刻尚无拳脚相向，“三拳”是后一刻之事。
- 史实：提辖是州级武官“提辖兵甲盗贼公事”之简称，小说中为经略府武职（据摘要）。
