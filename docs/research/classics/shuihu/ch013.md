# 《水浒传》第13回 急先锋东郭争功　青面兽北京斗武

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第013回>；读取日期：2026-10-19。

## 情节要点

1. 东郭门教场上杨志与周谨先比枪（枪头去尖、裹毡蘸石灰，周谨身上白点三五十处，杨志仅左肩胛下一点），
   再比箭：杨志闪身、拨开、徒手绰住三箭，回射一箭中周谨左肩，周谨落马。
2. 急先锋索超出面不服，求与杨志比试；梁中书令杨志换装披挂、借己之战马，李成借索超战马与披挂。
3. 两阵门旗分开，索超、杨志先后出阵立马，旗牌官传令后二人纵马相交，斗五十余合不分胜负，闻达令鸣锣分开；
   梁中书将二人同升管军提辖使，筵宴后迎入东郭门。
4. 端午家宴，蔡夫人催问六月十五日蔡太师生辰礼，梁中书说十万贯金珠已备九分，押送人选未定。
5. 郓城知县时文彬遣朱仝（马兵都头）、雷横（步兵都头）分头巡捕；雷横在东溪村灵官庙拿住睡在供桌上的大汉。

## 选定场面

东郭门教场，两阵前立马对阵：画面左侧索超骑雪白马，横金蘸斧立于左阵前；画面右侧杨志骑火块赤马，横
浑铁点钢枪立于右阵前；旗牌官持销金令字旗驰到喝令，二人尚未纵马。演武厅月台上梁中书坐银交椅，背后
撑茶褐罗三檐凉伞。具名索超、杨志、梁中书；旗牌官与将台上李成、闻达可作小像。三处依据：

- 「左阵上“急先锋”索超兜住马，掗着金蘸斧，立马在阵前。」
- 「右阵上“青面兽”杨志捻手中枪，勒坐下马，立于阵前。」
- 「正南上旗牌官拿着销金令字旗，骤马而来，喝道」

取此刻不取比箭与交手：比箭以周谨中箭落马收场，交手已是兵刃相接；唯有立阵一刻，两人盔甲袍马兵器原文
写得最足，且未出手。原文“左阵、右阵”未说从何方看，画面左右按先索超后杨志的行文次序定。

先后核对：比箭、周谨落马（前）→索超请战，二人换装，梁中书移坐月台（前）→三通鼓后索超出左阵、杨志出
右阵，各自立马（此刻）→旗牌官驰到喝令（此刻）→二人纵马出阵、中心相交（后）→五十余合、鸣锣分开（后）。

## 器物与环境

- 地点：大名府东郭门外教场，“绿茸茸芳草地”；演武厅前有月台，月台设栏干；将台与演武厅分处，以青、红、
  黄旗与鼓、锣、炮传令；两阵门旗于“鸾铃响处”分开，旗牌官自正南驰来。
- 时令：春季（后文“自东郭演武之后……春尽夏来”），天气未写；取白昼晴朗，草色青绿。
- 器物：金蘸斧（长柄，形制本回未写；兜底：宽刃长柄大斧，刃面带金色）；浑铁点钢枪；销金令字旗；银交椅。
- 现实中会动的：① 门旗、令字旗与两人盔上的青缨、红缨随风飘动；② 战马甩头喷气、前蹄刨地、鬃尾摆动；
  ③ 凉伞边饰与袍角在风中微摆（人物与战马本体不整体位移）。

## 排除项

- 比枪蘸石灰、比箭、周谨中箭落马（均在前）；纵马相交、斧枪并举、五十余合、鸣锣分开（均在后）。
- 杨志朴刀、腰刀、青纱衫、凉笠（第16回押纲时才有）；二人戴红花入东郭门、朱仝雷横灵官庙（本回后段）。
- 索超只持一柄金蘸斧，不是双斧（第63回写“两把”）；坐骑是李成借的雪白马，不用维基条目所写的“五花龙”。
- 戏曲年画：京剧《大名府》靠旗脸谱、武强年画式构图不入画；青记画成脸颊上一块不规则的青色胎记，不作脸谱纹样。
