# 《水浒传》第26回 偷骨殖何九叔送丧　供人头武二郎设祭

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第026回>；读取日期：2026-10-20。

## 情节要点

1. 何九叔装中恶回家，依妻子的主意，出殡日在化人场用纸钱支开王婆和潘金莲，拣两块酥黑骨头，连同十两银子和
   写明年月日的纸包好收着。
2. 武松三月初头回阳谷，见灵牌大惊；潘金莲换上孝服假哭。次日他在酒店逼何九叔交出骨殖，又带上郓哥作证，
   告到县里，知县受贿不准。
3. 武松买来酒肴祭物，请王婆与四家邻舍到家吃酒，土兵前后把门，叫胡正卿执笔，逼出王婆与潘金莲的口词。
4. 武松取了潘金莲的首级，奔狮子桥下酒楼杀西门庆，提两颗首级回灵前祭奠（此后各事不入画）。

## 选定场面

阳谷县紫石街武大家堂屋，三月上旬白天，前后门已关，烛光点着：灵床子前摆着灵牌和酒肴祭物，一张桌坐了六人，
潘金莲坐主位，王婆对席，四家邻舍依次落座；武松掇条凳坐在桌横头，土兵刚把前后门关了，后面土兵正在筛酒，
武松唱个大喏致歉。刀还在衣内，没人起身，没人被喝住。具名武松、潘金莲、王婆，另有四邻与土兵群像。三处依据：

- 「武松掇条凳子，却坐在横头，便叫土兵把前后门关了。」
- 「原来都有土兵前后把着门，都似监禁的一般。」
- 「武松唱个大喏，说道：『众高邻：休怪小人粗卤，胡乱请些个。』」

回目下联“设祭”落在这一桌；灵牌、两枝烛、一炉香、满桌酒肴、封门的土兵都有原文，气氛紧绷而无人动手。不取
狮子桥酒楼（武松先把首级掷向西门庆，不是出手前）；不取酒至三杯后（掣刀、写口词、踢翻桌子）。

先后核对：武松回家点烛焚香，摆祭物于灵前（前）→分头请王婆与四邻，扯来入座（前，原文“不由他不来”）→武松
坐横头，叫土兵关前后门，后面土兵筛酒，武松唱喏（此刻）→酒至三杯，胡正卿欲起身被喝住（后）→收杯盘，掣尖
刀，叫胡正卿写口词（后）→踢翻桌子，揪潘金莲到灵床前（后）。桌设在灵床子前，系据后文“放翻在灵床面前”推断。

## 器物与环境

- 地点：武大家，门挂帘子，堂屋里灵床子前设灵牌“亡夫武大郎之位”，原有琉璃灯，贴着经幡、钱垛、金银锭、彩缯；
  武松添两枝蜡烛、一炉香、一陌纸钱，祭物为猪首、鹅、鸡、酒、果品，堆盘满宴。屋有前后门，楼上另有楼门。
  形制未写，兜底：方桌与条凳（宋代市井最普通的座具），灵床子在桌侧。
- 时令天气：三月初头，春；武松到家约巳牌（九至十一时，推算），此刻略后。天气未写，兜底：春日白昼，门缝透
  进暖白光，室内以烛光为主，不画夜、不画雪。
- 器物：灵牌、灵床子（放灵牌与祭品的桌子，据摘要）、烛、香炉、纸钱、大碗、酒筛；武松腰间麻绦与衣下的刀。
- 现实中会动的：① 两枝烛焰与香炉青烟；② 土兵斟酒时的酒线与碗中酒面；③ 灵前纸钱和经幡边角被门缝风吹动。

## 排除项

- 后拍：胡正卿欲走被喝住、掣尖刀、写口词、踢翻桌子、揪潘金莲、剜心与割头、狮子桥酒楼、首级、西门庆。前拍：
  何九叔酒店被逼、骨殖与银子、县衙告状、夜里灵前冷气与亡魂，均不画。
- 刀不出鞘，不握刀，桌未翻，无人被按；不画血、尸首、人头；祭物写作酒肴，不画猪首特写。
- 他回：武松的红袄毡笠（第23回）、行枷与金印（第27回）、头陀装（第31回）；潘金莲不穿红裙绣袄、不戴首饰。
- 戏曲：京剧武松戴软罗帽、穿箭衣或快衣快裤（据摘要），不画；不画鬼影、不画戏曲脸谱。
