# 《水浒传》第7回 花和尚倒拔垂杨柳 豹子头误入白虎堂

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第007回>；读取日期：2026-10-19。

## 情节要点

1. 智深收服酸枣门外二三十个泼皮（张三、李四为头）；次日泼皮置酒，听见门外老鸦叫，说墙角绿杨树上新添了
   鸦巢，要搭梯拆。
2. 智深脱去直裰，把绿杨树带根拔起，泼皮拜倒；数日后他在槐树下用六十二斤浑铁禅杖演武，墙缺边林冲喝彩，
   两人结义。
3. 林冲陪妻去岳庙还愿，妻在五岳楼下被高衙内拦住，林冲认出是本管高太尉的螟蛉之子，手软；陆谦、富安又设
   计把林冲妻赚到陆家楼上，林冲赶到，衙内跳墙逃走。
4. 一汉在阅武坊巷口叫卖宝刀，林冲以一千贯买下；次日两个承局把他诳进白虎节堂，高俅喝令拿下，下回解送
   开封府。

## 选定场面

相国寺菜园墙角的绿杨树下：智深已脱去直裰，右手在下、左手拔住树干上截，腰一用力、树将带根拔起的一刻。
二三十个泼皮立在周围旁观，尚未拜倒。具名只鲁智深一人，张三、李四混在泼皮群像里，不必单画。三处依据：

- 「智深相了一相，走到树前，把直裰脱了」
- 「用右手向下，把身倒缴着，却把左手拔住上截」
- 「众泼皮见了，一齐拜倒在地」（在拔起之后，不入此刻）

仍取旧题而不改白虎堂：拔树是回目上联，一人一树、众人围观，动势集中且无血腥；白虎堂一场只有林冲持刀立在
檐前，另有匾额四字与绿栏杆，缺少动作，也要靠文字才认得出。

先后核对：老鸦叫、众人叩齿→种地道人说杨树上新添鸦巢→众人要搭梯，李四说“我与你盘上去，不要梯子”→
智深相树、脱直裰→右手向下、身倒缴、左手拔住上截、腰一趁、带根拔起（此刻）→泼皮拜倒→智深说“明日都看
洒家演武”。直裰脱在拔树之前，脱后放在哪里、何时重穿，本回未写。“倒缴着”原文无注，题面只写右手在下、
左手拔住上截，不规定面朝哪边（含推断）。

## 器物与环境

- 地点：东京酸枣门外、大相国寺退居廨宇后的菜园；墙角边一株绿杨树（回目称“垂杨柳”，正文作“绿杨树”，
  不强求柳条下垂），树上一个老鸦巢；园里另有葫芦架、菜园池子、粪窖，墙缺是后文林冲入园处。
- 时令：暮春（后文“正是三月尽”，杨树叶绿）；拔树时酒至半酣，时辰、天气未写，兜底：白天晴。
- 老鸦：只写门外“哇哇的叫”和树上新添的巢；拔树时鸦飞、巢落、有人取巢，原文均未写，不令老鸦飞离。
- 器物：此刻无禅杖（演武日才从房内取出）；酒席设在廨宇内，不在树下；泼皮不持器械。
- 现实中会动的：① 杨树枝叶随拔树摇晃，根旁土块松裂、尘土扬起；② 老鸦在巢边扑翅、不离树；
  ③ 泼皮衣角与头巾带被风拂动。

## 排除项

- 后一刻：泼皮拜倒、称“真罗汉”；智深重穿直裰；演武日的浑铁禅杖，林冲喝彩、墙缺跳入、结义。
- 他版添加：拔后把树栽回、给鸦另安新家（新版电视剧）；先用肩背撞树根、反复摇晃（原文没有）。
- 前一刻：踢张三、李四下粪窖、满身粪污；第4回醉后褪膊露脊背花绣（本回不画全裸）。
- 同回他段：白虎堂、高衙内、陆谦、林冲买刀；买刀汉（抓角儿头巾、旧战袍）本回未具名，不要与第12回杨志混同。
- 后世造型：京剧脸谱、袈裟、月牙铲式禅杖。
