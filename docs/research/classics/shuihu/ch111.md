# 《水浒传》第111回 张顺夜伏金山寺　宋江智取润州城

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第111回>；读取日期：2026-10-20。

## 情节要点

1. 金山、焦山在扬子江心，金山寺绕山而建，焦山寺藏在山凹；润州由方腊的东厅枢密使吕师囊守，统十二个统制官，战船三千余只。
2. 宋江派柴进、张顺、石秀、阮小七扮客探路；张顺与柴进借宿瓜洲民房，黄昏脱膊泅水奔金山，在山脚夺得一只小船，
   得陈家献粮的号旗、号衣与官诰。
3. 吴用设计，燕青扮叶虞候赚得陈观父子；宋军用三百只假扮献粮的船渡江，穆弘、李俊扮陈益、陈泰混入润州，里应外合夺城，
   折宋万、焦挺、陶宗旺三将。
4. 吕师囊退守丹徒；宋江遣关胜等十将迎战苏州来援的邢政，两将交锋。

## 选定场面

黄昏入夜的扬子江上：张顺独自从瓜洲下水，赤膊，腰间扎白绢水裈，头顶用头巾衣服裹着两锭大银的包袱，江水只没到胸口，
在星月交辉、风平浪静的江面上向前涉水游进；前方江心是金山，山上寺院环山而建。具名张顺（一人）。选它因为全回只有这一刻没有杀伐，
又是回目“夜伏金山寺”唯一能入画的前奏。回目虽称“夜伏金山寺”，正文张顺只到金山脚下，并未入寺、也未伏在寺边，
故不画入寺与伏寺。三处依据：

- 「是夜星月交辉，风恬浪静，水天一色。」
- 「张顺脱膊了，扁扎起一腰白绢水裈儿，把这头巾衣服，裹了两个大银，拴缚在头上」
- 「那水淹不过他胸脯，在水中如走旱路。」

先后核对：张顺在江边望见金山寺在江心，决定“今夜去走一遭”，与柴进商议，柴进留守（前）→ 黄昏，脱膊扎水裈，包袱顶头，腰带尖刀，
从瓜洲下水（此刻）→ 到金山脚下，见石峰边缆着一只小船，爬上去擦身穿衣，更鼓三更（后）→ 来船、杀人、夺文书（后，不画）。
此刻他还在水里，衣服在头顶的包袱里而不是穿在身上，既无船也无他人。

## 器物与环境

- 地点：扬子江，金山在江心，北岸瓜洲，南岸润州（今镇江）。宋时瓜洲渡口江面约十八里（《读史方舆纪要》，据摘要），
  金山当时是江中岛屿，清代才与南岸相连（据摘要）。原文写“水淹不过胸脯”，按原文画水只到胸口；构图约定金山在画面右侧远处江心，
  张顺侧身朝右涉水，侧脸可见，避免画成背影。
- 时令天气：初春，白天“日暖花香”；夜里“星月交辉，风恬浪静，水天一色”；月相未写，兜底：一弯月与满天星，月影映水；
  天际尚留黄昏残红。
- 器物：包袱（头巾衣服裹两个大银，宋代银铤，包内不露）、尖刀、白绢水裈；这一刻没有船。
- 现实中会动的：① 水面细波与星月倒影闪烁；② 张顺划水的手臂和胸前被带起的波纹向后扩散；③ 星光明灭、远处南岸旌旗微动。
  人物不整体漂移，可在原地小幅起伏。

## 排除项

- 后拍：爬上山脚小船、解湿衣擦身穿衣、三更遇船、杀虞候与管家、取文书、回瓜洲；柴进与两名伴当在瓜洲屋内，石秀、阮小七在焦山，
  白发婆婆，均不入画。
- 张顺不穿上衣（只扎白绢水裈，没在水下）、不画全裸、不戴青纱万字巾、不持朴刀或叉、不衔刀、不拔刀；不画方腊军士兵、江南十二神、吕师囊与南岸三千战船。
- 不画苏轼《游金山寺》诗里的“江心炬火”（据摘要，与本回无关）；不画影视与戏曲水衣扮相。
