# 《水浒传》第11回 朱贵水亭施号箭 林冲雪夜上梁山

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第011回>；读取日期：2026-10-19。

## 情节要点

1. 林冲醉倒雪中被庄客吊在门楼下，柴进认出放下；官府悬赏三千贯，柴进写荐书荐梁山泊，并把林冲混在猎队里
   送出关。
2. 林冲换上自己的衣裳，系腰刀，戴红缨氈笠，提袞刀上路；暮冬大雪中到枕溪靠湖的酒店，题诗，被店主朱贵认出。
3. 朱贵引林冲到店后水亭，说明自己是王伦手下耳目，酒店为探听客商而开；两人吃酒到半夜。
4. 五更朱贵开水亭窗，朝对港败芦射出响箭，芦苇泊里摇出快船，渡林冲到金沙滩。
5. 王伦不肯收留，要林冲三日内纳投名状；前两日无人，第三日遇一青面大汉争斗（下回接续）。

## 选定场面

水亭窗前，五更天未明：朱贵拉开水亭的窗子，弓上搭着响箭，觑准对港败芦折苇，箭尚未离弦；林冲立在旁边看。
具名朱贵、林冲。三处依据：

- 「此时天尚未明，朱贵把水亭上窗子开了」
- 「取出一张鹊画弓，搭上那一枝响箭」
- 「觑着对港败芦折苇里面射将去」

不取雪夜题诗：题诗靠白粉壁上的八句字才成立，且与上回风雪夜相近；水亭、弓箭、芦苇泊独立成图，是回目上联。
先后核对：题诗、朱贵揪住（前夜）→水亭吃酒到半夜→五更朱贵叫醒林冲，洗漱，吃酒肉→开窗，取弓搭箭，
觑准（此刻）→箭射出；林冲问“此是何意”，朱贵答“山寨里的号箭，少顷便有船来”（后）→没多时芦苇泊摇出
快船（后）。题面画搭箭觑准，不画箭已离弦，也不画小船出现。

## 器物与环境

- 地点：酒店“枕溪靠湖”，店后临水有水亭；亭窗朝向“对港”，对面是芦苇泊，“败芦折苇”，枯芦；去梁山泊
  只数里，全是水路；店前疏荆篱落、黄土绕墙、老树，门挂芦帘，本场面不入画。
- 时令：暮冬；前夜大雪，店被雪“漫漫地压着”；五更天未明，是否仍在下雪未写，兜底：积雪未化，空中无雪，
  水面微有冷雾。
- 器物：鹊画弓，形制未写，兜底：弓身绘喜鹊纹样（据名称，含推断）；响箭，形制未写，兜底：箭镞后带骨哨，
  飞行发声（据摘要）。第19回朱贵射箭写的是“皮靶弓”，与本回不同。
- 现实中会动的：① 对港枯芦随风摇摆；② 水面细波与冷雾缓缓飘移；③ 朱贵、林冲呼出的白气。

## 排除项

- 前一刻：酒店题诗、朱贵劈腰揪住、林冲谎称姓张；水亭夜谈。
- 后一刻：箭离弦、林冲发问；芦苇泊摇出快船、上船、金沙滩、断金亭、聚义厅与王伦；投名状、杨志（青面汉）。
- 林冲戴枷、骑马、持花枪；朱贵穿渔夫蓑衣；响箭拖火、烟或带火药（原文只是响箭）。
- 戏曲影视造型：朱贵脸谱、短打扮；林冲白袍、翎子；梁山泊大旗与寨门此刻不入画。
