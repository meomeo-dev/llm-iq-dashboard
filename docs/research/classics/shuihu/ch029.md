# 《水浒传》第29回 施恩重霸孟州道　武松醉打蒋门神

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第029回>；读取日期：2026-10-20。

## 情节要点

1. 施恩说明快活林被张团练带来的蒋门神夺去、自己被打伤；武松要立即去，老管营出面，施恩拜武松为兄。
2. 次日推说蒋门神不在，改约后日，席上只设肉不设酒，怕武松中酒；武松早起裹头巾、穿布衫，贴膏药遮金印。
3. 施恩与武松出东门，约定“无三不过望”，逢酒店饮三碗，施恩先退到别处；武松只有五七分酒，却装作十分醉。
4. 武松到快活林，见蒋门神在槐树下乘凉，走进“河阳风月”酒店挑衅，把蒋门神的妾与酒保丢进酒缸；蒋门神赶来，
   在大路上被虚拳、飞脚打倒（不入画）。

## 选定场面

快活林口的路上，七月午牌，天正热、有微风：武松布衫摊开，前颠后偃，从林子背后抢过去，斜着眼瞥路旁绿槐树下
的大汉——蒋门神披着白布衫，撒开交椅坐着，手拿蝇拂子乘凉；武松心里认定他是蒋门神，直走过去。酒店在前面三五十步
的丁字路口，尚在视野之外。具名武松、蒋门神。三处依据：

- 「武松酒却涌上来，把布衫摊开。」
- 「披着一领白布衫，撒开一把交椅，拿着蝇拂子，坐在绿槐树下乘凉。」
- 「武松假醉佯颠，斜着眼看了一看」

回目“醉打”，但出手之后是酒缸抛人与路上拳脚，不取。取出手前：一醉一闲，路上两人，无人动手。不取大路对峙
（武松虚晃拳影时已把布衫上半截揣进怀里，上身半裸，且已是动手）；不取酒店内（调戏店主之妾、丢人入缸）。

先后核对：无三不过望，施恩退到别处（前）→再饮十来碗，午牌酒涌，布衫摊开，装醉（前）→林子前，仆人指丁字路口
酒店，武松叫他躲远（前）→抢过林子背后，见槐树下大汉；武松假醉斜眼看（此刻）→心想“一定是蒋门神”，直抢过去
（紧后）→三五十步见“河阳风月”大酒店（后）→入店挑衅，脱布衫上半截揣怀里，丢妾丢酒保（后）→蒋门神闻报踢翻
交椅奔来，大路上撞见（后）。原文未写蒋门神此刻是否看见武松，不画他起身或回头。

## 器物与环境

- 地点：孟州东门外快活林，离东门十四五里（施恩估）；施恩自述这里有百十处大客店、三二十处赌坊兑坊。林子背后
  的官路，绿槐树下，蒋门神的酒店在三五十步外的丁字路口（檐前望竿，酒望子“河阳风月”，绿油栏杆，两把销金旗，
  此刻不画，也不画可辨的字）。快活林今址有城东庙底村、城南黄河边等说，无定论（据摘要）。
- 时令天气：七月，“炎暑未消，金风乍起”；午牌（十一至十三时），“天色正热，却有些微风”。兜底：正午强光，
  槐荫浓黑，路面发白。
- 器物：交椅——折叠椅，腿交叉，宋人画中有，小店多用方桌条凳，交椅非平民常备（据摘要）；蝇拂子——驱蝇的拂子，
  长柄束马尾（据摘要），形制本回未写；万字头巾——巾上饰“卐”字纹（据摘要）；红绢搭膊——腰带，可裹零钱；腿绷即绑腿；
  八搭麻鞋周边八个襻（均据摘要）。
- 现实中会动的：① 蝇拂子在蒋门神手里轻摇；② 槐叶与树影在微风中晃动；③ 武松敞开的布衫衣襟与红搭膊垂带随步摆动。

## 排除项

- 后拍：进酒店、敲桌嫌酒、泼酒、把妾丢进酒缸、酒保被丢入缸、蒋门神踢翻交椅奔来、大路虚拳与飞脚（玉环步、
  鸳鸯脚）、踏住胸脯、饶命、三件事。前拍：施恩退下、无三不过望的逐店饮酒。
- 武松此刻不脱布衫、不赤膊，不倒地，不持刀棒、酒葫芦；原著没有“醉拳”，只有后面的玉环步、鸳鸯脚（据摘要）。
- 蒋门神不是“三头六臂”（那是武松的玩笑）；不画戏曲脸谱，不画成穿甲或持兵器；不画他的徒弟（第30回）。
- 他回：第28回的石墩；第27回的行枷；第30回的枷、飞云浦与鸳鸯楼。酒旗联句不画成可读长句。
