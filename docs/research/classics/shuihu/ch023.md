# 《水浒传》第23回 横海郡柴进留宾　景阳冈武松打虎

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第023回>；读取日期：2026-10-19。

## 情节要点

1. 宋江醉后踩了火锨柄，惹恼廊下害疟疾的大汉，柴进叫出“宋押司”，大汉便是在庄上住了一年的武松；宋江与他
   结伴同住十数日。
2. 武松思乡，穿新纳红䌷袄，戴白范阳毡笠，提杆棒辞柴进；宋江兄弟送出十里上下，酒店里武松拜宋江为义兄。
3. 数日后武松到阳谷县地面，晌午在“三碗不过冈”酒店连吃十五碗；酒家劝他看官司榜文，武松不听，于冈下树上
   见字，冈上山神庙门见印信榜文，仍上冈。
4. 申牌时分，十月红日西坠，武松酒涌，把毡笠背在脊梁、哨棒绾在肋下，在大青石上将睡，狂风起，吊睛白额大虫
   扑出；一扑一掀一剪落空，武松抡棒打在枯树，棒折两截；揪住顶花皮按下，踢脸，按嘴入泥坑，提拳连打，虎死。
5. 武松力尽，遇两名穿虎皮衣的猎户；次日被迎往阳谷县，知县赏千贯，武松转散猎户，被参为步兵都头；回末街上
   有人叫“武都头”（下回接续）。

## 选定场面

景阳冈乱树林中大青石旁，傍晚：折断的半截棒已丢在松树边，白毡笠落在大青石边，武松左手紧揪虎的顶花皮，
把虎嘴按在虎自己刨出的黄泥坑里，右拳提起，还没落下。具名武松，另有大虫一只。三处依据：

- 「武松将半截棒丢在一边，两只手就势把大虫顶花皮肐瘩地揪住，一按按将下来。」
- 「武松把那大虫嘴直按下黄泥坑里去。」
- 「武松把左手紧紧地揪住顶花皮，偷出右手来，提起铁锤般大小拳头」

原文先“只顾打”五七十拳，之后才写虎“迸出鲜血”，故取第一拳提起、未落之时，画面无血。不取扑、掀、剪三闪
（虎在半空，构图散）与棒折（落在空处，气势在空中）。

先后核对：上冈酒涌，毡笠背在脊梁、哨棒绾肋下→狂风，虎扑出，武松翻下青石闪在石边→虎一扑、一掀、一剪，
武松三闪→武松抡棒劈下，打在枯树，棒折两截，只剩半截（此事在揪虎之前）→虎再扑，武松退十步，虎前爪搭在
面前→丢半截棒，双手揪顶花皮按下→脚望面门、眼睛乱踢（前）→虎爪刨起两堆黄泥成坑，嘴被按进坑（此刻之前）→
左手揪住，右手提拳（此刻）→打到五七十拳，虎眼口鼻耳迸血（后）→寻松树边的棒橛再补打（后）→“就石头边
寻了毡笠儿”下冈（后）。毡笠何时落下原文未写；虎死后在青石边寻回，可知打虎时已不在身上。

| :-- | :-- | :-- |
| 武松 | 清河县人，排行第二；“身躯凛凛，相貌堂堂，一双眼光射寒星，两弯眉浑如刷漆，胸脯横阔”；第24回补“身长八尺”“虚度二十五岁”（八尺约二米半，画面只取魁梧）。装束：新纳红䌷袄（新缝絮的红绸袄，据摘要）、白范阳毡笠儿、背上包裹、杆棒（哨棒）。上冈时“把毡笠儿背在脊梁上”“一只手把胸膛前袒开”，故红袄前襟敞开（不赤膊）；虎死后“就石头边寻了毡笠儿”，故打虎时毡笠落在大青石边，不戴头上也不背在背上；哨棒已折，半截弃在松树边地上。靴鞋、腰带、腿绷本回未写，兜底：麻鞋、腿绷、布腰带，不披甲 | 第23回；第24回 |

| 猎户、乡夫 | 打虎之后才出现，穿虎皮缝的衣裳、持五股叉，不入画 | 第23回 |

## 器物与环境

- 地点：阳谷县景阳冈（今山东阳谷县东约16公里，据摘要）。打虎处在敝败山神庙之上更远的“乱树林”：“光挞挞大
  青石”、被哨棒劈中的枯树、松树；虎爪刨出“两堆黄泥”成坑。印信榜文（阳谷县示，限巳午未三时辰结伴过冈）贴在
  山神庙门上；冈下另有刮去树皮书写的告示，非印信榜文。两处均在前，不入此刻。
- 时令天气：“此时正是十月间天气，日短夜长，容易得晚”；上冈已“申牌时分”，红日西坠（申时约15至17时，
  据摘要）；虎出前“狂风”；古风写“晚霞挂林”“冷雾弥苍穹”，“天色看看黑了”在虎死之后。兜底：黄昏暖红光，
  枯叶，不画雪。
- 器物：杆棒折剩半截，丢在松树边（后文“来松树边寻那打折的棒橛”；《武经总要》称杆棒取坚木，长四五尺，
  据摘要）；白毡笠，落在大青石边；包裹；大青石；枯树。
- 现实中会动的：① 虎尾抽动；② 虎爪刨起的黄泥与草屑；③ 狂风中乱树枝叶与枯枝摇晃。

## 排除项

- 后拍：见血、补打棒橛、拖不动虎、遇穿虎皮衣的猎户、抬虎游街、知县赏钱。前拍：酒店十五碗与“三碗不过冈”
  酒旗、冈下树上字、山神庙榜文、青石上欲睡、虎的扑掀剪、棒打枯树。
- 哨棒：折在打枯树时，不是打在虎身；此刻不画整根棒，也不画武松持棒。
- 毡笠：此刻不戴在头上，也不背在脊梁上（背笠是上冈途中的事），只画落在大青石边。
- 虎只有一只；不画虎血；踢虎面门一拍在提拳之前，此刻不画踢。
- 他回装束：第24回雪天的鹦哥绿紵丝衲袄、油膀靴；行者装束与戒刀（后文）；柴进庄上的新衣。
- 戏曲年画：戏曲武松头戴罗帽、窄袖短衣、颈系领巾，手持长棍（据摘要），不画；不赤膊、不披虎皮。
