# 《水浒传》第74回 燕青智扑擎天柱　李逵寿张乔坐衙

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第074回>；读取日期：2026-10-20。

## 情节要点

1. 燕青向宋江请命，三月二十八日独去泰安州岱岳庙献台上与“擎天柱”任原相扑，扮山东货郎下山；李逵偷跟来，
   答应燕青三件事：入店不出、推病蒙头、庙上不要大惊小怪。
2. 二十六日燕青在庙前用匾担打碎任原的粉牌（劈牌）；二十八日四更起身，脱去衲袄，系熟绢水裩，混在人丛中等候。
3. 献台上，知州在殿门外月台弹压，老部署执竹批上台；任原脱锦袄，燕青从人背上飞上台，脱布衫露出遍身花绣，
   部署读社条，叫“看扑”。燕青两次钻过任原胁下，将他托起旋转，用“鹁鸽旋”摔下台。
4. 任原徒弟拽倒山棚抢利物，李逵拔杉刺子打人、打死任原，二人上屋揭瓦，卢俊义引兵接应。
5. 李逵独闯寿张县衙，穿官服坐公座，令人扮告状；被穆弘拖回山，宋江责骂。朝廷收到各处申奏，派陈宗善招安。

## 选定场面

三月二十八日清晨，泰安州岱岳庙嘉宁殿前献台：部署叫过“看扑”，任原在台左立个门户，燕青在台右蹲低，
台上只有三人，各占一半，中间空着，尚未接触。具名燕青、任原，另有老部署、台下观众群像、远处月台上的知州。
选它是因为两人的体型对比、燕青的花绣和满场围观都在这一刻，且尚未交手。三处依据：

- 「净净地献台上只三个人，此时宿露尽收，旭日初起」
- 「部署拿着竹批，两边吩咐已了，叫声：‘看扑！’」
- 「当时燕青做一块儿蹲在右边，任原先在左边立个门户」

先后核对：燕青飞上台、脱衣露花绣、被知州唤下问话、再上台（前）→部署读社条、劝燕青留命（前）→叫“看扑”（此刻）→
燕青蹲右、任原立左，各占一半（此刻）→任原逼近、燕青钻胁下、鹁鸽旋（后）→徒弟拽倒山棚（更后）。此刻燕青头巾、草鞋、
腿绷护膝、布衫都已脱下；任原锦袄已脱、巾帻已除；山棚尚立着；李逵在廊下人丛中，未上台。

## 器物与环境

- 地点：泰安州岱岳庙嘉宁殿前。“朝着嘉宁殿扎缚起山棚，棚上都是金银器皿，锦绣疋；门外拴着五头骏马”；殿宇“雕梁画栋，碧瓦朱檐”。
  献台形制未写，兜底：方形木台，台面铺板，无绳圈无护栏。真实岱庙主殿是天贶殿，前有露台（据摘要），题面以小说为准。
- 时令天气：三月二十八日是东岳大帝诞辰，自宋起有庙会（据摘要）；此刻旭日初起、宿露已收，兜底：春日晴晨。
- 观众：香官亚肩叠背，屋脊、廊庑坐满，台两边排得“似鱼鳞一般”。
- 现实中会动的：① 山棚上的锦绣疋、彩旗随风飘动；② 屋脊与廊下观众挥臂喝彩、小幅起伏；③ 殿前香炉的香烟袅袅上升。
  燕青与任原只做呼吸、手指与脚尖的小动作，不整体位移。

## 排除项

- 后拍：任原逼近、燕青穿胁下、托起旋转的“鹁鸽旋”、任原摔下台、徒弟拽倒山棚抢利物、李逵拔杉刺子并打死任原、
  上屋揭瓦、卢俊义引兵接应。前拍：货郎挑担、打碎粉牌、客店李逵蒙被、知州问话。寿张县衙一段（官服、公座、枷人、学堂）
  是另一场面，不混画。
- 不画血腥与落台；李逵不上台；燕青不穿衲袄、不戴头巾；擎天柱粉牌已碎，不画牌。
- 日本相扑的兜裆带、大银杏髻、圆形土俵不用；西式摔跤擂台绳圈、现代擂台不用；不画京剧勾脸武生、戏曲小生扮相。
