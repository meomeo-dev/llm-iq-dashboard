# 《水浒传》第110回 燕青秋林渡射雁　宋江东京城献俘

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第110回>；读取日期：2026-10-20。

## 情节要点

1. 降将胡俊招降胡显，淮西收复；朝廷下旨解王庆赴京；南丰设太平宴、打醮，孙安病卒，乔道清、马灵辞去，宋江立碑龙门山。
2. 大军分五起北归，到宛州内乡县秋林山南的秋林渡。宋江在马上见雁阵惊鸣，前军喝彩，原来燕青初学弓箭，须臾射下十数只雁；
   宋江以雁的“仁义礼智信”训诫，赋诗作词，当晚屯兵渡口。
3. 暮冬回京，屯陈桥驿；文德殿朝见，王庆凌迟，公孙胜辞去；水军头领出怨言，宋江誓不反。
4. 燕青、李逵扮客入城看灯，得知方腊作乱；宋江经宿太尉保奏，受封平南都总管，出师征方腊。

## 选定场面

秋林渡口，山南：燕青站在岸边，弓已拉开、箭已搭弦，仰头望着天上雁阵，箭尚未离弦；数行雁从秋林山上空向南飞过；
道旁几名军士仰头观看。具名燕青。选它因为回目点名“秋林渡射雁”，单人仰角、构图简洁，又避开雁坠地与宋江训诫。三处依据：

- 「见空中数行塞雁，不依次序，高低乱飞，都有惊鸣之意」
- 「原来是“浪子”燕青，初学弓箭，向空中射雁，箭箭不空」
- 「小弟初学弓箭，见空中一群雁过，偶然射之」

先后核对：行数日到秋林渡，宋江马上遥看山景（前）→ 仰观见雁阵乱飞惊鸣，又听前军喝彩，差人去问（同时）→ 飞马回报：
燕青射雁，须臾射下十数只（结果）→ 燕青“弯弓插箭”飞马来见，马后捎死雁数只，下马立一边，宋江训诫（后）→ 当晚屯渡口，作诗词（后）。
原文只写射雁的结果，未写拉弓的瞬间；本题取又一箭搭弦未发的一刻（雁已惊飞、前军已喝彩，说明此前已射过），是推定的一刻。
宋江此时在行军队伍的马上，另派人去问才知，不与燕青同框。此刻没有雁正在坠落，没有箭在空中，马后没有死雁。

## 器物与环境

- 地点：宛州内乡县秋林山之南的秋林渡，“山泉石佳丽”。宋代无宛州，内乡属邓州，应为小说拟名；百回本等作“双林渡”（据摘要）。
  兜底：渡口、河面在前，北侧远山有泉有石，岸边林木。
- 时令天气：原文未写。上承第109回孟冬擒王庆，其后南丰十余日、打醮七日、再行数日，约在冬季；宋江说雁“避寒…趁江南地暖”，
  射雁当晚屯兵渡口，次日起行即“正值暮冬”。兜底：暮冬晴日，林叶多已落尽，枝头残留枯黄叶，草枯，天高；白天（当晚才屯兵渡口）。
  地名“秋林”不等于满树红叶。
- 雁阵：数行，秋南春北，十月至十一月南飞高峰，常成“人”字或斜行（据摘要）；兜底：三四行松散斜线，每行六七只，高低错落，
  从远山上空飞向画面右下，不画整齐“人”字。
- 弓：宋弓以筋角复合反曲弓为主（《武经总要》有黑漆弓等，据摘要）；兜底：深色漆弓，反曲，满弦，羽箭；弓袋、箭囊宋代形制未检得。
- 现实中会动的：① 雁阵扇翅缓缓向前飞，可出画后从画面远端循环再入（不画坠落）；② 林梢残叶、岸边草丛随风摆；
  ③ 河面细波与燕青的衣带、巾带轻摆。燕青与弓姿势不变，箭不离弦。

## 排除项

- 后拍：雁中箭坠落、死雁捎在马后、下马立一边、“仁义礼智信”训诫、口占诗词、当夜屯兵；前拍：南丰太平宴、孙安下葬、乔道清辞去；
  后文：陈桥驿、文德殿献俘、王庆凌迟、燕青与李逵看灯。
- 燕青用弓，不用川弩，不露花绣，不画第61回的簪花银丝白衫旧装；不画宋江、李逵；不画落羽与血。
- 不画影视造型与戏曲扮相。
