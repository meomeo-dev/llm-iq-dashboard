# 《水浒传》第57回 徐宁教使钩镰枪　宋江大破连环马

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第057回>；读取日期：2026-10-20。

## 情节要点

1. 聚义厅上，晁盖、宋江、吴用、公孙胜请徐宁教枪；徐宁下厅拿起钩镰枪自使一回，讲马上、步下的枪法与诗诀，不到
   半月教成五七百人。
2. 宋江定计：全用步军，分十队下山诱敌，钩镰枪手与挠钩手各十人相间，埋伏在芦苇荆棘；凌振放子母炮，水军接应。
3. 呼延灼锁上连环甲马追赶，马群收勒不住，跑进败苇枯草，被钩镰枪钩倒、挠钩搭住，三千甲马被擒；韩滔被擒入伙，
   呼延灼单骑逃走。
4. 呼延灼投青州慕容知府，歇村店时御赐马被桃花山偷走；借兵攻桃花山，遇二龙山鲁智深、杨志来救，不分胜负；白虎山
   孔明、孔亮来攻青州，武松遇孔亮，三山议攻青州（下回接续）。

## 选定场面

冬日，梁山聚义厅前空地：徐宁刚选军完毕，下厅拿起一把钩镰枪，当众使一回，讲“上中七路，三钩四拨，一搠一分”；
被选中的壮健军士列队观看，晁盖、宋江、吴用、公孙胜等头领立在厅上，喝采。取四拨中的一式：徐宁两手握枪，枪身横过
身前，带钩的一端斜朝上，目视前方，脚下半步前压。具名徐宁、宋江（宋江只作厅上小像）。无马无敌，不涉伤人。三处依据：

- 「便下聚义厅来，拿起一把钩镰枪自使一回」
- 「上中七路，三钩四拨，一搠一分，共使九个变法」
- 「众人见了喝采」

先后核对：第56回末众头领在聚义厅上看徐宁选军（前）→徐宁选军已罢，下厅自使一回，众人喝采（此刻）→对众军讲马上、
步行枪法和诗诀，逐路敷演（紧接，口头）→教成五七百人（后）→宋江定计，埋伏（后）。此刻没有马、芦苇与敌人，枪也
没有钩向任何东西；军士只看，不同时对练。

## 器物与环境

- 地点：梁山聚义厅（木构厅堂）及厅前空地；厅形制原文未写，宋代官署厅堂为台基、踏道、木构梁架（据摘要），按此
  作画，不画殿宇、不画石狮。
- 钩镰枪：原文只写“鉤鐮鎗”，未描形制；公开资料称枪头下部带向内弯的倒钩，宋代《武经总要》记有双钩枪、单钩枪
  等带钩枪（据摘要）。一篇网文给出全长七尺二寸、枪头八寸、杆六尺、尾鐏四寸，但该文标明系AI生成，且无一手出处，
  仅作参考。兜底：木杆长枪，枪尖一侧生一个弯钩，钩尖朝内；枪缨原文未写，可不画。
- 口诀：“四拨三钩通七路，共分九变合神机。二十四步挪前后，一十六翻大转围”；步战“八步四拨，十二步一变，十六步大
  转身”。“钩拨搠缴攒分斗夺”八字口诀不见于原文（据摘要），不使用。
- 时令：冬（第56回“寒冬”；本回后段“败苇折芦”“枯草荒林”），兜底：晴冷，枯草，不画雪。
- 现实中会动的：① 聚义厅前旗帜随风飘；② 徐宁袍襟与乌巾带随枪势微摆；③ 脚下尘土在枪势带起时轻扬、落下。

## 排除项

- 后拍：宋江分十队、芦苇伏兵、钩倒马腿、挠钩搭人、连环马被擒、呼延灼逃走、韩滔入伙。前拍：第56回赚上山。
- 不画马与马腿，不画实战、倒地、被擒；不画韩滔、呼延灼、彭玘、凌振、汤隆。
- 钩镰枪不是月牙戟、镰刀、关刀或朴刀；不画成两侧对称的戟。
- 徐宁此刻不穿雁翎甲，不戴宫中赐花；京剧《雁翎甲》又名《连环马》（据摘要），戏曲扮相不入画。
- 他回人物：鲁智深、杨志（本回后段）；“金枪班随驾”场面（第56回）。
