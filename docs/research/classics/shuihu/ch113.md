# 《水浒传》第113回 混江龙太湖小结义　宋公明苏州大会垓

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第113回>；读取日期：2026-10-20。

## 情节要点

1. 宋江苏醒后，李逵等夺无锡；吕师囊败退苏州，三大王方貌率八骠骑出战；两军各出八将对阵，朱仝胜苟正，收兵。
2. 李俊带童威、童猛驾小船探太湖，被榆柳庄费保、倪云、卜青、狄成擒住，报名后四人拜服，李俊提议结义，七人结拜。
3. 费保等设计劫杭州押运的铁甲船，李逵等扮艄公水手混入苏州，戴宗、凌振放炮，里应外合夺城，武松斩方貌；宣赞、施恩、孔亮阵亡。
4. 费保四人不愿做官，辞别宋江，李俊送回榆柳庄。

## 选定场面

太湖榆柳庄草厅内：李俊三人刚被松绑，费保等四人听了名字拜服；李俊说“就这里结义为兄弟”，四人大喜，设酒宴结拜，
李俊居上位，费保等四人向李俊拱手行礼（姿势是构图约定，原文只写“结拜”），童威、童猛立在李俊身后两侧，
桌上陈酒与熟猪羊肉。具名李俊、费保、童威、童猛，
另三名太湖好汉作群像。选它因为回目点名“太湖小结义”，是全回唯一的江湖义气场面，无厮杀。三处依据：

- 「团团一遭，都是驼腰柳树，篱落中，有二十余家。」
- 「既是恁地，我等只就这里结义为兄弟如何？」
- 「四个好汉见说大喜，便叫宰了一口猪、一腔羊，致酒设席，结拜李俊为兄。」

先后核对：李俊三人被挠钩搭住、绑在桩木，草厅上四人喝问，“取他心肝来吃酒”（前）→ 李俊不报名，为头者割断绳索，扶入屋内，
纳头便拜；李俊自报“混江龙”及童威、童猛，四人报名；李俊劝他们做官，费保辞（前）→ 结义，宰猪羊设席，童威、童猛一并结义（此刻）→
七人商议取苏州，费保派渔人打探，劫杭州官船（后）→ 李逵四人到庄上，费保见李逵相貌“皆骇然”（后）。
此刻绳索已断，挠钩大汉不在场，无兵器出鞘，李逵等尚未到。

## 器物与环境

- 地点：太湖榆柳庄，在“渐近吴江”处；“四下里都是深港，非船莫能进”，二十余家，四周驼腰柳；渔人撑船引入。原文只写柳不写榆，
  今地未检得。兜底：茅草顶的敞厅（宋代乡村民居以茅屋为多，据摘要），柱梁外露，厅前竹篱，院外弯腰老柳、水港与渔船。
- 陈设：兜底：桌、长凳（宋代高坐家具已普及，据摘要），酒坛、粗瓷大碗、盘中熟猪肉与羊肉（原文“宰了一口猪、一腔羊”），
  不画屠宰与血；香案、神像、歃血原文均未写，不画。
- 时令天气：原文未写；湖景赞诗有“绿净春深”，承第111、112回初春；兜底：晴暖，柳条新绿，白天，光从厅前射入。
- 现实中会动的：① 柳条随风摆；② 厅外湖面波光与远处渔船缓缓漂；③ 七人抱拳躬身、倾壶斟酒（小幅往复）。人物不整体位移。

## 排除项

- 前拍：挠钩大汉搭人、绑桩木、“取心肝来吃酒”、割绳；后拍：商议劫官船、平望镇劫船、抛尸太湖、李逵等到庄上、苏州夺城、
  武松斩方貌、费保辞官、劝李俊走海外。
- 不画宋江、吴用、李逵、鲍旭、项充、李衮、戴宗、凌振；张顺只被提到，不入画。
- 不画血腥宰杀、桃园式香案、割臂歃血、李俊三人仍被捆；不把费保等画成异族或丑化形象；不画影视与戏曲造型。
