# 《水浒传》第101回 谋坟地阴险产逆　蹈春阳妖艳生奸

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第101回>；读取日期：2026-10-20。

## 情节要点

1. 武学谕罗戬上奏淮西王庆作乱五年，童贯、蔡攸出征覆没却隐瞒；蔡京等巧辩，天子不即加罪。
   次日亳州太守侯蒙荐宋江征王庆，蔡京等把侯蒙、罗戬送到陈瓘军前，想借王庆之手除掉宋江。
2. 侯蒙携诏敕赏赐到威胜，设龙亭香案宣读：陈瓘为安抚，宋江为平西都先锋，卢俊义为副先锋，
   先救宛州。五月五日宴后大军南行。
3. 张清、琼英解田虎等到东京，琼英之母受追赠，琼英受封；田虎等被凌迟，琼英以首级祭父母。
4. 倒叙王庆：父王砉与风水先生设计夺人坟地；王庆生后浮浪，好斗鸡走马、使枪抡棒，家产败尽，
   充开封府副排军。
5. 政和六年仲春，王庆出城游玉津圃，见童贯侄女娇秀乘轿，尾随至艮岳、岳庙，被虞侯打骂；
   此后与娇秀私通，事发，童贯欲整治他；五月下旬板凳作怪（引下回）。

## 选定场面

东京城南玉津圃，仲春白昼。王庆当班后出城闲逛，独自把肩胛斜倚在傍池的一棵垂杨上，等相识的人
同去酒肆吃三杯；周围游人如蚁、马匹如云。具名王庆，另有游人群像。选它是因全回大半是朝堂与
私情，这是少有的无打斗、无私情的春日景象，回目“蹈春阳”可直接入画，王庆形貌也可借此交代。
依据：

- 「仲春天气，游人如蚁，军马如云」
- 「向那圃中一颗傍池的垂杨上，将肩胛斜倚着」
- 「欲等个相识到来，同去酒肆中吃三杯进城」

先后核对：五更入衙画卯，干办完毕，闲步出城南到玉津圃，独自闲耍一回（前）→ 倚垂杨等人（此刻）→
“无移时”见池北十来个干办、虞候簇拥一乘轿子（后）→ 他尾随至艮岳（后）→ 酒店、岳庙点烛、被董虞候
掌掴（更后）。此刻没有轿子、娇秀、虞候和艮岳。夺坟地、虎梦、少年习武都是叙述，不是现场。

## 器物与环境

- 地点：玉津圃即玉津园，在城南；《东京梦华录》卷六：“州南则玉津园外学方池亭榭”。园内有池，
  池边垂杨。玉津园为皇家园林，春季向市民开放（据摘要）。
- 时令天气：政和六年仲春；原文诗“上苑花开堤柳眠……玉楼人醉杏花天”，《梦华录》写同季
  “粉墙细柳，芳草如茵，杏花如绣”；兜底：晴日，杏花盛开，垂杨初绿，池水平静，芳草初生。
- 器物：垂杨、池、杏花、芳草；远处游人与马匹。艮岳是别处，不入画；史上艮岳政和七年末才
  开工（据摘要），与原文政和六年已有不合，更不画。
- 现实中会动的：① 垂杨枝条随风轻摆；② 池面波纹，倒影微晃；③ 杏花花瓣飘落。
  人物不整体位移。

## 排除项

- 后拍：娇秀乘轿到池北、王庆尾随、艮岳、岳庙点烛、被董虞候打、薛婆子牵线、私通。
  前拍：王砉夺坟地、王砉虎梦、少年赌博嫖饮、打骂父母、侯蒙在威胜宣诏龙亭、田虎受刑。
- 后文的板凳作怪、刺配、枷、刺字不可提前画上；不画王庆色眯眯的神态，不画戏曲小生扮相。
- 不画大象、狮子、犀牛等苑中异兽（摘要所称，原文未写）；不画灯笼、轿子、艮岳奇石。
- 游人女子不特写、不丑化，不画裸露。
