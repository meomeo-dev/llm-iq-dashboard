# 《水浒传》第115回 张顺魂捉方天定　宋江智取宁海军

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第115回>；读取日期：2026-10-20。

## 情节要点

1. 宋江与戴宗在西陵桥祭张顺，方天定遣南山、北山各五将半夜出城来拿；樊瑞、马麟、石秀、阮小二、阮小五等举火设伏，擒茅迪，李逵、鲍旭等斩三将。
2. 戴宗报卢俊义取独松关经过：董平、张清、周通战死；孙新、顾大嫂夫妇与时迁等夜上关放火，擒三守将，卢军过关。
3. 宋军分攻杭州各门：鲁智深与邓元觉步战五十余合不分胜负，武松斩贝应夔；石宝连折索超、邓飞，刘唐死于候潮门闸板下，鲍旭亦折。
4. 解珍、解宝探得范村有富阳袁评事的数十只粮船；吴用定计，王英、扈三娘等三对夫妻扮艄公艄婆，众将伏舱随粮入城。
5. 当夜二更凌振在吴山顶放炮，众将举火破城；方天定出南门逃至五云山下，被“张横”扯下马割头。“张横”自称张顺魂附体，向宋江说完倒地。

## 选定场面

杭州城东北角外的江岸：粮船已靠岸，方天定遣六员将领一万军拦在东北角，由袁评事指挥搬粮入城；宋军众将混在艄公水手里
扛粮，三名扮艄婆的女将也随队入城，兵器全藏在舱里。具名袁评事、解珍、解宝，另有艄公、艄婆、水手与南军群像。选它因“智取”
一眼可认：表面是运粮，实为伏兵，无人动手。“张顺魂附张横”一幕不选：原文张横“赤条条”上岸、口衔刀、割下方天定首级，
又把首级撇在宋江面前的地上，属不画之列。三处依据：

- 「方天定差下六员将，引一万军出城，拦住东北角上，着袁评事搬运粮米，入城交纳。」
- 「此时众将人等，都杂在艄公水手人内，混同搬粮运米入城。」
- 「扈三娘、顾大嫂、孙二娘三人女将，扮做艄婆。」

先后核对：吴用定计，将校下船，艄公衣服给王英、孙新、张青穿，三女将扮艄婆，小校扮水手，“军器众将都埋藏在船舱里”，
船放到江岸边（前）→袁评事上岸，解珍、解宝与几个艄公跟着到城下叫门；吴值开城门到江边点船，回城奏知（前）→方天定差六将
引一万军拦在东北角，袁评事搬粮，众将混在人堆里搬运，三女将随入城（此刻）→五千粮食须臾搬完，六将统兵入城，宋兵分投围城
（后）→二更吴山放炮举火（更后）。此刻没有放炮举火，没有吴值点船，兵器不外露。

## 器物与环境

- 地点：杭州城东北角外的江岸。艮山门属东面城门，艮为东北方位，原文另写宋军攻艮山门；原文未明说粮从哪门入，
  兜底：东北角城门洞敞开。城门形制：候潮门处写“关外一重闸板，中间两扇铁叶大门，里面又是一层排栅门”，此处未写，兜底：铁叶大门敞开，吊桥放下。
- 时令天气：本回未写；第116回开头“此时已是四月尽间”，当日放炮在“当夜二更”，故为初夏白天；兜底：晴。
- 器物：粮船“一连有数十只”，兜底：平底、拱形舱顶（《清明上河图》漕船，据摘要），船舷搭跳板；粮袋为麻布袋，扛在肩上，“五千粮食”是容量，不必数袋。
- 现实中会动的：① 江面波纹与船身随水轻晃（船不整体漂移）；② 城头与军阵旗帜随风飘；③ 岸边芦苇、柳枝摆动。

## 排除项

- 后拍：当夜二更吴山顶放炮、众将举火；李俊等取船由涌金门登城；方天定出南门；五云山下“张横”扯马、割头、提首级、拜宋江、自称张顺、倒地。
- 前拍：西陵桥奠酒与伏击；独松关战况；鲁智深战邓元觉、武松斩贝应夔、刘唐闸死；吴值开门点船；解珍、解宝叫门。
- 不画赤身、口衔刀、首级、张顺鬼魂或水中现形；不画外露的刀枪；艄婆不画成泼辣丑角，不露肤，不用戏曲扮相和影视造型。
- 不画吴用、宋江、凌振等不在此场的人；不画第116回的天使、御酒。
