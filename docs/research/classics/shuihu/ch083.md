# 《水浒传》第83回 宋公明奉诏破大辽　陈桥驿滴泪斩小卒

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第083回>；读取日期：2026-10-20。

## 情节要点

1. 辽国四路入侵，童贯等四贼臣瞒报。宿元景在殿上驳斥，奏请遣宋江破辽立功；天子封宋江为
   破辽都先锋、卢俊义为副先锋，命宿太尉到行营开读。
2. 宋江请假还山，安置晁盖灵位、遣送家眷、拆毁寨栅战船，回京后在武英殿朝见，受赐御酒、
   描金鹊画弓箭、名马、宝刀。
3. 大军分两起北上，经陈桥驿。中书省差来的两名厢官克扣酒肉，项充、李衮部下一名军校与其争执，
   杀死厢官；宋江含泪将军校缢死、斩首示众，垂泪上马北进。
4. 到辽境，段景住引路，攻檀州：密云县张清飞石打败辽将阿里奇，耶律国珍、国宝来援被董平、
   张清击败，水陆并进夺下檀州，洞仙侍郎出北门逃走，被关胜、林冲拦住。

## 选定场面

初夏晴日上午，东京城外通往陈桥驿的官道。宋江军分两起北上：前队已先行，画面前景是中军——宋江
居中骑御赐名马，鞍侧挂描金鹊画弓箭，腰悬御赐宝刀；卢俊义在他一侧，吴用、公孙胜随行；前导两面
红旗“顺天”“护国”，身后枪戟旌旆成列，路两旁榆柳新绿，黄土路上轻尘微扬。具名宋江、卢俊义、
吴用、公孙胜。选它是因整军北上、旗号招展是本回最先的大场面，且无任何动手。三处依据：

- 「令五虎八彪将引军先行，十骠骑将在后」
- 「宋江催趱三军，取陈桥驿大路而进，号令军将，毋得动扰乡民」
- 「招摇旌旆出天京，受命专师事远征」

先后核对：封都先锋、副先锋（前）→武英殿朝见，受赐弓箭、名马、宝刀（前）→中书省备酒肉，差官二员
往陈桥驿（前）→分两起进程，宋江等统领中军，催趱三军取陈桥驿大路（此刻）→前队在驿领酒肉，
厢官克减，军校杀厢官（后）→宋江令军校自缢后斩首示众，垂泪上马（后）→檀州战事（更后）。此刻队伍在
路上、未到驿：没有酒肉分发，没有厢官，没有事端，没有首级。

## 器物与环境

- 地点：东京北出陈桥驿大路。陈桥驿在陈桥门外东北，今河南封丘陈桥镇，南临黄河（据摘要）；陈桥门是
  “大辽人使驿路”（卷一）。原文未写城门、驿舍形制，兜底：只画平原官道，不画城门与驿舍。
- 路旁与季节：宋代官道夹植榆柳（据摘要），故路旁榆柳。本回无月日；前回告示署“宣和四年三月”，买市
  至三月十三，之后济州、东京、还山拆寨、再返京，此时不早于四月；第84回称“炎天”，兜底：初夏晴日。
- 旗：前导两面红旗“顺天”“护国”，是第82回入京队伍所打，本回未重写，兜底沿用；红旗之外不再写字，
  不画“破辽都先锋”帅旗（原文未写）。杏黄旗“替天行道”是第71回山顶旗，不画。
- 现实中会动的：① 红旗与旌旆迎风飘动；② 路面轻尘随风飘散；③ 马鬃马尾、盔缨、枪缨随步伐摆动。
  队伍不整体平移。

## 排除项

- 后拍：陈桥驿给散酒肉、克减（酒半瓶、肉十两）、军校掷酒肉拔刀、杀厢官、宋江询问、军校缢死与
  悬首、宋江大哭；檀州、密云县、潞水战，张清飞石，辽将阿里奇、耶律国珍。前拍：宿元景殿上奏对、
  武英殿受赐、还山拆寨祭晁盖。
- 不画辽军、辽旗“皂雕旗”；不画水军战船。
- 不画赵匡胤陈桥兵变与黄袍加身（该地的另一史事）；不画戏曲靠旗、雉尾翎、龙套行军。
- 不画朝廷御营兵（诗句只以其衬托梁山军纪）。
