# 《水浒传》第90回 五台山宋江参禅　双林镇燕青遇故

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第090回>；读取日期：2026-10-20。

## 情节要点

1. 破辽后鲁智深告假去五台山参本师智真长老，宋江等百余人同往；宋江一行脱去戎装，各穿随身衣服，步行上山，
   在方丈拜见长老，鲁智深献金银被拒，长老只教为他置经一藏。
2. 次日法堂升座，宋江问浮世生死，长老答偈；夜里长老写四句偈给宋江（“当风雁影翩……”），另赠鲁智深四句
   （“逢夏而擒，遇腊而执，听潮而圆，见信而寂”），都不明说。
3. 下山回军，行至双林镇，燕青在人丛中遇到旧友许贯忠；燕青随他到大伾山草舍住了两夜，得一轴手卷。
4. 宋江等在陈桥驿听候旨意，入城朝见：宋江等众将身穿锦袍金带，只有吴用、公孙胜、鲁智深、武松仍是本身服色。
5. 戴宗、石秀便服出营，在酒店遇一公人，引出下回。

## 选定场面

五台山寺法堂，智真长老在引磬与红纱灯笼的引导下刚升法座、坐定；两旁众僧问讯后侍立，宋江上前捻香礼拜，
合掌近前请问；鲁智深立在一旁的头领行列里。具名智真长老、宋江、鲁智深。选它是因法座、香烟、灯笼、袈裟
都是原文写明的静态陈设，三人关系（长老、宋江、鲁智深）清楚，且无任何动手。三处依据：

- 「引磬响处，两碗红纱灯笼，引长老上升法座。」
- 「两下众僧，打罢问讯，复皆侍立。」
- 「宋江向前捻香礼拜毕，合掌近前参禅」

先后核对：宋江、鲁智深并众头领立于两边（前）→引磬响，灯笼引长老升座，长老捻信香祝赞三炷（前）→就法座坐，
众僧问讯侍立（此刻）→宋江捻香礼拜，合掌上前问浮世生死（此刻）→长老答偈（后）→众将捻香设誓“同生同死”（后）
→去云堂赴斋（后）→夜里方丈，长老写四句偈、赠鲁智深偈（更后）。此刻偈语尚未说出，众将尚未设誓，
长老尚未授偈；画面不要求出现任何可读文字。

## 器物与环境

- 地点：五台山寺法堂。第4回称“文殊院”“文殊寺”，是文殊菩萨道场；本回只写“五台山寺中法堂”。
  兜底：宽敞的木构大堂，正面一座高于地面的法座，座前设香案、铜香炉与烛台，两侧留出僧众列班的空地。
- 法座：原文只写“法座”；兜底：宋代禅椅式扶手靠背座，铺织锦座垫，座前设脚踏（宋代禅师像中禅椅前常有足承，据摘要）。
- 器物：引磬是铜制小磬配木柄，用于指挥僧众起坐（据摘要），此刻可由一名僧人持在手中；两盏红纱灯笼，宋代有红纱贴金烛笼
  （据摘要），兜底：由侍者立于法座两侧；信香数炷，已插入香炉（长老升座“先捻信香”，又两次“再捻信香一炷”，宋江随后
  “向前捻香礼拜”，此刻炉中不止一炷）；袈裟、问讯合掌。
- 时令天气：五台山时令本回未写；上下文在宣和四年冬月之后，五台山冬季酷寒（据摘要），兜底：冬日室内，窗外不画景。
- 现实中会动的：① 香炉中信香的烟缕上升后弯折飘散；② 两盏红纱灯笼内烛焰明灭、灯笼轻晃；③ 香案烛火摇曳
  （兜底，原文未写蜡烛）。人物不整体位移。

## 排除项

- 后拍：长老说偈的内容、众将设誓、云堂斋、夜里方丈两段偈语与宋江、鲁智深的前程，双林镇燕青遇许贯忠（头戴抹眉头巾、
  身穿皂沿边道服，与第61回吴用近似），大伾山草舍，陈桥驿朝见，戴宗石秀酒店。前拍：山门迎接、方丈初见、献金银被拒。
- 第4、5回的鲁智深：醉打山门、拆亭子、有发有络腮胡的鲁达俗家形象、露花绣脊背、持禅杖，均不画；宋江不披甲、不佩刀。
- 不画文殊菩萨大像和佛光金身；不画长老入定（本回只由首座转述“坐禅入定”）；不加原文未写的拂尘、念珠。
- 不画影视里的僧袍或戏曲扮相；法堂内不出现兵器。
