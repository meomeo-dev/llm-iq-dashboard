# 《水浒传》第10回 林教头风雪山神庙 陆虞候火烧草料场

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第010回>；读取日期：2026-10-19。

## 情节要点

1. 林冲在沧州营前遇旧识李小二，小二夫妇在营前开茶酒店，照应林冲；陆谦、富安携金银在小二店中与管营、
   差拨密谈，小二报信，林冲买尖刀寻了数日，不见动静。
2. 管营调林冲去东门外十五里的大军草料场替老军，林冲带花枪、尖刀，与差拨同去，天降大雪。
3. 草料场草屋被朔风吹得摇动，林冲挑着酒葫芦去沽酒；回来草厅已被雪压倒，他拿絮被到半里外古庙安身，
   用大石头靠住庙门。
4. 草料场起火，林冲在庙内听见陆谦、富安、差拨在庙檐下说话，掇开石头、开门挺枪（以下杀人不入画）。
5. 林冲杀三人后到庄客处烘衣，抢酒打翻庄客，醉倒雪中被缚。

## 选定场面

山神庙门内：大石头已掇开，林冲右手挺着花枪，左手拽开庙门，尚未出声的一刻。陆谦、富安、差拨三人仍站在
庙檐下，面向草料场看火（面向为推断）。具名林冲、陆谦、富安、差拨。三处依据：

- 「三人在庙檐下立地看火」
- 「轻轻把石头掇开，挺着花枪，左手拽开庙门」
- 「草料场里火起，刮刮杂杂的烧着」

先后核对：壁缝看见火起→拿枪待开门救火→听见三人脚步，伏门边听→三人推门被石头靠住，在檐下看火说话→
林冲辨出是差拨、陆虞候、富安→轻轻掇开石头，挺枪、左手拽开庙门（此刻）→大喝“泼贼那里去”，三人惊呆
（后）→枪拨、搠、提翻，剜心割头（后，不画）。酒葫芦放在纸堆上，白布衫与氈笠脱在供桌上（后二者杀人后才
重新穿戴，被与葫芦则丢弃）；花枪挑葫芦只出现在去沽酒与回来的路上。

## 器物与环境

- 地点：沧州东门外十五里的大军草料场，庙在场外约半里的路上；庙门掩上，一块大石头靠门；殿上一尊金甲
  山神，两边一个判官、一个小鬼，侧边堆一堆纸，另有供桌；无邻舍、无庙主；壁缝透出草场火光。
- 时令：严冬夜，彤云密布，朔风渐紧，大雪越下越紧；天色已黑，光只来自草场火光与雪光。
- 器物：花枪，形制未写，兜底：长杆枪头下系红缨（据摘要），不用丈八蛇矛；解腕尖刀；酒葫芦、牛肉；絮被；
  白布衫与氈笠。
- 现实中会动的：① 大雪被朔风斜卷；② 草场方向火焰跳动，火光映在雪地与庙檐上；
  ③ 庙门缝漏进风雪，纸堆上的纸片被风吹动。

## 排除项

- 后一刻：喝声、三人惊呆；一枪拨倒差拨，搠倒富安，提翻陆谦，剜心割头，首级摆供桌；烘衣抢酒、醉倒被缚。
- 前一刻：李小二店中密谈，草料场交割，沽酒，草厅被雪压倒。
- 央视版把“轻轻掇开石头”改成一脚踢飞石墩（仅见搜索摘要）；原文是轻轻掇开。
- 林冲穿白布衫、戴氈笠、枪上挑葫芦：只在路上与杀人后；此刻不得有。
- 他回器物：后文林冲所用的丈八蛇矛；第11回上路时的袞刀、腰刀、红缨氈笠。
- 后世造型：京剧《林冲夜奔》式盔头翎子、披风、脸谱。
