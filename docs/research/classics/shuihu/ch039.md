# 《水浒传》第39回 浔阳楼宋江吟反诗　梁山泊戴宗传假信

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第039回>；读取日期：2026-10-20。

## 情节要点

1. 李逵点倒卖唱女，宋江送银二十两；宋江吃鲜鱼闹肚子，在营里养病数日。
2. 病愈后宋江入城寻戴宗、李逵、张顺不遇，独自上浔阳楼饮酒，醉后在白粉壁上题《西江月》词与四句诗，署
   “郓城宋江作”。
3. 无为军在闲通判黄文炳登楼抄走题壁，向蔡九知府拆解童谣，诬宋江谋反；戴宗教宋江装疯，仍被拷问招供，
   二十五斤死囚枷入牢。
4. 知府差戴宗送家书上东京，戴宗拴四个甲马赶路，在酒店被朱贵麻翻，带上梁山。
5. 吴用定计，让萧让仿蔡京笔迹、金大坚刻图书写假回书，戴宗带回江州（下回接续）。

## 选定场面

浔阳楼上靠江的阁子里，宋江独自立在白粉壁前，手持毛笔、墨浓笔饱，写《西江月》词的起首几句；壁上已有他人
题咏的墨迹；身后桌上一樽酒、朱红盘碟。具名宋江。题的是先词后诗：先写《西江月》词，词后另写四句七言诗，
最后大书“郓城宋江作”五字；此刻只取写词，诗与署名在后。字写在白粉壁上，不是纸、屏风或刻石。三处依据：

- 「忽然做了一首《西江月》词，便唤酒保索借笔砚来」
- 「见白粉壁上多有先人题咏」
- 「乘着酒兴，磨得墨浓，蘸得笔饱，去那白粉壁上挥毫便写道」

先后核对：上楼占靠江阁子，酒肴“鱼便不要”（前）→独饮沉醉，思乡落泪（前）→作词，唤酒保借笔砚（前）→起身到
粉壁前，磨墨蘸笔写词（此刻）→写罢大喜大笑，再饮数杯，手舞足蹈，另写四句诗（后）→大书署名，掷笔桌上，付
酒钱，拂袖下楼（后）。时辰未写：辰牌前后出营，入城寻人后上楼，醉归睡到五更，兜底：午后，日光入窗。

## 器物与环境

- 地点：浔阳楼在城外江边：望竿挑青布酒旆，上写“浔阳江正库”；雕檐外牌额“浔阳楼”三字（苏东坡大书）；门边朱红
  华表，柱上两面白粉牌各书五个大字；楼上“雕檐映日，画栋飞云，碧栏干，翠帘幕”，阁子靠江，窗外渔父鸣榔、
  钓翁击楫，楼畔绿槐、门前翠柳。
- 时令：月份未写；次日黄文炳登楼嫌“天气暄热”，文册记宋江“五月间新配到”，兜底：初夏，窗外槐柳青翠。
- 器物：白粉壁（石灰刷白的墙，宋人酒楼、驿舍多有题壁，据摘要）；毛笔、墨与砚（宋江自己“磨得墨浓”，笔墨材质
  未写，兜底：普通毛笔、浓黑墨）；一樽“蓝桥风月”美酒（南宋名酒，据摘要）；肥羊、嫩鸡、酿鹅、精肉、时新果品，
  朱红盘碟，无鱼。
- 现实中会动的：① 青布酒旆在江风里飘；② 窗外江面渔舟缓行；③ 笔锋沿壁面移动、墨痕逐笔延伸（局部）。

## 排除项

- 后拍：写四句诗、手舞足蹈、署名、掷笔；黄文炳读诗抄录；宋江披发泼屎尿装疯、竹箩抬、受拷、死囚枷；戴宗
  拴甲马。前拍：琵琶亭、卖唱女、吃鱼闹肚子。
- 宋江不戴枷、不披发；酒保、黄文炳不入画；壁上字不要求可辨认。
- 不画成纸卷、屏风或刻石；底本是“词加诗”，不是单首七言诗。
- 不另加彩楼欢门（宋代酒楼常见，据摘要，但本回写的是雕檐画栋与酒旆）。
- 影视：明清楼阁样式的浔阳楼、舞台醉态与脸谱不用。
