# 《水浒传》第82回 梁山泊分金大买市　宋公明全伙受招安

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第082回>；读取日期：2026-10-20。

## 情节要点

1. 天子文德殿痛责童贯、高俅，宿元景自请招安，天子亲书丹诏，赐金牌三十六、银牌七十二、
   红锦三十六匹、绿锦七十二匹、黄封御酒一百八瓶。
2. 宋江沿路扎二十四座山棚；济州太守张叔夜上山报信，吴用等四人下山迎宿太尉。第三日宿太尉
   捧诏出济州，宋江、卢俊义路上跪迎，千百战船渡水，诏书抬入忠义堂。
3. 萧让开读诏文，宋江等三呼万岁；宿太尉令裴宣给散牌面锦缎，先饮御酒以示无疑，再劝众头领。
4. 宋江请宿太尉回京，随后买市十日（三月初三至十三），遣散不愿从军者三五千人，府库金帛分发众人。
5. 大军入京，前导红旗“顺天”“护国”，天子在宣德楼观军，众人换御赐锦袍入文德殿赴宴；
   枢密院建议分调军马，童贯进谗，御屏风后转出一大臣喝止。

## 选定场面

春日白昼，梁山泊忠义堂。堂上居中摆三个几案，围黄罗龙凤桌围：正中立“万岁”龙牌，御书丹诏居中，
金银牌面与红绿锦缎分列两侧，案前放御酒，金炉焚香。宿元景坐在堂上案侧；萧让立在案旁，双手展开
黄纸诏书开读；乐和立画面左侧，裴宣、燕青立画面右侧。宋江、卢俊义领头，众头领成排跪在堂前阶下，
低头听诏。具名宿元景、萧让、宋江、卢俊义。选它是因“全伙受招安”的仪式一幅可见，端正、无动手。依据：

- 「正中设万岁龙牌，将御书丹诏，放在中间」
- 「宋江、卢俊义等，都跪在堂前」
- 「拜罢，萧让开读诏文」

先后核对：香车龙亭抬放堂上，设三几案（前）→宋江、卢俊义邀宿太尉、张太守上堂设坐，左立萧让、乐和，
右立裴宣、燕青（前）→宋江等跪堂前，裴宣喝拜，拜罢（前）→萧让开读诏文（此刻）→读罢三呼万岁
再拜（后）→宿太尉令裴宣给散牌面锦缎（后）→宿太尉先饮御酒再劝众人（后）。此刻牌面、锦缎、御酒仍
在案上，没有发到人身上，无人持杯；读诏的是萧让，不是宿太尉；众人尚未换御赐锦袍（入京后才换）。

## 器物与环境

- 地点：忠义堂，堂前敞开，可见阶下。兜底：宋式木构厅堂，出檐深，斗拱，石阶。原文陈设：几案三个，
  “都用黄罗龙凤桌围围着”，正中万岁龙牌，丹诏居中，金银牌面一侧、红绿锦缎另一侧（兜底：金银牌面在
  画面左、锦缎在画面右），“御酒表里，亦放于前”，“金炉内焚着好香”。龙亭已抬放堂上，兜底：画在案后一角或不画。
- 诏书与龙牌：宋制诏敕用黄纸（据摘要），故画黄纸卷轴；不画清代双龙云纹锦缎圣旨。“万岁龙牌”明清官府
  有设（据摘要），宋代未检得，原文有则照画，牌面只写“万岁”二字。
- 时令天气：诏文署“宣和四年春二月”，兜底：春日晴，树木新绿；不画雪、荷花。
- 现实中会动的：① 金炉香烟袅袅上升；② 堂前旗幡与彩旗被风吹动；③ 萧让手中黄纸诏书卷边轻颤。
  跪着的人与建筑不整体位移。

## 排除项

- 后拍：给散牌面锦缎、宿太尉先饮御酒、筵宴三日、送行、买市十日、遣散军校、入京、宣德楼观军、换御赐
  锦袍、文德殿赐宴、童贯进谗。前拍：沿路二十四座山棚、宋江卢俊义路上跪迎、金沙滩渡船。
- 这是宿太尉（宿元景），不是第75回的陈太尉；张干办、李虞候、村醪换御酒的情节不入画。
- 不画清代龙亭圣旨仪仗、乌纱翅帽、补服；不画戏曲髯口、勾脸；不画买市场面。
- 山顶杏黄旗“替天行道”（第71回）不画；此次招安后前导旗是“顺天”“护国”，且在入京队伍，不入此刻。
