# 《水浒传》第81回 燕青月夜遇道君　戴宗定计出乐和

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第081回>；读取日期：2026-10-20。

## 情节要点

1. 萧让、乐和被高俅带回京城软禁。宋江、吴用料定高俅不会奏请招安，遣燕青、戴宗带金珠
   进东京打通关节；闻焕章写信给同窗宿元景。
2. 燕青以假公文混入城，到李师师家送金珠，认姊弟；当夜借李师师引见道君皇帝，唱曲诉“流落”，
   求得御笔赦书，并讲明梁山招安始末，天子由此得知童贯、高俅隐瞒败绩。
3. 次日燕青、戴宗向宿太尉呈上书信与礼物，宿太尉应允在天子前奏请。
4. 二人买通高府年轻虞候，在耳房见到乐和，约定四更用两条粗索隔墙接应。四更得手，
   四人出东京回梁山。

## 选定场面

四更，东京高太尉府后墙外。墙内一排大柳树，两条粗索从柳树绷过墙头；墙外的戴宗与燕青各握一条
索头，立在墙根；乐和正手足并用沿索从墙头向外攀出，面朝墙外；萧让尚在墙内，不入画；远处河边缆着
两只空船。具名燕青、戴宗、乐和。选它是因这是回目“定计出乐和”的落点，动作端正、无人受伤，
夜、粉墙、柳树、绷索构图清晰。本书不画妓家与调情，李师师与道君皇帝不入画。三处依据：

- 「绕着墙后咳嗽，只听的墙里应声咳嗽」
- 「两个在外面对绞定，紧紧地拽住索头」
- 「只见乐和先盘出来」

先后核对：茶坊以银买通虞候，耳房见乐和，约四更（前）→买粗索，先看府后落脚处，在河边空船里伏着
（前）→听得四更，上岸绕墙咳嗽，墙内应声（此刻前一瞬）→燕青把索漾过墙，墙内拴牢，两人在外对绞定
拽住（此刻）→乐和先盘出来（此刻）→萧让随后，两人溜下，索子丢入墙内（后）→客店取行李、出城（后）。
此刻两人已离开空船、站在墙根，空船只在远处河边；索子未丢入墙内；萧让尚未上索。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 燕青 | 浪子。“六尺以上身材，二十四五年纪，三牙掩口细髯，十分腰细膀阔”，“雪练也似白肉”，遍体花绣——本场不露臂，不画纹身。夜行衣着未写（白天扮作闲汉，换领布衫、搭膊系腰、头巾歪戴），兜底：深色布衫，搭膊束腰，皂色头巾，麻鞋，腰缠袋；第61回的攒顶头巾、银丝白衫、金环、簪花不沿用 | 第61、81回 |
| 戴宗 | 神行太保。赞诗“面阔唇方神眼突，瘦长清秀人材”，兜底：脸宽口方，目光有神（不画凸眼），身形瘦长，中年；衣着未写，兜底：深色长衫扎腰，皂纱巾（不插翠花），麻鞋；甲马、令字黄旗、宣牌是奔走行头，本场不画 | 第38、81回 |
| 乐和 | 铁叫子。“玲珑心地衣冠整，俊俏肝肠语话清”；年龄、身形未写。兜底：清秀青年，无须，素色布袍，头巾，在索上手足并用向外攀，目视墙外 | 第49、81回 |

## 器物与环境

- 地点：高太尉府后墙外。墙内“旁边一遭，都是大柳树”，府后是条河，河边缆着两只空船，离岸不远。
  墙高原文未写，兜底：粉墙青瓦，一丈余。东京沿河植杨柳、官宅多粉墙（据摘要）。不画桥。
- 时辰季节：“更鼓已打四更”（北宋四更约凌晨1–3时，据摘要）；月色未写，兜底：深蓝夜色，淡薄月光，
  不画灯火。闻焕章信署“宣和四年春正月”，兜底：早春，柳枝下垂，疏叶新芽，不画盛夏浓荫。
- 器物：两条街上买的粗索（质地未写，兜底：麻索，拇指粗）；折花梯子已被藏过，不画梯子。
- 现实中会动的：① 绷紧的索随乐和攀行微微颤动；② 柳条在夜风中摆动；③ 河面水纹反光，远处空船
  随水轻晃。三人身体不整体位移。

## 排除项

- 前拍：李师师家客位、吹箫弹阮、拜为姊弟、道君皇帝御书赦书；宿太尉府投书；茶坊买通虞候。
  后拍：萧让溜下、索子丢入墙内、客店取行李、四人出城；高俅发觉人走了（第82回）。
- 不画李师师、道君皇帝、高俅、虞候；不画妓家、酒席、调情。燕青不脱衣露花绣。
- 不画蒙面黑色夜行衣、飞檐走壁、火把追兵（明清武侠式）；不画戏曲武生翻腾、水袖。
- 戴宗不系甲马；不画宿太尉、闻焕章。
