# 《水浒传》第112回 卢俊义分兵宣州道　宋公明大战毗陵郡

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第112回>；读取日期：2026-10-20。

## 情节要点

1. 关胜在丹徒斩邢政，吕师囊退常州；宋江与卢俊义抓阄分兵，宋江取常、苏，卢俊义取宣、湖，另遣李俊等十员水军攻江阴、太仓。
2. 关胜率十一员马军到常州城下搦战，与方腊的常州制置使钱振鹏及六统制官对阵；韩滔、彭玘阵亡，关胜坐骑失蹄落马被救回。
3. 宋江立白旗；李逵等四人斩高可立、张近仁，宋江在白旗下祭韩、彭。
4. 守将金节与妻秦玉兰谋归降，射书入宋营；凌振放炮打塌敌楼，金节诈败引孙立入西门，常州收复。
5. 卢俊义攻宣州得手但折三将，宋江闻讯昏倒。

## 选定场面

常州城下两军对阵，尚未交手：关胜把军马退开一步，让钱振鹏列阵，自己立马横刀，向对阵厉声叫阵；钱振鹏骑卷毛赤兔马、
持拨风刀，在南军阵前，六个统制官分立两侧，城门敞开、吊桥已放下。具名关胜、钱振鹏，两军作群像。选它因为是两军主将
未交手前的对峙，仪式感强，无血腥，又切回目“大战毗陵郡”。三处依据：

- 「关胜见了，把军马暂退一步，让钱振鹏列成阵势，六个统制官，分在两下。」
- 「对阵关胜当先立马横刀，厉声高叫」
- 「钱振鹏使口拨风刀，骑一匹卷毛赤兔马，当先出城。」

先后核对：宋军三千马军到城下搦战，吕师囊点钱振鹏与六统制官出战，开城门放吊桥，钱振鹏先出城（前）→ 关胜退军一步，
南军列阵，关胜立马横刀叫阵（此刻）→ 钱振鹏大怒回骂，关胜舞刀直冲，二将斗三十余合（后）→ 赵毅、范畴夹攻，黄信、孙立出阵，
高可立射韩滔，张近仁刺杀韩滔、彭玘，关胜坠马（后，不画）。此刻关胜骑自己的赤兔马；后文他骑钱振鹏的卷毛赤兔（时间原文未明），不画；
无人落马、无人中箭。

## 器物与环境

- 地点：常州毗陵郡城下，城池“高广”（金节语），“开了城门，放下吊桥”。宋代常州有子城与罗城，罗城周二十七里、开九门（据摘要）；
  《武经总要》载城外凿壕、壕上设吊桥、城上有女墙与敌楼（据摘要）。兜底：高城墙，门楼上有敌楼，门前吊桥落下，壕内有水。
- 时令天气：承第111回初春，本回未写；兜底：晴天，地面干。
- 兵器：青龙偃月刀。偃月刀（《武经总要》作“掩月刀”）宋代始见，主要用于演武，三国时并无（维基已读，形制据摘要）。
- 现实中会动的：① 两军旗帜、枪缨、盔缨随风飘；② 战马喷鼻、甩鬃尾、蹄在原地刨地（不前冲）；③ 城头旗帜与阵前轻尘。
  关胜与钱振鹏不交手、不前移。

## 排除项

- 后拍：二将交锋、赵毅范畴夹攻、黄信孙立出阵、金节佯败、高可立射韩滔、张近仁刺杀韩彭、关胜坠马、徐宁救回；前拍：关胜斩邢政、
  吕师囊退常州。后几日：宋江立白旗、李逵斩高张首级、凌振炮塌敌楼、金节献城；卢俊义取宣州不画。
- 关胜不骑卷毛赤兔，不画落马、首级、白旗、被箭射中。
- 不画戏曲靠旗与脸谱，不画影视关公；关胜是三柳细须，不画美髯长髯。
