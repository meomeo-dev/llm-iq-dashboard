# 《水浒传》第66回 时迁火烧翠云楼　吴用智取大名府

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第066回>；读取日期：2026-10-20。

## 情节要点

1. 吴用献计趁元宵攻北京：时迁正月十五夜在翠云楼放火为号，其余头领扮作猎户、客商、僧道、乞丐等先入城埋伏，另分
   八路军马，限十五日二更到城下。
2. 梁中书、闻达议定仍照例放灯，比往年多设花灯，市心添搭两座鳌山，放灯五夜；北京各处张灯结彩。
3. 时迁正月十三入城，劝孔明、孔亮不要扮乞丐太显眼；十五日夜二更，挟篮上翠云楼，遇解珍、解宝，随后楼前喊声大起，
   翠云楼烈焰冲天。
4. 梁山各路同时发动，梁中书四门受阻，由李成护着逃出；柴进、乐和在牢中放出卢俊义、石秀；燕青、张顺擒住李固、
   贾氏；城中死伤近半，吴用、柴进下令收军（后拍均不画）。

## 选定场面

元宵夜二更，北京大名府翠云楼上：阁子里笙箫鼓板正闹，灯火通明；走廊里时迁挟着一只插着闹蛾的篮子，扮作卖闹蛾的
小贩，篮里是硫黄、焰硝的药头，尚未点燃；解珍、解宝扮猎户，拖着挂了兔子的钢叉站在阁子前，时迁问“更次到了”，
解珍答“你只顾去行事”。具名时迁、解珍、解宝。选它是因元宵灯市的繁盛与小贩伪装形成反差，“火将起未起”靠篮中药头
这件道具表达，不靠火焰，也不涉及放火后的伤亡。三处依据：

- 「时迁挟着一个篮儿，里面都是硫黄、焰硝放火的药头」
- 「篮儿上插几朵闹鹅儿，踅入翠云楼后」
- 「撞见解珍、解宝，拖着钢叉，叉上挂着兔儿，在阁子前踅」

先后核对：正月十三时迁入城，在东岳庙神座下安身（前）→十五日黄昏月上，街市点灯，楼上鼓打二更（前）→时迁挟篮上楼，
只做买闹蛾儿的各阁子去看，阁中吹笙箫、动鼓板（此刻）→撞见解珍、解宝，时迁问更次，解珍答“只顾去行事”（此刻）→
楼前发喊“梁山泊军马到了西门外”（后）→翠云楼烈焰冲天（后，不画）。吴用原定一更放火，原文写到二更才动手；原文无
火折、火把，篮内只有药头，所以时迁手里不画点着的火种。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 时迁 | “鼓上蚤”。赞诗“骨软身躯健，眉浓眼目鲜”，第56回汤隆称“鲜眼睛黑瘦汉子”；转述为身形瘦，肤色偏黑，眉浓眼亮，动作灵便；“形容如怪族”一句不入画，不画异族面貌。本回扮“买闹鹅儿的”小贩：衣着未写，兜底：短衣、头巾，臂弯挟一只篮，篮中几包纸裹药头，篮沿插几朵闹蛾（元宵时用丝帛或纸做的蛾形饰物，据摘要）；不穿黑色夜行衣，不蒙面，不持火把 | 第46、56、66回 |

## 器物与环境

- 地点：翠云楼，“名贯河北，号为第一。上有三檐滴水，雕梁绣柱”，“楼上楼下，有百十处阁子”；楼前扎一座鳌山，盘一条
  白龙，四面点灯。翠云楼是小说虚构（据摘要）。宋代酒楼为二至三层楼阁，歇山顶，腰檐平座，彩楼欢门，阁子有吊窗花竹
  （据摘要）；“三檐”宋代专条未检得，兜底：两三层木构楼，层层挑檐，檐下悬灯，不画明清牌楼式屋顶。
- 时令天气：正月十五上元，“好生晴明，黄昏月上”，此刻二更，月高天朗。宋代元宵有灯山（鳌山）、走马灯、琉璃灯等（据摘要）；
  原文另有“五色屏风砲灯”、州桥边纸龙，本题只取楼前白龙与檐下灯。
- 器物：篮；药头（宋代火药原料为硫黄、焰硝、木炭，据摘要），兜底：纸裹小包，露出灰白药线，不画明火；闹蛾；钢叉与兔；
  笙箫、鼓板；灯笼。
- 现实中会动的：① 楼前鳌山白龙周身的灯焰闪烁；② 檐下悬灯与阁子里的灯影随风轻摇；③ 乐人手臂与鼓板小幅往复敲击。
  人物不整体位移。

## 排除项

- 后拍：楼前发喊、梁山军马到、翠云楼烈焰冲天；各路动手（李应、史进劫东门，王太守被打死，杜迁、宋万杀梁中书一门，
  柴进放囚）；李固、贾氏被擒；城中死伤。一律不画火焰、浓烟、尸体、血、爆炸。前拍：十三日孔明、孔亮扮乞丐，杨雄、
  刘唐撞见；公孙胜、凌振扮道士；柴进、乐和到蔡福家。
- 时迁此刻不拿火把、火折、油桶；吴用、宋江、卢俊义不在楼上。
- 他回：第46回时迁偷鸡；第56回盗徐宁甲。
- 戏曲：时迁武丑扮相、鼻梁涂白块（据第46回笔记检索）不画。
