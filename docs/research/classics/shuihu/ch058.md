# 《水浒传》第58回 三山聚义打青州　众虎同心归水泊

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第058回>；读取日期：2026-10-20。

## 情节要点

1. 鲁智深、杨志、武松议救孔明；孔亮连夜赴梁山请宋江，宋江分五军、二十头领、三千人马赴青州，与三山人马会合。
2. 宋江与鲁智深、杨志相见，鲁智深设酒；次日吴用定计，秦明与呼延灼斗四五十合不分胜负；呼延灼夜里追宋江、吴用、
   花荣三骑，落陷坑被擒，宋江亲解其缚，呼延灼归降。
3. 呼延灼赚开城门，秦明打死慕容知府，救出孔明及其叔孔宾；三山人马同归梁山泊，新上山头领十二位（后拍，不画）。
4. 鲁智深荐史进，与武松去少华山，闻史进被华州贺太守拿下，单身入华州行刺，反被擒（下回接续）。

## 选定场面

青州城下，宋江中军到后的军营：孔亮已先到鲁智深军中报信，宋江领二十头领到了，武松引鲁智深、杨志、李忠、周通、
施恩、曹正前来相见。宋江抬手让鲁智深坐，鲁智深回答“久闻阿哥大名”，杨志与武松立在鲁智深两侧，其余作背景群像。
具名宋江、鲁智深、杨志、武松。三山首领与梁山之主在此首次聚首，无人动兵器，不涉战斗；“让坐”与答话之外的手势为
构图兜底。三处依据：

- 「武松引鲁智深、杨志、李忠、周通、施恩、曹正，都来相见了」
- 「宋江让鲁智深坐地」
- 「久闻阿哥大名，无缘不曾拜会」

先后核对：孔亮离青州赴梁山（前）→宋江分五军到青州，孔亮先到鲁智深军中报知（前）→宋江中军到，武松引众人相见，
宋江让鲁智深坐（此刻）→鲁智深答话，宋江答，杨志起身再拜（紧接）→鲁智深置酒管待（后）→次日吴用定计（后）。此刻
杨志、武松均站立，杨志的“起身再拜”在其后；鲁智深与呼延灼的阵前交手在第57回，本回两人未对阵。

## 器物与环境

- 地点：青州城下军营。青州是京东东路治所，宋代治益都（今山东青州）；城有敌楼（第57回慕容知府“在敌楼上”）；二龙山
  在青州城西一说属地方考证（据摘要）。军帐形制宋代无专条，按原文“军中”作大帐或帐前空地。
- 时令：本回未写。第56回为寒冬，次日呼延灼出城追赶处有“枯树”；兜底：冬末，枯树，淡日光，不画雪与花。
- 器物：梁山与三山旗号（行军诗有“绣彩旗如云似雾”）；就坐用的椅凳，兜底：交椅或方凳数把；酒后拍。
- 现实中会动的：① 营旗与彩旗随风飘；② 帐帘与帐顶飘带轻摆；③ 拴在营边的战马甩尾低头。

## 排除项

- 后拍：杨志起身再拜之后的宴饮；次日吴用定计、秦明斗呼延灼、呼延灼落陷坑、赚城门、秦明打死慕容知府、放火斩全家
  （均不画）；鲁智深、武松去少华山、鲁智深被贺太守擒。前拍：第57回鲁智深骑白马挥禅杖斗呼延灼、杨志斗呼延灼。
- 不画呼延灼；不画孔明、孔亮；不画李逵。
- 他回装束：鲁智深第3回提辖战袍（鹦哥绿紵丝战袍、鹰爪皮靴）；杨志第12回的白缎征衫、范阳毡笠；武松未做
  行者前的都头与头陀衣冠。
- 不画京剧杨志蓝脸脸谱、鲁智深僧脸谱（据摘要），不套用影视造型；杨志的赤须与青记不画成异族面貌；不把鲁智深画成
  凶恶相。
