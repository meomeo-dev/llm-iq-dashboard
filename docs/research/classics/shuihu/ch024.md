# 《水浒传》第24回 王婆贪贿说风情　郓哥不忿闹茶肆

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第024回>；读取日期：2026-10-19。

## 情节要点

1. 武松在县前遇兄武大，随回紫石街见嫂潘金莲；金莲屡以言语、饮酒撩拨，被武松怒斥；武松搬回县衙，不久领
   差赴东京，临行叮嘱武大“下了帘子，早闭上门”。
2. 武松去后，武大每日早归，金莲到时先收帘、关大门；一日冬将残，她叉帘子时叉竿失手，打在路过的西门庆头巾
   上，王婆在隔壁茶坊看见。
3. 西门庆几次到王婆茶坊，王婆说破他的心思，献“潘驴邓小闲”与“十分光”之计；以做送终衣料为由，三日内引
   金莲到茶坊，西门庆与金莲成奸（此事不入画），王婆逼二人每日相会。
4. 半月后街坊尽知，只瞒武大；郓哥提雪梨篮寻西门庆，闯进茶坊，被王婆揪打赶出，梨滚满街，扬言去告武大
   （下回接续）。

## 选定场面

阳谷县紫石街武大家门前，冬末将晚：潘金莲在门前用叉竿叉帘子，叉竿失手滑倒，竿梢刚好打在路过的西门庆头巾上；
西门庆脚步刚停，还没回脸；金莲两手脱竿，神色惊愕；隔壁茶坊门帘内，王婆望着，没出声。具名潘金莲、西门庆、
王婆。三处依据：

- 「那妇人惯了，自先向门前来叉那帘子」
- 「这妇人正手里拿叉竿不牢，失手滑将倒去，不端不正，却好打在那人头巾上」
- 「那婆子正在茶局子里水帘底下看见了」

不取郓哥闹茶肆：王婆揪打孩童、雪梨滚落，动作粗暴。不取叉手万福后的对礼：二人相视而笑，易画成眉目调情。
取此刻：回目上联的起因，失手无意，门前一景，无亲昵。

先后核对：武大将归，金莲先去叉帘子→叉竿拿不牢，滑倒，打在头巾上（此刻）→西门庆立住脚、待发作，回脸，怒气
变笑（后）→金莲叉手道万福，西门庆整头巾、曲腰还礼（后）→王婆笑道“兀谁教大官人打这屋檐边过”（后；她“看
见”与竿落同时，开口在后，故不画开口）→西门庆唱肥喏、回头七八遍而去，金莲收竿帘进屋（后）。叉竿、帘子、
头巾的位置：事在武大家门前一楼，叉的是门帘，不是二楼窗；打中的是头巾，不是脸。

## 器物与环境

- 地点：阳谷县紫石街。武大赁居的房屋与王婆茶坊“间壁”相邻，同在街面一排平房（影视多改成对面或二楼，原文并非）。
  武大门口挂芦帘（“芦帘起处”），用叉竿叉收；茶坊有烧茶处“茶局子”与“水帘”，形制未写，兜底：茶坊门口的帘。
- 时令天气：“冬已将残，天色回阳微暖”，在武松走后十数日；时辰“武大将次归来”，傍晚前；雪在十一月，已过，
  不画雪，也不画春花柳绿。
- 器物：叉竿（叉收放门帘的长竿，顶端分叉，形制本回未写，兜底：细长木竿）、芦帘、头巾、茶炉。
- 现实中会动的：① 芦帘下摆与叉竿梢端摆动；② 茶局子炉上水汽缓缓升起；③ 两人衣带、头巾带与袖摆随微风飘动。

## 排除项

- 后拍：西门庆回脸怒转笑、金莲叉手万福、西门庆整巾还礼、王婆开口、唱肥喏、回头七八遍；
  之后王婆茶坊的议计、成奸、郓哥闹茶肆。
- 改编出入：影视多改成金莲在二楼窗口掉竿（据摘要），原文在一楼门前叉帘子；《金瓶梅》第二回写春日一阵风
  刮倒叉竿，本回无风、非春日。
- 折扇：北宋折扇为稀见舶来品，南宋渐有仿制，明代才普及（据摘要），原文也无；西门庆不持折扇，不添金银饰。
- 他回人物：武松已赴东京、武大未归、郓哥与雪梨篮不入画；金莲不画胸颈外露，不画眉目传情。
