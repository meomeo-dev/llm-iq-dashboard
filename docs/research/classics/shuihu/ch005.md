# 《水浒传》第5回 小霸王醉入销金帐 花和尚大闹桃花村

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第005回>；读取日期：2026-10-19。

## 情节要点

1. 智真长老赠偈，智深辞山，在铁匠隔壁客店住数日，取得插鞘戒刀与漆裹禅杖，上路。
2. 半月后天晚投桃花村刘太公庄，得知桃花山周通要强招太公之女为婿，智深自荐为他说因缘，
   让太公把女儿藏到邻庄，自己坐进新房销金帐。
3. 初更，周通带人举火把到庄前，太公迎入；周通入房摸黑，被智深揪下痛打，逃回山寨（智深在帐中
   脱得赤条条，此一刻不画）。
4. 桃花山大头领李忠领人来报仇，与智深对面认出旧识，劝周通折箭为誓；智深在山住几日，嫌二人悭吝，
   绑小喽啰、卷酒器，从后山滚下逃走。
5. 午后饥饿，闻远处铃铎声，寻向寺院（下回为瓦罐寺）。

## 选定场面

桃花庄前，初更，周通骑在马上到了庄门前，尚未下马：前有四五对红纱灯笼，四五十火把，喽啰红头巾红袄，
器械旗枪缚着红绿绢帛，头巾边插野花；刘太公命庄客大开庄门，出来迎接。具名周通、刘太公，另有喽啰、
庄客群像。理由：周通装束原文写得最全，红绿火光对比强，无伤亡，智深在房内，不涉及裸身。

- 「只见前遮后拥，明晃晃的都是器械旗枪，尽把红绿绢帛缚著。」
- 「前面摆著四五对红纱灯笼，照著马上那个大王。」
- 「头戴撮尖干红凹面巾，鬓傍边插一枝罗帛像生花」

先后核对：天黑点灯烛，打麦场摆桌设香花灯烛→初更，山边锣鸣鼓响→太公与庄客出门，见火把人马
飞奔而来→太公叫大开庄门迎接→人马前遮后拥，灯笼照着马上大王（此刻，仍在马上）→大王下马，喽啰
齐贺“帽儿光光”（后）→太公捧台盏跪迎（后）→“刘太公把了下马杯”（后）→入房（后）。原文“那大王已有
七八分醉了，呵呵大笑”写在太公跪迎之后、把下马杯之前，“已有”表明周通到庄时已带酒意，不是饮下马杯后
才醉。故此刻不画下马；周通面带酒意、仍坐稳鞍上，不画醉倒落马。

## 器物与环境

- 地点：桃花村刘太公庄前，庄后重重叠叠都是乱山；庄门大开；打麦场上有桌，摆香花灯烛。
  桃花山上的李忠此时不在场。
- 时令：初更，夜；沿途晚景“绿杨郊外”“红杏村中”，二月下山又行半月，按初春处理（推断）；天气、月色
  未写；“桃花村”只是地名，原文无桃花盛开之景，不强加。
- 器物：火把四五十，红纱灯笼四五对，器械旗枪上缚红绿绢帛，锣鼓；周通马此刻未系树。
- 现实中会动的：① 火把火焰与飘飞的火星；② 灯笼与旗枪上的红绿绢帛随步摆动；③ 白马的卷毛、鬃尾与
  呼出的气。

## 排除项

- 后一刻：周通下马，喽啰贺“帽儿光光，今夜做个新郎”，太公捧下马杯，周通入房摸帐被打。
- 智深“脱得赤条条地”坐在销金帐内、赤条条骑翻大王打——不画；房内床头戒刀、床边禅杖也不入这一场面。
- 他人他回：李忠（大头领，后来才领人马、挺枪）；第2回陈达（同戴干红凹面巾、骑高头白马，但披生铁甲）；
  周通不穿甲，不持兵器，“走水绿沉枪”的说法见于他处，本回无（据摘要）。
- 后世造型：戏曲丑角扮相、红袍花轿式新郎不取；原文只写绿罗袍、红搭膊，花是一枝。
- 时间：不画白昼；也不画满山桃花。
