# 《水浒传》第70回 没羽箭飞石打英雄　宋公明弃粮擒壮士

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第070回>；读取日期：2026-10-20。

## 情节要点

1. 宋江打下东平府后，白胜来报：卢俊义攻东昌府连输两阵，守将张清善飞石，副将龚旺使飞枪、丁得孙使飞叉；宋江引兵来援。
2. 两军摆开平川阵势，张清出马，连用石子打中徐宁、燕顺、韩滔、彭玘、宣赞、呼延灼、刘唐等十五员梁山将领。
3. 董平提双枪斗张清；龚旺被林冲、花荣擒，丁得孙被燕青射倒马蹄，张清收了刘唐退回城中。
4. 吴用设计，用粮车和船队诱张清夜出劫粮，公孙胜起黑雾，张清被赶下水，被阮氏兄弟擒获；宋江亲迎，张清归降。
5. 张清举荐兽医皇甫端；梁山泊凑足一百单八人，宋江说要提出一个主意，引出下回。

## 选定场面

东昌府城外平川旷野，白天，阵排一字、旗分五色。张清骑“青骢玉勒马”与金枪手徐宁交马，五合后拨马佯走；徐宁挺钩镰枪
追赶，张清左手提枪，右手伸进锦袋拈出石子，扭回身，对准徐宁面门，石子还捏在手里。具名张清、徐宁，龚旺、丁得孙在门旗
一侧。不涉人被打中。三处依据：

- 「斗不到五合，张清便走。徐宁去赶」
- 「右手便向锦袋中摸出石子，扭回身，觑得徐宁面门较近」
- 「锦袋石子，轻轻飞动似流星」

先后核对：张清出马，龚旺、丁得孙自门旗影里左右闪出，张清手指宋江骂（前）→徐宁出阵，两马相交、双枪并举（前）→五合后
张清便走（前）→徐宁去赶，张清摸石扭身（此刻）→一石子打中眉心，徐宁翻身落马（后）→龚旺、丁得孙来捉，吕方、郭盛救回（后）。
底本此处作“左手虚提长”，疑脱“枪”字；他处写张清“手执长枪”“带住枪杆”，故取长枪。

## 器物与环境

- 地点：东昌府境内平川旷野；“东昌府”是明代的名称（元代称东昌路），北宋为博州（今山东聊城，据摘要），不画真实地标。
- 时令天气：本回未写；承第69回三月末，兜底：晴天，暮春，不强调花草。张清阵“排一字，旗分五色”，三通鼓罢。
- 器物：锦袋与石子（徒手飞石，原文无弹弓；手投石的历史记载不多，据摘要）；张清长枪；徐宁钩镰枪；五色旗，战鼓。
- 现实中会动的：① 张清坐骑的雉尾、朱缨与熟铜铃随跑动摆动；② 五色旗在风中飘；③ 马蹄下扬起尘土。

## 排除项

- 后拍：石子击中徐宁眉心落马；龚旺丁得孙来捉；吕方郭盛救回；燕顺、韩滔、彭玘、宣赞、呼延灼、刘唐、杨志、雷横、朱仝、
  关胜、索超等人被石打或刀口迸火；董平斗张清；夜间劫粮车、石打鲁智深、黑雾、水战。前拍：郝思文被石打额角、项充中叉（均在此前）。
- 不画人被石子击中、流血、受伤；不画宋江阵中其他将领出手。石子此刻不在空中。
- 他回：第69回董平；第71回张清座位与排名。
- 不用弹弓、投石索，不用现代图谱的“宫锦花袍、手中利剑代飞石”和影视的碎花装饰（据摘要）。
