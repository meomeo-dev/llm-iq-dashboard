# 《水浒传》第102回 王庆因奸吃官司　龚端被打师军犯

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第102回>；读取日期：2026-10-20。

## 情节要点

1. 王庆踢板凳闪肭了腰，买膏药，遇卖卦的李助算出“屯卦”；因误了点卯，被府尹以“捏造妖言”
   屈打，押入死囚牢。
2. 蔡京、蔡攸怕丑闻坐实，密嘱府尹改判刺配：去长枷，二十脊杖，刺面颊，配陕州牢城，钉十斤半
   团头铁叶护身枷，差孙琳、贺吉押送；丈人牛大户逼他写下休书。
3. 六月，王庆过嵩山，到北邙山东镇，带枷与使棒汉比棒赢了两贯钱；被龚端、龚正邀至龚家村，
   二人拜他为师。
4. 次日清晨，王庆在打麦场点拨龚端拳腿，外面一个人背着手踱进来，喝骂“配军”（下回黄达）。

## 选定场面

龚家村龚端庄院的打麦场上，清晨。王庆颈上戴着护身枷，立在柳荫下，点拨龚端、龚正“拽拳使腿”，
兄弟二人依样出拳蹬腿；外来的人尚未进场。具名王庆、龚端、龚正。注意：这一刻教的是拳腿，
不是棒——使棒是前一日在邙东镇柏树下比棒。选它是因全回少有的无拷打、无私情的一刻，
“配军戴枷教徒”的反差鲜明，人物只有三人，构图简单。三处依据：

- 「王庆乘着早凉，在打麦场上点拨龚端拽拳使腿」
- 「庄外新蝉噪柳，庄内乳燕啼梁」
- 「一周遭都是土墙，墙处有二三百株大柳树」

先后核对：北邙山东，王庆带枷赢使棒汉两贯钱（前）→ 到龚家村，入草堂，沐浴置酒，龚端兄弟拜师，
“乘凉歇息”（前）→ 次日天明，打麦场点拨拳腿（此刻）→ 外面一个背叉着手的人踱进喝骂（后）。
枷与柳荫据第103回开篇回述：“在打麦场上柳阴下，点拨龚端兄弟，使拳拽腿”，随后王庆“只一枷”
打黄达，说明教拳时枷未去，张管营在陕州才为他除枷。此刻没有黄达，没有人动手。

## 器物与环境

- 地点：西京新安县龚家村，庄院“一周遭都是土墙”，墙边大柳树二三百株，场边有草堂。打麦场据第103回
  在柳荫下；北邙山西起新安（据摘要），与“过嵩山”“望见北邙山”的路线相合。
- 时令天气：王庆离京时“六月初旬”，行十五六日后过嵩山，到此约六月下旬（推算）；清晨，“杲日初升，
  清风徐来”（第103回）；“新蝉噪柳”“乳燕啼梁”；兜底：晴，晨光斜照，薄尘。
- 器物：护身枷；场边麦秸垛、石碌碡与连枷为兜底（宋代麦场农具形制未检得，宋人有打连枷的诗，据摘要）；
  草堂在场边，檐下可有燕子。
- 现实中会动的：① 柳枝随清风摆动；② 龚端、龚正在原地照样出拳、蹬腿，手臂与腿小幅往复；
  ③ 晨光里麦场细尘与麦壳缓缓飘浮（兜底）。王庆身体不位移，枷不脱落。

## 排除项

- 后拍：黄达闯入、王庆以枷打黄达、众人殴打黄达。前拍：邙东镇柏树下的比棒（使棒汉“蟒蛇吞象势”、
  王庆“蜻蜓点水势”）、开封府堂上受杖、李助卜卦、牛大户逼写休书、瞎眼的王砉来送别。
- 本刻教的是拳腿，不画棒与比棒；不画赤膊（原文使棒汉赤着上身，黄达后来被扯光衣服），三人都衣着整齐。
- 不画去枷、不画脊杖伤、不画血；刺字不可辨读；孙琳、贺吉可不入画。
- 不画戏曲武生扮相、影视剧王庆造型；王庆不画成面目凶恶。
