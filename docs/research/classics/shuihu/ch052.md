# 《水浒传》第52回 李逵打死殷天锡　柴进失陷高唐州

底本：<https://zh.wikisource.org/wiki/水滸傳_(120回本)/第052回>；读取日期：2026-10-20。

## 情节要点

1. 朱仝不肯与李逵同山，柴进把李逵留在庄上，朱仝随吴用、雷横上梁山，家眷已先接到；李逵一月后随柴进赴高唐州。
2. 柴皇城被高廉妻舅殷天锡要占花园、推打成病，柴进到时叔叔临终，托他进京告状；柴进说铁券誓书在沧州家里。
3. 第三日殷天锡带二三十个闲汉游玩后醉骑到宅前，限柴进搬走并喝打；李逵在门缝里看见，冲出打死殷天锡（不画）。
4. 高廉当厅拷打柴进，下狱；李逵回山，宋江下山打高唐州，高廉以妖法连败梁山两阵，吴用决定请公孙胜（下回）。

## 选定场面

柴皇城去世第三日，高唐州柴皇城宅前：殷天锡骑马勒住，带着酒意，二三十个闲汉围在马前；柴进一身孝服出来答话，
空着手，说誓书铁券“现在沧州家里，已使人去取来”；李逵被留在宅内，隔着门缝往外看，尚未出手。具名殷天锡、
柴进、李逵。孝服、铁券、闲汉器物，加上门缝里的一只眼，都有原文，且不涉血腥。三处依据：

- 「柴进听得说，挂着一身孝服，慌忙出来答应」
- 「现在沧州家里，已使人去取来」
- 「李逵在门缝里都看见」

先后核对：柴进到宅，留李逵在外面厅房（前）→柴皇城临终，柴进说“誓书在我家里，不曾带得来”，办丧、一门重孝（前）
→第三日殷天锡游玩回，勒住马叫管家出来说话（前）→柴进答话，殷天锡限三日搬走；柴进提铁券，殷天锡喝“你将出来我
看”，柴进答“现在沧州家里”（此刻）→殷天锡大怒喝打（后）→李逵拽开房门，揪他下马打死（后）。故此刻柴进手里没有
铁券，殷天锡仍在马上，李逵仍在门内。

## 器物与环境

- 地点：高唐州柴皇城宅前。宅为“金枝玉叶”之家，门户形制未写；兜底：官宅门屋，双扇板门半掩，门内一间厅房
  （宋制六品以上宅可建乌头门，据摘要，不强用）。高唐州为元至元七年所设，宋时仅高唐县，属河北东路博州（据读取
  页面与摘要），小说移用，不画真实地标。
- 时令天气：季节本回未写；七月十五后一个多月再行路，兜底：初秋，晴；时辰未写，兜底：白天。
- 器物：马（鞍鞯未写）；闲汉所持各器；孝服。铁券此刻不在场，形制备查：铁制弧形瓦状，丹砂或金字填字，君臣各执
  一半（据读取页面与摘要）；原文称“誓书铁券”（第9回）、“丹书铁券”（本回），宋太祖赐柴氏之事为小说家言（据摘要）。
- 现实中会动的：① 马尾与马鬃摆动、马喷鼻刨蹄；② 孝巾与白色衣角被风吹动；③ 门缝里的眼睛眨动、门扇微颤。

## 排除项

- 后拍：殷天锡喝打，李逵拽开房门、揪下马、拳打脚踢致死；柴进被缚、受刑、下狱；高廉妖法；李逵回山与朱仝对阵。
  前拍：柴皇城临终、入殓、灵位、僧人做法事。
- 柴进不手捧铁券或誓书，画面里不出现铁券匣；殷天锡此刻不下马、不挥鞭、不被打；李逵不出门、不持斧、不挥拳。
- 高廉、神兵、宋江、公孙胜不入画；“殷天赐”是别本写法，本书作殷天锡。
- 戏曲：李逵花脸脸谱不入画（殷天锡戏曲造型未检得）。
