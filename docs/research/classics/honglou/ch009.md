# 《红楼梦》第9回 恋风流情友入家塾　起嫌疑顽童闹学堂

底本：<https://zh.wikisource.org/wiki/紅樓夢/第009回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。
页面正标题为庚辰本等回目；程甲本回目为「训劣子李贵承申饬　嗔顽童茗烟闹书房」。

## 情节要点

1. 宝玉择日上学，袭人收拾书笔、嘱咐添衣；宝玉向贾政请安被冷语训斥，李贵被盘问，宝玉在院外候着，
   又去向黛玉辞行，随后与秦钟同到家塾。
2. 家塾设在离荣府一里的地方，由代儒掌管；宝玉秦钟同来同往，同窗中渐起流言。
3. 这日代儒回家，命贾瑞暂管。秦钟与香怜在后院说话被金荣撞见，金荣高声嘲讽，二人告贾瑞反被搪塞；
   金荣与玉爱口角，说出污言（不入画），被贾蔷听见，贾蔷唤来宝玉的书童茗烟，调拨几句。
4. 茗烟闯进学堂找金荣，随后砚瓦、书匣、竹板相继飞出，学堂大乱，李贵等进来喝住，金荣被逼赔礼（不画）。

## 选定场面

家塾学堂里，代儒不在，学童们各在座位上；茗烟一头闯进来，站到金荣座前（站位原文未写，兜底），叫「姓金的，你是什么东西」。
此刻砚瓦未飞、书匣未落，茗烟还没动手。具名茗烟、金荣、宝玉、秦钟，其余学童作群像。选它是因为这是全回
最贴回目「闹学堂」又在动手之前的一刻，学堂的桌案、书匣、笔砚都有明文，不涉血与伤。起因（同窗间的流言）
不画，也不写进题面。依据：

- 「可巧这日代儒有事，早已回家去了」
- 「连秦钟也讪讪的各归坐位去了」
- 「便一头进来找金荣，也不叫金相公了，只说“姓金的，你是什么东西！”」

先后核对：代儒回家，贾瑞暂管；秦钟、香怜告状被搪塞，各归座位；金荣在座上说闲话，与玉爱口角（前）→
贾蔷出去，把茗烟唤到身边调拨（前）→ 茗烟进来叫「姓金的」（此刻）→ 贾蔷跺靴整衣向贾瑞说先走；茗烟一把揪住金荣并
污言辱骂，满屋子弟怔怔痴望（后）→ 金荣气黄了脸要抓打宝玉秦钟，一方砚瓦飞来，贾菌掷书匣，砸碎宝玉的茶碗（后）→
李贵等进来喝住（更后）。此刻：金荣坐在原座，原文未写他起身；宝玉的茶碗尚完好地放在桌上；无人持械。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 茗烟 | 宝玉「第一个得用的」书童，年轻少年。衣冠本回未写；兜底：束发或戴小帽（同回李贵「摘了帽子」可证小厮戴帽），青灰短袍、腰束带，不剃发垂辫；站在金荣座前，怒目，一手叉腰，不挥拳、不揪人 | 第9回 |
| 金荣 | 附学的亲戚子弟，少年，岁数未写；其母说他「爱穿件鲜明衣服」（第10回）。兜底：束发，穿一件颜色鲜亮但不艳的长衫；坐在座位上抬头看向茗烟，神情错愕，尚未发怒 | 第9、10回 |
| 宝玉 | 少年，画十来岁。上学衣冠未写，袭人备了「大毛衣服」；兜底：头发束成小髻，额上勒抹额，素色棉袍，项上挂通灵玉；坐在桌后，桌上有书、笔砚和一碗茶 | 第3、9回 |
| 秦钟 | 少年，与宝玉「一样的年纪」；「较宝玉略瘦些，眉清目秀，粉面朱唇……怯怯羞羞」（第7回），清秀腼腆，不作女性化处理。家境清寒、贾母「助他些衣履」，兜底：素净棉袍；坐在宝玉近旁的桌后，抬头望，头部完好 | 第7、9回 |
| 学童群像 | 同窗少年若干，含暂管的贾瑞（二十来岁，第12回，不具名）；素色袍子，各坐桌后，或抬头或低头 | 第9回 |

## 器物与环境

- 地点：贾家家塾（义学），「离此不甚远，不过一里之遥」，族中出银办学，供贫寒子弟与亲戚附读。
  学堂里有桌案、笔砚、书匣、茶碗、窗（后文茗烟「在窗外」说话）；「四处各坐」与「宝玉秦钟桌案」写法不一，
  兜底：两张相邻桌案，各坐各的；屋不大，座位挨得近（后文「地狭人多」）。
- 时令天气：袭人说「学里冷」，备大毛衣服，当是冷天；贾蔷「看看日影儿」，可知白昼有日光；
  兜底：初冬白昼，窗格透入斜阳，学童着棉袍。
- 器物：一人一桌案，桌上笔砚、书；书匣子（竹木制，明清学童常用，据摘要）；此刻无砚瓦飞出，无竹板、门闩、马鞭。
- 现实中会动的：① 窗格透入的日影在桌面缓缓移动；② 门口带进的风吹动桌上书页与帘角（兜底）；
  ③ 茗烟与学童的衣摆、衣带轻摆。人物不整体位移。

## 排除项

- 后拍：茗烟揪住金荣与对骂、砚瓦飞、贾菌掷书匣、磁水壶与茶碗碎、竹板、门闩、马鞭、群殴、李贵喝止、
  秦钟头被撞破、金荣赔礼磕头。前拍：宝玉辞贾政与黛玉、秦钟与香怜后院、金荣嘲讽与污言、贾蔷调拨。
- 起因（流言及香怜、玉爱、薛蟠相关情节）不画；不画任何兵器与血、伤。
- 贾蔷、香怜、玉爱、贾兰、贾菌、李贵、锄药、扫红、墨雨不入画；塾师代儒不在场。
- 宝玉与秦钟各坐各的，不并肩、不搂靠；不画清宫剧的剃发垂辫与马蹄袖，不画私塾先生与戒尺。
