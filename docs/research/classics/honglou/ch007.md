# 《红楼梦》第7回 送宫花周瑞叹英莲　谈肄业秦钟结宝玉

底本：<https://zh.wikisource.org/wiki/紅樓夢/第007回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。
页面正标题取甲戌本回目；庚辰本回目为「送宫花贾琏戏熙凤　宴宁府宝玉会秦钟」。

## 情节要点

1. 周瑞家的送走刘姥姥，到梨香院回话，听宝钗讲「冷香丸」的来历；薛姨妈取纱堆宫花十二枝，
   嘱她分送：三位姑娘各一对，林姑娘两枝，凤姐四枝。
2. 周瑞家的依次到迎春探春（窗下围棋）、惜春（与水月庵智能儿玩耍）、凤姐院（平儿取走四枝），
   最后到黛玉处；黛玉在宝玉房中同人解九连环，接花后问是否只送她一人，冷笑「别人不挑剩下的也不给我」。
3. 次日凤姐带宝玉到宁府，宝玉初见秦钟，相约同入家塾；夜归时焦大醉骂被捆（污言，不入画）。

## 选定场面

宝玉房中：周瑞家的送花到，宝玉先伸手接过花匣，开匣见是两枝纱堆的花；黛玉就着宝玉手里看了一看，
问是单送她一人，还是别的姑娘都有。具名黛玉、宝玉、周瑞家的，可加一两个丫鬟作群像（原文「大家」）。
选它是因为花、匣、九连环和黛玉的敏感口吻同在一间屋里，室内、无动手，人物关系一眼可认。依据：

- 「黛玉不在自己房中，却在宝玉房中大家解九连环顽呢」
- 「开匣看时，原来是宫制堆纱新巧的假花儿」
- 「还是单送我一人的，还是别的姑娘们都有呢？」

先后核对：周瑞家的在薛姨妈处领花，送迎春探春、惜春、凤姐（平儿取四枝，匣中余两枝）（前）→
穿堂遇女儿，说「给林姑娘送了花儿去就回家」（前）→ 进宝玉房笑说来意；宝玉问「什么花儿？拿来给我」，
伸手接过、开匣；黛玉就宝玉手中看一看，发问（此刻）→ 周瑞家的答「各位都有了，这两枝是姑娘的了」，
黛玉冷笑，周瑞家的一声不言语（后）→ 宝玉问宝钗的病，打发茜雪去问安（更后）。此刻匣在宝玉手里、已打开，
匣中两枝，花未戴上；黛玉未冷笑，周瑞家的未答话。原文未写坐站：兜底，黛玉与宝玉在窗下桌边坐着，
周瑞家的站在二人面前，九连环放在桌上。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 黛玉 | 少女；第2回称「年方五岁」，第3回称「年貌虽小」，岁数前后不一，画十来岁孩童模样，不成人化。眉尖微蹙、眼含泪光（「两弯似蹙非蹙罥烟眉，一双似泣非泣含露目」），身形怯弱而有「自然的风流态度」。衣着本回未写，兜底：素雅浅色袄裙加对襟小褂，不强加颜色；发式未写，兜底：双丫髻或小髻，少首饰 | 第3回；本回 |
| 宝玉 | 少年（第2回称「长了七八岁」，第9回称与秦钟「一样的年纪」，画十来岁）。面若中秋之月，眉如墨画，目若秋波。本回在家，衣冠未写，兜底按第3回家常装：周围短发结小辫、红丝结束、总编一根大辫，辫梢一串四颗大珠；银红撒花半旧大袄；项圈、通灵宝玉、寄名锁可见。不戴紫金冠；双手捧着打开的花匣 | 第3回；本回 |
| 周瑞家的 | 王夫人陪房，中年仆妇。样貌衣冠未写，兜底：发髻挽起，素色袄裙外罩深色背心（明代称比甲），少首饰；含笑立在二人面前，空手（匣已被接去） | 本回 |
| 丫鬟 | 原文「大家」，不具名，至多两个，素色袄裙立在一旁；茜雪后文才被差遣，不指认 | 本回 |

## 器物与环境

- 地点：荣国府贾母院落内宝玉房中（原文「宝玉房中」）。第3回宝玉睡「碧纱橱外的床」、黛玉暂居橱内，
  房内有床，画面不取；兜底：窗下桌边，玻璃窗（本回李纨后窗写作「玻璃窗户」），门口一道软帘。
- 时令天气：第6回「这年秋尽冬初，天气冷将上来」；本回金钏在台阶上「晒日阳儿」，白昼晴；
  室内兜底：衣着微厚，不开窗，不画落雪。
- 器物：薛姨妈取的是「小锦匣」；到黛玉处匣中余两枝，「宫制堆纱」，颜色花样未写，兜底：两枝淡色小花。
  九连环为金属圆环套在横板或框架上、可拆解（明代已有，据摘要），兜底：一具铜环九连环放在桌上。
- 现实中会动的：① 九连环的环被碰后轻晃；② 宝玉手中纱花的花枝微颤（兜底）；③ 宝玉辫梢与丝绦、
  黛玉衣带轻摆（兜底）。人物不整体位移。

## 排除项

- 后拍：周瑞家的答话、黛玉冷笑、宝玉问宝钗病、茜雪去请安。前拍：薛姨妈处取花、冷香丸、迎探惜三处送花、
  凤姐院与平儿；次日宁府初会秦钟；焦大醉骂、被捆、填马粪；「贾琏戏熙凤」（庚辰回目，本回只闻笑声，不画）。
- 在场只有黛玉、宝玉、周瑞家的与至多两名丫鬟；不画宝钗、薛姨妈、凤姐、平儿、惜春、智能儿、香菱、秦钟。
- 花是纱堆假花，不画真花、通草花，不戴在头上；匣中只两枝。房内不画床帐与卧具。
- 黛玉不画成成年美人，不用87版的白蓝粉衣色与「齐眉穗」发式（据摘要），不画清宫剧旗头与花盆底；
  宝玉不画紫金冠、箭袖、抹额（出门装）。
