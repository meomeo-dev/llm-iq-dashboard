# 《红楼梦》第1回 甄士隐梦幻识通灵　贾雨村风尘怀闺秀

底本：<https://zh.wikisource.org/wiki/紅樓夢/第001回>；读取日期：2026-10-20。

## 情节要点

1. 石头缘起：女娲补天遗下一块顽石，弃在大荒山青埂峰下，经一僧一道施幻术变作扇坠大小的美玉；
   空空道人抄录其事，几经易名，曹雪芹增删成《金陵十二钗》。
2. 姑苏阊门外葫芦庙旁，乡宦甄士隐年已半百，只有三岁女儿英莲。炎夏白昼他在书房睡去，梦见一僧一道
   谈绛珠还泪、神瑛下凡，行至“太虚幻境”石牌坊，被霹雳惊醒。
3. 醒后士隐抱英莲到街前看过会，癞头僧与跛足道人走来，僧大哭并说英莲“有命无运”。此后士隐接济
   寄居葫芦庙的穷儒贾雨村，中秋夜书房对饮，赠银五十两，雨村进京应考。
4. 元宵夜英莲被家人霍启丢失；三月十五葫芦庙失火，甄家烧尽。士隐投岳丈封肃，听跛足道人唱《好了歌》
   顿悟，随道人而去。雨村中进士任本府知府，差人传封肃问话。

## 选定场面

士隐抱着三岁的英莲站在自家门前街上，一僧一道自街那边走到门前，癞头僧见了英莲大哭、正向士隐
开口的一刻。具名甄士隐、英莲、僧、道（僧道不具名），可在远处加看过会的街坊作群像。选它是因为
僧道的怪相与粉妆玉琢的女童对照鲜明，场面静止、无人动手，也不与青埂峰神话、梦中幻境拼接。三处依据：

- 「又带至街前，看那过会的热闹。」
- 「那僧则癞头跣脚，那道则跛足蓬头，疯疯癫癫，挥霍谈笑而至。」
- 「看见士隐抱着英莲，那僧便大哭起来」

先后核对：梦中见僧道，被霹雳惊醒，烈日下见奶母抱英莲走来（前，书房内）→士隐接过女儿抱在怀内逗玩
（前）→带至街前，僧道自那边走来（前）→到门前，僧见士隐抱着英莲大哭，说“有命无运”（此刻，街上，
士隐仍抱着女儿）→士隐当疯话不睬，抱女儿转身要进门，僧指着他大笑念四句偈（后）→道人说三劫后北邙山
再会，二人分手（后）→雨村出场（更后）。此刻偈未念，士隐未转身，雨村未出现，奶母不在街上。

## 器物与环境

- 地点：姑苏阊门外十里街仁清巷，士隐宅在葫芦庙隔壁，画面取宅门前街面。兜底：沿街木构房屋，门前台阶，
  一侧露出古庙山门一角；街远处过会队伍的几面彩旗与伞盖，原文只称“过会的热闹”，仪仗未写。
- 时令天气：“炎夏永昼”，“烈日炎炎”；白昼，兜底午后；人物穿夏衣。不画雪、月、元宵灯。
- 现实中会动的：① 过会彩旗与伞盖随风摆动；② 僧道破旧的衣袂与蓬散的头发被风吹动；③ 烈日下街面的
  浮尘与热气（兜底）。士隐与僧道不整体位移。

## 排除项

- 前拍：青埂峰与女娲补天、石头化玉、梦中太虚幻境牌坊与对联、绛珠神瑛；后拍：僧念偈、道人分手、雨村
  窗外见丫鬟、中秋对饮、元宵丢女、葫芦庙大火、《好了歌》。
- 梦中与青埂峰初见时僧道“骨骼不凡，丰神迥异”，本回街前是癞头跣脚的形象，二者不混用；不画拐杖、拂尘、
  法器（原文未写）。
- 英莲不画成大童或少女，不画被拐；男子不画清宫剧的辫发与瓜皮帽，不画官服，不画戏曲髯口。
