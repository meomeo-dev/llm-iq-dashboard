# 《红楼梦》第23回 西厢记妙词通戏语　牡丹亭艳曲警芳心

底本：<https://zh.wikisource.org/wiki/紅樓夢/第023回>；读取日期：2026-10-20。

## 情节要点

1. 元春命宝钗等入园居住，宝玉也随进；贾政传宝玉训诫，问起“袭人”之名，宝玉答出“花气袭人知昼暖”。
   二月二十二日众人搬入园，黛玉住潇湘馆，宝玉住怡红院。
2. 宝玉入园后日日与姊妹丫头相伴，作四时即事诗传出；闷时茗烟买来传奇外传给他看。
3. 三月中浣，宝玉在沁芳闸桥边桃花下读《会真记》，落花满身；黛玉肩担花锄、锄挂花囊、手拿花帚
   来，要把落花扫起埋进花冢；二人同看书，宝玉以书中词句戏语惹黛玉嗔怪，随后赔礼和好。
4. 袭人来唤宝玉去见大老爷；黛玉独行，经梨香院墙外听见《牡丹亭》曲文，心动神摇，落下泪来。

## 选定场面

沁芳闸桥边桃花树下：宝玉站在落花间，手里拿着书，刚把兜起的花瓣抖进池水回来，听见背后有人
问话，回过头；黛玉从身后走来，肩担花锄，锄上挂花囊，手拿花帚。具名宝玉、黛玉两人，无群像。
选它是因“荷锄、花囊、花帚”的黛玉形象是原文明写，落花、桃树、闸桥、池水齐备，是整回里最
鲜明的暮春景象，没有任何冲突。三处依据：

- 「走到沁芳闸桥边桃花底下一块石上坐着，展开《会真记》，从头细玩」
- 「回来只见地下还有许多，宝玉正踟蹰间」
- 「宝玉一回头，却是林黛玉来了，肩上担着花锄，锄上挂着花囊，手内拿着花帚。」

先后核对：宝玉坐石上读《会真记》（前）→读到“落红成阵”，风吹桃花落满身满书满地（前）→他起身，
兜起花瓣走到池边抖入池内，花瓣漂出沁芳闸（前）→回来，见地下还有许多，正踟蹰（此刻）→背后问话，
他回头，黛玉肩担花锄、锄挂花囊、手拿花帚而来（此刻）→黛玉说花冢在畸角，宝玉说“待我放下书”，
慌忙藏书（后）→黛玉放下花具接书同看，二人收拾落花掩埋（后）→袭人来唤（后）。此刻宝玉已离开那块
石头，站在地上；书仍在他手上（后文他说“待我放下书”）；黛玉尚未放下花具，没有看书；花冢在畸角，
不在此处，不画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾宝玉 | 少年，十二三岁（同回“十二三岁的公子”）；本回未写衣冠，兜底：暮春家常袍服，素雅轻薄，色不强加；在园内读书，不戴冠，四围短发编小辫、总编一根大辫，红绦结住，辫上珍珠与金坠脚（第3回写家常，第21回写“在家不戴冠”）；一手持线装书册（明清通行装订，据摘要），封面不画可辨认的字；衣襟肩头沾落花；回头，神情惊讶含笑 | 第23、3、21回 |
| 林黛玉 | 少女，约十二岁（据摘要）；眉眼纤弱，“闲静时如姣花照水，行动处似弱柳扶风”（第3回）；本回未写衣冠，兜底：暮春家常素雅袄裙，色不强加，发挽整齐，不戴帷帽、不披大氅；“肩上担着花锄，锄上挂着花囊，手内拿着花帚”：锄扛肩上，花囊（她自称“绢袋”）挂在锄上，帚在手中；神情平和带问 | 第23、3回 |

## 器物与环境

- 地点：大观园沁芳闸桥边。第17回写这座“大桥”即引泉入园的水闸，“水如晶帘一般奔入”，本回写花瓣
  “流出沁芳闸去了”，水流方向两回说法不一，画水面平缓，不强调方向。桥边一株桃树，树下一块石
  （宝玉刚才坐过），池水，花瓣浮在水面。
- 时令天气：三月中浣，即农历三月十一至二十日（汉典等）；早饭后，上午；暮春，桃花盛极而落
  （桃花花期因地而异）；天气只写“一阵风过”，兜底晴暖，花瓣仍在飘落。
- 器物：书（线装，一册）、花锄（扛肩）、花囊（绢袋，挂锄上，装花在后，此刻按空袋画）、
  花帚（黛玉手中）。
  原文黛玉要把落花“装在这绢袋里”，不是花篮。
- 现实中会动的：① 桃花瓣随风飘落、水面落花缓缓漂移；② 桃枝与黛玉衣带裙角轻摆；③ 锄上花囊随步
  轻晃。

## 排除项

- 后拍：宝玉藏书、说《中庸》《大学》，黛玉放下花具读书，“多愁多病身”“倾国倾城貌”的戏语，黛玉
  嗔恼，宝玉赌咒，二人同埋落花，袭人来唤；黛玉梨香院墙外听《牡丹亭》。前拍：贾政传宝玉、入园、
  茗烟买书。
- 他回：第27回的葬花吟与花冢（本回花冢在畸角，不画）；宝玉不坐在石上，也不画宝玉“放下书”。
- 道具与构图：不画花篮；不画改琦《葬花》式的宽檐帷帽；不画孙温式的黛玉坐山石、白衣大花冢；
  不画清代年画式的衣襟兜花撒向花冢；不用 87 版或新版的剧照构图。
- 造型：不画清宫剧两把头与花盆底；男子不画辫子与顶戴；不用戏曲造型。
