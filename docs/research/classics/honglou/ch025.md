# 《红楼梦》第25回 魇魔法姊弟逢五鬼　红楼梦通灵遇双真

底本：<https://zh.wikisource.org/wiki/紅樓夢/第025回>；读取日期：2026-10-23。

## 情节要点

1. 贾环在王夫人处抄经，嫉恨宝玉与彩霞亲昵，故意推蜡灯烫伤宝玉面颊；黛玉探望关切。
2. 马道婆进府向贾母兜售大海灯香油，又勾结赵姨娘，以五百两欠契换得五鬼纸人与木偶，暗施魇魔法。
3. 宝玉、凤姐中邪发狂，持刀弄杖狂乱，百医无效，至第四日奄奄一息，阖府大乱备办后事。
4. 门外忽闻木鱼声，癞头和尚与跛足道人登门；和尚手擎通灵宝玉持诵除祟，嘱悬挂门槛，二人渐愈。

## 选定场面

王夫人上房外厅堂：贾政惊疑敬立一侧，癞头和尚双手擎通灵宝玉于掌上低头长叹，跛足道人执木鱼侍立其旁。具名癞和尚、跛道人、贾政三人，无群像。选此瞬间因“通灵遇双真”是仙凡交接之枢纽，一僧一道再抚凡玉，超然玄妙，完全避开病榻血光与发狂劈砍。三处依据：

- 「众人举目看时，原来是一个癞头和尚与一个跛足道人。」
- 「贾政听说，便向宝玉项上取下那玉来递与他二人。」
- 「那和尚接了过来，擎在掌上，长叹一声道：青埂峰一别，展眼已过十三载矣！」

先后核对：宝玉凤姐中邪濒危、合家备后事（前）→堂外隐闻木鱼声念偈、贾政请僧道入堂询问（前）→贾政取玉递与和尚（前）→和尚擎玉于掌长叹摩弄、道人持木鱼侍立、贾政屏息敬立（此刻）→僧道交代悬玉门槛之法后飘然而去（后）→悬玉上槛二人晚间渐醒（后）。此刻二人未入卧房，病榻与棺木皆在别处不入画。

## 器物与环境

- 地点：荣国府王夫人正院上房外堂。青砖铺地，雕花隔扇门窗，设条案、木椅，内室垂素帘。
- 时辰天气：第四日清晨；晨光穿过明窗，尘息未扬。
- 节令：农历四月下旬，初夏之交，庭前嘉木葱茏。
- 器物：通灵宝玉（如雀卵大小，润泽如脂，系五色丝绦）、小木鱼（道人手持）。
- 现实中会动的：① 掌心宝玉温润宝光微弱明灭流转；② 僧道破旧衣角随堂风轻拂；③ 门帘下垂轻摆。

## 排除项

- 前拍：贾环推灯泼油烫伤、赵姨娘马道婆床底塞纸鬼、凤姐持钢刀杀鸡砍狗、贾母啐骂赵姨娘、抬出棺木。
- 后拍：僧道交还玉佩、迈步出户瞬间无踪、将玉悬于门槛、二人醒来进米汤、宝钗取笑黛玉。
- 道具与构图：不画内室病榻病容、不画符水与血迹棺木；不画清代红顶花翎剃发辫子；不画戏曲脸谱。
