# 《红楼梦》第113回 忏宿冤凤姐托村妇　释旧憾宝玉探巧姐

底本：<https://zh.wikisource.org/wiki/紅樓夢/第113回>；读取日期：2026-10-23。

## 情节要点

1. 刘姥姥得知贾母仙逝三进荣国府吊唁，闻知凤姐病危，特至卧榻前探视问疾。
2. 凤姐神思恍惚、深悔平生强梁积下宿冤，见刘姥姥朴实厚道，于病榻前拉住其双手痛哭流涕，郑重将巧姐托孤相付。
3. 刘姥姥感念昔日周济大恩，热泪盈眶慨然应诺，誓言纵使吃糠咽菜亦定护全巧姐，彰显民间质朴仁义。
4. 宝玉探望凤姐与巧姐，目睹昔日威风八面的当家奶奶今日病骨支离托孤村妇，深感世事无常因果昭然，为真挚乡情深为触动。

## 选定场面

荣国府王熙凤正房卧榻前：仲春晴日，窗棂透入一抹温暖薄阳，映照简素的病榻。王熙凤面色枯黄如金纸，身穿月白细绫中衣、
肩披褪色秋香短夹袄，病骨支离倚在软枕之上，双手死死拉住刘姥姥布满厚茧的双手，眼中涕泪横流挣扎欲拜，将爱女巧姐一生托付；
刘姥姥头扎深蓝粗布头巾，穿赭黄土布棉袄、青布棉裙，两眼噙着滚烫热泪，紧紧回握凤姐枯瘦双手，连声应承“阿弥陀佛”慨然许诺相护；
巧姐年约十岁，身穿淡水红窄袖短袄、牙白绫裙，含泪依偎在母亲榻侧，神色怯弱依恋；平儿在床侧手托青瓷药盏轻声拭泪；
外间槅扇珠帘旁，贾宝玉着素色交领长衫静默侍立探望，神情悲悯而肃穆。具名王熙凤、刘姥姥、巧姐、平儿、贾宝玉五人。
选此景因“凤姐托村妇”为全书最催人泪下的人性光辉绝唱；机关算尽之末路豪门与淳朴乡妪的“留余庆”善缘在此交汇，慈悲动人；
严禁凄厉厉鬼索命，定格病榻托孤、质朴应诺之至真至情瞬间。三处依据：

- 「巧姐兒便走到跟前，劉姥姥忙著拉著道：‘阿彌陀佛，不要折殺我了！巧姑娘，我一年多不來，你還認得我麼？’」
- 「鳳姐道：‘這孩子乾脆託付給你罷……我如今把這孩子託你，也就是託我的靈魂一樣。你若是肯擔待他，我死了也瞑目。’」
- 「劉姥姥趕忙攙住……‘既是姑奶奶這樣信著我，我就帶了他去。只是到了我們那裡，休嫌粗糙就是了。’」

先后核对：刘姥姥三进荣府吊唁贾母（前）→引至凤姐榻前探视问疾（前）→凤姐涕泣忏悔宿怨，拉手郑重托孤巧姐，刘姥姥热泪慨允（此刻）→
平儿取衣物纹银赠予姥姥作为路费盘缠（后）→宝玉探视紫鹃释怀旧恨感悟无常（后）。此刻双手紧握，眼波含泪，因果善缘，真情动地。

## 器物与环境

- 地点：荣国府王熙凤正房内室病榻前。陈设黄花梨架子床、青素棉帐、紫檀小圆桌、青瓷药盏、素铜手炉、粗布包袱。
- 时令天气：仲春晴日午后；斜阳淡照纸窗，室内陈设简素泛出萧索冷清。
- 器物：青瓷汤药盏、粗布蓝印花包袱、银两荷包、旧棉被褥、素银扁簪。
- 现实中会动的：① 紫檀桌上刚熬好的药盏表面升起淡淡的一缕白色热气；② 窗棂斜射入屋内的微尘光束随空气轻缓游移漂浮；③ 刘姥姥握紧凤姐颤抖枯手时两袖粗布与缎面相接轻颤。

## 排除项

- 前后拍：严禁出现王仁邢舅等狠舅奸兄密谋典卖巧姐之卑鄙丑恶嘴脸；不得出现凤姐弥留之际厉鬼锁链索命之恐怖幻象；不得出现抢掠财物。
- 他回他场：不得出现第6回刘姥姥一进荣国府之局促窘相；不得出现第40回宴饮醉卧大观园之戏谑滑稽；严禁将刘姥姥画成肮脏邋遢乞丐。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；刘姥姥虽为农妇，衣着须整洁古朴、透出乡土厚重与尊严；凤姐须保留大家主母之骨相气度。
