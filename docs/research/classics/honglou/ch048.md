# 《红楼梦》第48回 滥情人情误思游艺　慕雅女雅集苦吟诗

底本：<https://zh.wikisource.org/wiki/紅樓夢/第048回>；读取日期：2026-10-23。

## 情节要点

1. 薛蟠养伤躲羞，趁铺面老伙计张德辉南下贩纸札香扇之机，发狠随行出门学做买卖、游历山水。
2. 薛姨妈与宝钗权衡利弊后允准，薛蟠辞别亲友启程远行，薛姨妈将香菱送入大观园蘅芜苑与宝钗作伴。
3. 香菱进园遂了心愿，晚饭后至潇湘馆拜林黛玉为师学诗，黛玉详述立意至上、不以词害意之要诀。
4. 黛玉命紫鹃取出朱圈王维五言律诗集授与香菱，香菱如获至宝，回蘅芜苑挑灯苦诵、通宵达旦。
5. 香菱学诗入迷成痴，向黛玉谈“大漠孤烟直”三昧，随后在池边山石苦思冥想，梦中终成咏月绝句。

## 选定场面

潇湘馆内室书斋窗下：黛玉安坐窗前紫檀书案后，一手扶朱笔笑语指点，细说律诗“立意为先”之法；香菱恭立案旁，
双手欣喜接过案头墨色朱圈的《王摩诘全集》，眉心一点红痣若隐若现，专注倾听；紫鹃侍立在侧。具名林黛玉、
香菱两人（兼紫鹃），无群像。选此场面因“香菱学诗”是红楼梦最具文化诗性与心灵纯粹的经典篇章，
名门闺秀与薄命侍妾以诗相契，窗外修竹萧疏、案头墨卷书香，全无俗世机巧争斗。三处依据：

- 「黛玉笑道：‘既要作诗，你就拜我作师。我虽不通，大略也还教得起你。’」
- 「黛玉道：‘词句究竟还是末事，第一立意要紧。若意趣真了，连词句不用修饰，自是好的，这叫做“不以词害意”。’」
- 「黛玉听说，便命紫鹃将王右丞的五言律拿来，递与香菱，又道：‘你只看有红圈的都是我选的，有一首念一首。’」

先后核对：薛蟠出京，香菱随宝钗搬入大观园蘅芜苑（前）→香菱各处请安后晚饭毕，急奔潇湘馆拜师（前）
→黛玉论起承转合与立意，命紫鹃取《王摩诘全集》递授香菱，指点朱圈（此刻）→香菱捧书回蘅芜苑挑灯
通宵读诗（后）→次日再来换杜甫律诗，谈大漠孤烟三昧（后）→黛玉命以十四寒咏月，香菱池边抠土成痴（后）
→梦中成诗（后）。此刻黛玉正倾囊相授，香菱满怀喜悦接书，尚未回屋通宵苦诵，亦未陷入疯魔抠土。

## 器物与环境

- 地点：大观园潇湘馆有凤来仪内室书房。临窗紫檀雕花大平头案，陈设端砚笔架、铜水丞、朱笔与一摞线装古籍；窗外千竿翠竹掩映，竹影映入素色窗纸。
- 时令天气：农历十月中旬孟冬初寒；黄昏入夜初点灯火，室内烛光和润清朗，空气幽静宁谧。
- 器物：线装本《王摩诘全集》（封面墨签，开页可见朱砂小红圈批点）、铜烛台灯火、竹帘。
- 现实中会动的：① 窗外修竹在初冬夜风中枝叶微拂、窗纱竹影轻移；② 案头烛火光焰随开卷轻微跳动；③ 香菱接书时线装书页在微风中轻微翻折。

## 排除项

- 前后拍：薛蟠打点行装、雇骡马辞别薛姨妈宝钗出京；香菱回蘅芜苑通宵苦读不肯入睡；次日谈“大漠孤烟直”三昧；池边山石上抠土出神、含笑皱眉；探春宝玉李纨隔窗笑唤；梦中得句。
- 他回他场：不得出现夏金桂虐待香菱之惨境；不可出现薛宝钗或薛蟠在场；不可画现代排版书籍或钢笔纸笔；不得混入第37回结海棠社的群像。
- 造型禁忌：严禁满清旗装两把头与花盆鞋；严禁男子剃头留辫；香菱衣饰不可奢华艳丽，保持淡雅侍妾兼书卷灵秀之气。
