# 《红楼梦》第24回 醉金刚轻财尚义侠　痴女儿遗帕惹相思

底本：<https://zh.wikisource.org/wiki/紅樓夢/第024回>；读取日期：2026-10-20。

## 情节要点

1. 黛玉听曲后被香菱唤回；宝玉被袭人找回，往大老爷处请安，路遇贾琏与贾芸，戏称贾芸“倒象我的
   儿子”，贾芸顺势说愿认作父亲。
2. 贾芸求差事不成，去母舅卜世仁的香料铺赊冰片麝香，被冷拒；回家路上一头撞上醉汉倪二，倪二
   认出是邻居，无息无约借给他十五两三钱银子。
3. 贾芸买冰麝送给凤姐，凤姐许他种树的差事，领银二百两；他还了倪二，又去买树。
4. 宝玉房里的小红趁无人给宝玉倒茶，被秋纹、碧痕数落；听说贾芸要来监工，心中一动；贾芸在窗外
   说拾到她的手帕，小红急退，被门槛绊倒。

## 选定场面

街上：贾芸垂头走路，一头撞在醉汉身上，被对方一把抓住，抡拳要打，听见喊“住手”，倪二睁开
醉眼认出是邻居贾芸，忙把手松开，趔趄着笑。具名倪二、贾芸两人，无群像。选它是因回目“醉金刚轻财
尚义侠”的转折正在此刻，凶相变笑脸，落魄清秀的青年与醉汉的对比一眼可辨，没有殴打与血。
三处依据：

- 「早被那醉汉一把抓住，对面一看，不是别人，却是紧邻倪二。」
- 「倪二听见是熟人的语音，将醉眼睁开看时，见是贾芸，忙把手松了，趔趄着笑道」
- 「原来这倪二是个泼皮，专放重利债，在赌博场吃闲钱，专管打降吃酒。」

先后核对：贾芸在舅舅卜世仁家被拒，赌气出门，低头想事（前）→一头撞在醉汉身上，被骂“瞎了眼睛”
（前）→醉汉一把抓住，对面一看是倪二，倪二抡拳要打（前，不画）→贾芸叫“老二住手！是我冲撞了你”（前）
→倪二睁醉眼认出，松手，趔趄着笑说“我该死”（此刻）→贾芸诉苦，倪二从搭包里掏银借钱（后）→倪二
说“天气黑了”，趔趄着走去（后）。此刻倪二不再举拳，抓住贾芸的手已松开，搭包里的银子没有掏出，二人
没有谈钱。

## 器物与环境

- 地点：贾芸“一径回归旧路”，倪二是他“紧邻”，原文说“三街六巷”，街名未写；兜底：回家路上的
  街巷，青砖或夯土路面，两侧低矮砖墙与旧门面。
- 时辰：倪二说“天气黑了”，贾芸到家时“已是掌灯时候”，兜底：黄昏，天色将暗，远处零星灯火，不画深夜。
- 季节：承第23回三月中浣，凤姐“正是要办端阳的节礼”，故为春末；兜底：
  树叶新绿，不强加某种花，不画雪与落叶。
- 器物：倪二腰间搭包；二人手空，不画银两、秤、文约。
- 现实中会动的：① 倪二醉态的左右趔趄（往复）；② 衣襟与搭包带随晃动轻摆；③ 远处灯火的闪烁
  （兜底）。贾芸站定，不整体位移。

## 排除项

- 后拍：倪二掏出银卷、借钱、不写文约、说“天气黑了”离去、贾芸称银；前拍：卜世仁拒赊并讥讽、
  倪二抡拳（不画举拳与殴打）。
- 他场：宝玉与鸳鸯、贾芸遇宝玉与贾琏、贾芸送冰麝给凤姐、小红倒茶、宝玉换衣洗澡、小红手帕与绊倒。
- 造型：倪二不画成凶神、打手或戏曲丑角；贾芸不画奸猾相；男子不画清宫剧的前额剃发长辫与顶戴
  （兜底用巾帽束发）；不画清宫剧两把头与花盆底。
