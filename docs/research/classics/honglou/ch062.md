# 《红楼梦》第62回 憨湘云醉眠芍药裀　呆香菱情解石榴裙

底本：<https://zh.wikisource.org/wiki/紅樓夢/第062回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉、宝琴、岫烟、平儿四人同日做寿，大观园红香圃大开寿席，薛姨妈、李纨、尤氏、探春等群芳齐聚。
2. 众人射覆行令、行酒作乐，史湘云生性豁达豪爽，猜拳斗酒连饮数杯，不胜酒力离席独自寻僻静处纳凉。
3. 丫头引众人至山石僻处，见湘云醉卧青石板凳沉酣入梦，芍药花飞满一身，鲛帕包花作枕，引蜂蝶闹绕。
4. 众人推唤湘云醒转，湘云犹呓语酒令，随后服醒酒石与酸汤解酲；宝玉、探春等相顾莞尔。
5. 香菱与众丫鬟在草地斗草嬉戏，不慎滚落泥水弄脏新石榴裙，宝玉以袭人同款新裙悄悄换下解围。

## 选定场面

红香圃假山石僻处芍药丛中：史湘云衣冠整肃侧卧于青板石凳上，香梦沉酣；四面粉红与胭脂芍药花瓣落满一身，
散落头脸衣襟；身下一袭落英红茵，头枕鲛帕包成的芍药花枕；右手垂落，白绢团扇半埋于落花泥土；几只蜂蝶
在身畔轻盈飞舞盘旋；假山石畔探春、黛玉、宝玉等相携探视，掩口含笑。具名史湘云（群像林黛玉、贾宝玉）。
选此场面因“湘云醉眠”为红楼第一纯美诗意名场面，神态娇憨超逸、天人合一，毫无凡俗滞碍。三处依据：

- 「果见湘云卧于山石僻处一个石凳子上，业经香梦沉酣，四面芍药花飞了一身」
- 「满头脸衣襟上皆是红香散乱，手中的扇子在地下，也半被落花埋了，一群蜂蝶闹穰穰的围着他」
- 「又用鲛帕包了一包芍药花瓣枕着。众人看了，又是爱，又是笑，忙上来推唤挽扶。」

先后核对：红香圃行酒令射覆划拳（前）→湘云多罚两杯离席纳凉（前）→湘云卧石凳沉睡，落花飞满衣襟，
蜂蝶盘旋，众人寻至含笑相看（此刻）→众人上前推唤挽扶，湘云犹呓语酒令（后）→同至红香圃口衔醒酒石喝酸汤
（后）→香菱斗草污裙（后）。此刻湘云尚未被推醒，娇憨安详，意境超然完备。

## 器物与环境

- 地点：大观园红香圃三间敞厅后假山僻处。古雅嶙峋青太湖石，石后横置平整青石板凳，周遭红白芍药盛开。
- 时令天气：农历四月下旬暮春初夏正午午后；天光晴和，微风阵阵，花香浮动。
- 器物：青石板凳、白绢团扇（落花半掩）、鲛绡素帕（鼓鼓囊囊包满红芍药花瓣垫于脑后）。
- 现实中会动的：① 春末微风中芍药花瓣从枝头打旋飘落；② 数只彩蝶与蜜蜂在湘云身周轻舞盘旋；③ 假山石隙芍药细枝叶片微拂。

## 排除项

- 前后拍：红香圃猜拳行酒令之喧闹；众姐妹上前推唤摇晃湘云；湘云醒来喝酸汤、含醒酒石；香菱伏泥弄污石榴裙。
- 造型禁忌：严禁衣衫不整、酥胸半露或风尘轻浮之态；严禁西式裸露睡姿；严禁满清两把头与旗装；严禁剃发留辫；禁用87版特异戏服。
