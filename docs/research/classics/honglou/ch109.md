# 《红楼梦》第109回 候芳魂五更承警策　访妙玉半夜走栊翠

底本：<https://zh.wikisource.org/wiki/紅樓夢/第109回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉因痛悼黛玉神魂颠倒，夜间在怡红院设供设案祈求梦魂相遇，痴心“候芳魂”而不可得。
2. 麝月与五儿值夜，宝玉见五儿形容酷似晴雯，神思迷惘之际移情垂询，醒悟后更添人生幻灭之悲。
3. 迎春在夫家孙绍祖处横遭凌虐毒打，归府向贾母哭诉泣别，贾母虽深怜孙女却衰朽无力回天。
4. 宝玉五更深夜难眠，踏雪漫步至栊翠庵叩访妙玉；古松积雪映衬红梅，素衣妙玉焚香对坐，以出世清言警策开导。

## 选定场面

大观园栊翠庵客堂禅室：隆冬严寒深夜，阶前残雪凝晶，寒月映照古松偃蹇与凌寒初放的红梅。妙玉头梳素净妙常髻，身穿月白素绸袄、
外罩水田青缎镶边长背心，系秋香色丝绦与淡墨白绫裙，手执麈尾念珠，端坐于青石蒲团之上；紫檀小几上宣德铜炉香烟如缕、紫砂吊壶微沸；
贾宝玉身穿石青缎交领夹袍、外罩银灰白狐皮短坎肩，双手合十对坐倾听，面上褪去轻浮痴迷而现肃穆敬畏之容，于万籁俱寂中承领禅锋开示。
具名妙玉、贾宝玉二人。选此景因宝玉失黛玉后大悲迷失，栊翠庵半夜访道受妙玉当头棒喝与警策，为全书空门悟道的重要精神阶梯；
雪夜古松红梅对素衣清茶，境界高洁脱俗。三处依据：

- 「只見妙玉頭帶妙常髻，身上穿一件月白素綢襖兒，外罩一件水田青緞鑲邊長背心……手執麈尾念珠。」
- 「寶玉推門進來，只見妙玉坐在蒲團上，爐中香煙裊裊，窗外古松積雪，紅梅映雪，極是幽靜。」
- 「妙玉道：‘此時萬籟俱寂，正是參悟之時，何必苦苦戀著塵緣？’」

先后核对：怡红院更深设供候黛玉芳魂无着（前）→误认五儿触痛忆晴雯（前）→夜深披衣踏雪扣栊翠庵门，妙玉素衣焚香对坐以禅机警策（此刻）→
宝玉拜别还院默思红尘因果（后）→次日迎春归省哭诉（后）。此刻松雪映窗，沉香一线，对坐参玄，孤明独照。

## 器物与环境

- 地点：大观园栊翠庵客堂静室。设青石蒲团、紫檀条案、素白纸窗、宣德三足铜香炉、白玉胆瓶插红梅、紫砂茶具。
- 时令天气：农历十一月隆冬五更深夜；严风初定，积雪未销，残月清辉冷照。
- 器物：水田青缎长背心、麈尾念珠、宣德古铜香炉、紫檀矮几、红梅积雪枯枝。
- 现实中会动的：① 宣德铜炉中一缕笔直白香烟在清冷空气中微颤升腾；② 窗外古松针叶积雪承受不住微震抖落数片雪沫；③ 案上青花烛台豆大火苗在穿堂微风中轻微摇曳。

## 排除项

- 前后拍：严禁出现宝玉在怡红院卧榻拉扯五儿之床帏狎昵暧昧；不得出现迎春被孙绍祖毒打伤痕之凄惨哭嚎；不得出现大殓哭丧。
- 他回他场：不得出现第41回栊翠庵品梅花雪茶盛筵；不得出现第87回走火入魔听琴乱心；严禁出现幻境妖仙精怪。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；妙玉为带发修行名门千金，严禁剃光头着破僧袍，须严格依带发道冠素雅形制。
