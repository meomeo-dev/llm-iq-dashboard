# 《红楼梦》第95回 因讹成实元妃薨逝　以假混真宝玉疯颠

底本：<https://zh.wikisource.org/wiki/紅樓夢/第095回>；读取日期：2026-10-23。

## 情节要点

1. 岫烟携妙玉仙乩“青埂峰下倚古松”回怡红院，袭人四处搜寻无迹；黛玉闻金玉断裂暗自宽慰，私心稍安。
2. 凤藻宫元春痰疾暴作溘然薨逝，追谥“贤淑贵妃”，荣宁二府进宫哭临；贾府痛失皇室靠山，家势骤危。
3. 宝玉失通灵玉日见怔忡痴呆；贾政贾母贴出告示悬银万两寻玉，市井之徒照告示伪造昏暗假玉登门冒领。
4. 贾琏携假玉入呈，贾母戴老花镜与凤姐王夫人细细摩挲辨认，宝玉接玉冷笑掷地；贾母仁厚赐银遣去。

## 选定场面

荣国府贾母正房东暖阁：腊月隆冬正午，室内炉炭微红。贾母身着古铜织锦盘领灰鼠袄端坐暖榻之上，鼻梁上架着精巧玳瑁圆框
老花眼镜，手捧红绫垫底木匣，细细摩挲审视一块色泽昏暗发毛的伪造通灵宝玉；王熙凤着秋香色洋缎皮袄伏在紫檀案旁，伸出
纤指点玉神情机敏狐疑；王夫人面带重忧合掌侧立凝视；里间珠帘半卷处，宝玉着月白素绫袍斜倚软榻，神思若失、面容清癯，
对案前辨玉喧扰报以凄清冷笑。具名贾母、王熙凤、贾宝玉、王夫人四人。选此景因“以假混真”为本回文眼，老太君戴镜辨玉
充满末世世家面对虚妄执念的荒诞反讽；宝玉失玉而显出勘破虚妄的超脱冷笑，与全家执迷假玉构成鲜明对比，雅致深刻，且严避
丧乱丑态。三处依据：

- 「賈母打開看時，只見那玉比先前昏暗了好些。一面擦摸，鴛鴦拿上眼鏡兒來，戴著一瞧」
- 「鳳姐看了道：‘象倒象，只是顏色不大對。不如叫寶兄弟自己一看就知道了。’」
- 「寶玉睡眼朦朧，接在手裡也沒瞧，便往地上一撂道：‘你們又來哄我了。’說著只是冷笑。」

先后核对：妙玉扶乩录仙谶（前）→元妃薨逝合府哭临（前）→悬万两赏格引来投机假玉（前）→贾琏携假玉入室呈献，贾母戴镜
细辨，凤姐王夫人疑窦丛生，宝玉冷笑掷地揭破假象（此刻）→贾母吩咐还玉赏银（后）→贾琏书房斥退奸民（后）。此刻贾母
刚戴镜摩挲假玉，凤姐出语质疑，宝玉冷笑视之，满室屏息。

## 器物与环境

- 地点：荣国府贾母正房东暖阁。设紫檀平头大案、黄花梨暖榻、水晶珠帘、紫铜红炭火盆，光影暗淡温穆。
- 时令天气：农历十二月隆冬晌午；冬风吹撼窗棂，薄日斜穿窗纸，室内微带肃杀清冷。
- 器物：仿制假通灵宝玉（质地昏暗）、红绫衬垫雕漆木匣、玳瑁圆框老花眼镜与眼镜盒、万两赏格招帖。
- 现实中会动的：① 暖阁槅扇悬挂的水晶珠帘在穿堂微风中轻微晃动折光；② 紫铜火盆中暗红炭火表面泛起缕缕微弱热浪；③ 托玉匣内红绫缎角受案前动静微颤。

## 排除项

- 前后拍：凤藻宫元妃病榻溘逝；合府女眷进宫穿素缟长跪哭临；门房市井小人叫嚣索银；贾琏书房大声斥骂骗徒。
- 他回他场：不得出现宝玉砸玉疯狂丑态；不得出现贾府抄家查封；严禁出现元妃尸椁灵柩等丧葬压抑细节。
- 造型禁忌：严禁清代顶戴长辫与两把头大拉翅；老花眼镜须按明代传世玳瑁折叠镜式样绘制；宝玉神态须为凄清超然，严禁狂躁癫痫态。
