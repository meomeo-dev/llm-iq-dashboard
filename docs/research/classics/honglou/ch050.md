# 《红楼梦》第50回 芦雪广争联即景诗　暖香坞创制春灯谜

底本：<https://zh.wikisource.org/wiki/紅樓夢/第050回>；读取日期：2026-10-23。

## 情节要点

1. 众人在芦雪庵按阄联句，凤姐起首“一夜北风紧”，李纨、香菱、探春、黛玉、湘云、宝琴等各展才情，湘云宝琴联句最多。
2. 宝玉联句落第，李纨罚他冒雪往栊翠庵向妙玉乞红梅；湘云、黛玉敬热酒壮行。
3. 宝玉笑捧二尺余高胭脂红梅折枝归来插瓶，岫烟、李纹、宝琴分赋“红梅花”三字七律，宝玉赋《访妙玉乞红梅》。
4. 贾母乘小竹轿冒雪来芦雪庵凑趣，吃糟鹌鹑，随后众人出夹道东门前往暖香坞看惜春作画。
5. 雪后山坡上，宝琴披凫靥裘遥等，身后丫鬟抱一瓶红梅，宛若仇十洲《双艳图》；宝玉披大红猩毡从坡后转出，妙玉赠众人红梅各一枝。

## 选定场面

大观园雪晴山坡（出夹道东门往暖香坞途中）：雪后初晴，天地粉妆银砌；薛宝琴披金翠辉煌的凫靥裘站在白雪皑皑的山坡上遥等，身后小丫鬟怀抱一美女耸肩瓷瓶，瓶中斜插一蓬胭脂般的艳丽红梅；贾宝玉身披大红猩猩毡斗篷，手折栊翠庵红梅花枝从山坡后踏雪转出相迎。具名薛宝琴、贾宝玉两人及抱梅小丫鬟。选此场面因“宝琴立雪、踏雪寻梅”乃全书最具色彩张力与诗画神韵的极致美景，白雪、红梅、金翠凫靥裘、猩红大毡交织，如仇十洲名画入凡，全无尘俗机巧。三处依据：

- 「忽见宝琴披着凫靥裘站在山坡上遥等，身后一个丫鬟抱着一瓶红梅。」
- 「贾母喜的忙笑道：‘你们瞧，这山坡上配上他的这个人品，又是这件衣裳，后头又是这梅花，象个什么？’」
- 「只见宝琴背后转出一个披大红猩毡的人来……那是宝玉。」

先后核对：芦雪庵即景联句，宝玉落第（前）→宝玉往栊翠庵乞得一枝红梅插瓶，众赋红梅诗（前）→贾母坐竹轿来芦雪庵吃糟鹌鹑（前）→凤姐唤轿，众人出夹道东门往暖香坞看惜春作画（前）→雪坡之上，宝琴披凫靥裘俏立，丫鬟抱梅瓶，宝玉披大红猩毡从坡后转出，众人赞叹如仇十洲《双艳图》（此刻）→宝玉说妙玉赠每人一枝梅花，已命人送去（后）→众人进暖香坞揭帘看画、制春灯谜（后）。此刻二人正立于雪后山坡，红梅映雪，金翠与大红交辉，尚未入暖香坞揭帘看画。

| 小丫鬟 | 侍女，约十二三岁；着淡青或月白缎棉袄，素雅齐整；双手稳稳怀抱一只白瓷或天青釉美女耸肩梅瓶，瓶中斜插一蓬胭脂红梅，乖巧立于宝琴身后 | 第50回 |

## 器物与环境

- 地点：大观园雪坡山岗（出夹道东门、通往暖香坞的山石道旁，高坡积雪掩映，远景大观园粉妆银砌）。
- 时令天气：冬日大雪初霁，晴光映照琉璃世界，天地皑皑一白，寒气清冽澄明。
- 器物：美女耸肩瓷瓶（梅瓶小口丰肩）、盛开胭脂红梅花枝（横斜老干与红艳骨朵）、宝玉手中折枝红梅。
- 现实中会动的：① 宝琴与宝玉斗篷下摆在冬日山风中微微拂动；② 树梢与山石上积雪偶有细粉被微风吹散如雾；③ 胆瓶与宝玉手中横斜红梅枝在冷风中轻颤摇曳。

## 排除项

- 前后拍：芦雪庵割腥啖膻；众女子联句争写“一夜北风紧”；贾母坐小竹轿撑油伞；暖香坞看惜春作画与画具纸砚；制春灯谜。
- 他回他场：不可混入第49回烤鹿肉炉火；不可混入第23回暮春落花；严禁画成室内场景。
- 造型禁忌：严禁满清金钱鼠尾辫、马褂与旗妇两把头；严禁戏曲戏装与现代冬装羽绒服；宝琴斗篷不可画成普通红斗篷（必须是金翠辉煌野鸭羽）。
