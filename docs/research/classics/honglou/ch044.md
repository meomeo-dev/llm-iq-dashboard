# 《红楼梦》第44回 变生不测凤姐泼醋　喜出望外平儿理妆

底本：<https://zh.wikisource.org/wiki/紅樓夢/第044回>；读取日期：2026-10-23。

## 情节要点

1. 王熙凤生日宴上多饮了几杯酒，回房歇息时撞破贾琏与鲍二家的偷情私语，泼醋大闹。
2. 凤姐与贾琏迁怒撕打平儿，平儿含冤受屈欲寻短见，被尤氏李纨等人救下并劝入园中。
3. 贾琏仗酒持剑闹至贾母处，贾母斥责贾琏并抚慰凤姐与平儿。
4. 平儿在怡红院洗面理妆，袭人赠衣换服，宝玉殷勤传授紫茉莉花粉与玫瑰花露胭脂，并剪并蒂秋蕙为平儿簪鬓。
5. 次日贾母主持，贾琏与凤姐当众向平儿赔礼道歉，三人和解归房；旋闻鲍二家的上吊自缢。

## 选定场面

怡红院内室妆台前：平儿坐在雕花妆台前对镜理妆，宝玉立在妆台一侧，手揭宣窑瓷盒拈出玉簪花粉棒笑递给平儿，
细说用法；袭人在一旁含笑相顾。具名平儿、宝玉、袭人三人，无群像。选此场面因“平儿理妆”是全回乃至全书
极具生活美学与温情体贴的经典时刻，以脂粉花草之美拂去内宅风波之浊，无撕打刀剑与暴力争闹。三处依据：

- 「宝玉忙走至妆台前，将一个宣窑瓷盒揭开，里面盛着一排十根玉簪花棒，拈了一根递与平儿。」
- 「只用细簪子挑一点儿抹在手心里，用一点水化开抹在唇上，手心里就够打颊腮了。」
- 「宝玉又将盆内的一枝并蒂秋蕙用竹剪刀撷了下来，与他簪在鬓上。」

先后核对：贾琏鲍二家的事发、凤姐撒泼、平儿无辜挨打（前，不画）→贾琏拔剑追闹贾母处（前）→李纨袭人
拉平儿入怡红院，袭人开箱取旧衣给平儿换上（前）→平儿洗面，宝玉妆台前揭瓷盒递紫茉莉玉簪粉棒、指点
玫瑰胭脂（此刻）→宝玉执竹剪刀剪盆中并蒂秋蕙簪于平儿鬓上（此刻/后）→李纨使人唤平儿（后）→次日
贾琏凤姐向平儿赔礼（后）。此刻平儿正对镜匀面，宝玉手拈粉棒递授，袭人侍立在侧，气氛安详融洽。

## 器物与环境

- 地点：大观园怡红院内室。临窗设红木雕花妆台，台上立铜镜，陈设宣窑瓷粉盒（内盛十根玉簪花棒）、小巧白玉胭脂盒（盛玫瑰膏子）、小铜盆与净水盂；几案上供有一盆盛开的秋蕙。
- 时令天气：农历九月初二，深秋午后；秋阳透过茜纱窗棂柔和照入，室内温暖雅致。
- 器物：宣窑瓷盒、玉簪花粉棒（紫茉莉花种制）、白玉胭脂盒、小巧细簪、竹剪刀、盆栽并蒂秋蕙。
- 现实中会动的：① 平儿手持粉棒在掌心轻轻研抹匀粉；② 窗边盆栽并蒂秋蕙的兰叶与花茎随微风轻颤；③ 窗纸上透进的秋阳竹影微拂摇曳。

## 排除项

- 前后拍：戏台大宴、王熙凤捉奸、打小丫头、贾琏拔剑追逐；贾母内室对质；次日赔礼磕头；鲍二家的吊死。
- 他回他场：不得出现刘姥姥醉卧怡红院之物；不得出现贾琏、王熙凤或鲍二家的身影；严禁兵刃刀剑与殴打惨相。
- 造型禁忌：不得作清代旗人两把头与高底花盆鞋；平儿不得穿艳丽凤袍；宝玉严禁剃头扎满清辫。
