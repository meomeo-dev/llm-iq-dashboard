# 《红楼梦》第61回 投鼠忌器宝玉瞒赃　判冤决狱平儿行权

底本：<https://zh.wikisource.org/wiki/紅樓夢/第061回>；读取日期：2026-10-23。

## 情节要点

1. 迎春房丫鬟莲花儿往大观园厨房要蒸蛋遭柳家的推脱，赌气向司棋挑唆，司棋带小丫头大闹厨房。
2. 莲花儿在厨房搜出失窃的玫瑰露瓶，林之孝家的又搜出柳五儿身上的茯苓霜，一口咬定柳氏母女盗窃并将五儿扣押。
3. 次早众人争相贿赂平儿欲夺厨房差事，平儿心知冤枉，手持露瓶与茯苓霜悄至怡红院寻袭人、宝玉查问实情。
4. 宝玉为庇护暗赠贾环玫瑰露的彩云及顾全探春体面，主动应承瞒赃；平儿体恤无辜，巧妙劝服彩云悔悟。
5. 平儿行权决狱，洗刷柳家母女冤屈并当场释放柳五儿，退回秦显家之钻营，王熙凤依从平儿发落平息风波。

## 选定场面

怡红院庭院廊下：清晨阳光穿过蕉叶修竹，平儿手托三寸螺丝银盖玻璃小露瓶与棉纸包茯苓霜，神色温雅沉静，
正与袭人、宝玉轻声计议；宝玉神情诚挚急切，主动伸手示意愿揽下盗露之名以护探春体面与彩云；袭人温言劝和。
具名平儿、贾宝玉、花袭人三人。选此场面因“平儿行权”与“宝玉瞒赃”是大观园中层治理最具仁心智谋的一笔，
以理服人、体恤下微，全无严刑逼供与私欲算计，静穆安详而意蕴深远。三处依据：

- 「平儿一一的都应着，打发他们去了，却悄悄的来访袭人，问他可果真芳官给他露了。」
- 「宝玉便瞅他两个不提防的时节，自己进去拿了些什么出来……我待要说出来……里面又伤着一个好人的体面」
- 「平儿笑道：‘我可怜的是他，不肯为打老鼠伤了玉瓶。’说着，把三个指头一伸。」

先后核对：五儿被搜露瓶茯苓霜扣押上夜房中（前）→清早众人争相买转平儿谋夺厨房（前）→平儿携物悄至
怡红院，与袭人宝玉商议以宝玉认赃化解风波（此刻）→平儿传唤彩云玉钏挑明因由（后）→彩云愿认，平儿袭人
劝阻并定计（后）→平儿释放柳五儿、斥退秦显之妻（后）。此刻三人正秉公计议，尚未传唤彩云，更未拷问下人。

## 器物与环境

- 地点：大观园怡红院庭院雕花游廊下。粉墙翠嶂，芭蕉展绿，太湖石掩映，晨光明澈幽静。
- 时令天气：农历五月中下旬仲夏清晨；微风拂煦，天气晴朗和润。
- 器物：三寸高螺丝银盖透明玻璃小露瓶（盛浅红玫瑰露）、四方中药棉纸折叠包（茯苓霜）。
- 现实中会动的：① 晨风中芭蕉修竹枝叶轻颤摇曳；② 玻璃小瓶内淡红玫瑰露随动作轻漾；③ 廊外雀鸟在花树间轻盈掠过。

## 排除项

- 前后拍：司棋大闹厨房摔掷盘盏；林之孝家的捆绑拘押柳五儿；上夜婆子索贿刁难；平儿升堂发落秦显家的。
- 暴力与刑名：严禁出现四十板子杖责、枷锁绳索等残暴刑讯画面；严禁赵姨娘贾环泼污争吵。
- 造型禁忌：严禁满清旗装两把头与花盆底鞋；严禁男子剃发留大辫；禁用87版电视剧特定戏服。
