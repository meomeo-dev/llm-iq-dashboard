# 《红楼梦》第19回 情切切良宵花解语　意绵绵静日玉生香

底本：<https://zh.wikisource.org/wiki/紅樓夢/第019回>；读取日期：2026-10-20。

## 情节要点

1. 贾妃回宫后，荣宁二府收拾陈设数日。新年里袭人被母亲接回家吃年茶，宝玉去东府看戏嫌吵，
   在小书房撞见小厮茗烟与一个丫头相会，喝散后让茗烟带他骑马去袭人家。
2. 到花家，宝玉坐上炕，袭人备脚炉手炉、焚香饼、拈松子穰，又从他项上摘下通灵玉给姊妹们
   传看，叫花自芳雇小轿送他回去。
3. 宝玉房中的李嬷嬷吃了留给袭人的酥酪。夜里袭人以赎身之说试探宝玉，再提三件规劝，宝玉应允。
4. 次日袭人感冒，宝玉去黛玉房中编“林子洞耗子精”的故事逗她，宝钗来笑谈，被宝玉房中的吵嚷打断。

## 选定场面

花自芳家屋内：宝玉坐在炕上，脚搁脚炉，怀抱手炉；袭人立在炕边，拈起松子穰，吹去细皮，
用手帕托着递给他。宝玉项上的通灵玉尚未摘下。花家母子刚摆齐果桌，三五个女孩儿低头站在
一旁。具名宝玉、袭人，另有花母、花自芳与女孩儿群像。袭人此刻坐立原文未写，题面按立于炕边
构图。选它是因主人殷勤、袭人照拂宝玉的神情一眼可认，手炉、脚炉、果桌、手帕器物齐备，没有
争执。三处依据：

- 「将自己的坐褥拿了铺在一个炕上，宝玉坐了，用自己的脚炉垫了脚」
- 「又将自己的手炉掀开焚上，仍盖好，放与宝玉怀内」
- 「便拈了几个松子穰，吹去细皮，用手帕托着送与宝玉。」

先后核对：宝玉在东府看戏，溜进书房撞见茗烟（前，不画）→骑马到花家，花自芳抱他下马，袭人
迎出拉进屋（前）→花家母子让上炕、摆果桌、倒茶（前）→袭人铺坐褥，宝玉坐下，脚炉垫脚，香饼
焚入手炉放进他怀内，斟茶（前）→果品摆齐，袭人拈松子穰托在手帕上递去（此刻）→宝玉见她两眼
微红，悄问；袭人问他怎又换新服（紧随）→袭人摘下通灵玉传看一遍，仍与他挂好（后）→雇小轿送回
（后）。此刻玉仍在宝玉项上，没有传看；二人在室内，宝玉在炕上不在地下；茗烟是否在屋原文未写，
不画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾宝玉 | 少年，约十二三岁（第23回称“十二三岁的公子”）；本回“穿着大红金蟒狐腋箭袖，外罩石青貂裘排穗褂”（金蟒为金线绣蟒纹，箭袖为窄袖，石青为深青，排穗为下缘缀穗，据搜索摘要）；冠、抹额本回未写，兜底按第3、8回出门装束：束发嵌宝紫金冠、二龙抢珠金抹额；项上通灵玉系五色丝绦，另有长命锁、记名符；不画家常大辫 | 第19、3、8回 |
| 袭人 | 少女，比宝玉大两岁（第6回），约十四五岁；本回及前文均无衣冠描写，兜底：素色小袄配裙，外罩坎肩，色不强加（丫鬟袄与背心的搭配见第24回鸳鸯“水红绫袄、青缎背心”）；发挽简髻，少首饰；“两眼微红，粉光融滑”，含笑，一手拈松子穰，一手托手帕 | 第19、6、24回 |
| 花母与花自芳 | 平民：花母年长妇人，素色布袄裙，挽髻；花自芳成年男子，布袍，头裹素巾；站在炕前，神情殷勤，刚摆好果桌；“茅檐草舍，又窄又脏”是他自谦，不画破败 | 第19回 |
| 女孩儿（群像） | 袭人的外甥女、侄女，三五个，进屋时“都低了头，羞惭惭的”；素净衣裙，立于一侧，不具名 | 第19回 |

## 器物与环境

- 地点：花自芳家（离贾府“不过一半里路”），屋内炕上；炕上铺袭人的坐褥，炕前设果桌；朴素小屋，
  窄而干净。
- 器物：脚炉、手炉（铜胆，口沿有镂空盖可焚香，通高多不超过十八厘米，故宫词条；脚炉形制未检得）、
  梅花香饼（荷包里取出两个）、袭人的茶杯、果桌上的果品、手帕、松子仁；炭火不外露。
- 时令天气：正月新年（“吃年茶”），天冷，所以用手炉脚炉；白日，室内。
- 现实中会动的：① 手炉盖孔里升起的细香烟（原文写焚香饼，烟形兜底）；② 茶杯上的热气；
  ③ 宝玉冠上绛绒簪缨与衣带穗子随呼吸轻颤（兜底）。

## 排除项

- 后拍：袭人摘通灵玉传看、雇小轿送回、茗烟牵马；前拍：东府看戏、书房撞见茗烟、骑马出后门。
- 同回他场：李嬷嬷吃酥酪、晴雯赌气、夜里剥栗子与赎身争执、袭人约法三章、黛玉房中的耗子精、宝钗。
- 通灵玉按原文画：小如雀卵，以红为主，周身五色花纹，丝绦系挂；不画 87 版白绿相间的大玉与金镶金链；
  金锁是宝钗的，不画。87 版还把箭袖改成圆领团花甲衣并加披风，本回不取。
- 不画清宫剧的两把头与花盆底（两把头道光年间才见，据搜索摘要）；男子不画剃前额留长辫与顶戴花翎；
  不用戏曲造型。
