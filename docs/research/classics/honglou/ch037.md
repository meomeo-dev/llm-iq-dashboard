# 《红楼梦》第37回 秋爽斋偶结海棠社　蘅芜苑夜拟菊花题

底本：<https://zh.wikisource.org/wiki/紅樓夢/第037回>；读取日期：2026-10-23。

## 情节要点

1. 贾政点学差外任，宝玉在园中闲散度日；探春送花笺提议结诗社，贾芸送来两盆白海棠。
2. 宝玉、宝钗、黛玉、迎春、惜春聚于秋爽斋，李纨闻讯赶来掌坛，众人各起雅号并定社规。
3. 迎春抽书限七言律，抽得“十三元”韵牌，点梦甜香限时；探春、宝钗、宝玉、黛玉各赋《咏白海棠》。
4. 李纨评宝钗第一、黛玉第二；次日史湘云赶至补和两首入社，夜间宝钗与湘云在蘅芜苑拟定菊花十二题。

## 选定场面

秋爽斋内作诗：梦甜香将烬，探春、宝钗已交稿，宝玉踱步苦吟，黛玉倚案提笔一挥而就，将诗稿掷向众人。具名黛玉、宝玉、宝钗、探春四人。选它是因起社赛诗是全书青春文采之顶峰，限香掷稿生动展现黛玉才情与宝玉痴态，室内文房雅致，毫无冲突血腥。依据：

- 「迎春又令丫鬟炷了一支‘梦甜香’」
- 「宝玉背着手，在回廊上踱来踱去」
- 「黛玉道：‘你们都有了？’说着提笔一挥而就，掷与众人。」

先后核对：探春发帖邀聚起社（前）→李纨自荐掌坛，众人取别号、定每半月一集（前）→小丫头抽得门字韵，迎春取十三元韵牌盆魂痕昏，炷梦甜香限时（前）→探春先成，宝钗抄出，宝玉回廊苦踱急催黛玉（前）→黛玉倚案一挥而就、掷卷于案（此刻）→众人争看黛玉诗稿，李纨评定宝钗端凝居首、黛玉风流居次（后）→次日湘云补诗，夜宿蘅芜苑拟菊花题（后）。此刻黛玉墨迹刚成，香剩残寸，评阅未起，白海棠尚在怡红院未抬至案前。

## 器物与环境

- 地点：秋爽斋正房。室内宽阔无隔，大理石大案，案上笔墨纸砚，韵牌木匣；香几置香炉插梦甜香；轩窗外芭蕉梧桐掩映。
- 时令：初秋（八月下旬），天气微凉爽霁，白昼天光清朗。
- 器物：花笺白纸、毛笔、砚台、十三元韵牌、铜香炉与“梦甜香”（长约三寸、粗如灯草）。
- 现实中会动的：① 梦甜香微红炭头与青烟袅袅升腾消散；② 窗外蕉叶与桐叶随秋风微曳；③ 案上刚掷出诗笺墨迹的反光微动。

## 排除项

- 后拍：李纨评阅诗次争论、宝玉抱怨不公；次日史湘云入园补作；蘅芜苑夜拟菊花十二题与螃蟹宴商议。
- 前拍：贾政启程洒泪亭；贾芸托婆子送白海棠与孝敬帖；众姐妹争论别号“蕉下客”“潇湘妃子”。
- 误置道具：秋爽斋案前不摆两盆白海棠（花按宝玉吩咐送怡红院，李纨仅路上偶见，迎春明言“都还未赏”）。
- 禁忌造型：清代剃发垂辫、瓜皮帽、旗袍、高底鞋；戏曲舞台冠戴；87版电视剧独有戏服花色。
