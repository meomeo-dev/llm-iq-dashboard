# 《红楼梦》第63回 寿怡红群芳开夜宴　死金丹独艳理亲丧

底本：<https://zh.wikisource.org/wiki/紅樓夢/第063回>；读取日期：2026-10-23。

## 情节要点

1. 查夜婆子散去后怡红院闭门卸正装，宝玉与晴雯、袭人等丫鬟凑份子备办绍兴酒果菜私开生辰夜宴。
2. 众人兴致勃勃，晴雯、袭人等掌灯冒夜分头将薛宝钗、林黛玉、贾探春、李纨、薛宝琴、香菱尽数请来。
3. 众人褪去礼服长裙短袄围坐花梨圆炕桌，晴雯取来竹雕签筒与骰子盒行“占花名”酒令，掷得五点轮至宝钗。
4. 宝钗先掣得牡丹签，题“艳冠群芳”并唐诗“任是无情也动人”，众人笑贺饮酒，命芳官唱《赏花时》侑酒。
5. 探春、李纨、湘云、黛玉相继掣签；次晨玄真观惊报贾敬吞丹暴亡，夜宴骤散，尤氏独理宁府亲丧接二尤。

## 选定场面

怡红院正房暖阁花梨圆炕桌前：夜深红烛高照，群芳皆着家常长裙短袄围坐；桌上陈列竹雕雕花签筒、乌木骰子盒、
白瓷酒盏与攒盒果碟；薛宝钗端坐案前，右手从竹筒中掣出一根刻有牡丹图样与“任是无情也动人”的象牙签条，
眉目含笑、端重沉静；宝玉倚着花瓣纱枕拍手赞叹，黛玉、探春等相顾莞尔举杯共贺。具名薛宝钗、贾宝玉（兼黛玉、探春）。
选此场面因“群芳开夜宴”为大观园女儿极乐之顶点，诗酒流连、花签寓命，温润雅致且无俗艳浮华。三处依据：

- 「晴雯拿了一个竹雕的签筒来，里面装着象牙花名签子，摇了一摇，放在当中。」
- 「宝钗便笑道：‘我先抓，不知抓出个什么来。’说着，将筒摇了一摇，伸手掣出一根」
- 「只见签上画着一支牡丹，题着‘艳冠群芳’四字，下面又有镌的小字一句唐诗，道是：任是无情也动人。」

先后核对：查夜管事散去、怡红院闭门（前）→袭人等请齐宝钗黛玉探春李纨宝琴围坐（前）→晴雯取签筒骰子盒，
掷骰五点数至宝钗，宝钗掣出牡丹签，众人共贺（此刻）→芳官唱《赏花时》（后）→探春黛玉等依次掣签、各占花名
（后）→次晨闻贾敬暴毙，群芳惊散（后）。此刻夜宴欢洽正盛，宝钗首掣群芳之冠，全无后半回死亡与丧仪阴霾。

## 器物与环境

- 地点：大观园怡红院正房内室暖阁。设紫檀花梨雕花圆炕桌，炕上铺红猩猩毡毯，绛纱窗帘低垂，红烛高烧。
- 时令天气：农历四月下旬初夏子夜；窗外暖风习习、竹影摇曳，室内酒香花气氤氲融融。
- 器物：竹雕圆签筒、细长象牙花名签（开首一根牡丹图样刻字清晰）、铜镀金骰子盒、骨质红黑点骰子、精巧白瓷酒盅。
- 现实中会动的：① 案头红烛烛芯微跳、火苗摇曳映照金石光晕；② 宝钗手中象牙签微转、象牙光泽闪动；③ 窗纱随夜风极细微拂动。

## 排除项

- 前后拍：众人饮至五更烂醉横卧；宝玉与芳官猜拳喧闹；次早玄真观惊报贾敬吞丹暴毙、停灵守丧；尤氏迎接二尤。
- 丧葬与荒唐：严禁出现道观炼丹、丹毒溃烂、丧服白布、棺木纸幡等凶丧元素；严禁贾珍贾琏纵酒挑情。
- 造型禁忌：严禁满清旗装两把头与花盆鞋；严禁男子剃发留辫；严禁晚会式现代布景或87版电视剧独有戏装。
