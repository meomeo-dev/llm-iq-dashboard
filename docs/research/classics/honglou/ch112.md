# 《红楼梦》第112回 活冤孽妙玉遭强掳　死散聚惜春入空门

底本：<https://zh.wikisource.org/wiki/紅樓夢/第112回>；读取日期：2026-10-23。

## 情节要点

1. 贾府内贼引盗夜袭大观园，妙玉在栊翠庵被强盗施放闷香掳走，下落不明，应验“无瑕白玉遭泥陷”之凄凉宿命。
2. 惜春留守园中惊闻大难，目睹金玉繁华与佛门清修皆遭尘世污浊摧折，对红尘彻底心死冷绝。
3. 水月庵女尼智通、圆心入园借故探问相劝，惜春心志坚逾金石，决意脱离侯门缁衣出家。
4. 惜春在栊翠庵禅房佛前手执剪刀断发焚香，勘破三春富贵幻象，立誓独卧青灯古佛旁，断绝人间执念。

## 选定场面

大观园栊翠庵禅房佛堂：初春拂晓，风定雪融，庭除幽竹覆霜。佛堂内供白瓷观音立像，铜炉沉香微袅，案前青灯如豆，
几案上散落着佛经木鱼与几绺刚剪下的漆黑发丝。贾惜春面容清冷孤峭、双眸深邃了无尘念，身上穿着一袭宽大的素青布交领女尼长袍，
乌黑青丝垂肩，右手紧握一柄雪亮铁剪断绝发梢，左手正将一炷线香插向铜炉，整个人宛如脱胎换骨的寒霜冷梅；几案旁侧，水月庵女尼智通
身穿灰褐缁衣双手合十低眉念佛，圆心面露惊诧与怜惜之色欲劝又止。具名贾惜春、智通、圆心三人。选此景因妙玉遭劫后惜春断发入空门，
为金陵十二钗中四春彻底散尽、“勘破三春景不长，缁衣顿改昔年妆”之宿命巅峰；坚决摒弃盗贼淫暴掳掠恶景，定格佛堂静寂下孤绝断发出家之清净大彻大悟。三处依据：

- 「惜春心想：‘妙玉何等潔淨，尚遭此劫；這塵世間更有何可戀？’」
- 「便叫找了把剪子來，自己將頭髮抓起，一剪子鉸了去。」
- 「智通圓心見他心志已決，只得合掌道：‘阿彌陀佛，姑娘真是宿世佛緣，看破紅塵了。’」

先后核对：夜盗潜入栊翠庵掳走妙玉（前）→惜春惊魂甫定痛悟世态炎凉，智通圆心入内言语试探相劝（前）→惜春决绝引剪断青丝、
素服焚香立誓入空门（此刻）→王夫人邢夫人闻讯急阻而惜春誓死不从（后）→惜春终伴青灯古佛遁入缁衣（后）。此刻寒晓残灯，断发插香，孤标绝世，宿命了结。

## 器物与环境

- 地点：大观园栊翠庵静室佛堂。供德化白瓷观音像、紫檀素面长案、青铜三足香炉、青玉油灯、沉香木鱼、断发剪刀。
- 时令天气：初春拂晓时分天光微熹；窗外残雪微融、晓风吹拂阶前疏竹，室内清寒透骨。
- 器物：精钢雪亮剪刀、断落青丝发绺、沉香经卷、青瓷素净花插、青石蒲团。
- 现实中会动的：① 佛前青玉油灯如豆灯焰在晨风中微跳泛起细微爆星；② 惜春执剪断发时手腕微颤引动素青宽袖飘摆；③ 铜香炉中新插长香升起缕缕白烟向佛像前缭绕扩散。

## 排除项

- 前后拍：严禁出现黑衣盗贼翻墙入室、用闷香迷倒妙玉并扛抱撕扯之淫暴、打斗与侵害画面；不得出现赵姨娘暴毙五官扭曲中邪丑相。
- 他回他场：不得出现第7回惜春与智能儿戴花嬉笑；不得出现第74回赶走丫鬟入画绝情冷漠场景；严禁出现寺庙脏乱丑陋。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；惜春出家断发，严禁画成全秃尼姑头，须依带发修行女冠之素发披肩清雅仙风。
