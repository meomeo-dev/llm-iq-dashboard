# 《红楼梦》第83回 省宫闱贾元妃染疾　闹闺阃薛宝钗吞声

底本：<https://zh.wikisource.org/wiki/紅樓夢/第083回>；读取日期：2026-10-23。

## 情节要点

1. 探春湘云探视黛玉，黛玉卧病弱不胜衣；贾母得知后命请大夫先看宝玉风邪，顺便至潇湘馆为林姑娘诊脉。
2. 次日太医院名医王大夫先至怡红院看视宝玉无碍，随后由贾琏陪同至潇湘馆，隔帐为黛玉切脉断出“六脉皆弦”。
3. 宫中风传贵妃贾元春偶染重疾，太医院御医前往诊治；内相传旨宣召荣宁亲丁入宫探视，贾政贾赦等奉旨进宫省视。
4. 薛家夏金桂借题发挥大闹闺阃，泼醋凌虐香菱逼薛姨妈气倒，宝钗忍辱负重劝慰母亲调摄家事。

## 选定场面

潇湘馆内寝卧榻前：初冬午后，室雅香清。落地帐幔低垂，雕花楠木牙床上垂挂浅绛色软帐；紫鹃小心自帐幔缝隙中扶出黛玉一段
白皙皓腕，轻平搁于紫檀迎手之上，衣袖轻轻挽起避开金镯；太医院名医王大夫头戴儒巾端坐绣墩，神情肃穆凝神，指搭脉关
沉着切脉；贾琏着素青便袍侧立于落地花罩旁静候回禀；雪雁侍立窗侧捧备药茶。具名林黛玉（露皓腕）、王大夫、紫鹃、贾琏
四人（雪雁旁衬）。选此景因“太医请脉”是红楼梦医学礼仪与大家闺秀禁防之极典雅范本，医家凝神察脉、侍婢细致照拂、
贾琏端肃以待，展现公府威仪与深闺雅韵，亦彻底避开夏金桂闹闺阃之泼悍撕扯及元妃宫闱沉疴。三处依据：

- 「老婆子打起帘子，賈璉讓著進入房中坐下。賈璉道：‘紫鵑姐姐，你先把姑娘的病勢向王老爺說說。’」
- 「紫鵑便向帳中扶出黛玉的一隻手來，擱在迎手上。紫鵑又把鐲子連袖子輕輕的摟起，不叫壓住了脈息。」
- 「那王大夫診了好一回兒，又換那隻手也診了，便同賈璉出來……說道：‘六脈皆弦，因平日郁結所致。’」

先后核对：元妃宫中传旨染疾风声渐起（前）→大夫入荣府先看宝玉风邪（前）→贾琏引王大夫入院至潇湘馆，紫鹃放下锦帐
（前）→紫鹃自软帐引出黛玉皓腕搁迎手，王大夫凝神按脉，贾琏立侧恭听（此刻）→王大夫出外间议论脉案并开补气理脾方（后）
→贾政等奉旨进宫省视贾元春（后）→夏金桂大闹薛家宝钗吞声忍气（后）。此刻太医正按指切脉，全室屏气凝神。

## 器物与环境

- 地点：大观园潇湘馆内寝。垂设浅绛色撒花绉绸帐幔，陈设紫檀雕花架子床、红缎雕花迎手脉枕、落地八扇湘妃竹透雕屏风。
- 时令天气：孟冬初冬晴朗；午后天光明爽，室内熏有安神百合沉香，静穆安详。
- 器物：红木迎手脉枕（包锦缎软垫）、沉香小铜鼎、紫檀圆绣墩、青花茶盅、楠木雕花落地罩。
- 现实中会动的：① 案头铜香炉中百合沉香散出之一丝笔直青烟袅袅舒卷；② 遮挡门廊的厚织秋锦门帘在微风中轻微起伏；③ 窗格外庭前竹林寒风中几片修长青竹叶婆娑摇晃。

## 排除项

- 前后拍：夏金桂借题发挥摔盘砸碗逼倒薛姨妈；贾元妃宫闱病重内相传旨；贾赦贾政进宫跪拜朝贺；太监勒索银两。
- 他回他场：严禁夏金桂恶相泼妇骂街；严禁宫廷重症惊悚悲切；严禁黛玉卧床挣扎咳血痛苦之容。
- 造型禁忌：严禁清代旗人太医顶戴补服与长辫；大夫不可作江湖游医浮浪画法。
