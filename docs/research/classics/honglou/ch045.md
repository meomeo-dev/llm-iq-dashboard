# 《红楼梦》第45回 金兰契互剖金兰语　风雨夕闷制风雨词

底本：<https://zh.wikisource.org/wiki/紅樓夢/第045回>；读取日期：2026-10-23。

## 情节要点

1. 探春李纨等拉王熙凤做海棠诗社监社御史，凤姐爽快应承并资助五十两银子作东道，笑议李纨月例。
2. 赖嬷嬷来给凤姐道喜，劝说宝玉等年轻人守规矩，并为周瑞家之子求情免遭逐出。
3. 宝钗冒雨来潇湘馆探视，开导黛玉病情并答应赠送上等燕窝，二人冰释前嫌、剖心互结金兰。
4. 暮色苍茫风雨大作，黛玉感伤身世，挑灯翻阅《乐府杂稿》，写下七言乐府《秋窗风雨夕》。
5. 宝玉披蓑戴笠冒雨夜探潇湘馆，二人笑谈“渔翁渔婆”；黛玉赠玻璃绣球灯照夜，送宝玉归去。

## 选定场面

潇湘馆内室灯下：黛玉独坐窗前案几旁，刚吟罢搁笔手抚诗笺；宝玉身披轻巧细草蓑衣、头戴大箬笠推门而入，
一手举灯一手微遮光亮笑探黛玉气色。具名林黛玉、贾宝玉两人，无群像。选此场面因“风雨夕”是红楼梦
最负盛名的诗意意境之一，窗外凄风苦雨敲竹打叶，室内孤灯与宝玉一身笠蓑的渔翁打扮构成极温馨动人的对映，
纯真无邪，毫无争竞与喧嚣。三处依据：

- 「吟罢搁笔，方要安寝，丫鬟报说：‘宝二爷来了。’」
- 「一语未完，只见宝玉头上带着大箬笠，身上披着蓑衣。黛玉不觉笑了：‘那里来的渔翁！’」
- 「一手举起灯来，一手遮住灯光，向黛玉脸上照了一照，觑着眼细瞧了一瞧，笑道：‘今儿气色好了些。’」

先后核对：宝钗探望黛玉、互剖金兰语后离去（前）→日落天变，秋霖脉脉雨滴竹梢（前）→黛玉挑灯翻书，
写成《秋窗风雨夕》（前）→黛玉搁笔，宝玉头戴大箬笠身披蓑衣冒雨掀帘进门、举灯照面探看（此刻）→宝玉
脱下蓑笠露出红绫袄，看案头诗稿（后）→黛玉失言说“渔婆”羞红了脸、夺诗向灯上烧了（后）→宝玉看怀中
金表辞去，黛玉取玻璃绣球灯相赠（后）→蘅芜苑婆子送燕窝洋糖（后）。此刻宝玉刚进门，笠蓑未卸，诗草
仍在案头未烧，绣球灯尚在架上。

## 器物与环境

- 地点：大观园潇湘馆有凤来仪内室书斋。临窗紫檀书案，陈设短檠泪烛、端砚笔架、《乐府杂稿》书卷与诗草；窗外雨滴修竹翠梢与阔芭蕉。
- 时令天气：农历秋深之夜；黄昏后暴雨骤至，夜黑风急，寒气穿帘，竹林萧萧雨声淅沥。
- 器物：大箬笠（活顶细竹笠）、细草蓑衣、短檠泪烛、笔墨诗笺、书架上的玻璃绣球灯（背景陈设）。
- 现实中会动的：① 窗外竹梢与蕉叶在秋风暴雨中摇曳滴水；② 案头烛火随宝玉推帘进门的气流微微晃动；③ 宝玉蓑衣草尖凝结的细密雨珠滑落轻滴。

## 排除项

- 前后拍：王熙凤与探春李纨商议诗社筹款；宝钗登门送药、姐妹互剖金兰语；宝玉解下蓑笠露出落花鞋；黛玉向灯火焚烧诗稿；宝玉怀掏金表看时刻；宝玉提玻璃绣球灯在雨中归去；蘅芜苑婆子送燕窝。
- 他回他场：不得出现袭人紫鹃等侍女入画遮挡二人焦点；不得画成金碧辉煌的大厅；严禁出现伞具（宝玉是穿木屐、披蓑戴笠独步而入）。
- 造型禁忌：严禁男子剃头脑后垂辫；严禁清宫旗装两把头与戏曲夸张戏服；斗笠蓑衣必须为素细轻巧草编，不作粗糙刺猬状笨重蓑衣。
