# 《红楼梦》第64回 幽淑女悲题五美吟　浪荡子情遗九龙珮

底本：<https://zh.wikisource.org/wiki/紅樓夢/第064回>；读取日期：2026-10-23。

## 情节要点

1. 贾敬灵柩停放宁国府正堂，贾珍、贾蓉等守丧；宝玉趁无客回园看视黛玉，途中遇雪雁拿瓜果私祭。
2. 宝玉至潇湘馆见案头“炉袅残烟，奠余玉醴”，黛玉病体恹恹面向里歪着，二人互诉挂牵无言对泣。
3. 宝玉漫步书案见端砚下露出一纸角，取出见是黛玉手书五首绝句，黛玉嗔怪夺诗，正闹间宝钗掀帘进房。
4. 宝玉取出诗卷凑至宝钗身旁一同细看，盛赞其才并提笔命名《五美吟》；宝钗赞叹其命意新奇、善翻古意。
5. 贾琏自平安州回京，在宁府见尤二姐貌美心动，借茶水间调情私赠九龙珮，贾蓉从中撮合谋划偷娶。

## 选定场面

潇湘馆内室临窗书案旁：日光透过千竿修竹洒在紫檀案头，案上置端砚笔架与残烟微袅的宣德铜香炉；贾宝玉
手持刚自砚台下抽出的《五美吟》墨迹诗笺，神色惊喜赞叹；林黛玉斜倚在侧榻上，素衣纤弱，含羞带嗔；
薛宝钗身着蜜合色袄裙正自门前掀帘而入，笑语询问。具名贾宝玉、林黛玉、薛宝钗三人。选此场面因“题五美吟”
为潇湘馆最核心的诗性觉醒时刻，三人在竹影清供间诗卷唱和，文雅高旷，完全脱离世俗机巧与红白诸事。三处依据：

- 「只见砚台底下微露一纸角，不禁伸手拿起。黛玉忙要起身来夺，已被宝玉揣在怀内」
- 「一语未了，只见宝钗走来，笑道：‘宝兄弟要看什么？’……凑至宝钗身旁，一同细看。」
- 「宝玉看了，赞不绝口，又说道：‘妹妹这诗恰好只做了五首，何不就命曰《五美吟》。’」

先后核对：宝玉由宁府回园探望黛玉（前）→见紫鹃收陈设、黛玉私祭毕恹恹卧榻（前）→宝玉案头砚下抽诗笺，
黛玉起夺，宝钗掀帘入门，三人同赏评《五美吟》（此刻）→宝玉题签，宝钗评善翻古人之意（后）→贾琏回京，
宝玉出迎相见（后）→贾琏情遗九龙珮（后）。此刻三人正文墨雅集，绝无出殡哭丧之哀，亦无调情私相授受之俗。

## 器物与环境

- 地点：潇湘馆有凤来仪内室书斋。临窗设紫檀平头书案，陈设端溪砚台、小楷狼毫笔、宣德铜香炉、《五美吟》宣纸诗笺。窗外千竿翠竹。
- 时令天气：农历七月初秋早饭后；竹影筛金，室内幽静微凉，香烟微袅。
- 器物：宣纸手卷（墨写《五美吟》）、黑石端砚、宣德素铜小香炉、竹帘。
- 现实中会动的：① 宣德炉中一线青烟随风轻袅升腾；② 窗外修竹随初秋微风摇动、竹影在素壁轻移；③ 宝玉手中展开的宣纸诗笺轻微抖颤。

## 排除项

- 前后拍：宁国府贾敬出殡丧仪、灵柩纸幡大葬；铁槛寺僧道作法；贾琏在茶房趁空赠玉佩调情；贾蓉拉纤；偷娶尤二姐。
- 丧葬与风月：严禁出现棺木、重孝麻衣、哭丧牌位等丧葬元素；严禁任何市井偷情、轻薄调谑之色。
- 造型禁忌：严禁满清旗装两把头与花盆底；严禁男子剃头留辫；严禁87版电视剧独有戏服。
