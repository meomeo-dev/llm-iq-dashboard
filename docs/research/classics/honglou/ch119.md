# 《红楼梦》第119回 中乡魁宝玉弃红尘　沐皇恩贾门延世泽

底本：<https://zh.wikisource.org/wiki/紅樓夢/第119回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉随贾兰赴乡试，行前叩别王夫人与宝钗，诀别言辞悲凄决绝；入场文思平正通达。
2. 贾环趁家中无主串通邢夫人欲强发巧姐，平儿暗随刘姥姥护送巧姐避难于乡间庄上，巧姐农舍纺纱度日。
3. 乡试桂榜揭晓，贾宝玉高中第七名举人，贾兰中第一百三十名举人；然而场门开后宝玉不知所踪，合家悲喜交加。
4. 圣上阅卷嘉奖贾氏叔侄平正之才，念及开国功勋特降恩旨：赦免贾赦贾珍，荣宁二府官复原职，家道复起。

## 选定场面

荣国府荣禧堂正厅（五更龙虎捷报迎门）：秋夜残月微明，五更鼓绝，厅堂上巨烛通明。二门外报子飞骑传捷、红笺捷报高举飞报而入，宣告贾宝玉高中乡试第七名、贾兰中第一百三十名；堂上李纨着石青凤纹命妇长袍，手执报条喜极而泣，贾兰头戴进士儒巾、身着宝蓝生绢长袍侍立生母之侧，意气风发躬身拜母；堂前王夫人身着素锦大袄，颤抖手扶紫檀雕花案几，眼顾堂外空无一人之风露门庭，泪流满面痛呼“宝玉呢”；薛宝钗身着品月素绫长裙，扶侍王夫人身侧，神容木然悲咽，深知宝玉已践诺弃尘而去。具名王夫人、薛宝钗、李纨、贾兰四人。选此景因全书“中乡魁”与“弃红尘”之最高戏剧矛盾同台迸发，两代苦求之功名荣耀与复爵恩典终于实现，而承担此重托之人却以高中为代价永远割断尘缘、飘然消逝，大喜之中包蕴大悲，家族回光返照之下见证宿命绝望。三处依据：

- 「那一夜五更多天，外頭幾個家人進來到二門口報喜……進了屋子便說：‘太太奶奶們大喜……中了第七名舉人。’」
- 「王夫人道：‘寶玉呢？’家人不言語，王夫人仍舊坐下……見賈蘭中了一百三十名。李紈心下喜歡，因王夫人不見了寶玉，不敢喜形于色。」
- 「只見寶玉一聲不哼，待王夫人說完了，走過來給王夫人跪下，滿眼流淚，磕了三個頭，說道：‘母親生我一世……只有這一入場用心作了文章，好好的中個舉人出來……’」

先后核对：宝玉贾兰辞别入贡院秋闱（前）→宝玉交卷后出场门不知所向、家人四处寻访无着（前）→五更天报子入堂飞报叔侄同榜高中，李纨贾兰悲喜受贺，王夫人宝钗迎捷哭寻宝玉，宝玉决绝隐迹（此刻）→朝廷恩旨降临官复原职（后）→巧姐自乡间接回（后）。

## 器物与环境

- 地点：荣国府正堂荣禧堂。雕梁画栋，红烛高烧，案设朱漆报单托盘、白玉茶盏与大理石迎门插屏。
- 时令天气：农历八月中秋乡试放榜之夜，五更寒凉，微风吹拂庭院，残星冷月映照阶墀。
- 器物：泥金朱红桂榜捷报单、双柄红木托盘、高脚青铜烛台、紫檀平头大案、青瓷万寿茶盏。
- 现实中会动的：① 堂前高脚青铜烛台上巨烛烛泪缓缓顺竿淌落，烛焰随门风跳荡闪耀；② 捷报报子飞步奔上石阶时，红绫扎结的捷报泥金红纸在晨风中簌簌翻抖；③ 李纨手执红纸捷报的纤细指尖激动得微微颤抖。

- 他回他场：严禁第119回后半袭人悲泣贾琏回府；严禁出现贡院考官受贿等丑行。
