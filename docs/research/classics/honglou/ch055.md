# 《红楼梦》第55回 辱亲女愚妾争闲气　欺幼主刁奴蓄险心

底本：<https://zh.wikisource.org/wiki/紅樓夢/第055回>；读取日期：2026-10-23。

## 情节要点

1. 元宵节后王熙凤因操劳小月卧病调养，王夫人命李纨协理家务，又命探春协同裁处，特请宝钗从旁照看监察。
2. 探春与李纨将大观园门南边原太监起坐的小花厅（悬“辅仁谕德”匾）辟为议事厅，每日卯正至午正升厅理事。
3. 管事媳妇吴新登家的欺探春年轻，隐瞒旧例请示赵国基丧葬赏银，探春令其取旧账核查，当场按例裁决二十两。
4. 赵姨娘因赏银少于袭人母亲四十两，气势汹汹至议事厅哭闹争闲气，探春严守家法公事公办，据理驳回生母。
5. 平儿奉凤姐之命到厅回话，申明二奶奶全力支持探春秉公裁处，并当众敲打众管事媳妇不可藐视姑娘。

## 选定场面

大观园门南“辅仁谕德”议事厅内：探春端坐宽大紫檀公案正中，神色从容明毅，一手轻按案头旧账册；李纨侧坐
案旁神态温厚；平儿手持对牌恭敬垂手立于大案一侧回话，神情谦和通达；门外廊下阶前数名管事媳妇垂手侍立
听候发落。选此场面因“议事厅立威”展现探春果决精明的治家才干与凤姐平儿的默契策应，明堂肃整，无打斗血腥。
三处依据：

- 「这厅上也有一匾，题着‘辅仁谕德’四字，家下俗呼皆只叫‘议事厅’儿。」
- 「只一边垂手默侍……平儿忙笑道：‘奶奶说……若照常例，只得二十两。如今请姑娘裁夺着。’」
- 「众媳妇皆在廊下静候，里头只待书素云平儿三个侍立。」

先后核对：元宵后凤姐小月，李纨探春受命协理，设座议事厅（前）→吴新登家的试探旧例，探春令取旧账查办（前）
→赵姨娘来厅大哭大闹，探春按例赏银二十两（前）→赵姨娘离去，平儿奉凤姐之命来厅回话，垂手侍立表明遵从姑娘
裁夺（此刻）→平儿伺候探春挽袖盥沐，探春蠲免学中八两公费（后）→平儿阶前训诫众媳妇，宝钗至厅用饭（后）。

## 器物与环境

- 地点：大观园南门内三间小花厅（议事厅），檐下悬挂墨底金字“辅仁谕德”匾额；厅中设紫檀大公案、交椅、方桌脚踏。
- 时令天气：孟春正月过后早春时节，天已和暖，晴光透过门帘照入厅内。
- 器物：公案上整齐陈设荣国府账册、红木对牌盒与银质牙质支银对牌、青花茶盏、端砚笔墨。
- 现实中会动的：① 门外檐下竹帘随初春微风轻晃；② 案头账册纸页微被清风拂起；③ 廊外早春庭树枝影微移。

## 排除项

- 前后拍：严禁赵姨娘撒泼打滚、哭闹指骂之丑态；不可画探春委屈拭泪；不可画平儿在石矶上与秋纹吃茶歇息。
- 他回他场：不得画凤姐卧病服药之卧房；不得混入第56回分派大观园竹林花木之情景。
