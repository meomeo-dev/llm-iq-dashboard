# 《红楼梦》第100回 破好事香菱结深恨　悲远嫁宝玉感离情

底本：<https://zh.wikisource.org/wiki/紅樓夢/第100回>；读取日期：2026-10-23。

## 情节要点

1. 贾政在海疆任所遇镇海总制为子求亲，家书报回贾府，贾母王夫人定夺允婚将探春远嫁海外。
2. 薛家薛蟠惹人命重案未结，夏金桂挑唆生事致香菱受屈遭忌，宝钗百般委曲周全。
3. 探春远嫁启程在即，大观园姐妹骨肉离散，宝玉闻耗万念俱灰，感叹死的死、走的走，离情凄楚。
4. 秋爽斋内探春身着郡主远嫁盛服端肃辞别，宝玉临风泣涕，江头楼船锦帆猎猎已待发。

## 选定场面

大观园秋爽斋阔朗庭院与临水画舫远景：初夏晴昼，苍苔露润，芭蕉展绿，梧桐深碧。贾探春容貌俊朗顾盼神飞却带坚毅凝重之气，
身着朱红织金云霞大袖礼袍、下着石青洒金凤尾裙、挽高髻插赤金累丝步摇凤簪；端肃挺拔立于秋爽斋石阶之上，双手微敛胸前作别；
近前贾宝玉身着淡蓝竹布直裰、腰束丝绦，面容憔悴双目泛红，临阶掩面泣下、深感骨肉永诀之痛；远景大观园水门外隐现官舫锦帆高悬、
仪仗列阵，预示万里海疆一去不归。具名贾探春、贾宝玉二人。选此景因“悲远嫁宝玉感离情”乃大观园群芳星散之关键关捩，
“分骨肉”曲文之悲剧具象化，探春盛服端肃与宝玉涕泪伤怀形成剧烈对比，英雄气与儿女泪交织。三处依据：

- 「賈母道：‘三丫頭這一去了，不知三年兩年那邊可能回家？若再遲了，恐怕我趕不上再見他一面了。’說著，掉下淚來。」
- 「寶玉因問道：‘三妹妹，我聽見林妹妹死的時候你在那里來著……’」
- 「這里探春又氣又笑，又傷心，也不過自己掉淚而已……寶玉得知探春遠嫁，極感離情別緒。」

先后核对：海疆总制求亲家信至，贾母王夫人定计远嫁（前）→夏金桂闹薛家香菱遭厄（前）
→秋爽斋探春盛服辞行，宝玉相对涕泗横流感伤离别（此刻）→探春登舟辞母远赴海疆（后）
→宝玉归房悲恸欲绝服定心丸（后）。此刻阶前微风翻卷衣袂，探春神情决然端肃，宝玉洒泪千行，骨肉生离。

## 器物与环境

- 地点：大观园秋爽斋庭前石阶，回廊曲折，远衬大观园池水与接引水闸。芭蕉浓绿如伞，梧桐叶大蔽日。
- 时令天气：暮春初夏之交，骄阳微炙，晴空辽阔而偶有长风掠过，天地苍茫。
- 器物：秋爽斋大理石案陈设一角、探春辞行行囊锦袱数袭、雕花远嫁朱红妆匣、水关外官舫黄龙大锦帆隐角。
- 现实中会动的：① 探春朱红大袖礼袍与石青凤尾裙下摆在庭院穿堂风中猎猎扬起；② 秋爽斋阶前大叶芭蕉在初夏长风中摇曳击拂、洒下碎金斑驳日光；③ 远景池水水面上官舫锦旗受风翻卷。

## 排除项

- 前后拍：夏金桂与薛蟠撕打闹剧；香菱受屈挨打卧病；码头官船祭江吹号；贾母王夫人泣别辞宴。
- 他回他场：不得出现第40回秋爽斋秋爽晓妆大宴；不得出现前八十回探春理家之威严管家相；严禁出现洋枪洋炮或清代水师兵丁。
- 造型禁忌：严禁清代旗装大拉翅与满汉吉服；探春为明式郡主贵女大礼服（霞帔凤钗），宝玉为淡雅文生常服，严禁戏曲花旦化。
