# 《红楼梦》第49回 琉璃世界白雪红梅　脂粉香娃割腥啖膻

底本：<https://zh.wikisource.org/wiki/紅樓夢/第049回>；读取日期：2026-10-23。

## 情节要点

1. 香菱苦吟终得佳作入诗社；邢岫烟、李纹、李绮、薛宝琴、薛蝌等亲友同日进京投亲，大观园群芳齐聚。
2. 贾母极喜宝琴，命王夫人认作义女并留寝同住，赐金翠辉煌的凫靥裘斗篷；保龄侯迁委外省，贾母留下史湘云住园。
3. 次日大雪初霁，众人在芦雪庵重开诗社准备即景联句。
4. 宝玉与湘云悄向凤姐要来新鲜生鹿肉，在芦雪庵命老婆子搬来铁炉、铁叉与铁丝蒙，平儿、探春、宝琴、凤姐等围炉割腥啖膻大嚼。
5. 平儿褪下金镯放于案上，吃毕发觉少了一只；李纨出题限二萧韵，众人入室内地炕准备联句。

## 选定场面

芦雪庵傍山临水轩堂前雪地：湘云与宝玉并立铁炉旁，手持铁叉翻烤鹿肉，焦香四溢；平儿挽袖褪下腕上金镯，三人围炉割腥啖膻；宝钗、黛玉、探春笑语围观，宝琴披金翠闪烁的凫靥裘笑看。具名史湘云、贾宝玉、平儿三人烤肉，林黛玉、薛宝钗、薛宝琴环立。选此场面因雪天茅舍围炉烤肉是大观园最具豪情诗韵与烟火生气之胜景，名士风流尽显，毫无血腥争斗。三处依据：

- 「只见老婆们拿了铁炉，铁叉，铁丝幪来」
- 「平儿……褪去手上的镯子，三个围着火炉儿，便要先烧三块吃。」
- 「湘云一面吃，一面说道：‘我吃这个方爱吃酒，吃了酒才有诗。’」

先后核对：宝玉、湘云计较要生鹿肉送入园（前）→众人齐聚芦雪庵，李纨探春进屋拟题（前）→婆子抬来铁炉铁叉，宝玉湘云生火烤肉（前）→平儿赶来传话被拉住，褪下金镯，三人围炉烧烤大嚼，宝钗黛玉探春宝琴笑看（此刻）→宝琴凤姐加入啖肉，湘云论“是真名士自风流”（后）→吃毕洗漱，平儿寻镯不见，众人入地炕联句（后）。此刻三人正围炉翻烤，平儿已褪镯在旁，黛玉宝钗笑语围看，尚未进内地炕联诗，镯子尚未失落。

## 器物与环境

- 地点：大观园芦雪庵（傍山临水河滩之上，茅檐土壁，槿篱竹牖，四周寒水芦苇覆雪，穿苇经竹桥通藕香榭）。
- 时令天气：冬日大雪初霁，天地琉璃世界、粉妆玉砌，朔风晴冷，室内外炉火融融。
- 器物：铁炉（炭火熊熊）、铁叉、铁丝蒙、大块生鲜红润鹿肉、几案、平儿褪下的一只金镯（虾须镯）。
- 现实中会动的：① 铁炉炭火微红、烤肉腾起的缕缕青白轻烟随风飘散；② 茅檐积雪在炉火暖意中偶有细雪微融飘落；③ 湖畔雪芦苇与众人猩猩毡斗篷在冬风中轻拂微扬。

## 排除项

- 前后拍：宝玉披蓑戴笠如渔翁独行冒雪而来；内室地炕联句“一夜北风紧”；吃毕平儿乱寻手镯；次日宝玉雪中乞红梅；黛玉作十独吟。
- 他回他场：不可混入第52回晴雯拿簪子戳坠儿偷镯的冲突；不可画室内热炕联句；不得画夏秋无雪景色。
- 造型禁忌：严禁满清金钱鼠尾辫、长袍马褂及旗妇两把头；严禁戏曲花脸或油彩戏装；不可照搬87版电视剧独有皮帽道具。
