# 《红楼梦》第58回 杏子阴假凤泣虚凰　茜纱窗真情揆痴理

底本：<https://zh.wikisource.org/wiki/紅樓夢/第058回>；读取日期：2026-10-23。

## 情节要点

1. 老太妃薨逝，贾母等入朝随祭，薛姨妈移居潇湘馆照管黛玉，梨香院十二个学戏女孩子遣散分入各房使唤。
2. 清明节贾琏等往铁槛寺扫祭，病体初愈的宝玉独步园中，见大杏树花落结实，对满树小青杏感叹女孩子红颜易逝。
3. 忽见山石后火光微闪，小生藕官满面泪痕在石角私烧纸钱，被巡园管事婆子揪住要押送治罪。
4. 宝玉急中生智，手持竹杖敲开婆子的手将藕官护在身后，谎称是自己梦中杏花神索要白纸钱，吓退刁顽婆子。
5. 藕官感激宝玉护庇，私下让其询问芳官；晚间芳官在怡红院向宝玉尽述藕官与已故菂官相爱祭悼之至情真理。

## 选定场面

沁芳桥畔大杏树与山石掩映处：大杏树繁叶成荫、缀满豆大青杏，树下湖石嶙峋；藕官面带泪痕蹲于石隙，脚下瓦盆
余烬未熄、青烟袅袅；宝玉身着宽袍靸鞋，一手执竹节手杖横臂将藕官护在身后，手中竹杖正敲开凶恶婆子的枯瘦手腕；
婆子惊惶后退。选此场面因“杏子阴庇藕官”是宝玉怜惜纯洁少女、超越世俗礼法偏见的极高境界，石树清幽，情义动人。
三处依据：

- 「山石之后，一株大杏树，花已全落，叶稠阴翠，上面已结了豆子大小的许多小杏。」
- 「忙转过山石看时，只见藕官满面泪痕，蹲在那里，手里还拿着火，守着些纸钱灰作悲。」
- 「宝玉忙把藕官拉住，用拄杖敲开那婆子的手……」

先后核对：太妃薨逝贾母随祭，十二伶人入各房，宝玉病愈拄杖游园（前）→宝玉在杏树下望杏兴叹、雀儿乱啼（前）
→山石后火光起雀儿飞，婆子呵斥拿问藕官（前）→宝玉转过山石拉住藕官，用手杖敲开婆子之手，编杏花神之梦为其解围
（此刻）→婆子惧祸散去，藕官感激指点宝玉问芳官（后）→芳官与干娘争水洗头，宝玉袭人相劝（后）→芳官夜说菂官（后）。

## 器物与环境

- 地点：大观园沁芳桥畔山石之后。一株老杏树枝繁叶茂，结满豆粒大青杏；山石下避人石角，地面陈一小瓦盆。
- 时令天气：暮春清明时节，和风轻吹，杏树树阴如盖，春意深浓。
- 器物：宝玉手中细竹手杖、地上小瓦盆、半燃纸钱灰烬、火折子、残存白纸角。
- 现实中会动的：① 瓦盆余烬中一缕淡淡白烟随风轻袅飘散；② 杏树翠叶与密生小青杏在微风中轻微摇动；③ 婆子惊退时衣角微摆。

## 排除项

- 前后拍：不可画老太妃送灵大丧排场；不可画贾琏在铁槛寺上坟；不可画宝玉对杏花神祝祷行礼；严禁芳官干娘泼水大吵厮打。
- 他回他场：严禁混入第23回黛玉荷锄葬花；不可出现戏台彩唱盛装；严禁男子薙发留辫与清宫旗装两把头马蹄底。
