# 《红楼梦》第115回 惑偏私贾政受欺诳　借梦兆宝玉遇幻影

底本：<https://zh.wikisource.org/wiki/紅樓夢/第115回>；读取日期：2026-10-23。

## 情节要点

1. 贾政督责宝玉功课，地藏庵姑子造访，惜春矢志出家绞发避世之志愈坚。
2. 甄宝玉随母进京谒见贾政与王夫人；贾政称许其应对应变之才，命宝玉带贾环、贾兰相陪叙谈。
3. 荣禧堂外书房客堂中，真假宝玉生平首次同室对坐相勘；贾宝玉原望得超凡知己，惊觉甄宝玉竟满口忠孝显亲与仕途经济。
4. 贾宝玉大失所望，斥甄宝玉为“禄蠹”；回房后神魂迷离更甚，乃至食水不进，合家大骇延医料理后事。

## 选定场面

荣禧堂外书房客堂：秋深薄暮，素帘半卷。贾政回避内书房后，同名同貌之真假二宝玉分坐客堂花梨木椅上对坐相勘。贾宝玉着白绫素服、面色苍白神清骨冷，目露孤傲超逸之色，欲探超凡入圣真谛；甄宝玉同貌同形却着簇新天青团花行袍，意态安详老成，从容纵论立德立言、显亲扬名之世途大道；下首贾兰着蓝布直裰拱手倾听心悦诚服，贾环偏坐一隅神色讪讪不乐。具名贾宝玉、甄宝玉、贾兰、贾环四人。选此景因全书“真假二玉”终局肉身会勘，第2回冷子兴演说与第56回南柯旧梦终成实体对照；昔日同一肉身幻影，今朝一人决意超然出尘、一人深陷名利牢笼，二人同名异趣构成巨大的哲学反差与幻灭悲剧。三处依据：

- 「賈政見甄寶玉相貌果與寶玉一樣，試探他的文才，竟應對如流，甚是心敬，故叫寶玉等三人出來警勵他們。」
- 「今日見面，真是謫仙一流的人物……想欲領教一番超凡入聖的道理，從此可以淨洗俗腸，重開眼界……」
- 「後來見過那些大人先生盡都是顯親揚名的人……自有一番立德立言的事業……所以把少時那一派迂想痴情漸漸的淘汰了些。」

先后核对：贾政考问甄宝玉嘉许其才（前）→宝玉穿素服领贾环贾兰出见，贾政退入内室，二宝玉对坐叙谈，一人求脱俗超凡、一人讲经世扬名，心志冰炭不投（此刻）→甄宝玉入内拜见王夫人（后）→宝玉回房向宝钗叹甄宝玉亦是禄蠹、神魂迷惘昏厥（后）。

## 器物与环境

- 地点：荣国府荣禧堂侧外书房客堂。古柏森森，轩窗高敞，室内陈设紫檀案几、素绢屏风与博古瓷尊。
- 时令天气：农历八月深秋，薄暮微凉，金风拂动廊前翠竹，夕照斜穿轩窗。
- 器物：白玉素盖碗茶盏、紫檀平头案、青花博古水盂、素绢松石条幅、客座垫锦褥。
- 现实中会动的：① 窗外深秋穿堂风掠过庭前翠竹，竹梢微摇拂向棂格；② 紫檀平头案上白玉茶盏中新沏热茶微泛轻烟，随风袅袅斜曳；③ 贾宝玉素白道袍宽袖下垂，受窗隙秋风微卷轻拂。

## 排除项

- 前后拍：地藏庵姑子引诱惜春；后房宝钗劝宝玉攻书；宝玉回房发呆昏厥人事不知；癞头僧持通灵宝玉索银一万两。
- 他回他场：严禁第56回怡红院梦中见甄宝玉之虚幻景象；不得混入江南甄家被抄之籍没旧事；严禁出现市井粗俗喧哗。
- 造型禁忌：严禁清代长辫顶戴与马蹄袖；严禁旗袍与马褂；二宝玉神貌虽同，气质必须截然分开（贾超逸离尘，甄端肃入世）。
