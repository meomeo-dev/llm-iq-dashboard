# 《红楼梦》第26回 蜂腰桥设言传心事　潇湘馆春困发幽情

底本：<https://zh.wikisource.org/wiki/紅樓夢/第026回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉调养痊愈回大观园；贾芸在蜂腰桥与红玉四目相对，后经坠儿之手互换帕子互传心事。
2. 宝玉闲步至潇湘馆，见黛玉春困发幽情，言语相戏惹黛玉嗔怪；薛蟠假借贾政之名哄宝玉出府赴庆生私宴。
3. 冯紫英带伤赴宴喝两海大酒即去；宝玉席散回园微醺，宝钗到访怡红院对坐闲谈。
4. 黛玉闻信深夜往探，见院门紧闭，扣门遭晴雯赌气回拒；黛玉听得院内笑语误会伤怀，独立花阴悲泣惊飞宿鸟。

## 选定场面

大观园怡红院闭门外：黛玉一人孤立于粉墙花阴与垂柳之下，一手执绢帕拭泪，神色凄楚；高墙朱门紧闭，柳枝间栖息的宿鸟被哭声惊起展翅飞离。具名林黛玉一人，无群像。选此瞬间因“花阴闭门咽泣”是黛玉寄人篱下敏感心境的典型写照，亦是次日题咏《葬花吟》之直接情感前因；画意凄清静谧，规避卧房私密。三处依据：

- 「再往怡红院来，只见院门关着，黛玉便以手扣门。」
- 「也不顾苍苔露冷，花径风寒，独立墙角边花阴之下，悲悲戚戚呜咽起来。」
- 「那附近柳枝花朵上的宿鸟栖鸦一闻此声，俱忒楞楞飞起远避，不忍再听。」

先后核对：宝玉回院宝钗来访、黛玉挂念步来（前）→黛玉以手扣门被晴雯赌气阻拒（前）→黛玉隔门误闻笑语伤感无着（前）→黛玉独立院外墙角花阴下呜咽拭泪，枝上宿鸟惊飞（此刻）→黛玉正自啼哭忽闻门响有人出来（后）→次日清晨芒种节大观园饯花神（后，第27回）。此刻门未启，院内宝玉宝钗不见，门外唯黛玉一影。

## 器物与环境

- 地点：大观园怡红院外墙角花径。院门紧闭，朱漆铜环；粉墙下一湾苍苔，临径植花树、细竹与垂柳。
- 时辰天气：入夜初更掌灯之后，夜色微蒙，夜凉如水，露冷风清。
- 节令：农历四月下旬（四月二十六芒种前夕），暮春初夏之交，花径落英点点。
- 器物：素白绢帕（黛玉手中擦泪）。
- 现实中会动的：① 垂柳与花树上的宿鸟栖鸦扑棱展翅向夜空飞离；② 花阴柳丝与黛玉衣带裙边随夜风轻曳；③ 枝头落花随风缓缓坠向苍苔。

## 排除项

- 前拍：贾芸红玉蜂腰桥相顾、宝玉潇湘馆倚碧纱窗窥黛玉春困、薛蟠书房弄西瓜鱘鱼宴、晴雯隔门高声顶撞拒开门。
- 后拍：怡红院门吱喽打开、次日黛玉退避宝玉、宝钗扑蝶、滴翠亭藏奸、黛玉扫花落泪葬花吟。
- 造型与构图：不画门内宝玉宝钗对坐；不画晴雯门缝张望；黛玉不披厚斗篷或大氅；不画清代满洲高底旗鞋。
