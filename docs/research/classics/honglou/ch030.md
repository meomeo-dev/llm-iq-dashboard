# 《红楼梦》第30回 宝钗借扇机带双敲　龄官划蔷痴及局外

底本：<https://zh.wikisource.org/wiki/紅樓夢/第030回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉往潇湘馆陪不是，二人言归于好，凤姐打趣拉二人同往贾母处。
2. 宝玉失言将宝钗比作杨妃惹其大怒，靛儿寻扇遭宝钗借题双敲讽刺；宝钗以《负荆请罪》反唇相讥。
3. 宝玉午间至王夫人房调笑金钏儿，王夫人翻身掌掴金钏儿并执意撵出，宝玉慌乱逃回大观园。
4. 宝玉漫步至蔷薇架，见龄官蹲地以金簪划“蔷”字垂泪，宝玉看痴同淋夏雨；宝玉回怡红院踹门误伤袭人。

## 选定场面

大观园蔷薇花架竹篱畔：龄官蹲在繁茂的粉红蔷薇花丛下，一手支膝，一手握着拔下的绾头发金簪，在松软地面上反复划写十八笔的“蔷”字，面带泪痕神情凄楚；宝玉穿藕合纱衫，隔着绿竹花架竹篱洞儿屏息凝视，右手食指在左手心模仿笔划，两人一内一外皆看痴。具名龄官、贾宝玉两人，无群像。选此瞬间因“龄官划蔷”为红楼最富诗意与哲思之情悟瞬间，避开掌掴金钏儿与踹伤吐血，静谧纯粹。三处依据：

- 「如今五月之际，那蔷薇正是花叶茂盛之际，宝玉便悄悄的隔着篱笆洞儿一看」
- 「只见一个女孩子蹲在花下，手里拿着根绾头的簪子在地下抠土，一面悄悄的流泪」
- 「再看，还是个“蔷”字。里面的原是早已痴了... 外面的不觉也看痴了」

先后核对：宝钗借扇双敲宝黛（前）→王夫人掌掴金钏儿并撵出府、宝玉慌走（前，不画）→宝玉进园漫步至蔷薇花架听得哽咽之声（前）→龄官蹲花下金簪反复划“蔷”字垂泪、宝玉隔篱偷看且掌心摹字（此刻）→骤雨忽至宝玉隔花提醒龄官避雨（后）→宝玉奔回怡红院飞脚误踢袭人肋下咳血（后，不画）。此刻夏云骤聚而骤雨未落，落红满径，蝉鸣初起。

## 器物与环境

- 地点：大观园内曲折花径旁的蔷薇花架。竹编篱笆，满架苍翠叶蔓与盛开蔷薇，花下泥土湿润松软。
- 时辰天气：农历五月端阳前后正午；赤日当空，盛暑日长，浓荫合地，远近满耳蝉鸣，天际隐有阴云聚拢。
- 节令：仲夏五月初，蔷薇盛花繁茂期，落花点点。
- 器物：细长金簪一根（龄官绾发金簪，用于划地写字）、地面反复划刻的“蔷”字笔痕。
- 现实中会动的：① 龄官右手执金簪在松土上一笔一画反复勾写“蔷”字；② 宝玉右手食指在左手掌心同步比划摹写；③ 蔷薇藤蔓花枝与落花在微风中摇荡。

## 排除项

- 前拍：宝钗冷笑驳斥“没好兄弟作杨国忠”、王夫人翻身坐起掌掴金钏儿半边脸、金钏儿哭求下跪。
- 后拍：夏日阵雨倾盆而下、宝玉与龄官隔花互问避雨、宝玉冒雨狂奔、抬脚猛踢怡红院门踢中袭人肋骨、夜照地下一口鲜血。
- 造型与构图：不画戏曲旦角厚重戏装与大靠；宝玉不戴紫金冠与大氅；不画清代马蹄袖与金钱鼠尾辫。
