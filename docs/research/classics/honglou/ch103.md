# 《红楼梦》第103回 施毒计金桂自焚身　昧真瞒雨村判案

底本：<https://zh.wikisource.org/wiki/紅樓夢/第103回>；读取日期：2026-10-23。

## 情节要点

1. 贾琏至吏部为贾政回京销假打点停妥，薛家老妪慌张奔来报称夏金桂暴亡。
2. 夏金桂意欲毒杀香菱反自食恶果误饮鸩汤，夏母率众登门索命大闹薛府。
3. 宝钗镇定分辩，放宝蟾对质查出砒霜真相，贾琏引刑部相验平息夏家诬告。
4. 贾雨村升任京兆府尹，于顺天府大堂调阅薛蟠人命案卷与金桂自鸩验状，勘断公案。

## 选定场面

顺天府大堂贾雨村升堂勘阅薛蟠案卷与夏氏验状：仲春日暮，顺天府尹正堂威严肃穆。贾雨村头戴乌纱帽、身着
正四品云雁纹朝服，端坐于朱红公案之后，秉烛按卷沉吟；左侧书吏躬身捧呈薛蟠命案与夏金桂自鸩相验文书；
右侧当值衙役手执水火棍肃立堂侧。具名贾雨村、顺天府书吏、当值衙役三人。选此景因本回回目“昧真瞒雨村
判案”，严禁服毒惨状与尸身，取京兆正堂查勘公牍之森严场景，展现官场弄权与官官相护之暗流。三处依据：

- 「且說賈雨村升了京兆府尹兼管稅務，一日出都查勘開墾地畝。」
- 「只見來了一位老爺，認得是榮國府的大爺賈璉，因在部里打點，認得刑部司員。」
- 「金桂的母親便依著寶蟾的所在取出匣子……此時惟有夏家母子著忙，想來總要吃虧的。」

先后核对：夏金桂投毒反自毙、夏母索命大闹薛府（前）→宝钗查实砒霜、贾琏邀刑部相验（前）→贾雨村顺天府
大堂阅勘薛蟠案卷与夏氏呈词，谋划包庇薛家（此刻）→雨村出都巡察（后）→急流津庙内遇甄士隐（后）。公堂
烛火掩映，雨村神态深沉，案牍高悬。

## 器物与环境

- 地点：顺天府大堂正堂公座。红雕漆暖阁上悬“明镜高悬”金匾，大案陈设朱砂御笔、签筒与文书档案。
- 时令天气：农历二月仲春薄暮时分；堂外暮霭沉沉，庭柏含翠，堂内红烛高照。
- 器物：顺天府公案、薛蟠命案卷宗、仵作验尸呈文、朱砂笔、青花笔筒、水火棍。
- 现实中会动的：① 公案铜烛台上高烧的烛火受穿堂微风吹拂轻轻摇曳；② 书吏捧卷呈递时公文纸页在指尖微动；③ 堂外庭前苍柏枝叶在初春暮色中缓缓摆动。

## 排除项

- 前后拍：严禁夏金桂口鼻流黑血、在地下乱滚抓胸之暴毙惨状与尸身；严禁夏母撒泼扭打；严禁古庙失火烟焰蔽天。
- 他回他场：不得出现第4回葫芦案薛蟠抢香菱；不得出现第93回水月庵风月案；严禁市井殴斗。
- 造型禁忌：严禁清代剃发长辫、马蹄袖与顶戴花翎；官服依明代大明会典汉家圆领袍定制，不染旗俗。
