# 《红楼梦》第117回 阻超凡佳人双泪落　听谶语盲女独抚琴

底本：<https://zh.wikisource.org/wiki/紅樓夢/第117回>；读取日期：2026-10-23。

## 情节要点

1. 癞头僧登门荣府索玉，贾宝玉决意将通灵宝玉归还和尚以斩断凡情，冲入内房取玉。
2. 袭人拼死抱住宝玉腰带哭阻，紫鹃与宝钗先后赶来夺玉护持；宝玉虽留玉身却立定出世之志。
3. 贾琏领命护送贾赦灵柩前往配所，外书房贾蔷、贾芸聚赌纵乐，邢大舅、王仁亦借端设局赌酗。
4. 怡红院闺阁之中，宝钗与袭人泣涕交加苦劝宝玉留恋红尘、克尽夫职孝道；宝玉抚琴相对默然，尘缘已尽。

## 选定场面

怡红院深闺幽室：深秋日暮，萧瑟秋风席卷庭阶落叶。贾宝玉独坐紫檀琴案前，手按古琴素弦，面容清癯超逸，眼神空寂默然；身侧薛宝钗着石青云缎暗花交领长袄、素面长裙，立于案旁执帕掩面垂泪苦谏，劝夫君怜念老母与骨肉宗祧；花袭人跪伏于宝玉膝侧脚踏之上，双手紧挽宝玉素服袍角，泪落如雨，苦苦哀告；案头通灵宝玉锁于锦盒中散落一旁，窗外枯荷冷竹迎风瑟缩。具名贾宝玉、薛宝钗、花袭人三人。选此景因本回核心乃“阻超凡”，历经太虚重游与疯僧点化，宝玉已看破人间一切机巧，宝钗之礼教纲常与袭人之痴情温存化作最后挽留，佳人双双泪落，与宝玉之静默超凡构成全书最深沉之情理交锋。三处依据：

- 「襲人聽說，即忙拉住寶玉道：‘這斷使不得的！那玉就是你的命，若是他拿去了，你又要病著了。’」
- 「寶玉道：‘如今不再病的了，我已經有了心了，要那玉何用！’……襲人顧不得什麼，一面赶著跑，一面嚷……」
- 「他兩個還不知道寶玉自會那和尚以後，他是欲斷塵緣。一則在王夫人跟前不敢任性，已與寶釵襲人等皆不大款洽了。」

先后核对：宝玉取玉欲归还疯僧（前）→袭人紫鹃拼死抱持、宝钗赶来夺玉（前）→贾宝玉回深闺坐于琴案，宝钗袭人双双垂泪苦劝留恋红尘，宝玉抚琴默然，心如止水（此刻）→外书房贾芸贾蔷设局聚赌，四姑娘惜春决意出家（后）。

## 器物与环境

- 地点：大观园怡红院内室闺房。室内紫檀琴桌安设焦尾古琴，后设沉香木雕花床榻与素白纱帐，幽冷清肃。
- 时令天气：农历八月深秋暮霭，凉飙萧瑟，黄叶委地，窗棂投射苍茫冷光。
- 器物：七弦仲尼式古琴、红木琴桌、泥金锁扣朱漆宝玉锦匣、绣竹丝帕、青瓷水仙盆。
- 现实中会动的：① 窗外深秋回风吹卷庭前枯叶，碎黄落叶在青石阶上打转翻飞；② 案前白铜香炉中一线苏合细香受气流牵引徐徐盘旋升腾；③ 袭人伏跪啼哭时双肩伴随抽泣微微耸动起伏。

## 排除项

- 前后拍：二门外李贵拦阻疯僧；二门石阶前袭人抱宝玉带子哭倒在地；外书房贾蔷行月字流觞聚赌；惜春剪发断烦恼。
- 他回他场：严禁第87回林黛玉抚琴悲往事；严禁第28回宝玉薛蟠唱愁楚之宴；严禁出现床帏狎昵情态。
- 造型禁忌：严禁清代旗头大拉翅、旗袍与马褂；全员居家居丧素装，恪守明式文人居室典雅庄肃之规。
