# 《红楼梦》第96回 瞒消息凤姐设奇谋　泄机关颦儿迷本性

底本：<https://zh.wikisource.org/wiki/紅樓夢/第096回>；读取日期：2026-10-23。

## 情节要点

1. 贾政升任江西粮道行期迫促，贾母急欲赴任前为宝玉完婚，定议娶宝钗冲喜兼延子嗣宗祧。
2. 袭人含泪密陈宝黛私情恐生人命不测，凤姐遂献“调包计”：明娶宝钗而暗哄宝玉娶黛玉，合府紧闭铁桶禁宣。
3. 傻大姐因多嘴招祸遭珍珠掴颊，躲入沁芳桥山石后当年葬花僻静处痛哭，正遇散闷而来的林黛玉。
4. 傻大姐竹筒倒豆泄露娶宝姑娘冲喜之天大机密，黛玉如遭疾雷击顶、神魄骤散；步履虚浮迷失本性。

## 选定场面

大观园沁芳桥畔花冢与曲径幽竹：早春正月雪霁严冷，残冰初泮。林黛玉身姿纤弱绝代，着牙白暗花交领长衫、月白素绫裙，
单手紧紧扶住冰冷青黑的太湖山石，身形摇摇欲坠如风中弱柳；双眸空茫失神凝视空际，面容惨白如雪，极度震撼下神思俱丧；
左侧山石凹隙之后，粗使丫鬟傻大姐着粗蓝布袄正捂帕抽泣，神色惶急欲退；右侧远景竹径幽深处，紫鹃手执绣帕正急步寻来；
近景青苔残石畔尚留当年宝黛葬花之旧冢。具名林黛玉、傻大姐、紫鹃三人。选此景因“泄机关颦儿迷本性”为全书悲剧最高转折，
特意设于当年并肩葬花盟誓之圣地，昔日花冢今成断肠绝命之所，以极度静默空灵之大悲取代疯癫狂乱，典雅凄绝。三处依据：

- 「剛走到沁芳橋那邊山石背後，當日同寶玉葬花之處，忽聽一個人嗚嗚咽咽在那里哭。」
- 「黛玉聽了這一句，如同一個疾雷，心頭亂跳。略定了定神，便叫了這丫頭：‘你跟了我這里來。’」
- 「那黛玉此時心里竟是油兒醬兒糖兒醋兒倒在一處的一般，甜苦酸咸，竟說不上什麼味兒來了。」

先后核对：凤姐献调包计欺瞒宝玉（前）→傻大姐遭掴面啼哭躲石后（前）→黛玉遣紫鹃取手绢，独行至沁芳桥偶遇傻大姐，
惊闻金玉合婚冲喜奇耗，五雷轰顶神魄尽散（此刻）→黛玉脚软如踩棉花顺堤乱行，紫鹃寻至搀扶（后）→黛玉贾母房与宝玉
相对傻笑（后）。此刻傻大姐语毕拭泪，黛玉扶石失魂，晴天霹靂，万籁俱寂。

## 器物与环境

- 地点：大观园沁芳桥畔太湖山石后葬花旧址。修竹笼寒，残苔凝冻，花冢泥土残存，沁芳溪水残冰微泮。
- 时令天气：农历正月下旬早春时节；雪霁天寒，朔风割面，薄云惨白。
- 器物：太湖怪石、葬花旧冢遗迹、傻大姐粗布手帕、紫鹃所执湘妃竹色绣帕。
- 现实中会动的：① 沁芳溪碧绿残波随早春风势泛起微粼冷光；② 黛玉身侧万竿修竹竹梢在料峭春寒中簌簌摇曳；③ 黛玉牙白长衫素袖下端受寒风轻卷微摆。

## 排除项

- 前后拍：贾母王夫人凤姐暗室密议调包奇计；袭人进言落泪；珍珠狠掴傻大姐；潇湘馆焚稿断痴情；宝黛对坐傻笑发狂。
- 他回他场：不得出现第23回黛玉葬花欢快共读《西厢》；不得出现抄检大观园搜绣春囊；严禁出现疯癫抓扯等失仪丑态。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；傻大姐衣饰粗拙但不可丑怪荒唐；黛玉必须保持孤标傲世之仙姿品格。
