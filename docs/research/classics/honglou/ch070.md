# 《红楼梦》第70回 林黛玉重建桃花社　史湘云偶填柳絮词

底本：<https://zh.wikisource.org/wiki/紅樓夢/第070回>；读取日期：2026-10-23。

## 情节要点

1. 仲春时节众人齐集潇湘馆重建桃花社，林黛玉作《桃花行》，史湘云偶填《如梦令·柳絮》，引动诸人竞填柳絮词。
2. 暮春东风骤起，外来大雁风筝落入竹梢，众人趁兴取来自制风筝至潇湘馆外敞地齐放，借断线祈消灾祸。
3. 众人各展奇巧纸鸢，探春放软翅大凤凰，宝钗放七连大雁，宝琴放大红蝙蝠，宝玉黛玉各放美人风筝。
4. 黛玉以帕垫手握籰放飞，紫鹃执西洋小银剪子剪线放晦气；探春凤凰与外来风筝绞缠同去，众人散归。

## 选定场面

潇湘馆外空阔敞地平坡：晴空高爽，东风和畅。林黛玉身着淡雅春衫，手垫绣帕紧握竹籰子迎风引线，高空美人风筝
乘风飘飖；紫鹃立于身侧，手执一把精巧西洋小银剪子凑近线轴引线欲铰，面带爽朗笑意；宝玉、宝钗在旁仰面观赏，
空中浮现软翅凤凰与一连七个大雁。具名林黛玉、紫鹃、贾宝玉、薛宝钗四人。选此景因“大观园放风筝”为全书
最明朗欢快之暮春闺阁雅戏，兼具民俗风情与纸鸢高蹈之美，洋溢青春生命力。三处依据：

- 「黛玉笑道：‘把咱們的拿出來，咱們也放晦氣。’」
- 「黛玉聽說，用手帕墊著手，頓了一頓，果然風緊力大，接過籰子來」
- 「向雪雁手中接過一把西洋小銀剪子來，齊籰子根下寸絲不留，咯登一聲鉸斷」

先后核对：填词毕见外来风筝飘落竹梢，众人命退还（前）→丫鬟搬取风筝与线籰，众人出至院外敞地（前）
→丫鬟助放美人风筝升空，黛玉以帕垫手接握竹籰，紫鹃持西洋小银剪欲铰放晦气，宝玉宝钗仰视晴空（此刻）
→紫鹃咯登一声剪断线根，美人化作黑星消失（后）→宝玉剪断美人风筝作伴（后）→探春凤凰与外来喜字绞缠
断线同飞（后）。此刻黛玉正握竹籰迎风，紫鹃持剪欲下，纸鸢高扬碧空，尚未剪断丝线。

## 器物与环境

- 地点：大观园潇湘馆外空阔敞地。近处千竿修竹摇曳生姿，坡前芳草如茵、桃英初谢柳絮微飘，远景见沁芳溪水。
- 时令天气：暮春三月下旬；天气晴爽温润，东风劲吹，万里碧空如洗。
- 器物：竹籰子（竹制绕线轮与细麻绳）、西洋小银剪子、彩绘绢制美人风筝、空中软翅大凤凰与七连大雁风筝。
- 现实中会动的：① 美人风筝在湛蓝晴空中逆风起伏飘飖；② 黛玉手中竹籰绷线随风力紧绷颤动；③ 潇湘馆外万竿翠竹随东风沙沙摇曳。

## 排除项

- 前后拍：清晨怡红院晴雯芳官按炕抓痒；潇湘馆填柳絮词；外来蝴蝶风筝挂竹梢；剪断引线后风筝飘入云端；宝玉踩烂放不起的风筝；三风筝空中绞缠。
- 他回他场：不得出现刘姥姥游园；不得混入第27回芒种节祭花神情景；严禁出现现代塑料尼龙风筝与现代金属轴承线轮。
- 造型禁忌：严禁清代旗袍旗头马蹄袖与金钱鼠尾辫；林黛玉不可作病入膏肓卧榻态。
