# 《红楼梦》第32回 诉肺腑心迷活宝玉　含耻辱情烈死金钏

底本：<https://zh.wikisource.org/wiki/紅樓夢/第032回>；读取日期：2026-10-23。

## 情节要点

1. 史湘云来怡红院见宝玉，拿出翠缕拾得的金麒麟；袭人请湘云代做宝玉的鞋面，湘云微有嗔怪，谈及扇套被铰往事。
2. 贾雨村来访传见宝玉，湘云劝宝玉常会为官作宰之人讲究仕途经济；宝玉大为反感，冷言驳斥，称“林妹妹从不说这些混帐话”。
3. 黛玉偶至窗外隔帘听见宝玉深心赞许，不觉又喜又惊、又悲又叹，感念知己相契却悲己身薄命，泪落沾襟，拭泪抽身离去。
4. 宝玉出门追上黛玉，情极吐露“你放心”，黛玉含羞怔忡离去；宝玉误将袭人作黛玉尽吐肺腑，王夫人处传来金钏含耻投井死讯。

## 选定场面

怡红院廊下窗外：夏日午间，林黛玉独自立在怡红院半卷竹帘的雕花窗外花荫下，隔着碧纱窗听得宝玉在室内正色称赞“林妹妹不说这样混帐话”，黛玉又喜又惊、又悲又叹，眼角泪痕未干，右手微提绢帕拭泪，侧身正欲抽身离去；碧纱窗内隐现宝玉更衣、湘云摇扇的虚影。具名林黛玉一人立于前景，窗内虚映室内情景，无群像。选它是因“隔窗听知己之言”是全书宝黛灵魂相通的最关键情感契合点，窗隔内外，光影与情愫交错，清幽典雅，绝无暴戾打杀或床帏之嫌。三处依据：

- 「不想刚走来，正听见史湘云说经济一事，宝玉又说：“林妹妹不说这样混帐话”」
- 「林黛玉听了这话，不觉又喜又惊，又悲又叹。」
- 「便一面拭泪，一面抽身回去了。」

先后核对：湘云劝宝玉应酬世务仕途经济（前）→宝玉驳斥并赞黛玉不说混帐话（前）→黛玉行至窗外听闻此语，喜得知己又悲叹孤苦薄命，泪洒罗襟（前）→黛玉停步窗外，手持绢帕拭泪，微侧身躯正欲抽身离去（此刻）→宝玉出房追及黛玉诉肺腑“你放心”（后）→宝玉误对袭人倾吐深情、金钏投井噩耗传来（后）。此刻黛玉尚在窗前拭泪欲退，宝玉未出门。

## 器物与环境

- 地点：怡红院正房外廊檐下。朱漆雕花木格窗，糊碧纱，半卷细竹帘，窗前修竹翠掩、芭蕉承荫，青砖阶矶。
- 时令天气：五月初夏午间，天气和暖微熏，蝉鸣隐隐，花木葱郁，微风送凉。
- 器物：素色绢帕（黛玉手中擦泪）、碧纱窗隔扇、半卷竹帘；隔窗隐见桌案茶盏。
- 现实中会动的：① 黛玉裙角与披帛随风微拂；② 窗前竹影与芭蕉叶微风轻摇；③ 窗内透光处室内微影流动。

## 排除项

- 后拍：宝玉出门追至甬道拉住黛玉替她拭泪、诉肺腑“你放心”、宝玉误向袭人跪诉肺腑、金钏投井死讯与宝钗探视。
- 前拍：湘云送戒指、湘云袭人谈做鞋、湘云论阴阳捡麒麟。
- 构图与造型：黛玉不画泣不成声仆地之态；室内人物不画成清晰并列实景（以碧纱窗隔作虚焦背景）；不出现清代旗装或两把头。
