# 《红楼梦》第107回 散余资贾母办丧仪　颁圣诏皇恩续旧世

底本：<https://zh.wikisource.org/wiki/紅樓夢/第107回>；读取日期：2026-10-23。

## 情节要点

1. 贾政入朝听参，朝廷降旨格外开恩：贾赦发台站、贾珍发海疆免死减等，贾政承袭荣国世职。
2. 贾赦贾珍进内拜别辞行，合家抱头痛哭；贾母深明大义，决意倾尽私囊整顿家业。
3. 贾母正房大开铁皮大箱，将数十年私攒积蓄查点分派，均赠长幼各房作为生计与度难盘费。
4. 贾赦、贾政、贾琏等跪听分派，感激涕零叩头谢恩，贾母从容主持维持百年世家门祚。

## 选定场面

荣国府贾母正房堂屋开箱散尽私蓄分赠各房：仲秋晴明，贾母正房堂屋宏敞开阔。八十一岁贾太君身着深褐色长袍
端坐于雕花正榻，慈威并重、从容指挥；堂下大开数十具朱漆铁皮大箱，元宝银锞与绫罗箱匣排列整齐；贾政伏跪
于榻前砖地上感泣叩首，贾琏侧跪垂泪聆听分派。具名贾母、贾政、贾琏三人。选此景因贾母散资为全书贾母大义
担当之极境，尽散浮财以安人心、济度儿孙，慈悲与魄力并具，于世家凋敝中闪烁着博大母性光辉。三处依据：

- 「賈母叫鴛鴦等開了箱柜，將自己歷年積聚的東西，逐一拿出來。」
- 「賈母道：‘……我如今將我所有的東西分派分派，大家散了罷。’」
- 「賈赦賈政賈璉等聽了，都跪在地下，痛哭流涕，口稱：‘老太太何出此言！’」

先后核对：圣旨复贾政世职宽减贾赦贾珍（前）→赦珍入堂拜别生离死别大哭（前）→贾母从容命鸳鸯开锁启箱，
当堂清点数万银两与重物分赠各房度日（此刻）→贾政贾琏感激泣谢痛改前非（后）→贾母探视弥留凤姐（后）。
此刻大箱尽启，老太君神定从容，子孙伏地泣拜。

## 器物与环境

- 地点：荣国府贾母正房荣庆堂。堂内铺设大红毡毯，紫檀正榻前排开数口敞开之朱漆铁皮大箱。
- 时令天气：农历八月仲秋晴爽时节；堂外秋日高朗，晴光自明瓦大窗斜射入室内。
- 器物：朱漆铁皮箱柜、大库元宝银锭、赤金锞子、分派折子底簿、象牙算盘、青瓷盖碗。
- 现实中会动的：① 秋日晴光斜照下，大敞开的银箱上方浮尘在光柱中回旋曼舞；② 廊外秋风吹掠，一两片金黄槐叶自檐前飘落翻转落在门槛内；③ 贾政泣谢叩首时长袍宽袖在红毡上微幅起伏颤动。

## 排除项

- 前后拍：军差羁押贾赦贾珍披枷带锁；发配边疆号哭诀别；凤姐弥留气绝；贾琏私房失窃吵闹。
- 他回他场：不得出现第40回开箱取软烟罗给黛玉糊窗；不得出现元宵开夜宴摆赏银；严禁争产吵闹。
- 造型禁忌：严禁清朝旗袍马褂长辫顶戴；贾政虽袭职，在家不着吉服朝冠；贾母衣着庄重尊贵，不失国公夫人气象。
