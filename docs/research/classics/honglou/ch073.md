# 《红楼梦》第73回 痴丫头误拾绣春囊　懦小姐不问累金凤

底本：<https://zh.wikisource.org/wiki/紅樓夢/第073回>；读取日期：2026-10-23。

## 情节要点

1. 赵姨娘向贾政絮叨挑唆，贾政次日问宝玉功课，宝玉惶恐，晴雯教宝玉装遇贼受惊，怡红院传警彻查。
2. 贾母闻讯严查园中赌博，抓获林之孝家两姨亲等聚赌之首，重责革罚，大观园戒备肃然。
3. 傻大姐于山石草丛间拾得五彩绣春囊，邢夫人撞见没收，由此伏下抄检大观园之惊天巨澜。
4. 迎春乳母聚赌获罪，其媳王住儿媳妇求迎春说情遭拒，绣桔揭出乳母私当累金凤，迎春独读《太上感应篇》，探春平儿至缀锦楼斥退刁奴。

## 选定场面

紫菱洲缀锦楼迎春卧房：初秋日丽，风过池塘。迎春神情恬淡安闲，斜倚于临窗暖榻引枕之上，手执一卷黄绢古抄《太上感应篇》
静心默读，视室内纷扰若无闻；探春身着素雅秋罗长袄端坐紫檀官帽椅，按几正色严词申饬贪婪刁奴，英气夺人；平儿刚掀帘入内，
面容端肃威重，挺身斥退无礼下人并许诺代赎累金凤。具名贾迎春、贾探春、平儿三人。选此景因“不问累金凤”为二姑娘迎春
极懦极淡性格之绝顶写照，与探春刚烈有为、平儿理事得体形成鲜明对照，尽显闺阁风骨与深宅波澜。三处依据：

- 「迎春勸止不住，自拿了一本《太上感應篇》來看。」
- 「探春從紗窗內一看，只見迎春倚在床上看書，若有不聞之狀。」
- 「平兒正色道：‘姑娘這里說話，也有你我混插口的禮！……幾曾有外頭的媳婦子們無故到姑娘們房里來的例。’」

先后核对：傻大姐山石拾囊，邢夫人收存入怀（前）→王住儿媳妇至缀锦楼求情，绣桔司棋逼问累金凤大吵（前）
→迎春不理纷争倚榻展读《太上感应篇》，探春引众人至楼上坐定申饬，平儿掀帘入内厉言弹压（此刻）
→王住儿媳妇满面羞惭喏喏退去（后）→岫烟私告平儿实情，平儿允诺晚间补齐（后）→宝玉探望迎春（后）。
此刻迎春恬退静读，探春正言弹压，平儿立威门阶，纷乱方定。

## 器物与环境

- 地点：大观园紫菱洲缀锦楼上房。轩窗轩敞，设紫檀雕花官帽椅、黄花梨临窗暖榻、斑竹几案，窗外即是紫菱洲清澈湖波。
- 时令天气：八月初秋清晨至午前；天气晴朗高爽，早秋微凉，日光温润洒入纱窗。
- 器物：黄绢封面《太上感应篇》道经、青花茶盅、黄铜火盆火罩（早秋空置）、紫檀茶案。
- 现实中会动的：① 窗外紫菱洲池面微风吹皱一顷秋水，岸边残荷轻摇；② 迎春手中《太上感应篇》书页在指间微动；③ 门前竹青帘帷被平儿掀动微拂。

## 排除项

- 前后拍：宝玉装病怡红院喧嚷；大观园夜查赌博打板子；傻大姐山石捉蟋蟀误拾五彩绣春囊；邢夫人封存囊包；王住儿媳妇坐地撒泼。
- 他回他场：不得出现抄检大观园队伍；严禁出现绣春囊具体图样；不可混入香菱学诗场景。
- 造型禁忌：严禁清代长辫马褂与旗袍两把头；迎春不得作受辱啼哭状，探春不得作泼辣失态状。
