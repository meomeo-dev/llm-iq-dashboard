# 《红楼梦》第36回 绣鸳鸯梦兆绛芸轩　识分定情悟梨香院

底本：<https://zh.wikisource.org/wiki/紅樓夢/第036回>；读取日期：2026-10-23。

## 情节要点

1. 贾母吩咐免除宝玉日常应酬，宝玉如蒙大赦，只在园中消闲，除四书外尽焚杂书；王夫人将袭人月例银升为二两一吊，暗定为准姨娘。
2. 夏日午后大观园寂静，宝钗入怡红院寻宝玉谈讲解倦，见宝玉在榻上熟睡，袭人在榻旁为宝玉刺绣白绫红里的“鸳鸯戏莲”兜肚。
3. 袭人借故出外走走，宝钗顺势坐在绣墩上，见针线活计鲜亮可爱，不由拿起绣针替袭人代刺；黛玉与湘云行至窗外窥见，掩口悄然离去。
4. 宝玉梦中大喊“什么是金玉姻缘，我偏说是木石姻缘”，宝钗闻之怔忡；宝玉往梨香院求龄官唱曲，目睹龄官画蔷与贾蔷放雀，深悟“人生情缘，各有分定”。

## 选定场面

怡红院内室窗前榻旁：夏日正午沉寂，薛宝钗端坐在榻旁绣墩上，体态娴雅，垂首凝神，素手轻提绣针，正专注替袭人代刺绣绷上的白绫红里兜肚，针下彩线正绣着红莲绿叶与五色鸳鸯；榻旁小几上搁着一柄白犀角柄拂尘（白犀麈）；宝玉身着夏日银红纱衫白昼横卧榻上酣睡，盖薄纱被，衣冠齐整；花香袭人，窗外竹蕉静憩。具名薛宝钗、贾宝玉两人，无群像。选它是因“绣鸳鸯”乃全书极具闺阁情愫与深心微澜的传神名画，针线精微，意态端丽，宝玉昼寝衣衫严谨，绝无床帏私密或亵慢之态。三处依据：

- 「原来是个白绫红里的兜肚，上面扎着鸳鸯戏莲的花样，红莲绿叶，五色鸳鸯。」
- 「因又见那活计实在可爱，不由的拿起针来，替他代刺。」
- 「只见宝玉穿着银红纱衫子，随便睡着在床上，宝钗坐在身旁做针线，旁边放着蝇帚子」

先后核对：袭人在榻旁刺绣、执白犀麈驱虫（前）→宝钗进室闲话，袭人借故出门（前）→宝钗落座绣墩，起针代刺白绫兜肚之鸳鸯（此刻）→黛玉湘云行至窗外窥见掩口离去（后）→宝玉梦呓驳斥金玉姻缘，宝钗发怔（后）→梨香院龄官画蔷贾蔷放雀（后）。此刻宝钗刚代刺花瓣针线，宝玉熟睡安恬未发梦语，窗外黛玉尚未至。

## 器物与环境

- 地点：大观园怡红院内室。雕花隔扇、紫檀长榻、天然几案、锦面绣墩；纱窗掩映，日光和煦。
- 时令天气：盛夏烈日当午，庭院寂静无声（仙鹤在芭蕉下睡去），室内水木生凉、沉静清幽。
- 器物：白绫红里兜肚（白绫底子、朱红绫里，绷在小圆绣绷上，绣有半成之鸳鸯莲花）、小剪刀彩线团、白犀麈（白犀角柄拂尘/蝇帚子）。
- 现实中会动的：① 宝钗手中引线穿针的轻微起伏；② 榻旁案头白犀麈细长麈毛在微风中轻拂；③ 窗纱上映照的芭蕉竹影在日光下微摇。

## 排除项

- 后拍：窗外黛玉湘云掩口偷窥招手离去、宝玉梦中大喊“偏说是木石姻缘”宝钗发怔、凤姐提袭人月例、龄官画蔷贾蔷放雀。
- 前拍：王夫人定袭人二两一吊月银、外间丫鬟横七竖八熟睡、袭人跟宝钗说脖子酸。
- 床帏禁忌：宝玉必须白昼齐整身着银红纱衫长裤，严禁画床幔深垂、赤身卧床或被褥凌乱；宝钗严禁画与宝玉有肢体接触。
- 造型禁忌：不画清代旗头两把头与清宫长辫顶戴。
