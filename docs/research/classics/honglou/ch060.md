# 《红楼梦》第60回 茉莉粉替去蔷薇硝　玫瑰露引来茯苓霜

底本：<https://zh.wikisource.org/wiki/紅樓夢/第060回>；读取日期：2026-10-23。

## 情节要点

1. 蕊官托春燕带一包治春癣的蔷薇硝赠芳官，正值贾环来怡红院探宝玉，见硝闻香便从靴桶掏纸索要一半。
2. 芳官舍不得蕊官心意，依麝月之言取自用茉莉粉包了一包，故意向炕上一掷，贾环拾取揣入怀中欢喜而去。
3. 贾环将粉赠彩云被识破是茉莉粉，赵姨娘大怒挑唆，亲自冲进怡红院殴打芳官，引来戏班五女伶混战围攻。
4. 探春李纨尤氏赶来斥退赵姨娘息事宁人；王夫人房中失窃玫瑰露，厨役柳叶渚柳家嫂子与柳五儿受冤牵连。
5. 赵姨娘素日积怨与大观园下层奴仆矛盾全面爆发，为后文抄检大观园伏下深重线索。

## 选定场面

怡红院明间木榻旁：贾环身穿交领锦袍，躬腰曲膝自靴桶中掏出白纸索粉，见芳官拿来纸包便满脸贪喜伸手迎接；
芳官容貌娇俏明媚，身穿水红比甲，微翘下颌含一丝狡黠轻慢，正将调包的茉莉粉小包掷向红木暖榻；宝玉闲坐靠几含笑。
选此场面因“茉莉粉替蔷薇硝”为全回戏眼与矛盾枢纽，以闺阁香粉细物刻画嫡庶形态与少女任性，室内清雅，避开恶斗。
三处依据：

- 「贾环听了，便伸着头瞧了一瞧……便弯着腰向靴桶内掏出一张纸来托着……」
- 「芳官便将些茉莉粉包了一包拿来。贾环见了就伸手来接。芳官便忙向炕上一掷。」
- 「贾环只得向炕上拾了，揣在怀内，方作辞而去。」

先后核对：蕊官托春燕送蔷薇硝至怡红院给芳官（前）→贾环进屋问安见芳官持硝闻香，掏纸央告分一半（前）
→芳官回房取茉莉粉调包成纸包，向炕上一掷，贾环躬身拾取揣入怀中（此刻）→贾环献粉彩云被识破，赵姨娘怒骂
（后）→赵姨娘大闹怡红院撕打芳官，五女伶围攻赵姨娘，探春赶来喝止（后）→玫瑰露失窃柳五儿遭冤枉（后）。

## 器物与环境

- 地点：大观园怡红院明间正厅。雕花落地罩旁设花梨木大暖榻（炕），案上陈设青花瓷茶盏、芳官的妆奩镜盒与素瓷瓶花。
- 时令天气：暮春晴和上午，红日当窗，室内几明窗净，微带花草幽香。
- 器物：贾环自靴桶掏出的折叠白纸、调包好微透粉红的茉莉粉小纸包、花梨木小炕桌、茶钟。
- 现实中会动的：① 芳官掷出的茉莉粉小包在木榻案面上轻轻滑落；② 贾环伸手捡拾纸包时宽袖轻颤；③ 宝玉手中折扇微摇。

## 排除项

- 前后拍：严禁赵姨娘气势汹汹闯入怡红院拍桌打滚；严禁芳官葵官蕊官等女伶围打撕扯赵姨娘；严禁探春赶来厉声训斥。
- 他回他场：不可画柳五儿在厨房受冤被关；不可画彩云与贾环在下房私语；严禁男子薙发留辫与清代满洲旗装两把头马蹄底。
