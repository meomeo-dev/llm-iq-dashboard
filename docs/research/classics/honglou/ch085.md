# 《红楼梦》第85回 贾存周报升郎中任　薛文起复惹放流刑

底本：<https://zh.wikisource.org/wiki/紅樓夢/第085回>；读取日期：2026-10-23。

## 情节要点

1. 贾政（存周）由员外郎升授工部郎中，北静王水溶于王府召见宝玉，传达巡抚吴大人保举嘉许之语。
2. 荣府备酒称贺，正值贾政升官又逢林黛玉生日，王子腾等亲友送新戏班，贾母欢喜定于正厅搭台同庆。
3. 荣国府贾母正厅后厦隔琉璃戏屏摆宴，黛玉盛装宛如嫦娥下界，众姊妹恭让坐上首，台上演《冥升》隐寓宿命。
4. 薛家下人满头大汗急报薛蟠在外省酒肆再惹人命官司，薛姨妈骇然退席奔归，宝钗薛蝌急谋营救。

## 选定场面

荣国府贾母正厅后厦：初冬晴昼，正厅前搭台唱戏，后厦设描金琉璃戏屏隔断，屏前张挂明黄色软烟罗彩幔。
贾母皓首慈容端坐正中雕漆宝座，王夫人、宝琴、岫烟分侍围坐；画面中部十六岁林黛玉换穿簇新罗绮，容光皎洁宛如嫦娥下界，
含羞带笑端坐上席案前；右侧凤姐满头珠翠、着簇新大红织金缎袄执壶布菜凑趣，二门侍女垂手执红漆茶盘侍立。具名贾母、
黛玉、王熙凤三人。选此景因贾政升迁与黛玉生辰双庆后厦开宴，是后四十回极罕见的欢聚极盛时刻。三处依据：

- 「里面为着是新戏，又见贾母高兴，便将琉璃戏屏隔在后厦，里面也摆下酒席。」
- 「那黛玉略换了几件新鲜衣服，打扮得宛如嫦娥下界，含羞带笑的出来见了众人。」
- 「金童玉女，旗幡宝幢，引着一个霓裳羽衣的小旦，头上披着一条黑帕，唱了一回儿进去了。」

先后核对：王子腾家送新戏，贾母命同为黛玉庆生（前）→荣府后厦设琉璃戏屏摆宴，黛玉盛妆宛如嫦娥下界入座首席，
贾母、凤姐与众姐妹围聚看戏（此刻）→外台演《蕊珠记·冥升》，薛家小厮闯入报薛蟠打死人（后）→薛姨妈宝琴仓促
离席（后）→薛姨妈归家惊闻凶耗（后）。此刻吉庆盛极、黛玉神采皎然，满堂锦绣祥和，全无凶煞败兴之音。

## 器物与环境

- 地点：荣国府贾母正厅后厦。高悬琉璃戏屏，设红雕漆平头宴桌、紫檀南官帽椅、明黄撒花软烟罗彩幔，透入庭前微光与戏台彩幡。
- 时令天气：农历十月中旬孟冬正午，天气晴和微寒，室内设地炉熏香暖融。
- 器物：景德镇青花缠枝莲盘盏、赤金双耳爵杯、掐丝珐琅寿字炭熏炉、雕漆托盘、象牙箸。
- 现实中会动的：① 案间掐丝珐琅寿字熏炉口缕缕白烟悠然袅袅升腾；② 琉璃戏屏前所垂明黄软烟罗彩幔受穿堂轻风微幅飘拂；③ 黛玉腰间系着的羊脂玉佩垂穗丝绦随其呼吸微幅轻荡。

## 排除项

- 前后拍：薛蟠酒肆打死当槽伙计；薛家小厮满头大汗闯席报信；薛姨妈骇然变色仓促退席；宝钗金桂哭泣商量营救。
- 他回他场：不得出现大观园芦雪广烤鹿肉联诗；严禁元春省亲大典銮驾仪仗；不可出现公堂审讯刑名枷锁。
- 造型禁忌：严禁清代旗袍、大拉翅、一字头与剃发长辫；男子不可着红顶花翎；女性不可着暴露服饰。
