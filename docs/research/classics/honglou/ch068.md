# 《红楼梦》第68回 苦尤娘赚入大观园　酸凤姐大闹宁国府

底本：<https://zh.wikisource.org/wiki/紅樓夢/第068回>；读取日期：2026-10-23。

## 情节要点

1. 贾琏羁留平安州两月未归，凤姐趁隙布置东厢房，假托往姑子庙进香直趋小花枝巷外宅。
2. 凤姐着国孝家孝中素服登门，巧言自抑、陪笑赔礼，以姊妹同居免外人闲话为由，将尤二姐哄骗接入大观园。
3. 凤姐暗中差旺儿指使张华具状告发贾琏停妻再娶、国孝家孝中强占人妻，大闹宁国府逼勒尤氏与贾蓉。
4. 贾蓉跪求调解，凤姐借势索银五百两，反施毒计命旺儿于路暗害张华以灭口。

## 选定场面

小花枝巷二姐外宅门前庭院：王熙凤下车进院，头戴素白银器，身穿月白缎袄、青缎披风、白绫素裙，满面堆笑；
尤二姐整衣慌忙迎出施万福礼，凤姐双手相搀还礼不迭，携手相挽互致问候；周瑞家的、旺儿家的捧素缎包袱侍立，
平儿静立在后。具名王熙凤、尤二姐、平儿三人。选此景因“素服赚尤娘”是红楼梦最具戏剧张力与笑里藏刀的
经典段落，极具肃穆素雅的白衣反差与心机暗涌。三处依据：

- 「只見頭上皆是素白銀器，身上月白緞襖，青緞披風，白綾素裙。」
- 「俏麗若三春之桃，清潔若九秋之菊。周瑞旺兒二女人攙入院來。」
- 「尤二姐陪笑忙迎上來萬福... 鳳姐忙陪笑還禮不迭。二人攜手同入室中。」

先后核对：凤姐借进香素车出府，兴儿引路至小花枝巷叩门（前）→鲍二家的惊慌报信，尤二姐整衣迎出（前）
→凤姐下车入庭，满身素白银器素衣，笑容温婉，与二姐庭前迎拜、执手相看（此刻）→携手入室，分宾主落座，
周家的奉上尺头簪环拜礼（后）→凤姐涕泣倾诉，二姐倾心引为知己，收拾行李随车入大观园（后）→凤姐大闹宁国府
唆告贾琏（后）。此刻刚进小院执手，尚未入室落座赠礼。

## 器物与环境

- 地点：小花枝巷私宅门前小院。乌油小砖门外停素衣素盖大车两辆，青砖院落狭长清幽，正房台阶下秋砖平整。
- 时令天气：农历十月十五日清晨；深秋霜重风清，天光微阴清冷。
- 器物：素幔车轿、素缎包裹（内备绸缎尺头与金珠簪环）。
- 现实中会动的：① 凤姐青缎披风与白绫素裙摆随清冷秋风微扬；② 门外挽车马匹微打响鼻喷吐淡白霜汽；③ 院角秋树黄叶轻飘拂落阶前。

## 排除项

- 前后拍：鲍二家的惊骇奔逃；室内炕上对坐赠尺头金珠；尤二姐收拾箱笼辞别外宅；凤姐大闹宁国府撒泼拍案；张华公堂打官司。
- 他回他场：不得出现尤三姐自刎血迹；不得混入贾琏、贾蓉或尤氏；严禁秋桐辱骂或尤二姐吞金自尽场景。
- 造型禁忌：王熙凤绝不可穿戴大红吉服与金凤累丝花冠（原文明确强调“全素白银器素服”）；严禁清代旗袍旗头马蹄袖。
