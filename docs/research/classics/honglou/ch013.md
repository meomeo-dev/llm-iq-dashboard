# 《红楼梦》第13回 秦可卿死封龙禁尉　王熙凤协理宁国府

底本：<https://zh.wikisource.org/wiki/紅樓夢/第013回>；读取日期：2026-10-20。

## 情节要点

1. 凤姐梦见秦氏来别，秦氏嘱在祖茔附近置田庄、设家塾，留“三春过后诸芳尽”一句；
   云板连叩四下，惊报秦氏已殁。
2. 贾珍办丧极尽奢华：用薛蟠带来的樯木棺，托大明宫掌宫内相戴权为贾蓉捐五品龙禁尉，
   灵前执事按五品职例。
3. 尤氏旧疾发作，内宅无人主事；宝玉荐凤姐，贾珍拄拐到内宅上房，向邢夫人、王夫人恳求。
4. 王夫人怕凤姐没经过丧事，凤姐应承；贾珍取出宁国府对牌，宝玉接过强递给凤姐。
5. 凤姐到三间抱厦里坐下，想出宁国府五件积弊，本回止于此。

## 选定场面

宁国府内宅上房：贾珍拄拐站着，一手扶拐，一手捏着对牌；宝玉正从他手里接过对牌，
强递向凤姐；凤姐站在原处，眼望坐着的王夫人，尚未伸手；邢夫人坐在近旁。具名贾珍、
凤姐、宝玉、王夫人，邢夫人为陪坐。选它是因“交牌授权”是回目后半的转折，病中的族长、
少年、年轻主妇、长辈的关系一眼可辨，全在室内，无灵柩与床帏。三处依据：

- 「贾珍此时也有些病症在身，二则过于悲痛了，因拄个拐踱了进来。」
- 「贾珍便忙向袖中取了宁国府对牌出来，命宝玉送与凤姐」
- 「宝玉早向贾珍手里接过对牌来，强递与凤姐了。」

先后核对：贾珍进门，众婆娘往后躲，凤姐独自款款站起（前）→贾珍扶拐欲跪安，邢夫人叫
宝玉搀住、命挪椅子，贾珍不肯坐（前）→贾珍恳请，说着滚下泪来，作揖，凤姐还礼不迭
（前）→取对牌，命宝玉送凤姐；凤姐不敢接，看着王夫人，王夫人答“照看照看罢了”（此刻）
→宝玉接牌强递（此刻）→宝玉问她住下还是天天来，凤姐说天天来（后）→贾珍出去，王夫人
等回去，凤姐往抱厦（后）。此刻贾珍不跪、不坐、不作揖、不流泪，凤姐手里还没有牌。

## 器物与环境

- 地点：宁国府内宅上房。依据：贾珍“往上房里来”“进来”，里面是近亲堂客；说完王夫人等“回去”；
  不是荣国府。陈设本回未写，兜底：明堂式上房，炕、靠背椅、茶几；为贾珍挪来的空椅摆在近旁，他不坐。
- 时令：本回未写月份。第14回昭儿报林如海“九月初三日”殁，可推秦氏殁在秋季；另有“腊月”说
  （仅见摘要）。题面不写季节景物，只写室内。
- 器物：对牌形制原文未写，兜底：掌心大小的小牌，不画字；贾珍的拐杖。
- 现实中会动的：① 茶碗热气（兜底）；② 门帘或屏后躲藏者的衣角轻动；③ 凤姐腰间宫绦、衣带轻晃。

## 排除项

- 后拍：凤姐往抱厦、五件积弊、点卯；前拍：秦氏托梦（床帏）、云板、宝玉吐血、灵前痛哭、
  薛蟠献樯木棺、戴权捐官、贾蓉履历。
- 不画秦氏遗体、灵柩、棺木、停灵、瑞珠触柱、尤氏卧床；不画任何床帏。
- 不画贾赦、贾政等男宾入内宅；不画凤姐已接牌、贾珍下跪或落泪。
- 造型：不取87版凤姐的橙金色调（据摘要）；不画清宫剧两把头、花盆底；贾珍不穿官服、不戴顶戴。
