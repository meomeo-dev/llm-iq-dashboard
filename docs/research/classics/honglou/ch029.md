# 《红楼梦》第29回 享福人福深还祷福　痴情女情重愈斟情

底本：<https://zh.wikisource.org/wiki/紅樓夢/第029回>；读取日期：2026-10-23。

## 情节要点

1. 端阳节元春拨银清虚观打平安醮，贾母率众女眷浩荡出行，车马填街；凤姐打翻小道士，贾母怜贫抚慰。
2. 八十余岁老住持张道士（大幻仙人、终了真人）请安，为宝玉提亲十五岁小姐，贾母以八字尚早婉拒。
3. 张道士将通灵宝玉托去供道友瞻仰，回时以大红蟒缎茶盘盛回三五十件金玉贺礼法器，贾母挑出赤金点翠金麒麟。
4. 戏演《白蛇记》《满床笏》《南柯梦》；宝黛因提亲与金麒麟生嫌隙，回园大闹，宝玉砸玉，黛玉剪穗呕吐香薷饮。

## 选定场面

清虚观正楼明间：八旬老道张道士面带和蔼微笑，躬身双手捧着垫大红蟒缎经袱之大漆茶盘；盘中琳琅堆满三五十件珠穿宝贯、金玉法器，其中赤金点翠大金麒麟耀目光华；贾母端坐正中锦椅探身细看，宝玉立于一侧伸手翻弄拨挑。具名张道士、贾母、贾宝玉三人，无群像。选此瞬间因“清虚观捧贺盘”乃全书极盛道场之富丽缩影，金麒麟关键信物由此亮相，祥和华贵，无喧闹砸玉。三处依据：

- 「刚说着，只见张道士捧了盘子，走到跟前笑道」
- 「只见也有金璜，也有玉玦，或有事事如意，或有岁岁平安，皆是珠穿宝贯，玉琢金镂」
- 「用手翻弄寻拨，一件一件的挑与贾母看。贾母因看见有个赤金点翠的麒麟」

先后核对：贾府大队到观拈香拜神（前）→张道士进见请安并借盘捧玉出示众道友（前）→张道士捧大茶盘归还通灵玉并献上满盘金玉法器（前）→贾母看盘、宝玉翻拨挑出赤金点翠金麒麟（此刻）→贾珍来回神前所拈三出戏文（后）→回园宝玉黛玉因亲事口角大闹砸玉剪穗吐药（后）。此刻戏台未鸣锣，宝黛未生嫌隙，满楼清风祥气。

## 器物与环境

- 地点：清虚观正楼看楼大厅。朱栏明窗，雕梁画栋，挂有竹帘纱幛，窗外可俯瞰观内开阔院落与戏台。
- 时辰天气：五月初一端阳节午前；盛夏初临，天朗气清，楼间有穿堂风拂过。
- 节令：农历五月初一端午节前，观中香烟缭绕，钟磬声息。
- 器物：朱漆大茶盘（垫大红蟒缎经袱）、盘中金玉器物堆叠（金璜、玉玦、事事如意、赤金点翠大麒麟）。
- 现实中会动的：① 托盘内赤金点翠麒麟与金玉法器在晨光中流转微光闪烁；② 张道士飘拂白须与道袍宽袖随呼吸微动；③ 楼廊檐角悬挂的黄色道幡随风轻摆。

## 排除项

- 前拍：荣府门前车马拥塞填街、凤姐一巴掌打滚小道士、贾母招手护童给钱、贾珍命小厮向贾蓉脸上啐唾沫。
- 后拍：贾珍报申表戏目《白蛇记》《满床笏》《南柯梦》、宝玉藏金麒麟、回府宝玉砸玉黛玉铰断穗子、黛玉吐药四人对泣。
- 造型与构图：不画戏台唱戏小丑；张道士不画狰狞巫祝；男子不画清代长辫顶戴；贾母不着戏曲厚重蟒袍凤冠。
