# 《红楼梦》第110回 史太君寿终归地府　王凤姐力诎失人心

底本：<https://zh.wikisource.org/wiki/紅樓夢/第110回>；读取日期：2026-10-23。

## 情节要点

1. 贾母病入膏肓自知大限将至，命人开库散财，分派私房细软与众儿孙，回顾一生富贵通达，谆谆交代后事。
2. 贾母在东暖阁寿终正寝，面带从容笑容溘然辞世，享年八十三岁；合府上下号啕痛哭举哀，荣宁二府如天塌地陷。
3. 贾府家底已尽内囊空虚，凤姐抱病勉力操办庞大国公府太夫人丧仪，诸事拮据力不从心。
4. 邢夫人借故吹毛求疵，下人婆子多生怨谤私下咒骂，凤姐心力交瘁“力诎失人心”，末世悲凉尽显。

## 选定场面

荣国府贾母正寝内室东暖阁：初春残冬清晨，窗外阴霾凝云。八十三岁史太君安卧于紫檀吉祥榻之厚锦褥上，慈眉合目，面容泛出从容慈和笑容，
于无疾而终中安详辞世，呈现福寿双全之寿终正寝神采；榻前王夫人悲恸合掌、薛宝钗含泪轻扶锦衾；邢夫人立于榻旁指挥仆妇，
王熙凤重病初起面色枯黄，着斩衰白绢长袄素裙，一手撑榻一手捧奉寿服，神情精疲力竭中透出焦灼痛楚；床前鸳鸯长跪伏榻痛哭失声。
具名贾母、王夫人、薛宝钗、王熙凤、鸳鸯五人。选此景因贾母之死乃贾府彻底崩塌、繁华落尽之终极大转折；老太君含笑辞世之安详尊贵
与王熙凤重病支撑丧务之“力诎”形成强烈对照；严格剔除尸身腐变阴森，定格寿终阖目、合府举哀之庄重肃穆大典。三处依据：

- 「賈母的牙關已經緊了，合了一回眼，又睜著滿屋裡瞧了一瞧。」
- 「王夫人寶釵上去輕輕扶著，邢夫人鳳姐等便忙穿衣……聽見賈母喉間略一響動，臉變笑容，竟是去了，享年八十三歲。」
- 「大家嚎啕痛哭起來。那時賈政等在外，聽得裡面哭聲，知已停舁，賈政等便捶胸大哭進來。」

先后核对：贾母散财分给宝玉黛玉等众儿孙（前）→榻前回光返照含笑阖目辞世，妇人穿衣举哀（此刻）→贾政捶胸哭进停床大殓（后）→
灵堂设祭，凤姐抱病调度百弊丛生（后）。此刻太君刚断气含笑，室内妇眷齐声痛恸，凤姐强撑支应。

## 器物与环境

- 地点：荣国府贾母荣禧堂后东暖阁。设紫檀吉祥床、织锦寿衾、青玉参汤碗、素白帐幔、紫铜火盆、引枕。
- 时令天气：早春寒意料峭天光阴惨；朔风摇撼窗纸，穿堂寒风掠动素帏。
- 器物：锦绣寿衣、百宝绣金寿被、玳瑁眼镜盒、素木香案、青瓷药盏。
- 现实中会动的：① 暖阁门槅悬挂的素白丧幔下角受过堂风轻微掀动；② 吉祥榻旁紫铜火盆中残炭冒出微弱一缕青烟；③ 凤姐手中捧持的白绫寿衣边缘因抽泣动作而微颤。

## 排除项

- 前后拍：严禁出现尸身停灵数日腐臭、散发异味秽气之不雅与惊悚；不得出现贾政男丁捶胸抢地失控哭闹；不得出现婆子门房背后唾骂算账。
- 他回他场：不得出现第13回秦可卿奢靡停灵大出殡；不得出现第95回元妃薨逝宫中哭临；严禁出现妖魔鬼怪阴间判官幻影。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；寿衣与丧服严格依照明代礼制吉服与斩衰麻布规制绘制，严禁披麻戴孝丑怪化。
