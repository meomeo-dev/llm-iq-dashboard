# 《红楼梦》第8回 薛宝钗小恙梨香院　贾宝玉大醉绛芸轩

底本：<https://zh.wikisource.org/wiki/紅樓夢/第008回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。
页面正标题取甲戌本回目；庚辰本回目为「比通灵金莺微露意　探宝钗黛玉半含酸」。

## 情节要点

1. 宝玉向贾母说明秦钟入塾之事；后日随贾母到宁府看戏，趁贾母午睡，绕路去梨香院看养病的宝钗。
2. 薛姨妈让宝玉进里间；宝钗坐在炕上做针线，要细看通灵玉，莺儿说玉上的话与姑娘项圈上的是一对，
   宝钗被缠不过，从衣内取出金锁，宝玉托锁来看，闻到一阵幽香。
3. 黛玉来，说「早知他来，我就不来了」；薛姨妈留茶果，宝玉吃酒，李嬷嬷拦阻，黛玉出言相护，雪雁送来手炉。
4. 宝玉醉回绛芸轩，因枫露茶摔杯，袭人劝阻；次日秦钟拜见贾母，秦业备礼，送入家塾。

## 选定场面

梨香院里间炕上：宝玉把通灵玉摘下递给宝钗，宝钗托在掌上细看，念了两遍「莫失莫忘，仙寿恒昌」，
回头笑问莺儿「你不去倒茶，也在这里发呆作什么」。具名宝钗、宝玉、莺儿。选它是因为玉的形制、五色花纹和
三人站坐关系都有明文，室内、安静，又是「金玉」主题的起点；金锁在下一拍才出现，本场面不画，避免前后拼接。依据：

- 「宝钗托于掌上，只见大如雀卵，灿若明霞，莹润如酥，五色花纹缠护」
- 「宝钗看毕，又从新翻过正面来细看，口内念道」
- 「你不去倒茶，也在这里发呆作什么？」

先后核对：宝玉掀红绸软帘入里间，见宝钗坐炕上作针线（前）→ 宝钗起身含笑，让他在炕沿上坐了，命莺儿斟茶；
宝钗挪近，宝玉凑上，摘玉递在宝钗手内（前）→ 宝钗托玉细看，翻过正面念两遍，回头问莺儿（此刻）→
莺儿嘻嘻笑说两句话像姑娘项圈上的一对；宝钗解排扣，从大红袄上掏出璎珞，宝玉托锁看（后）→ 宝玉闻到
冷香，要丸药（后）→ 黛玉来（更后）。此刻：玉在宝钗掌中；金锁仍藏衣内；莺儿两手空着（茶尚未斟）；
薛姨妈在外间，未进里间；黛玉未到。坐站：宝钗坐炕上，宝玉坐炕沿，莺儿立在炕前地下。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 宝钗 | 少女，比宝玉年长（宝玉称「姐姐」），岁数未写（第4回只称比薛蟠小两岁）。「头上挽着漆黑油光的䰖儿（髻），蜜合色棉袄，玫瑰紫二色金银鼠比肩褂，葱黄绫棉裙，一色半新不旧，看去不觉奢华」；「唇不点而红，眉不画而翠，脸若银盆，眼如水杏」。蜜合色按近白的浅黄、葱黄按近黄的浅绿画，比肩褂是半袖及腰的外褂、边口见金银鼠毛；首饰原文未写，不添。金锁在大红袄内的项圈上，不露出 | 第8回 |
| 宝玉 | 少年，画十来岁。「戴着累丝嵌宝紫金冠，额上勒着二龙抢珠金抹额，穿着秋香色立蟒白狐腋箭袖，系着五色蝴蝶鸾绦」；项上挂长命锁、记名符，通灵玉此刻已摘下在宝钗手中（玉上五色丝绦见第3回）。冠戴出门装，发束冠内，不画小辫 | 第3、8回 |
| 莺儿 | 少女丫鬟。样貌衣冠本回未写；兜底：素色袄裙加深色背心，双丫髻，不强加颜色；立在炕前，两手空着，神情发呆 | 第8回 |

## 器物与环境

- 地点：荣国府东院梨香院薛姨妈住处（第4回「小小巧巧，约有十余间房屋」），薛姨妈在外间，宝钗在里间，
  里间「比这里暖和」，门上吊「半旧的红绸软帘」；炕、炕沿见本回，里间炕上有小炕桌（第7回同一房内写过），
  兜底：炕桌放在宝钗与宝玉之间，桌上有针线笸箩。
- 时令天气：薛姨妈说「这们冷天」，黛玉到时「下了这半日雪珠儿」是下一拍；此刻窗外未写，兜底：阴冷，不画雪。
- 器物：通灵玉雀卵大小，有五色花纹；正面篆字「通灵宝玉　莫失莫忘　仙寿恒昌」，不要求画出可辨文字；
  兜底：一枚椭圆形玉，系五色丝绦，丝绦垂在宝钗掌边。
- 现实中会动的：① 玉下五色丝绦轻摆；② 里间红绸软帘微晃；③ 宝玉冠上绛绒簪缨（后文写作「颤巍巍」）与鸾绦穗子轻颤。
  人物坐姿不变，仅头部与视线可轻微转动。

## 排除项

- 后拍：莺儿说「一对儿」、宝钗解排扣取出金锁、宝玉托锁看、闻冷香要丸药、黛玉来、雪珠、手炉、酒、李嬷嬷、
  斗笠斗篷、醉回绛芸轩、摔茶杯。前拍：路遇詹光单聘仁、吴新登等管事、薛姨妈拉宝玉入怀。
- 金锁与璎珞不出现；不画宝钗宝玉同榻或身体相靠，不画宝玉凑近闻香的姿势（闻香在下一拍）。
- 宝钗不画清宫剧旗头与花盆底，不堆金银首饰；87版为上镜去掉毛皮比肩褂并改袄色（据摘要），本回以原文为准，
  比肩褂有毛边、袄为浅黄。宝玉不画戏曲扮相的雉鸡翎与绒球冠，不画第3回家常小辫。
- 在场只有宝钗、宝玉、莺儿；不画薛姨妈、黛玉、雪雁、李嬷嬷、袭人、晴雯。
