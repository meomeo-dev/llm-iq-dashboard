# 《红楼梦》第52回 俏平儿情掩虾须镯　勇晴雯病补雀金裘

底本：<https://zh.wikisource.org/wiki/紅樓夢/第052回>；读取日期：2026-10-23。

## 情节要点

1. 平儿查明虾须镯系坠儿所偷，为顾全宝玉与怡红院体面，私下交与麝月并叮嘱勿扬，晴雯得知气极欲立刻惩处。
2. 宝玉次日往王子腾府拜寿，贾母特赐俄罗斯国孔雀毛拈线织成的“雀金裘”（雀金呢）大氅御寒。
3. 宝玉晚间归来，后襟不慎被手炉迸出的炭火烧出指顶大焦洞；外间能干织补匠人裁缝皆不认得、不敢揽活。
4. 重病中的晴雯为解宝玉次日正日子还要穿戴之急，强支病体拥被坐起，自告奋勇以孔雀金线连夜界线织补。
5. 晴雯拆开里子、背面钉牢茶杯口大竹弓，用金刀刮松破口，按经纬界线织补，至四更补毕用小牙刷剔出绒毛，力竭倒下。

## 选定场面

怡红院暖阁热炕灯下：晴雯披着灰鼠斗篷拥被坐起，背靠拐枕，面泛烧红，手持背面钉牢茶杯口大竹弓的雀金裘破口处，一手拈针引孔雀金线，就着移过来的铜灯台细心界线织补；宝玉着单衣紧伴炕沿，神情焦急疼惜，一手托茶盅探视；麝月在旁协助拈线。具名晴雯、贾宝玉、麝月三人。选此场面因“勇晴雯病补雀金裘”乃全书展现晴雯刚烈忠勇与通天绝艺之最高光巅峰，孤灯夜雨、病榻金丝，情感纯粹炽热，毫无血腥暴力。三处依据：

- 「一面坐起来，挽了一挽头发，披了衣裳，只觉头重身轻，满眼金星乱迸」
- 「用茶杯口大的一个竹弓钉牢在背面，再将破口四边用金刀刮的散松松的，然后用针纫了两条，分出经纬」
- 「补两针，又看看，织补两针，又端详端详……宝玉在旁，一时又问：‘吃些滚水不吃？’」

先后核对：平儿掩镯，坠儿被撵（前）→宝玉穿雀金裘赴宴，后襟烧焦小洞（前）→送出外间工匠裁缝皆不敢揽（前）→晴雯卸装披衣坐起，背面钉竹弓、金刀刮松破口，引孔雀金线界线细补，宝玉焦急侍立照料（此刻）→四更时分补完，晴雯用小牙刷剔出绒毛（后）→晴雯力竭倒下，自鸣钟敲响四下（后）。此刻晴雯正低头引线织补，宝玉在旁端水探看，织补正在紧要攻坚关头，尚未完工倒下。

## 器物与环境

- 地点：大观园怡红院内室暖阁（设雕花热炕、锦被、拐枕、螺钿小柜、博古架）。
- 时令天气：隆冬寒夜，室外朔风凛冽、夜深人静，室内药香隐约，铜灯台烛光通明。
- 器物：雀金呢大氅（孔雀羽织成，金翠闪烁、碧彩灼烁，后襟有指顶大破洞）、茶杯口大竹弓、孔雀金线、绣针、金刀、小牙刷、铜烛台（带挑亮灯花）。
- 现实中会动的：① 案头铜灯台的红烛火苗随挑灯轻微闪烁；② 晴雯持针上下穿引时孔雀金线的流光起伏；③ 窗外寒风轻吹窗纱竹帘的微幅颤动。

## 排除项

- 前后拍：平儿在窗外与麝月窃窃私语掩镯；晴雯拿簪子戳坠儿手心；贾母赏赐荔色天马箭袖与雀金裘；王子腾府拜寿盛筵；补毕力竭昏厥。
- 他回他场：不可出现林黛玉、薛宝钗或凤姐在场；不可画成群像；严禁出现现代电烙铁、缝纫机或现代剪刀。
- 造型禁忌：严禁满清金钱鼠尾辫、马褂与旗妇两把头；严禁戏曲花脸或油彩戏装；不可穿外氅赴宴装束（此时为室内深夜）。
