# 《红楼梦》第47回 呆霸王调情遭苦打　冷郎君惧祸走他乡

底本：<https://zh.wikisource.org/wiki/紅樓夢/第047回>；读取日期：2026-10-23。

## 情节要点

1. 贾母在正房严辞训诫邢夫人，随后拉薛姨妈、王夫人、凤姐与鸳鸯斗牌取乐，凤姐凑趣彩头逗贾母大喜。
2. 赖大之子赖尚荣摆酒谢客，贾珍、贾琏、薛蟠等齐聚，柳湘莲亦在席；宝玉与湘莲在小书房长谈秦钟修坟与远行之事。
3. 薛蟠误认柳湘莲为风月优伶，席间百般纠缠调戏；柳湘莲怒生一计，假意相约出城北门外幽会。
4. 柳湘莲策马出北门诱薛蟠入荒郊苇塘，下马假令设誓，趁机挥拳执马鞭痛打薛蟠并拖入苇塘泥洼以惩其无赖。
5. 贾蓉等寻回狼狈不堪的薛蟠；薛姨妈宝钗劝阻薛家兴讼；柳湘莲深知薛家势大，遂收拾行囊远走他乡。

## 选定场面

北门外荒郊苇塘柳岸边：柳湘莲骑在一匹矫健骏马上，身着干练骑装，一手提缰一手执鞭微指前方苇荡，回眸冷笑诱引；
薛蟠骑着一匹高头大马紧追其后，前倾伏鞍，满脸醉意喜色。两匹马在郊道黄草间奔驰，背景为连绵起伏的秋风苇塘。
具名柳湘莲、薛蟠两人，无群像。选此场面严格避开殴打残暴，聚焦“冷郎君”与“呆霸王”策马追随的荒诞前奏，
北郊野景萧疏苍茫，双马疾驰动感极强，画面纯净而戏剧张力十足。三处依据：

- 「湘莲又是笑，又是恨，便也撒马随后赶来。」
- 「湘莲笑道：‘快往前走，仔细人看见跟了来，就不便了。’说着，先就撒马前去，薛蟠也紧紧的跟来。」
- 「湘莲见前面人迹已稀，且有一带苇塘，便下马，将马拴在树上……」

先后核对：赖家酒宴，薛蟠纠缠调戏，湘莲忍怒定计（前）→湘莲跨马出城在北门桥上等候（前）→薛蟠醉眼昏花
策大马寻至北郊荒道相会（前）→湘莲策马在前诱薛蟠疾驰奔向苇塘，薛蟠满心欢喜紧随（此刻）→至苇塘边
下马拴树，薛蟠跪地发誓（后）→湘莲挥拳持鞭痛打薛蟠、将其拖入泥苇（后，不画）→贾蓉等寻获送回，
湘莲连夜避走（后）。此刻二人皆在马背疾驰，尚未下马，毫无殴打与血腥。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 柳湘莲 | 青年游侠，二十岁上下；“年纪又轻，生得又美”，容貌俊朗出众，气质冷傲爽侠；穿月白或雪青素缎窄袖骑猎短袍，腰束深色革带，足蹬黑色软皮马靴；头戴黑色软角武生巾；骑于骏马上，英姿飒爽，面带隐忍冷笑 | 第47回 |
| 薛蟠 | 青年阔少，二十余岁；“呆霸王”，体态稍显富态，面色白润带酒晕；身穿华丽大红或石青织锦窄袖圆领长袍，腰悬丝绦荷包；跨骑高头大马，身体前探，眉眼带笑、神情轻佻痴迷 | 第47、4回 |

## 器物与环境

- 地点：京城北门外荒僻野道。土路蜿蜒，道旁衰柳数株、杂草枯黄，远处连绵一片广袤白茫茫的深秋芦苇塘（苇花如雪）。
- 时令天气：农历深秋十月中旬；秋高气爽，北风渐起，晴空万里，郊野萧瑟凄冷。
- 器物：两匹骏马（带精制马鞍辔头）、马鞭两柄（各自手中握持）。
- 现实中会动的：① 远处广袤苇塘中的洁白芦花随秋风波浪般层层起伏；② 双马疾驰奔跑时的马蹄踏风与马鬃飞扬；③ 柳湘莲袍带与薛蟠衣角在烈风中向后翻卷招展。

## 排除项

- 前后拍：贾母上房斗牌洗牌、凤姐算命说笑；赖家酒席柳湘莲唱戏、宝玉书房谈修秦钟坟；薛蟠下马跪地发誓；柳湘莲马鞭殴打、拳打鼻青脸肿、拉薛蟠入烂泥潭灌泥水；薛蟠挨打后卧床痛哭；湘莲收拾行装出京。
- 他回他场：严格禁止任何打斗伤残、流血、皮鞭抽打或泥污狼狈惨相；不得出现赖家宴席或贾府内宅女眷。
- 造型禁忌：严禁清代剃发垂辫与顶戴；严禁清装马蹄袖旗袍；薛蟠不得画成纯粹的老年丑角，柳湘莲不可画作涂脂抹粉的戏子花旦。
