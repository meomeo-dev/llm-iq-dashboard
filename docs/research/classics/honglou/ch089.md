# 《红楼梦》第89回 人亡物在公子填词　蛇影杯弓孺人丧魄

底本：<https://zh.wikisource.org/wiki/紅樓夢/第089回>；读取日期：2026-10-23。

## 情节要点

1. 贾政因河南黄河决口工部承修城工日夜繁剧，宝玉于怡红院静室闭户点香设果，填词焚悼晴雯。
2. 孟冬寒冷，宝玉往潇湘馆探视，见黛玉穿月白小毛皮袄、银鼠坎肩临案濡墨，宝黛相见展颜对谈诗文。
3. 黛玉见旧物触动前尘，检点旧帕旧稿深自感伤；侍书与雪雁偶语提及外界议论宝玉娶亲金玉姻缘之信。
4. 黛玉偶闻讹传，疑心大起，杯弓蛇影致心魄俱丧，自此立意自戕、绝粒不食卧榻转危。

## 选定场面

潇湘馆书斋宝玉探视黛玉临案写词：孟冬微雪，窗外瘦竹凝霜。书斋内生着铜丝罩火盆，满室温润馨香。
画面中部十六岁林黛玉头挽随常云髻插赤金扁簪，身穿月白绣花小毛皮袄、外罩银鼠小坎肩、系杨妃色绣花绵裙，
亭亭玉立于斑竹案侧手悬霜毫临纸沉吟；画面左侧十七岁宝玉穿秋香色缎袍捧白瓷茶盅立于桌前，凝眸细看案头诗帕；
画面右侧紫鹃立于紫檀屏风旁掀起湘妃竹帘，小丫鬟雪雁正用银火箸拨弄盆中炭火。具名林黛玉、贾宝玉、紫鹃三人。
选此景因原著第89回详细工笔勾勒了林黛玉罕见的盛冬闺秀衣装与绝美丰仪，宝黛静好、词墨凝情，
且严格避让后文绝粒咳血之惨状。三处依据：

- 「但见黛玉身上穿着月白绣花小毛皮袄，加上银鼠坎肩，头上挽着随常云髻，簪上一枝赤金匾簪，别无花朵，腰下系着杨妃色绣花绵裙。」
- 「真比如：‘心较十二分多偏弄巧，病如三五步走也难支’……但见他巧笑嫣然，转盼流光，肌肤白润。」
- 「雪雁沏了茶来，宝玉吃着。又等了一会子，黛玉经才写完，站起来道：‘简慢了。’」

先后核对：宝玉在怡红院密室焚词祭奠晴雯（前）→宝玉信步至潇湘馆，黛玉身着月白皮袄银鼠坎肩临案濡墨，
宝黛相见展颜（此刻）→黛玉收泪与宝玉对坐谈论学业诗文（后）→侍书入馆误传亲事之信，黛玉绝粒（后）。
此刻黛玉冰雪晶莹、服饰华美典雅，宝黛静好，毫无绝食濒危与杯弓虚妄之态。

## 器物与环境

- 地点：大观园潇湘馆后轩书房。设斑竹书案、螺钿紫檀椅、青花瓷砚滴、泥金花笺、悬古画挂轴、地设紫铜火盆。
- 时令天气：农历十一月仲冬初寒，窗外竹梢带霜，天色阴晴欲雪，室内炉火融融。
- 器物：白玉镇纸、羊毫提笔、薛涛粉红花笺、景德镇白瓷茶盏、赤金扁簪、紫铜丝罩火盆、兽炭。
- 现实中会动的：① 地面紫铜火盆中点燃的红萝兽炭微微泛起明暗柔和的红炽微光；② 黛玉握笔悬腕间，纤指指尖与狼毫笔尖微幅凝顿起伏；③ 门前湘妃竹细帘丝线流苏受门缝漏入的冬日微风细碎轻颤。

## 排除项

- 前后拍：宝玉闭门焚词悼晴雯；黛玉听闻谣言惊恐疑心、绝粒不食卧床垂危；凤姐贾母忧急探病。
- 他回他场：不得出现黛玉焚稿断痴情；不可画宝玉梦入太虚幻境；严禁枯槁病态与咯血之状。
- 造型禁忌：严禁长辫旗装两把头；严禁黛玉蓬头垢面病容失态；衣冠严格按照原著第89回“月白小毛皮袄配银鼠坎肩”绘制。
