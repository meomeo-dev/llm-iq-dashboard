# 《红楼梦》第54回 史太君破陈腐旧套　王熙凤效戏彩斑衣

底本：<https://zh.wikisource.org/wiki/紅樓夢/第054回>；读取日期：2026-10-23。

## 情节要点

1. 荣国府元宵大开夜宴，贾母高坐花厅设席，贾珍贾琏率众子弟排班按序进酒撒钱。
2. 席间散小戏，婆子领两个门下常走的女先生儿入内坐杌子，手持弦子与琵琶弹唱残唐故事《凤求鸾》。
3. 贾母听开头即猜中情节，当场“掰谎”，痛斥才子佳人陈腐旧套全系落魄文人捏造，败坏大家闺秀名节。
4. 王熙凤执暖银壶上前斟酒说笑解围，戏称讲一回《掰谎记》，效“斑衣戏彩”引得贾母与满堂女眷笑声不绝。
5. 贾母命女先儿对奏《将军令》；三更天寒移入暖阁挤坐饮酒，击鼓传梅行令、放花炮，欢尽方散。

## 选定场面

荣国府大花厅元宵夜宴：贾母歪坐东边透雕夔龙短榻上，倚锦褥引枕含笑听说书；两个女先生儿坐红木杌子上，怀抱弦子（三弦）与琵琶弹唱《凤求鸾》；王熙凤手执一把新暖银壶，笑嘻嘻上前为贾母满斟暖酒、巧舌“掰谎”承欢；宝玉、宝钗、黛玉、湘云、宝琴等姊妹盛装围坐花厅席间欢笑；窗外廊檐悬满花灯，庭院夜空中烟火流光闪烁。具名贾母、王熙凤、两位女先儿（兼林黛玉、薛宝钗等群像）。选此场面因“破陈腐旧套、效戏彩斑衣”乃全书最具元宵年节风雅、伶俐诙谐与贵族天伦乐事之高潮，弹词评话、锦绣满堂、银壶玉盏，欢声笑语，毫无凄凉伤感。三处依据：

- 「便有婆子带了两个门下常走的女先生儿进来，放两张杌子在那一边命他坐了，将弦子琵琶递过去。」
- 「贾母笑道：‘这些书都是一个套子，左不过是些佳人才子，最没趣儿……’」
- 「凤姐儿走上来斟酒，笑道：‘罢，罢，酒冷了，老祖宗喝一口润润嗓子再掰谎。’」

先后核对：贾珍贾琏率子弟捧壶斟酒撒钱（前）→花厅演《八义·观灯》，贾母命戏班暂歇吃滚汤滚菜（前）→女先生儿抱弦子琵琶入座开讲《凤求鸾》，贾母痛斥才子佳人旧套，凤姐执银壶斟酒效斑衣戏彩，满堂哄笑（此刻）→女先儿合奏《将军令》（后）→三更天寒挪入暖阁并桌挤坐，行击鼓传梅令，放花炮烟火（后）。此刻正值花厅正席女先儿抚弦开书、贾母开怀评书、凤姐持壶斟酒巧言承欢之核心高潮，尚未移入暖阁。

## 器物与环境

- 地点：荣国府大花厅（轩敞华贵，设透雕夔龙护屏矮足短榻、锦皮褥、洋漆描金小几、炉瓶三事、盆景花卉、花雕筵席）。
- 时令天气：正月十五元宵深夜，室内灯烛辉煌如昼、暖香扑鼻；窗外回廊满挂宫灯花灯，庭院夜空偶现璀璨花炮烟火。
- 器物：一把精巧新暖银执壶、白瓷酒钟、三弦（弦子）、琵琶、红木圆杌、洋漆描金几、铜香炉（百合宫香）。
- 现实中会动的：① 暖银壶倾注温酒时细细酒线注入玉盏微晃；② 席间炉瓶三事百合宫香青烟与花厅红烛光芒轻微摇曳；③ 窗外庭院夜空中绽放的彩雪烟火与风中彩灯流苏轻拂。

## 排除项

- 前后拍：贾珍贾琏带子弟一溜跪地捧杯敬酒；宝玉私自离席回园探望袭人与鸳鸯；贾母命梨香院十二女伶清唱《西楼·梳妆》；三更移入内室暖阁击鼓传梅放花炮；凤姐说“聋子放炮”笑话。
- 他回他场：不可混入第53回除夕祭宗祠的肃穆青绿铜器；不可出现僧道鬼神；严禁画成外台大戏戏班唱大戏。
- 造型禁忌：严禁清代旗人服饰两把头；严禁男子剃头留长辫；女先儿不得穿破衣烂衫（系门下常走体面艺人）。
