# 《红楼梦》第105回 锦衣军查抄宁国府　骢马使发审荣国公

底本：<https://zh.wikisource.org/wiki/紅樓夢/第105回>；读取日期：2026-10-23。

## 情节要点

1. 贾政于荣禧堂设宴接风，锦衣府堂官赵全奉特旨率锦衣武官突至查抄宁国府。
2. 锦衣官封禁宁府正厅前后各门，羁押贾赦贾珍；北静王西平王奉旨临府宣谕弹压。
3. 锦衣司员查封清点宁府金银首饰、田契庄票与违禁重器，贾府上下仓皇失措。
4. 贾政面色惨白躬奉圣旨查封，百年赫赫望族一朝抄没，大厦倾覆惊心动魄。

## 选定场面

宁国府正厅锦衣卫赵堂官宣奉圣旨封箱贴条：孟夏黄昏，宁国府嘉会堂正厅阴冷森然。锦衣府堂官赵全头戴锦衣冠、
身着织金飞鱼服佩绣春刀，手持朱红印封宣奉谕旨；贾政面色煞白、躬身拱手垂首听旨，神情战栗；阶前锦衣校尉
正俯身以白纸朱印封条封贴漆木大箱。具名赵全、贾政、锦衣校尉三人。选此景因抄家为全书盛衰转折最高顶点，
严格避开内室打砸抢掠与妇孺号哭，取前厅宣旨查封之历史性时刻，官威峻烈与世家陨落震撼人心。三处依据：

- 「忽見賴大急忙走上榮禧堂來回賈政道：‘有錦衣府堂官趙老爺帶領好幾位司官說來拜望。’」
- 「只見北靜王已到大廳，就向外站著，說：‘有旨意，錦衣府趙全聽宣。’」
- 「此時賈政魂魄方定，猶是發怔。……見賈政同司員登記物件。」

先后核对：荣禧堂治席备酒宾客齐集（前）→赵堂官突率锦衣官兵临府宣旨查封宁国府正堂（此刻）→西平王宣旨
提贾赦免连坐荣国府（后）→各司员清点抄没箱笼首饰（后）→凤姐惊厥病危、贾母受惊（后）。此刻大堂肃杀，
圣谕凛冽，贾政躬身噤若寒蝉。

## 器物与环境

- 地点：宁国府前厅嘉会堂。朱漆蟠龙巨柱，正堂横额高挂，前置公案与查封大漆箱，阶下甲士列戟。
- 时令天气：农历四月孟夏向晚，铅云凝滞，堂外暮风渐起，灯火森冷。
- 器物：圣旨黄绫封筒、朱砂封条、紫铜大锁、抄没黄册、赤金箱盒、绣春刀。
- 现实中会动的：① 堂外骤起冷风吹拂正门紫呢夹帘剧烈掀扬摆动；② 锦衣校尉手中白纸朱印封条在穿堂风中微颤飘动；③ 廊前两盏大红宫灯在风中剧烈晃动，投下急促光影。

## 排除项

- 前后拍：内室丫鬟仆妇乱抬乱扯混乱抢掠；邢夫人哭天抢地；凤姐气绝翻滚；焦大在门外遭绑喧嚷。
- 他回他场：不得出现第74回抄检大观园；不得出现江南甄家抄没惨状；严禁撕扯血腥。
- 造型禁忌：严禁清代顶戴花翎、辫发马蹄袖；锦衣官与校尉遵循明制飞鱼服定制，正气威严。
