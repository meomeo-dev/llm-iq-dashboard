# 《红楼梦》第46回 尴尬人难免尴尬事　鸳鸯女誓绝鸳鸯偶

底本：<https://zh.wikisource.org/wiki/紅樓夢/第046回>；读取日期：2026-10-23。

## 情节要点

1. 贾赦贪色欲强纳贾母首席大丫鬟鸳鸯为妾，命邢夫人先向凤姐商议并亲自找鸳鸯试探，鸳鸯低头不语。
2. 鸳鸯避入大观园，在枫树下与平儿、袭人倾诉愤怨，发誓即便当姑子或一死也决不从命。
3. 贾赦遭拒恼羞成怒，召鸳鸯之兄金文翔威逼恐吓，诬指鸳鸯妄图外聘或贪恋少爷。
4. 鸳鸯假意顺从，拉嫂子至贾母正房当众跪哭控诉，袖出剪刀散发断发明志，立誓终身不嫁。
5. 贾母震怒斥责贾赦并迁怒王夫人，探春巧言为嫡母解围，凤姐凑趣说笑缓和气氛。

## 选定场面

荣国府贾母正房堂前：鸳鸯跪在贾母榻前砖地上，满面泪痕神情决绝，左手扯散一把乌黑长发，右手高执一把
锋利铁剪正铰向发丝；榻上贾母惊怒交加气得浑身乱战，王夫人与薛姨妈惊立一旁。具名鸳鸯、贾母、王夫人三人，
兼有惊呆的嫂子。选此场面因“鸳鸯断发抗婚”是全书反抗强权最具冲击力的经典高潮，以断发代断头，悲壮
刚烈之气贯穿全回，毫无血腥殴打却张力十足。三处依据：

- 「原来他一进来时，便袖了一把剪子，一面说着，一面左手打开头发，右手便铰。」
- 「当着众人在regist里，我这一辈子莫说是‘宝玉’，便是‘宝金’‘宝银’‘宝天王’‘宝皇帝’，横竖不嫁人就完了！」
- 「贾母听了，气的浑身乱战，口内只说：‘我通共剩了这么一个可靠的人，他们还要来算计！’」

先后核对：贾赦逼婚、邢夫人找凤姐与鸳鸯碰壁（前）→园中枫树下鸳鸯与平儿袭人痛斥（前）→金文翔逼妹，
鸳鸯佯从（前）→鸳鸯拉嫂子进贾母上房跪下哭诉始末（前）→鸳鸯袖出剪子，左手散发、右手铰发明誓（此刻）
→众丫鬟婆子慌忙上前夺剪挽发（后）→贾母发作乱战、迁怒王夫人（后）→探春入内圆场、凤姐解嘲（后）
→邢夫人挨训（后）。此刻剪锋刚触及青丝，断发半绺尚未被夺，誓词落地，满堂震惊。

## 器物与环境

- 地点：荣国府贾母正堂上房。正中陈设紫檀透雕罗汉榻，上铺锦垫引枕，榻后立雕花漆木大屏风，地面铺平整青砖方砖；几案陈设素雅古董花瓶。
- 时令天气：农历秋深晴朗白昼；穿堂光线明亮，堂内气氛凝重紧绷。
- 器物：锋利铁剪刀一把（鸳鸯手中）、被剪落的半绺黑色发丝（飘落膝前）。
- 现实中会动的：① 鸳鸯手中铁剪寒光随决绝发誓微颤；② 贾母怒极时胸口急促起伏与袍袖微晃；③ 散乱青丝随发誓仰首时在空中轻飘。

## 排除项

- 前后拍：贾赦外书房训斥贾琏；邢夫人求鸳鸯碰钉子；园中枫树下石上平儿、袭人、鸳鸯三女低语；金文翔夫妇私宅密谋；众婆子夺下剪刀替鸳鸯挽发；探春帘外进言为王夫人辩解；凤姐承欢取笑。
- 他回他场：严禁抹脖自尽流血等血腥画面（原文明写仅剪落半绺头发）；不得出现贾赦、贾政或贾琏在场；绝不可画成戏曲花旦造型。
- 造型禁忌：严禁清代旗人两把头与旗装马蹄袖；严禁满清剃发辫子；不可给鸳鸯着艳红大绿俗装。
