# 《红楼梦》第98回 苦绛珠魂归离恨天　病神瑛泪洒相思地

底本：<https://zh.wikisource.org/wiki/紅樓夢/第098回>；读取日期：2026-10-23。

## 情节要点

1. 黛玉临终紧握紫鹃之手含恨气绝归天，彼时荣国府正庆宝玉宝钗合卺大礼，唯仙乐缥缈隐过潇湘。
2. 宝玉神魂稍醒惊悉金玉合婚之假与黛玉已故奇耗，五内俱摧、放声嚎啕大哭，誓死前往潇湘馆吊唁。
3. 贾母等令人用竹椅抬宝玉入潇湘馆，见灵柩素幔、空室凄凉，宝玉抚竹榻抚棺嚎哭断肠。
4. 紫鹃素服相对垂泪，将黛玉复病焚帕、绝笔遗言尽数细诉，宝玉痛悔交加泪尽力竭。

## 选定场面

潇湘馆黛玉灵柩白幔之后：冷雨初歇，窗外残竹疏影森森。堂中设黛玉楠木素棺灵柩，白绫素幔低垂。贾宝玉重病初醒神容惨白消瘦，
身着素白麻布长衫、腰束麻绦、散发无冠；跌坐在灵榻旁的斑竹椅上，单手紧按竹椅靠背，身躯前倾涕泪横流，双目失魂凝视灵前空案；
紫鹃身穿月白孝布素袄青裙，跪坐于灵前蒲团侧旁，泪湿罗帕，正低语哀诉临终焚稿断痴情之字字血泪；案头白瓷爵、素烛残灰微明。
具名贾宝玉、紫鹃二人。选此景因“病神瑛泪洒相思地”乃木石前盟于现世之终局凭吊，抚竹哭灵、知音永诀，以生者之至恸
照映逝者之孤贞，悲意深沉。三处依据：

- 「寶玉聽說，立刻要往瀟湘館來。賈母等只得叫人抬了竹椅子過來，扶寶玉坐上。」
- 「寶玉一到，想起未病之先來到這里，今日屋在人亡，不禁嚎啕大哭。」
- 「紫鵑本來深恨寶玉，見如此，心里已回過來些……便將林姑娘怎麼復病，怎麼燒毀帕子，焚化詩稿，並將臨死說的話，一一的都告訴了。」

先后核对：黛玉含恨绝气咽喉闭目（前）→宝玉醒悟得知调包真相大恸（前）→宝玉乘竹椅至潇湘馆，抚椅面对紫鹃痛哭问遗言（此刻）
→宝玉悲极气塞昏死见黛玉仙姿幻影（后）→合府依礼设灵发引出殡（后）。此刻灵堂香烟未断，生者痛悔，逝魂已远。

## 器物与环境

- 地点：大观园潇湘馆正堂灵寝。青砖冷硬，白绫挽幔重重，窗外翠竹斑驳残叶，苔痕凝碧。
- 时令天气：暮春残夜（或初春风雨初霁），阴云低压，凉风穿堂透幔，寒意入骨。
- 器物：黛玉梓木素柩、灵前素木供案、白瓷香炉（残香三炷袅袅）、素白蜡烛、斑竹扶手椅、草编素蒲团。
- 现实中会动的：① 灵案前白瓷炉中残香升起之一缕淡白青烟在冷堂风中回旋飘摇；② 灵前悬挂之白绫挽幔下摆受微风侵拂徐徐拂动；③ 窗外数丛湘妃斑竹枯梢冷叶随残风瑟瑟摇颤。

## 排除项

- 前后拍：黛玉两眼翻白气绝瞑目死状；李纨探春更殓装裹；宝玉新婚洞房红烛喜被；宝玉昏厥游黄泉遇警幻使者。
- 他回他场：不得出现通灵宝玉佩戴之贵相；不得出现怡红院群鬟簇拥；严禁灵堂过度阴森恐怖或死尸外露。
- 造型禁忌：严禁清代剃发垂辫与马蹄袖长袍；宝玉作魏晋文士素麻丧服，紫鹃纯白孝素，严禁华丽饰物。
