# 《红楼梦》第69回 弄小巧用借剑杀人　觉大限吞生金自逝

底本：<https://zh.wikisource.org/wiki/紅樓夢/第069回>；读取日期：2026-10-23。

## 情节要点

1. 凤姐引尤二姐拜见贾母与众夫人，贾母称赞其标致并许其一年后圆房，二姐移居大观园东厢房。
2. 凤姐暗唆张华再告贾家，察院判张华还银领妻，贾蓉借百金威逼张华父子连夜返籍。
3. 贾琏得贾赦赐妾秋桐，秋桐倚势凌辱尤二姐，凤姐暗施“借剑杀人”挑唆相斗，二姐积郁成疾。
4. 贾琏延请太医胡君荣诊视病势，胡妄断瘀血开出虎狼药致二姐男胎被打下；二姐绝望吞金自尽。

## 选定场面

大观园厢房外间书案前：胡君荣戴医官方巾、着青灰道袍，端坐紫檀案前手拈羊毫拟写药方；贾琏身着素雅交领家常袍，
焦灼立于案侧躬身拱手探问病由；小厮垂手捧铜托盘侍立门边。具名胡君荣、贾琏两人。选此景因本回严格遵循
回避暴力血腥与自残原则，以胡君荣外间草率定论开方为全篇命运急转之枢纽，写尽庸医误人与世情深险，画面端凝克制。
三处依据：

- 「一時掩了帳子，賈璉就陪他出來，問是如何。」
- 「胡太醫道：‘不是胎氣，只是迂血凝結。如今只以下迂血通經脈要緊。’」
- 「於是寫了一方，作辭而去。賈璉命人送了藥禮」

先后核对：内室诊脉，胡太医掀帐窥面神魂失据（前）→掩帐步出内室，至外间书案前研墨展纸（前）→胡君荣案前
悬腕写方，贾琏躬立案侧急问病情，小厮端盘候送药礼（此刻）→胡君荣执方作别，携药礼去（后）→煎服药剂致男胎流下
（后）→贾琏痛骂查拿、胡君荣卷包逃走（后）→秋桐窗下泼骂、二姐饮恨（后）。此刻外间正录医方，内室肃寂，全无死伤血腥。

## 器物与环境

- 地点：大观园东厢房外间客厅。陈设紫檀平头书案、楠木圈椅，案头设松花石砚、紫毫笔、红边药方笺与小水丞。
- 时令天气：冬尽初春残冬（腊月之后），寒气料峭，室内设铜火盆，窗外阴云薄照。
- 器物：药方笺纸、端砚毛笔、红漆药箱、铜托盘（内盛药礼散碎银锭）。
- 现实中会动的：① 紫毫笔尖在药方笺上缓缓勾写墨迹；② 案头火盆炭火隐现微弱红晕；③ 门布帘在回廊冷风中轻微泛动。

## 排除项

- 前后拍：内室掀帐窥面失态；二姐服药腹痛血崩；贾琏大骂追捕胡君荣；秋桐窗下指桑骂槐；二姐吞金自逝与开丧停灵。
- 他回他场：不得出现尤三姐与柳湘莲；不可出现王熙凤或秋桐在场；严禁张华公堂对簿；严禁任何尸身、棺椁、服毒自残画面。
- 造型禁忌：严禁清代旗袍、红缨顶戴与马蹄袖；胡君荣不得作江湖行脚游医摇串铃之相。
