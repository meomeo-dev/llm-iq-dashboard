# 《红楼梦》第40回 史太君两宴大观园　金鸳鸯三宣牙牌令

底本：<https://zh.wikisource.org/wiki/紅樓夢/第040回>；读取日期：2026-10-23。

## 情节要点

1. 贾母率众人大观园晨游，李纨采菊进献，凤姐把一盘各色菊花横三竖四插满刘姥姥一头。
2. 众人游潇湘馆，贾母见窗纱旧了，教辨珍贵古纱“软烟罗”并命以银红霞影纱糊窗。
3. 移席秋爽斋晓翠堂早宴，凤姐与鸳鸯设计捉弄，特备沉重四楞象牙镶金筷与滑溜鸽子蛋，满堂笑绝。
4. 饭后游探春阔朗居室，随后乘棠木舫至缀锦阁水亭宴饮，鸳鸯三宣牙牌令行酒令。

## 选定场面

秋爽斋晓翠堂早宴：刘姥姥满头横插各色菊花，坐在小楠木桌前，双手握着沉重笨拙的四楞象牙镶金筷，伸长脖子吃力撮起小巧圆滑的鸽子蛋；贾母笑得搂住怀中宝玉，凤姐鸳鸯忍俊不禁。具名刘姥姥、贾母、宝玉、王熙凤四人。选它是因乡土幽默与贵胄奢华的喜剧张力达全书之冠，象牙镶金与滑溜鸽蛋极具戏剧性，毫无血腥戾气。依据：

- 「凤姐便拉过刘姥姥，笑道：‘让我打扮你。’说着，将一盘子花横三竖四的插了一头。」
- 「原是凤姐和鸳鸯商议定了，单拿一双老年四楞象牙镶金的筷子与刘姥姥。」
- 「好容易撮起一个来，才伸着脖子要吃，偏又滑下来滚在地下」

先后核对：游园插菊、潇湘馆辨软烟罗（前）→秋爽斋晓翠堂设席，凤姐发象牙镶金重箸、放鸽子蛋，鸳鸯密授言语（前）→刘姥姥念“食量大似牛”，黛玉岔气、湘云喷饭、宝玉滚贾母怀（前）→刘姥姥伸长脖子持重筷撮夹圆滑鸽子蛋欲吞（此刻）→鸽蛋滑落于地被捡出，贾母喝令换乌木镶银箸（后）→众人进探春卧房看法帖大案，乘棠木舫登缀锦阁宣牙牌令（后）。此刻鸽蛋正悬于筷尖滑脱瞬间，满头花朵微颤，满堂欢笑未收。

## 器物与环境

- 地点：大观园秋爽斋晓翠堂。雕梁敞厅，设红木圆桌、小楠木案，堂外竹影芭蕉相映。
- 时令：金秋晴晨，秋阳明净爽朗。
- 器物：老年四楞象牙镶金箸（粗长有角、两端包金）、青白瓷小碗、熟鸽子蛋（白嫩滑圆）、西洋布手巾、翡翠菊花大盘。
- 现实中会动的：① 筷尖圆滑鸽子蛋摇摇欲坠的细微晃动；② 刘姥姥头上插满菊花随伸颈的上下微颤；③ 堂外芭蕉修竹秋风掩映下的光影浮动。

## 排除项

- 前拍：大观楼开锁搬高几、潇湘馆刘姥姥苍苔滑倒、贾母辨软烟罗与霞影纱。
- 后拍：鸽蛋滑落被丫鬟捡去、换乌木镶银箸；探春房中板儿摸佛手敲比目磬；荇叶渚登棠木舫；缀锦阁金鸳鸯宣牙牌令行酒令。
- 误置道具：刘姥姥不戴破毡帽；象牙镶金筷不画成普通竹木筷；不画清代旗袍旗头高底鞋、男子剃发辫子。
