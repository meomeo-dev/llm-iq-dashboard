# 《红楼梦》第3回 金陵城起复贾雨村　荣国府收养林黛玉

底本：<https://zh.wikisource.org/wiki/紅樓夢/第003回>；读取日期：2026-10-20。

## 情节要点

1. 雨村得知朝廷起复旧员，经冷子兴献计，请林如海写荐书给贾政；如海送女入京，雨村同路，后经贾政
   周旋补了应天府缺。
2. 黛玉辞父，随奶娘乘船进京，由荣国府西角门入，过垂花门，在贾母上房与外祖母相拥痛哭，拜见舅母、
   嫂子，迎春三姊妹来见。
3. 黛玉述幼时癞头和尚要化她出家的话；王熙凤在一群媳妇丫鬟簇拥下自后房门笑着进来，贾母笑介绍
   “凤辣子”，凤姐拉着黛玉细问，拭泪，转悲为喜。
4. 邢夫人带黛玉见贾赦，到荣禧堂、王夫人东耳房，王夫人说起“混世魔王”；晚饭后宝玉进来，与黛玉
   初见并摔玉，贾母哄劝；安排黛玉住碧纱橱，次日闻薛蟠打死人命案。

## 选定场面

贾母上房里，黛玉与众人叙话，王熙凤自后房门笑着进来，黛玉连忙起身的一刻。具名贾母、黛玉、王熙凤；
群像为迎春三姊妹、邢夫人、王夫人、李纨、奶嬷嬷与丫鬟媳妇。选它是因为原文对凤姐的首饰衣裙写得最细，
黛玉的谨慎与凤姐的外放对照分明，且无任何动手。宝玉此刻不在场（晚间才回），不选摔玉。依据：

- 「一语未了，只听后院中有人笑声，说：“我来迟了，不曾迎接远客！”」
- 「只见一群媳妇丫鬟围拥着一个人从后房门进来。」
- 「黛玉连忙起身接见。」

先后核对：黛玉进上房，贾母搂哭，介绍舅母嫂子（前）→三姊妹来，归坐，丫鬟斟茶（前）→谈母病，黛玉述
癞头和尚（前）→笑声，凤姐自后房门进来，黛玉起身（此刻，室内，凤姐刚进后房门，黛玉离座站起；贾母
坐姿原文未写，兜底坐着）→贾母介绍“辣子”，凤姐携黛玉手上下打量，用帕拭泪（后）→摆茶果，问月钱（后）。此刻凤姐
未碰到黛玉、手无帕子，贾母尚未开口，茶果未上。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 林黛玉 | 幼女，约六岁（第2回“年方五岁”受聘，一年后母亡；她称宝玉“比我大一岁”；常见推算六至七岁），身形纤弱，“身体面庞虽怯弱不胜，却有一段自然的风流态度”。衣饰未写，因母丧未久（第2回“上月竟亡故”“守制”），兜底：素净浅色衣裙，不戴艳饰；发式兜底：双丫髻或垂髻，不梳成人发髻；起身，双手敛于身前，神色谨慎 | 第2、3回 |
| 王熙凤 | 青年妇人，年岁未写（第2回贾琏“二十来往”，婚后两年）。“头上戴着金丝八宝攒珠髻，绾着朝阳五凤挂珠钗，项上戴着赤金盘螭璎珞圈，裙边系着豆绿宫绦，双衡比目玫瑰佩，身上穿着缕金百蝶穿花大红洋缎窄褙袄，外罩五彩刻丝石青银鼠褂，下着翡翠撒花洋绉裙”；“一双丹凤三角眼，两弯柳叶吊梢眉，身量苗条”，“粉面含春威不露，丹唇未起笑先开”。取色：大红窄袄，深青（石青）外褂，翠绿裙，豆绿腰绦；钗上五股凤口衔珠串（通行注解） | 第3回 |
| 贾母 | 老妇，“鬓发如银”，由两人搀扶迎上黛玉；此刻坐着，笑意；衣冠未写，兜底：素雅深色绸袄，银发梳髻，不戴抹额，不拄龙头拐杖 | 第3回 |
| 三姊妹等 | 迎春“肌肤微丰，合中身材”，探春“削肩细腰，长挑身材，鸭蛋脸面，俊眼修眉”，惜春“身量未足，形容尚小”，均为少女；“钗环裙袄，三人皆是一样的妆饰”，色未写，兜底：三人同款素雅衣裙，各有奶嬷嬷侍立；邢夫人、王夫人、李纨只作侍坐群像 | 第3回 |

## 器物与环境

- 地点：荣国府贾母上房（“正面五间上房，皆雕梁画栋”），室内陈设本回未写。兜底：厅堂里设榻与椅，后房门
  在画面一侧，门帘被丫鬟打起；地下侍立丫鬟媳妇。
- 时令天气：冬季（贾母说“等过了残冬，春天再…”，凤姐外罩银鼠褂）；室内场面，窗外不画雪景。
- 器物：茶盏（丫鬟已斟茶），不画茶果和食盒。
- 现实中会动的：① 凤姐的珠钗、璎珞圈、裙边宫绦与玫瑰佩随步轻摇；② 后房门口被打起的门帘晃动；
  ③ 茶盏上的热气（兜底）。人物不整体位移。

## 排除项

- 后拍：凤姐携黛玉手、拭泪、“该打”、茶果、月钱；邢夫人带黛玉去贾赦处、荣禧堂、王夫人耳房；前拍：贾母
  搂黛玉痛哭、雨村入京、癞头和尚话。宝玉、袭人、摔玉、碧纱橱、薛蟠命案均不画。
- 凤姐不用 1987 版改动（橘红袄、明黄裙、轻薄春装、披帛），按原文大红窄袄、石青银鼠褂、翡翠裙的冬装；
  不画清宫剧“两把头”旗头与花盆底，发髻是珠髻；凤姐眼眉“丹凤三角眼、吊梢眉”不丑化，不画泼辣恶相。
- 贾母不画龙头拐杖、抹额（本回未写）；黛玉不画成成年女子。
