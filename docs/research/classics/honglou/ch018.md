# 《红楼梦》第18回 林黛玉误剪香囊袋　贾元春归省庆元宵

底本：<https://zh.wikisource.org/wiki/紅樓夢/第018回>；读取日期：2026-10-20。
回目取杨藏本；程甲本作“皇恩重元妃省父母　天伦乐宝玉呈才藻”。

## 情节要点

1. 宝玉出园，佩物被小厮解去，黛玉赌气剪未完工的香囊，宝玉解衣取出所赠荷包，二人和好（不入画）。
2. 贾蔷自苏州买回女孩子并聘教习，妙玉受邀之事议定；十月底园内陈设齐备，次年正月十五上元恩准贾妃省亲。
3. 十五日夜贾妃乘金黄绣凤版舆经仪仗入府，更衣后上舆进园，在水边登舟，见“蓼汀花溆”匾灯，
   命只用“花溆”。
4. 元春在行宫受礼，与贾母、王夫人相见垂泪，隔帘见贾政；游园赐名“大观园”，命姊妹与宝玉题诗，
   黛玉代宝玉作“杏帘在望”。
5. 点戏赏赐，丑正三刻回銮，贾妃含泪而去。

## 选定场面

元宵夜园中水道上：元妃端坐在饰有珠帘绣幙的彩舟里，舟行到石港口，她抬头看港上写着
“蓼汀花溆”的匾灯，含笑说“花溆”二字便妥；两岸石栏上点着各色风灯，树上挂着通草花与灯，
侍座太监在旁听着。具名元春，另有执拂太监、侍座太监与划桨内监群像。选它是因元宵灯景在这一
段写得最全，元妃、水、灯同在一景，不必画跪迎与哭泣。三处依据：

- 「忽又见执拂太监跪请登舟，贾妃乃下舆。」
- 「已而入一石港，港上一面匾灯，明现着“蓼汀花溆”四字。」
- 「贾妃看了四字，笑道：“‘花溆’二字便妥，何必‘蓼汀’？”」

先后核对：版舆经仪仗入府，元春更衣后“上舆进园”（前）→舆中看园，叹奢华，执拂太监跪请登舟，
元妃下舆（前）→舟行清流，入石港，见匾灯（此刻）→元妃笑说“花溆”便妥（此刻）→侍座太监下小舟登岸
飞传贾政（后）→舟临内岸，弃舟复上舆，见牌坊“天仙宝境”，命改“省亲别墅”（后）。此刻元妃在舟中，
不在舆中，匾灯尚是“蓼汀花溆”四字，没有改；沿岸只画灯与景，不画跪迎者。

## 器物与环境

- 地点：新园内水道。“清流一带，势如游龙”；两边石栏上皆水晶玻璃各色风灯；柳杏诸树无花叶，
  以通草、绸、绫、纸、绢作花粘在枝上，每株悬灯数盏（底本作“数盏”，程高本作“万盏”）；池中荷荇凫鹭
  是螺蚌羽毛作的灯；舟上有盆景灯、珠帘绣幙、桂楫兰桡；石港上悬匾灯。
- 时令：正月十五夜，太监语“只怕戌初才起身”，故在入夜后；天寒，树无花叶；月色原文未写，不写月亮。
- 兜底：珠帘半卷，使元妃可见；舟形为带篷画舫，篷檐挂灯，不画龙舟。
- 现实中会动的：① 风灯与匾灯的灯焰闪烁，灯影在水面碎动；② 桨划水的波纹；③ 珠帘、流苏随舟行轻摆。

## 排除项

- 后拍：舟临岸复上舆、“天仙宝境”改“省亲别墅”、行宫受礼、见贾母与王夫人垂泪、隔帘见贾政、题诗、
  点戏、赏赐、回銮；前拍：仪仗入府、贾母等路旁跪迎、版舆进大门、更衣。
- 同回他景：黛玉剪香囊、宝玉被解佩物、妙玉、黛玉传纸团代作“杏帘在望”，均不入画。
- 不画贾政、贾母、跪迎者；水中荷花、鸟都是灯，不画成真花真鸟；不画大观楼。
- 造型：不取87版元妃的明代后妃朝服加京剧元素（据摘要）与2010版被议的冠式；不画清宫剧两把头。
