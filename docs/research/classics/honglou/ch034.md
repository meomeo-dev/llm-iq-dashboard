# 《红楼梦》第34回 情中情因情感妹妹　错里错以错劝哥哥

底本：<https://zh.wikisource.org/wiki/紅樓夢/第034回>；读取日期：2026-10-23。

## 情节要点

1. 宝钗托药丸来探视受杖的宝玉，温言劝其好生静养并规劝行事谨慎；宝玉感知体贴，心中畅快。
2. 袭人向王夫人进言，剖陈宝玉年渐长大、男女嫌疑当防，建议设法使宝玉搬出大观园；王夫人深以为然，将宝玉重托于袭人。
3. 宝玉醒来记挂黛玉，借故遣开袭人，命晴雯送两块半新不旧的家常旧帕子给黛玉；晴雯送至潇湘馆，黛玉恍然参透帕中深情寄托。
4. 黛玉悲喜神驰，命掌灯研墨，在旧帕上题写《题帕三绝》；薛蟠吃酒归来与宝钗互生争执，薛蟠赔礼认错。

## 选定场面

潇湘馆内室书案旁：夏夜灯火清辉，林黛玉衣冠齐整端坐于紫檀书案前。案上展铺着晴雯刚送来的两块半新不旧白绢素帕，砚中新磨浓墨，黛玉右手悬腕轻握竹管羊毫饱蘸浓墨，左手抚案，眼角泪光晶莹，凝眸旧帕神思驰荡，正欲走笔题下《题帕三绝》；窗外千竿翠竹随风摇曳，灯影竹影映于窗纱。具名林黛玉一人，无群像。选它是因“黛玉题帕”是全书诗意与木石深情明朗化的至高时刻，红烛研墨，文房端正，高雅脱俗，全无病榻卧床或私密亵慢。三处依据：

- 「林黛玉体贴出手帕子的意思来，不觉神魂驰荡」
- 「黛玉由不得余意绵缠，令掌灯，也想不起嫌疑避讳等事」
- 「便向案上研墨蘸笔，便向那两块旧帕子上走笔写道」

先后核对：宝玉遣晴雯送旧帕（前）→晴雯放下旧帕离去（前）→黛玉细思参透深意，百感交集令掌灯（前）→黛玉端坐案前，研墨蘸笔，悬腕凝眸旧帕正欲落笔（此刻）→黛玉在两方旧帕上走笔题就三绝句（后）→黛玉五内沸然神昏发热（后）。此刻黛玉刚蘸饱浓墨悬笔欲落，帕上墨迹尚未题下。

## 器物与环境

- 地点：大观园潇湘馆内室书斋。紫檀长书案、雕花靠背椅、碧纱窗，窗外修竹掩映，青石叠秀。
- 时令天气：初夏夜间，微风穿竹，室内清凉，四围阒寂。
- 器物：长书案、文房四宝（端砚、紫竹管毛笔、墨锭）、两块折痕犹存的素白旧绢手帕、案头青铜或瓷座油灯（蜡烛）。
- 现实中会动的：① 案头灯芯火焰轻微摇曳跳动；② 窗外千竿修竹绿影随夏夜微风轻摆；③ 黛玉悬腕笔端悬垂浓墨的微颤。

## 排除项

- 前拍：宝玉卧榻臀部青紫敷药、宝钗送药娇羞、袭人向王夫人进言防范、晴雯潇湘馆门前见春纤晒帕、室内黑屋问答。
- 后拍：黛玉走笔写完三绝全诗、五内沸热生病、薛蟠与宝钗口角赌气。
- 构图与造型：黛玉严禁画成披头散发卧床或寝衣内裳；不画卧榻床幔；不出现清代满族发式与服饰；帕上不画可辨长文。
