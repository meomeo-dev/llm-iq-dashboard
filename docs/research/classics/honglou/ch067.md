# 《红楼梦》第67回 见土仪颦卿思故里　闻秘事凤姐讯家童

底本：<https://zh.wikisource.org/wiki/紅樓夢/第067回>；读取日期：2026-10-23。

## 情节要点

1. 薛蟠远行贩货归来，伙计送至两大棕箱私购土物，薛家母子开箱清点姑苏名产玩物。
2. 宝钗将笔墨笺纸、虎丘泥人等土仪分送园中姊妹与长辈；黛玉睹故乡土物触景生情暗自垂泪，宝玉温言开解。
3. 赵姨娘见贾环受赠土仪喜而往王夫人处卖好，反遭冷落讪讪而退；袭人出园探病，见果园老妪扑赶蜜蜂。
4. 凤姐风闻贾琏停妻偷娶尤二姐秘事，设局严讯旺儿与兴儿，查清水月庵私定与平安州内情。

## 选定场面

薛姨妈堂屋内室案前：两个夹板大棕箱已启，薛蟠笑指箱中物件，薛姨妈与宝钗围案观看姑苏土仪，宝钗手持
青纱罩匣细看虎丘泥捏薛蟠小像忍俊不禁；案头铺陈自行人、水银筋斗小儿、沙子灯与泥人戏匣；莺儿侍立在旁
欣喜整理。具名薛姨妈、薛宝钗、薛蟠、莺儿四人。选此景因开箱检视江南风物生机盎然、市井巧作洋溢闺阁，
骨肉天伦祥和亲密，极具世俗生活与工艺情趣。三处依据：

- 「解了绳子，去了夹板，开了锁看时，这一箱都是绸缎绫锦洋货等家常应用之物。」
- 「那一箱是给妹妹带的。亲自来开。母女二人看时，却是些笔，墨，纸，砚」
- 「外有虎丘带来的自行人，酒令儿，水银灌的打筋斗小小子，沙子灯，一出一出的泥人儿的戏」

先后核对：张大爷差小厮搬入两只夹板大棕箱（前）→小厮解绳去夹板开锁，首箱尽是绸缎洋物（前）→薛蟠
亲启次箱，母女笑看姑苏文玩土仪，宝钗持泥小像取笑薛蟠，莺儿整理铺陈（此刻）→宝钗命莺儿与婆子抬箱入园
分送诸处（后）→黛玉思乡对景落泪，宝玉抚慰（后）→凤姐审讯家童（后）。此刻二箱已开，尚未打点送出。

## 器物与环境

- 地点：荣国府东北上薛姨妈幽静房舍内堂。设紫檀大条案、红木靠背椅，案后挂大红幔帐，光影明澈。
- 时令天气：夏末初秋（三伏刚尽），天气晴和微燥。
- 器物：夹板大棕箱两只、虎丘泥塑薛蟠小像、水银打筋斗小人、沙子灯、青纱罩泥人戏匣、线装笺纸香袋。
- 现实中会动的：① 案角水银灌制小儿重心微移缓缓翻滚；② 沙子灯琉璃罩内细沙匀速流落；③ 门外微风吹动青纱帘角与窗幔。

## 排除项

- 前后拍：小厮抬箱绑绳未开；宝钗蘅芜苑分发礼物；潇湘馆黛玉对土仪啼哭；王夫人房中赵姨娘遭批；凤姐拷讯兴儿旺儿之暴怒。
- 他回他场：不得出现尤三姐自刎尸身或柳湘莲出家道袍；不得出现大观园水榭；不得混入林黛玉、贾宝玉或贾环。
- 造型禁忌：严禁清代金钱鼠尾辫、长袍马褂与旗头；薛蟠不可做凶暴斗殴相；器物严禁现代机械发条铁皮玩具。
