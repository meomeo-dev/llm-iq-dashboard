# 《红楼梦》第20回 王熙凤正言弹妒意　林黛玉俏语谑娇音

底本：<https://zh.wikisource.org/wiki/紅樓夢/第020回>；读取日期：2026-10-20。

## 情节要点

1. 宝玉、黛玉、宝钗在黛玉房中说笑，被宝玉房里李嬷嬷骂袭人的吵嚷声打断；凤姐赶来，把李嬷嬷
   哄去吃酒，宝玉安慰病中的袭人。
2. 夜里宝玉替麝月篦头，晴雯进来讥讽。次日贾环在宝钗处赶围棋赌钱，输了抓骰子耍赖，哭着被宝玉
   打发走，凤姐隔窗训斥赵姨娘与贾环。
3. 湘云来了，宝玉随宝钗去见；黛玉赌气回房，宝玉追去赔话，二人说开，黛玉问起他脱掉的青肷披风。
4. 湘云走进黛玉房，把“二哥哥”叫得含糊，黛玉笑她“爱哥哥”，湘云反讽黛玉将来得一个咬舌的
   林姐夫，笑着跑开。

## 选定场面

黛玉房内：宝玉与黛玉刚把话说开，湘云走进来，笑着说“二哥哥，林姐姐，你们天天一处顽”，黛玉
笑她咬舌。具名宝玉、黛玉、湘云三人，无群像。黛玉住处在贾母院内（第3回暂居贾母上房的碧纱橱），
本回只写“房”，不画具体位置。选它是因三人关系靠神态就能读出，湘云爽朗，黛玉含笑打趣，宝玉
夹在中间发笑，没有哭闹，也不涉及衣着问题。三处依据：

- 「二人正说着，只见湘云走来，笑道」
- 「你们天天一处顽，我好容易来了，也不理我一理儿。」
- 「偏是咬舌子爱说话，连个‘二’哥哥也叫不出来，只是‘爱’哥哥‘爱’哥哥的。」

先后核对：宝玉听说湘云来，随宝钗去贾母处相见；黛玉冷笑回房（前）→宝玉追来，说“死活”，宝钗
来推他去见湘云，黛玉独自流泪（前）→宝玉隔“两盏茶的工夫”回来，黛玉抽噎，宝玉讲“亲不间疏，先不
僭后”（前）→黛玉低头半日，问他“怎么倒反把个青肷披风脱了”，宝玉说“见你一恼，我一炮燥就脱了”
（前）→湘云走进来说话，黛玉笑她咬舌（此刻）→宝玉笑，湘云反击，说“咬舌的林姐夫”，回身跑开
（后）。此刻宝钗不在屋内（已把宝玉推走，未回），披风已脱，不在宝玉身上。宝玉、黛玉此刻坐立
原文未写，题面按二人在近旁相对、湘云立于门帘内侧构图。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾宝玉 | 少年，约十二三岁；本回只写他把青肷披风脱了，衣色冠饰未写，兜底：家常素雅袍服，披风不在身上，不戴冠，四围短发编小辫、总编一根大辫，红绦结住，辫上珍珠与金坠脚（第3回写家常、第21回写“在家不戴冠”）；项上通灵玉丝绦可见；含笑，眼望湘云 | 第20、3、21回 |
| 林黛玉 | 少女，约十二岁（据摘要）；“两湾似蹙非蹙罥烟眉，一双似泣非泣含露目，态生两靥之愁，娇袭一身之病”，身形纤弱；刚哭过，兜底：眼圈微红，已止泪，含笑打趣；正月室内，家常素雅袄裙，色不强加 | 第20、3回 |
| 史湘云 | 少女，年岁未写，画成与宝黛相仿；“大笑大说”，笑语爽朗；本回及前文均无衣冠描写（详写服饰的第49回属他回，不取）；兜底：冬日素雅袄裙，合身，发挽整齐，色不强加，不画男装；一手掀帘或扶门框，笑着说话 | 第20回 |

## 器物与环境

- 地点：黛玉卧房（里间有“绣线软帘”，见第19回）；室内陈设本回未写，兜底：窗、几案、炕或床一角，
  窗前是黛玉先前流泪处。湘云自门外进来，门口软帘兜底作掀动状。
- 时令天气：正月，黛玉说“今儿冷的这样”；白天室内，取暖设施原文未写，不强加。
- 器物：青肷披风已脱，不画在场；案上可放书与茶盏，原文未写，不强加。
- 现实中会动的：① 门口软帘随湘云进屋摆动；② 湘云的衣带、发梢；③ 黛玉笑时肩与袖口的轻颤（兜底）。

## 排除项

- 前拍：李嬷嬷拄拐骂袭人、凤姐劝走李嬷嬷、宝钗推宝玉、黛玉流泪与“死活”之争；后拍：湘云跑开、
  黛玉追到门口被宝玉拦住（第21回）、湘云留宿黛玉房。
- 他场：麝月篦头与晴雯撞见、贾环赌钱与赵姨娘、凤姐训环、宝钗与香菱莺儿赶围棋。
- 宝钗不在场；袭人在宝玉房中养病，不在场；青肷披风不穿在宝玉身上。
- 不用 87 版湘云的萝莉式造型（据摘要，原著湘云身段修长，细腰长臂，见第49回）；不画清宫剧两把头；
  男子不画辫子与顶戴；不用戏曲造型。
