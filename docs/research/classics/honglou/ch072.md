# 《红楼梦》第72回 王熙凤恃强羞说病　来旺妇倚势霸成亲

底本：<https://zh.wikisource.org/wiki/紅樓夢/第072回>；读取日期：2026-10-23。

## 情节要点

1. 司棋因私情惊散惧祸卧病，鸳鸯探视立誓保密；鸳鸯顺道至凤姐院中探病，平儿密告凤姐下红成疾。
2. 贾府办寿后内囊罄尽、地税未至，贾琏于东屋向鸳鸯低声赔笑，央求偷运贾母查不着的金银箱笼押银周转。
3. 林之孝向贾琏回禀贾雨村降官之讯，并提议裁减冗仆女婢以减日常开支；贾琏欲惩治来旺无赖幼子。
4. 来旺妇依仗凤姐势焰强为酗酒逆子求娶彩霞，彩霞不甘糟踏含悲向赵姨娘与贾政求援。

## 选定场面

凤姐院东厢平儿房内：午后秋阳斜照，鸳鸯着素雅罗袄端坐临窗暖炕之上，神情自若端肃带笑；贾琏身着素青家常夹袍，
欠身立于椅侧，满脸堆笑、躬身拱手低声向鸳鸯求借贾母金银箱笼以典当银两应急；平儿抱夹袍立于案侧侧首含笑相顾；
小丫鬟正捧青花茶盖碗奉茶。具名贾琏、鸳鸯、平儿三人。选此景因贾琏求借贾母金银家伙是荣国府经济崩溃、外强中干
之决定性铁证，堂堂国公府当家少爷反向老太太贴身大丫鬟奴颜求告，充满末世荒诞与深沉反讽。三处依据：

- 「賈璉忙也立身說道：‘好姐姐，再坐一坐，兄弟還有事相求。’」
- 「暫且把老太太查不著的金銀家伙偷著運出一箱子來，暫押千數兩銀子支騰過去。」
- 「鴛鴦聽了，笑道：‘你倒會變法兒，虧你怎麼想來。’」

先后核对：鸳鸯探视司棋后至凤姐院，平儿拉入东屋悄叙凤姐下红之重症（前）→贾琏进屋见鸳鸯在座，借腊油冻佛手
盘道搭话（前）→贾琏立身命换好茶，躬身拱手求偷运金银箱笼当银抵亏空，鸳鸯含笑推车，平儿从旁插科打诨（此刻）
→贾母房中小丫头跑来唤鸳鸯回房（后）→贾琏进里间找凤姐央求说合（后）→林之孝来回报雨村降职与遣仆（后）。
此刻贾琏正曲意奉承央告，鸳鸯微笑未许，平儿执衣看戏，全无吵闹喧嚣。

## 器物与环境

- 地点：荣国府贾琏凤姐院落东边房（平儿住处）。设临窗暖炕、紫檀木平头案、黄花梨南官帽椅，窗格嵌明瓦透入温润日光。
- 时令天气：八月下旬初秋午后，秋阳明媚，燥气初褪天气清爽。
- 器物：景德镇青花白瓷茶盖碗、红漆小茶盘、家常绸缎夹衣布料、炕几茶盘。
- 现实中会动的：① 小丫头奉上青花茶盖碗时热气如轻烟徐徐升腾；② 贾琏欠身拱手求告时长袍宽袖微带颤动；③ 门前薄纱竹帘随廊下秋风轻晃。

## 排除项

- 前后拍：司棋病榻含泪托孤发誓；平儿附耳密语血山崩细节；里间凤姐卧病假寐要谢礼；林之孝议遣散奴仆；来旺妇倚势强逼彩霞父母。
- 他回他场：不得出现王熙凤病容出镜；不可出现贾母大寿盛宴；严禁箱笼实际搬出府门或当铺交割场面。
- 造型禁忌：严禁清代旗袍、红缨顶戴、长辫马褂；贾琏不可穿大红蟒袍或朝服。
