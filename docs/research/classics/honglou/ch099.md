# 《红楼梦》第99回 守官箴恶奴遭抵戏　腾吏智小官受逼勒

底本：<https://zh.wikisource.org/wiki/紅樓夢/第099回>；读取日期：2026-10-23。

## 情节要点

1. 贾政受命出任江西粮道，抵任后力行廉洁官箴，严禁属员馈送私弊，誓为清官以保祖勋。
2. 官署衙蠹书吏与恶仆长随因断绝浮收油水心怀怨望，相率托病散职、停滞公务以图抗拒。
3. 恶奴李十儿趁签押房夜静公文堆积之际，以“官民兼顾、保全清名”巧言令色逼勒劝降。
4. 贾政见公文壅塞、门庭冷落无从周转，在祖宗门楣与现实吏治潜规则逼迫下默然动摇妥协。

## 选定场面

江西粮道官署签押房内：初冬深夜，窗外枯树阴冷。签押房内陈设简肃庄重，红木官案上公文朱卷堆积成帙，青铜烛台上巨烛高烧、爆起烛花。
贾政端坐于紫檀官帽椅上，头戴乌纱平巾、身着宝蓝云缎圆领常服袍、面容清癯威严而微带疲惫深沉之色，右手悬按朱批狼毫笔，
双目森严逼视案侧；亲随恶奴李十儿身穿赭石青布窄袖仆衫、头顶软巾，微躬身躯侍立案旁下首，低眉垂目、满面堆笑却暗藏黠智，
正屏息吐舌进献“官民兼顾、外面清名里头委屈”之险恶谗言。具名贾政、李十儿二人。选此景因“守官箴”与“吏智逼勒”乃全书极罕见之
官场吏治现实写照，揭示贾府腐朽并非仅在深闺内院，封建清流文官在严酷基层潜规则逼勒下之软弱妥协，极具针砭力。三处依据：

- 「賈政道：‘據你一說，是叫我做貪官嗎？送了命還不要緊，必定將祖父的功勳抹了才是？’」
- 「李十兒回稟道：‘老爺要知道，民也要顧，官也要顧……只要老爺外面還是這樣清名聲原好，里頭的委屈只要奴才辦去，關礙不著老爺的。’」
- 「簽押上呈進一封書子……賈政聽了李十兒一番言語，心想這也是沒法的事。」

先后核对：贾政发牌严禁粮道浮收陋规，属吏长随散班抗议（前）→签押房公文堆积无人承办，贾政独坐焦虑（前）
→贾政秉烛批公文，李十儿伺机上前软硬兼施巧言进言逼勒（此刻）→贾政叹息动摇默许李十儿在外勾连（后）
→州县馈送复行，贾政反遭风闻弹劾（后）。此刻烛火摇曳，正邪攻防，贾政守箴之志正受侵蚀。

## 器物与环境

- 地点：江西粮道道台衙署内签押房。青砖铺地，四壁悬挂山水法帖条幅，陈设端严规整。
- 时令天气：秋末初冬深夜；四境静悄，窗棂微有寒风瑟瑟声。
- 器物：红木翘头大书案、紫檀南官帽椅、堆叠厚厚的线装朱卷文书公牍、青铜荷叶盘烛台、朱砂印泥盒、羊毫狼毫笔架、紫端石砚台。
- 现实中会动的：① 官案青铜烛台上明烛烛火在夜风穿隙中微微摇曳跳动，投射出长长的人影；② 贾政右手悬停之羊毫狼毫笔笔端欲滴未滴之朱砂墨汁在半空微颤；③ 李十儿回话进言时微启之嘴唇与闪烁滴溜转动之眼神。

## 排除项

- 前后拍：粮道衙署大堂击鼓升堂；属员轿夫公然闹罢工；荣国府宝玉宝钗婚后起居；贾政被都察院御史参奏题参。
- 他回他场：不得出现清代顶戴花翎补服；不得出现官场公然收受金银元宝之俗态；不得出现贾府内宅女眷。
- 造型禁忌：严禁长辫马褂与清代官服补子；贾政乃端正方严正统文官，李十儿为典型黠仆，严禁脸谱化小丑妆造。
