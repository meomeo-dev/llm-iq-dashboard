# 《红楼梦》第78回 老学士闲征姽婳词　痴公子杜撰芙蓉诔

底本：<https://zh.wikisource.org/wiki/紅樓夢/第078回>；读取日期：2026-10-23。

## 情节要点

1. 晴雯含恨夭亡，小丫鬟为慰宝玉谎称晴雯登天司掌大观园芙蓉花神，宝玉信以为真，悲思成疾。
2. 贾政在贾母处回明晴雯挪出一事，并率宝玉、贾环、贾兰至客堂，贾政与幕友征作《姽婳词》以吊林四娘，宝玉成长歌大获激赏。
3. 宝玉归园，备办群花之蕊、冰鲛之縠、沁芳之泉、枫露之茗四样晴雯生前所喜素洁之物，夜至怡红院后芙蓉花池畔设祭。
4. 宝玉于月下芙蓉花前悬挂诔文，焚香酹茗痛读千古奇文《芙蓉女儿诔》；读毕黛玉自芙蓉花阴转出赞叹，相与修改定格“茜纱窗下”。

## 选定场面

怡红院后池畔芙蓉花阴前：深秋月华清冽，木芙蓉繁花盛放如锦绣云霞。宝玉身着月白素绢交领长袍，腰系淡青素绦，立于白玉香几前，
双手徐徐展阅写于冰鲛縠上的长卷《芙蓉女儿诔》，仰天含泪朗诵，神情孤绝深痛；几案上宣德白瓷炉燃起信香一缕，水晶盘陈设群花之蕊
与青白瓷瓯；盛开的粉白木芙蓉花树阴下，林黛玉一袭素淡紫绡长裙、外罩月白风露披风，自花影幽岩后含笑款步转出。具名贾宝玉、
林黛玉二人（侧畔置捧香小丫鬟）。选此景因“芙蓉女儿诔”为大观园群芳命运之崇高挽歌，黛玉花下隐现与诔文末句互成谶语，凄美绝伦。三处依据：

- 「用晴雯素日所喜之冰鮫穀一幅楷字寫成，名曰《芙蓉女兒誄》，前序後歌。」
- 「于是夜月下，命那小丫頭捧至芙蓉花前。先行禮畢，將那誄文即挂于芙蓉枝上，乃泣涕念曰」
- 「忽聽山石之後有一人笑道：‘且請留步。’……卻是個人影從芙蓉花中走出來」

先后核对：贾政聚众征作《姽婳词》，宝玉展才获赞（前）→小丫鬟戏言晴雯掌管芙蓉花神，宝玉笃信备四样雅物（前）
→夜月下宝玉设几池畔，悬冰鲛縠诔文于芙蓉枝，焚香展卷痛诵诔文，黛玉自花阴缓步而出赞叹（此刻）
→二人推敲改“红绡帐里”为“茜纱窗下，我本无缘”（后）→黛玉惨然变色（后）→迎春出嫁消息至（后）。
此刻深秋月明，宝玉展縠诵诔，黛玉步出花阴，天人合一。

## 器物与环境

- 地点：大观园怡红院后近水池畔芙蓉花树前。池边数株木芙蓉盛开如锦霞，临池太湖奇石嶙峋，池水澄碧倒映花影与明月。
- 时令天气：秋深露重之夜（蓉桂竞芳之月）；天宇晴澈，清月高照如水，秋夜微风送寒。
- 器物：冰鲛縠楷书诔文长卷、宣德白瓷香炉、白玉几案、水晶浅盘盛群花之蕊、青白瓷瓯盛枫露茶。
- 现实中会动的：① 临池木芙蓉花树枝头盛开的粉白重瓣花朵与秋叶在夜风中轻颤；② 白玉几上宣德瓷炉升腾起的信香青烟如丝缕般飘散入月色；③ 池塘水面倒映的中天秋月水波微荡，一两片零落芙蓉花瓣随流水悠悠浮移。

## 排除项

- 前后拍：王夫人向贾母禀告晴雯“女儿痨”；客堂作《姽婳词》贾赦贾珍聚饮；小丫鬟随口扯谎芙蓉花神；晴雯火化收骨；黛玉闻“茜纱窗下”惊悚退去。
- 他回他场：不得出现恒王出征战场厮杀；严禁出现灵堂祭奠、死尸或招魂巫术场面；不可混入第23回共读西厢情景。
- 造型禁忌：严禁清代旗人发型顶戴衣饰；宝玉不可穿色彩艳丽之正装大红礼服；黛玉不可作惊悚鬼魅之状。
