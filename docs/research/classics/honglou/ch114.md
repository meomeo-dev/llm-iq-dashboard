# 《红楼梦》第114回 王熙凤历幻返金陵　甄宝玉降心归大道

底本：<https://zh.wikisource.org/wiki/紅樓夢/第114回>；读取日期：2026-10-23。

## 情节要点

1. 王熙凤弥留之际胡言乱语吵闹要船要轿回金陵“归入册子”，在贾府落魄凄清中撒手人寰，应验太虚幻境薄命司册子判词。
2. 贾政守孝于外书房，奉皇旨护送贾母灵柩南下金陵祖茔安葬；贾琏抱病沿途料理舟车丧务，家中拮据凋敝。
3. 江南甄家（甄应嘉）蒙恩复职，江南旧族盛衰荣枯互见，甄宝玉亦随同北上，与贾府长辈在客堂相见。
4. 贾宝玉在客堂外书房与相貌酷似自己的甄宝玉相晤长谈，见其谈吐一意钻研八股功名、降心归附世俗仕途，宝玉顿悟同类异道之幻灭，更坚归大道出尘之念。

## 选定场面

荣国府外书房客堂：暮春清冷正午，庭院绿荫渐浓，廊下停放着预备南下金陵的素白仪仗舆具。客堂正中设紫檀案几与太师椅，
贾政身穿素麻斩衰守孝长袍，面容清瘦衰迈，端坐案后细看南下金陵扶柩舆图与朝廷勘合；贾琏着素白孝服躬身侍立案侧，
手捧灵柩沿途舟车脚力支应账册，神态疲惫凄惶；客堂另一侧窗明几净处，甄宝玉身穿宝蓝织锦箭袖圆领袍、外罩石青缎坎肩，
容貌果与贾宝玉如同脱胎一人，正正襟危坐向贾宝玉抱拳揖礼，高谈圣贤性理与禄蠹仕途；贾宝玉着月白素绫交领袍立于书案旁，
面色微带冷笑与怅惘，听其陈言如隔云泥，彻底顿悟红尘假相、降心归向出世大道。具名贾政、贾琏、甄宝玉、贾宝玉四人。
选此景因“历幻返金陵”与“降心归大道”为全书自京华大繁华转回金陵大寂灭的关键枢纽；贾母灵柩南归与真假宝玉客堂相晤，
将全书“真亦假时假亦真”的哲学主题推向终极破局；避开凤姐咽气停尸之凄凉，定格客堂议柩、真假相见悟道之高雅深邃。三处依据：

- 「璉二奶奶沒有住嘴說些胡話，要船要轎的，說到金陵歸入冊子去……人都有個定數的了。」
- 「賈政守著老太太的孝，總在外書房……叫他辦理喪事。自己回明了賈政去，然後行事。」
- 「甄少爺在外書房同老爺說話，說的投了機了……相貌倒還是一樣的。只是言談間看起來並不知道什麼，不過也是個祿蠹罷了。」

先后核对：王熙凤弥留吵闹归册，气绝历幻返金陵，贾琏痛哭失措（前）→贾政外书房商议奉旨护灵柩南下，甄宝玉客堂来访，与贾宝玉相晤悟道（此刻）→
贾琏打点行装护柩南下金陵（后）→惜春决绝辞绝家门，宝玉决意归彼大荒（后）。此刻客堂肃立，真假对视，机锋顿开，大道归一。

## 器物与环境

- 地点：荣国府外书房退步客堂。设紫檀平头大案、黄花梨太师椅、素纱屏风、南下金陵水陆舆图、文房四宝、青铜香炉。
- 时令天气：暮春正午天朗气清；树影穿窗，廊外微风吹动南归素白仪仗引幡。
- 器物：金陵水陆舆图、灵柩开销支应折子、端砚宣纸、素漆引魂旌幡、青花茶盏。
- 现实中会动的：① 窗外廊下南下灵柩的素白引幡在暮春清风中徐徐舒卷摆动；② 案头青铜香炉中一柱细烟在穿堂风里曲折飘拂；③ 贾政手持的金陵舆图宣纸边缘在微风中轻微泛起波纹。

## 排除项

- 前后拍：严禁出现王熙凤病榻断气、双目圆睁形销骨立之死尸惨相；严禁出现纸扎轿马焚烧之凄厉阴森；不得出现家仆追债争吵。
- 他回他场：不得出现第2回冷子兴演说荣国府；不得出现第56回贾夫人提及甄宝玉骄纵；严禁出现妖僧魔道作法。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；甄宝玉与贾宝玉容貌酷肖但气质迥异，甄宝玉须现俗世端方禄蠹相，贾宝玉须现孤标超然出世相。
