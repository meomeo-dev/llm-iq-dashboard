# 《红楼梦》第76回 凸碧堂品笛感凄清　凹晶馆联诗悲寂寞

底本：<https://zh.wikisource.org/wiki/紅樓夢/第076回>；读取日期：2026-10-23。

## 情节要点

1. 凸碧堂山顶夜宴，贾母命于深桂幽处吹笛，呜咽凄清之声随风荡漾，引动贾母凄然落泪，诸人皆感凄切。
2. 众人因寒露更深相继告退，贾母倦极下山安歇，月夕盛宴冷清散场，大观园复归万籁俱寂。
3. 史湘云与林黛玉难遣凄清，携手至水凹深处近泉水榭“凹晶溪馆”，二人倚栏凭虚赏月，分韵联句作五言排律。
4. 湘云拾石击水惊起白鹤掠波，得“寒塘渡鹤影”绝唱；黛玉冥思相对“冷月葬花魂”诗谶；妙玉自石后走出相邀并续成全篇。

## 选定场面

大观园凹晶溪馆临水月台：中秋深夜残月照水，池光荡漾如万顷琉璃。史湘云手执白绢团扇与桂花细枝，半倚朱红白石围栏，昂首英姿朗发；
林黛玉身披素雪月华缎披风，倚坐于青藤绣墩之上，微仰螓首凝思吟出“冷月葬花魂”千古绝唱；清池中一只洁白仙鹤展开双翼破水惊飞，
掠过荷波激起环环银色涟漪；远处假山石后幽竹掩映间，妙玉一袭缁衣静立驻足微笑赞叹。具名林黛玉、史湘云、妙玉三人。选此景因
“凹晶馆联诗”为全书诗性美学与红楼女儿孤高清拔品格之至高巅峰，“鹤影”与“花魂”双璧辉映，极富凄清空灵之仙意。三处依据：

- 「只見一個在里邊假山石上坐著，一個在外邊池沿上坐著，看月色在池中沉浮。」
- 「只聽那黑影里嘎然一聲，卻飛起一個大白鶴來，直往藕香榭去了……因聯道：窗燈焰已昏。寒塘渡鶴影」
- 「黛玉只看天，不理他，半日，猛然笑道……因對道：冷月葬花魂。」

先后核对：凸碧堂月下品笛凄咽，众人散席贾母归房（前）→黛玉湘云下山漫步，往凹晶馆近水临轩（前）
→石投池水惊飞白鹤掠水，湘云朗吟“寒塘渡鹤影”，黛玉仰首对出“冷月葬花魂”，妙玉自石后走出（此刻）
→妙玉赞二语清奇悲凉，邀二人往栊翠庵喝茶（后）→妙玉笔录并续十三韵（后）→天明黛湘回房（后）。
此刻清鹤掠波，水波微澜，二女脱口吟绝唱，妙玉转出太湖石。

## 器物与环境

- 地点：大观园凹晶溪馆临水白石敞台。紧邻清澈湖水，水面残荷荇藻沉浮，背靠峻拔太湖假山石，幽竹千竿。
- 时令天气：八月十五中秋子夜转后半夜；明月西斜水气苍茫，寒露浸衣，夜风微凉而池水如镜。
- 器物：白绢绣白鹤团扇、折枝丹桂花、白石凭栏、紫藤软榻绣墩、池中惊飞之大白仙鹤。
- 现实中会动的：① 仙鹤自池面振翼掠水腾飞，在荷池水面激起一圈圈扩展的银白涟漪；② 凹晶馆临水朱栏外一丛残荷与衰柳在深夜微风中轻轻摇曳；③ 妙玉素色缁衣长飘带随水面夜风微拂。

## 排除项

- 前后拍：凸碧山庄桂树阴下吹笛贾母落泪；贾赦跌脚；黛湘二人回栊翠庵吃茶写字；妙玉自拟十三韵墨迹；天明醒来黛玉咳痰。
- 他回他场：不得出现大观园开诗社热闹作诗；不可混入芦雪广联诗烤鹿肉情景；严禁出现二人抱头痛哭场景。
- 造型禁忌：严禁清代旗人妇女长袍大拉翅；妙玉不可作衰朽苦僧相；黛玉不可作病弱濒死态。
