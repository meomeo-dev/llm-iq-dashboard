# 《红楼梦》第71回 嫌隙人有心生嫌隙　鸳鸯女无意遇鸳鸯

底本：<https://zh.wikisource.org/wiki/紅樓夢/第071回>；读取日期：2026-10-23。

## 情节要点

1. 八月初三贾母八旬大庆，宁荣两府连开八日筵宴，皇室亲王诰命纷至，元春亦赐金寿星与沉香拐。
2. 尤氏夜游大观园见角门夜不闭户，传管夜婆子反遭顶撞；凤姐得知欲重惩，邢夫人当众求情使凤姐难堪生隙。
3. 园内起更散席后，鸳鸯深夜独自回园，行至山石大桂树阴下，无意撞破司棋与姑表弟潘又安月下私会。
4. 司棋恐慌伏地痛哭哀求，潘又安磕头求饶，鸳鸯慨然许诺守口如瓶，脱身出角门回房。

## 选定场面

大观园湖山石后大桂树阴下：更深人静，微月半天。鸳鸯自青砖甬路漫步转过假山石，忽闻衣衫窸窣声而警觉驻足；
月光树影斑驳间，迎春贴身丫鬟司棋穿红裙梳鬅头，正惊惶拉扯裙角往树石深处藏躲；小厮潘又安蜷伏于太湖石后阴影中；
远景角门值班房透出微黄灯火。具名鸳鸯、司棋、潘又安三人。选此景因“无意遇鸳鸯”为本回题眼，以月夜深园之幽寂
反衬大庆背后的松懈溃散，纯用光影与偶遇悬念造势，严格规避私情狎昵与风月之态。三处依据：

- 「此時園內無人來往，只有該班的房內燈光掩映，微月半天。」
- 「行至一湖山石後大桂樹陰下來。剛轉過石後，只聽一陣衣衫響，嚇了一驚不小。」
- 「鴛鴦眼尖，趁月色見准一個穿紅裙子梳鬅頭高大丰壯身材的，是迎春房里的司棋。」

先后核对：贾母寿筵起更散席，园内幽寂、角门未锁（前）→鸳鸯独行入园，步下甬路循微草至大桂树旁（前）
→转过湖山石，闻衣衫响动惊骇驻足，趁微月辨认出红裙鬅头的司棋与石后躲闪的潘又安（此刻）→鸳鸯笑语戏呼，
司棋急奔出来双膝跪地拉袖苦求（后）→潘又安爬出连连磕头（后）→角门婆子呼唤上锁，鸳鸯应承脱身（后）。
此刻鸳鸯刚驻足凝眸，二人惊觉避匿，尚未奔出跪求。

## 器物与环境

- 地点：大观园沁芳亭附近湖山石后。巨幅漏透太湖石掩映，一株大桂树枝繁叶茂，远处隐见竹影与虚掩角门值房窗火。
- 时令天气：农历八月初三夜起更时分；初秋月夜，微风送凉，“微月半天”，桂花初绽散发幽香。
- 器物：太湖山石、桂树繁枝、远景值房纸窗青灯。
- 现实中会动的：① 大桂树繁密枝叶与碎花在初秋凉风中婆娑摇曳；② 司棋鲜亮的大红裙摆在树石草丛间急促掠摆；③ 半空微月浮云缓缓流移、地表树影微荡。

## 排除项

- 前后拍：宁荣两府寿堂摆大席点戏；尤氏与大观园夜班婆子争吵；邢夫人当众羞辱王熙凤；司棋与潘又安跪地哀告哭求；角门婆子落锁。
- 他回他场：不得出现抄检大观园绣春囊；不得出现贾母受贺拜寿群像；严禁任何肌肤相亲或苟且狎昵动作描写。
- 造型禁忌：严禁清代旗装旗头；小厮不可作剃发长辫马褂打扮；司棋衣饰不可作贵族命妇盛装。
