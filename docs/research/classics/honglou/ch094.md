# 《红楼梦》第94回 宴海棠贾母赏花妖　失通灵宝玉知命蹇

底本：<https://zh.wikisource.org/wiki/紅樓夢/第094回>；读取日期：2026-10-23。

## 情节要点

1. 怡红院枯萎数月之西府海棠于十一月寒冬奇迹怒放，满府耸动；贾母认作祥瑞，遂降谕在院中大开海棠喜宴。
2. 贾母携王夫人、探春、黛玉诸人亲赴怡红院赏花，命宝玉赋诗志喜；平儿代凤姐送大红洋缎两匹缠裹树干贺瑞。
3. 盛宴散席归房更衣，宝玉骤然发觉颈上通灵宝玉不知去向，袭人、麝月惊骇欲绝，合院翻箱倒柜秘密大索。
4. 探春闻讯密命锁闭园门防闲，平儿巧探贾环虚实；王夫人与病中凤姐得知大骇，宝玉失玉失魄始呈呆滞。

## 选定场面

怡红院前庭与抱厦廊下：十一月隆冬雪后初晴，朔风料峭。庭中枯槁海棠竟凌寒异样怒放，满树绯红灼灼夺目，树干缠裹大红洋缎
飘带为贺；贾母身着玄狐皮裘端坐廊下软椅之上，满面惊奇欣悦仰观奇花；宝玉着狐腋箭袖、罩元狐腿石青外褂，手捧红笺诗稿
恭谨侍立石阶前；平儿着品月罗袄捧朱漆锦盒笑语承应；远景探春、黛玉等群芳环侍雕栏画廊。具名贾母、贾宝玉、平儿、林黛玉
四人。选此景因“冬日开花妖”为贾府盛极而衰、末世回光返照之宿命表征，寒冬枯木吐艳繁华至极，转瞬引爆失落通灵玉之奇祸，
强烈的色彩反差与戏剧张力兼具，且场面华贵雅致。三处依据：

- 「那賈母高興，叫人傳話到廚房里，快快預備酒席，大家賞花。」
- 「忽然聽說賈母要來，便去換了一件狐腋箭袖，罩一件元狐腿外褂，出來迎接賈母。」
- 「平兒笑嘻嘻的迎上來說：‘我們奶奶知道老太太在這里賞花，自己不得來，叫奴才來伏侍老太太，太太們，還有兩匹紅送給寶二爺包裹這花，當作賀禮。’」

先后核对：怡红院枯海棠冬日吐蕊（前）→探春宝玉争观称异（前）→贾母闻讯大喜传摆海棠宴，群芳齐集，宝玉呈诗，平儿送红缎
缠树（此刻）→贾母尽欢散席还房（后）→宝玉更衣惊觉失落通灵玉，满屋翻箱倒柜密索（后）→探春封门大查（后）。此刻奇花
怒放，宴席正盛，大祸尚未发作。

## 器物与环境

- 地点：大观园怡红院庭前与抱厦穿堂。枯枝反季怒放西府海棠一株，前庭残雪未尽，廊下设软椅紫檀宴桌果馔。
- 时令天气：农历十一月隆冬雪后初晴；晴光映雪，朔风清寒。
- 器物：大红洋缎两匹（缠绕树干）、泥金红笺诗稿、紫铜雕花温酒壶、朱漆雕花果盘、青白瓷茶盏。
- 现实中会动的：① 海棠树梢密缀绯红花瓣在初冬寒风中微微颤动；② 缠裹树干的大红洋缎系带随风轻柔翻卷飘拂；③ 廊下石桌紫铜温酒壶壶口白气缕缕袅袅升腾。

## 排除项

- 前后拍：宝玉卧室更衣失玉；袭人麝月面如土色翻箱倒柜；探春下令落锁封园搜查；平儿盘问贾环；岫烟往栊翠庵求妙玉扶乩。
- 他回他场：不得出现第37回海棠诗社盛况；不得出现大观园抄检；严禁出现下人搜查粪坑茅厕污秽情景。
- 造型禁忌：严禁清代暖帽顶戴与两把头大拉翅；全员冬装依明代勋贵狐裘锦缎定制；人物仪态端雅开朗。
