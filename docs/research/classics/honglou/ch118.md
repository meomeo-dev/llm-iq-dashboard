# 《红楼梦》第118回 记微嫌舅兄欺弱女　惊绝艳姑表成嘉姻

底本：<https://zh.wikisource.org/wiki/紅樓夢/第118回>；读取日期：2026-10-23。

## 情节要点

1. 惜春剃发为尼，王夫人与尤氏无可奈何只得准其在栊翠庵带发修行；宝玉细读《秋水》，更弃佛道杂书一心应考。
2. 王仁（狠舅）勾结邢大舅与贾环、贾芸，图谋将巧姐许给外藩王爷为妾以分肥谋利，邢夫人糊涂听信应允。
3. 平儿察觉外藩暗中相看巧姐之阴谋，惊骇欲绝，奔走告知李纨、宝钗并求王夫人做主，王夫人亦难抗邢夫人长房专断。
4. 刘姥姥闻讯赶来荣府探望，平儿与刘姥姥于暗室密设锦囊奇计，巧扮妆容用村车将巧姐星夜护送潜逃乡下农舍避难。

## 选定场面

荣国府平儿幽僻耳房（密设锦囊定计逃生）：更深夜静，案头孤灯荧荧摇曳。平儿着月白短袄、墨绿素裙，泪流满面扑跪于刘姥姥膝前，双手紧紧握住刘姥姥粗糙双掌，将狠舅奸兄卖姐儿与外藩为妾之奇祸低声痛陈相托；巧姐儿年方十三，着鹅黄绫袄素绢裙，满面惶恐战栗蜷缩依偎在平儿怀侧抽泣；对坐老妪刘姥姥头扎青布帕、身着粗蓝布滚边土布袄裤，神情果决凝重，眼中精光迸现，一手搂住巧姐、一手按膝低语密授瞒天过海锦囊之计；案头摊放乡下粗布包袱与改扮村服。具名平儿、巧姐、刘姥姥三人。选此景因全书因果报应之大枢纽，“偶因济刘氏，巧得遇恩人”，昔日凤姐施银种因，今日平儿托孤得果；深宅贵胄穷途末路出卖骨肉，唯乡野老妪舍命重义相救，高下立判，震撼人心。三处依据：

- 「平兒便嚇的沒了主意，雖不和巧姐說，便赶著去告訴了李紈寶釵，求他二人告訴王夫人。」
- 「平兒道：‘太太該叫他進來，他是姐兒的乾媽，也得告訴告訴他。’」
- 「那知巧姐隨了劉姥姥帶著平兒出了城，到了庄上，劉姥姥也不敢輕褻巧姐，便打掃上房讓給巧姐平兒住下。」

先后核对：王仁邢大舅串谋外藩相看巧姐（前）→平儿察破阴谋奔走告求受阻（前）→刘姥姥至荣府，平儿于私室托孤定计，巧设锦囊，连夜携巧姐出奔农舍避祸（此刻）→巧姐随刘姥姥抵庄上纺车纺绩（后）→贾赦大赦贾琏回京，巧姐平安回府（后）。

## 器物与环境

- 地点：荣国府内院平儿居室耳房。窗外竹影幽冷，室内设榆木小几、素纱挑灯，乡间竹制提篮与村妇粗布衣装。
- 时令天气：农历八月深秋深夜，朔风初起，冷月穿窗，万籁俱寂。
- 器物：白铜单股挑灯烛台、粗布青花小包袱、乡下黑陶茶碗、村姑蓝布头巾、竹编提篮。
- 现实中会动的：① 木几上白铜挑灯烛火在秋夜穿隙微风中微微摇曳跳荡，光影明灭；② 刘姥姥粗布棉袄宽袖按在膝头时，手掌轻轻拍抚巧姐背心；③ 巧姐惊恐呜咽间，鹅黄绫袄前襟随着急促呼吸急剧起伏。

## 排除项

- 前后拍：王仁邢舅在花厅吃酒分肥；外藩使女上门相看巧姐；宝玉与宝钗论《庄子》；贾兰呈递贾政家书；荒村纺车全景。
- 他回他场：严禁第39回刘姥姥醉卧怡红院与信口胡诌雪下抽柴；严禁出现青楼妓馆烟花巷之污浊场景。
- 造型禁忌：严禁清代旗人服制；刘姥姥须是纯朴厚重之明清北方乡妪形象，切忌滑稽丑角化；平儿与巧姐恪守贵门落难仕女仪态。
