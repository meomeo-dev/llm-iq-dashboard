# 《红楼梦》第5回 开生面梦演红楼梦　立新场情传幻境情

底本：<https://zh.wikisource.org/wiki/紅樓夢/第005回>；读取日期：2026-10-20。

## 情节要点

1. 黛玉住进荣府后与宝玉同行同坐，宝钗到来后黛玉心生不忿，二人口角，宝玉俯就才和好。
2. 宁府会芳园梅花盛开，尤氏请贾母等赏花；宝玉倦怠，由秦可卿引到她房中午睡，随即入梦。
3. 梦中宝玉随警幻仙姑到“太虚幻境”石牌坊，过“孽海情天”宫门，进薄命司，翻看金陵十二钗正册、副册、
   又副册，册中图画判词多不能解。
4. 警幻引他入室，品“千红一窟”茶、“万艳同杯”酒，听新制《红楼梦》十二支曲；又受警幻规劝，
   行至迷津，被夜叉拖拽，惊呼“可卿救我”而醒，袭人等丫鬟上前安抚。

## 选定场面

梦中，宝玉随警幻仙姑走到“太虚幻境”石牌坊前，抬头看牌坊匾额与两边对联的一刻。具名贾宝玉、警幻仙姑，
不另加群像。选它是因为全回最有标志性的画面就是这座牌坊，朱栏白石、绿树清溪的仙境入口一眼可认，
一个男童、一位女仙，无床帏、无册子，也没有任何动手。三处依据：

- 「但见朱栏白石，绿树清溪，真是人迹稀逢，飞尘不到。」
- 「竟随了仙姑，至一所在，有石牌横建，上书“太虚幻境”四个大字」
- 「假作真时真亦假，无为有处有还无。」

先后核对：秦氏房中午睡、入梦（前，室内，不画）→随秦氏悠悠荡荡至朱栏白石处，闻山后歌声（前）→警幻自
柳坞花房走出，宝玉作揖问路，警幻自报家门并邀他同游（前）→宝玉“便忘了秦氏在何处”，随仙姑至石牌坊
（此刻，户外，二人立于牌坊前）→转过牌坊才是“孽海情天”宫门（后）→二层门、各司、薄命司翻册（后）→
饮茶酒听曲（后）。此刻秦氏不在身边，宫门匾额未现，册子、众仙子、茶酒均未出现。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾宝玉 | 男童，约八岁上下（第2回冷子兴说“长了七八岁”，本回称“年纪尚小”，学界推算有八岁与十一二岁两说）；面容沿第3回“面若中秋之月，色如春晓之花”。衣冠本回未写，兜底：窄袖锦袍外罩褂，头戴束发冠（第3回出门装束），衣色不强加，衣着端正，孩童身量；项圈与通灵宝玉本回未写，可不画；神情惊喜好奇，微仰头，向前探身 | 第3、5回 |
| 警幻仙姑 | 年轻女仙，“蹁跹袅娜，端的与人不同”。赋中写“云堆翠髻”“满额鹅黄”（额间黄色妆饰）“仙袂乍飘”“荷衣欲动”“听环佩之铿锵”“纤腰之楚楚”“珠翠之辉辉”。兜底：乌黑高髻缀翠饰，额间淡黄妆，长袖飘带的浅色衣裙（色不强加），腰佩玉环，衣着端正；一手微抬引路，神态端庄含笑 | 第5回 |

## 器物与环境

- 地点：梦中太虚幻境入口，户外。兜底：白石牌坊，四柱三间，正中匾额“太虚幻境”四字（字少，可辨），
  柱上刻对联（联字不要求可辨）；牌坊之后的宫门不入画。前景朱栏、白石、绿树、清溪，不见他人，不见飞尘。
- 时令天气：现实中是宁府梅花盛开的时节，梦境季节未写；兜底：柔和春意，柳色轻绿、花树常青，
  不画雪，不画会芳园的梅花盛景。
- 现实中会动的：① 警幻的仙袂、衣带与披帛随风飘动；② 清溪水波，落花顺水缓流（曲词“飞花逐水流”）；
  ③ 牌坊远处的云霭缓缓飘移（兜底）。二人不整体位移。

## 排除项

- 后拍：“孽海情天”宫门与对联、各司匾额、薄命司、橱柜册子与画谶、众仙子、群芳髓、茶与酒、舞女与曲、
  兼美、迷津与夜叉；前拍：会芳园赏梅、秦可卿房中陈设与午睡、袭人等丫鬟。
- 不画宝玉卧榻与睡姿，不画秦可卿，不画册中自缢等画面；不画云雨情节。
- 警幻不画翅膀，不画成西式天使或戏曲式甩袖彩带仙女；衣着端正，不作性感化描写。
