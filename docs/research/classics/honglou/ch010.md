# 《红楼梦》第10回 金寡妇贪利权受辱　张太医论病细穷源

底本：<https://zh.wikisource.org/wiki/紅樓夢/第010回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。

## 情节要点

1. 金荣回家生气，被母亲劝住；其姑母璜大奶奶（金寡妇）听说学房之事，要去宁府向秦氏评理。
2. 璜大奶奶到宁府见尤氏，听尤氏说秦氏病重、不思饮食，又说起秦钟在学房受欺的话已传到秦氏耳中，
   满腔怒气全丢开，转怒为喜，说了些闲话就回去了。
3. 贾珍听冯紫英荐了精通医理的张友士，差人去请；先生当日劳累，次日午间到府。
4. 张友士由贾蓉陪着进内为秦氏诊脉，先看脉后问病，说出心、肝、肺、脾四脉的病象，开出「益气养荣补脾和肝汤」，
   断「水亏木旺」，说今冬无碍，过了春分可望痊愈。

## 选定场面

宁国府贾蓉居室里间：张友士为秦氏诊脉。家下媳妇捧来大迎枕，拉起秦氏的袖口露出右手腕，先生伸左手按在腕上
（原文只写按秦氏“右手脉”，未写先生用哪只手；按交叉取脉，且先生在画面右侧面朝左，兜底用左手），调息凝神，
细诊了半刻，尚未换手。具名张友士、秦氏、贾蓉，另有媳妇婆子作群像。选它是因为诊脉的姿势、大迎枕、
先生的专注都有明文，室内安静，无动手，也不画病势。依据：

- 「请先生坐下，让我把贱内的病说一说再看脉如何？」
- 「家下媳妇们捧过大迎枕来，一面给秦氏拉着袖口，露出脉来」
- 「先生方伸手按在右手脉上，调息了至数，宁神细诊了有半刻的工夫」

先后核对：贾珍请先生到大厅，茶毕，请进去看（前）→ 贾蓉同入，到贾蓉居室，见了秦氏；贾蓉想先说病，先生主张
先看脉（前）→ 媳妇捧大迎枕、拉袖口，先生按秦氏右手脉，调息细诊半刻（此刻）→ 换诊左手脉亦复如是，说「我们外边坐罢」（后）→
外间房里床上坐下，吃茶，论脉象、开方（更后）。此刻先生只在诊右手脉，没有开口论病，没有药方；秦氏没有说话。
帐幔：原文未写，不画。对照第51回大夫诊晴雯「幔中单伸出手去」、嬷嬷用手帕掩手，那是另一回，本回不照搬。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 张友士 | 冯紫英幼时从学的先生，「学问最渊博，更兼医理极深」；上京为儿子捐官，故非少年，兜底：中年，短须。他自称「晚生」，正文称「先生」，不是太医院官员，不穿官服。兜底：儒生衣冠，方巾或儒巾，深蓝或黑色宽袖长袍；坐在秦氏侧面，左手食中无名三指并按秦氏右腕上，目光下垂，神情专注 | 第10回 |
| 秦氏 | 青年少妇，岁数未写；「形容袅娜，性格风流」（第8回），病中「到了下半天就懒待动，话也懒待说，眼神也发眩」，经期两月未至。尤氏说她「一日换四五遍衣裳，坐起来见大夫」，所以端坐、衣冠整齐，兜底：素色秋袄加裙，发髻整齐，少首饰，面色苍白清瘦；坐在铺褥子的座上（第11回写她坐「褥子」），右臂搭在大迎枕上 | 第8、10、11回 |
| 贾蓉 | 少年，第2回称「今年才十六岁」。衣冠本回未写，兜底：年轻公子，家常袍服，束发，站在先生侧后，垂手恭敬 | 第2、10回 |
| 媳妇婆子 | 「家下媳妇们」「贴身伏侍的婆子」，中年，素色袄裙，一人捧枕、一人拉袖，至多三人 | 第10回 |

## 器物与环境

- 地点：宁国府贾蓉居室（原文「到了贾蓉居室」），诊后「到外间房里床上坐下」，所以诊脉在里间；
  里间陈设本回未写，兜底：窗边一张铺褥子的座椅给秦氏，一把椅给先生，不画床帐、被褥。
- 时令天气：次日午间；第11回说「如今才九月半」，上承本回，是秋天。第7、8回写冬初，时令前后不一，
  以本回上下文为准。兜底：秋日午间，窗外光亮，衣着为夹袄或薄棉袄。
- 器物：大迎枕是靠垫类软枕，本回兼托腕用（据摘要，具体尺寸形制未检得）；兜底：一个长方形缎面软枕放在秦氏手边，
  手腕平放其上、掌心向上。不画药箱、药方、药碗（药方在后一拍）。
- 现实中会动的：① 窗格透入的日光与帘影缓缓移动；② 先生胸前长须与袖口随呼吸轻动（兜底）；
  ③ 媳妇们的衣带轻摆。人物不整体位移。

## 排除项

- 后拍：换诊左手脉、到外间坐下、论「左寸沉数」等脉象、开方、贾蓉问生死、送先生。前拍：金荣之母、璜大奶奶到宁府、
  尤氏诉说、贾珍与冯紫英、贾敬寿辰的安排。
- 秦氏不画成垂危或卧床，不画吐血、汤药，不画第5回、第13回中的秦氏卧室与丧事；不画悬丝诊脉、隔帐、手帕盖腕。
- 张友士不穿官服、不戴官帽，不画戏曲医生扮相与药箱；贾珍、尤氏不在居室内。
- 87版秦可卿以串珠抹额著称（据摘要），原文未写，不采用。
