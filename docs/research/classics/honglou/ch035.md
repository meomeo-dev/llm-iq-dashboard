# 《红楼梦》第35回 白玉钏亲尝莲叶羹　黄金莺巧结梅花络

底本：<https://zh.wikisource.org/wiki/紅樓夢/第035回>；读取日期：2026-10-23。

## 情节要点

1. 黛玉在花阴下见贾母众人热热闹闹探望宝玉，感伤自身无依无靠泪流满面，回潇湘馆隔纱窗教鹦哥念葬花诗。
2. 宝玉欲吃莲叶羹，凤姐忙令人用精巧银模做汤送来；王夫人命玉钏儿送汤，宝玉百般温存诱哄，玉钏儿尝汤转嗔为喜，傅家婆子探问笑宝玉呆气。
3. 宝玉请薛宝钗的丫鬟莺儿来打络子，二人兴致盎然商讨丝线配色（松花配桃红、葱绿柳黄）与“攒心梅花”式样。
4. 莺儿理线编结，宝钗步入怡红院看视，提议用金线配黑珠儿线打络子将通灵宝玉络上；袭人喜得太太赏菜。

## 选定场面

怡红院室内窗前：夏日清昼，莺儿坐在一张圆矮绣墩上，低眉含笑，双手纤指正敏捷翻飞各色丝线编结打至半截的“攒心梅花络”；宝玉斜倚在近旁椅榻上含笑专注凝视，神情怡然自得；薛宝钗端坐一侧圈椅上，身躯微向前倾，一手轻拂衣袖，一手含笑探看指点，正温言建议“倒不如打个络子把玉络上”。具名莺儿、贾宝玉、薛宝钗三人，无群像。选它是因“巧结梅花络”是全书极富生活情趣与传统闺阁手工之美景，配色典雅，温润明丽，构图动静相映，全无暴戾阴暗。三处依据：

- 「宝玉一面看莺儿打络子，一面说闲话」
- 「二人回头看时，不是别人，正是宝钗来了。宝玉忙让坐。」
- 「宝钗坐了，因问莺儿“打什么呢？”一面问，一面向他手里去瞧，才打了半截。宝钗笑道：“这有什么趣儿，倒不如打个络子把玉络上呢。”」

先后核对：宝玉向莺儿定下攒心梅花花样与桃红松花各色彩线（前）→莺儿挽线穿结，宝玉在旁谈笑看视（前）→宝钗从门外步入落座，探身察看莺儿手中半截络子，含笑建议用金线络通灵玉（此刻）→宝玉拍手赞绝命袭人取金线（后）→袭人端太太赏菜进房、宝钗离去（后）。此刻莺儿正手执半截梅花络编结，宝钗刚探看指点，金线黑线未取出。

## 器物与环境

- 地点：大观园怡红院正房次间。朱红长案、紫檀靠背几榻、花梨木圈椅、锦缎小垫绣墩；窗棂明净透光，窗外蕉翠拂影。
- 时令天气：农历五月中下旬夏日白天，日光明媚，室外微热，室内帘卷簟凉、清幽恬适。
- 器物：编织中的半截攒心梅花络（桃红、松花、葱绿三色丝线垂挂）、小针线匣（内放彩线团）、案头瓷茶盏。
- 现实中会动的：① 莺儿手中彩线丝绦随着指尖穿插轻微翻转；② 窗外芭蕉叶影在日光下随风微摆；③ 宝玉与宝钗衣袂下摆微风轻扬。

## 排除项

- 前拍：黛玉花阴泣啼、鹦哥念葬花诗、薛蟠向宝钗作揖赔礼、玉钏儿尝莲叶羹打翻汤水、傅家两个婆子议论宝玉呆气。
- 后拍：袭人进门夸赞太太赏菜、取金线黑珠线、邢夫人遣丫头送果子、黛玉再至院外。
- 构图与造型：不画宝玉受杖趴伏之惨状；不画清代马褂长辫或大拉翅；不强加过于繁复的室内大场景。
