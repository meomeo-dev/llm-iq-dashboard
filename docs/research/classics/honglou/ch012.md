# 《红楼梦》第12回 王熙凤毒设相思局　贾天祥正照风月鉴

底本：<https://zh.wikisource.org/wiki/紅樓夢/第012回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。

## 情节要点

1. 贾瑞来找凤姐，凤姐约他夜里在西边穿堂等候，随即把两边门关死，贾瑞冻了一夜，回家被祖父责罚（不入画）。
2. 凤姐再约他到房后空屋，与贾蓉、贾蔷设局，逼他写下欠契，又被泼了一身粪（不入画）。
3. 贾瑞相思成病，百医无效；跛足道人送来「风月宝鉴」，嘱咐只照背面，贾瑞偏照正面，屡入镜中，病重不起，
   代儒要烧镜，被道人取走（不入画）。
4. 贾家料理贾瑞丧事。冬底，林如海来信说自己身染重疾，要接黛玉回去；贾母定要贾琏护送，
   择日后，贾琏与黛玉辞别贾母，登舟往扬州。

## 选定场面

运河边：贾琏领着黛玉，带领仆从登舟南下。具名贾琏、黛玉，仆从作群像。这是全回唯一不涉贾瑞淫念、镜中幻象和
死亡的场面，也是回末明文写出的动作。原文对此只有一句，人物衣冠、码头、船型均无明文，下文凡标兜底者皆为
推定。依据：

- 「林如海的书信寄来，却为身染重疾，写书特来接林黛玉回去」
- 「于是贾母定要贾琏送他去，仍叫带回来」
- 「贾琏与林黛玉辞别了贾母等，带领仆从，登舟往扬州去了」

先后核对：林如海来信，贾母忧闷，忙着打点黛玉起身，宝玉大不自在却不好拦劝，贾母定要贾琏送，一应土仪盘缠备妥，
择日（前）→ 辞别贾母等（前，在家中，不画）→ 带领仆从，登舟（此刻）→ 往扬州去了（后，船已开行）。此刻船还泊在岸边，
跳板连着岸与船，人在上船途中；贾母、宝玉等送行者原文未写在码头，不画。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 黛玉 | 少女，画十来岁，身形怯弱（第3回「身体面庞虽怯弱不胜」，「如今还是吃人参养荣丸」）；因父病，兜底：神情含忧，不哭。衣着本回未写，兜底：冬日袄裙外加斗篷（第8回写她穿「大红羽缎对衿褂子」、用手炉，是别回，只取式样，颜色不强加），怀抱小手炉；发式兜底：双丫髻或小髻，可戴风帽；至多一名女仆在旁扶持（兜底，不具名） | 第3、8、12回 |
| 贾琏 | 青年，第2回称「今已二十来往了」，「捐的是个同知」，「于世路上好机变」；相貌前文未写。衣冠兜底：棉袍外罩披风，戴暖帽，腰束带，不穿官服补子；走在黛玉侧前，一手引向跳板 | 第2、12回 |
| 仆从 | 数名男仆，深色棉袍，戴帽，肩扛手提箱笼包袱（土仪盘缠）；船工一二人；至多六人 | 第12回 |

## 器物与环境

- 地点：运河码头。原文只写「登舟」；荣府南下扬州，运河北端的张家湾、通州是客旅上下船处（据摘要），原文未点名。
- 船：官员乘的客船为画舫型，设舱楼，门窗宽大彩绘，船尾有舵楼，插官衔牌，两桅挂席帆（据摘要）。
  兜底：一艘两桅木船，舱楼门窗宽大，船首平甲板，搭一块跳板到岸，帆收拢，船头一面小旗，不画现代船只。
- 时令天气：「这年冬底」。北方运河冬季会封冻、漕船停航（据摘要），小说不计较，兜底：晴冷，河水未冻，
  岸边枯柳与枯苇，人呼出白气，不画雪、不画冰封河面。
- 器物：箱笼、包袱、手炉；不画镜子。
- 现实中会动的：① 河水波纹与船身轻晃、缆绳微动；② 船头小旗与岸边枯苇、柳枝随风摆；③ 黛玉斗篷下摆、
  贾琏披风衣角与呼出的白气。人物不整体位移出画。

## 排除项

- 后拍：船开行、抵扬州、林如海之死（第14回）、返京。前拍：林如海来信、贾母忧闷、宝玉不自在、辞别贾母。
- 贾瑞全部情节不画：相思局、穿堂冻夜、被泼粪、罚跪、病中、道人送镜、风月宝鉴的镜背骷髅与镜中影像、丧事。
  跛足道人本回不入画（若他处需要：跛足、蓬头、衣衫破旧，不作怪诞）。
- 贾母、宝玉、凤姐、平儿、林如海不在码头；不画哭泣送别，不画黛玉病容垂危。
- 黛玉不画成成年美人，不照87版以白蓝粉素色为主的配色（据摘要）；贾琏不画官服补子与清宫剧发式。
