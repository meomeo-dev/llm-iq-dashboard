# 《红楼梦》第11回 庆寿辰宁府排家宴　见熙凤贾瑞起淫心

底本：<https://zh.wikisource.org/wiki/紅樓夢/第011回>（汇校本，前八十回以庚辰本为底本）；读取日期：2026-10-20。

## 情节要点

1. 贾敬寿辰，贾珍备下食盒送去，贾敬不肯来；邢夫人、王夫人、凤姐、宝玉到宁府，
   尤氏说起秦氏的病，说新请的先生断定不是喜，是大症候。
2. 凤姐与宝玉随贾蓉去看秦氏，秦氏说自己「未必熬的过年去」，宝玉落泪；凤姐劝了许久，
   独自带着婆子丫头，从便门绕进会芳园，去天香楼赴席。
3. 凤姐在园中走着看景，被假山后出来的贾瑞拦住搭话；她假意应付，心中暗恨。
   到天香楼与邢、王二夫人和尤氏吃酒看戏，点了《还魂》《弹词》。
4. 冬至后凤姐再探秦氏，劝尤氏预备后事；贾瑞几次求见，平儿骂他，凤姐说「我自有道理」。

## 选定场面

会芳园里：凤姐探过秦氏，带着婆子丫头和宁府的媳妇婆子，从便门进园，一路看着园中秋景，赞赏而行。
具名凤姐，另有婆子丫头作群像；贾瑞尚未从假山后走出，不画。选它是因为原文有一整段写景，秋色、水石、
小桥、红叶、菊花俱全，人物只是赏景行走，无任何冲突。依据：

- 「黄花满地，白柳横坡」
- 「石中清流激湍，篱落飘香，树头红叶翩翻，疏林如画」
- 「凤姐儿正自看园中的景致，一步步行来赞赏」

先后核对：凤姐在秦氏处劝解，说「你好生养着罢，我再来看你」，带婆子丫头、宁府媳妇婆子，从里头绕进园子便门（前）→
进园看景，一步步行来赞赏（此刻）→ 假山石后走出贾瑞，请安搭话（后）→ 凤姐假意应付，暗忖「叫他死在我的手里」（后）→
两三个婆子来催，到天香楼后门，见宝玉和丫头们玩（更后）→ 上楼点戏（更后）。此刻没有贾瑞，没有楼，没有宝玉
（他已先随贾蓉过园）；凤姐在行走，不是站定。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 凤姐 | 青年妇人，岁数未写。「一双丹凤三角眼，两弯柳叶吊梢眉，身量苗条……粉面含春威不露，丹唇未起笑先开」（第3回）。衣冠本回未写；第3回初见写过一套：金丝八宝攒珠髻、朝阳五凤挂珠钗、赤金盘螭璎珞圈、缕金百蝶穿花大红洋缎窄褙袄、外罩五彩刻丝石青银鼠褂、翡翠撒花洋绉裙。本回九月半、「暖日当暄」，兜底：沿用头面与袄裙式样，外褂去皮毛，改素缎石青褂；侧头看景，含笑，缓步前行，手空着 | 第3、11回 |
| 婆子丫头 | 「跟来的婆子丫头并宁府的媳妇婆子」，至多四人，落后凤姐几步；丫头为少女，婆子中年，素色袄裙加青缎背心，不戴华饰 | 第11回 |

## 器物与环境

- 地点：宁国府会芳园。凤姐从秦氏住处「里头」绕进「园子的便门」；园中有小桥通溪、曲径、石间激湍、篱落、
  疏林，远处「依山之榭」与「临水之轩」（左右方位不作要求）。天香楼、凝曦轩、戏台在园中他处，不入画。
- 时令天气：秦氏的病「如今才九月半」；贾珍说「天气正凉爽，满园的菊花又盛开」；赋文「西风乍紧……暖日当暄」。
  兜底：秋日午后，日光明亮，风略紧。
- 景物：「黄花」即菊花，开在篱边与路旁；「白柳」原文未释「白」，兜底：垂柳，枝叶偏浅，斜出坡边，
  不是第5回「白杨村」的坟地意象，不画白杨；树梢有红叶，地上有落叶。
- 现实中会动的：① 红叶从树头飘落；② 石间溪水激湍起伏；③ 柳枝与凤姐裙裾、衣带随西风摆动。
  凤姐与随从的脚步不整体位移出画。

## 排除项

- 后拍：贾瑞从假山后出现、请安、觑着凤姐；凤姐假笑与暗恨；天香楼点戏；凝曦轩爷们吃酒。前拍：宁府家宴、
  秦氏的话与宝玉落泪、贾蓉送食盒。更后：冬至后探秦氏、贾瑞求见、平儿的骂。
- 贾瑞、宝玉、秦氏、尤氏、邢夫人、王夫人不入画；假山后不露出人影。
- 不画春景花卉（桃杏梅），不画白杨，不画雪；不画凤姐的怒容或杀意（暗恨在后一拍）。
- 凤姐不画清宫剧旗头与花盆底；银鼠褂是第3回所写，本回天气不画皮毛。
