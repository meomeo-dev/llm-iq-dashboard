# 《红楼梦》第106回 王熙凤致祸抱羞惭　贾太君祷天消灾患

底本：<https://zh.wikisource.org/wiki/紅樓夢/第106回>；读取日期：2026-10-23。

## 情节要点

1. 北静王回奏荣府未干重罪，贾政暂安；贾母惊吓气逆，服药苏醒痛哭子孙不肖。
2. 贾琏私蓄及凤姐体己抄抢略尽，凤姐重病沉疴，自悔往日放利致祸，羞愧饮泣。
3. 贾政痛斥凤姐重利害家，邢夫人尤氏相对悲啼，全府风声鹤唳人心惶惶。
4. 贾母于东暖阁设大香案，率合家老幼虔诚跪拜苍天，白发苍苍痛陈祖德消弭祸患。

## 选定场面

荣国府东暖阁贾太君设大香案率全家跪祷苍天：初秋薄暮，东暖阁庭前青石坪上。八旬贾太君发如白雪、身着素白长袍，
双手捧降香虔诚跪于蒲团之上，仰面泣祷苍天求释儿孙罪咎；王夫人素衣垂泪侧跪于后；右侧内室病榻旁王熙凤素面
掩面伏枕饮泣。具名贾母、王夫人、王熙凤三人。选此景因贾母祷天为全书最悲壮之家族救赎，老太君以八旬之躯
承当天地祖宗之罚，庄严肃穆，苍凉沉雄，将百年世家之幻灭与亲情大爱推至崇高。三处依据：

- 「賈母見祖宗世職革去，現在子孫在監質審……日夜不宁，思前想後，眼淚不乾。」
- 「一日傍晚，叫寶玉回去，自己扎掙坐起……在院中設了香案，跪在地下，禱告天地。」
- 「鳳姐現在病重，知他所有什物盡被抄搶一光，心內郁結，悔恨交加。」

先后核对：贾琏清点存物伤痛无计（前）→凤姐病笃羞悔泣血（前）→贾母东暖阁设案焚香，叩拜苍天痛陈祖德消祸
（此刻）→王夫人等相随叩拜祈祷（后）→次日内廷传捷报获恩宽免（后）。此刻青烟直上，老太君白发苍苍，
全府伏地哀告。

## 器物与环境

- 地点：荣禧堂后贾母东暖阁庭前。正中设朱漆雕花大香案，案上陈三足铜鼎香炉、白玉烛台与五供素果。
- 时令天气：农历七月初秋黄昏；落霞惨淡如血，暮色深沉，秋风瑟瑟。
- 器物：朱红供桌、青铜三足香炉、紫檀降香线香、白蜡烛台、素蓝布拜垫、佛堂经卷。
- 现实中会动的：① 铜鼎香炉中三炷降香所燃青烟在冷落暮风中徐徐袅袅升腾；② 烛台上两枝白蜡烛火苗在夜气中轻轻摇曳颤动；③ 贾母素袍宽袖与额前缕缕白发在秋风吹拂下微弱颤动。

## 排除项

- 前后拍：狱吏严刑拷讯贾赦贾珍；下人私下哄抢财物作鸟兽散；凤姐断气僵死；赵堂官冷笑索贿。
- 他回他场：不得出现第29回清虚观打醮祈福；不得出现元妃省亲颂圣；严禁怪力乱神现形。
- 造型禁忌：严禁清代旗人两把头、大拉翅与马蹄底鞋；贾母全家服饰一律依汉制素服，严禁浓艳珠翠。
