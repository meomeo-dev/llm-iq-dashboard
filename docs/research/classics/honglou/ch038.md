# 《红楼梦》第38回 林潇湘魁夺菊花诗　薛蘅芜讽和螃蟹咏

底本：<https://zh.wikisource.org/wiki/紅樓夢/第038回>；读取日期：2026-10-23。

## 情节要点

1. 史湘云在藕香榭设螃蟹宴请贾母赏桂，平儿与凤姐互抹蟹黄嬉闹，贾母忆昔年枕霞阁落水往事。
2. 贾母散后众人撤大席另开小宴，湘云将拟就的十二首菊花诗题针绾在墙上，不限诗韵自由选作。
3. 黛玉倚栏垂钓，宝钗折桂戏鱼，宝玉两头探看；随后黛玉自斟合欢烧酒，众人依次勾选题目分赋七律。
4. 李纨评定黛玉《咏菊》《问菊》《菊梦》包揽前三魁夺诗魁；宝玉、黛玉、宝钗复作螃蟹咏，宝钗诗讽世夺冠。

## 选定场面

藕香榭水榭构思作诗前：大圆桌上摆着螃蟹果酒，墙上别着诗题；黛玉坐绣墩倚朱栏垂钓，宝钗俯窗槛掐桂蕊掷水引鱼，宝玉俯身宝钗旁笑看，湘云在大案前张罗。具名黛玉、宝钗、宝玉、湘云四人。选它是因水榭四面环水、钓竿戏鱼与金秋桂蟹交相辉映，是全书最闲雅悠适的青春胜景，动静成趣毫无乖戾。依据：

- 「林黛玉因不大吃酒，又不吃螃蟹，自令人掇了一个绣墩倚栏杆坐着，拿着钓竿钓鱼。」
- 「宝钗手里拿着一枝桂花玩了一回，俯在窗槛上掐了桂蕊掷向水面，引的游鱼浮上来唼喋。」
- 「宝玉又看了一回黛玉钓鱼，一回又俯在宝钗旁边说笑两句」

先后核对：贾母众人登竹桥品蟹赏桂、凤姐逗趣（前）→贾母散去，湘云大圆桌放当中摆酒菜，诗题针绾于墙（前）→黛玉倚栏垂钓，宝钗折桂掷水戏鱼，宝玉回首流连两头说笑，湘云张罗（此刻）→黛玉收竿自斟合欢花烧酒（后）→宝钗、黛玉、宝玉、湘云依次提笔勾题（后）→雪浪笺誊录，李纨评黛玉为魁，再赋螃蟹诗（后）。此刻未至勾题提笔，未至撕烧诗稿，众人神态闲适自得。

## 器物与环境

- 地点：大观园藕香榭。建于碧波池中，四面雕窗，左右回廊竹桥；柱挂黑漆嵌蚌对联，墙上针别白纸诗题。
- 时令：金秋九月，桂花盛开，天朗气清，水波澄澈。
- 器物：青竹钓竿与丝线、绣墩、折枝金桂、大圆桌、乌银梅花自斟壶、海棠冻石蕉叶杯、青白瓷盘蒸螃蟹。
- 现实中会动的：① 水中鱼群聚散唼喋与细微水晕涟漪；② 钓竿丝线在微风与水流中轻微晃动；③ 岸边垂柳与金桂碎花随风拂落。

## 排除项

- 前拍：贾母与凤姐平儿抹蟹黄说笑；上竹桥咯吱响；李纨凤姐虚席伺候。
- 后拍：黛玉自斟烧酒、勾《问菊》；迎春雪浪笺誊诗；黛玉撕烧螃蟹诗；平儿复入园传话。
- 误置道具：不可出现清宫服饰（马蹄袖、旗头、花盆底）；男子剃发蓄辫；舞台戏服行头。
