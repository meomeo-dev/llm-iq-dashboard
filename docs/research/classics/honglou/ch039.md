# 《红楼梦》第39回 村姥姥是信口开河　情哥哥偏寻根究底

底本：<https://zh.wikisource.org/wiki/紅樓夢/第039回>；读取日期：2026-10-23。

## 情节要点

1. 众人聚藕香榭续食螃蟹，平儿受留饮酒；平儿私下告知袭人凤姐挪扣月钱放利取息之事。
2. 刘姥姥带板儿二进荣国府送现摘瓜菜，周瑞家的引见贾母；贾母怜贫留宿，鸳鸯引其沐浴换衣。
3. 晚间刘姥姥坐贾母榻前闲话，信口胡诌雪地抽柴的红袄白裙美貌姑娘，宝玉痴心深信、凝神细听。
4. 马棚意外走水打断夜谈；次日宝玉密追底细，刘姥姥顺嘴编出“茗玉小姐”，宝玉遣茗烟出城寻破庙只得瘟神。

## 选定场面

贾母上房内室内：刘姥姥沐浴更衣后坐在贾母罗汉榻前椅上，手舞足蹈讲述雪下抽柴故事；贾母歪靠迎枕含笑细听，身后侍女轻捶双腿；宝玉倾身向前如痴如醉，黛玉在侧抿嘴含笑。具名刘姥姥、贾母、宝玉、黛玉四人。选它是因乡野老妪与深闺富贵的反差生动鲜活，雪地红袄之奇谈触发宝玉痴情宿慧，室内温熙祥和，毫无打斗乖戾。依据：

- 「只见一张榻上歪着一位老婆婆，身后坐着一个纱罗裹的美人一般的一个丫鬟在那里捶腿」
- 「彼时宝玉姊妹们也都在这里坐着，他们何曾听见过这些话，自觉比那些瞽目先生说的书还好听。」
- 「原来是一个十七八岁的极标致的一个小姑娘，梳着溜油光的头，穿着大红袄儿，白绫裙子……」

先后核对：平儿吃蟹透月钱底细（前）→刘姥姥携瓜菜进府，周瑞家的引见贾母（前）→贾母留宴，鸳鸯领姥姥沐浴并换贾府常服（前）→刘姥姥坐榻前高谈雪下抽柴，贾母含笑、宝玉痴听（此刻）→忽报南院马棚走水，贾母出门念佛烧香，故事打断（后）→黛玉戏谑雪下抽柴，宝玉遣茗烟寻茗玉庙碰见瘟神（后）。此刻未至走水惊慌，亦未至茗烟出城，室中灯火融融。

## 器物与环境

- 地点：荣国府贾母正房上房。陈设宏丽，设朱漆罗汉榻、软褥迎枕、雕花木椅、茶几与座地铜灯台。
- 时令：秋夜（八月秋深），秋风初凉，室内掌灯，暖意融融。
- 器物：罗汉榻、迎枕、木椅、青花盖碗茶具、捶腿用小美人拳（或布捶）、高脚铜烛台。
- 现实中会动的：① 烛台火苗微微跳跃与青烟摇曳；② 身后侍女轻柔均匀的捶腿动作；③ 刘姥姥讲故事时起伏比划的双手。

## 排除项

- 前拍：平儿在藕香榭被灌酒、诉说凤姐放高利贷扣月钱；刘姥姥送南瓜扁豆卸在廊下。
- 后拍：南院马棚失火火光大作；宝玉背地拉刘姥姥编茗玉小姐庙；次日茗烟寻到瘟神庙。
- 误置道具：刘姥姥不穿破烂补丁土布衣裳（前文明写鸳鸯刚引其洗澡换了贾府干净家常衣裳）；不画插满菊花（此为第40回情节）。
- 禁忌造型：清代满式旗袍与两把头、瓜皮帽、辫子；戏曲小丑脸谱。
