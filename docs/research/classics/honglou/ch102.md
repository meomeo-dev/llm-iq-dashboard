# 《红楼梦》第102回 宁国府骨肉悲题暗　大观园夜静走惊魂

底本：<https://zh.wikisource.org/wiki/紅樓夢/第102回>；读取日期：2026-10-23。

## 情节要点

1. 尤氏送探春归宁国府后染重病，贾珍贾蓉延请江南术士毛半仙占卜，断为旧宅伏虎作怪、邪祟侵凌。
2. 大观园荒芜冷落人烟日稀，贾赦在园中亦撞怪受惊，下人夜间频传狐鬼夜号、人心皇皇。
3. 贾赦惊惧无措，请道纪司四十九位道众入园，于省亲正殿敕建道场设三清法坛驱邪逐妖。
4. 法师手提宝剑法水、挥桃木打妖鞭、布列五方旗击令牌，符水四洒大作法事，荒诞中尽显大族末世穷途。

## 选定场面

大观园大观楼省亲正殿法坛之前：冬日昏昼，寒烟锁院。昔日元妃省亲之金碧正殿如今空旷阴冷，堂中大设道家法坛：中供三清圣像，
旁挂二十八宿与四大元帅神轴，两旁钟鼓法器齐备，五方旌旗森列。主法高功法师道冠道袍、足踏芒履，一手执古铜桃木法剑、
一手执白瓷法水孟，立于法坛正中，口念真言、振臂喷洒法水；身侧配坛法师或执七星皂旗，或高举桃木打妖鞭凌空虚击；
坛前香炉内符箓焚化，浓郁香烟紫雾翻滚弥漫；下首丹墀下贾赦着古铜暗花狐皮大氅、面带病容惊疑不定，率众仆屏息旁观。
具名法师、贾赦二人。选此景因“大观园符水驱妖孽”乃大观园由青春极乐之境彻底沦为阴森鬼蜮、末世穷途之荒诞挽歌，
省亲正殿当年烈火烹油之皇家威仪今沦为道士弄鬼驱妖之场，对比极度荒谬与凄凉。三处依据：

- 「擇吉日先在省親正殿上鋪排起壇場，上供三清聖像，旁設二十八宿並馬，趙，溫，周四大將……插著五方旗號。」
- 「三位法師，一位手提寶劍拿著法水，一位捧著七星皂旗，一位舉著桃木打妖鞭，立在壇前。」
- 「賈赦沒法，只得請道士到園作法事驅邪逐妖。」

先后核对：尤氏卧病毛半仙占卦断旧宅有妖（前）→大观园狐魅频出人心惶恐（前）
→省亲正殿立坛净坛，法师提宝剑法水打妖鞭作法驱妖（此刻）→道众各处放符贴印封门封锁园门（后）
→贾府各处病灾不息家势更替（后）。此刻法水飞溅、符烟腾空、法铃齐鸣，昔日大观圣境如坠冥司。

## 器物与环境

- 地点：大观园正门内省亲正殿（正殿明堂）。雕梁画栋虽在而尘封冷落，高悬巨幅道教神轴画像。
- 时令天气：隆冬寒昼，朔风怒号，彤云蔽日，寒烟弥漫正殿内外。
- 器物：三清诸神挂轴画像、五方神旗（青红白黑黄）、朱漆高法坛、三清铃、桃木宝剑、桃木打妖鞭、七星皂旗、白瓷法水盂、焚符铜火盆。
- 现实中会动的：① 法师长袖翻卷振腕间，法水盂中飞溅出之晶亮水珠在半空散开；② 法坛铜盆中焚烧之黄绫符箓所化青紫香烟在殿堂寒流中翻腾翻卷；③ 坛前悬挂之五方五色神旗被殿外灌入之冬风吹拂烈烈翻舞。

## 排除项

- 前后拍：宁府尤氏服药呻吟之病榻惨状；毛半仙在宁府弄铜钱算命抽签；道士持符水在潇湘馆怡红院捉鬼之跳梁丑态；抄检大观园。
- 他回他场：不得出现清代道袍样式；不得出现第17、18回省亲时繁花锦簇之宫灯太监；严禁真妖魔鬼怪出场之玄幻低俗画风。
- 造型禁忌：严禁长辫马褂；法师严格依正统正一或全真道门法衣威仪，贾赦为明制贵族冬日暖服，不可丑化为江湖草莽。
