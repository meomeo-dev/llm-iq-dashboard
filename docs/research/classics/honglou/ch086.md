# 《红楼梦》第86回 寄闲情审局释痴呆　泄幽恨弹琴悲往事

底本：<https://zh.wikisource.org/wiki/紅樓夢/第086回>；读取日期：2026-10-23。

## 情节要点

1. 薛姨妈托凤姐、贾琏重金行贿知县，县官得银后舞弊颠倒口供，将薛蟠斗杀张三案巧翻为失手误伤。
2. 薛蝌探监照看薛家事务回报薛家，薛姨妈往贾府致谢，两府人等暂时释怀。
3. 宝玉闲步至潇湘馆，见黛玉凭案研读减字古琴谱，宝玉不识篆文字形如天书，黛玉笑解减字谱法与按弦取音。
4. 黛玉阐述古琴“圣人之器”与弹琴之旨：须择静室高斋、整肃衣冠、焚香静坐、调和血气，并讲究手势疾徐。

## 选定场面

潇湘馆幽轩内黛玉凭案解琴谱：孟冬午后，潇湘馆书斋明轩幽静，窗外千竿翠竹掩映，竹影拂窗。画面中部十六岁林黛玉
着雪青窄袖小袄、浅月白绫裙，斜依紫檀书案，纤手执卷点划古法减字琴谱，容颜宁和灵秀；画面左侧十七岁贾宝玉
穿秋香色夹袍微倾身躯，指着谱上“大”“九”“五”减字满脸探寻求教之趣；案上设素瓷博山熏炉吐雾，琴囊裹古琴端放琴桌；
画面右侧紫鹃捧青花茶瓯含笑侍立。具名林黛玉、贾宝玉、紫鹃三人。选此景因黛玉讲琴为全书极重要之文艺与哲思高潮，
“琴者禁也”道尽黛玉高洁秉赋与知音之叹。三处依据：

- 「只见黛玉靠在桌上看书。宝玉走到跟前，笑说道：‘妹妹早回来了。’……书上的字一个也不认得。」
- 「黛玉笑道：‘这“大”字“九”字是用左手大拇指按琴上的九徽，这一勾加“五”字是右手钩五弦。’」
- 「琴者，禁也。古人制下，原以治身，涵养性情，抑其淫荡，去其奢侈。若要抚琴，必择静室高斋……」

先后核对：薛家行贿翻案完毕，宝玉从外间返荣国府（前）→宝玉信步入潇湘馆，见黛玉展古琴谱，黛玉细细讲解减字谱
与琴道精微（此刻）→紫鹃进言劝宝玉莫让姑娘劳神（后）→秋纹送来四盆兰花（后）。此刻静室书香，宝黛对坐论琴，
雅致绝俗。

## 器物与环境

- 地点：大观园潇湘馆有凤来仪正房书斋。雕花紫檀平头长案、琴桌、锦袱锦囊裹七弦古琴、斑竹窗棂外透碧篁竹影。
- 时令天气：农历十月中旬孟冬午后，天朗气清，冬日温阳洒于窗案竹石之间。
- 器物：线装减字古琴谱、紫檀琴桌、锦缎琴囊、博山熏炉、端溪兰亭砚、兼毫笔、景德镇青白瓷茶瓯。
- 现实中会动的：① 案上博山香炉口缕缕淡青线香余烟匀速回旋飘散；② 窗棂外潇湘馆修竹枝叶受初冬微风轻拂摇荡，窗纸竹影微晃；③ 案头翻开的琴谱书页边角在穿堂轻风下微微翻起复落。

## 排除项

- 前后拍：薛蟠公堂受审与知县受贿；薛蝌探监交涉；秋纹送兰花；黛玉见双朵兰花暗自垂泪。
- 他回他场：不得出现大观园栊翠庵妙玉打坐走火；不可出现林黛玉月夜隔竹抚琴弦断；严禁公堂刑具枷锁。
- 造型禁忌：严禁长辫马褂、旗装花盆底；宝黛服饰严禁艳俗或不合礼数；古琴谱不得画成现代五线谱。
