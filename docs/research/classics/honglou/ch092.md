# 《红楼梦》第92回 评女传巧姐慕贤良　玩母珠贾政参禅理

底本：<https://zh.wikisource.org/wiki/紅樓夢/第092回>；读取日期：2026-10-23。

## 情节要点

1. 贾母设冬日消寒会邀亲友围炉，宝玉免塾课清晨往贾母房中请安，巧姐亦随奶妈早至行礼。
2. 巧姐自述已识三千字并诵习《女孝经》，半月前开蒙《列女传》；宝玉详为解说姜后脱簪、孟光举案诸贤德典故。
3. 巧姐聪颖向慕前贤，贾母含笑嘉许；凤姐因病告假，司棋表兄潘又安殉情绝命信传至，凤姐叹惜出资成全合葬。
4. 冯紫英携洋货母珠、鲛绡帐入贾政书房求售，母珠引小珠聚拢显聚散消长；贾府囊空未纳，贾雨村复起拜官。

## 选定场面

贾母正房东暖阁：冬日清晨，红炭火温。贾母高卧临窗软榻靠引枕，慈眉含笑俯视榻侧；巧姐年约七岁，身着水红织金小袄
依偎贾母膝旁，手捧《列女传》善本木刻书册仰首聆听，眼神纯澈向慕；宝玉着石青熟罗家常袍，欠身坐于绣墩，手点书卷插图
耐心解说姜后脱簪与孟光举案之德；鸳鸯捧朱漆茶盘垂手侍立榻后。具名贾母、巧姐、贾宝玉、鸳鸯四人。选此景因“巧姐慕贤良”
为本回文眼，在大厦将倾的末世暗潮中，祖孙叔侄围炉讲经，纯善温馨，且深伏巧姐日后“留余庆”归田织桑之命途。三处依据：

- 「巧姐兒道：‘認了三千多字，念了一本《女孝經》，半個月頭里又上了《列女傳》。’」
- 「寶玉道：‘你念了懂得嗎？你要不懂，我倒是講講這個你聽罷。’賈母道：‘做叔叔的也該講究給侄女聽聽。’」
- 「巧姐兒道：‘二叔叔才說的，也有念過的，也有沒念過的。念過的二叔叔一講，我更知道了好些。’」

先后核对：宝玉向贾政贾母请安免学（前）→巧姐随奶妈先至贾母房请安（前）→宝玉与巧姐相谈，就《列女传》后妃贤能才德
逐一解说，巧姐聪颖向慕，贾母含笑静听（此刻）→众姐妹陆续至贾母房赴消寒宴（后）→司棋潘又安双亡信至凤姐处（后）
→冯紫英携母珠至贾政书房（后）。此刻群芳未至，祖孙三代暖阁静坐论书，清贵祥和。

## 器物与环境

- 地点：荣国府贾母正房东暖阁。设紫檀雕螭平头案、花梨木暖榻、织锦坐褥、落地雕花罩，室内设黄铜炭火盆。
- 时令天气：农历十一月初冬清晨；雪霁初晴，晨曦斜映窗棂，室内融融如春。
- 器物：线装木刻《列女传》善本书册、紫铜红炭火盆、红漆小茶盘、青花盖碗、青玉水仙浅盆清供。
- 现实中会动的：① 暖阁铜火盆上方升腾起一缕缕温润透明的热气微光；② 巧姐手中所捧线装册页书角随翻动微颤；③ 案头青玉浅盆中水仙花白瓣黄蕊受暖气微荡。

## 排除项

- 前后拍：凤姐房中闻司棋潘又安殉情绝命信；薛姨妈推托宝钗病情；冯紫英贾政对弈打劫；黑漆茶盘母珠吸引小珠；展玩鲛绡帐。
- 他回他场：不得出现刘姥姥二进荣府为巧姐起名；严禁司棋双棺自刎血光入画；不得出现抄家官差查抄洋货。
- 造型禁忌：严禁清代旗袍两把头与大拉翅；巧姐不可穿现代童装；贾母宝玉衣冠须依明代贵族世家法度。
