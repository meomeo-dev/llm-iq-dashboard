# 《红楼梦》第51回 薛小妹新编怀古诗　胡庸医乱用虎狼药

底本：<https://zh.wikisource.org/wiki/紅樓夢/第051回>；读取日期：2026-10-23。

## 情节要点

1. 薛宝琴以历年经各省古迹为题，新编十首怀古绝句，内隐十物；众人于暖香坞争相传阅称奇。
2. 宝钗指后二首《蒲东寺》《梅花观》取材杂书戏曲于史无考，主张删改；黛玉笑批宝钗“胶柱鼓瑟”，李纨探春皆赞同保留。
3. 袭人母病重告假回家探视，王熙凤安排皮袄车轿排场送行，并派晴雯、麝月夜间在宝玉房中上夜照看。
4. 晴雯夜间只穿单袄出房吓唬麝月，受了风寒，次日发热鼻塞咳嗽；宝玉避开王夫人，命婆子悄从后门请大夫入园诊视。
5. 新请胡庸医隔红绣幔诊脉，误开麻黄、枳实虎狼之剂；宝玉识破重请王太医开温和疏散方，在房中自寻银吊子煎药。

## 选定场面

暖香坞内室书案灯下：宝琴立于紫檀大平头案旁，手托新抄各省古迹怀古绝句诗笺，笑意盈盈；黛玉倚案展笺细读，巧笑驳议；宝钗端坐案侧执卷沉思，李纨、探春围聚案头争看奇谜，满室书香暖意融融。具名薛宝琴、林黛玉、薛宝钗三人展笺辩诗，李纨、贾探春环聚。选此场面因“小妹新编怀古诗”乃红楼诗社极富才情与人文巧思之名篇，十首绝句融古迹、物谜与命运隐喻于一体，闺阁灯下评诗论史，清雅温馨，全无疾疫用药之愁云。三处依据：

- 「众人闻得宝琴将素习所经过各省内的古迹为题，作了十首怀古绝句，内隐十物，皆说这自然新巧。」
- 「宝钗先说道：‘前八首都是史鉴上有据的，后二首却无考……不如另作两首为是。’」
- 「黛玉忙拦道：‘这宝姐姐也忒“胶柱鼓瑟”，矫揉造作了。’」

先后核对：众人出雪地进暖香坞，贾母看画制谜（前）→宝琴取出素日所作各省古迹十首怀古绝句诗笺，铺于案头（前）→宝琴展诗，宝钗疑后二首无考，黛玉笑驳“胶柱鼓瑟”，李纨探春称妙支持保留，众人灯下争看猜谜（此刻）→袭人母病告假，凤姐派行装（后）→晴雯夜起受寒，胡庸医隔幔诊脉乱投药剂（后）→王太医改方，宝玉自煎药（后）。此刻众女灯下聚首展笺论诗，诗情融洽，袭人尚未出府，晴雯尚未受凉感冒。

## 器物与环境

- 地点：大观园暖香坞内室（惜春画室书斋，设紫檀大平头案、画屏画轴、笔洗水丞、红泥小火炉、熏笼）。
- 时令天气：冬夜初降，室内红烛高照、银釭温润，暖香拂面，窗外暮色雪光掩映。
- 器物：粉红或素白洒金小楷诗笺十张、紫檀书案、笔架宣砚、铜烛台（火光融融）、茶盏。
- 现实中会动的：① 案头蜡烛焰心与红泥小火炉炭火微光轻跳；② 宝琴与黛玉手中轻薄诗笺随翻读微幅晃动；③ 窗外冬风穿竹、修竹雪影在窗纱上徐徐拂动。

## 排除项

- 前后拍：芦雪庵联句与雪坡宝琴立雪；袭人换盛装出府探母；晴雯穿单袄扑雪吓唬麝月；胡庸医隔红幔看三寸金凤花染红指甲；火盆上架银吊子熬煎虎狼药。
- 他回他场：不可出现贾宝玉避在书架后看诊；不可画第52回晴雯病中补雀金裘；不可画夏秋陈设。
- 造型禁忌：严禁清代旗人服饰两把头；严禁戏曲花衫；室内不得穿雪天厚斗篷（已卸大毛斗篷）。
