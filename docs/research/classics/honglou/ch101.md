# 《红楼梦》第101回 大观园月夜感幽魂　散花寺神签惊异兆

底本：<https://zh.wikisource.org/wiki/紅樓夢/第101回>；读取日期：2026-10-23。

## 情节要点

1. 凤姐精神恍惚夜巡大观园，途经秋爽斋与旷野土山之间，遇黑油巨犬尾随扑袭受惊，恍惚见秦氏幽魂警示盛衰。
2. 凤姐受惊成疾心神不宁，散花寺尼僧大了进府奉承，力荐散花寺神签灵验可析灾祥。
3. 凤姐抱病赴散花寺进香，佛殿昏沉古佛青灯，凤姐素服虔心拜祷摇动签筒。
4. 签筒跃出第三十三签“王熙凤衣锦还乡”，签诗“蜂采百花成蜜后，为谁辛苦为谁甜”，暗示凄凉败局惊异兆。

## 选定场面

散花寺佛殿大雄宝殿之内：残阳收尽暮霭初降，殿内昏暗森然，唯佛前青铜长明灯与高燃线香散发幽微金红光晕。王熙凤因惊魂病体未愈
神色苍白憔悴，身着月白暗花交领织锦长袄、墨绿素绫裙、头挽家常低髻插素银蝠簪，正双手紧捧髹黑圆木签筒跪于暗红锦缎蒲团之上；
竹质神签自筒中弹起一枝落地；凤姐目视掉落神签，瞳孔微张、眉心紧蹙，掠过极度惊惶与惊异之色；右侧下首，老尼大了身着缁衣光头
手持青铜烛台侍立，弯腰欲拾神签；佛龛上斑驳泥金佛像俯视众生，面容静穆莫测。具名王熙凤、大了二人。选此景因“散花寺神签惊异兆”
乃王熙凤机关算尽、一生宿命之盖棺警语，古佛青灯与荣华贵妇之衰竭对照鲜明，签诗“为谁辛苦为谁甜”字字诛心。三处依据：

- 「鳳姐到了散花寺中，先到各殿拈香。走到正殿，見菩薩塑得十分嚴肅莊嚴。」
- 「只見筒中骨碌碌的跳出一枝簽來，落在地下。大了連忙拾起，看了看……」
- 「簽上寫著‘第三十三簽 上上大吉’，底下寫著‘王熙鳳衣錦還鄉’。詩曰：‘去國離鄉二十年，於今衣錦返家園。蜂采百花成蜜後，為誰辛苦為誰甜？’」

先后核对：凤姐夜行大观园遇大犬与秦氏游魂惊魂得疾（前）→尼僧大了入府怂恿进香（前）
→凤姐散花寺大殿跪拜摇签筒，神签坠地现谶语异兆（此刻）→大了顺口阿谀谄媚解签“衣锦还乡”（后）
→凤姐归家疑虑更甚沉疴难愈（后）。此刻签落青砖、烛影摇曳，凤姐脸色骤变，宿命难逃。

## 器物与环境

- 地点：京郊散花寺正殿大佛堂。殿宇幽深古旧，栋宇沉黑，佛前长幡垂挂，青砖地面映照微弱烛影。
- 时令天气：初冬薄暮入夜时分；暮风穿过殿门，寒气逼人，殿角阴影重重。
- 器物：高大泥金阿弥陀佛坐像、青石供案、红木兽面签筒与竹签数枝、青铜三足香炉（盘香袅绕）、老铜莲花台油灯、猩红绣金蒲团。
- 现实中会动的：① 佛前长明灯与青铜烛台上幽微火苗在穿殿寒风中明灭跳荡；② 供案上方悬垂之朱红幡幔穗子随风徐徐摆荡拂拭；③ 自签筒飞坠落地之竹签在冰冷青砖上反弹翻滚微颤。

## 排除项

- 前后拍：大观园夜黑大犬扑身撕咬；秦可卿幽魂现身说话之灵异惊悚镜头；贾府内乱尤氏养病；凤姐归家与贾琏争执。
- 他回他场：不得出现第3回凤姐泼辣彩绣辉煌华贵服色；不得出现清代庙宇喇嘛喇嘛教装束；严禁鬼怪妖魔实体化丑陋表现。
- 造型禁忌：严禁清代旗装两把头与高底旗鞋；凤姐为重病贵妇祈禳素装，大了为典型汉传佛教缁衣尼僧，神色不可过度夸张作怪。
