# 《红楼梦》第93回 甄家仆投靠贾家门　水月庵风弄水月案

底本：<https://zh.wikisource.org/wiki/紅樓夢/第093回>；读取日期：2026-10-23。

## 情节要点

1. 贾赦携宝玉赴临安伯寿席观蒋玉菡演《占花魁》，彼此关切会心；贾府收租车于城外遭讹扣，门第渐现衰象。
2. 江南甄家遭抄没待罪，忠仆包勇携甄应嘉手书北上投奔贾府，贾政感念世交收留；荣宁二府门下滋生流言。
3. 荣宁两府夹道墙壁突现匿名飞贴，直揭贾芹在城外水月庵诱引女尼道童、滥支月钱之风月丑案。
4. 贾政内书房震怒命查办，赖大奉密谕疾驰水月庵查抄，将诸女尼道童拘押进府，唯芳官独守清白不入俗流。

## 选定场面

城外水月庵殿前石阶与禅舍：初冬傍晚，枯柏老松萧森。贾府大总管赖大身披石青斗篷、脚踏青石台阶，手执马鞭面带霜威，
正声传贾政彻查令谕；贾芹身着宝蓝细绢夹袍立于客堂雕花木槅前，神情仓皇惶遽、躬身拱手迎问；右侧幽静禅舍窗前，昔日
大观园优伶芳官身着素灰缁衣缁帽，双手合十持菩提念珠，神情冷峻超脱、孤标自许，冷眼旁观尘网喧扰。具名赖大、贾芹、
芳官三人。选此景因“水月庵案”为贾府家风败坏由暗转明之转折，以芳官“惟有芳官不来”之高洁孤傲，反衬贾芹之卑琐荒唐，
深扣水月镜花之悲剧意蕴，且严避风月狎昵，尽显端方冷峻。三处依据：

- 「那些女孩子都高興，便擺起桌子，連本庵的女尼也叫了來，惟有芳官不來。」
- 「正說著，只見道婆急忙進來說：‘快散了罷，府里賴大爺來了。’」
- 「話猶未完，已見賴大進來，見這般樣子，心里大怒。為的是賈政吩咐不許聲張，只得含糊裝笑」

先后核对：临安伯府看戏饮酒（前）→包勇投府（前）→两府夹道现揭帖，贾政震怒遣人（前）→赖大跨骡疾至水月庵宣谕，
贾芹仓皇迎谒，芳官静室冷眼以对（此刻）→赖大封庵驱车载人回城（后）→贾政补班入署（后）。此刻赖大刚踏阶传讯，
贾芹惊愕失措，芳官凝神超拔，风波骤起。

## 器物与环境

- 地点：京郊城外水月庵后殿庭院与禅舍。古松枯柏相映，青石台阶苔痕斑驳，门前挂布幡，远处隐现青幔大车。
- 时令天气：农历十月中旬初冬傍晚；朔风料峭，寒鸦归林，铅灰暮云笼罩。
- 器物：铁铸古铜兽耳香炉、缁衣念珠、禅案木鱼、马鞭、青幄大车。
- 现实中会动的：① 殿前铁香炉内残香随冷风飘起细缕青烟；② 庭中老松干枯斜枝在朔风中微动起伏；③ 赖大斗篷下摆受寒风吹拂微幅摆动。

## 排除项

- 前后拍：贾芹与沁香、鹤仙划拳赌酒之放浪行径；贾政拍案怒斥贾琏；夹道小厮窃看飞贴；女尼道童哭叫登车；临安伯府戏台。
- 他回他场：不得出现栊翠庵妙玉品茶；严禁甄府抄家流血现场；严禁庵内任何违规男女狎昵动作。
- 造型禁忌：严禁清代顶戴长辫与僧尼不整衣饰；芳官缁衣须整肃端方；赖大与贾芹衣冠符合明代官宦世家规制。
