# 《红楼梦》第88回 博官家宁国府逢祥　惜春院荣国府避乱

底本：<https://zh.wikisource.org/wiki/紅樓夢/第088回>；读取日期：2026-10-23。

## 情节要点

1. 贾母将临八十一岁（暗九），许下九昼夜大功德，发心命惜春抄写三千六百部《金刚般若波罗蜜经》。
2. 鸳鸯赍黄绢袱包至大观园蓼风轩宣贾母之意，惜春方揣摩棋谱，接经受命以笔墨写经静心自守。
3. 宝玉携蝈蝈篾笼承欢贾母膝下，盛赞贾兰敏学工对；宁国府鲍二与何三醉酒争吵斗殴，贾珍严正家法鞭挞惩仆。
4. 贾芸备礼欲结纳凤姐谋求工部差事，凤姐因贾政掌印谨防弊端严词拒纳，惜春深居暖阁冷眼避远荣宁纷扰。

## 选定场面

大观园蓼风轩暖阁惜春领写佛经避喧：孟冬晴昼，大观园深处蓼风轩暖阁幽静清肃。画面中部十三四岁贾惜春
身着浅缃色窄袖交领棉袄、水绿绫裙，端坐于朱红炕几案前，手执紫毫小楷，神情淡漠冷峻、凝神于黄绢经册之上；
画面左侧十九岁鸳鸯身着素青罗袄、月白绫裙，双手恭敬将御赐黄绢经包奉于黑漆描金案上；画面右侧侍女彩屏
正轻揭暖阁门帘，暖炕边小铜熏炉泛着温香。具名贾惜春、鸳鸯、彩屏三人。选此景因惜春在蓼风轩领写《金刚经》
为全书重要伏笔，“身在富贵丛，心在佛门外”，避喧避乱、独善其身，极具孤标意境。三处依据：

- 「惜春正在那里揣摩棋谱，忽听院内有人叫彩屏，不是别人却是鸳鸯的声儿。」
- 「老太太因明年八十一岁，是个暗九。许下一场九昼夜的功德，发心要写三千六百部《金刚经》。」
- 「惜春道：‘老太太的吩咐，我敢不依么。’」

先后核对：贾母发心许愿建九昼夜功德祈福（前）→鸳鸯携小黄绢包至蓼风轩宣老太太之命，惜春接经发心抄写
《金刚经》，独守深阁避乱（此刻）→鸳鸯回贾母处见宝玉提蝈蝈笼承欢、李纨对弈双陆（后）→贾珍东府鞭挞
恶仆、贾芸行贿受拒（后）。此刻惜春青灯黄卷、脱略纷华，孤高自持。

## 器物与环境

- 地点：大观园蓼风轩暖阁。设红雕漆平头炕几、紫檀多宝槅、围棋盘与棋子盒、明瓦花窗透入晴和冬阳。
- 时令天气：农历十月下旬初冬，天气晴干清冷，暖阁内设小脚炉与炭盆，纸窗映出暖光。
- 器物：明黄绢经包、泥金楷书《金刚经》样册、紫毫蝇头小楷笔、徽墨端砚、青瓷水盂、素铜手炉。
- 现实中会动的：① 炕几案头铜手炉镂空雕盖中丝缕微烟缓慢游移上升；② 暖阁门槛处被彩屏掀起的青毡夹帘在微风中轻微摆动；③ 窗外冬风吹拂庭前枯柳细枝缓缓摇曳，纸窗上枯影轻移。

## 排除项

- 前后拍：宁国府贾珍坐堂捆打鲍二何三、家法鞭笞皮开肉绽；贾芸提礼盒钻营凤姐门路；凤姐院小丫头撞鬼受惊。
- 他回他场：不得出现惜春画大观园行台起稿；严禁水月庵静虚招摇撞骗；严禁血腥私刑。
- 造型禁忌：严禁男子长辫、恶仆刑具入画；严禁清朝满洲旗装；惜春与鸳鸯服饰清素典雅，不着浓艳珠翠。
