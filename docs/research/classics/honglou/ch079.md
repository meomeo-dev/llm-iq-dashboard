# 《红楼梦》第79回 薛文龙悔娶河东狮　贾迎春误嫁中山狼

底本：<https://zh.wikisource.org/wiki/紅樓夢/第079回>；读取日期：2026-10-23。

## 情节要点

1. 贾赦执意将迎春许配大同府指挥孙绍祖，贾政深恶孙家劝阻无效，贾母亦不甚合意；邢夫人接迎春出园备嫁。
2. 宝玉痛惜迎春出阁与随嫁丫鬟离散，长叹“世上又少了五个清洁人”，日日漫步至紫菱洲徘徊瞻顾、凭轩感伤。
3. 宝玉睹紫菱洲轩窗寂寞、蓼花残荷凋零，信口吟成《紫菱洲歌》；香菱偶过紫菱洲，笑问宝玉何故发呆。
4. 薛蟠迎娶桂花夏家夏金桂，金桂生性娇悍妒忌，过门后作威作福降服薛蟠，薛蟠暗自悔恨莫及。

## 选定场面

大观园紫菱洲蓼溆水畔：深秋向晚，残阳铺水。迎春已迁出备嫁，紫菱洲缀锦楼轩窗深闭、屏帐翛然。宝玉着素雅秋袍独立
水草丛边，抚石怅然长吟《紫菱洲歌》方罢；香菱为薛蟠娶亲之事入园寻凤姐恰好路过，自右侧石径花木丛中转出，手携香帕，
拍手含笑探问宝玉“又发什么呆呢”。具名贾宝玉、香菱二人。选此景因宝玉题咏《紫菱洲歌》与香菱天真贺喜形成全书至深
悲剧反衬，以空阔萧索之园林盛景折射金陵十二钗离散飘零，回避暴力冲突而极富诗意张力。三处依据：

- 「因此天天到紫菱洲一帶地方徘徊瞻顧，見其軒窗寂寞，屏帳翛然」
- 「再看那岸上的蓼花葦葉，池內的翠荇香菱……是以情不自禁，乃信口吟成一歌」
- 「忽聞背後有人笑道：‘你又發什麼呆呢？’寶玉回頭忙看是誰，原來是香菱。」

先后核对：迎春被接出大观园备嫁（前）→宝玉深感悲切，日日漫步至紫菱洲凭吊（前）→见轩窗寂寞、蓼花残荷，信口长吟
《紫菱洲歌》（前）→香菱入园寻凤姐路过紫菱洲，见宝玉痴立，拍手笑问“又发什么呆呢”，宝玉回身惊顾（此刻）→二人驻足
笑叙薛蟠迎娶夏金桂与大观园近况（后）→香菱往稻香村寻凤姐（后）→薛蟠娶夏金桂、薛家大乱（后）。此刻宝玉刚吟罢回首，
香菱拍手笑问，两相映衬。

## 器物与环境

- 地点：大观园紫菱洲缀锦轩外蓼溆水际。朱栏回廊、槅扇深掩，庭前老树萧疏、太湖假山石壁立，池中残荷宿鹭。
- 时令天气：农历九月深秋；天气清寒，夕阳向晚微风拂水，池边蓼花开遍、黄叶飘坠。
- 器物：紫菱洲雕花朱漆水槛、太湖奇石、紧闭斑竹软帘、岸上深浅蓼花苇叶、池中枯焦荷茎。
- 现实中会动的：① 水际丛生之蓼花与苇叶在秋风中轻拂摇曳；② 紫菱洲紧闭轩窗垂下的斑竹帘角随风微卷；③ 池塘秋水微泛清漪，一两片枯黄落叶随水波缓缓漂浮。

## 排除项

- 前后拍：贾赦强配孙绍祖；贾政劝谏无效；夏金桂过门坐花轿大吹大打；夏金桂撒泼撕扯弹压薛蟠；香菱遭毒打。
- 他回他场：严禁夏金桂泼醋打人见血；严禁孙绍祖家暴摧残迎春；不得出现晴雯病亡幻境；严禁任何床帏狎昵。
- 造型禁忌：严禁清代旗袍旗头、长辫马褂与马蹄袖；严禁作冬季落雪或盛夏天水景致。
