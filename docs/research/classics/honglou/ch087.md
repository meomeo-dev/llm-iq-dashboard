# 《红楼梦》第87回 感深秋抚琴悲往事　坐禅寂走火入邪魔

底本：<https://zh.wikisource.org/wiki/紅樓夢/第087回>；读取日期：2026-10-23。

## 情节要点

1. 黛玉得宝钗家书深感同病相怜，触景伤情忆及海棠诗社盛况，听窗外檐铁齐鸣、秋风扫叶而独自伤神。
2. 宝玉往蓼风轩访惜春，见妙玉与惜春静坐对弈围棋，妙玉见宝玉来面露羞意、拂袖而去。
3. 是夜深秋月冷，宝玉与妙玉步月至潇湘馆墙外，隔竹闻黛玉于幽轩内抚琴悲歌《秋思赋》，琴韵由幽怨转急促突崩。
4. 琴弦忽崩断，妙玉惊呼“其音太过”，二人骇然避回；栊翠庵妙玉夜半打坐心神走火入魔。

## 选定场面

潇湘馆秋夜隔竹听琴：深秋冷月高悬，潇湘馆千竿修竹在霜风中萧瑟摇曳。画面右侧潇湘馆幽轩内纱窗明澈、微灯如豆，
十六岁林黛玉着素白暗花长袍、青缎背心，临轩端坐琴几前抚弄七弦朱漆古琴，低眉沉吟；画面左侧修竹矮墙外曲径小桥上，
二十岁妙玉身着月白缁衣道袍手持白丝麈尾驻足侧首，十七岁贾宝玉着石青斗篷随立身侧，二人踩着斑驳竹影屏息凝神侧耳细听琴韵。
具名林黛玉、妙玉、贾宝玉三人。选此景因月下隔竹听琴为全书极具诗意与空灵哲理之经典名场面，琴音通神、知音互感，
避开一切走火入魔与恐怖怪诞。三处依据：

- 「两人便顺着脚步，走至一处，听见隐隐竹林深处有琴声。」
- 「只见黛玉一人坐在窗前，几上放着抚好的琴，香炉里冉冉的香烟未断。」
- 「只听见琴声呜咽，似有感触，……妙玉侧耳听了半天，说道：‘这琴声好是好，只是太哀怨了。’」

先后核对：惜春妙玉弈棋散局，妙玉离蓼风轩月夜回庵，宝玉相伴行至翠竹小径（前）→至潇湘馆粉墙修竹外，听闻
林黛玉幽窗抚琴长吟《秋思》，妙玉宝玉屏息潜听（此刻）→琴音忽厉、四叠弦断，妙玉断言“音太过”（后）→妙玉
回庵禅坐受魔扰（后）。此刻清月溶溶，琴韵清冷，妙玉与宝玉月下侧听，极富红楼空灵禅韵，严格排除走火魔怪之景。

## 器物与环境

- 地点：大观园潇湘馆外竹林曲径与窗前幽轩。一堵粉墙掩映千竿翠竹，曲折青石甬道，半空一轮冷月与飞云。
- 时令天气：农历深秋孟冬之交寒夜，冷风萧瑟，霜华满地，庭院静谧幽寒。
- 器物：七弦朱漆古琴、紫檀琴桌、窗内青玉香炉、竹林外青白石栏、妙玉手中古木柄白丝麈尾。
- 现实中会动的：① 潇湘馆幽窗内青玉香炉中袅袅上升的一柱细细青烟微折盘旋；② 墙外高低修竹与竹梢在萧萧秋夜寒风中往复倾晃；③ 悬空冷月前几缕流移淡云缓慢平移掠过，地表竹影微动。

## 排除项

- 前后拍：妙玉栊翠庵夜坐走火入魔、群鬼夜叉幻象；潇湘馆琴弦崩断惊呼；惜春蓼风轩乱丢棋子；黛玉伤秋咳喘。
- 他回他场：不得出现栊翠庵品梅花雪水茶；严禁凹晶馆湘云黛玉中秋联诗；严禁血腥凶煞。
- 造型禁忌：妙玉不可作光头僧尼或妖娆少妇；严禁鬼怪妖魔与阴森恐怖之相；严禁清代长辫旗装。
