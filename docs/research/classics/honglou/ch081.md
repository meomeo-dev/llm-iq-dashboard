# 《红楼梦》第81回 占旺相四美钓游鱼　奉严词两番入学堂

底本：<https://zh.wikisource.org/wiki/紅樓夢/第081回>；读取日期：2026-10-23。

## 情节要点

1. 迎春归孙家后王夫人暗自伤感，宝玉欲接迎春回园遭王夫人严斥，转至潇湘馆，黛玉规劝其安心念书求取功名。
2. 宝玉回怡红院翻看古卷引动感伤，依袭人之劝到大观园中散心，经沁芳亭、蘅芜院，转过藕香榭至蓼溆水边。
3. 见探春、李纹、邢岫烟（与李绮）凭栏垂钓，宝玉投石戏弄，提议以钓鱼“占旺相”测年运；众人轮流垂钓各有所获。
4. 轮至宝玉垂钓心急用力过猛，将竿碰石折为两段；麝月急奔来报贾母相召，贾政严厉督饬宝玉重入家塾攻读。

## 选定场面

大观园蓼溆水榭石矶畔：初冬晴朗，水天如镜。探春体态英挺，立于朱红雕花凭栏处，双手巧提翠竹钓竿，竿丝垂入澄澈碧水，
一条杨叶窜儿欢跃出水；身旁李纹、邢岫烟二位少女着素雅锦袄凭栏探身微笑凝望；侍书半蹲于石矶平整处，双手小心捧着盛水
小磁坛；宝玉自太湖假山石后雀跃探身，手持小石作势欲掷，满面淘气顽皮。具名贾探春、邢岫烟、李纹、贾宝玉四人（侍书
旁衬）。选此景因“四美钓游鱼”为程高本开卷第一闺阁雅趣，水畔垂钓以占旺相，群芳笑语嫣然，在大观园萧瑟渐显的大势中
平添一抹灵动生机与青春亮色。三处依据：

- 「轉過藕香榭來，遠遠的只見幾個人在蓼漵一帶欄杆上靠著……有幾個小丫頭蹲在地下找東西。」
- 「探春把絲繩拋下，沒十來句話的工夫，就有一個楊葉竄兒吞著鉤子把漂兒墜下去，探春把竿一挑，往地下一撩，卻活迸的。」
- 「侍書在滿地上亂抓，兩手捧著，擱在小磁壇內清水養著。」

先后核对：宝玉向王夫人诉迎春之冤遭训，往潇湘馆见黛玉论读书（前）→宝玉回怡红院阅古书伤怀，入园散步（前）→行至
蓼溆见探春、李纹、李绮、岫烟凭栏垂钓，丫鬟草间捉饵（前）→探春垂钓起杨叶窜儿，侍书捧小磁坛注水盛鱼，宝玉匿山石后
作势投石惊鱼（此刻）→宝玉跳出山石提议钓鱼“占旺相”（后）→宝玉急躁断竿（后）→麝月传贾母相召（后）。此刻探春正挑竿
得鱼，侍书捧磁坛，宝玉隐于石后探首戏弄。

## 器物与环境

- 地点：大观园蓼溆（邻近藕香榭水际水榭）。朱漆雕花木栏杆依水而筑，旁立峥嵘太湖石矶；池水清澈见底，岸边垂柳残叶倒映。
- 时令天气：初冬孟冬晴日；天光微凉而明澈，微风吹拂水面，日色淡金。
- 器物：精细翠竹钓竿、蚕丝钓线、细苇浮漂、青花小磁坛、水榭朱栏、太湖石矶。
- 现实中会动的：① 探春挑起之翠竹钓竿尖端与垂挂小鱼在半空欢跳微晃；② 水面钓丝周围漾开一圈圈同心细细清漪；③ 小磁坛中清水微漾泛出微细反光。

## 排除项

- 前后拍：王夫人房中训斥宝玉；潇湘馆黛玉劝勉用功读书；宝玉急躁碰断鱼竿折断钓丝；麝月慌跑报贾母急召；贾政严命入塾。
- 他回他场：不得出现迎春在孙家受虐；不得出现贾府内堂盘查家奴；严禁冬季风雪漫天或盛夏荷花盛景。
- 造型禁忌：严禁清代旗装旗头大拉翅；侍书不可穿粗劣破衣；严禁钓竿画成现代滑轮海竿。
