# 《红楼梦》第14回 林如海捐馆扬州城　贾宝玉路谒北静王

底本：<https://zh.wikisource.org/wiki/紅樓夢/第014回>；读取日期：2026-10-20。

## 情节要点

1. 宁国府总管来升听说请了凤姐理事，嘱同事小心；凤姐点名册、分派差使，定卯正二刻点卯，
   每处专人专责，缺损由守处之人赔偿。
2. 五七正日凤姐寅正起身，卯正二刻乘车到宁府，灵前哭过，回抱厦发放荣、宁两府领牌的人；
   一名迟到者被责二十板、革一月银米。
3. 宝玉带秦钟到抱厦，向凤姐讨对牌；昭儿自苏州回报，林如海九月初三日殁，贾琏送黛玉扶灵回苏。
4. 贾珍勘定铁槛寺为寄灵处；凤姐预备送殡车轿；出殡日路旁各家设祭棚，北静王水溶设路奠，
   与贾珍等以国礼相见，命宝玉脱孝服来见，本回止于宝玉望见水溶（会面在第15回开头）。

## 选定场面

宁国府抱厦内，凤姐坐在案后，一旁有人执簿念帖，荣国府的王兴媳妇站在案前领牌取线；
凤姐听毕，认为数目相合，正取出荣国府对牌向案前掷下。具名凤姐、王兴媳妇，另有执簿
记录者和垂手立在一旁、尚未发落的迟到者。选它是因“点卯理事、凭牌发物”正是凤姐协理的
日常，场景单一，全在室内，不必画任何责罚。三处依据：

- 「那凤姐不畏勤劳，天天于卯正二刻就过来点卯理事，独在抱厦内起坐」
- 「连忙进去说：“领牌取线，打车轿网络。”」
- 「凤姐听了，数目相合，便命彩明登记，取荣国府对牌掷下。」

先后核对：寅正梳洗，卯正二刻到宁府，灵前坐大圈椅哭，被劝止（前）→回抱厦，按名查点，
传来迟到者，凤姐“且不发放这人”（前）→王兴媳妇探头，递帖，彩明念，凤姐掷荣国府对牌
（此刻）→王兴家的去，另四名荣府执事来领牌，凤姐指两件开销错了，掷还帖子（后）→
喝命“带出去，打二十板子”（更后，不画）。此刻迟到者仍站着，没有喝令，没有板子。

## 器物与环境

- 地点：宁国府“三间一所抱厦”（第13回末），凤姐“独在抱厦内起坐”；有门有窗（“窗外”“在前探头”）。
  抱厦是接在正屋前或后的小厅（据摘要）。陈设本回未写，兜底：长案一张，案上簿册、笔砚、茶盏，
  椅一把带椅搭，脚踏。
- 时令：到宁府时为卯正二刻，约六时半（据摘要），理事在其后；季节本回未写，不强加景物，
  兜底：晨光从窗入。
- 器物：对牌形制原文未写，兜底：掌心大小的小牌，不画字；帖子为纸帖。
- 现实中会动的：① 门帘或窗帘被晨风吹动；② 茶盏热气；③ 记录者执笔往复书写、簿页轻翻。

## 排除项

- 后拍：打板子、革银米、掷宁国府对牌、荣府四执事领牌、宝玉秦钟来抱厦、昭儿报讯、凤姐怒容；
  前拍：灵前大哭、登仙阁、前一日点花名册。
- 不画灵柩、灵堂、僧道法事、受罚者；不画北静王路祭与出殡队伍（会面在第15回）。
- 造型：凤姐不穿第3回大红装，不画87版橙金色调（据摘要）、清宫剧两把头、花盆底。
