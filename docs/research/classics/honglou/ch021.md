# 《红楼梦》第21回 贤袭人娇嗔箴宝玉　俏平儿软语救贾琏

底本：<https://zh.wikisource.org/wiki/紅樓夢/第021回>；读取日期：2026-10-20。

## 情节要点

1. 湘云跑开，黛玉追到门口被宝玉拦住，宝钗劝开；当晚湘云仍宿黛玉房中。次晨宝玉到黛玉房里，
   在镜台旁等她们梳洗，央湘云替他梳头。
2. 袭人见宝玉与姊妹们厮闹，冷淡嗔怪；宝玉夜读《庄子·胠箧》续写文字，次晨折簪赔罪。
   黛玉见了续文，题诗讽他。
3. 凤姐的女儿大姐出痘，贾琏搬到外书房，与仆妇多姑娘相识；痘愈搬回后，平儿在枕套里抖出一绺
   头发，替贾琏瞒过凤姐。

## 选定场面

黛玉房中清晨：宝玉坐在镜台旁，湘云站在他身后，扶着他的头，一边编辫一边说话；黛玉在一旁
盥手，冷眼看着。具名宝玉、湘云、黛玉三人，可加侍立的丫鬟作群像。宝玉梳头时坐立原文未写，
他此前“坐在镜台旁边”，题面按坐在镜台旁的凳上。选它是因梳头是全回最有家常气的一幕，三人
亲昵、打趣、吃味靠动作就能读出，辫上红绦、珍珠、金坠脚有鲜明的视觉。三处依据：

- 「好妹妹，替我梳上头罢。」
- 「只将四围短发编成小辫，往顶心发上归了总，编一根大辫，红绦结住。」
- 「湘云一面编着，一面说道：“这珠子只三颗了，这一颗不是的。”」

先后核对：宝玉披衣靸鞋进黛玉房，见二人睡着，退出（前，床上的情形不画）→二人穿衣起来，宝玉
复进，坐在镜台旁，紫鹃、雪雁进来伺候梳洗（前）→湘云洗面，宝玉趁残水弯腰洗脸，青盐擦牙漱口
（前）→湘云“已梳完了头”，宝玉央“好妹妹，替我梳上头罢”，湘云推说忘了，经再三央告才肯（前）
→湘云扶过他的头编辫，指出珠子少了，黛玉在旁盥手冷笑（此刻）→宝玉拿起妆奁里的胭脂要往口边送，
被湘云“拍”的一下打落（后）→袭人进来（后）。此刻宝玉手里没有胭脂，湘云没有动手打，辫子正在编，
尚未编完。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾宝玉 | 少年，约十二三岁；本回写“在家不戴冠，并不总角”，将四围短发编成小辫，归总编一根大辫，红绦结住，自发顶至辫梢一路四颗珍珠、下面有金坠脚，所以不戴冠、不勒抹额（他说“又不带冠子勒子”）；清晨“披衣靸鞋”赶来，兜底：家常素雅袍服，衣襟整齐，足下不画拖鞋；辫上珍珠，依湘云所说三颗同式、一颗不同（据其话的解读）；低头任湘云梳理，含笑 | 第21、3回 |
| 史湘云 | 少女，年岁未写；本回写她“已梳完了头”，“二人都穿了衣服”，发式衣色未写；兜底：整齐的家常发髻，不画披散长发；素雅家常袄裙，衣襟端正，不露臂（金镯只在睡态写及，不画）；立于宝玉身后，一手扶其头，一手持篦子，神情嗔笑 | 第21回 |
| 林黛玉 | 少女，约十二岁（据摘要）；眉眼见第3回；已梳洗，“一旁盥手，冷笑”；兜底：素雅家常衣裙，发式整齐，面带薄嗔；手在盆中或正取巾 | 第21、3回 |
| 紫鹃、雪雁（可选） | 黛玉的丫鬟，本回写她们“进来伏侍梳洗”，紫鹃递香皂；年岁衣冠未写，兜底：少女丫鬟，素色袄裙，捧盆或巾，侍立一旁；最多画两名 | 第21回 |

## 器物与环境

- 地点：黛玉卧房，镜台近旁。原文：“镜台两边俱是妆奁等物”。明代镜台多为带镜架的梳妆匣，盖掀起支镜、
  匣内多屉（据搜索摘要）；兜底：一具木制镜台，镜面斜立，两侧放妆奁。
- 洗漱用具：盆、青盐、香皂、手巾（均见原文）；画面只取一只盥洗盆，黛玉手在盆边。
- 梳具：篦子，湘云手中；辫饰：红绦、四颗珍珠、金坠脚。
- 时令天气：承上回为正月（第20、22回称“大正月里”）；清晨，“这天还早呢”；室内光线柔和。
- 现实中会动的：① 湘云手中编动的发辫与篦子；② 盆里被黛玉搅动的水波；③ 辫梢的金坠脚与珍珠
  随她动作轻晃。

## 排除项

- 前拍：湘云、黛玉睡态，湘云外露的手臂与金镯，宝玉替她盖被，二人同衾（一概不画）；
  宝玉弯腰在盆中洗脸、青盐擦牙。后拍：宝玉拈胭脂，湘云拍落；袭人进房，与宝钗对话。
- 他场：袭人嗔怪、四儿倒茶、续《庄子》、折玉簪、黛玉题诗、大姐出痘、多姑娘、平儿收头发、贾琏。
- 造型：宝玉不戴紫金冠与抹额，不画披风；女子不画清宫剧两把头与花盆底，发式不画披散长发；
  男子不画辫子与顶戴；不用 87 版造型。
