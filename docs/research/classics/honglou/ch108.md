# 《红楼梦》第108回 强欢笑强作祝寿宴　死相催惜别诉离情

底本：<https://zh.wikisource.org/wiki/紅樓夢/第108回>；读取日期：2026-10-23。

## 情节要点

1. 贾政奏请大观园入官未准，封闭荒园命包勇看守；荣府紧缩开支裁汰奴仆以资度日。
2. 史湘云出嫁回门请安，贾母欲借喜事驱遣阴霾，于荣庆堂设家宴为宝钗庆贺生辰。
3. 宴席间众人勉力强欢笑语行令掷骰，宝玉环顾不见黛玉触景生情，暗自饮泣借故离席。
4. 宝玉夜行至荒芜潇湘馆，见秋竹萧疏落叶满阶，冷风悲鸣如黛玉怨诉，抚景伤情恸绝断肠。

## 选定场面

月夜荒芜潇湘馆宝玉独立修竹下抚景伤情：仲秋深夜，大观园潇湘馆庭前幽篁寂落。残月如钩、清光如洗，万竿修竹
苍凉冷落；宝玉身着月白素面交领单袍，只身僵立于落叶覆阶的苔石旁，单手抚摸冰冷湘妃斑竹，掩面垂泪痛断肝肠；
远景竹径转角处，袭人手提八角琉璃宫灯急步寻来。具名贾宝玉、花袭人二人。选此景因宝玉夜访潇湘馆为后四十回
至情至痛之神笔，以荒园枯竹反衬昔日海棠诗社之盛，生死相隔、人去楼空，典雅清峻，极具悼亡宿命悲剧感。三处依据：

- 「复又看看湘雲寶釵，雖說都在，只是不見了黛玉，一時按捺不住，眼淚便要下來。」
- 「寶玉走進瀟湘館，但見落葉滿階，修竹蕭疏，滿屋漆黑，早已人去樓空。」
- 「只見一陣冷風吹來，那竹梢上發出凄凄慘慘的響聲，寶玉心酸腸斷，放聲大哭。」

先后核对：荣庆堂为宝钗做生日行令强颜欢笑（前）→宝玉借口换衣出席避席（前）→宝玉独自潜入荒闭潇湘馆，
抚竹望月凄恸哀号追悼黛玉（此刻）→袭人持灯自竹径后匆匆寻至解劝（后）→宝玉疑幻听闻潇湘幽咽鬼哭（后）。
此刻残月冷竹，孤影抚石，人去楼空万籁悲鸣。

## 器物与环境

- 地点：大观园潇湘馆庭院。万竿湘妃斑竹萧森，庭前青石台阶堆积枯叶残枝，旧匾暗淡，窗扉紧锁。
- 时令天气：农历八月下旬仲秋深夜；秋风惨冽刺骨，冷月斜挂竹梢，露湿苔痕。
- 器物：湘妃斑竹、八角琉璃防风宫灯、斑驳石阶、枯黄落叶、素白绣帕。
- 现实中会动的：① 潇湘馆万竿斑竹竹梢在萧瑟秋风中簌簌摇曳、发出凄凉呜咽声；② 袭人急行寻来时手中所提八角琉璃灯的昏黄光圈在竹径青石上微微摇晃晃荡；③ 宝玉身上的月白单袍素袖在秋夜寒风中翻卷飘摆。

## 排除项

- 前后拍：堂上寿宴掷骰耍令喧腾之强欢假笑；包勇醉卧荒园痛骂贾雨村；厉鬼狰狞显形；疯魔乱滚。
- 他回他场：不得出现第23回西厢记并坐落花；不得出现第27回葬花吟；严禁阴森恐怖荒诞怪异。
- 造型禁忌：严禁清朝长辫、马蹄袖与旗装两把头；宝玉不着寿宴大红吉服，更易为月白素袍以全至情悼念。
