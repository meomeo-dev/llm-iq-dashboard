# 《红楼梦》第97回 林黛玉焚稿断痴情　薛宝钗出闺成大礼

底本：<https://zh.wikisource.org/wiki/紅樓夢/第097回>；读取日期：2026-10-23。

## 情节要点

1. 贾政任期迫促急于完婚，贾母王夫人定计明娶宝钗冲喜兼安香火，调包瞒哄宝玉以安其神魂。
2. 潇湘馆内黛玉病势垂危已入膏肓，自知大限将至，神情凄冷淡漠，气绝声微。
3. 黛玉命雪雁点灯并笼上火盆移至炕边，命取题诗旧帕与平生所作诗稿，狠命掷入烈火之中。
4. 贾府另一端怡红院鼓乐喧天、宝钗盛妆出闺行大礼，潇湘馆冷月残灯、香消玉殒在即。

## 选定场面

潇湘馆幽竹深处的病榻之前：早春正月料峭寒夜，室内素幔低垂、青灯如豆。病榻之上林黛玉容颜枯槁消瘦至极却不失仙风傲骨，
着牙白暗花素绫寝衣，半欠身躯颤抖支撑；双眸冷光森然注视炕几铜火盆中腾起的烈烈火舌；手中紧攥之题诗旧竹绫帕与宿命诗稿
正片片焦黑卷曲化为灰烬；榻侧紫鹃泪流满面、双手欲夺又不敢骤惊姑娘；雪雁刚端铜火盆置于小几，呆立掩面抽泣。
具名林黛玉、紫鹃、雪雁三人。选此景因“焚稿断痴情”乃全书绛珠仙子还泪宿命之绝笔象征，诗帕焚尽即痴情断绝，
避开宝玉喜堂之喧嚣与后续断气死相，以室内孤灯火舌之极静大悲凸显毁灭之美。三处依据：

- 「黛玉這才將方才的絹子拿在手中，瞅著那火點點頭兒，往上一撂。」
- 「紫鵑怕他也要燒，連忙將身倚住黛玉，騰出手來拿時，黛玉又早拾起，撂在火上。此時紫鵑卻夠不著……」
- 「雪雁只得端上來，出去拿那張火盆炕桌。那黛玉卻又把身子欠起，紫鵑只得兩隻手來扶著他。」

先后核对：黛玉病重向紫鹃索要旧帕（前）→雪雁取帕点灯笼火盆（前）→黛玉欠身扶火盆狠命掷帕焚诗稿，二鬟垂泪惊呼（此刻）
→黛玉痰喘气厥沉沉昏睡（后）→宝玉怡红院揭盖头见宝钗呆怔（后）。此刻火苗窜起、诗帕卷化灰烬，决绝断情，凄楚庄严。

## 器物与环境

- 地点：大观园潇湘馆寝堂病榻。素竹帘半卷，四壁清寒，窗外万竿修竹在冷夜中萧索摇曳。
- 时令天气：时值早春正月料峭寒夜；夜色漆黑如墨，残星隐退，冷风自窗缝微透。
- 器物：红木雕花小炕几、紫铜镂空兽首炭火盆（内燃红萝炭）、题诗旧茜纱白绫帕、手抄诗稿线装残卷、白铜豆油灯。
- 现实中会动的：① 铜火盆中炭火吐出淡青与橘红焰舌，题诗绫帕遇火翻卷飞腾黑灰；② 几案上青灯油盏之豆大灯花在冷风中轻微跳跃颤动；③ 黛玉素白寝衣广袖及散垂发丝在欠身微颤中轻轻拂荡。

## 排除项

- 前后拍：王夫人贾母密谋调包计；凤姐调度吉庆喜轿；怡红院宝玉揭宝钗盖头；黛玉气绝两眼翻白之惨死相。
- 他回他场：不得出现第34回题诗旧帕之娇羞少女神态；不得出现贾府喜堂之红绸吉服；严禁床帏狎昵与病容秽污。
- 造型禁忌：严禁清代旗装大拉翅与满汉杂糅吉服；黛玉神态为高洁决绝之宿命大悲，严禁蓬头垢面泼妇自毁相。
