# 《红楼梦》第2回 贾夫人仙逝扬州城　冷子兴演说荣国府

底本：<https://zh.wikisource.org/wiki/紅樓夢/第002回>；读取日期：2026-10-20。

## 情节要点

1. 接上回：差人传封肃，原来新任知府贾化就是贾雨村，他送银缎酬谢甄家娘子，又讨甄家丫鬟娇杏作二房，
   后扶为正室。
2. 雨村任官不久因贪酷被革职，游至扬州，被巡盐御史林如海聘作独女黛玉（五岁）的塾师；一年后黛玉之母
   贾氏病逝，黛玉哀痛多病，连日不上学。
3. 雨村出城闲步，到山环水旋处，见破败的智通寺，门旁有旧对联；入寺只见一个又聋又昏的老僧煮粥，
   遂转往村肆沽酒。
4. 村肆里遇旧识冷子兴，二人饮酒闲谈：宁荣二府世系，宝玉衔玉而生、周岁抓周，雨村论正邪两赋之人，
   又谈甄家宝玉与贾府三春、贾琏夫妇。
5. 天晚起身算还酒账，后面有人叫“雨村兄，恭喜了”，雨村回头，本回止。

## 选定场面

雨村独自站在扬州城外智通寺残破的山门前，抬头看门旁的旧对联，心想“文虽浅近，其意则深”、尚未入寺
的一刻。具名一人：贾雨村。选它是因为山环水旋、茂林深竹的野趣，破败山门与对联构图清楚，无人动手，
且不与第1回街前、第3回堂内重复；不选村肆，是因酒肆陈设与二人衣着原文几乎未写，谈话多为口述。依据：

- 「门前有额，题着“智通寺”三字」
- 「门旁又有一副旧破的对联」
- 「身后有余忘缩手，眼前无路想回头。」

先后核对：病愈，风日晴和，饭后出来闲步，偶至郭外（前）→信步到山环水旋、茂林深竹处，隐隐见庙宇
（前）→见门巷倾颓、墙垣朽败，见额见联，雨村想“何不进去试试”（此刻，寺门外，未入寺）→入寺见老僧
煮粥，问话所答非所问（后）→不耐烦出来，往村肆沽饮，冷子兴起身大笑相迎（后）。此刻老僧不入画；
原文只写“信步”，未写随从、轿马，雨村独行。

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 贾雨村 | 成年男子，年龄未写；已革职、病愈，现在林家作塾师。体貌沿第1回：“腰圆背厚，面阔口方，更兼剑眉星眼，直鼻权腮”（权腮指颧骨高，另有“方腮”异文，不强调），第3回贾政见他“相貌魁伟，言语不俗”。衣冠本回未写（第1回“敝巾旧服”是落魄时）；兜底：整洁素净的汉式儒服，青灰或深色直裰，方巾或软巾，不戴官帽，不穿官服；仰头看联，一手背后，神态沉吟 | 第1、2、3回 |

## 器物与环境

- 地点：扬州（维扬）城外郊野，“一山环水旋，茂林深竹之处，隐隐的有座庙宇，门巷倾颓，墙垣朽败”。
  兜底：一条土路通向残旧山门，灰墙剥落，瓦缝生草，门楣悬匾额“智通寺”三字（字少，可辨），门旁木柱或
  墙面上挂有旧联（联字不要求可辨）；四周竹林、溪水环绕，远处低矮山岗。
- 时令天气：原文只写“风日晴和”，季节未写；兜底：晴日，竹树常绿，不画雪、花、红叶。
- 现实中会动的：① 竹叶与林梢随风摆动；② 溪水水面的波纹；③ 雨村的衣带与袖摆被风吹动。人物不整体位移。

## 排除项

- 后拍：入寺见老僧煮粥、问话；村肆饮酒、冷子兴起身迎接、演说荣国府、谈宝玉与三春；前拍：雨村革职、
  林府教馆、黛玉丧母。不画老僧、随从、轿马、黛玉与林府。
- 雨村不穿官服、不乘官轿（那是第1、4回的知府形象），也不是第1回的“敝巾旧服”。
- 对联的脂批与学者释义（“当头一喝”“智通无累”）不入画；不画野服蓑笠、竹杖（原文只写“信步”）。
