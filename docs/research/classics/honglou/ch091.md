# 《红楼梦》第91回 纵淫心宝蟾工设计　泄真情呆童自招尤

底本：<https://zh.wikisource.org/wiki/紅樓夢/第091回>；读取日期：2026-10-23。

## 情节要点

1. 薛蝌秉正自持拒宝蟾夜诱，薛家内宅暗潮汹涌；薛姨妈为薛蟠人命案多方奔走求托，宝钗忧劳发热染疾。
2. 薛姨妈赴荣国府求贾政打点道里回文，王夫人怜宝钗孤苦而动结缡之心；贾宝玉往探薛姨妈，觉情意转淡。
3. 宝玉转至潇湘馆，黛玉因闻薛家婚议微露机锋，假借禅机步步叩问真心，宝玉大笑立誓“弱水三千只取一瓢饮”。
4. 二人机锋问答互印木石前盟，黛玉低头含情默契；檐外忽闻老鸦占吉凶，秋纹急报贾政传唤，宝玉慌促离去。

## 选定场面

潇湘馆内室：深秋日暮，窗外数竿幽竹清影摇曳。林黛玉身着淡水绿窄袖长袄端坐紫檀椅上，秀眉微扬、手执折扇含情探问；
贾宝玉着秋香色罗袍盘膝端坐绣墩，合掌闭目朗笑立誓，神态庄重中见纯真痴情；紫鹃手捧青花茶钟立于湘妃竹帘畔含笑顾盼。
具名贾宝玉、林黛玉、紫鹃三人。选此景因“弱水三千只取一瓢饮”为全书宝黛爱情之最高定盟，在风刀霜剑与金玉流言逼仄下，
借禅语直抒孤忠深情，典雅凄美而无纤毫俗尘。三处依据：

- 「黛玉乘此机會說道：‘我便問你一句話，你如何回答？’」
- 「寶玉呆了半晌，忽然大笑道：‘任憑弱水三千，我只取一瓢飲。’」
- 「黛玉道：‘水止珠沉，奈何？’寶玉道：‘禪心已作沾泥絮，莫向春風舞鷓鴣。’」

先后核对：宝蟾送酒果设计诱薛蝌（前）→薛姨妈求贾政托人情（前）→黛玉自薛姨妈处归潇湘馆（前）→宝玉掀帘而入，
黛玉设五问试探木石盟，宝玉大笑以弱水一瓢明志，黛玉低头默许（此刻）→檐外老鸦鸣叫飞向东南（后）→秋纹急步唤归（后）。
此刻宝玉正盘足合掌言誓，黛玉低头含情，紫鹃止步听禅，室内静雅祥和。

## 器物与环境

- 地点：大观园潇湘馆内室。临窗设紫檀平头画案、斑竹靠背椅、湘妃竹垂帘，窗纸透进暮秋落日余晖。
- 时令天气：农历十月中旬深秋傍晚；秋风初劲，竹影横窗，气温转寒。
- 器物：斑竹长案、博山青铜香炉、景德镇青花白瓷茶钟、湘妃竹骨折扇、紫檀多宝格书卷。
- 现实中会动的：① 案头铜香炉中一缕檀香细烟呈S形徐徐袅袅升腾；② 窗外数竿修竹枝叶随晚风轻柔俯仰摇曳；③ 门侧湘妃竹帘下端丝绦垂穗微风轻晃。

## 排除项

- 前后拍：薛蝌房中宝蟾斟酒弄姿；金桂隔窗窥伺；薛姨妈登门为薛蟠请托；宝钗高烧身如燔灼；秋纹慌张催促贾政问话；檐外黑鸦啼叫。
- 他回他场：不得出现第22回宝玉听曲填词参禅；严禁出现黛玉病榻焚稿残景；严禁薛家房舍风月私会。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；宝玉不可作真僧缁衣光头扮相；人物仪态必须高雅端庄。
