# 《红楼梦》第22回 听曲文宝玉悟禅机　制灯迷贾政悲谶语

底本：<https://zh.wikisource.org/wiki/紅樓夢/第022回>；读取日期：2026-10-20。

## 情节要点

1. 宝钗十五岁生日，贾母出资二十两命凤姐置酒戏；二十一日在贾母内院搭小戏台，宝钗点《西游记》，
   又向宝玉念《鲁智深醉闹五台山》中的《寄生草》。
2. 戏散后湘云说小旦像黛玉，宝玉使眼色，两头得罪；宝玉作偈并《寄生草》，被黛玉、宝钗、湘云问住，
   一笑了之。
3. 元春差太监送出灯谜，众人猜后各作一谜；贾母命人做围屏灯，姊妹们把谜写好粘在屏上。
4. 灯节夜贾政来陪贾母，母子互猜谜后，贾政起身逐条看屏上姊妹的谜语，心生不祥，被贾母打发去歇息。

## 选定场面

贾母上房灯谜夜：贾母居上座含笑；贾政已起身走到围屏灯前，逐条细看姊妹们粘在屏上的灯谜；宝玉
坐在贾母身旁的席上；身后下席坐着王夫人、宝钗、黛玉、湘云，另一席坐着三春，地下站满婆娘丫鬟。
具名贾政、贾母、宝玉，其余作群像。贾政背朝观众半侧看屏，为构图约定，原文未写朝向。选它是因围屏灯、
粘谜、分席、祖孙父子的位置均有原文依据，画面中心明确，灯火通明，没有争吵。三处依据：

- 「命他姊妹各自暗暗的作了，写出来粘于屏上」
- 「上面贾母，贾政，宝玉一席，下面王夫人、宝钗、黛玉、湘云又一席」
- 「贾政答应，起身走至屏前，只见头一个写道是」

先后核对：太监送白纱灯谜，众人猜谜（前，不画）→贾母命作围屏灯，设于当屋，姊妹作谜粘屏（前）
→晚上贾政来，上房悬彩灯，三处分席，李纨、凤姐在里间另一席（前）→贾母与贾政互猜“荔枝”“砚台”，
赏彩（前）→贾母命宝玉执壶、迎春送酒，再叫贾政看屏（紧前）→贾政起身走至屏前，逐条念“炮竹”
“算盘”“风筝”“海灯”，众姊妹席上应答（此刻）→读到宝钗七律，心中不祥，垂头沉思（此刻末）→贾母
叫他去歇息（后）→宝玉跑到屏前评点（后）。此刻贾母仍在席上，贾政尚未告退；宝玉此时起坐原文
未写，题面按坐在贾母席上。

## 器物与环境

- 地点：荣国府贾母上房堂屋，三处分席；围屏灯“设于当屋”，上房另悬彩灯。
- 围屏灯：原文只写“小巧精致”，谜“粘于屏上”，形制未写。民间围屏灯可参照汪曾祺记高邮灯节所见：
  硬木长方框，约三尺高、一尺半宽，镶绢，屏后点蜡烛（此为江苏民间做法，非贾府式样）。兜底：数扇
  折叠的绢纱屏，木框，烛光自内透出，每扇贴一张谜条，条上不画可辨认的字。
- 席面：设酒果与玩物（原文“设了酒果，备了玩物”），贾母席上有酒壶、果品，不写谜面与诗句。
- 时令天气：灯节夜晚，室内烛灯通明。原文称“上元佳节”“节间”，与前文正月二十一日生日之后的
  时序有出入，题面只写灯节夜晚。
- 现实中会动的：① 屏内烛火透过绢纱的明暗闪动；② 上房悬灯的流苏轻摆；③ 席上酒壶、茶盏的热气
  （兜底）。人物不整体位移。

## 排除项

- 后拍：贾母打发贾政歇息、贾政退出、宝玉跑到屏前评点、凤姐出里间、贾母散席；前拍：太监送白纱灯谜、
  贾环“枕头、兽头”谜、宝钗生日听戏、点戏、《寄生草》、湘云说小旦像黛玉、宝玉作偈。
- 不画谜面诗句，不画谜底实物（爆竹、算盘、风筝、海灯）；屏上第一条原文由宝玉应“是”，贾政事后以为
  是元春所作，原文自相出入，题面不写谁作。
- 贾政只写沉思，不画痛哭与发怒；他立在屏前，不画坐在席上。
- 不画戏曲贾政的髯口与乌纱官帽；不画清宫剧辫子、顶戴、两把头与花盆底。
