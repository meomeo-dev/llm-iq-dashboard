# 《红楼梦》第82回 老学究讲义警顽心　病潇湘痴魂惊恶梦

底本：<https://zh.wikisource.org/wiki/紅樓夢/第082回>；读取日期：2026-10-23。

## 情节要点

1. 宝玉正式入家塾就读，下学归来急奔潇湘馆探望黛玉；黛玉命紫鹃沏龙井茶，二人相对品茗坐论八股制艺与功名进取。
2. 宝玉夜读四书发虚热，次日塾师贾代儒考问讲释《论语》“后生可畏”章，宝玉串讲得体获代儒首肯。
3. 袭人到潇湘馆探听黛玉口风，薛家婆子送来蜜饯荔枝一瓶，口出“林姑娘与宝二爷是一对儿”之语，触动黛玉愁肠。
4. 黛玉入夜作恶梦受惊，五更醒后咳痰带血，紫鹃雪雁惊忧；探春湘云闻讯赶来探视慰问。

## 选定场面

潇湘馆明间书案旁：初冬午后，冬阳煦暖。馆内千竿修竹掩映于窗外，案头书卷笔砚整饬。黛玉着淡藕合色暗花长袄，一手支颐
倚坐紫檀椅上，神采清绝含笑；宝玉下学卸去书囊，着石青素面夹袍微倾身立于几侧向黛玉展袖倾谈；紫鹃双手稳端朱漆茶盘，
上一盅冒着温润热气的龙井茶，笑吟吟打帘奉茶；门外秋纹探首掩映。具名林黛玉、贾宝玉、紫鹃三人。选此景因宝黛潇湘馆
论书品茗展现二人深层知己相通，黛玉以柔语开导宝玉对经义之成见，化刻板时文为知己温情，亦严格避让午夜恶梦与绝症咳血之
禁忌，意境清贵韶秀。三处依据：

- 「剛進門口，便拍著手笑道：‘我依舊回來了！’猛可里倒唬了黛玉一跳。紫鵑打起帘子，寶玉進來坐下。」
- 「黛玉微微的一笑，因叫紫鵑：‘把我的龍井茶給二爺沏一碗。二爺如今念書了，比不的頭里。’」
- 「黛玉道：‘我們女孩兒家雖然不要這個，但小時跟著你們雨村先生念書，也曾看過。內中也有近情近理的，也有清微淡遠的……’」

先后核对：宝玉下学见贾政贾母，急回园奔潇湘馆（前）→紫鹃打起门帘，宝玉进房坐定，诉说一日不见如隔三秋之闷（前）
→黛玉命紫鹃取龙井茶沏茶相待，二人促膝对坐论八股功名（此刻）→秋纹来寻宝玉回怡红院，紫鹃取笑打诨（后）→次日薛家
婆子送蜜饯荔枝（后）→黛玉夜作恶梦惊醒咳痰见血（后，禁忌不画）。此刻宝玉正论及八股，黛玉含笑劝勉，紫鹃捧茶将至。

## 器物与环境

- 地点：大观园潇湘馆明间正房。精巧落地长窗嵌透明明瓦，湘妃竹帘高卷；临窗设紫檀平头书案、南官帽椅，案头陈宣德炉、端砚与四书讲章。
- 时令天气：初冬午后；冬日晴暖，和暖阳光透过窗格竹影洒入室内，温馨明洁。
- 器物：紫檀书案、定窑白瓷茶盖碗、朱漆小茶盘、宣德铜香炉、线装经籍、紫毫毛笔。
- 现实中会动的：① 龙井茶盖碗中袅袅升起之一丝温润热气；② 案头宣德铜炉内篆香散出之一缕笔直青烟；③ 窗外万竿修竹随微风拂动投在素纸窗棂上的斑驳竹影。

## 排除项

- 前后拍：贾代儒在讲堂板脸责训童生；宝玉夜读四书发虚热；薛家老婆子窥脸混言蜜饯荔枝；黛玉梦中贾雨村作媒逼嫁与宝玉剖心淌血；五更咳痰见血。
- 他回他场：严禁绝症咳血、痰盒血星与病榻濒死悲凄之状；严禁梦魇神魔幻觉。
- 造型禁忌：严禁清代满族服饰；宝玉不可作垂头丧气挨打之态；黛玉不可作蓬头散发病容。
