# 《红楼梦》第27回 滴翠亭杨妃戏彩蝶　埋香冢飞燕泣残红

底本：<https://zh.wikisource.org/wiki/紅樓夢/第027回>；读取日期：2026-10-23。

## 情节要点

1. 芒种节大观园众女儿早起设礼祭饯花神，彩线系轿马旌幢，满园绣带飘颻；独不见黛玉。
2. 宝钗探望黛玉，见宝玉先进潇湘馆遂退避；途中见一双大如团扇的玉色蝴蝶，取扇戏扑至滴翠亭。
3. 宝钗隔窗偶闻红玉与坠儿私相授帕传情，使“金蝉脱壳”之计假意寻黛玉脱嫌；凤姐见红玉口齿伶俐有意调拨使用。
4. 宝玉兜落花往花冢，闻得山坡后悲切哭声，见黛玉荷锄葬花，痛赋《葬花吟》，宝玉听后痴倒。

## 选定场面

大观园草地与滴翠亭水畔：薛宝钗手持轻扇，蹑手蹑脚俯身追扑；面前一双玉色蝴蝶大如团扇，一上一下迎风翩跹飞舞，引向水上四面回廊曲桥的滴翠亭。具名薛宝钗一人，无群像。选此瞬间因“杨妃戏彩蝶”极具生机与古典画意，尽展宝钗罕见之天真烂漫，与池水曲亭相映成趣，明媚清朗，全无死伤郁结。三处依据：

- 「忽见前面一双玉色蝴蝶，大如团扇，一上一下迎风翩跹，十分有趣。」
- 「宝钗意欲扑了来玩耍，遂向袖中取出扇子来，向草地下来扑。」
- 「倒引的宝钗蹑手蹑脚的，一直跟到池中滴翠亭上，香汗淋漓，娇喘细细。」

先后核对：芒种众姊妹饯花神、宝钗欲唤黛玉（前）→见宝玉先进潇湘馆避嫌折返（前）→草地偶遇一双大玉色蝴蝶（前）→宝钗袖中出扇蹑步追扑、双蝶迎风起落引向水亭曲桥（此刻）→跟至滴翠亭外止步喘息闻亭内私语（后）→宝钗推门金蝉脱壳使计脱嫌（后）→黛玉花冢掩埋落红痛赋葬花吟（后）。此刻宝钗追蝶兴正浓，未止步偷听，亭窗皆闭。

## 器物与环境

- 地点：大观园青草地及通向滴翠亭的曲桥水边。滴翠亭四面游廊曲桥盖造在池中水上，四周雕镂隔子糊纸，柳拂池波。
- 时辰天气：四月二十六日未时交芒种前上午；初夏晴暖，微风徐徐，草木丰茂。
- 节令：芒种饯花之日，池边柳枝花树上系有彩线轿马、绫罗旌幢，绣带微拂。
- 器物：轻罗小扇（宝钗自袖中取出，素面轻巧）、玉色大蝴蝶一对（大如团扇，粉白带玉色）。
- 现实中会动的：① 玉色双蝶在草地与花丛上空一上一下迎风翩跹飞舞；② 宝钗手腕轻扇起落与裙裾轻盈微晃；③ 树梢系系的彩色绫罗绣带随风飘扬。

## 排除项

- 前拍：迎春探春等聚集看鹤舞、宝钗驻足潇湘馆院外窥探宝玉进去。
- 后拍：宝钗立于滴翠亭窗外偷听、推隔子诈寻颦儿使计、红玉帮凤姐传四五门子话、山坡花冢黛玉扶锄哭赋《葬花吟》。
- 造型与构图：不画戏曲宽大凤冠；不画清代旗袍马蹄底鞋；不画折扇骨架破损；排除滴翠亭窗格洞开露出内中侍女。
