# 《红楼梦》第75回 开夜宴异兆发悲音　赏中秋白发叹双折

底本：<https://zh.wikisource.org/wiki/紅樓夢/第075回>；读取日期：2026-10-23。

## 情节要点

1. 尤氏在惜春处碰壁后至李纨贾母处用膳，显贾府连上等白米细面等家常日用皆告匮乏，内外窘相毕现。
2. 贾珍聚众于宁府丛绿堂借习射为名赌博纵饮；八月十四夜宴忽闻祠堂方向发出叹息长啸之悲音，隐兆大难将临。
3. 八月十五中秋佳节，贾母率荣宁全家登上大观园最高处山脊“凸碧山庄”敞厅设大圆席夜饮赏月。
4. 贾母感伤人丁日稀，命折桂击鼓传花，贾赦讲偏心之笑话刺贾母，贾政讲怕老婆笑话承欢，夜阑席散凄清渐生。

## 选定场面

大观园山顶凸碧山庄敞厅：中秋圆月高悬碧空，满山清辉如洗。贾母银发梳整插素玉扁簪，身披石青暗花织锦鹤氅，端坐于正中大圆席
首席软榻之上，慈祥面容中深含繁华落尽之苍凉感叹；贾政着石青熟罗家常交领袍，手执一枝刚折下的金粟丹桂，躬身面带谦和笑意向贾母
说笑话承欢；贾宝玉身着秋香色窄袖便袍，手捧鎏金双耳酒爵垂手侍立于侧案含笑注视。具名贾母、贾政、贾宝玉三人。选此景因中秋凸碧堂
夜宴为贾府盛极转衰、回光返照之标志场景，高处不胜寒之山庄夜月，烘托出末世族长白发长叹与强颜欢笑之悲凉底色。三处依据：

- 「至山之峰脊上，便是這座敞廳。因在山之高脊，故名曰凸碧山庄。于廳前平台上列下桌椅……皆是圓的」
- 「賈母便命折一枝桂花來，命一媳婦在屏後擊鼓傳花。若花到誰手中，飲酒一杯，罰說笑話一個。」
- 「鼓聲兩轉，恰恰在賈政手中住了，只得飲了酒……賈政笑道：‘一家子一個人最怕老婆的。’」

先后核对：宁国府丛绿堂聚赌闻祠堂异兆悲音（前）→十五晚贾母携儿孙步上山脊凸碧堂入座圆席（前）
→贾母叹人少，命传桂击鼓传花，鼓声停于贾政，贾政执桂饮酒说怕老婆笑话承欢贾母（此刻）
→贾赦接花讲天下父母偏心笑话暗讽贾母（后）→贾赦出厅扭伤脚骨（后）→子夜人散，仅留黛湘听笛（后）。
此刻皓月当空，贾政执桂欢言，贾母含笑微叹，宝玉捧爵奉酒。

## 器物与环境

- 地点：大观园最高峰脊“凸碧山庄”前敞阔月台。设红毡圆桌面、紫檀圆凳、高大雕花隔断围屏，临风凭虚、俯瞰大观园全景。
- 时令天气：八月十五中秋子夜；天宇澄澈万里无云，满月如银盘吐曜，秋风浩荡带微寒。
- 器物：折枝丹桂花、鎏金双耳酒爵、青花瓷碟供切瓣西瓜与月饼、屏后传花小扁皮鼓与鼓槌。
- 现实中会动的：① 高天一轮明月周围浮动丝绢般轻薄晕轮；② 凸碧堂檐角悬挂的四盏大红绢纱宫灯随山脊浩荡秋风缓缓摆荡；③ 案头酒樽中琼浆随山风轻荡微漪。

## 排除项

- 前后拍：尤氏在李纨处洗脸吃面；宁府丛绿堂聚赌呼卢喝雉；贾氏祠堂黑夜凄厉长叹悲音；贾赦讲偏心断足笑话离席；席散笛声凄咽。
- 他回他场：不得出现元宵节花灯射谜；不可出现凹晶馆联诗；严禁鬼魅幻象在席前显露。
- 造型禁忌：严禁清代旗人服饰顶戴马蹄袖；贾政不可作狂悖滑稽相，贾母不可作颓唐涕泪状。
