# 《红楼梦》第17回 会芳园试才题对额　贾宝玉机敏动诸宾

底本：<https://zh.wikisource.org/wiki/紅樓夢/第017回>；读取日期：2026-10-20。
回目取杨藏本；庚辰本、程甲本等作“大观园试才题对额　荣国府归省庆元宵”。

## 情节要点

1. 秦钟死后，园内工程告竣，贾政约众清客游园拟匾额对联，并命宝玉跟随，贾珍引路。
2. 入口山前宝玉题“曲径通幽处”；到桥上亭，众人拟“翼然”，贾政提“泻玉”，宝玉改“沁芳”，
   并口占一联。
3. 一路游过潇湘馆（“有凤来仪”）、稻香村（“杏帘在望”“稻香村”）、“蓼汀花溆”、“蘅芷清芬”、
   “红香绿玉”等处，宝玉屡被贾政斥责，又屡被点头。
4. 游到玉石牌坊，宝玉出神，贾政限他一日拟题；游了全园十之五六，从大桥闸口出来。
5. 宝玉随至书房，贾政命他快回去见贾母。

## 选定场面

桥上亭中：贾政倚栏坐着，手捻胡须，含笑点头；宝玉站在亭上，环视四周，口占对联；两三位
清客在旁。具名贾政、宝玉，贾珍随行但亭上位置原文未写，可省。选它是因全回题额处里，沁芳亭是
第一处正式拟名的景点，亭、桥、清溪、垂柳、白石栏齐备，父子与清客的关系一眼可辨，
没有责骂。三处依据：

- 「贾政与诸人上了亭子，倚栏坐了」
- 「宝玉听说，立于亭上，四顾一望，便机上心来」
- 「绕堤柳借三篙翠，隔岸花分一脉香。」

先后核对：入园见翠嶂，山口题“曲径通幽处”（前）→入洞，见池沿、三港石桥、桥上亭，
贾政与诸人上亭倚栏坐（前）→众拟“翼然”，贾政提“泻”，宝玉辩驳，献“沁芳”，贾政拈髯点头
不语（前）→命作七言联，宝玉立于亭上四顾，口占此联（此刻）→贾政点头微笑，众人称赞（此刻末）
→出亭过池，才见粉垣翠竹处（后）。此刻尚未到潇湘馆、稻香村，匾额也还没有悬挂，
宝玉没有被喝斥。

## 器物与环境

- 地点：新建园内入口山后的桥亭。原文：“清溪泻雪，石磴穿云，白石为栏，环抱池沿，石桥三港，
  兽面衔吐。桥上有亭”，亭“压水而成”。“三港”指桥下几个桥洞，说法不一（据摘要），兜底：三孔石桥。
- 匾额：众人拟“暂且做灯匾联悬了”，此刻亭上无匾，画面不挂匾，不写字。
- 时令：“今日天气和暖”（原文）；联句有柳翠花香，实景花种本段未写；兜底：春夏之交，垂柳新绿，
  岸边野花，不强加某种花。
- 陈设：亭中只写“倚栏坐”，不另画家具。
- 现实中会动的：① 柳条随风；② 兽面口中吐水、清溪泻下的水流与波纹；③ 贾政捻须的手往复轻动。

## 排除项

- 后拍：潇湘馆“有凤来仪”、稻香村“杏帘在望”、“蓼汀花溆”、“蘅芷清芬”、“红香绿玉”、怡红院、
  玉石牌坊、沁芳闸；前拍：山口“曲径通幽处”。
- 不画贾政喝斥、“叉出去”、“打嘴”；不画宝玉低头受训、奶娘小厮。
- 不画第18回元妃、灯景与船；不画秦钟之殇。
- 造型：不画戏曲贾政的髯口与乌纱官帽，不画清宫剧辫子、顶戴；沁芳亭不画成现代复建园林的
  样子，不加原文没有的楼阁。
