# 《红楼梦》第43回 闲取乐偶攒金庆寿　不了情暂撮土为香

底本：<https://zh.wikisource.org/wiki/紅樓夢/第043回>；读取日期：2026-10-23。

## 情节要点

1. 贾母见王夫人等为大观园诸事操劳，提议由两府上下凑份子给王熙凤办热闹生日，老少共凑了一百五十两银。
2. 尤氏总管筹办，私下退回平儿、鸳鸯、彩云及周、赵二姨娘的份子钱，体恤各人微薄艰难。
3. 九月初二凤姐生日正宴，宝玉大清早一身素服，带茗烟骑马瞒过众人溜出北门，直奔荒郊。
4. 宝玉因金钏儿当日生辰且投井含冤而死，特到水仙庵借香炉，在后院井台上焚随身沉速香含泪祭奠。
5. 茗烟代祝祈愿，宝玉祭毕回府换华服入席给凤姐祝寿，推称去北静王府探视爱妾丧事。

## 选定场面

水仙庵后院井台旁：宝玉一身素白袍服站在古井台边，将荷包内两星沉速香焚入石台上的小香炉中，垂泪肃立；
茗烟垂手恭立在井台一侧守护。具名宝玉、茗烟两人，无群像。选此场面因“不了情”祭奠金钏儿是全回至情
之笔，水仙庵井台与投井自尽相契，清冷荒僻与前府繁华庆寿形成强烈对映，无争吵与打斗。三处依据：

- 「便命茗烟捧着炉出至后院中，拣一块干净地方儿，竟拣不出。」
- 「茗烟道：‘那井台儿上如何？’宝玉点头，一齐来至井台上，将炉放下。」
- 「宝玉掏出香来焚上，含泪施了半礼，回身命收了去。」

先后核对：宝玉穿纯素骑马出北门（前）→荒郊摸出衣襟荷包两星沉速香（前）→茗烟引路至水仙庵，老尼接马
（前）→前殿观洛神泥塑落泪，回绝纸马供品单借香炉（前）→茗烟捧炉至后院井台放下（前）→宝玉在井台
焚香、含泪施礼（此刻）→茗烟伏地磕头代祝女孩儿来世相伴（后）→宝玉踢他笑骂，禅堂用素菜（后）→骑马
回府换华服入大花厅看戏（后）。此刻香刚燃起，宝玉垂泪，茗烟尚立于一侧未下跪代祝，老尼未入后院。

## 器物与环境

- 地点：城郊水仙庵后院。青石砌筑的圆形古井台，台石斑驳；荒落萧疏，墙角秋草丛生，泥地冷清。
- 时令天气：农历九月初二，深秋早晨；红日初升，天朗气清，秋风微带寒意。
- 器物：小青铜香炉置于井台石沿上；宝玉胸前佩带的随身素绣小荷包（掏香用）；两星沉速香屑。
- 现实中会动的：① 井台上小香炉中一缕青烟随秋风微晃袅袅上升；② 井旁残草枯茎与落叶随风轻拂；③ 宝玉与茗烟的衣角下摆在秋风中轻摆。

## 排除项

- 前后拍：大观园及宁荣府大排筵席、尤氏商议分金、点戏吃酒；宝玉清晨角门策马疾驰、前殿观洛神塑像；茗烟跪地磕头祷祝；二人回府后换彩服花厅行礼。
- 他回他场：不可出现大花厅热烈群像、戏台乐器或寿礼；不可画供桌蜡烛、纸马纸钱（原文明言“一概不用”）；不得画洛神金身神像或尼僧入画。
- 造型禁忌：严禁清代剃发垂辫（宝玉为红楼独有小辫发式，茗烟戴巾帽）；严禁满式马蹄袖与清代官服补子。
