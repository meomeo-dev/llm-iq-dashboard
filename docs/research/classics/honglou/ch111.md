# 《红楼梦》第111回 鸳鸯女殉主登太虚　狗彘奴欺天招贼盗

底本：<https://zh.wikisource.org/wiki/紅樓夢/第111回>；读取日期：2026-10-23。

## 情节要点

1. 贾母大丧二更辞灵，亲朋各散，满堂白幡惨淡；鸳鸯灵前哭至昏厥，苏醒后立下“老太太疼我一向我跟了去”之从死誓言。
2. 鸳鸯自省身世，既不愿受大太太邢夫人摆布蹂躏，更深恶贾府恶奴日后欺凌，决意追随贾母殉节，以保冰清玉洁。
3. 鸳鸯在灵前抚棺持香决绝辞灵，暗入套间从容就义殉主登太虚幻境，合府闻讯无不痛悼敬服其忠贞清白。
4. 贾府家奴何三等背主忘恩勾结外盗，趁夜引贼潜入荣府抢劫地窖金银，包勇闻声持杖勇斗群寇。

## 选定场面

荣国府前堂贾母灵寝大堂：二更深夜，吊唁远客皆散，合府女眷退入偏房。灵堂素幔高悬、素幡森然垂地，两柄白烛泪痕累累，
光影惨淡幽凝。鸳鸯身穿粗白麻布交领斩衰长衫、白布裙，素面朝天毫无脂粉，发髻松挽木簪，双眸泛泪却透露出凛不可侵之大义决然；
她长跪于贾母朱漆高大灵柩前，一手紧紧抚摩冰冷厚重的漆棺，另一手高举一炷青烟袅袅的素香，仰首向贾母灵位默祝明志、决意从死殉节；
灵堂廊柱背影处，贴身侍女琥珀手执素帕掩面拭泪，满面哀悯震动。具名鸳鸯、琥珀二人。选此景因鸳鸯抗婚守节一生，于贾母灵前抚棺持香
从死殉主，乃全书女儿风骨最悲壮圣洁之高光；坚决摒弃套间自缢悬梁之血腥恐怖，定格抚棺祭主、从容秉节之圣洁绝唱。三处依据：

- 「只見鴛鴦已哭的昏暈過去了，大家扶住捶鬧了一陣才醒過來，便說‘老太太疼我一場我跟了去’的話。」
- 「自己跟著老太太一輩子，身子也沒有著落……我是受不得這樣折磨的，倒不如死了乾淨。」
- 「到了辭靈之時，上上下下也有百十餘人，只鴛鴦不在……眾人忙亂之時，誰去撿點。」

先后核对：辞灵女眷散去（前）→鸳鸯哭晕苏醒，暗定殉节大志，灵前抚棺举香向贾母立誓殉节（此刻）→缓步入贾母套间从容就义（后）→
群贼盗潜入荣府盗宝被斥（后）。此刻灵烛摇影，长香如缕，素衣烈女抚棺誓死，天地肃穆。

## 器物与环境

- 地点：荣国府正堂贾母停柩灵堂。悬“福寿全归”素匾、素白巨帏、紫檀供案、白石香炉、贾母朱漆高大梓棺。
- 时令天气：初春二更深夜；夜寒露重，冷气逼人，夜风穿帘呜咽。
- 器物：贾母朱漆灵柩棺木、白石三足素香炉、祭灵线香、素白高烛、哭丧素幔竹竿。
- 现实中会动的：① 鸳鸯手中紧握的长香上一缕笔直青烟在夜气中微颤摇荡；② 灵堂两侧素白麻布长幡受夜风轻拂微微起伏飘卷；③ 供案上素烛融化的烛泪顺着蜡台缓缓流淌滴落。

## 排除项

- 前后拍：严禁出现套间内悬梁自缢、舌突气绝、绳套勒颈之血腥惊悚惨状；不得出现秦氏冤魂阴森引路；严禁出现盗贼逾墙挥刀打杀抢掠。
- 他回他场：不得出现第46回鸳鸯大观园剪发抗婚；不得出现第74回抄检大观园；严禁任何鬼影憧憧之怪力乱神。
- 造型禁忌：严禁清代旗袍旗头两把头与长辫马褂；丧服严格按明代齐衰素麻服饰设计；鸳鸯神采必须端庄贞烈，严禁画出恐惧猥琐之态。
