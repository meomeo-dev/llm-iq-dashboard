# 《红楼梦》第59回 柳叶渚边嗔莺吒燕　绛芸轩里召将飞符

底本：<https://zh.wikisource.org/wiki/紅樓夢/第059回>；读取日期：2026-10-23。

## 情节要点

1. 贾母、王夫人离家送灵往铁慈县先陵，贾府诸门夜间严格落锁加派巡夜，大观园由林之孝家的等带婆子轮值。
2. 清晓雨歇，湘云两腮微发春癣，宝钗命莺儿与蕊官往潇湘馆找黛玉取蔷薇硝。
3. 莺儿心灵手巧，路经柳叶渚折柳采花编成玲珑过梁花篮赠黛玉，返回柳堤复坐山石编织，春燕前来赞赏。
4. 春燕姑妈与生母先后赶来，因争夺柳树花木利益辱骂殴打春燕，莺儿劝阻被抢白，负气将花柳掷于河中。
5. 春燕哭奔怡红院求救，何婆追打至绛芸轩，袭人麝月秉公斥责，命人唤管家娘子回明予以惩戒。

## 选定场面

大观园柳叶渚畔柳堤晨景：五更微雨初歇，土润苔青，堤畔垂柳丝丝吐碧；莺儿身穿淡黄短襦、浅绿裙，闲坐溪畔山石，
纤手灵巧穿引柳条与桃花；春燕双手轻捧一只刚编就的带梁嫩绿花篮，上面盛满带露鲜花，笑语盈盈；蕊官立于一侧捧柳。
选此场面因“柳堤编花篮”是全书极为清新灵动的春日少女风俗画，晨光凝露、巧手飞梭，完全避开后文婆子打骂之戾气。
三处依据：

- 「二人你言我语……不觉到了柳叶渚，顺着柳堤走来。因见柳叶才吐浅碧，丝若垂金……」
- 「他却一行走一行编花篮，随路见花便采一二枝，编出一个玲珑过梁的篮子。」
- 「枝上自有本来翠叶满布，将花放上，却也别致有趣。」

先后核对：贾母等启程出城送灵，荣府夜间闭锁各门（前）→清晓雨霁，湘云发痒托取蔷薇硝，莺儿蕊官同出（前）
→莺儿初试折柳编篮送黛玉取硝（前）→莺儿复坐柳叶渚山石编织，春燕走来含笑观赏，捧花篮闲话家常（此刻，祥和宁静）
→春燕姑妈赶来持杖打春燕，何婆继而追打掌掴（后）→莺儿气掷花柳于河，春燕哭奔怡红院，袭人麝月唤管家斥退何婆（后）。

## 器物与环境

- 地点：大观园沁芳溪流经之柳叶渚。柳堤蜿蜒，绿水如染，岸边垂柳依依、柳丝金碧交辉；堤畔青苔湿润，怪石横卧。
- 时令天气：暮春清晓，五更细雨初霁，土润苔青，微风清凉，晨曦和煦。
- 器物：刚编成带提梁的青翠柳条花篮（内插粉桃、各色带露野花）、散落石上的柳条、紫鹃所包蔷薇硝小纸包。
- 现实中会动的：① 溪边垂柳枝条在清晨微风中轻拂水面；② 莺儿指间嫩柳与花枝穿插盘绕；③ 溪中水波微漾映出柳影。

## 排除项

- 前后拍：严禁春燕姑妈拿拄杖抽打春燕；严禁春燕母亲抓柳条抽打春燕耳光；严禁春燕哭跑与何婆滑倒；严禁莺儿赌气将花篮扔进河中。
- 他回他场：不得画贾母王夫人乘轿送灵出大门；不得画怡红院麝月指责何婆；严禁清代旗装两把头、马蹄底鞋与男子发辫。
