# 《红楼梦》第53回 宁国府除夕祭宗祠　荣国府元宵开夜宴

底本：<https://zh.wikisource.org/wiki/紅樓夢/第053回>；读取日期：2026-10-23。

## 情节要点

1. 腊月将尽，贾珍在宁国府开宗祠、扫上房、领春祭恩赏银、受乌进孝交租年货。
2. 腊月二十九日两府换新门神桃符，宁府自大门至正堂正门大开、高照朱红；次日贾母率诰封命妇入宫朝贺领宴。
3. 众人回抵宁府宗祠行除夕大祭：白石甬路旁苍松翠柏，青绿古铜鼎彝森列；贾敬主祭，贾赦陪祭，贾珍献爵，贾琏贾琮献帛，宝玉捧香。
4. 祭毕众人至正堂，祖宗遗像披蟒腰玉前，阶上阶下挨次传菜至供桌，男东女西、左昭右穆，全族数百人伏地拈香叩拜。
5. 贾母在尤氏上房饮茶受贺后回荣国府；元宵夜贾母花厅大开夜宴，设暖榻小几，聚全族女眷看戏听弹词。

## 选定场面

宁国府贾氏宗祠正殿前庭阶上：香烛辉煌、烟缕氤氲，先皇御笔“慎终追远”匾额高悬；月台上青绿古铜鼎彝古朴森严；贾敬、贾赦、贾珍、贾宝玉等子孙按昭穆整齐排班，贾敬庄严主祭，贾珍手捧青铜古爵献酒，宝玉神情肃穆双手捧香，青衣乐声中依序向神位献祭。具名贾敬、贾赦、贾珍、贾宝玉四人（群像肃立）。选此场面因“除夕祭宗祠”乃全书展现贾府钟鸣鼎食世家礼乐宗法与鼎盛气象之第一大典，青铜重器、朱红宫灯、钟磬齐鸣，庄严肃穆、规模宏大，全无任何悖逆血腥。三处依据：

- 「月台上设着青绿古铜鼎彝等器。抱厦前上面悬一九龙金匾，写道是：“星辉辅弼”。」
- 「只见贾府人分昭穆排班立定：贾敬主祭，贾赦陪祭，贾珍献爵，贾琏贾琮献帛，宝玉捧香」
- 「鸦雀无闻，只听铿锵叮当，金铃玉珮微微摇曳之声，并起跪靴履飒沓之响。」

先后核对：宁府开宗祠、领恩赏、受庄头乌进孝年贡（前）→除夕贾母率命妇进宫朝贺，回府入宗祠（前）→宗祠正殿月台前，青衣乐奏，贾敬主祭、贾珍献爵、宝玉捧香行三献礼（此刻）→礼毕退出至正堂，内外传递菜肴供奉二祖遗像，贾母领全族伏拜（后）→尤氏上房受茶叙话，回荣府开夜宴（后）。此刻正值宗祠正殿前月台祭祖献爵捧香之庄严瞬间，尚未转入正堂传递菜供，亦未到元宵夜宴。

## 器物与环境

- 地点：宁国府贾氏宗祠正院（白石甬路、苍松翠柏、五间正殿、抱厦悬“星辉辅弼”与“慎终追远”匾、月台）。
- 时令天气：除夕隆冬，天色向晚，庭院两边朱红大高照点燃如两条金龙，廊檐宫灯高悬，香烟如云。
- 器物：青绿古铜鼎彝（鼎、彝、尊、爵等祭礼重器）、长柄铜香炉（香烟升腾）、红毡拜毯、锦幛绣幕。
- 现实中会动的：① 鼎彝与香炉中沉香檀香的青白香烟袅袅升腾盘旋；② 廊前朱红大宫灯流苏与宝玉腰间玉珮在微风中微微摇曳；③ 两侧庭院苍松翠柏在冬风中枝柯微拂。

## 排除项

- 前后拍：黑山村庄头乌进孝进贡野鸡野鹿；贾蓉领小黄布口袋春祭恩赏银；尤氏看金银锞子；荣国府正堂隔门传递菜盘；贾母花厅元宵夜宴看女先儿说书放烟花。
- 他回他场：不可混入第54回元宵击鼓传花与放鞭炮；不可混入铁槛寺停灵与出殡僧道；严禁画成寺庙道观神仙法会。
- 造型禁忌：严禁清代剃发留辫与马褂顶戴；严禁女性满清旗装两把头与花盆底鞋；祭服一律依明清古典华服古制（蟒袍玉带、交领圆领礼袍）。
