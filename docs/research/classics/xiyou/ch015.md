# 《西游记》第15回 蛇盘山诸神暗佑　鹰愁涧意马收缰

底本：<https://zh.wikisource.org/wiki/西遊記/第015回>；读取日期：2026-10-19。

## 情节要点

1. 腊月寒天，师徒到蛇盘山鹰愁涧；涧中钻出一龙，吞下三藏的白马连鞍辔，悟空抱师父下马躲开。
2. 空中响起观音差来暗保的诸神（六丁六甲、五方揭谛、四值功曹、十八伽蓝），金头揭谛昼夜随侍。
3. 悟空叫阵与龙相斗，龙退入水底；悟空翻江搅浑涧水，龙变水蛇钻入草丛。
4. 山神土地说明涧名由来，并说此龙是观音所救的玉龙，奉命在此等取经人；金头揭谛往南海请观音。
5. 观音到，唤出小龙，摘其项下明珠，用杨柳枝蘸甘露一拂，变回原来白马的毛色；又赠悟空三根救命毫毛。
6. 水神扮渔翁渡师徒过涧；次晨里社祠老者（落伽山山神土地所化）送上鞍辔与一条鞭。

## 选定场面

鹰愁涧龙吞白马：涧心水响，龙推波掀浪窜上崖边，一口吞下带鞍辔的白马；悟空丢下行李，
抱着三藏下马回身便走。这是白龙马的来历，辨识度高，龙、马、人三方动势同在一个瞬间，无血腥。
具名角色两个：悟空、三藏，另有一龙一马。依据三处原文：

- 「涧当中响一声，钻出一条龙来，推波掀浪」
- 「慌得个行者丢了行李，把师父抱下马来，回头便走」
- 「把他的白马连鞍辔一口吞下肚去」

备选：观音杨柳枝点化小龙，龙变回白马（观音、悟空、小龙、金头揭谛，场面在半空，较散）。

## 器物与环境

- 涧：蛇盘山鹰愁陡涧，深陡宽阔，水清彻底，鸦鹊不敢飞过（鸟见水中倒影当作同群，投水而死，故名）；
  赋体写寒脉穿云、千仞浪飞喷碎玉、一泓水响吼清风；两侧悬崖峭壁、叠岭层峦。
- 时令：腊月寒天，朔风凛凛，滑冻凌凌；吞马在白昼（悟空事后在空中搭凉篷远望）。
- 鞍辔：被龙吞下的是唐王所赐马的原鞍辔；观音所化之马无鞍辔，次晨由里社祠老者送新的一副，
  并有衬屉、缰笼与一条鞭，均不入本场面。
- 现实中会动的：① 涧水涌浪与飞溅水珠；② 龙须与明珠彩雾飘动；③ 朔风中悟空衣摆、虎皮裙边与三藏衣袂。

## 排除项

- 观音点化、金头揭谛、山神土地、诸神现声均在吞马之后；吞马一刻无诸神现身。
- 悟空此刻未持棒，不画他与龙交手；叫阵、相斗、翻江搅海是下一段。
- 原文称「孽龙」「小龙」「玉龙」「龙马」，无「小白龙」「白龙马」「敖烈」等称呼；
  体色未写，不指定通体雪白。
- 龙是整匹吞下，不画嚼食与血肉；新鞍辔是次日之事，勿提前给马。
- 八戒、沙僧未出场；「又值早春」是此后两个月的事，本场面是腊月。
- 渔翁渡涧是涧水之神，与龙无关，属后段。
