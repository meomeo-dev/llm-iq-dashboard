# 《西游记》第86回 木母助威征怪物　金公施法灭妖邪

底本：<https://zh.wikisource.org/wiki/西遊記/第086回>；读取日期：2026-10-19。

## 情节要点

1. 三人入隐雾山，行二十里见悬崖下洞府，石版刻「隐雾山折岳连环洞」；八戒一钯把石门
   筑出大窟窿。
2. 妖怪先锋（铁背苍狼怪）献计：先抛柳树根砍成的假人头，被悟空摔出梆子声识破；再抛
   剥皮亭里挑的真人头，三人信以为师父已死。
3. 八戒把人头埋在向阳处，筑坟，以柳枝当松柏、卵石当点心供养；悟空留沙僧庐墓、看守
   行李马匹，与八戒打洞，用分身法打倒先锋，老妖堵门逃回。
4. 悟空变水老鼠、蚂蚁从后门入洞，见唐僧与樵子绑在园中树下；放瞌睡虫，捆倒老妖，
   烧洞，八戒筑死艾叶花皮豹子精。樵子引师徒到家，野菜斋饭后辞别。

## 选定场面

隐雾山崖上向阳处，八戒刚用钉钯筑起新坟，把涧边攀来的大柳枝插在坟的左右，鹅卵石堆
在坟前，煞有介事地答悟空的问；悟空喝他夯货，沙僧在旁滴泪，白龙马与行李在坟边。
坟里埋的其实是妖怪抛出的人头，画面只画土坟、柳枝、卵石，不画人头。又哭又笑，一图
可见。具名角色悟空、八戒、沙僧，另有白龙马。三处依据：

- 「这柳枝权为松柏，与师父遮遮坟顶；这石子权当点心，与师父供养供养」
- 「夯货，人已死了，还将石子儿供他」
- 「表表生人意，权为孝道心」

## 器物与环境

- 地点：隐雾山深处悬崖洞府之外，八戒「跑上山崖向阳处」，择「藏风聚气」之处筑坟；
  近处有涧，柳枝、卵石皆在涧边取得。洞府石门、石版不入画。
- 坟：钉钯筑坑，埋后「又筑起一个坟冢」，大小未写，兜底：一个矮土堆。柳枝数根，
  分插坟的左右；卵石堆在坟前。原著没有墓碑、香炉、纸钱，不添。
- 时间天气：白昼，坟在向阳处。八戒说「天气不是好天气」，是怕人头放臭，阴晴与季节
  均未直写，按晴天画，不强加季节。
- 现实中会动的：① 涧水流动；② 坟边柳枝随风摇摆；③ 白龙马的尾鬃与人物衣摆被山风
  带起。

## 排除项

- 假人头（柳树根）与真人头都不入画，不画血迹、骷髅；坟内之物不外露。
- 唐僧与樵子被绑在洞后园中，此刻不入画；悟空变水老鼠、蚂蚁在立坟之后。
- 八戒脱直裰、束小衣上阵，在立坟之后；筑死豹子精、烧洞、艾叶花皮豹子精与苍狼先锋
  均在后文，不入画。
- 悟空此刻没有变化、没有分身；沙僧只是滴泪，不画成哭倒在地。
- 86版第12集《泪洒隐雾山》给樵子添了妻子，原著樵子只有老母；画面不放任何女子。
- 画面里不写字，不立牌位或碑。
