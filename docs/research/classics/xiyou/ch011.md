# 《西游记》第11回 游地府太宗还魂　进瓜果刘全续配

底本：<https://zh.wikisource.org/wiki/西遊記/第011回>；读取日期：2026-10-19。

## 情节要点

1. 太宗魂灵出五凤楼，在荒郊遇见崔珏；崔珏收下魏徵书信，许诺送他还阳。
2. 入鬼门关，建成、元吉拦路索命，被崔珏唤鬼使喝退；到森罗殿，与十王对质泾河龙案。
3. 十王命取生死簿，崔珏在司房查得太宗注定「一十三年」，将「一」字添两画后呈上，
   阎王算得尚余二十年阳寿。
4. 太宗许诺还阳后进瓜果；崔珏、朱太尉引路，过阴山、十八层地狱、奈河桥，
   在枉死城借相良金银一库打发饿鬼，又经六道轮回。
5. 渭水边朱太尉将太宗推落马下，魂归躯壳，棺中喊「渰杀我耶」复生；次日朝会，大赦天下。
6. 均州刘全因妻李翠莲自缢，揭榜愿死进瓜，头顶南瓜到森罗殿；十王许其夫妻还魂。

## 选定场面

森罗殿验簿：崔判官将生死簿呈上，十王从头验看，太宗以宾位就座，听说还有二十年阳寿，
躬身称谢。选它是因为这是游地府里辨识度最高的一幕：十王列坐、判官捧簿、太宗拱手，层次清楚，
无打斗与血腥，原文对判官衣冠和殿宇有具体描写。具名角色三个：太宗、崔珏、秦广王，十王作群像。
备选：渭水边朱太尉推太宗落马（太宗与太尉的冠服原文均未写，故未选）。依据三处原文：

- 「头顶乌纱飘软带，腰围犀角显金厢」（崔珏出场）
- 「见太宗名下注定三十三年」（十王验簿）
- 「急取浓墨大笔，将『一』字上添了两画」（在司房，十王未见，本场面不画添笔）

## 器物与环境

- 殿宇：森罗殿碧瓦楼台，彩霞堆叠，红雾隐现；门钉赤金，门槛白玉；左有牛头、右有马面守门。
- 器物：生死簿即「天下万国国王天禄总簿」，由崔珏捧上；兽鼎、绛纱灯火、宫扇，外有两对提烛。
- 时令天气：阴司不写日月与天色，不强加季节。
- 现实中会动的：① 兽鼎香烟升腾；② 提烛与绛纱灯火摇曳；③ 崔珏乌纱软带与胡须飘动。

## 排除项

- 民间判官造型：红袍、右手勾魂笔（判官笔）、钟馗式怒目，原文均无；笔只在司房添画时出现。
- 添笔发生在司房，十王与太宗未亲见；不画崔珏当众提笔，也不把「添一笔」画成一划（原文是两画）。
- 阎罗王只是十王之一，原文先发言的是秦广王；不画阎罗王独坐正中。
- 太宗还阳后的「冲天冠、赭黄袍、蓝田碧玉带」属次日朝会，不入地府。
- 阴山、十八层地狱、奈河桥、枉死城、六道轮回属殿外后段，不入画；渭水推落属还阳一幕。
- 生死簿页面不写可辨认字句。
