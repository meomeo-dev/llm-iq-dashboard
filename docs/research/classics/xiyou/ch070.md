# 《西游记》第70回 妖魔宝放烟沙火　悟空计盗紫金铃

底本：<https://zh.wikisource.org/wiki/西遊記/第070回>；读取日期：2026-10-19。

## 情节要点

1. 悟空在半空迎住麒麟山獬豸洞赛太岁部下的先锋，一棒打断其长枪，先锋败走并在西门放火；
   悟空抛出金杯，酒化大雨浇灭火。
2. 悟空向国王讨得金圣宫旧戴的一双黄金宝串，驾云南行三千里到麒麟山。
3. 山凹里迸出火光、五色烟和黄沙；悟空沙灰入鼻打了两个喷嚏，摸两颗鹅卵石塞住鼻孔，
   变攒火的鹞子飞入烟火，烟火随即平息。
4. 悟空打死送战书的小妖“有来有去”，取其牙牌、黄旗、铜锣，变作他的模样混入洞中，
   在后宫现本相见金圣娘娘，得知妖王的三个金铃分别放火、放烟、放沙。
5. 娘娘哄妖王交出金铃，悟空偷铃到剥皮亭前，扯掉棉花，铃响迸出烟火黄沙，被妖王察觉，
   他变苍蝇钉在石壁上。

## 选定场面

麒麟山巅峰，悟空站在岩石上，一手捏着塞进鼻孔的鹅卵石，面前山凹里火焰冲天、五色烟与
黄沙遮天蔽日。具名角色只悟空一位。“放烟沙火”是回目前半句，塞鼻是一个清楚的动作瞬间，
不涉及变身与偷铃的具体细节。三处依据：

- 「霎时间，扑天红焰，红焰之中冒出一股恶烟，比火更毒」
- 「又见那山中迸出一道沙来。好沙，真个是遮天蔽日」
- 「即回头，伸手在岩下摸了两个鹅卵石，塞住鼻子」

## 器物与环境

- 山：麒麟山，赞词写尖峰矗矗、岭头松郁郁四季常青、崖下石磷磷，山禽山兽出没；悟空站在“巅峰”。
- 火烟沙：火光如“万点金灯”，火焰如“千条红虹”；烟分青、红、白、黑、黄五色，
  比火更毒；沙“遮天蔽日”，细尘迷眼，粗灰满谷。三者来自山凹，谁放的原文此处未写，
  不画人影。
- 石：岩下随手摸到的两颗鹅卵石，大小未写，兜底：能堵住鼻孔的圆润小石。
- 方位时令：朱紫国之南约三千里；炎天（第68回）；时辰承接第69回的巳时之后，兜底：白天，
  烟火映红山凹。
- 现实中会动的：① 火焰与火光的跳动；② 五色烟柱翻滚上升；③ 黄沙随风卷过山脊，松枝摇摆。

## 排除项

- 三个金铃、豹皮包袱、棉花塞口，是后文娘娘讲述与偷铃时才出现，不画在山凹，也不在悟空手里。
- 悟空尚未变鹞子；“攒火的鹞子”在塞鼻之后，不画鸟形，不画变身中途。鹞子是雀鹰一类小猛禽，
  不是燕雀，也不是蜂虫。
- 先锋（第69回写九尺长身、豹皮裙）、小妖有来有去、赛太岁（獠牙、铁杵）、金圣娘娘与
  洞口五百妖都不入画；朱紫国城池、国王、避妖楼属前文，不入画。
- 悟空不用布掩口鼻，也不施法护身，只塞两颗石；不画他被烟火灼伤。
- “熏着南天门外柱，燎着灵霄殿上梁”是夸张的赞语，不画天宫。
- 本回未见86版赛太岁与金铃的造型资料；86版第20集覆盖第68–71回，不沿用影视造型。
