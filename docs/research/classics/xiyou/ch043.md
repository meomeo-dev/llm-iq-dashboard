# 《西游记》第43回 黑河妖孽擒僧去　西洋龙子捉鼍回

底本：<https://zh.wikisource.org/wiki/西遊記/第043回>；读取日期：2026-10-19。

## 情节要点

1. 观音收服红孩儿，悟空、沙僧攻入洞中救出八戒、唐僧；师徒西行一个多月，遇一条黑水滔天的
   大河，约十来里宽，马不能进。
2. 上游棹来一只小船，由整段木头刻成，只有一个舱口，坐得下两人；八戒扶唐僧先上船，
   船到河心狂风卷浪，船与二人一齐不见，棹船人是黑水河鼍龙所变。
3. 沙僧下水，在“衡阳峪黑水河神府”门前与鼍龙战三十合不分胜负；黑水河神出面诉冤，
   悟空到西海，截获黑鱼精送的请帖，西海龙王遣太子摩昂去擒鼍龙。
4. 摩昂用三棱简擒住鼍龙，沙僧救出唐僧、八戒；河神作法截断上流，师徒过河。

## 选定场面

黑水河心，狂风骤起的一瞬：独木小船上，唐僧与八戒并坐舱里，梢公立在舱外船尾持桨，黑浪
卷起，飞沙迷日，小船被浪头掀得倾侧；东岸远处，悟空、沙僧守着白马与行李。入画理由：
“黑水、独木小舟、妖风”构图单纯；本回后半多在水下，这一瞬是水面上最有辨识度的画面。
具名角色三位（唐僧、八戒、梢公），岸上悟空、沙僧与马匹合作远景群像。三处依据：

- 「那船儿原来是一段木头刻的，中间只有一个舱口，只好坐下两个人」
- 「方才行到中间，只听得一声响亮，卷浪翻波，遮天迷日」
- 「近观不照人身影，远望难寻树木形」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 梢公（鼍龙所变） | 样貌衣冠原文未写，只写“有一人棹下一只小船儿来”，悟空事后觉得他“不正气”。此时仍是人形，真身（圆睛、卷唇巨口、铁线稀髯、金盔铁甲）到水下才现。兜底：寻常船夫装束，立舱外船尾、一手持桨，不画鳞甲与鳄首 | 来船段；后文披挂赞词 |
| 唐僧 | 骑白马到河边，下马上船；衣着本回未写，未提袈裟、毗卢帽（第44回进寺时才“取袈裟披起”，可见平时收在行李中）。他自吟诗有芒鞋、竹笠之句，属自述旅况。兜底：缁色僧衣、光头，不披袈裟、不戴毗卢帽 | 渡河段；自吟诗；第44回 |
| 八戒 | 黑脸短毛、长嘴大耳；青锦直裰；上船时扶着唐僧。钉钯是否带上船原文未写，兜底：钯横置舱侧 | 渡河段；第22回 |
| 悟空、沙僧 | 岸边远景。悟空金箍勒头，直裰、虎皮裙，铁棒；沙僧落发，蓝靛脸（本回称“晦气色脸”“黑汉子”），黄锦直裰，降妖宝杖，另有白马与行李 | 议渡段；第14回；第22回 |

## 器物与环境

- 黑水河：黑水滔天，约十来里宽，浪如乌潦黑油，近看照不出人影；牛羊不饮、鸦鹊难飞。
  岸上芦苹、滩头花草仍青翠。
- 小船：独木舟，一段木头刻成，单个舱口、只容两人，无篷无桅。梢公“扶着桨”“举棹冲流”，
  桨即长桨（棹），兜底：一支长桨，立于船尾划行。
- 风势：当空一片炮云，中流千层黑浪，两岸飞沙迷日，树倒枝摇。
- 时令：季节与时辰原文未写（第40回秋尽冬初，行一个多月后至此，第44回已是早春）。
  兜底：白昼、天色沉暗，不画雪，不画花开。
- 现实中会动的：① 翻卷的黑水浪涛与浪花；② 狂风卷起的飞沙，岸边芦苇倒伏；③ 唐僧、八戒与梢公的衣摆被风吹起。

## 排除项

- 鼍龙真身与披挂、竹节钢鞭属沙僧水下一战；此刻是船夫，不画鳄首鳞甲，也不画“龙”。
- 船被浪吞、唐僧八戒不见踪影是下一瞬；本图取风浪初起、船倾侧而人仍在船上。
- 黑水河神、黑鱼精、四海龙王、摩昂太子均属后段；沙僧此刻仍在岸上未入水，悟空未驾云。
- “清水盛入碗中变黑”及河神之女是《西游记续集》影视设定；原著河水本就是黑的，也无此人物。
  摩昂用的是三棱简。
- 红孩儿、观音、火云洞属上一回，不入图。船上只有两位乘客，不画四众同船。
