# 《西游记》第23回 三藏不忘本　四圣试禅心

底本：<https://zh.wikisource.org/wiki/西遊記/第023回>；读取日期：2026-10-19。

## 情节要点

1. 师徒过流沙河，又值九秋；八戒抱怨挑担，悟空使马狂奔，天晚见一座大庄院。
2. 庄中半老妇人自称娘家姓贾、夫家姓莫，寡居，有真真、爱爱、怜怜三女，欲招四人为婿；
   唐僧、悟空、沙僧推辞，八戒动心。
3. 悟空变红蜻蜓跟着八戒，听他在后门与妇人说合；八戒进内堂拜“丈母”，顶手帕撞天婚，
   撞不着人，跌得嘴肿头青。
4. 妇人取珍珠嵌锦汗衫，八戒穿上被绳绷住，众人隐去；次晨师徒睡在松柏林中，
   古柏上留颂子，点明四圣为黎山老母、观音、文殊、普贤。

## 选定场面

庄院内堂，妇人坐在上首，八戒头顶手帕遮脸，两手前伸在满堂银烛中乱撞。滑稽、动势明确，
原文细节具体；具名角色只需八戒与妇人，三女仅作掠过的衣影。三处依据：

- 「我这里有一方手帕，你顶在头上，遮了脸，撞个天婚」
- 「东扑抱着柱科，西扑摸着板壁」
- 「满堂中银烛辉煌，这獃子朝上礼拜」

## 器物与环境

- 地点：庄院内堂，经仓房、库房、碾房才至；上有妇人座位，堂中有柱与板壁，门槛绊脚。
- 时间：入夜，晚斋之后；季节九秋，但内堂陈设只写银烛。
- 会动的：① 银烛火苗；② 手帕垂角与八戒乱扑的双手；③ 三女掠过时的绣带与环佩。
- 手帕颜色、烛台形制、堂中家具原文均未写，不强加。

## 排除项

- 庄院、妇人、三女均为四圣化现，次晨化为松柏林；画面是内堂，不画林中。
- 悟空、唐僧、沙僧此时在前厅客座歇息，不入画；悟空变红蜻蜓是此前跟八戒放马的一段。
- 汗衫与绳子在撞天婚之后；撞天婚时八戒仍穿青锦布直裰，身上没有绳。
- 撞天婚是顶手帕遮脸伸手扯人，不是抛绣球。
- 四圣与四位女子的对应，原文未写（颂子只说南海菩萨请黎山老母下山，普贤文殊为客，
  化成美女）；“观音即真真”等是后世推断。
- 原文“娘家姓贾，夫家姓莫”，个别转述写反；八戒被“绷”在树上，非“吊”起，“吊”只是后世概括。
