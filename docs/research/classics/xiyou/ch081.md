# 《西游记》第81回 镇海寺心猿知怪　黑松林三众寻师

底本：<https://zh.wikisource.org/wiki/西遊記/第081回>；读取日期：2026-10-19。

## 情节要点

1. 唐僧在镇海禅林寺夜里起身没戴帽子，病了三日；悟空取水时听僧众哭诉，三日里寺中
   失了六个和尚，决意替寺里除妖。
2. 悟空夜里变成十二三岁的小和尚在佛殿敲木鱼念经，引出一个美貌女子，引至后园动手；
   女妖脱下一只花鞋变成替身，真身化风摄走唐僧，打落的只是一只花鞋。
3. 悟空气急，抡棒要打八戒、沙僧，被沙僧劝住；天明悟空告诉僧众，黑松林树上绑着的女子
   就是妖精，三人回头向东进了黑松林。
4. 悟空变回大闹天宫时的三头六臂，在林里乱打，打出山神、土地；二神说妖精在正南千里外
   的陷空山无底洞。
5. 三人驾云南行，见一座大山拦路；悟空留沙僧同在，叫八戒先下山凹打听路径。

## 选定场面

黑松林里，悟空现出三头六臂，六只手分执三根棒乱打，一个山神、一个土地被打了出来，
跪在他脚前；八戒立在一旁看这场热闹。具名角色四位：悟空、山神、土地、八戒；沙僧与
白龙马原文在场但无动作，不入画。三头六臂一眼可辨，场面喜剧，无血腥，也避开寺内夜间
那一段。三处依据：

- 「三头六臂，六只手，理着三根棒，在林里辟哩拨喇的乱打」
- 「打出两个老头儿来：一个是山神，一个是土地」
- 「云蔼蔼，雾漫漫；石层层，路盘盘」

## 器物与环境

- 地点：黑松林，与第80回是同一片林：松树东西密摆、南北成行，荆棘与藤葛缠绕，杂有
  千年槐、万载桧。本回写林中狐兔虎豹出没，只作环境，不画出来抢戏。
- 时间天气：妖精摄走唐僧后的次日，三人用过早斋回头向东，白天；林中云雾低垂。季节
  第80回为暮春，本回未再写，不强加。
- 兵器：三根棒，每根由两只手握持；棒身两端有金箍，长短粗细原著未写，按平常的棒画。
- 现实中会动的：① 林间低垂流动的云雾；② 松枝与缠绕的藤葛随风摇摆；③ 被棒风扫落的
  松针与落叶。

## 排除项

- 镇海寺内的夜话、佛殿里变小和尚、女妖现身、后园斗法与花鞋替身，属前半回，不入画；
  题面与评判标准不写寺中失踪和尚的情形。
- 陷空山、无底洞、牌楼与缸口洞在山神土地口中和第82回，本场面不出现；八戒沙僧驾云
  南行亦不画。
- 三头六臂是一身变化，不是三个悟空并立，也不是分身；悟空不戴凤翅紫金冠，不披黄金甲，
  “本相”指这一变化，衣着仍是取经装束。第4回哪吒也变三头六臂，其六件兵器不混入悟空手中。
- 山神土地不画成戴员外帽、双手持护板的民间土地公造型；该造型来自民间图像，原著没有。
- 悟空此刻没有变大，不顶天立地；山神土地只是被打出来跪地，不画受伤、血迹或被棒击中。
- 央视版《四探无底洞》对应第80–83回，资料中未见本段三头六臂的拍法，不以影视造型为据。
