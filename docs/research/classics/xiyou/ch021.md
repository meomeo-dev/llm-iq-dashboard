# 《西游记》第21回 护法设庄留大圣　须弥灵吉定风魔

底本：<https://zh.wikisource.org/wiki/西遊記/第021回>；读取日期：2026-10-19。

## 情节要点

1. 黄风怪闻虎先锋被打死，披挂持三股钢叉出洞，与悟空斗三十回合不分胜负。
2. 悟空使身外身围攻，妖怪向巽地张口吹出黄风，分身被卷得乱转，悟空双眼被风吹得睁不开，
   败阵。
3. 当夜借宿的庄院次晨化为乌有，树上留帖，原是护教伽蓝点化，献三花九子膏治好眼痛。
4. 悟空变蚊虫入洞，见唐僧缚在定风桩上，听妖怪说只怕灵吉菩萨；太白金星化老者指路。
5. 灵吉携飞龙宝杖同往，杖化八爪金龙抓住妖怪，现形为黄毛貂鼠，被带往灵山。

## 选定场面

黄风洞口半空，黄风怪回头向巽地张口吹出三昧神风，悟空的身外身被风卷得乱转。
具名角色仅黄风怪与悟空两位；披挂、风势原文写得具体，张口吹风是一个明确瞬间。三处依据：

- 「急回头，望着巽地上，把口张了三张，呼的一口气吹将出去」
- 「刮得在那半空中却似纺车儿一般乱转，莫想抡得棒」
- 「金盔晃日，金甲凝光」（披挂诗首句）

## 器物与环境

- 地点：黄风岭黄风洞口，洞门上有“黄风岭黄风洞”六字（第20回）。巽为八卦东南方。
- 时间天气：白天；风起时“天地无光”，季节原文未写。
- 兵器：妖怪三股钢叉；悟空如意铁棒。
- 现实中会动的：① 黄风裹着沙土与折断的树枝；② 被风卷转的分身；③ 盔缨雉尾与罗袍被风吹起。

## 排除项

- 灵吉菩萨、飞龙宝杖、八爪金龙在后半段，本场面不出现；灵吉面貌原文只写穿袈裟。
- 定风丹本回只被提及，降妖靠飞龙杖；定风丹至第59回才送给悟空。
- 悟空眼珠酸痛、冷泪常流，并未失明；八戒守马在山凹，沙僧第22回才入伙。
- “脚屣着虎怪的皮囊”指脚踏拖来的虎怪尸身，不是衣着；虎先锋已在第20回死去。
- 黄毛貂鼠原形此刻不显；黄风怪不是第17回黑熊精，也不是第28回起的黄袍怪。
