# 《西游记》第20回 黄风岭唐僧有难　半山中八戒争先

底本：<https://zh.wikisource.org/wiki/西遊記/第020回>；读取日期：2026-10-19。

## 情节要点

1. 夏日向晚，师徒借宿路旁王姓老者家，八戒食量惊人；老者说前路有八百里黄风岭，多妖怪。
2. 次日行不上半日，遇高山，旋风大作，悟空抓风闻出腥气，断定是怪风。
3. 山坡下跳出斑斓猛虎，唐僧坠马；八戒抢先举钯迎上，虎自剥虎皮，自称黄风大王的前路先锋。
4. 虎先锋施金蝉脱壳：把皮盖在卧虎石上，化风攫走唐僧，献给洞主，绑在后园定风桩上。
5. 悟空八戒识破脱壳之计，寻到黄风洞；悟空败虎先锋，被八戒一钯筑死，悟空拖尸到洞口叫阵。

## 选定场面

黄风岭旋风中，斑斓猛虎从山坡下跳出，唐僧坠下白马，八戒丢下行李、举钯抢上，悟空在侧。
取虎尚未剥皮的出手瞬间：动势足，回目所说八戒争先正落在这里，并避开后一刻虎自剥皮、
露出赤剥身躯的血腥描写。三处依据：

- 「正看那山，忽闻得一阵旋风大作」
- 「慌得那三藏坐不稳雕鞍，翻根头跌下白马」
- 「八戒丢了行李，掣钉钯，不让行者走上前」

## 器物与环境

- 地点天气：高山险峻，白云、怪石、挟魂崖、藏龙洞；山中有带角鹿、红鳞蟒、白面猿。
  旋风起处，千树吼、万竿摇，柳连根动，尘沙迸起，崖前桧柏倒、涧下松篁凋。
- 时令：夏景炎天；次日出发后不上半日遇山，约在午前后。
- 器物：九环锡杖、白马、行李担、八戒的九齿钉钯（第19回有详细来历）、悟空的金箍铁棒。
- 现实中会动的：① 旋风卷起的尘沙；② 被风吹弯摇晃的松竹柏枝；③ 山间飘动的白云。

## 排除项

- 沙僧第22回才入伙；黄风大王（后查明是黄毛貂鼠）本回未现身，三股钢叉等装束属第21回。
- 虎皮自剥、金蝉脱壳、攫走唐僧、八戒筑死虎先锋都在后一刻，不入此一瞬。
- 虎先锋开口说话、取赤铜刀发生在剥皮之后；画面里只取普通猛虎，不要直立人形。
- 悟空抓风闻风在虎出现之前，不另画闻风动作；风的来源原文未写，不强指为虎所化。
- 借宿的王老者一家不在场。九环锡杖是唐僧所持，不是悟空的兵器。
- 悟空不得出现凤翅紫金冠、黄金甲；八戒不得穿第18回已挣破的梭布直裰。
