# 《西游记》第40回 婴儿戏化禅心乱　猿马刀圭木母空

底本：<https://zh.wikisource.org/wiki/西遊記/第040回>；读取日期：2026-10-19。
回目末字底本并录“圭”“归”两种写法（刀圭 / 刀归），此处从“圭”。

## 情节要点

1. 国王复位，酬谢不受；师徒辞行，国王一家送出城廓。
2. 秋尽冬初，师徒行半月余，遇高山；山凹红云冒起火气，悟空识破是妖，把三藏推下马；
   妖精落下云头，变成七岁顽童，吊在松树梢头喊救人。
3. 悟空前两次拦阻，第一次还用移山缩地法绕开；第三次三藏见孩童，责骂悟空，鞭梢指问；孩童
   编造红百万家遭劫的身世，八戒用戒刀挑断绳索，悟空背他同行。
4. 悟空试出孩童轻，妖精用重身法压人、解尸出神，被悟空摔碎假身；随即旋风摄走三藏。
5. 师徒险些散伙，沙僧劝住；山神、土地道出妖精是牛魔王之子红孩儿，住枯松涧火云洞（下回）。

## 选定场面

山路松树下，三藏骑在马上，鞭梢指着吊在树梢的孩童发问，悟空低头不语。入画理由：孩童的
伪装是本回最具辨识度的形象，“吊树”“鞭指”“悟空闷声”三者构成清晰的构图关系。三处依据：

- 「变作七岁顽童，赤条条的身上无衣，将麻绳捆了手足，高吊在那松树梢头」
- 「那长老将鞭梢指着问道」
- 「低着头，再也不敢回言，让唐僧到了树下」

## 器物与环境

- 地点：六百里钻头号山的山路，一棵松树，树梢吊着孩童；山高险峻；枯松涧、火云洞在山中，
  此时尚未现身。
- 时间天气：秋尽冬初；山景诗写霜凋红叶、山竹风摇作寒声、岭梅向暖开；具体时辰原文未写。
- 空中：先前的红云已散尽、火气全无，天空不再有红光。
- 现实中会动的：① 麻绳与吊着的孩童随风轻摆；② 松枝与山竹在风中摇动；③ 飘落的红叶。

## 排除项

- 红孩儿真身要到第41回才出场：面如傅粉、唇若涂朱，腰束锦绣战裙、赤脚，用丈八火尖枪，
  洞中有五辆小车喷火，均不属本图。本图只有伪装的孩童，不画獠牙、火焰、红光。
- 红肚兜、风火轮不见于本回与第41回红孩儿描写，属影视、游戏改编，不写。原文是“赤条条的
  身上无衣”；题面宜说“以简化的小人轮廓表现，不描绘细节”，也不要补衣、补围兜。
- 断绳用的是戒刀，不是钉钯，且是下一瞬；悟空背孩童、重身法、摔碎假身、旋风摄走三藏均在后段。
- 山神、土地现身与报出名号、观音收服（第42回）不入图。
- 国王一家送行、辞别乌鸡国是前段，不入图。
- 悟空此刻未举棒指向孩童，也不画三头六臂（那是找不到师父后的举动）。
