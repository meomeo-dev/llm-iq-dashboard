# 《西游记》第54回 法性西来逢女国　心猿定计脱烟花

底本：<https://zh.wikisource.org/wiki/西遊記/第054回>；读取日期：2026-10-19。

## 情节要点

1. 师徒入西梁国界，街上女子喊“人种来了”，八戒作丑相吓退众人；迎阳驿丞接待，入城奏报。
2. 女王欲招唐僧为夫，遣太师作媒；悟空劝唐僧将计就计，假意允婚，骗取通关文牒后脱身。
3. 女王排大驾出城，到迎阳驿下辇，扯住唐僧请他同上龙车。设素荤两席，殿上用印倒换关文。
4. 女王陪唐僧出西关送行，扯住不放，八戒撒泼，沙僧抢出唐僧；路旁女子卷旋风摄走唐僧。

## 选定场面

迎阳驿门外，女王下辇，一把扯住香案前的唐僧，请他同上龙车；唐僧耳红面赤，悟空在侧劝他，
八戒口流涎水。具名角色四位：女王、唐僧、悟空、八戒；沙僧在场但本幕无专写，可不具名，
女官宫娥为群像。龙凤车驾与窘迫的唐僧反差明确，无打斗。三处依据：

- 「那驿门外香案前穿襕衣者便是」
- 「御弟哥哥，请上龙车，和我同上金銮宝殿，匹配夫妇去来」
- 「耳红面赤，羞答答不敢抬头」

## 器物与环境

- 地点：迎阳驿门外，驿在东关厢（城外），匾书“迎阳驿”三字，门外设香案。女王“卷帘下辇”。
- 车驾：六龙喷彩扶车、双凤生祥驾辇；三檐罗盖，鸳鸯掌扇遮驾，翡翠珠帘；五色旌旗；
  金鱼玉佩的女官簇拥，宝髻云鬟的宫娥排列；笙歌弦管。龙车、凤辇、銮驾指同一辆。
- 时令：上回为早春，本回未再写；时辰未写。
- 现实中会动的：① 罗盖、掌扇与五色旌旗随风摆；② 女王斜垂的红绡；③ 香案上升起的香烟。

## 排除项

- “女儿国”是后世通称，底本称西梁女国、西梁国。
- 此刻唐僧尚未登车，也未落泪；落泪在悟空劝他之后，“同携素手，共坐龙车”是下一刻。
- 西关外送别、八戒骂“粉骷髅”、沙僧抢人、旋风女子是后一幕，不入画；蝎子精不在此刻。
- 悟空的定身法原文并未用上；女王无“凤冠”，是鬟堆金凤丝；八戒的肚子已落胎，不再隆起。
- 1986版女王的花冠、褂袍造型，报道说法不一，不作依据。

## 现有题面核对

对象：xiyou-054 静态与 xiyou-anim-054。结论：沿用“女王迎驾、请唐僧同乘”的场面，改正场所与细节。
有据：

- 龙凤华驾、女官宫娥仪仗成列：有六龙、双凤、罗盖、掌扇、旌旗，“宝髻云鬟众女排”。
- 女王“金凤、珠翠、红纱”：鬟堆金凤丝、高簪珠翠、斜垂红绡，大意相符（“簪满”略夸张）。
- 请唐僧同乘、唐僧窘迫：“请上龙车”；耳红面赤、羞答答、似醉如痴。女王红纱飘拂（动）有据。

有误、无据或含后世说法之处：

- “城门外”（静、动）：不确，是迎阳驿门外，驿在城外东关厢，门外有香案。
- “锦襕袈裟、毗卢帽”（静、动）：无据。原文只写“穿襕衣者”，未提袈裟与帽。
- “含笑”（静、动）：此刻无明文，原文是“俏语娇声”；女王笑见于殿上。
- “拉住唐僧的手”（静）、“牵住唐僧双手”（动）：不确。原文“一把扯住三藏”，未写扯手，“双手”无据。
- “悟空、八戒与沙僧站在一旁，神情各异”：含糊。悟空催劝，八戒流涎；沙僧本幕无专写，但在场。
- “金铃流苏摇晃”（动）：无据，原文是罗盖、掌扇、珠帘、旌旗，可改摇这些。
- “唐僧念珠轻转”（动）：无据，所查各回底本无“念珠”。
- “车驾停在路中”：车驾在驿门前下辇，非路中，应写驿门外。
