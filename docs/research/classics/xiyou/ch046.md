# 《西游记》第46回 外道弄强欺正法　心猿显圣灭诸邪

底本：<https://zh.wikisource.org/wiki/西遊記/第046回>；读取日期：2026-10-19。

## 情节要点

1. 国王欲放行，三道士拦下关文，改赌“云梯显圣”坐禅：虎力踏席云上西台，悟空以五色祥云托唐僧上东台；
   鹿力弹发化臭虫咬唐僧，悟空变蜈蚣叮虎力，虎力跌下台。
2. 隔板猜枚三番：悟空把宫衣变成破烂流丢一口钟，啃光仙桃只留核，又把道童剃成和尚；唐僧三番皆中。
3. 赌砍头、剖腹：悟空头断复长、理肠复合；虎力头被黄犬衔走，现无头黄毛虎；鹿力脏腑被饿鹰抓走，现白毛角鹿。
4. 赌下油锅：悟空选“武洗”，脱衣入锅戏水，后沉底变枣核钉，众以为烹死；唐僧设奠，八戒痛骂，悟空现身。
5. 羊力下锅，悟空探得油冷，唤北海龙王敖顺收走羊力自炼的冷龙，羊力骨脱皮焦，现原形为羊（羚羊）。

## 选定场面

车迟国殿前，悟空脱去布直裰与虎皮裙，纵身跳进烧滚的油锅，翻波斗浪如同戏水，八戒咬着指头对沙僧夸他。
猴身入沸油而无伤，画面靠烈火、油浪、热气与旁观者神情成立，不涉血腥；具名角色三位，动作是“入锅戏水”一个瞬间。三处依据：

- 「脱了布直裰，褪了虎皮裙，将身一纵，跳在锅内，翻波斗浪，就似负水一般顽耍」
- 「八戒见了，咬着指头对沙僧道」
- 「那当驾官果安下油锅，架起干柴，燃着烈火，将油烧滚」

## 器物与环境

- 地点：车迟国金銮殿前一带；油锅摆放处原文未写，兜底：殿前阶下空地，国王与官员在阶上观看。
- 时间天气：白天（次回开头国王“哭到天晚”）；季节原文未写。
- 油锅：一口大锅盛满香油，锅下架干柴、烈火烧滚。悟空口述武洗要衣架、手巾，原文未写是否备办；
  衣物放置处未写，兜底：叠放锅边地上。
- 现实中会动的：① 灶下烈火与升起的烟；② 滚油翻涌、冒泡与溅起的油花；③ 锅口升腾的热气。

## 排除项

- 不画砍头、剖腹、血迹、无头黄毛虎、白毛角鹿：这些在油锅之前。虎力、鹿力此时已死，三国师不同台。
- 冷龙只出现在羊力入锅之后，悟空洗浴时锅里没有龙；动画把冷龙画成锅中游动的小龙，属后世演绎。
- 不画枣核钉、沉底、捞骨骸、羊力皮焦肉烂、铁笊篱：均在洗浴之后。
- 八戒、沙僧此刻未被捆；八戒被校尉揪翻、唐僧设奠、悟空打死监斩官都在悟空“烹死”之后。
- 1986 版电视剧没有拍油锅，影视无可参照；剧中三道士的虎纹衣、白衣造型不属原著。
- 悟空此刻不穿直裰与虎皮裙；原文无“金箍棒搅油”之说。
