# 《西游记》第95回 假合真形擒玉兔　真阴归正会灵元

底本：<https://zh.wikisource.org/wiki/西遊記/第095回>（回目另有“假合形骸”一读）；读取日期：2026-10-19。

## 情节要点

1. 唐僧随国王入鳷鹊宫赴合卺宴，悟空伏在毘卢帽上看出公主头顶有妖氛，现本相揪住公主，
   满宫惊散。
2. 假公主脱去衣冠首饰，跑到御花园土地庙取出碓嘴样的短棍（捣药杵），与悟空从花园打到
   半空；悟空棒变千百条围打，妖精化清风逃向西天门。
3. 西天门前天王与四大元帅拦阻，妖精自述杵是月宫捣药杵，又斗十数合，败逃正南毛颖山，
   躲进兔穴。
4. 悟空回宫安顿唐僧，再往山中，唤出土地山神，撬开顶窟石块，妖精跳出再战；天晚，太阴
   星君带姮娥仙子降云制止，说明素娥与玉兔的前因，喝令玉兔现原身。
5. 太阴星君在天竺国上空向国王验明，收玉兔回月宫；次日悟空领国王到布金寺救出真公主，
   改山名宝华山，唐僧辞王西行。

## 选定场面

毛颖山上空，天色将晚，悟空刚收起铁棒，躬身行礼；太阴星君驾彩云降临，身后带着姮娥仙子，
手指玉兔喝令归正，玉兔打个滚，现出白毛红眼的原身。避开前半回假公主脱衣后的打斗，取收伏
的瞬间：画面干净，兔身造型原文写得最细。具名角色悟空、太阴星君、玉兔三位，另加姮娥仙子
群像。三处依据：

- 「玉兔儿打个滚，现了原身」
- 「缺唇尖齿，长耳稀须」
- 「双睛红映，犹欺雪上点胭脂」

## 器物与环境

- 地点：天竺国正南毛颖山上空；山有三处兔穴，顶窟被两块大石挡住，悟空撬开（碎石可
  散落山顶）。土地、山神已被唤出，可不画。
- 时间天气：申时后，天色渐晚（月亮此刻原文未写）；九霄间彩云。
- 杵：羊脂白玉磨琢，形如舂碓的杵头，一头粗一头细，是一条短棍。
- 现实中会动的：① 彩云流转与晚霞；② 太阴星君、仙子的飘带与衣袖被风吹起；③ 兔身
  毛尖与长须在风中微颤。

## 排除项

- 假公主在宫中被揪、脱衣卸钗环、持杵打斗，宫中妃嫔所说“精著身子”：一律不取。玉兔此刻
  已是兔身，不画公主形貌，不画任何裸露。
- 西天门前天王与四大元帅、悟空以棒变千百条围打在前；天竺国上空验明、八戒抱霓裳仙子、
  布金寺救真公主在后，均不入画。
- 86版《天竺收玉兔》以嫦娥出场收伏，玉兔着人形装束；原著出场的是太阴星君，嫦娥是其
  随从的统称，不沿用。
- 太阴星君不是嫦娥，不画成单个嫦娥奔月造型；玉兔不画成卡通粉兔或月饼兔，不穿人衣。
- 无血、无打斗，悟空不举棒。
