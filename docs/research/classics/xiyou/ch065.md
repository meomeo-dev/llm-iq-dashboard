# 《西游记》第65回 妖邪假设小雷音　四众皆遭大厄难

底本：<https://zh.wikisource.org/wiki/西遊記/第065回>；读取日期：2026-10-19。

## 情节要点

1. 师徒春季西行，见高山上有雷音寺气象，山门额“小雷音寺”；悟空劝阻，三藏执意进寺，
   命八戒取袈裟、换僧帽。
2. 殿中莲台上假佛祖高坐，阶下罗汉揭谛成列；三藏、八戒、沙僧拜倒，悟空不拜，识破后抡棒
   便打，半空落下金铙将他罩住；三人被擒。
3. 揭谛奏玉帝，二十八宿夜降；亢金龙以角拱进铙缝，悟空自角尖钻孔脱身，一棒打碎金铙。
4. 妖王现身，自称黄眉老佛，使狼牙棒与悟空斗五十合；他抛出白布搭包，把悟空与诸神装去。
5. 悟空夜里救出师父，盗袈裟不成；再战又遇搭包，悟空逃上九霄，欲请真武。

## 选定场面

小雷音寺大殿宝台前，莲台上假佛祖高坐；三藏、八戒、沙僧拜倒，悟空不拜，抡棒冲向莲台，
半空落下一副金铙，要将他连头带足合住。具名角色四位：悟空、三藏、八戒、沙僧；假佛祖
与阶下罗汉揭谛作群像。众人伏拜与悟空独立对冲，金铙将合未合，无血腥。三处依据：

- 「行者公然不拜」
- 「双手抡棒，上前便打」
- 「只听得半空中叮当一声，撇下一副金铙，把行者连头带足，合在金铙之内」

## 器物与环境

- 金铙：一副“浑金之宝”，铙钹形制，即成对、中央碗状隆起的圆形金属盘；合拢后无一丝缝隙。
  兜底：两片碗状大圆盘上下相合，把悟空罩在中间；合拢前一瞬可见盘沿与棒梢。此刻尚未
  随悟空变大变小。
- 小雷音寺：祥光霭霭，彩雾纷纷；珍楼宝座，青松带雨遮高阁，翠竹留云护讲堂，朱栏玉户，
  画栋雕梁；二层门内是如来大殿，殿门外为宝台。山门额四字，不要求画字。
- 时令：三春（“草芽遍地绿，柳眼满堤青”“一岭桃花红锦涴”）；
  入寺时辰未写（夜里二更在后文）。
- 现实中会动的：① 殿中香烟与祥光彩雾；② 自空落下合拢的金铙；
  ③ 悟空衣带与虎皮裙摆被劲风带起。

## 排除项

- 黄眉怪真身（蓬头、扁薄金箍、黄眉竖、连环铠、狼牙棒）、白布搭包、二十八宿、
  悟空打碎金铙、弥勒收妖（第66回），均在后文，不入画；此刻妖王仍扮佛祖，不显妖身。
- 小雷音寺不是大雷音寺；假佛祖不是如来真身。金铙不是“金钵”“金钹”（二手资料常误写）。
- 毘卢帽是第12回太宗所赐，本回只写“僧帽”；悟空被罩后的变大变小、钻角是后一幕。
- 央视版第19集对应原著第64–66回；未检到可核对的假佛、金铙造型资料，不依影视。
