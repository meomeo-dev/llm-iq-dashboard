# 《西游记》第87回 凤仙郡冒天致旱　孙大圣劝善施霖

底本：<https://zh.wikisource.org/wiki/西遊記/第087回>；读取日期：2026-10-19。
回目「致旱」，底本标注一作「止雨」。

## 情节要点

1. 师徒别樵子，数日后到天竺外郡凤仙郡，街市荒凉；郡侯上官氏出榜求雨。三年前十二月
   二十五日，他推倒斋天素供喂狗，触怒玉帝，郡中连年亢旱。
2. 悟空唤来东海龙王敖广，龙王称无旨意、无行雨神将，不敢下雨；悟空上天请旨，护国天王
   透露玉帝立了米山、面山、金锁三事，玉帝说明立在披香殿。
3. 玉帝令四天师引悟空到披香殿看三事：鸡啄尽米、狗舔尽面、灯焰燎断锁梃，才该下雨；
   天师指点，劝善即可化解。
4. 郡侯皈依，合郡念佛；悟空向九天应元府借邓辛张陶四雷将，善念上达，米面山倒、锁梃
   断，玉帝降旨下雨三尺零四十二点；四部神祇显真身受拜，郡侯建「甘霖普济寺」。

## 选定场面

披香殿内，四天师引悟空看玉帝立下的三事：画面两座大山，米山十丈、面山二十丈，面山
高出米山一倍；米山边一只拳头大的鸡在啄米，面山边一只金毛哈巴狗在舔面；殿的一侧铁架
上悬一把金锁，锁下一盏明灯，灯焰正燎着锁梃。悟空回头问天师。具名角色悟空，天师作
群像，画一至二位。三处依据：

- 「米山边有一只拳大之鸡，在那里紧一嘴，慢一嘴，嗛那米吃」
- 「面山边有一只金毛哈巴狗儿，在那里长一舌，短一舌，餂那面吃」
- 「下面有一盏明灯，灯焰儿燎着那锁梃」

## 器物与环境

- 地点：天宫披香殿，殿宇形制原著未写，兜底：云气托起的敞阔殿堂，不借用灵霄殿。
- 米山约十丈高，面山约二十丈高；颜色未写，兜底：米山米黄偏白，面山纯白。
- 鸡「拳大」，紧一嘴慢一嘴地啄米；狗为金毛哈巴狗，长一舌短一舌地舔面，大小未写，
  兜底：寻常小型犬大小。
- 铁架在殿「左边」（以谁为左未说明），题面写成「殿的一侧」；架上挂一把黄金大锁，
  约一尺三四寸长，锁梃有指头粗细；下面一盏明灯，灯焰燎着锁梃。
- 时令：十二月二十五日是三年前惹祸之日，现今时序未写，不强加季节。
- 现实中会动的：① 灯焰摇曳燎锁梃；② 鸡头点啄、狗舌舔动，山脚米粒与面粉簌簌滑落；
  ③ 悟空的衣带、虎皮裙边与天师衣袖。

## 排除项

- 玉帝、灵霄殿、通明殿、护国天王、龙王敖广、雷将与闪电娘子、四部神祇显身，均属别节，
  不入画。
- 八戒、沙僧、唐僧、郡侯在凤仙郡，不在殿中；八戒说「变出法身，一顿把他的米面都吃了」是悟空回到
  下界之后的话，殿中无八戒。
- 此刻米山、面山未倒，鸡狗未吃尽，锁梃未断，也没有下雨；不画倒塌、雨幕。
- 86版第10集《大闹披香殿》演八戒真吃米山、悟空偷风婆婆风口袋把面粉吹满天宫、玉帝
  受惊，原著无此事，不沿用。
- 二手文章称金锁「斗大」、灯「豆粒大」、狗「板凳大」，与底本不合，以底本为准。
- 米山、面山是天上殿中之物，不是郡侯家粮仓；画面里不写榜文或「上官」之类的字。
