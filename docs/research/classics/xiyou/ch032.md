# 《西游记》第32回 平顶山功曹传信　莲花洞木母逢灾

底本：<https://zh.wikisource.org/wiki/西遊記/第032回>；读取日期：2026-10-19。

## 情节要点

1. 师徒离开宝象国，值三春景候，上平顶山。日值功曹化作樵夫拦路，说山中莲花洞有两个
   魔头，随身五件宝贝，专要吃唐僧；悟空追到云端识破功曹。
2. 悟空假意落泪，激八戒去巡山；八戒挺钉钯走进深山，悟空变蟭蟟虫伏在他耳后跟着听。
3. 八戒躲进红草坡睡觉，悟空变啄木虫啄醒他；八戒走到山凹，对三块青石唱喏，把石头当作
   唐僧、沙僧、悟空，演习“石头山、石头洞、钉钉铁叶门”的谎话；回去被悟空当面说破。
4. 洞中金角大王、银角大王商议吃唐僧；银角带三十名小妖巡山，凭画影图形认出八戒，
   与他斗二十回合，八戒被藤绊倒，被群妖擒入洞。

## 选定场面

八戒在山凹中放下钉钯，对三块青石唱喏，悟空变的蟭蟟虫钉在他耳后听着发笑。辨识度高，
原文写明石头的数量、大小与八戒的动作；两个具名角色，一个瞬间即可成画，无血腥。
三处依据：

- 「只见山凹中有桌面大的四四方方三块青石头」
- 「呆子放下钯，对石头唱个大喏」
- 「还变做个蟭蟟虫，钉在他耳朵后面，不离他身上」

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 猪八戒 | 野猪相，长嘴大耳，唐僧说他两耳盖着眼，脑后有鬃；穿直裰（第31回已被群猴揪破），赶路时“撒起衣裙”；兵器九齿钉钯，此刻放下在地；头饰、衣色未写 | 第19回钯与衣；第31回；本回 |

## 器物与环境

- 地点：平顶山（径过约六百里）中的一处山凹，凹中三块青石桌面大小、四四方方；
  八戒先前睡觉的红草坡是另一处，相距数里，不在此景。
- 时令：三春，即春季；时辰、天气未写。
- 现实中会动的：① 蟭蟟虫的薄翅振动（诗赞“翅薄舞风”）；② 山凹草木随春风摇动
  （原文未专写，属时令推定）；③ 八戒的大耳与直裰下摆随躬身晃动。

## 排除项

- 樵夫（日值功曹所化）、唐僧、沙僧都在山下，不入画。
- 八戒此时尚未遇银角与小妖，没有影神图，也没有交战；二魔此时不出场。
- 悟空此刻是蟭蟟虫，不现原身；啄木虫是前一段变化，苍蝇是第34回变化，均不画。
- 青石不是妖怪，也无字；“石头山、石头洞、钉钉铁叶门”是八戒编的谎话，山凹里没有洞门。
- 本回没有八戒唱巡山歌的情节，不添。
- 金角、银角之名首见本回洞中商议，原文未写二人相貌，更未写长角。
