# 《西游记》第53回 禅主吞餐怀鬼孕　黄婆运水解邪胎

底本：<https://zh.wikisource.org/wiki/西遊記/第053回>；读取日期：2026-10-19。

## 情节要点

1. 山神、土地献上悟空化来的斋饭，师徒吃毕上路；早春遇小河，老梢婆撑船渡过，收钱入屋。
2. 唐僧、八戒饮了河水，不到半个时辰腹痛隆起；村舍老婆婆笑说是西梁女国的子母河水，
   须喝解阳山破儿洞的落胎泉水才能解胎气。
3. 如意真仙是牛魔王之弟、红孩儿的叔父，用如意钩子阻拦悟空取水，钩他跌了两跤。
4. 悟空调虎离山，沙僧用降妖宝杖打伤道人，打得一桶泉水；悟空折断如意钩。
5. 唐僧、八戒各服半盏，化了胎，次日出村舍。

## 选定场面

村舍门前，唐僧、八戒喝了子母河水后腹部隆起，面黄眉皱，被悟空与沙僧一左一右搀扶着往草舍里走，
门外草墩上的老婆婆端坐绩麻，喜笑着看。具名角色四位：唐僧、八戒、悟空、沙僧，婆婆为配角。
腹大如孕与婆婆的笑构成反差，是本回最易辨认的一刻；无打斗。三处依据：

- 「忽然见那路傍有一村舍，树梢头挑着两个草把」
- 「但只见那门儿外有一个老婆婆，端坐在草墩上绩麻」
- 「行者即搀唐僧，沙僧即扶八戒，两人声声唤唤，腆着肚子」

## 器物与环境

- 地点：西梁女国境内的路旁村舍（辞别后还要走三四十里才到国界，见第54回），酒家标记是树梢上挑的两个草把；舍为草舍，有后屋。渡河后西行不到半个时辰才到村舍，河不在画面里。
- 时令：早春。燕子呢喃，黄鹂啼鸣，满地落红如布锦，遍山新绿，岭上青梅结豆，崖前古柏留云，
  园林花蕊初放，柳芽新发。赞词另有“野润烟光淡，沙暄日色曛”，时辰未写。
- 器物：草墩、麻线，白马，行李担，八戒的钉钯；钵盂是饮水用的，饮毕后文不再提，可不画。
- 现实中会动的：① 树梢挑着的草把与柳条随风摆；② 飞舞的燕子与飘落的花瓣；③ 婆婆手中捻动的麻线。

## 排除项

- 梢婆是渡口的另一个妇人（头裹锦绒帕、身穿百衲棉裆袄），收钱入庄屋，不是村舍婆婆；
  渡船、河水属前一幕，不入画。
- 此刻只有唐僧与八戒怀胎，悟空、沙僧不是；八戒吃十数碗粥是化胎之后的事，不是此刻。
- 女国城池、女官、女王均在下一回；婆婆口中的“一国都是女人”只是对话，不要画出街市。
- 如意真仙、聚仙庵、落胎泉、如意钩子、沙僧取水是后半段；如意真仙是人形道人，不是牛魔王。
- 不画分娩，不画“从胁下裂个窟窿”（悟空的玩笑话）；不画红孩儿。
- 据一篇评论，1986版把误饮挪到女国驿馆、删去村舍婆婆一段；不沿用其构图。
