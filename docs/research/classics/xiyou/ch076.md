# 《西游记》第76回 心神居舍魔归性　木母同降怪体真

底本：<https://zh.wikisource.org/wiki/西遊記/第076回>；读取日期：2026-10-19。

## 情节要点

1. 悟空在青狮老魔肚里逼其许诺抬轿送师；老魔被三魔挑唆咬他，崩了门牙。悟空以毫毛变绳
   拴住老魔心肝，从鼻孔出来，在山头扯绳把老魔拽得跌出土坑，老魔再度告饶。
2. 悟空回到坡下，八戒已谎称他被吃并在分行李，被悟空一掌打了踉跄。
3. 二魔叫战，八戒腰系“救命索”出战，被长鼻卷走；悟空变蟭蟟虫跟入洞，扮勾司人诓出八戒的
   私房银子，再放他出池塘，二人打出洞门。
4. 二魔欲卷悟空，只卷住腰胯；经八戒提醒，悟空把棒搠进鼻孔，一把抓住长鼻拉回坡下，
   八戒倒持钯柄在后敲打；唐僧交代只要肯送就饶命，二魔应允。
5. 三魔定“调虎离山”之计，众妖抬轿送唐僧到狮驼国城外，翻脸擒走唐僧，三徒与三魔恶战。

## 选定场面

狮驼岭山坡上，悟空一手抓住被搠松的二魔长鼻，用力前拉，二魔护疼举步跟走；八戒倒转钉钯，
用钯柄一步一敲；坡下唐僧凝睛远望。原文自比“两个象奴”。具名角色四位：悟空、八戒、
二魔、唐僧。牵鼻与倒持钯柄是同一瞬间，无血腥结果（悟空嫌钯齿尖、恐淌血，才改用钯柄）。
三处依据：

- 「行者牵着鼻子：就似两个象奴，牵至坡下」
- 「只调柄子来打罢」
- 「被妖精一鼻子卷住腰胯，不曾卷手」

## 器物与环境

- 地点：狮驼岭洞外山坡，坡下大路旁；沙僧在唐僧身侧，可不入画。
- 时令：秋（第75回悟空自述“如今秋凉”）；本回未再写天气，时辰未写，按白天作画。
- 钯：九齿，齿尖锋利，故倒持；二魔的鼻被搠后“鼻孔害疼流涕”，不画血。
- 救命索（悟空毫毛变绳）在八戒出战后的去向原文未写，不入画。
- 现实中会动的：① 八戒湿衣下摆滴落的水珠；② 被拖拽的二魔脚下扬起的坡面尘土；③ 山风吹动的草叶与衣带。

## 排除项

- 悟空钻进老魔肚内、毫毛绳拴心、八戒被捆浮在池塘如“黑莲蓬”，均属前几段，不入画。
- 青狮老魔此时已回洞，三魔大鹏在洞内，不画；二魔不是整只象，不画四足象形。
- “六牙白象”不见于第74–77回底本；二魔牙黄鼻毛银，沿用本回写法。
- 悟空不戴凤翅紫金冠、不披黄金甲；不画象钩、象鞍等原文未写的驯象具。
- 沙僧本段只在坡下说话，不单独刻画；不超过四个具名角色。
- 续集有《受阻狮驼岭》一集，未查到二魔卷鼻段的造型资料，不沿用影视造型。
