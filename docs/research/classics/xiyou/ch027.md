# 《西游记》第27回 尸魔三戏唐三藏　圣僧恨逐美猴王

底本：<https://zh.wikisource.org/wiki/西遊記/第027回>；读取日期：2026-10-19。

## 情节要点

1. 师徒辞别镇元子上路，过一座险峻高山，唐僧饥渴，悟空驾筋斗云去南山摘桃。
2. 山中尸魔三次变形：先变月貌花容的女子，提罐与瓶，自称还愿斋僧；悟空回来认出，举棒便打。
3. 尸魔用解尸法脱身，只留假尸首；罐中是蛆、瓶中是蛙蟆。八戒挑唆，唐僧念紧箍咒。
4. 尸魔再变八旬老妇、白发老公公，均被悟空打死假身；第三次现出一堆粉骷髅，脊背有字。
5. 唐僧写下贬书逐走悟空；悟空拔毫毛变四身拜别，嘱咐沙僧，回花果山。

## 选定场面

沿用已有题面的场面：第一变，悟空自南山摘桃落回，放下钵盂，举铁棒劈向女子，唐僧伸手拦阻，
八戒在侧。构图单纯，美貌女子与手提罐瓶的反差明确，不画蛆蛙与尸骨。三处依据：

- 「左手提着一个青砂罐儿，右手提着一个绿磁瓶儿，从西向东，径奔唐僧」
- 「放下钵盂，掣铁棒，当头就打」
- 「吓得个长老用手扯住道」

## 器物与环境

- 地点：白虎岭，女子自称“蛇回兽怕的白虎岭”。峰岩重叠，涧壑弯环，道旁荆棘牵漫，薜萝满目。
- 时令：夏日白昼，女子称“五黄六月”送午饭；岭上赞词写“日光寒”，阴风只指妖精所乘。
- 器物：青砂罐、绿磁瓶（磁即瓷；女子自称饭与面筋，实为长蛆与蛙蟆，要到打后才揭穿）、铁棒、盛桃钵盂、白马。
- 现实中会动的：① 悟空落地时收散的筋斗云；② 山风吹动女子翠袖湘裙与僧衣下摆；③ 路旁荆棘薜萝与芳草摇曳。

## 排除项

- “白骨精”一名不见原文，称尸魔、白骨夫人；“三打白骨精”是后世通称。白骨第三次打死后才现。
- 唐僧念紧箍咒在揭穿罐中蛆蛙、八戒挑唆之后，不是举棒的瞬间。紧箍儿咒之外没有松箍儿咒。
- 悟空此刻不戴紫金冠、不穿赭黄袍；沙僧不离场；黄袍怪第28回才出场，奎木狼之名第31回才揭晓。

## 现有题面核对

对象：xiyou-027 静态与 xiyou-anim-027。有据：白虎岭、年轻美貌女子、青砂罐绿瓷瓶、迎面而来、头戴金箍、铁棒当头劈打。
有误、无据或含后世说法之处：

- “三打白骨精”（标签与正文）：后世通称。原文回目为“尸魔三戏唐三藏”，女妖只称尸魔、白骨夫人。
- “荒凉阴森”（静、动）：荒凉有据，阴森无据；原文是夏日白昼，勿写成暗夜阴雨。
- “身披袈裟的唐僧”（静）、“宽大袈裟衣袖挥舞”（动）：无据，本回未写袈裟。
- “张开双手拦阻”（静）、“挥舞拦阻”（动）：不确。第一变唐僧“用手扯住”悟空；第二、三变并未拦阻，
  第二变打后惊下马念咒，第三变唐僧在马上吓得口不能言。
- “八戒撇嘴看热闹”（静、动）：不确。八戒见女子斋僧满心欢喜，努嘴埋怨师父不吃，用嘴拱倒罐子要吃，并非旁观。
- “女子脚下的影子显出骷髅”（静、动）：无据。原文无影子；尸骨第三次打死后才现；前两次只留假尸首。
- “腾空跃起”（动）：无据。悟空驾筋斗云回来，落地放下钵盂后举棒，“金箍棒”与“铁棒”均有据。
- “旋转遁逃的幽暗白烟”（动）：无据。尸魔用解尸法，元神在棒落前先走，留假尸首；之后在云端咬牙，无烟。
- 沙僧：两版均未写。原文沙僧在场，侍坐唐僧身旁，并非缺席；题面不应暗示他不在。
