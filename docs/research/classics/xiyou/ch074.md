# 《西游记》第74回 长庚传报魔头狠　行者施为变化能

底本：<https://zh.wikisource.org/wiki/西遊記/第074回>；读取日期：2026-10-19。

## 情节要点

1. 师徒走出情网，时已夏尽秋初；前遇高山，坡上一白发老者高呼前有妖魔，唐僧惊得
   跌下马。
2. 悟空变作俊俏小和尚去问，老者待答不答；悟空抹脸现出本相，老者吓得跌倒，装聋不应。
   八戒再去，才问出此山是八百里狮驼岭，洞中三魔，小妖四万七八千。
3. 悟空追上半空，认出老者是太白金星所变，金星称魔头厉害，须凭机谋方可过山。
4. 悟空变作小妖，遇上巡山的小钻风，以假牌自称“总钻风”，套出三魔的本事与来历，
   随即把他打死，变成他的模样赶往洞口。
5. 洞前万余小妖列阵，悟空编说“孙行者在磨杠子”，吓散了门前众怪，只身走向洞口。

## 选定场面

高山坡上，悟空抹脸现出本相，立在石崖下，龇牙咧嘴，腰系虎皮裙，手执金箍棒；白发老者
吓得面容失色，腿软跌倒。具名角色两位：悟空与老者（太白金星所化，此时不显真身）。
一静一倒，对比鲜明，没有打斗。三处依据：

- 「咨牙徕嘴，两股通红，腰间系一条虎皮裙，手里执一根金箍棒」
- 「立在石崖之下，就像个活雷公」
- 「鬓蓬松，白发飘搔；须稀朗，银丝摆动；项挂一串数珠子，手持拐杖现龙头」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙悟空 | 本相：尖嘴龇牙的毛脸，金睛火眼（第14回），腰系虎皮裙，手执金箍棒。“两股通红”指猴子的红臀，被裙遮住，不单独画。金箍、直裰本段未写，兜底：金箍戴头上，初秋穿单直裰 | 变化段；第14回；第75回 |
| 白发老者 | 蓬松白发、稀疏银须，颈挂一串数珠，手持龙头拐杖，年老体弱。衣着原著未写，兜底：粗布长袍的山野老翁，不穿官服；受惊后身子后仰、一手撑杖 | 报信段 |

## 器物与环境

- 地点：一座高山的山坡，“峰插碧空”“摩星礙日”；石崖在坡旁。师徒在坡下，不入画。
- 时间天气：夏尽秋初，“新凉透体”；时辰原文未写，兜底：白天。
- 器物：龙头拐杖、数珠；金箍棒此刻握在悟空手里，未变大小，按平常棒身画。
- 现实中会动的：① 山风吹动老者的白发银须与悟空虎皮裙边；② 坡上草木与梧桐叶；
  ③ 远处山间云气。

## 排除项

- 俊小和尚相（目秀眉清、头圆脸正、锦衣直裰）是变化形态，此刻已抹脸现出本相，不画。
- 唐僧跌下马、八戒二次问话、太白金星现真身，都在前后段，不入画。
- 太白金星此时是山林老翁，不画朝服、拂尘等原文未写之物；常见的白须仙官造型属后世。
- 小钻风、令字旗、梆铃、总钻风牌、笔峰、狮驼洞前列阵属后段；青狮、白象、大鹏
  三魔与阴阳二气瓶只是老者与小妖口中的话，不画。
- 老者是人，不是妖怪，不画獠牙尾巴；悟空也不是此回后段的小妖形态。
- 86版把报信人改成孔雀公主扮的村姑，与原著不同，该造型不沿用。
