# 《西游记》第73回 情因旧恨生灾毒　心主遭魔幸破光

底本：<https://zh.wikisource.org/wiki/西遊記/第073回>；读取日期：2026-10-19。

## 情节要点

1. 师徒走出盘丝洞，来到黄花观；观主道士迎入，不知七个蜘蛛精是他同堂学艺的师妹，
   她们已先来哭诉。
2. 道士用百鸟粪熬成的毒药掺进红枣，奉茶；唐僧、八戒、沙僧饮后倒地，悟空未饮，
   摔碎茶盅，与道士动手。
3. 七个蜘蛛精吐丝罩住悟空，悟空翻身冲破；土地点明她们是蜘蛛，悟空以分身叉棒搅断
   蛛丝，把七精打死。
4. 道士脱去皂袍，两胁下一千只眼放出金光黄雾，把悟空困住；悟空变穿山甲钻地逃出，
   遇黎山老母化作孝妇指点，去紫云山千花洞请毗蓝婆。
5. 毗蓝婆抛出绣花针破了金光，赐解毒丹救活三人，道士现七尺长蜈蚣原形被收去看门；
   师徒放火烧了道观。

## 选定场面

黄花观内，道士脱下皂袍、双臂齐抬，两胁下千只眼迸出金光黄雾，悟空被罩在光中进退
不得。具名角色两位：悟空与道士（百眼魔君，多目怪）。金光黄雾是视觉主体，一个人放光、
一个人受困，没有血腥结果。三处依据：

- 「只见那两胁下有一千只眼，眼中迸放金光」
- 「两边胁下似喷云；艳艳金光，千只眼中如放火」
- 「向前不能举步，退后不能动脚，却便似在个桶里转的一般」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 道士（多目怪） | 红艳艳戗金冠、绿阵阵云头履、黄拂拂吕公绦（已解开）；面色如铁、目若朗星、鼻准高大、唇口外翻；黑色皂袍此时已脱下。脱袍后的内衣原著未写，兜底：贴身浅色短衫，不画裸露的躯干，眼睛排布在两胁处；冠仍戴。剑的去向未写，兜底：落在脚边。此刻是人形，蜈蚣原形在后 | 初见赞；战斗段 |
| 孙悟空 | 金箍、直裰、虎皮裙；使金箍棒，取出时“碗来粗细”。在金光里神态焦躁，兜底：双手握棒，身周被光裹成桶状 | 战斗段；第72回 |

## 器物与环境

- 地点：黄花观院内。门上石板刻观名、二门有春联（画面不写字）；正殿紧闭，供三清像，
  东廊是道士丸药处。悟空打死蜘蛛精后赶进观内，与道士战五六十合。
- 时间天气：与上回同日，春光明媚；具体时辰原文未写。
- 金光黄雾：“森森黄雾”“艳艳金光”，从两胁千眼射出，形如金桶、铜钟罩住悟空，范围
  约十余里；悟空上跳会撞到光壁，撞得头疼。画成金黄光柱与黄雾，不用红蓝等他色。
- 兵器：道士宝剑；悟空如意金箍棒。
- 现实中会动的：① 翻涌的黄雾；② 千眼射出的金光明灭闪烁；③ 道士冠带、黄色吕公绦
  与落地皂袍衣角的摆动。

## 排除项

- 七个蜘蛛精吐丝罩悟空一节不入画，她们此时已被打死；不画蜘蛛精，也不画丝篷。
- 毗蓝婆、绣花针、昴日星官，道士现蜈蚣原形，都在后段，不出现；不画黎山老母孝妇相。
- 千眼在“两胁下”，不是满脸生眼、手心生眼，也不是蜈蚣腿足；眼数画“千”而非三两只。
- 唐僧、八戒、沙僧中毒倒地在殿内客位，不入画；悟空变穿山甲是之后，不画。
- 道士是道冠道袍的道士，不是和尚；不加拂尘、八卦等原文未写之物。
- 86版由李鸿昌饰百眼魔君，其金光与千眼的拍法资料未检到；游戏《黑神话：悟空》等的
  百眼魔君造型不沿用。
