# 《西游记》第36回 心猿正处诸缘伏　劈破傍门见月明

底本：<https://zh.wikisource.org/wiki/西遊記/第036回>；读取日期：2026-10-19。

## 情节要点

1. 师徒离了上回的山，西行又遇一山；三藏忧西天难行，悟空以“青天为屋瓦”作喻劝慰。
2. 日落时山凹现出楼阁，悟空升空察看；山门上“敕建宝林寺”五字被灰尘蒙住，悟空长身擦净。
3. 三藏独入借宿，僧官以“游方僧赖住不走”为由拒留，只许到前廊蹲一宿；三藏含泪出寺。
4. 悟空闯进方丈，把棍子变得盆口粗细竖在天井，举棍打碎方丈门外的石狮子，僧官吓得躲到床下。
5. 五百僧排班出山门跪接；饭后三藏对月怀归，悟空借月相讲丹道，三藏回禅堂挑灯念经。

## 选定场面

方丈院天井里，悟空一棍打碎石狮子，僧官与道人在窗后、灶门边惊惧。适合入画：动作瞬间明确，
石屑飞溅可直观表现，出场只需悟空与石狮，僧官自窗眼窥视作衬。三处依据：

- 「忽抬头，只见方丈门外有一个石狮子」
- 「却就举起棍来，乒乓一下，打得粉乱麻碎」
- 「那和尚在窗眼儿里看见，就吓得骨软筋麻」

## 器物与环境

- 地点：宝林寺方丈院；天井、方丈门（门扇已被悟空打破）、窗眼、石狮（原文称“一个”，姿态未写）。
- 时间天气：傍晚，天色已晚；明月当天是饭后；天气原文未写。
- 兵器：棍子此前已变得盆口粗细，打狮时未再写其变化，仍按盆口粗细理解。
- 现实中会动的：① 石狮裂开处崩落、飞溅的石屑与扬起的尘土；② 悟空腰间裙边被挥棍带起的风吹动。

## 排除项

- 三藏、八戒、沙僧与白马此时在山门外，不入方丈院。
- 五百僧排班跪接、“一裹穷”衣着、月夜论月相、禅堂念经均是此后场面。
- 本回悟空只称“铁棒”，“金箍棒”之名到第38回才出现；题面可称铁棒。
- 悟空腰间原文只写“裙子”，虎皮裙是第14回所制；不写成披甲、战袍或三头六臂。
- 石狮是被一棍打碎，不是推倒或劈开；原文只有一个，不要画成一对。
- 悟空只在擦匾时长到二丈余，打狮时是常人身量；不画成巨人。
- 唐僧入寺时所穿二十五条达摩衣、拖泥带水的达公鞋属三藏，与本场面无关。
