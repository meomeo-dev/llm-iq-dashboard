# 《西游记》第67回 拯救驼罗禅性稳　脱离秽污道心清

底本：<https://zh.wikisource.org/wiki/西遊記/第067回>；读取日期：2026-10-19。

## 情节要点

1. 师徒离小西天行月余，春深时到驼罗庄借宿；李姓老者说庄西三十余里的七绝山稀柿衕，
   烂熟柿子填满夹石衚衕，成了一路污秽，另有妖风三年来吃人畜。
2. 夜里妖风起，半空现出两盏灯似的亮眼；悟空与八戒与它在空中斗到天明，妖只舞枪不答话，
   追到稀柿衕现出红鳞大蟒原形；悟空被蟒吞下，在腹内撑棒，蟒死，两人拖尸回庄。
3. 庄上留住五七日，数百人相送到衕口。悟空要八戒吃饱后变大猪拱路。
4. 八戒脱了直裰、丢了钉钯，变成黑面长嘴大猪，吃光干粮后向前拱路；唐僧骑马，
   沙僧挑担，悟空扶持，拱了两日，庄上人又送饭追来。
5. 衕道拱开，师徒别过众人继续西行。

## 选定场面

稀柿衕中，八戒变作大猪在前拱路，唐僧稳坐马上，悟空、沙僧随行扶持。具名角色四位，
大猪体形远大于众人，画面主体清楚。大猪的形貌赞词写得具体，拱路是一个稳定的动作瞬间，
没有打斗。三处依据：

- 「脱了皂直裰，丢了九齿钯」
- 「黑面环睛如日月，圆头大耳似芭蕉」
- 「白蹄四只高千尺，剑鬣长身百丈饶」

## 器物与环境

- 稀柿衕：七绝山的夹石衚衕，老者称山径八百里；满山柿树，往年熟烂的落果填满路面，经雨雪霜露
  与一个夏天成为污秽。画法兜底：两侧石壁与柿树，路面铺橙褐色烂柿与泥浆，不写具体秽物。
- 时令：开篇写“春深花放”，东南风大。树上不强加红柿满树，兜底：枝叶青绿，路上是往年的烂果。
- 昼夜：拱路历时两日，具体时辰原文未写，兜底白天。庄上人在山脚遥望，不入画。
- 沙僧所挑行李担、唐僧所骑白龙马（第15回起）随行。
- 现实中会动的：① 大猪拱起又落下的烂柿与泥浆；② 两侧柿树枝叶在风中摇摆；
  ③ 马鬃马尾与悟空、沙僧的衣摆随行进飘动。

## 排除项

- 红鳞大蟒、软柄枪（实为蛇信）、悟空入腹作桥作船属夜战一段，本场面不出现。
- 大猪是四足真猪形，不画人身猪头，不穿直裰、不持钯；不画成粉白家猪。底本尺寸只有“高千尺、
  长百丈”，检索摘要里的“獠牙二十丈”等说法底本没有，不采。
- 八戒拱路在前，不要画成悟空骑猪或唐僧下马步行。
- 驼罗庄人群、骡马送饭在拱路之后，不入画。
- 沙僧第22回起落发，不画披发。86版四十一集中第19集止于第66回、第20集起于第68回，
  没有本回，无可沿用的影视造型。早期影视多把八戒画成黑猪，与本回“黑面”相合，但不作依据。
