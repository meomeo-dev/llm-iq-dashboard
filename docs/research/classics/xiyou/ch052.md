# 《西游记》第52回 悟空大闹金兜洞　如来暗示主人公

底本：<https://zh.wikisource.org/wiki/西遊記/第052回>；读取日期：2026-10-19。

## 情节要点

1. 悟空夜入洞中，变促织、跳蚤，见魔王臂上圈子不离身；转后房解锁，毫毛变小猴搬走兵器、
   放火烧洞，天明魔王用圈子再将众神兵器与悟空铁棒套走。
2. 悟空上灵山求如来，十八罗汉放金丹砂又被套走；降龙、伏虎传话：去兜率宫找老君。
3. 兜率宫牛栏空着，看牛童子吃了落地的七返火丹睡去，青牛偷了金刚琢下界。
4. 老君执芭蕉扇同到金兜山，悟空诱魔出洞；老君一搧接住圈子，再搧魔王现青牛本相，
   金刚琢穿鼻，系上勒袍带，骑牛回宫。
5. 悟空打入洞中，救出三人；师徒出洞，路旁有人叫“吃了斋饭去”。

## 选定场面

金兜山高峰上，老君先后搧了两下扇子，魔王现出青牛本相，被金刚琢穿了鼻子，老君解勒袍带系在琢上
牵在手里。具名角色三位：老君、青牛、空手的悟空，另有峰头众神为群像。现形与穿鼻是一个明确瞬间，
没有打斗血腥。三处依据：

- 「又一搧，那怪物力软筋麻，现了本相，原来是一只青牛」
- 「老君将金钢琢吹口仙气，穿了那怪的鼻子」
- 「解下勒袍带，系于琢上，牵在手中」

| :-- | :-- | :-- |
| 老君 | 太上老君，执芭蕉扇，一手牵带。衣冠须发原著未写（前后回只写他化作瞽者），兜底：须发皆白的老者，道袍，不添拂尘等未写之物 | 收怪段；第35回化瞽者 |

| 众神 | 李天王父子、火德、水伯、雷公、十八罗汉候在高峰，面貌原著未写，只作远处群像 | 收怪前一段 |

## 器物与环境

- 芭蕉扇：老君自己的扇子，形制原文未写；与第59回铁扇公主的芭蕉扇不是一把。
- 金刚琢：第6回老君自述左膊圈子，锟钢抟炼，一名金刚琢、金刚套；本回“吹口仙气”后穿鼻成环。
  勒袍带是老君束袍的腰带（第35回称“一根勒袍的带”），不是绳索法宝。
- 圈子被老君“一把接住”后，魔王已无圈子；他的长枪此后原文不再提。
- 地点：金兜山高峰与山坡，魔王从洞口追到峰下。时令原文未写；事在夜战后的次日，具体时辰与天色未写。
- 现实中会动的：① 老君搧动的芭蕉扇与袍袖；② 系在琢上绷紧后垂下的勒袍带；③ 山风吹动的草木与峰头云气。

## 排除项

- 老君的神态、衣色没有写，不要凭印象添加八卦图、仙鹤、拂尘、八卦炉等原文未写之物。
- 魔王此刻已是青牛，不再画人身持枪；不要画两个魔王，也不要画老君骑上牛背（那是下一句）。
- 悟空不持铁棒，不分身；金丹砂、罗汉放砂、如来与比丘尼属前半，不入画。
- 看牛童子、七返火丹在兜率宫，不在山上。
- “宾郎”拴牛鼻的拘儿是原文对后世习俗的交代，不是画面要素。
- 1986版电视剧没有金兜山一段，无可沿用的青牛造型；常见“板角青牛”“牛鼻环壁画”等说法非底本。
