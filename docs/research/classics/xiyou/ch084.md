# 《西游记》第84回 难灭伽持圆大觉　法王成正体天然

底本：<https://zh.wikisource.org/wiki/西遊記/第084回>；读取日期：2026-10-19。

## 情节要点

1. 夏日行路，观音化作老母、善财化作小孩，在路旁柳荫里劝师徒莫往西走：前面是灭法国，
   国王发愿杀一万和尚，已杀九千九百九十六个，只等四个有名的和尚凑数；说完驾云回南海。
2. 悟空变飞蛾进城，在王小二店里变老鼠偷来俗人衣帽；师徒扮成贩马客商，投宿赵寡妇店，
   四人躲进一只大柜里睡下。
3. 柜被一伙贼连马抬走，贼被官军赶散，官军夺回柜与白马，抬进总府封存。
4. 三更，悟空出柜入宫，拔毫毛变小行者与瞌睡虫，把金箍棒变成千百口剃头刀，一夜之间
   替宫里宫外的君臣后妃都剃了头。
5. 次晨国王、百官发现自己成了光头，国王许诺不再杀僧，国名改为钦法国。

## 选定场面

夏夜三更，灭法国皇宫门前的半空，悟空踏在云头，掂一掂金箍棒，叫声“宝贝，变”，棒化作一大把
剃头刀；他拿起一把，身边一群缩小的悟空（小行者）各伸手接刀，要散入下方的殿宇；
一团细小的瞌睡虫飘向各处屋顶。具名角色一位：悟空；小行者与瞌睡虫为群像。全场没有
人被剃头，刀也不碰任何人，只取分发剃头刀这一个喜剧瞬间。三处依据：

- 「将左臂上毫毛都拔下来，吹口仙气，叫：『变！』都变做小行者」
- 「叫声：『宝贝，变！』即变做千百口剃头刀儿」
- 「右臂上毛也都拔下来，吹口仙气，叫：『变！』都变做瞌睡虫」

## 器物与环境

- 地点：灭法国都城皇宫门前的半空（原文“踏起云头，径入皇宫门外”），下方是宫墙、殿宇
  屋脊与回廊（原文另有五府六部、各衙门，不必画全）。城中原文称“祥光喜气”。
- 时令时辰：夏（开篇“薰风初动，梅雨丝丝”，“榴火壮行图”）；三更；前夜有“一轮明月上东方”，
  月相未写，只画一轮月，不强加盈亏。
- 剃头刀：原文“千百口剃头刀儿”，形制未写，兜底：窄刃小剃刀配短柄，刃面反光；不画
  现代剃须刀与电推子。
- 当方土地奉命领瞌睡虫布散，是顺带一笔，本场面不画土地。
- 现实中会动的：① 殿前宫灯与烛火；② 毫毛与瞌睡虫在夜风里飘散；③ 云头下缓缓流动的云气。

## 排除项

- 不画任何人被剃头的过程，刀不贴近头皮，也不画剃下的头发成堆；次晨宫人、国王、百官
  发现光头一节是下一场，不入画。
- 观音与善财（老母牵孩儿）在前半回，王小二店、赵寡妇店、大柜、贼与官军，也都不入画。
- 悟空此刻不是飞蛾、老鼠或蝼蚁等变化形，也不戴俗人头巾；唐僧、八戒、沙僧在柜中，
  不入画。
- 小行者是毫毛变的小悟空，不是三头六臂，也不是数以千计的大型分身；瞌睡虫不画成人形
  或睡神。
- 央视版没有单独的灭法国，剃头情节并入第23集《传艺玉华州》并改为隐身潜入宫中，
  其场景与造型不沿用。
