# 《西游记》第4回 官封弼马心何足 名注齐天意未宁

底本：维基文库《西遊記》第004回 <https://zh.wikisource.org/wiki/西遊記/第004回>；读取日期：2026-10-19。

## 情节要点

1. 太白金星引悟空上天，玉帝授御马监“弼马温”；悟空半月后得知此官“未入流”，推倒公案，
   打出南天门回花果山。
2. 悟空在洞门外竖旗，旗上书“齐天大圣”；玉帝遣托塔李天王与哪吒下界征讨。
3. 巨灵神败于金箍棒；哪吒变三头六臂，悟空也变三头六臂、棒作三条，斗三十回合不分胜负。
4. 悟空拔毫毛变出本相缠住哪吒，真身绕到背后一棒打伤哪吒左膊，哪吒败走。
5. 太白金星建议招安，玉帝封悟空“齐天大圣”，在蟠桃园右首建府，设安静、宁神二司。

## 选定场面

水帘洞外，哪吒变三头六臂、六件兵器齐出，悟空亦变三头六臂、金箍棒化为三条，二人对阵。两个具名
角色左右对称，六兵器与三条棒是全回最具辨识度的图形元素，洞门外的旌旗交代地点与缘由；取“架住”
的出手瞬间，不取打伤哪吒一棒，无血腥。

- “门外竖一高竿，竿上有旌旗一面。”
- “即变做三头六臂，恶狠狠，手持着六般兵器。”
- “也变做三头六臂；把金箍棒幌一幌，也变作三条。”

## 器物与环境

- 地点：花果山水帘洞外；高竿旌旗上写“齐天大圣”四大字；天兵营寨设在平阳处，不入画。
- 天气：未写；赞词有“神兵怒气云惨惨”“地动山摇”，兵器在半空“似雨点流星”。
- 兵器形态：“缚妖索子如飞蟒”“降妖大杵似狼头”“火轮掣电烘烘艳”。
- 会动的物件（动效候选）：1. 火轮儿旋转并带火焰（有据）；2. 缚妖索如蟒蜿蜒摆动（有据）；
  3. 旌旗随风飘展（旗有据，风属添加）。

## 排除项

- 后世哪吒装备：脚踏风火轮、乾坤圈、混天绫、火尖枪、莲花化身，皆出《封神演义》；《封神》另作
  “三头八臂”。本回是“三头六臂”，火轮儿是手持、可抛掷的兵器。
- 悟空：紧箍与虎皮裙（第14回）；紫金冠上的双翎（戏曲与影视造型，底本未写）；后文才有的火眼金睛；
  “弼马温”官职在此刻已被他弃置。
- 第5回及以后：蟠桃园、齐天大圣府、十万天兵、天罗地网。
- 同回其他瞬间：败巨灵神、分身偷袭、招安上天，不并入此幅。
