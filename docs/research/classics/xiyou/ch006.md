# 《西游记》第6回 观音赴会问原因 小圣施威降大圣

底本：维基文库《西遊記》第006回 https://zh.wikisource.org/wiki/西遊記/第006回
读取日期：2026-10-19。引文由繁体转写为简体。

## 情节要点

1. 蟠桃会冷落，观音随玉帝听其诉说；惠岸行者到花果山打探，与悟空战五六十合败走。
2. 观音荐玉帝之甥二郎神（居灌江口）；二郎率梅山六兄弟赶到，要与悟空赌变化。
3. 二人斗三百余合，各现法天象地；悟空见猴群溃散败走，依次变麻雀、大鹚老、鱼、
   水蛇、花鸨，二郎逐一对变，并以弹弓打翻花鸨。
4. 悟空滚下山崖变土地庙，被二郎识破；又变作二郎模样入灌江口，被真身撞破，复打回花果山。
5. 观音与老君在南天门观战，老君掷下金刚琢击中悟空，细犬咬腿，悟空被擒，押赴斩妖台。

## 选定场面

取“变庙被识破”：悟空滚下山崖变成小土地庙，二郎神赶到崖下，盯住庙后竖着的旗竿，
掣拳要先捣窗棂、再踢门扇。入画理由：造型全书仅此一处，一眼可辨；具名角色只有二郎神与
化庙的悟空；无血腥；一个瞬间即成立。

> 只有尾巴不好收拾，竖在后面，变做一根旗竿。
> 我也曾见庙宇，更不曾见一个旗竿竖在后面的。
> 等我掣拳先捣窗棂，后踢门扇。

未选：法天象地对阵（须画两个万丈巨身）；金刚琢击顶与细犬咬腿（带擒伤结果）。

## 器物与环境

- 土地庙：大张口为庙门，牙为门扇，舌为菩萨，眼为窗棂，尾巴竖在庙后作旗竿。现代民俗资料称
  庙旗竿惯立庙前，后置即是破绽。
- 兵器：三尖两刃枪（亦称神锋）、弹弓；本场只写掣拳，未写手持何物。
- 地点：花果山崖下；前一变花鸨立于蓼汀，涧水、蓼草可作背景。时辰、天气原文未写。
- 现实中会动的：(1) 涧水波纹、蓼草摇摆；(2) 旗竿（即尾巴）尖端微颤，为画面处理；
  (3) 二郎帽缨与衣带随势飘动，为画面处理。

## 排除项

- 二郎神第三只眼：底本无，只写“凤目”；该形象见于明清民间宝卷与神像。
- 哮天犬：底本称“细犬”，且擒悟空时才出场。三尖两刃“刀”：本回写作枪与神锋。
- 梅山兄弟全名（如康安裕）：后世所补，底本只有康、张、姚、李四太尉与郭申、直健。
- 他段内容：二郎的青脸獠牙法天象地相、金刚琢、琵琶骨被穿、斩妖台。
- 悟空头无金箍、不围虎皮裙、无直裰（第14回之事）；变庙时不与庙同框现猴形。
