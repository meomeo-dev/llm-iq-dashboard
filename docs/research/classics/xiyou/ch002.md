# 《西游记》第2回 悟彻菩提真妙理 断魔归本合元神

底本：维基文库《西遊記》第002回 <https://zh.wikisource.org/wiki/西遊記/第002回>；读取日期：2026-10-19。

## 情节要点

1. 悟空随须菩提祖师听讲，喜得手舞足蹈被点名；祖师依次提出术、流、静、动四门，悟空因不能长生皆不学。
2. 祖师以戒尺在悟空头上打三下，倒背手入内、关上中门；悟空悟出暗示：三更、后门。
3. 三更悟空由后门入，跪于祖师榻前受长生口诀，其后又得地煞七十二变与觔斗云（一觔斗十万八千里）。
4. 悟空在松树下变松树炫技，惊动祖师，被逐，嘱不得提师名；乘觔斗云回花果山。
5. 悟空杀混世魔王，夺回水帘洞，告知群猴姓孙、名悟空。

## 选定场面

三更后门入室，悟空跪于祖师榻前受道。回目“悟彻菩提真妙理”的核心即此夜；两个具名角色、一张榻、
一道半开的后门，构图简单；夜景自带月、萤、雁等会动的环境物，不涉打斗。

- “月明清露冷，八极迥无尘。”
- “只见那门儿半开半掩。”
- “祖师闻得声音是悟空，即起披衣，盘坐喝道。”

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |

| 须菩提祖师 | 衣冠、须发、年岁底本均未写；第1回赞语（“大觉金仙”“西方妙相”）只写气象；讲道时“慢摇麈尾”；三更时先蜷身朝里睡，醒后披衣盘坐 | 第1回见祖师段；本回讲道段与三更段 |

## 器物与环境

- 地点：灵台方寸山斜月三星洞后进；后门半开半掩，祖师寝榻在内，悟空跪于榻下，洗耳用心。
- 时间天气：夜，子时前后（三更）；山中无打更传箭，悟空以调息估时；月明、露冷、深树幽禽宿。
- 会动的物件（动效候选）：1. 飞萤光点明灭漂移（“飞萤光散影”）；2. 雁阵排成字形缓缓飞过、
  薄云随之移动（“过雁字排云”）；3. 深树枝叶轻摇（风未写，属画面添加，不违原文）。
- 戒尺、拐杖、麈尾为祖师他处所持，三更榻前未写。

## 排除项

- 同回其他场面：白昼讲坛打三下、变松树、觔斗云、斗混世魔王，皆为另一瞬，不与三更榻前同框。
- 阶段错位：如意金箍棒（第3回）、紫金冠与黄金甲与步云履（第3–4回）、金箍与虎皮裙（第14回）。
- 祖师形象底本未定：既不强加白须长者，也不强加袈裟或道冠；影视改编造型不取。
- 悟空走的是后门；中门已被祖师关上，前门是他自己偷开出外。
