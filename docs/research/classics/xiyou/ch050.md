# 《西游记》第50回 情乱性从因爱欲　神昏心动遇魔头

底本：<https://zh.wikisource.org/wiki/西遊記/第050回>；读取日期：2026-10-19。

## 情节要点

1. 师徒离通天河西行，正遇严冬，山高路窄，遥见山凹有楼台房舍；唐僧又饥又寒，想去化斋。
   悟空看出那边凶云恶气，说是妖精点化的，不可入。
2. 悟空去别处化斋，临行用金箍棒在平地画圈，请唐僧坐中间，八戒、沙僧侍立左右，叮嘱出圈必遭毒手。
3. 悟空到南边村庄，被老者拄杖打头，隐身入厨取了一钵盂饭。
4. 八戒怨坐牢，撺掇唐僧出圈；进楼台后八戒取三件纳锦背心，与沙僧穿上，被绑得动弹不得，三人和马、行李被妖魔擒走。
5. 悟空回来不见人，山神土地现身说是金兜山独角兕大王；悟空与他战四五十合，把金箍棒变千百条，被妖魔抛出的白圈套走。

## 选定场面

山间一处平地，积雪严寒，悟空站在圈边，金箍棒点地划出一道圈子，唐僧已坐在圈中，八戒牵马、沙僧放下行李，各侍立两侧；
远处山凹里一座高耸的楼台，上空压着凶云。四位具名角色都在，画圈是后文“出圈”的起点，没有打斗与血腥。三处依据：

- 「即取金箍棒，幌了一幌，将那平地下周围画了一道圈子，请唐僧坐在中间」
- 「着八戒、沙僧侍立左右，把马与行李都放在近身」
- 「远望见山凹中有楼台高耸，房舍清幽」

## 器物与环境

- 地点：渡河后西行遇大山，路窄崖高、石多岭峻，怪石乱堆如坐虎，苍松斜挂如飞龙，崖前梅花开放，涧水潺湲。
  圈画在山路旁一处平处；山名金兜山此时尚未点明。
- 时间天气：严冬，飘雪凛风；时辰约在午前（悟空说化了斋还要赶回作午斋，属推断）。第48回在七八月之交，本回只写“正遇严冬之景”。
- 幻象：山凹楼台是妖怪点化，悟空以火眼金睛看出凶云隐隐、恶气纷纷；他拿蜃气放光似楼阁作比。
- 器物：金箍棒、地上的圈线、钵盂、行李担、白马。
- 现实中会动的：① 飘落的雪花与风扬起的雪粉；② 山凹楼台上空翻涌的凶云恶气；③ 风吹动的僧衣、马鬃与松梢。

## 排除项

- 圈只是地上画的一道线，原文没有光幕、符文、结界字样；此刻没有妖怪出现。
- 八戒撺掇出圈、入楼台、取背心被绑、被擒，都在悟空走后；此刻四人安坐或侍立在圈内。
- 兕大王与白圈套棒在后；白圈在第52回才点名为太上老君的金刚琢，本回只称“圈子”。
- 远处楼台是幻象，不画成真实的庄院，也不画妖洞；南庄老者、狗、山神土地都在其后。
- 唐僧不披袈裟、不戴毗卢帽；袈裟与毗卢帽是第12回的赐物，本回未提。
- 画圈用的是金箍棒点地，不是把棒变大；八戒、沙僧此刻未穿背心。
