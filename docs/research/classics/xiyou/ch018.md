# 《西游记》第18回 观音院唐僧脱难　高老庄大圣除魔

底本：<https://zh.wikisource.org/wiki/西遊記/第018回>；读取日期：2026-10-19。

## 情节要点

1. 悟空烧了黑风洞，取回袈裟；师徒辞别观音院西行，春融时节抵乌斯藏国界的高老庄。
2. 家人高才道出：高家三女翠兰被一妖精入赘三年，近半年被关在后宅不得见人。
3. 悟空应下降妖，捣开后宅铜汁灌锁的门，让太公带女儿去前宅，自己变作女儿等妖精。
4. 夜里狂风过后妖精进房，悟空装病躺在床上，几番戏弄后妖精自报福陵山云栈洞猪刚鬣。
5. 妖精闻齐天大圣之名要走，被悟空扯住现原身，挣破衣服化风逃走，悟空追去（下回）。

## 选定场面

沿用已有题面的场面：高老庄后宅夜里，悟空变作高家女儿躺在床上装病，猪刚鬣乘狂风走进房
来、伸手搂抱。反差强，两个角色即可成画。三处依据：

- 「黑脸短毛，长喙大耳；穿一领青不青、蓝不蓝的梭布直裰，系一条花布手巾」
- 「且睡在床上推病，口里哼哼啧啧的不绝」
- 「走进房，一把搂住，就要亲嘴」

## 器物与环境

- 地点：高家后宅的房间（门已被悟空捣开）；房内有床和净桶；灯火、窗、帐幔原文均未写。
- 时间天气：入夜（妖精昏来朝去）；一阵狂风，走石飞砂，风势诗写树倒林摧、房瓦如燕块飞起。
- 现实中会动的：① 飞沙走石与被吹折的树枝；② 被风掀起的屋瓦；③ 妖精衣摆与手巾被风带起。

## 排除项

- “八戒”之名是第19回唐僧所起；本回妖精自称猪刚鬣，题面不称猪八戒。
- 九齿钉钯本回只在妖精自述中出现，第19回云栈洞才实见；进房时不扛钯。
- 妖精是从半空乘风而来，原文没有推门；开门只见于他后来要走时。
- 高太公、高才及亲友在前宅；沙僧、乌巢禅师均不在场。
- 悟空此刻是女子外形，咨牙徕嘴、火眼金睛的真身要到被扯住之后才露。

## 现有题面核对

对象：xiyou-018 静态题面与 xiyou-anim-018 动态题面。回目、回数、“夜里”“昏暗”“狂风走石”
“黑脸短毛长嘴大耳”“九齿钉钯”这个兵器名均有依据。有误、无据或含后世说法之处如下：

- 床边坐着低头的女子（静态、动态皆有）：有误。妖精进房时悟空躺在床上装病，之后才被摔下
  床，更后才坐到净桶上；先前独自坐在房里等候是妖精到来之前。动态第3条写“床上女子”，
  与自己的“床边坐着”前后矛盾。
- 推门而入（静、动）：无据。妖精自半空乘风而来，原文只写走进房；开门是后来要走时。
- 扛着九齿钉钯（静、动）：有误。进房时无兵器，钯到第19回才在云栈洞取出。动态“钉钯
  寒光闪烁”随之无据。
- 猪八戒（动态第2条）：时序错位，本回应称猪妖或猪刚鬣；八戒是第19回唐僧所赐之名。
- 青蓝色粗布长衫：基本相符。原文是青不青、蓝不蓝，即颜色不正；直裰即长衫，梭布即粗布。
- 头上系着花布手巾（静态）：无据。原文只写系一条花布手巾，未说系在头上。
- 眼神透着猴子般的狡黠、眼眸狡黠眨动：无据。原文只写悟空暗笑，妖精未识破；若保留，
  应当明示这是创作提示而非原著。
- 窗外阴风（动态）：无据。原文无窗，风也未称阴风，只写狂风走石飞砂。
