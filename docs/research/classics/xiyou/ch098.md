# 《西游记》第98回 猿熟马驯方脱壳　功成行满见真如

底本：<https://zh.wikisource.org/wiki/西遊記/第098回>；读取日期：2026-10-19。

## 情节要点

1. 寇员外还阳，再备幢幡鼓乐送行；四众走了六七日，到灵山脚下玉真观，金顶大仙接待沐浴；
   次早唐僧披锦襕袈裟、戴毗卢帽、持锡杖，大仙送出后门，指点灵山。
2. 前行遇凌云渡：水宽八九里，只有一根又细又滑的独木桥，悟空跑过去，唐僧、八戒不敢走。
3. 下游撑来一只无底船，悟空认出撑船人是接引佛祖（南无宝幢光王佛）而不点破；悟空把唐僧
   往船上一推，唐僧跌进水里，被一把扯起；船撑开后上游漂下一具死尸，众人都说“是你”，
   渡过岸后船已不见。
4. 雷音寺：如来命阿傩、伽叶引四众赴珍楼赐宴、开阁检经；二尊者索人事不得，传了无字白本，
   燃灯古佛又遣白雄尊者刮风抢散经包。
5. 四众回告如来，奉上紫金钵盂，换得有字真经五千零四十八卷；观音奏请八日内送回，
   八大金刚驾云送唐僧东返。

## 选定场面

凌云渡岸边，无底船撑到近处，悟空把唐僧往船上一推，唐僧踏不住脚朝水面扑去，撑船人
伸手一把扯起。取这一刻而不取上游漂尸，是因为漂尸在船撑开之后，且要避免尸身细节。
具名角色建议接引佛祖（以撑船人面目出现）、唐僧、悟空、八戒四位；八戒站在岸上看，沙僧、
白龙马与行李在他身后，作小影或省去。三处依据：

- 「原来是一只无底的船儿」
- 「行者扠着膊子，往上一推」
- 「那师父踏不住脚，毂辘的跌在水里，早被撑船人一把扯起」

## 器物与环境

- 地点：灵山脚下的凌云渡。河是“一道活水”，滚浪飞流，约八九里宽，四无人迹；一根又细又滑
  的独木桥横在河上，桥边木匾写“凌云渡”三字；无底船从下游撑来。
- 无底船：原著只写“无底的船儿”，撑船人的偈诗称有风浪也自稳。后文“都立在□□之上”的生僻字，各本
  写法不一，语境指船体边缘一类（推断）。形制未写，兜底：窄长木船，船帮完整，船腹不画
  舱板、直见河水以示无底，不画成漏水下沉。
- 时间天气：次早自玉真观出发，步行五六里到水边，上午；天气未写，远处灵鹫高峰罩着五色祥光、
  千重瑞霭（金顶大仙所指）。季节承第96回，春尽夏初。
- 现实中会动的：① 滚浪飞流的河水与船边水纹；② 撑船人长篙入水处溅起的水花；
  ③ 远处灵山祥光云气的缓缓流动。

## 排除项

- 上游漂下的死尸（脱下的旧躯壳）在船撑开之后，本场面不画；悟空独自跑过独木桥、八戒趴地
  叫“滑”都在此刻之前，桥上无人。
- 金顶大仙与玉真观沐浴、雷音寺山门与四大金刚、无字经与阿傩伽叶，都在前后文，不入画。
- 《封神演义》里接引道人的“身高丈六、金身、面皮黄色”是另一部作品的设定，不用于撑船人。
- 86版初篇第25集含此渡，分集梗概只写“脱胎换骨”，未写船形与撑船人造型，影视造型不沿用。
- “唐僧在此已死、金蝉子取代”之类后世解读不入画；渡船是船，不画成木筏或大桥。
