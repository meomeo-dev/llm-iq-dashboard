# 《西游记》第30回 邪魔侵正法　意马忆心猿

底本：<https://zh.wikisource.org/wiki/西遊記/第030回>；读取日期：2026-10-19。

## 情节要点

1. 黄袍怪捆住沙僧、揪倒公主拷问；沙僧为报公主放唐僧之恩，一口咬定没有书信，怪转怒为温存。
2. 怪变成俊俏人形，到宝象国自称三驸马，诬唐僧是十三年前驮走公主的虎精，向唐僧喷水，唐僧变成斑斓猛虎。
3. 武将校尉乱砍不伤，天晚才把虎锁入铁笼；怪在银安殿饮酒，二更醉后现形，惊散宫娥。
4. 白龙马化龙再变宫娥，用逼水法斟酒、舞刀行刺，被满堂红打伤后腿，逃入御水河。
5. 八戒睡醒回馆驿，听白龙马说明后飞往花果山，谎称师父想念；悟空不去，八戒归途骂人，被群猴捉回。

## 选定场面

宝象国殿上，俊俏人形的黄袍怪含水喷向绣墩上的唐僧，唐僧当场化作斑斓猛虎，国王惊得魄散魂飞。
俊俏公子与猛虎、国王的惊惧形成强对比，喷水化虎是一个瞬间，不涉及血腥。三处依据：

- 「将一口水望唐僧喷去，叫声：变！」
- 「头上戴一顶鹊尾冠，乌云敛伏；身上穿一件玉罗褶，广袖飘迎」
- 「白额圆头，花身电目」

## 器物与环境

- 地点：宝象国朝堂，有白玉阶、金阶、龙床、御案与绣墩；唐僧坐的是绣墩。白昼，众臣闹到天晚才擒虎。
- 器物：半盏净水（国王命官取来递给驸马）；法术原文名“黑眼定身法”，念咒后以口喷水，喝一声“变”。
- 现实中会动的：① 喷出的水雾与水珠；② 人形黄袍怪的广袖与鸾带随喷水动作飘摆；③ 虎尾与刚须。

## 排除项

- 黄袍怪本相（青靛脸、白獠牙、黄金铠甲、追魂取命刀）不在此场面；原文无“书生”一词，称俊俏之人、俊俏文人。
- 唐僧被锁铁笼是天晚之后；白龙马变宫娥、逼水法、受伤，是当夜二更银安殿的事，不在朝堂。
- 白龙马原文称小龙、小龙王，后腿被满堂红（熟铁烛台）所伤，留青痕，并非被刀砍。
- 悟空不在场；八戒睡在草丛，沙僧被囚在洞中；奎木狼之名要到第31回才揭晓。
