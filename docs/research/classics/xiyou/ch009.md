# 《西游记》第9回 陈光蕊赴任逢灾 江流僧复仇报本

底本：维基文库《西遊記》第009回 https://zh.wikisource.org/wiki/西遊記/第009回
读取日期：2026-10-19。引文由繁体转写为简体。

版本与附录：底本页首注明“清康熙年间汪象旭、黄周星加入附录于此回”，本回内容即该附录，
讲唐僧出身。维基文库另有独立页 `西遊記/附錄`（https://zh.wikisource.org/wiki/西遊記/附錄），
导航置于第八回之后，正文与第009回逐字相同，页首注“加入此回于第九回”；目录中第八、九回
之间无其他附录条目。世德堂本系统无此完整故事，其第九回为“袁守诚妙算无私曲 老龙王拙计
犯天条”，只在底本第十二回前段以诗句交代出身，收养者名“迁安和尚”；本回写作“法明”。

## 情节要点

1. 贞观十三年开科，海州陈萼（字光蕊）中状元，被丞相殷开山之女温娇（满堂娇）绣球选中，授江州州主；
   赴任途中在万花店买下金色鲤鱼放生。
2. 洪江渡口，船夫刘洪、李彪害死光蕊、抛尸江中，刘洪霸占殷氏；龙王（即所放鲤鱼）收其魂魄。
3. 殷氏在江州生子，她咬指写血书，用木板载婴儿推入江中；金山寺法明长老救起，取乳名江流。
4. 江流十八岁受戒名玄奘，得知身世，以化缘为由到江州与母相认，再往洪州寻祖母，舔开其昏瞎双眼。
5. 殷丞相奏请唐王发兵，擒杀刘洪、李彪；龙王送光蕊还魂，一家团圆；殷氏自尽，玄奘回金山寺报恩。

## 选定场面

取“木板漂至金山寺脚下，法明长老救起江流儿”：长老打坐间闻婴儿啼哭，急到江边救起。
入画理由：木板、束带、血书、江水、寺脚皆有原文；具名角色两个（老僧、婴儿）；无血腥；一个瞬间。
备选：殷氏次早在江边把婴儿安在板上推入江中（前情含咬指血书，易引向血腥，未选）。

> 将此子安在板上，用带缚住，血书系在胸前，推放江中。
> 只见涯边一片木板上，睡着一个婴儿。
> 长老慌忙救起，见了怀中血书，方知来历。

## 人物造型

| 人物 | 本回阶段样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 法明长老 | 金山寺长老，已得无生妙诀；原文无相貌衣冠描写，只知是僧；救婴时正打坐参禅，一时心动，急到江边 | 救婴段 |
| 江流（婴儿） | 新生儿；贴身汗衫包裹，用带缚在木板上，血书系胸前；左脚小指已被咬下（不入画） | 放板段 |
| 殷氏（备选场面用） | 面如满月，眼似秋波，樱桃小口，绿柳蛮腰（刘洪初见时的描写）；衣着原文未写 | 劫船段 |

## 器物与环境

- 木板：一片，从江岸飘起，顺水流到金山寺脚下停住；婴儿以汗衫包裹，带缚，血书一纸。
- 金山寺：原文只写“金山寺脚下”，不描写殿宇，也未写在镇江；时辰、天气未写；水称“江”。
- 现实中会动的：(1) 江水波纹，木板随浪轻晃；(2) 缚婴的带与血书纸角被水风吹动；
  (3) 长老俯身时衣袖下垂摆动。后两项为画面处理。

## 排除项

- 血腥与暴力：光蕊被打死抛尸、咬指写血书、咬下脚趾、刘洪伏诛，均不入画。
- 玄奘成年后的形象与锦襕袈裟、九环锡杖（第12回起）；本场只有婴儿。
- 载具是“一片木板”，不是木盆、竹篮；收养者此回名“法明”，世德堂本诗作“迁安”。
- 镇江金山寺原为江心岛、清代才与南岸相连，属后话；水漫金山、法海属《白蛇传》，与本回无关。
- 史实中玄奘俗名祎、河南偃师人，与小说身世无涉，不入题面。
