# 《西游记》第63回 二僧荡怪闹龙宫　群圣除邪获宝贝

底本：<https://zh.wikisource.org/wiki/西遊記/第063回>；读取日期：2026-10-19。

## 情节要点

1. 悟空与八戒押二妖到乱石山碧波潭，割了二妖耳与唇放回，向万圣龙王索还塔宝。
2. 九头驸马披挂持月牙铲出潭，与悟空斗三十余合；八戒从背后筑一钯，被他架住。
3. 驸马腾空现出九头虫本相，悟空追打；他腰间又伸出一头，咬住八戒鬃毛拖入潭中。
4. 悟空变螃蟹入龙宫救八戒、偷回钉钯，八戒打入宫中；悟空一棒打死老龙王。
5. 二郎神携梅山六兄弟路过助战，细犬咬下九头虫一头，虫负伤逃往北海；悟空变驸马诈得宝物，
   八戒擒龙婆；舍利子安回塔顶，金光寺改名伏龙寺。

## 选定场面

乱石山头，九头驸马现出九头虫本相，悟空腾云举棒照头打，他掠到山前，腰间伸出第十个头，
一口咬住八戒的鬃毛。具名角色三位：九头虫、悟空、八戒。本相写得具体，十头是回中最有辨识
度的形象，打斗只取出手与咬住的一瞬，不取被拖入水之后。三处依据：

- 「毛羽铺锦，团身结絮」
- 「两只脚尖利如钩，九个头攒环一处」
- 「半腰里又伸出一个头来，张开口如血盆相似，把八戒一口咬着鬃」

## 人物造型

## 器物与环境

- 地点：乱石山山头与山前，山下是碧波潭，在祭赛国东南百十里（第62回供词）。山形、潭形
  未写，兜底：嶙峋乱石山，山脚一潭深水。时辰、天气原文未写（后文才写“天色晚了”）。
- 兵器：悟空铁棒，八戒九齿钉钯。九头虫此刻不持兵器；月牙铲前端为弯月形铲、尾端为斧状
  铲柄，人形斗法时才用。
- 体量：本相“方圆有丈二规模”，按明代营造尺（约32厘米）约3.8米，大于人而远小于怪兽。
- 现实中会动的：① 碧波潭水面波纹与浪花；② 山头云气；
  ③ 九头虫羽毛、八戒鬃毛与衣带被风带起。

## 排除项

- 二郎神、梅山六兄弟、细犬咬头、九头虫逃往北海，都在后文，此刻不出现；沙僧留在祭赛国
  陪国王，不在场。
- 月牙铲是九头驸马的兵器，不是沙僧的；央视版把沙僧兵器改成月牙铲、把九头虫拍成九头蛇，
  均不采。原著是羽禽形，不画成蛇身或蛇颈。
- 万圣龙王、公主、龙婆、龙子龙孙与龙宫都在水下，不画；八戒被拖入潭中是下一刻，不画。
- “长短似鼋鼍”只比体量，原文未写龟壳或鳄鳞，不画龟壳、鳄鳞。
