# 《西游记》第89回 黄狮精虚设钉钯宴　金木土计闹豹头山

底本：<https://zh.wikisource.org/wiki/西遊記/第089回>；读取日期：2026-10-19。

## 情节要点

1. 天明铁匠发现三般兵器失踪，悟空问得城北有豹头山虎口洞，跨云到山上，变蝴蝶偷听
   两个狼头小妖闲话，得知「明朝开宴庆钉钯会」，以定身法制住二妖，取走银两与粉漆牌。
2. 悟空定计：八戒变刁钻古怪，自己变古怪刁钻，沙僧扮贩猪羊的客人；赶猪羊进山，路上
   遇青脸小妖送请帖，帖上「门下孙黄狮」请祖翁九灵元圣赴会。
3. 虎口洞二层厂厅，正中桌上供着放光的九齿钉钯，金箍棒、降妖杖靠在两侧山头；八戒
   见钯就取，三人现出原身，各取兵器，黄狮精转后边取四明铲迎战，战至日落败走东南。
4. 三人打尽洞中群妖（原是虎狼彪豹、马鹿山羊）并放火烧洞；黄狮精奔竹节山求祖翁
   九灵元圣，次日带众狮攻玉华州城。

## 选定场面

虎口洞二层厂厅内，三人现出原身的一刻：八戒从供桌上拿起放光的钉钯抡起，望妖王劈脸
筑去；悟空、沙僧已各自握住靠在两侧墙边的金箍棒与降妖杖；黄狮精惊得抽身闪避，手里
还没有兵器。只画出手一瞬，不画打中与伤亡。具名角色悟空、八戒、沙僧、黄狮精。
三处依据：

- 「正中间桌上，高高的供养着一柄九齿钉钯，真个是光彩映目」
- 「物见主，必定取」
- 「跑上去，拿下来，抡在手中，现了本相，丢了解数，望妖精劈脸就筑」

## 器物与环境

- 地点：豹头山虎口洞。洞门外「周围山绕翠」「峭壁扳青蔓，高崖挂紫荆」；入内到二层
  「厂厅」（厂即敞，敞厅），后边通天井。本场面只取厅内。
- 陈设：桌在厅正中，上供一柄九齿钉钯，光彩映目；金箍棒靠东山头、降妖杖靠西山头。
  「山头」指厅两侧山墙，方位不对应画面左右，题面写「两侧墙边」。
- 距离：上回写妖精「离城只有七十里远近」，本回写「那城相去只有三十里」，二者不一，画面不涉及。
- 时间：悟空午间遇送帖小妖，一路战到「日头西」，故场面在午后；洞内光线未写。小妖
  盘算「买件绵衣过寒」，时令近冬，洞内不体现。
- 现实中会动的：① 钉钯放出的光彩，光晕明暗脉动；② 八戒抡钯带起的直裰下摆、悟空虎皮裙
  边与黄狮精颈后鬃毛；③ 天井口透入光柱里浮动的尘埃（原著未写，兜底画法）。

## 排除项

- 悟空变蝴蝶、定身法、青脸小妖与请帖、刁钻古怪与古怪刁钻两个狼头小妖、赶猪羊进山，
  都在前面；此刻三人已现原身，不画狼头、粉漆牌、猪羊，也不画请帖上的字。
- 洞外花树下的杂项小妖、事后打尽群妖与放火烧洞在后，不入厅内，不画血。
- 四明铲此刻尚未取出，不画黄狮精持铲；铲只写「杆长鐏利」，形制原著未写。
- 九灵元圣与猱狮、雪狮、狻猊、白泽、伏狸、抟象在第90回出场，青脸小妖亦不出现。
- 86版第23集写沙僧扮「赶鸭子的」，原著是贩猪羊的客人；沙僧用降妖宝杖，不用影视的月牙铲。
