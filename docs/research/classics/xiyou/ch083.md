# 《西游记》第83回 心猿识得丹头　姹女还归本性

底本：<https://zh.wikisource.org/wiki/西遊記/第083回>；读取日期：2026-10-19。

## 情节要点

1. 唐僧被女妖送出洞，悟空从女妖口中跳出，两人交手；八戒、沙僧助战，女妖又脱鞋变替身，
   趁隙回到洞门前，连唐僧、行李、白马一并摄回。
2. 悟空再入洞，空无一人，只在后屋供桌上见金字牌位“尊父李天王之位”“尊兄哪吒三太子位”，
   拿出洞外，决定上天告御状。
3. 玉帝准状，命太白金星宣李天王；悟空随金星到云楼宫，李天王不认，命人用缚妖索绑了
   悟空，又取砍妖刀要斩，哪吒赶来用斩妖剑架住。
4. 哪吒说明：老鼠精三百年前偷吃灵山香花宝烛被擒，认天王为父、认他为兄，是结拜的义女；
   天王惊醒，亲手解绑，奉旨点兵同下陷空山。
5. 天兵与悟空入洞，在东南黑角落的小洞里找到唐僧，擒了老鼠精，师徒重新上路。

## 选定场面

天宫云楼宫庭下，悟空被缚妖索捆住，仍笑吟吟地站着；李天王举着砍妖刀劈头砍来，哪吒
赶上前用斩妖剑把父亲的刀架住，太白金星在旁惊慌劝阻，几名天将持索立在庭下。具名角色
四位：悟空、李天王、哪吒、太白金星；另有天将群像。刀被架住的一刻定格，没有落下，也
没有受伤。三处依据：

- 「将缚妖索把这猴头捆了」
- 「早有那三太子赶上前，将斩妖剑架住」
- 「行者全然不惧，笑吟吟的道」

## 器物与环境

- 地点：云楼宫，原文“天王住宅”，宫门首有童子侍立，庭下设香案（天王接旨时所设）。宫殿
  建筑原著未写，兜底：云上楼阁、宫门、台阶与庭院，一座香案。
- 时间天气：原著未写，不强加时辰与天气，兜底：天上明亮日光下的云海。
- 缚妖索：哪吒六般兵器之一，第4回诗“缚妖索子如飞蟒”；形制未写，兜底：粗绳一圈圈缚在
  悟空身上，绳头由天将握着。砍妖刀、斩妖剑形制未写，兜底：宽刃大刀与直剑各一。
- 黄金宝塔：“玲珑剔透舍利子如意黄金宝塔”，塔上层层有佛，艳艳光明；此刻供在塔座上，
  可作背景小景，不在天王手中。
- 现实中会动的：① 香案上香炉里升起的青烟；② 台基下流动的云气；③ 天王盔缨、战袍下摆
  与金星衣带被风带起。

## 排除项

- 牌位与香炉已留在玉帝御前，不在本场；玉帝、灵霄殿、南天门、通明殿四天师不入画。
- 哪吒说明身世、天王回手托塔、解绑、点兵下界，及洞内擒妖，都在架剑之后，不入画；
  不画天王手托宝塔。
- 哪吒三朝下海、剔骨还父、碧藕为骨荷叶为衣，是本回追述，不入画，也不给哪吒画荷叶衣。
- 风火轮、乾坤圈、混天绫、火尖枪、荷叶战衣出自《封神演义》与后世影视；原著第4回的
  六般兵器是斩妖剑、砍妖刀、缚妖索、降妖杵、绣球儿、火轮儿，本场只画斩妖剑一件，哪吒
  也不变三头六臂。
- 老鼠精（地涌夫人）、唐僧、八戒、沙僧不在场；悟空不持棒、不戴凤翅紫金冠、不披黄金甲。
- 不画血迹与受伤；刀剑相交处至多有一点火花。
