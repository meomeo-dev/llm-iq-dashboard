# 《西游记》第71回 行者假名降怪犼　观音现像伏妖王

底本：<https://zh.wikisource.org/wiki/西遊記/第071回>；读取日期：2026-10-19。

## 情节要点

1. 悟空变苍蝇潜入后宫，与金圣娘娘相认；变作侍婢春娇，借虱子、跳蚤、臭虫逼妖王脱衣，
   以毫毛变的假铃换走真金铃。
2. 天明悟空在洞外叫战，自称朱紫国请来的“外公”；赛太岁手持宣花钺斧出战，五十回合
   不分胜负，借口用早膳回洞取铃。
3. 妖王摇的是假铃，不出烟火；悟空取出真铃三个齐摇，念咒唤风，烟火黄沙遍地，妖王
   走投无路。
4. 观音在半空洒甘露灭火，说明妖王是她的坐骑金毛犼，因朱紫国王少时射伤孔雀雏而
   “拆凤三年”；喝令现形，骑犼回南海。
5. 悟空打进洞中除尽群妖，接金圣娘娘回朝；紫阳真人解去娘娘身上棕衣毒刺，国王设宴
   谢别。

## 选定场面

麒麟山獬豸洞外，取观音现身、甘露初洒的一刻：烟火黄沙仍在翻滚，悟空刚把铃藏进腰间，
合掌倒身下拜；赛太岁困在火中，魂飞魄散。具名角色三位：观音、悟空、赛太岁。半空菩萨与
地面三色烟火上下呼应，没有打斗血腥。三处依据：

- 「左手托着净瓶，右手拿着杨柳，洒下甘露救火哩」
- 「红火、青烟、黄沙，一齐滚出」
- 「那菩萨将柳枝连拂几点甘露，霎时间，烟火俱无，黄沙绝迹」

## 器物与环境

- 地点：麒麟山獬豸洞门外，妖王“出了门，就占起上风”后在洞前被烟火围住；山上树木被烧。
- 时间天气：天明叫战，战至赛太岁说“还未早膳”，已是上午；本回未写季节。
- 紫金铃：三个，老君八卦炉炼成，用豹皮幅子包裹，中间一个茶钟大，两头两个拳头大；
  一个出火、一个出烟、一个出沙。悟空三铃齐摇，再念咒向巽地叫“风来”，风助火势。
- 净瓶、杨柳：观音以柳枝蘸甘露连拂数点，烟火黄沙随即消散。
- 兵器：妖王宣花钺斧（第70回座上赞所说“铁杵”不用）；悟空此刻无棒。
- 现实中会动的：① 翻滚上升的红火、青烟与黄沙；② 柳枝洒落的甘露水点；③ 观音衣带璎珞
  与山上被烟火吹动的树木。

## 排除项

- 观音骑犼、妖王打滚现原身，在“还不还原”之后，不入画；犼的原身原著只写“四足莲花
  生焰焰，满身金缕迸森森”，古籍与民间说法不一，不照搬。
- 妖王此时是人形，不画犼，也不画观音带着任何坐骑；孔雀大明王、落凤坡是观音口述往事。
- 悟空不持金箍棒；妖王手里的是悟空换给他的假铃，摇不出火，火是悟空手中真铃所出。
- 金圣娘娘、春娇、紫阳真人（棕衣）属前后段，不出现；赛太岁不是第28回起的黄袍怪。
- 观音此回不带鱼篮、千手等他回造型；第49回的紫竹篮不要带入。
- 86版有此段，但赛太岁与金毛犼的服饰造型资料未检到，不沿用任何影视造型。
