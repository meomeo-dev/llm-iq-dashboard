# 《西游记》第42回 大圣殷勤拜南海　观音慈善缚红孩

底本：<https://zh.wikisource.org/wiki/西遊記/第042回>；读取日期：2026-10-19。

## 情节要点

1. 悟空半路变作牛魔王，被六健将迎入火云洞；红孩儿起疑，问生辰八字，悟空答不上，
   现形脱身。
2. 悟空到南海落伽山请观音；观音掷净瓶入海，龟驮瓶上岸，瓶中借了一海水，悟空拿不动；
   悟空不愿留毫毛作当，观音仍亲自同行，借天罡刀三十六把，化作千叶莲台。
3. 观音倾净瓶，水漫号山一带，化成落伽仙境；在悟空手心写“迷”字，教他诱红孩儿追来。
4. 红孩儿坐上莲台，莲台退回刀尖，天罡刀穿腿；观音令刀变倒须钩，红孩儿求饶，
   被剃头、称善财童子。
5. 红孩儿反悔挺枪刺观音，观音取金箍抛出，变作五个套在他头手脚上，念咒使他痛得打滚。

## 选定场面

水漫的落伽仙境里，红孩儿受戒后反悔，挺枪刺向观音；悟空抡棒要打，被观音拦住，观音从
袖中取出金箍迎风一晃，变作五个，抛向红孩儿的头顶与四肢。画面取金箍刚出手、五环飞向目标
的一瞬；红孩儿头挽三个揪儿，枪尖指向观音。具名角色四位（观音、红孩儿、悟空、白鹦哥），
构图成三角：观音居上居中，红孩儿在前，悟空护在观音一侧。三处依据：

- 「望菩萨劈脸刺来」
- 「即变作五个箍儿，望童子身上抛了去」
- 「一个套在他头顶上，两个套在他左右手上，两个套在他左右脚上」

## 器物与环境

- 金箍：如来所赐金、紧、禁三箍之一（紧箍给了悟空，禁箍收守山大神，金箍此时才用）；
  一变五。粗细与花纹原著未写，兜底：素面金环，内径大于头颈手足。
- 场景：净瓶倾水，漫过山头、冲开石壁，化作“真如南海一般般”的景界：波涛起伏，
  秀蒲、昙花、香草、贝叶、紫竹、青松，万叠波涛里莲花开遍。
- 站位：红孩儿落地处原文只写刀“脱落尘埃”；观音与悟空是从空中“低下金光”到他面前。
  兜底：红孩儿立在水边浅滩，观音、悟空在稍高处的金光祥云上。
- 时令：本日白昼；季节承第40回秋尽冬初，但画面是仙境水景，季节不入画。
- 现实中会动的：① 水面波涛与浪花；② 观音的绣带、衣袂与垂杨柳枝被风带起；③ 飞出的五个金箍沿弧线飞向红孩儿。

## 排除项

- 红孩儿盘坐莲台、莲台退成刀尖、刀穿两腿、木叉用降魔杵捣刀柄，均在受戒之前。本图莲台
  与天罡刀已不在（刀已脱落，由木叉送回天宫）；不画血，不画木叉。
- 善财龙女、诸天、潮音洞、普陀山属出海前，未随行；悟空变牛魔王属本回开头。
- 观音念的是金箍儿咒，不是紧箍儿咒，悟空不受咒；此刻咒未念，红孩儿尚未打滚。
  红孩儿双手合掌（观音扭）在第43回开篇，不入图。
- 箍的位置：本回写头顶一、左右手各一、左右脚各一；第43回开篇却写“颈项里与手足上”。
  两回有出入，本图按本回，且只画飞行中的箍，不画已套上的样子。
- 善财童子合掌立像、项圈手镯、莲座旁侍立，是后世佛像画的样式；红孩儿此刻不是。
  红肚兜、风火轮属影视、动画造型，原著无。
- 观音此刻不坐莲台、不骑龙；不要与第49回提紫竹篮的鱼篮观音混淆。
