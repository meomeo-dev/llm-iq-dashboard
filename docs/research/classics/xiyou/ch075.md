# 《西游记》第75回 心猿钻透阴阳体　魔主还归大道真

底本：<https://zh.wikisource.org/wiki/西遊記/第075回>；读取日期：2026-10-19。

## 情节要点

1. 悟空变小钻风进狮驼洞，见青毛狮子怪、黄牙老象、大鹏坐在上首；他编话吓老魔，变金
   苍蝇戏耍时露了馅，被三魔认出，四马攒蹄绑住。
2. 三十六个小妖抬出二尺四寸高的阴阳二气瓶，把悟空吸入；悟空用观音所赐三根救命毫毛
   变钻具，在瓶底钻出孔，变蟭蟧虫逃出。
3. 悟空回报唐僧，带八戒到洞前叫战；老魔披挂持刀出洞，要悟空做桩子，先让他砍三刀，
   头皮毫发无伤。
4. 悟空还手，二人空中斗二十余合；八戒赶妖，老魔现狮形将悟空吞下，八戒逃回报信，
   唐僧痛哭，八戒要分行李。
5. 悟空在老魔腹中胡闹，老魔疼得倒地（此节不入画）。

## 选定场面

狮驼洞门外，老魔丁字步站定，双手举钢刀照悟空光头劈下；悟空仰头迎刀，头皮红也不红；
八戒闪在一旁观看。取第一刀将落未落的出手一刻，没有伤口血腥。具名角色三位：青毛狮子怪
（老魔）、悟空、八戒。三处依据：

- 「丁字步站定，双手举刀，望大圣劈顶就砍」
- 「这大圣把头往上一迎，只闻扢扠一声响，头皮儿红也不红」
- 「身披金甲无丝缝，腰束龙绦有见机。手执钢刀明晃晃」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 青毛狮子怪（老魔） | 披挂：铁额铜头戴宝盔，盔缨飘舞，双睛如电，勾爪如银，锯牙如凿，身披无缝金甲，腰束龙绦，手执钢刀。座上本相赞：凿牙锯齿、圆头方面、仰鼻朝天、赤眉飘焰，是“青毛狮子”。披挂时是否保留狮首原文未写，兜底：狮面人身，面覆青毛，不画现出狮形 | 披挂诗；座上赞 |

| 猪八戒 | 黑脸，长嘴大耳，颈项生鬃毛，皂直裰，九齿钉钯；闪在一边观战 | 洞前段；第74回 |

## 器物与环境

- 钢刀：形制未写，赞以“似苍蝇尾、白蟒腰”形容，称其为“大捍刀”；兜底：阔身长刀。
- 地点：狮驼洞门外。洞门原先紧闭、门外无人（小妖已被悟空吓散），老魔开门走出，声明
  只一对一、不许帮手，所以画面里没有妖兵。
- 时间天气：与第74回同在初秋，“夏尽秋初”；悟空早间混入洞中，之后回报再返洞前，时辰
  原文未写，兜底：白天。
- 现实中会动的：① 老魔盔缨与龙绦的飘动；② 刀风带起的尘土；③ 洞前草木与山风。

## 排除项

- 阴阳二气瓶内的火、蛇、火龙，用毫毛钻孔脱身，以及老魔腹中各节，涉及体内与吞咽，
  一概不画；老魔现狮形张口吞悟空也不画。
- 第二刀劈中后悟空就地一滚变出两个身子，在第一刀之后，不入画。
- 二魔白象、三魔大鹏不在洞前；三十六小妖抬瓶、洞内的骷髅与人肉景象（写在进洞口所见），
  都不画。
- 悟空此刻是本相，不是小钻风的头脸；唐僧、沙僧在山坡下，不入画。
- 青毛狮是文殊菩萨的坐骑，第77回才揭晓，此回不画文殊。
- 影视版青狮的演员记载互相矛盾，造型资料未检到，不沿用。
