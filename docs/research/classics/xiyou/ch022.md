# 《西游记》第22回 八戒大战流沙河　木叉奉法收悟净

底本：<https://zh.wikisource.org/wiki/西遊記/第022回>；读取日期：2026-10-19。

## 情节要点

1. 师徒过黄风岭，历夏经秋，抵八百里流沙河；岸上石碑篆字“流沙河”，腹刻四行小字。
2. 河中钻出一妖，红发蓝脸，项下悬九个骷髅，手持宝杖，卷旋风抢唐僧。
3. 悟空抱唐僧登高岸，八戒执钯迎战；其后水陆连战三场，妖怪不肯离水，悟空南海请观音。
4. 观音遣惠岸（木叉）携红葫芦，叫“悟净”，妖怪归顺，指沙为姓，受戒剃发，唐僧称他沙和尚。
5. 骷髅按九宫结成法船，中安葫芦，渡河后木叉收葫芦，骷髅化九股阴风。

## 选定场面

流沙河东岸，妖怪自浪中窜上岸抢唐僧，悟空抱住师父退上高岸，八戒掣钯便筑，妖怪以宝杖架住。
沙僧的样貌在本回写得最具体，兵器对峙是一个明确瞬间，不涉血腥。三处依据：

- 「那怪一个旋风，奔上岸来，径抢唐僧」
- 「慌得行者把师父抱住，急登高岸，回身走脱」
- 「项下骷髅悬九个，手持宝杖甚峥嵘」

## 器物与环境

- 地点：流沙河东岸；碑文“八百流沙界，三千弱水深，鹅毛飘不起，芦花定底沉”；浑波涌浪，
  水势狂澜。
- 时令：历夏经秋，“寒蝉鸣败柳，大火向西流”，初秋；白天交战，傍晚才收兵。
- 宝杖：妖怪自述“月里梭罗派”，吴刚伐枝、鲁班制造，内有金趁心，外有珠丝玠，可长可短。
- 现实中会动的：① 岸边翻涌的浪头；② 项下骷髅随身摆动；③ 旋风带起的氅衣、红发与沙尘。

## 排除项

- 骷髅在渡河后化阴风，取经路上不再佩戴；影视里的大念珠属改编。受戒前不画光头、僧衣。
- 兵器是宝杖，不是月牙铲；月牙铲是影视与民间说法，底本无此名。
- 木叉（底本模板标注异文“木吒”）、红葫芦、法船在后半段，本场面不出现。
- 九个骷髅的来历原文未交代；“唐僧前世九世”出自取经诗话与元杂剧。
- 悟空此刻只护师父，尚未挥棒；其后偷袭、八戒下水水战、南海请观音均不入画。
- 此时无人知道妖怪名字，题面不称沙僧、沙和尚、悟净。
