# 《西游记》第12回 唐王秉诚修大会　观音显圣化金蝉

底本：<https://zh.wikisource.org/wiki/西遊記/第012回>；读取日期：2026-10-19。
底本回目另标异文「玄奘秉诚建大会」「观音显象化金蝉」，此处取正文首选。底本无陈光蕊赴任一回，
玄奘身世仅在本回以一首诗交代；清代刊本把该故事列为第九回，故回数与底本相差，本笔记回数照底本。

## 情节要点

1. 鬼使送刘全夫妻还魂，翠莲借玉英公主之身复生；尉迟恭送金银还相良，相良不受，改建相国寺。
2. 傅奕上疏止浮图，萧瑀力辩；太宗令魏徵等选高僧，举出陈光蕊之子玄奘，赐僧官、
   五彩织金袈裟一件与毘卢帽一顶，主持长安化生寺水陆大会，九月初三开坛。
3. 观音与木叉变疥癞僧上街，售锦襕异宝袈裟（五千两）与九环锡杖（二千两），
   经萧瑀引见太宗，分文不取，太宗转赐玄奘。观音另藏有金、紧、禁三个箍儿，留待后用。
4. 七日正会，观音与木叉混入听讲，指小乘不能超亡，被擒后飞上高台，现救苦原身，
   留下颂子；太宗命吴道子描像。
5. 玄奘当众愿往西天，太宗与他拜为兄弟；翌日赐文牒、紫金钵盂，出关饯行并赐号「三藏」。

## 选定场面

化生寺观音显圣：观音带木叉飞上高台，踏祥云升到九霄，现出救苦原身，太宗率文武跪地焚香，
玄奘在拜祷的僧众之中。回目所指正是这一幕；画面有高低三层（云上、高台、地面），原文装束写得极细，
无打斗。具名角色四个：观音、木叉、唐太宗、玄奘，文武僧俗作群像。依据三处原文：

- 「遂踏祥云，直至九霄，现出救苦原身，托了净瓶杨柳」
- 「左边是木叉惠岸，执着棍，抖擞精神」
- 「面前又领一个……黄毛红嘴白鹦哥」

## 器物与环境

- 地点：长安化生寺，玄奘升座的多宝台。开坛九月初三，现身在「七日正会」，原文未写日期与天气。
- 寺内陈设：幢幡飘舞，宝盖飞辉；世尊金像、罗汉玉容；瓶插仙花，炉焚檀降，香云透霄。
- 法物：净瓶杨柳；观音飞去后半空落下一张简帖（颂子），不在现身一刻。
- 现实中会动的：① 幢幡宝盖在风中飘舞；② 香炉烟缕上升；③ 垂杨柳枝与脚下祥云缓缓摇动。

## 排除项

- 观音不画白衣、莲花座、千手、鱼篮（通天河一回另有不梳妆的形象）；原文是蓝袍、缨络。
- 底本此回称「木叉」，第8回底本作「木吒」，同为观音弟子；「木吒」配吴钩剑是《封神演义》系说法。
- 毘卢帽出自本回太宗所赐，不是观音所赠；影视的五佛冠是戏曲造型，原文无。
- 袈裟颜色原文只用「红雾」「彩云」作比，不指定色，不画成大红袈裟。
- 悟空、八戒、沙僧、白龙马均未出场；三个箍儿仍藏在观音手中，金箍到第14回才戴上。
- 观音卖袈裟是疥癞僧形，与显圣是两个阶段，勿混画；紫金钵盂、文牒属出关一幕。
