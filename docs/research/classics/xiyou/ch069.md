# 《西游记》第69回 心主夜间修药物　君王筵上论妖邪

底本：<https://zh.wikisource.org/wiki/西遊記/第069回>；读取日期：2026-10-19。

## 情节要点

1. 悟空在寝宫门外悬丝诊脉，断国王为惊恐忧思的“双鸟失群”之症；太医院奉上八百八味药，
   送到会同馆；唐僧被留在宫中。
2. 夜里悟空只取少数几味，搓成三丸，名“乌金丹”，要用无根水送服。制药一节涉及不雅原料，
   题面不取。
3. 悟空请东海龙王敖广在空中吐涎化作甘霖，百官嫔妃持杯盏接水；国王服下三丸，泻出积滞，
   当日病愈。
4. 东阁设宴，国王说出三年前端阳节妖精赛太岁摄走金圣宫，又屡来索宫女；悟空答应降妖。
5. 国王引悟空看地下避妖楼，忽起妖风，君臣躲入地穴；半空现出一个妖怪，悟空上前问话。

## 选定场面

寝宫窗外，悟空立定，手里捏着三条金线的线头，线从窗棂穿进屋里，系在龙床上国王的左手腕上，
他正以指按线诊脉。具名角色两位：悟空与国王，国王在窗内，另有宦官为群像。这一幕是
“悬丝诊脉”，隔墙的构图一眼可辨，不涉及制药细节。三处依据：

- 「孙大圣同近侍宦官到于皇宫内院，直至寝宫门外立定」
- 「请国王坐在龙床，按寸、关、尺，以金线一头系了，一头理出窗外」
- 「行者接了线头，以自己右手大指先托着食指，看了寸脉」

## 器物与环境

- 金线：三条，每条长二丈四尺（按二十四气），金色，系在国王左手腕下寸、关、尺三处；
  线由窗棂穿出，在悟空指间绷直。线数不要多于三根。
- 寸关尺：在腕部桡动脉处，近腕端为寸，居中为关，近肘端为尺；悟空右手食指对寸、
  中指对关、无名指对尺。
- 寝宫：悟空在“寝宫门外”，窗为棂格窗。窗纸有无、窗扇开合原著未写，兜底：窗扇半支开，
  线从棂格间穿出；窗内可见龙床一角与国王。
- 时令：炎天（第68回）；时辰原文未写，唐僧此时在殿上，兜底：白天。
- 现实中会动的：① 绷紧的金线随风与脉搏微颤；② 窗口垂下的帘幔与宦官衣带；
  ③ 庭中花木枝叶随风摇摆。

## 排除项

- 夜间制药、药引原料、龙王降雨、百官接雨、东阁宴、避妖楼、赛太岁先锋都在后文，不入画。
- 唐僧被留在殿上，不在寝宫；国王自称“见不得生人面”，悟空在门外，不画他握着国王手腕。
- 悟空不用棒，不变形，不带药箱、药葫芦等原文未写之物；脉象议论（“双鸟失群”等）不要求画出。
- 国王吓得跌倒在龙床是第68回；本场面他是端坐在龙床上。
- 孙思邈悬丝识鹦鹉等传说，不是底本内容。
- 86版第20集《孙猴巧行医》含悬丝诊脉，检索摘要称国王见悟空吓晕后改悬丝；未看到剧照，
  不沿用影视造型。
