# 《西游记》第78回 比丘怜子遣阴神　金殿识魔谈道德

底本：<https://zh.wikisource.org/wiki/西遊記/第078回>；读取日期：2026-10-19。

## 情节要点

1. 师徒离狮驼城西行数月，入冬，到比丘国（今改称小子城）；街上家家门口放一只鹅笼，笼里坐着男童。
2. 驿丞悄告：国丈献美女，国王贪欢成疾，国丈称须用一千一百一十一个小儿的心肝作药引；
   唐僧闻言落泪，悟空夜里请城隍、土地等诸神，把鹅笼连小儿一并摄出城外藏好。
3. 次日唐僧入朝倒换关文，悟空变蟭蟟虫伏在他帽上；国丈入殿，与唐僧论佛道，国王赞同国丈。
4. 悟空飞回殿上翡翠屏后偷听：五城兵马奏报小儿被冷风刮走，国丈转而指唐僧心肝是更好的药引，
   国王下令闭城、围驿馆。
5. 悟空与唐僧互换形貌，由悟空扮作唐僧应召入朝。

## 选定场面

比丘国金殿，早朝。国王病弱，由近侍搀着挣下龙床，躬身迎接国丈；国丈摇摇摆摆自玉阶前
走来，更不行礼；唐僧急忙起身侧立一旁；悟空化作蟭蟟虫，伏在唐僧帽上旁观。具名角色四位：
国丈、国王、唐僧、悟空（虫形）。取材避开鹅笼、小儿与取心，只取人物同殿的对峙。
三处依据：

- 「那国王即扶着近侍小宦，挣下龙床，躬身迎接」
- 「原来是一个老道者，自玉阶前，摇摇摆摆而进」
- 「变做个蟭蟟虫儿，嘤的一声，飞在三藏帽儿上」

## 器物与环境

- 地点：比丘国金殿，有龙床、玉阶、翡翠屏；国丈在龙床左手的绣墩上就座；殿上有当驾官与文武官。
- 时令：入冬（“早值冬天”）；时辰：早朝，天色原文未写。
- 国丈的拐杖在本回只写“九节枯藤盘龙拐杖”，是国丈自己手中之物，形制按枯藤盘龙画。
- 现实中会动的：① 国丈脚下随步而起的云雾香气；② 国丈的苍髯与鹤氅下摆；③ 唐僧九环锡杖上的九环轻晃。

## 排除项

- 鹅笼、笼中小儿、取心肝、刀与剖心，一律不入画；街市的五色缎遮幔也不入画。
- 国丈的白鹿本相、鹿角、鹿尾，到第79回才现形；美后（白面狐狸）不入画。
- 悟空与唐僧互换衣貌、悟空脸上贴泥属后段；此刻唐僧衣着如前，悟空不是人形。
- 唐僧长篇偈语与国丈驳辞只是对话，不要求画面写字。
- 国丈“更不行礼”，不画他跪拜或合十；国王不画成强壮模样。
- 续集第13集《救难小儿城》演此段，其国丈、国王造型不沿用。
