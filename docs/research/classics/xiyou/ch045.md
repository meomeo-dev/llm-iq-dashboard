# 《西游记》第45回 三清观大圣留名　车迟国猴王显法

底本：<https://zh.wikisource.org/wiki/西遊記/第045回>；读取日期：2026-10-19。

## 情节要点

1. 接上回：悟空三人坐在三清殿像位上，道士拜求圣水，三人撒溺充数；被识破后悟空念诗
   留名，三人驾云回智渊寺。
2. 天明，唐僧披锦襕袈裟上朝倒换关文，三道士告状，国王欲诛四众；乡老来请雨，
   国王令僧道赌求雨。
3. 虎力大仙登坛，令牌连响四下，悟空在空中拦住风、云、雷、龙王，不许应他，道士一无所得。
4. 轮到唐僧登坛静坐念《密多心经》，悟空用金箍棒向天五指，风、云、雷、雨、晴依次应令；
   雨自辰时下到午时前后；道士争功，悟空令四海龙王现真身，国王放行关文。

## 选定场面

求雨坛上，唐僧端坐台上念经，悟空把棒从耳中取出，晃至丈二长短、碗口粗细，向天一指；
半空中风婆婆扯开皮袋，巽二郎松开袋口绳，狂风卷起沙石。入画理由：“棒一指，风出袋”
是本回斗法的开端，指棒、开袋、坐定的唐僧三者呼应，且只含风一件天象，易于构图。
具名角色四位（唐僧、悟空、风婆婆、巽二郎）；台下道士、官员、百姓与五凤楼上的国王和
三位国师作远景群像。三处依据：

- 「却去耳朵内取出铁棒，迎风幌了一幌，就有丈二长短，碗来粗细，将棍望空一指」
- 「那风婆婆见了，急忙扯开皮袋；巽二郎解放口绳」
- 「满城中揭瓦翻砖，扬砂走石」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 唐僧 | 登台端然坐下，定性归神，默念《密多心经》；上朝前已披锦襕袈裟，未写脱下，台上兜底披袈裟；光头，毗卢帽原文未写，不戴；锡杖由八戒拿、钵盂由沙僧捧，不在他手中 | 登坛段；上朝段；第46回“和尚头光” |
| 悟空 | 金箍勒头；直裰、虎皮裙；金箍棒由耳中取出，一晃长丈二、粗如碗口。站位原文未写，兜底：台上唐僧身侧，一手举棒指天 | 登坛段；第14回 |
| 风婆婆 | 面貌衣冠原文未写，只写她捻住、扯开口袋（前称布袋，后称皮袋）。民间风神多作老妇形象。兜底：半空中的老妇，双手撑开一只大袋 | 拦风段；开袋句 |
| 巽二郎 | 面貌衣冠原文未写，只写他扎住、解放口绳。兜底：半空中的壮年男子，立在风婆婆旁，松开袋口绳索 | 拦风段；开袋句 |
| 群像 | 台下道士执铁锤守桩；官员、百姓；五凤楼上国王与三位国师（只作远景，不具名） | 坛场段；登楼段 |

## 器物与环境

- 法坛：高台约三丈；台左右插二十八宿旗；台顶一张桌，桌上香炉与烛台，炉边靠一面
  雷神金牌；台下五口大缸盛满清水，水面浮杨柳枝，枝上托铁牌；五根大桩前各立道士执铁锤。
  画面取台、旗、香炉、水缸三四样即可。
- 五凤楼：国王与三位国师在楼上观看。楼形原著未写，兜底：一座多层门楼，带两侧翼楼。
- 时令：乡老称“一春无雨”，春旱；时辰原文未写，雨自辰时起，兜底：上午，风起前晴空无云，
  风起后“天边红日无光”。
- 风势：满城揭瓦翻砖、扬砂走石，殿宇梁柱摇动。
- 现实中会动的：① 风卷起的沙石、瓦片；② 台上旗幡、杨柳枝与人物衣袂被风鼓起；③ 香炉青烟被吹散。

## 排除项

- 第一轮虎力大仙登坛（令牌、符、宝剑）已结束，他此刻回到楼上；本图不画令牌、符檄、
  宝剑，唐僧是静功祈祷，不烧符、不打令牌。
- 风之后的云、雷、雨、龙王现身与放晴是五指的后四步；此刻只有风，不画乌云、闪电、雨、龙。
- 三清殿撒溺留名在本回开头、发生在夜里，不入图。
- 八戒、沙僧在台下，白马在智渊寺，均不入图；悟空这一轮没有毫毛替身。
- 风婆婆、巽二郎的面貌，影视各版不同；原文只给器物，不要照搬影视服饰与雷公嘴。
- 坐禅、隔板猜枚、砍头、开膛、下油锅是第46回的赌斗，不混入。
