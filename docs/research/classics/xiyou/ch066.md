# 《西游记》第66回 诸神遭毒手　弥勒缚妖魔

底本：<https://zh.wikisource.org/wiki/西遊記/第066回>；读取日期：2026-10-19。

## 情节要点

1. 悟空上武当山求荡魔天尊，祖师无玉帝旨意不敢擅动，只借龟、蛇二将与五大神龙；
   黄眉怪抛出搭包，连龙神带兵器一并装走，悟空事先跳开。
2. 日值功曹指路，悟空到盱眙山请泗州大圣国师王菩萨的徒弟小张太子与四大神将，同样被装走。
3. 弥勒降临，说黄眉是他座前司磬的童儿，搭包是后天袋（俗名人种袋），狼牙棒是敲磬的槌，
   定下瓜田计。
4. 弥勒在悟空掌上写「禁」字，悟空单手使棒挑战，放手后双手抡棒，妖王中禁不再用搭包；
   悟空变熟瓜，弥勒变种瓜叟，妖王啃瓜，悟空钻进喉下折腾，妖王跪地求饶。
5. 弥勒收袋夺槌，把妖装进袋里，随悟空回寺取碎金，吹仙气复原金铙；悟空解救唐僧与诸神，
   次日放火烧寺登程。

## 选定场面

西山坡瓜田边，弥勒现出本相，一把揪住跪地揉肚的黄眉怪，解下后天袋、夺了磬槌。
具名角色两位：弥勒与黄眉怪；悟空此时仍在妖王腹中，不入画。跪地与解袋是一个明确瞬间，
没有血腥，与第65回的金铙场面无重叠。三处依据：

- 「弥勒却现了本像，嘻嘻笑笑」
- 「那妖抬头看见，慌忙跪倒在地，双手揉着肚子，磕头撞脑」
- 「解了他的后天袋儿，夺了他的敲磬槌儿」

| :-- | :-- | :-- |
| 弥勒 | 东来佛祖，赞词称“笑和尚”：大耳，横颐，方脸，肩张腹满身躯胖，满面喜气，两眼含笑生光；袖子敞开，脚穿芒鞋（草鞋）。衣色、冠饰原著未写，兜底：宽袖素色僧袍，不戴冠，不添佛珠、莲台、背光 | 赞词；瓜田段 |
| 黄眉怪 | 蓬头，头勒扁薄金箍，两道黄眉竖起；悬胆鼻，四方口，牙齿尖利；穿叩结连环铠，腰勒生丝攒穗绦，脚踏乌喇鞋。面色、铠色原著未写，兜底：铠甲暗色，面色不设特殊色。此刻跪地，两手揉肚；搭包被弥勒解下，磬槌已到弥勒手中 | 第65回披挂赞；瓜田段 |

## 器物与环境

- 地点：小西天西山坡下，弥勒设的草庵与一田瓜果；别的瓜都是生的，熟瓜是悟空所变。
  瓜种原文只写“瓜”，兜底：藤蔓上圆形青瓜，不强调西瓜。寺院在山上，远景可露屋脊，非必须。
- 时间天气：妖王的午饭尚未吃，约近午。弥勒降云时“满山头大雨”，瓜田一幕天气未写，兜底晴天；
  同回国师王称“时值初夏”。
- 后天袋：第65回写“一条旧白布搭包儿”，尺寸未写，此刻被弥勒解下，妖未入袋。
- 磬槌：即妖王的“短软狼牙棒”，槌头形制未写，兜底：一根短棒，一端稍粗，不画铁蒺藜重锤。
- 现实中会动的：① 瓜藤与叶随风轻摆；② 弥勒敞开的衣袖与妖王腰间的丝绦穗子；
  ③ 妖王滚过瓜地后扬起又落下的尘土。

## 排除项

- 第65回的金铙、金头揭谛、二十八宿属前一段；武当龟蛇五龙、小张太子四将属本回前段，均不入画。
- 悟空不画：不画他蹲在弥勒身旁，也不画他变的瓜被啃。掌上字原著是「禁」，影视说法不一，
  网传86版为“乐”字，以底本为准，且不入画。
- 弥勒已现本相，不再是种瓜叟；不把老叟与大肚和尚画成两人。
- 弥勒不持布袋（布袋和尚是后世造型），手里只有夺来的后天袋与磬槌；不画金身坐像。
  “大肚”合底本“腹满”，不必夸张成球形。
- 黄眉怪是妖形披挂，不画成童子；他头上的金箍与悟空的金箍无关。
- 袋子斜挎腰间、妖被装入袋中是下一句，本场面袋子刚解下。
- 人种袋“生育隐喻”之说是后人解读，非底本，题面不涉及。
