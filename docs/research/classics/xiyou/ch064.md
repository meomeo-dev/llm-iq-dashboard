# 《西游记》第64回 荆棘岭悟能努力　木仙庵三藏谈诗

底本：<https://zh.wikisource.org/wiki/西遊記/第064回>；读取日期：2026-10-19。

## 情节要点

1. 祭赛国王送师徒出城，伏龙寺僧人不肯回，悟空拔毫毛变虎拦住；四众西行，冬残春至。
2. 荆棘岭荆棘丛生，悟空空中望去一望无际；八戒自请开路，变身二十丈高，钯柄长三十丈，
   搂开荆棘，行百十里，见石碣“荆棘岭”。
3. 傍晚古庙前，自称土地的老者献饼被悟空识破，一阵阴风把三藏摄走，送到木仙庵。
4. 十八公等四老与三藏吟诗论禅；杏仙来访，欲与三藏成配，三藏变色拒绝，扯拽至天明。
5. 悟空等赶到，识破四老、杏仙是松柏桧竹、杏树成精，八戒一顿钉钯全部筑倒。

## 选定场面

荆棘岭上，八戒变身二十丈高，双手使三十丈长的钉钯，将荆棘左右搂开；三藏骑马紧随，沙僧
挑担，悟空以铁棒拨开荆棘。具名角色四位：八戒、三藏、悟空、沙僧。体量悬殊，“悟能努力”
一眼可见，无打斗。备选的木仙庵吟诗是夜景，四老、杏仙、鬼使、女童人物过多，不取。
三处依据：

- 「就长了有二十丈高下的身躯」
- 「拽开步，双手使钯，将荆棘左右搂开」
- 「三藏见了甚喜，即策马紧随后面；沙僧挑着行李；行者也使铁棒拨开」

## 器物与环境

- 荆棘岭：荆棘丫叉，薜萝牵绕，左右尽是荆刺棘针；“路痕在下，荆棘在上”。林中有松柏竹梅
  柳桑，嫩叶初发、花开如锦，凝烟带雨，日影煌煌。
  兜底：带刺灌丛、垂挂藤蔓与新叶，路被覆盖。
- 体量：八戒约为常人三十倍以上，宜取近景半身或仰角，不必画全；钯柄横贯画面。
- 时令：冬残春至，“不暖不寒”；开路是白天（行到将晚才见石碣）。
- 现实中会动的：① 被搂开、拨开的荆棘枝条与藤蔓；② 林间凝烟薄雾；③ 白马鬃尾与人物衣带。

## 排除项

- 石碣“荆棘岭”及十四字小诗在行了百十里之后，不入画，也不要求写字。
- 木仙庵、十八公四老、杏仙、赤身鬼使都在夜里，土地献饼、阴风摄走三藏在傍晚，均为后一幕。
- 八戒变大猪、用嘴拱路是第67回稀柿衕；本回是变成二十丈高的人身，用钯“搂开”，不变猪。
- 悟空不变大，不用金箍棒变长；沙僧只挑担，不开路。伏龙寺僧人送行、毫毛变虎是前一幕。
- 央视版第19集对应原著第64–66回；未检到荆棘岭变身造型的资料，不依影视。
