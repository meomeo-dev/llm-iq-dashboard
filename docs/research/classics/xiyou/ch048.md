# 《西游记》第48回 魔弄寒风飘大雪　僧思拜佛履层冰

底本：<https://zh.wikisource.org/wiki/西遊記/第048回>；读取日期：2026-10-19。

## 情节要点

1. 悟空、八戒在灵感庙受祭，妖怪现身问名，八戒一钯筑下冰盘大的鱼鳞，妖怪化风钻回通天河。
2. 妖怪听鳜婆之计：夜里作法降大雪、冻河，让水族变人形在冰上来往，引唐僧踏冰，再在河心迸裂冰面擒人。
3. 大雪次日，河冻八百里。陈老苦留待船，唐僧坚持趁冰西行；八戒用钉钯筑冰，只留九个白迹，说冰已连底冻实。
4. 出发前八戒讨稻草包马蹄防滑；行三四里后又令众人把杖棒横担，防踩着凌眼落水，师徒踏冰走了一昼夜。
5. 冰下一声响，妖怪迸开冰面，白马、八戒、沙僧落水，唐僧被擒藏入石匣；悟空在空中，三人回陈家商议。

## 选定场面

通天河冰面上，师徒四人排定队形西行：唐僧骑白马，马蹄裹稻草，横担九环锡杖；悟空横担铁棒；沙僧横担降妖宝杖；
八戒肩挑行李，腰横钉钯。回目“僧思拜佛履层冰”，队形与持物逐人写明，冰面白茫茫，构图单纯，此刻冰面完好，无妖怪现身。三处依据：

- 「长老横担着锡杖，行者横担着铁棒，沙僧横担着降妖宝杖，八戒肩挑着行李，腰横着钉钯」
- 「要稻草包着马蹄方才不滑」
- 「通天阔水更无波，皎洁冰漫如陆路」

## 器物与环境

- 地点：通天河冰面，离东岸三四里，八百里河面冻成一片；陈家人留在岸上。凌眼指冰上的窟窿，一脚踏空会被冰盖住。
- 时间天气：雪后晴昼，看河时“云收破晓晴”，朔风凛凛、冰面滑溜；大雪此前已住，平地积雪二尺。
  节令陈老说七月已交白露、算八月节。
- 器物：稻草束只包马足；九环锡杖、铁棒、降妖宝杖（外嵌宝、内镶金，见第49回诗）、九齿钉钯、行李担。
- 冰厚：八戒一钯下去只留九个白迹，冰连底冻实。
- 现实中会动的：① 朔风卷起冰面的浮雪；② 人与马呼出的白气；③ 草蹄末端、衣摆与马鬃被风吹动。

## 排除项

- 冰裂、落水、白马沉没、唐僧被擒都在此后，此刻不画裂缝与水面；灵感大王的金盔金甲人形只在灵感庙一幕，此刻在冰下，不画。
- 不是暴风雪：大雪已住、天晴；动效里的浮雪只是风扬起的积雪。
- 师徒踏冰步行或骑马，悟空不驾云；稻草只包马蹄，不裹人脚。
- 担子在八戒肩上，沙僧不挑担；锡杖已由八戒交给唐僧，横在唐僧身前。
- 陈老与陈家人送到岸边便止，不上冰。
- 1986 版原定的《险渡通天河》因经费用完未拍，影视造型不作依据。
