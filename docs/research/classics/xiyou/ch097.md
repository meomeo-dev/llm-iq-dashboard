# 《西游记》第97回 金酬外护遭魔蛰　圣显幽魂救本原

底本：<https://zh.wikisource.org/wiki/西遊記/第097回>；读取日期：2026-10-19。

## 情节要点

1. 师徒在华光行院破屋熬雨夜；同夜城里一伙败家的赌嫖之徒冒雨劫了寇家，员外出门哀告，
   被踢倒身亡。
2. 老妪迁怒唐僧，与两子写失状，坐名告“唐僧点火、八戒叫杀、沙僧劫金、行者打死”；
   刺史点起一百五十人追赶。
3. 天明上路，西去二十里遇到刚分完赃又来拦路的强盗；悟空假称愿献盘缠，趁机撒土念咒，
   定住三十来名贼，逼供后夺回赃物，要送还寇家，反被官兵当贼捉去下狱。
4. 悟空狱中变蜢虫，夜入寇家与刺史宅，假托亡魂与阎君之名；次晨现大法身，伸一只脚踏进县堂，
   官吏答应放人。
5. 悟空到阴司向地藏王讨回寇洪魂魄，员外还阳，官员当堂赔罪，师徒再受送行。

## 选定场面

华光行院以西二十里的大路上，强盗一字摆开拦路；悟空低头打开包袱，就地抓一把尘土
往上一洒，念咒喝声“住”，三十来个强盗咬牙睁眼、撒着手直直定住。先被放过去的唐僧、
八戒、沙僧已在强盗身后向西走远，悟空在近处。取出手一刻，无血腥，也避开凶案。
具名角色悟空、唐僧、八戒、沙僧四位，强盗为群像。三处依据：

- 「束一束虎皮裙，抖一抖锦布直裰」
- 「就地挝把尘土，往上一洒，念个咒语」
- 「一个个咬着牙，睁着眼，撒着手，直直的站定」

## 器物与环境

- 地点：华光行院以西二十里的大路，路北有山凹（贼在此分赃）。悟空脚边是打开的包袱和
  沙僧丢下的行李担子。
- 时间天气：夜雨过后天明上路，晴否未写；悟空能就地抓起“尘土”，说明路面不是泥浆，
  兜底：微湿的黄土路，清晨，不画积水泥泞。季节承第96回，春尽夏初。
- 定身法：原文只写抓土、洒、念咒、喝一声“住”，贼人“莫能言语，不得动身”，没有宝光
  法器。兜底：尘土在空中散成一小片，悟空手势朝上。
- 兵器：夜劫所带为短刀、蒺藜、拐子、闷棍、麻绳、火把。蒺藜可指撒地的铁刺或带刺的骨朵，
  原文未明，本场面不画。
- 现实中会动的：① 洒出的尘土在空中散开、下落；② 白马鬃尾与远处三人的衣带被风吹动；
  ③ 路旁草木的摆动。

## 排除项

- 凶案不入画：寇员外被踢死、夜劫的火把与尸身都不画，题面与标准也不写“杀”“踢死”；强盗
  只作被定住的拦路者。
- 定住之后的毫毛变绳绑贼、逼供收赃，以及官兵、脑箍、牢狱、变蜢虫、现大法身伸脚、阴司
  地藏王，都在后文，不入画。
- 悟空此刻没有动棒，不画打斗；强盗不是妖魔，不画青面獠牙。
- 夜劫写“十数人”，路劫写“三十来名”，以后者为准；SVG 可画十余人，用排列暗示更多。
- 86版续篇第14–15集梗概只写悟空“截下强盗夺去的财物”，未写手法，影视造型不沿用。
