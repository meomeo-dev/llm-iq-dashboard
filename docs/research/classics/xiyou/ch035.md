# 《西游记》第35回 外道施威欺正性　心猿获宝伏邪魔

底本：<https://zh.wikisource.org/wiki/西遊記/第035回>；读取日期：2026-10-19。

## 情节要点

1. 悟空持真葫芦现身叫阵“行者孙”，套出银角葫芦的来历；银角叫名，悟空连应八九声不入
   （银角手中是假葫芦）；悟空反用真葫芦叫“银角大王”，应声即装，贴帖。
2. 金角取七星剑、芭蕉扇，率三百小妖出战；悟空用毫毛变身外身打退群妖，金角以芭蕉扇扇火，
   悟空捻避火诀跃出；悟空在洞中见羊脂玉净瓶放金光，取走；趁金角睡着，又盗走他的芭蕉扇。
3. 金角败走压龙山，带来舅父狐阿七，阿七被八戒一钯打死，现狐狸原形。
4. 悟空用净瓶叫“金角大王”，应声即装，得七星剑；师徒上路，太上老君扮瞽者拦路，收回
   五件宝贝，倒出两股仙气化回金、银二童子，同归兜率宫，并称是观音向他借了三次。

## 选定场面

金角被悟空的分身围困，左手擎剑，右手从项后取出芭蕉扇向下扇出火，山岭一片赤焰。
装束有诗赞，火势有专段描写，两个具名角色，不涉血腥。未选老君收宝：老君与童子的
相貌衣着原文未写，画面无据。三处依据：

- 「右手伸于项后，取出芭蕉扇子」
- 「更无一缕青烟，尽是满山赤焰」
- 「只烧得岭上松翻成火树，崖前柏变作灯笼」

## 器物与环境

- 芭蕉扇：平时插在后项衣领，尺寸不大（推定）；向“东南丙丁火，正对离宫”扇下，一连七八扇，
  扇火不扇风。老君收宝时说“扇子是我搧火的”。
- 火：原文说不是天火、炉火、山火、灶火，是五行中取出的一点灵光火；赤红无烟，松柏烧成
  火树、灯笼，走兽飞禽四散奔逃。
- 地点：莲花洞门外的山岭；此时时辰未写（“日将晡”是其后第二场交锋）。
- 现实中会动的：① 赤红火焰翻卷蔓延，无烟；② 燃烧的松柏摇曳、火星迸飞；
  ③ 金角的钢须、赤袍与盔缨被热风吹起。
- 收场对照：老君说葫芦盛丹、净瓶盛水、宝剑炼魔、扇子搧火、绳是勒袍带；两怪是看金炉、
  看银炉的童子。叫名应声即装的规则，净瓶与葫芦相同（老魔称“人应了就装得”）。

## 排除项

- 本回的芭蕉扇可插入衣领、只扇出火，不是第59回铁扇公主那把能灭火、扇风、变大小的
  宝扇，不画成巨扇。
- 此火不是第41回红孩儿的三昧真火，也不是天火。
- 金角、银角原文均无长角，不取金色皮肤或兽角造型。
- 悟空不在火中被烧；原文写他收回毫毛、捻避火诀跃出，不画烧焦。
- 净瓶（稍后在洞中取得）与芭蕉扇（金角睡着时盗得）此时都不在悟空手中。
- 唐僧、八戒、沙僧吊在洞内；狐阿七、老君与二童子属其后情节，均不入画。
