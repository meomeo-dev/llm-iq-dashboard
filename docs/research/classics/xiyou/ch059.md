# 《西游记》第59回 唐三藏路阻火焰山　孙行者一调芭蕉扇

底本：<https://zh.wikisource.org/wiki/西遊記/第059回>；读取日期：2026-10-19。

## 情节要点

1. 三秋时节师徒遇酷热，红砖红瓦庄院的老者说此地是火焰山，八百里火焰，铜头铁身
   也要化汁；卖糕人指点向铁扇仙求芭蕉扇。
2. 悟空到翠云山，樵夫说铁扇公主即罗刹女，是牛魔王之妻、红孩儿之母；悟空称嫂嫂
   求扇，罗刹女为子报仇，双剑砍他，战到日落，取出芭蕉扇一扇，把他扇到小须弥山。
3. 灵吉菩萨送定风丹；悟空折回，扇他不动，变蟭蟟虫随茶沫入腹，逼出扇子。
4. 悟空拿回的是假扇，扇火反助火势，烧掉两股毫毛；火焰山土地现身，指点去找
   “大力王”牛魔王借真扇。

## 选定场面

翠云山芭蕉洞外，战至日落，罗刹女取出芭蕉扇一扇，阴风起处悟空被扇得翻卷离地，如旋
风里的败叶。取“扇出”的一刻，无人受伤；一扇之威与悟空失态被卷的对比鲜明。具名角色
只有罗刹女与悟空。三处依据：

- 「即便取出芭蕉扇，幌一幌，一扇阴风，把行者扇得无影无形」
- 「就如旋风翻败叶，流水淌残花」
- 「却才斗到沉酣处，不觉西方坠日头」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 罗刹女（铁扇公主） | 头裹团花手帕，身穿纳锦云袍，腰间双束虎筋绦，微露绣裙偏绡；足蹬三寸凤嘴弓鞋，膝裤龙须金销；怒容（诗以“月婆”作比，五官未写，兜底：怒目蹙眉的中年妇人）；原持两口青锋宝剑，取扇时另一手是否仍握剑原文未写，兜底：一手持扇，一手握剑 | 披挂赞词 |
| 孙悟空 | 黄发、金箍、金睛火眼，绵布直裰，虎皮裙，麂皮靴，毛脸雷公嘴（全貌见第58回）；手中是耳中掣出幌成碗口粗的铁棒；任砍时“伸着光头”，不戴冠帽。定风丹此时还没有：被扇到小须弥山、灵吉所赠之后才缝进衣领 | 论辩段；斗法段；第58回 |

## 器物与环境

- 地点：翠云山芭蕉洞外，两扇洞门；洞外乔松、衰柳、碧梧，薜萝垂挂，石梯藤葛，竹荫
  如雨，繁花似绣，白云随风。洞在山中，樵夫指的路是向东五六里。
- 时令：三秋霜景（本回开头），火焰山一带却酷热；战到日落，兜底：秋日黄昏的暖光。
- 芭蕉扇：灵吉称其为昆仑山后天地产成的“太阴之精叶”，扇人飘八万四千里。此刻形制
  原文未写（第60回：平时藏口中如杏叶大，放大后一丈二尺长，柄上三十六缕红丝）；
  兜底：一柄大蕉叶形的扇，柄上缀红丝，不画成铁制扇面（“铁扇”是公主的称号）。
- 兵器：罗刹女两口青锋宝剑；悟空碗口粗铁棒。
- 现实中会动的：① 被扇起的阴风里翻卷的落叶、花瓣与尘土；② 罗刹女的手帕、衣带
  与悟空的虎皮裙被风吹起；③ 洞外松枝、垂挂的薜萝与竹枝摇动。

## 排除项

- 悟空入腹、蟭蟟虫、茶沫、定风丹，小须弥山与灵吉，火焰山土地、红砖庄院、卖糕人、
  樵夫，都在前后段，不入图。
- 此刻扇的是真扇；悟空带走的假扇是后文，扇灭火焰山要到第61回（三调），不挪到本回。
- 牛魔王、红孩儿、玉面公主不出场（牛魔王本回只被提及，他在积雷山）。
- 罗刹女砍悟空头十数下，悟空“全不认真”，是前一幕；不画砍击、不画流血。
- 旧刊插图把她画成披甲持剑；“铁扇”只是称号，别把扇画成铁制。原文是手帕、云袍。
