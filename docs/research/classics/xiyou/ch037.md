# 《西游记》第37回 鬼王夜谒唐三藏　悟空神化引婴儿

底本：<https://zh.wikisource.org/wiki/西遊記/第037回>；读取日期：2026-10-19。

## 情节要点

1. 三藏在宝林寺禅堂灯下念《梁皇水忏》《孔雀真经》到三更，狂风骤起，他伏案入梦。
2. 乌鸡国王鬼魂浑身是水立在禅堂门外，自述被结拜的全真推下御花园八角琉璃井，井口压石板、
   栽芭蕉；全真变成他的模样占了王位；求大圣降妖，留金厢白玉珪为表记。
3. 三藏惊醒，阶前果有玉珪；悟空定计：以毫毛变红金漆匣收玉珪，三藏披锦襕袈裟端坐正殿，
   悟空变二寸小和尚藏匣中。
4. 次晨太子率三千人马出猎；悟空变白兔挨了一箭，接住箭头，把太子引到寺门，箭插在门槛上。
5. 太子在殿上喝令拿人，被诸神护住；悟空现身道破冤情，太子半信半疑，持玉珪回城问母（下回）。

## 选定场面

三更禅堂，鬼王立在门外，三藏躬身伸手去搀，手扑了个空。入画理由：只需两人，鬼王衣冠与
“水淋淋”两处特征辨识度高，灯火、风、水滴皆是可动之物。三处依据：

- 「头戴一顶冲天冠，腰束一条碧玉带」
- 「手执一柄列斗罗星白玉珪」
- 「用手忙搀，扑了个空虚」

## 器物与环境

- 地点：宝林寺禅堂（三间，两梢间铺四张藤屉床）；鬼王在门外，夜游神的一阵神风送他来。
- 时间天气：三更；一阵狂风过，吹得灯或明或暗，星斗昏昧；风诗写香炉倾倒、幢幡宝盖摇拆。
- 玉珪：金厢（以金镶边）白玉所制，圭面“列斗罗星”；古圭为上尖（一说上圆）下方的长条玉片，
  具体纹样原文未写。鬼王在梦中谈话时把它放下作表记，醒后见于阶檐上。
- 现实中会动的：① 灯焰忽明忽暗；② 鬼王衣袍、衣带滴落的水珠；③ 风卷的落叶与尘土。

## 排除项

- 底本写作“珪”（同圭）：描写鬼王时称“白玉珪”，作表记时称“金厢白玉珪”；不写成玉玺或笏板。
- 鬼王是溺死冤魂，只写水湿垂泪，不画伤痕、血迹或骸骨；不画成厉鬼獠牙。
- 假国王（全真）、夜游神、红金漆匣、白兔与太子都是前后段，不入此图。
- 终南山底本作“钟南山”；旱灾在五年前，国王已死三年，题面如提时间须与此一致。
- 鬼王在门外，三藏的手扑空时二人之间无身体接触；不画鬼王进屋或坐下。
- 三藏此刻未写穿袈裟、持锡杖；袈裟次晨才穿。
