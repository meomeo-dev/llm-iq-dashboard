# 《西游记》第41回 心猿遭火败　木母被魔擒

底本：<https://zh.wikisource.org/wiki/西遊記/第041回>；读取日期：2026-10-19。

## 情节要点

1. 悟空带八戒别了沙僧，跳过枯松涧到火云洞前叫阵；红孩儿（自称圣婴大王）推出五辆小车，
   按金、木、水、火、土摆在门前，提丈八火尖枪出战，与悟空斗二十合，八戒从旁一钯，妖怪败退。
2. 红孩儿退到洞门前，站上中间小车捶自己鼻子两拳，口鼻喷出火烟，五辆车同时冒火；
   八戒先逃，悟空捏避火诀闯入，被烟火逼得看不见路，退出火场。
3. 沙僧提议以水克火；悟空到东海借四海龙王行雨，雨浇不灭三昧真火，悟空被烟呛后跳涧，
   冷水逼得火气攻心昏死，被八戒、沙僧救醒。
4. 八戒去南海请观音，红孩儿抢先变假观音，把他骗回洞中装进皮袋；悟空变包袱、苍蝇潜入，
   听妖怪遣六健将去请老大王来吃唐僧。

## 选定场面

火云洞门前：红孩儿被八戒一钯逼退后站上中间那辆小车，一手举枪，一手捶自己的鼻子，口鼻
火烟将起，五辆车同时涌出火光；悟空在车前举棒对阵，八戒在侧，已有退意。入画理由：“站车
捶鼻喷火”是红孩儿独有的出招，五车并列自带构图，火势即画面中心；只取火起一瞬，不画人被烧。
具名角色三位（红孩儿、悟空、八戒），另加群像小妖。三处依据：

- 「一只手举着火尖枪，站在那中间一辆小车儿上；一只手捏着拳头，往自家鼻子上捶了两拳」
- 「那五辆车子上火光涌出」
- 「只是腰间束一条锦绣战裙，赤着脚」（红孩儿出战时的装束）

## 器物与环境

- 地点：号山枯松涧火云洞。洞门外石碣刻“号山枯松涧火云洞”八字，洞门为两扇石门；
  洞外景致有古道、白云、流水过桥、藤萝石磴、松篁；涧上有石板桥（第40回）。
- 时令：第40回写秋尽冬初；本日白昼（悟空称“今早”见吊树孩童），具体时辰与天气原文未写。
- 兵器：火尖枪原文只写“丈八长”“火尖”，枪头样式原著未写，兜底：长杆枪、焰形枪头；
  悟空金箍棒；八戒九齿钉钯。
- 小车：五辆，按金、木、水、火、土安放，每辆有小妖看守。车制与颜色原著未写，兜底：
  双轮平板手推车、木色车身，五辆并排于洞门前。
- 火势：红焰焰大火烧空，口鼻喷火冒浓烟，眨眼间火焰齐生。
- 现实中会动的：① 车上与红孩儿口鼻喷出的火焰、浓烟；② 战裙、直裰下摆与虎皮裙被热浪掀动；③ 涧边松枝摇动、涧水流淌。

## 排除项

- 红肚兜、风火轮属影视、动画加入，原著本回与第40回均无；混天绫、乾坤圈亦无。
- 第40回的七岁顽童伪装（赤条条吊树），以及第42回剃出三个揪儿、套上金箍后的样子，不属本图。
- 龙王借雨、悟空昏厥、观音与假观音均在后段；本图无雨，不画龙王，不画观音。
- 悟空不怕火、只怕烟，且此刻未受伤；不画他被烧伤，也不画昏死。
- 沙僧守行李马匹在涧那边松林，唐僧被缚在洞内后院；牛魔王、六健将、皮袋均属后段，不入图。
