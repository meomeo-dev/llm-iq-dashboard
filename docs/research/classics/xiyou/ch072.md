# 《西游记》第72回 盘丝洞七情迷本　濯垢泉八戒忘形

底本：<https://zh.wikisource.org/wiki/西遊記/第072回>；读取日期：2026-10-19。

## 情节要点

1. 师徒别了朱紫国，春日行至一座庄院，唐僧执意自去化斋；八戒取出钵盂，替他换了衣帽。
2. 庄院石桥古树、茅屋蓬窗，先见四女做针线，又见三女在木香亭下踢气毬；唐僧被请入石屋，
   桌凳皆石，斋饭腥膻不敢吃，被众女捆吊在梁上。
3. 女妖在屋内放出丝绳，把庄院封得如雪如银；悟空赶到，按得丝绳粘软，欲打又止，拘来
   土地，问明此处是盘丝岭盘丝洞，洞中有七个女怪。
4. 悟空变蝇跟去濯垢泉，取走她们的衣物；八戒闯去，被女妖放出的丝篷罩住，跌了许多
   跟头（此节涉及沐浴，不入画）。
5. 女妖唤出七个蛛虫干儿子阻桥，悟空以毫毛变七种鹰啄尽；师徒救下唐僧，放火烧了庄院。

## 选定场面

盘丝岭下庄院前，丝绳已把整座庄院封成一片银白，悟空束紧虎皮裙、掣出金箍棒跑到跟前，
伸手按了按丝网，举棒欲打又停住。画面内不出现女子，只见丝网、庄院轮廓与悟空；八戒、沙僧
与白龙马在远处大道旁看守行李，作小景。具名角色悟空，另有八戒、沙僧远景。三处依据：

- 「那一片如雪又亮如雪，似银又光似银」
- 「好大圣，束一束虎皮裙，掣出金箍棒」
- 「看见那丝绳缠了有千百层厚，穿穿道道，却似经纬之势」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙悟空 | 金箍、直裰、虎皮裙，使金箍棒。直裰是第14回唐僧所给棉布直裰（“光艳艳”，色未写），兜底：素色布直裰；棒的长短粗细本回未写，取出时按平常的棒身画 | 本回；第14回 |
| 猪八戒 | 远景：黑脸短毛、长嘴大耳，皂锦直裰，九齿钉钯。本回原文只在后文写他“脱了皂锦直裰”，此刻放马看担，钉钯握持与否未写，兜底：倚在身边 | 本回；第19回 |
| 沙僧 | 远景：落发、蓝靛脸，黄锦直裰，降妖宝杖倚在身边 | 第22回 |
| 白龙马 | 远景，旁边有行李担子 | 本回“放马看担” |
| 唐僧 | 屋内被吊，不入画；本回只写“换了衣帽”，所换衣帽原著未写，不默认画袈裟、毗卢帽 | 本回 |

## 器物与环境

- 地点：盘丝岭下的庄院。石桥高耸，古树森齐，桥下流水接长溪；桥那边数椽茅屋、蓬窗，
  内有木香亭；屋后是山洞石屋（土地称盘丝洞）。
- 时间天气：春光明媚，唐僧说“今日天气晴明”；时辰原文未直写，土地后言“巳时已过，
  午时将来”，大致近午。
- 丝绳：女妖“腰眼”冒出，鸭蛋粗细，“迸玉飞银”；封门后缠了千百层厚，经纬交错，用手
  一按“粘软沾人”，硬棒打不断，只能打匾。色泽取原文“如雪”“似银”，画成银白发亮。
- 之后丝绳被收，发出“呼呼吸吸”如蚕食叶的声响，庄院复原；本场面取丝网未收之时。
- 现实中会动的：① 丝网上流动的银光与微微起伏的丝线；② 石桥下的流水；③ 树梢枝叶与
  悟空的虎皮裙边、直裰下摆被风带起的摆动。

## 排除项

- 濯垢泉沐浴、悟空变鹰取衣、八戒下水各节不入画，题面与评判标准也不写其中任何裸露细节；
  女妖放丝时的衣着同样不写、不画，画面里不放女子。
- 蜘蛛本相（第73回土地才点明，巴斗大）与七个蛛虫干儿子、七种鹰，在后文，不入画。
- 唐僧被吊梁上、石屋内景、人油人肉的斋饭，在屋内，不入画；不画踢气毬与做针线的女子。
- 悟空此刻没有变化，也没有动棒；变麻苍蝇是之后的事，土地也不入画。
- 黄花观与多目怪属第73回，不出现。
- 86版把盘丝洞演成纱衣蜘蛛精与莲花池，京剧用舞绸带表现蛛丝，均为改编；原著无莲花池，
  丝是纵横交织、层层叠叠的粗丝绳，不画成单张圆形蛛网。
