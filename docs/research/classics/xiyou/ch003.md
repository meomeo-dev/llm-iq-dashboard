# 《西游记》第3回 四海千山皆拱伏 九幽十类尽除名

底本：维基文库《西遊記》第003回 <https://zh.wikisource.org/wiki/西遊記/第003回>；读取日期：2026-10-19。

## 情节要点

1. 悟空回山后从傲来国武库取来刀枪操练猴兵，仍嫌自己的刀不趁手；四老猴献策：铁板桥下水通东海龙宫。
2. 悟空闭水入东洋海底，东海龙王敖广献大杆刀、九股叉、方天戟，悟空皆嫌轻。
3. 龙婆、龙女提议送海藏中放光的“天河定底神珍铁”；悟空令其变短变细，出海藏后见两头金箍与铭文
   “如意金箍棒”。
4. 悟空索披挂，四海龙王各献一件，悟空穿戴后打出龙宫，回洞演示棒的大小变化，与六魔王结义。
5. 醉后被勾魂，悟空打入幽冥界，勾去生死簿上猴属之名；龙王、阎王上奏，玉帝遣太白金星招安。

## 选定场面

海藏中悟空两手抓住放光的铁柱，令其变细变短，东海龙王在旁指引。取棒是本回的核心，金光万道的
铁柱有强烈视觉中心，两个具名角色，不涉打斗。以下两个瞬间在底本里先后相隔，不得并成一幅：
先是海藏抓柱变细；后是出海藏看清金箍、悟空持棒打转水晶宫，龙王与水族缩颈藏头。

- “忽见金光万道。”
- “乃是一根铁柱子，约有斗来粗，二丈有余长。”
- “忒粗忒长些，再短细些方可用。”

## 器物与环境

- 地点：东洋海底；宫殿称“水晶宫”，藏宝处称“海藏”；悟空以闭水法入海，出水“身上更无一点水湿”。
- 铁柱（取出前）：“铁柱子”，斗来粗、二丈有余长，金光万道；龙婆称其近日“霞光艳艳，瑞气腾腾”；
  龙王称它是大禹治水时“定江海浅深的一个定子”。
- 铁柱（取出后）：两头两个金箍，中间一段乌铁，紧挨箍刻“如意金箍棒”并注重一万三千五百斤；
  经变细后二丈长短、碗口粗细。
- 先献兵器：大杆刀、九股叉（三千六百斤）、方天戟（七千二百斤），悟空皆嫌轻。
- 披挂（取棒之后）：北海敖顺藕丝步云履、西海敖闰锁子黄金甲、南海敖钦凤翅紫金冠（据底本，个别
  版本把云履与黄金甲的赠者互换）。
- 会动的物件（动效候选）：1. 铁柱金光放射并明暗脉动（有据）；2. 海水中上升的气泡（原文未写，
  属画面添加）；3. 随水流摆动的海草与悟空衣摆（海草原文未写，“撩衣”有据）。

## 排除项

- “定海神针”一名：第1–5回底本均无此四字。本回称“天河定底的神珍铁”“天河镇底神珍”，铭文为
  “如意金箍棒”，另称“宝贝”。
- 阶段错位：取棒瞬间悟空尚未穿戴紫金冠、黄金甲、步云履；紧箍与虎皮裙（第14回）；哪吒与天兵（第4回）。
- 凤翅紫金冠上的双翎：底本未写，属戏曲与影视造型。
- 四海龙王同场：取棒时只有东海龙王（及龙婆龙女）；另三海龙王是后来击鼓撞钟才赶到。
- 变化尺度：绣花针大小与万丈身形都在回洞之后，不入龙宫。

## 现有题面核对

- “幽蓝的海底水晶宫”“海草与气泡”：水晶宫有据；幽蓝、海草、气泡为画面添加，原文未写，不冲突。
- “两头包着金箍、中间乌黑的铁柱迸发万道金光”：时点混合。万道金光在海藏中；金箍与乌铁是出海藏后
  才看清，此前只写“铁柱子”。
- “毛脸尖嘴、身材矮小的猴王”：有据，但出处不在龙宫段（尖嘴与矮在第2回，毛脸在本回末）。
- “双手抱住铁柱”：无据，底本写悟空撩衣上前、摸了一把，再尽力两手挝过（挝，抓取），非抱。
- “要它变细变短”：有据。
- “龙王和虾兵蟹将吓得纷纷后退”：时点与反应都不符。抓柱时龙王在旁引路；惊吓发生在持棒打转水晶宫
  之后，写龙王胆战心惊、龟鳖缩颈、鱼虾藏头，非后退。
- “定海神针”（动态题面括注）：无据，后世说法，应改称“天河定底神珍铁”或“如意金箍棒”。
