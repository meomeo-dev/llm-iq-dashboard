# 《西游记》第17回 孙行者大闹黑风山　观世音收伏熊罴怪

底本：<https://zh.wikisource.org/wiki/西遊記/第017回>；读取日期：2026-10-19。

## 情节要点

1. 悟空在黑风山芳草坡偷听，得知袈裟被黑汉所得，要办“佛衣会”；一棒打死白衣秀士（白花蛇精）。
2. 悟空寻到黑风洞口索衣，与披挂出战的黑汉交手，十数回合不分胜负，日已当午，黑汉收兵。
3. 悟空变作金池长老混进洞中被识破，再战到日落；夜里决定去南海请观音。
4. 观音与悟空打死送丹的苍狼道人，观音变作凌虚仙子献丹，悟空变丹入腹。
5. 熊罴吞丹倒地，观音取回袈裟并丢下一个箍儿，收其为落伽山守山大神。

## 选定场面

黑风洞口初战：悟空与披甲持枪的黑汉在石门前对阵，金箍棒与黑缨枪相交的一瞬。
装束、兵器、洞门匾额都有明确原文，两人对阵构图简洁，不涉及血腥结果。备选场面是观音变
凌虚仙子献丹，但仙子与悟空所变之丹均无外观细写，不宜作为首选。依据三处原文：

- 「碗子铁盔火漆光，乌金铠甲亮辉煌」
- 「如意棒，黑缨枪，二人洞口逞刚强」
- 「门上有一横石板，明书六个大字，乃‘黑风山黑风洞’」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 悟空 | 毛脸雷公嘴（小妖语）；围虎皮裙、穿绵布直裰、戴金箍；手执碗口粗的金箍棒 | 第14–15回造型延续；本回手执铁棒，战诗称如意棒 |
| 黑汉（熊罴怪） | 人形，通身乌黑；黑漆碗形铁盔、乌金铠甲、皂罗袍罩风兜袖、黑绿丝绦垂穗、乌皮靴；手执黑缨枪一杆；眼晃金睛 | 出战赞诗；悟空笑其似烧窑筑煤的 |

洞中会客时的装束（黑绿纻丝袄、鸦青花绫披风、乌角软巾、麂皮靴）不取。

## 器物与环境

- 洞府：两扇石门紧闭，门上横石板六个大字“黑风山黑风洞”；洞前烟霞缭绕、松柏森森，
  有枯木桥、薜萝、傍岸夭桃和绿柳，鸟衔红蕊、鹿踏芳丛。
- 兵器：悟空的金箍棒，黑汉的黑缨枪；交锋诗句写二人喷彩雾、吐毫光。
- 时间季节：初战斗十数合后日已当午；第17回写明正值春光时节。
- 现实中会动的：① 洞前烟霞与彩雾；② 枪缨与黑绿丝绦穗随招式摆动；③ 风送落花。

## 排除项

- 观音此时不在场（悟空战后才去南海请来）；箍儿是收伏时才丢，战斗时熊头上没有箍。
- 禁箍之名：第17回只写丢下一个箍儿；第42回观音自述，收守山大神用的是禁箍儿。
- 金池长老在第16回已撞墙而死，不入画；八戒、沙僧、白马均不在场。
- 原文称此怪为黑汉、黑大王、熊罴，诗中称黑风王；“黑熊精”是后世通称。原文没写熊耳熊吻，
  只写人形、乌黑、金睛，不画成熊头兽形。
- 袈裟此时已被黑汉藏起，不在手上；悟空不得出现紫金冠、黄金甲等第3回披挂。
- 洞中假金池长老会客、观音变道人献丹，均是之后的情节，不混入初战画面。
