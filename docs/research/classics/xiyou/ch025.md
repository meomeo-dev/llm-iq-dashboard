# 《西游记》第25回 镇元仙赶捉取经僧　孙行者大闹五庄观

底本：<https://zh.wikisource.org/wiki/西遊記/第025回>；读取日期：2026-10-19。

## 情节要点

1. 悟空认账后拔毫毛变假身陪唐僧，真身去推倒人参树；二童复查见树倒，哄师徒吃饭，
   将各层门锁死。
2. 悟空夜半用解锁法开门，弹瞌睡虫使二童昏睡，师徒连夜西行。
3. 镇元子回观，唤醒二童，驾云追上；变行脚全真诓悟空，动手后在半空现本相，
   以袖里乾坤笼走四僧。
4. 回观后以龙皮七星鞭鞭打，悟空替师受鞭；夜里用柳树变身脱逃，次日镇元子再追，
   三徒围攻，又被袖笼回。
5. 布裹漆身、油锅煠人；悟空变石狮子顶替，打破油锅，又回头主动替师。

## 选定场面

路旁松林上空，悟空抡棒打来，镇元子以玉麈遮挡，随即迎风一展袍袖，把下方四僧连马一袖笼住。
画面主体是镇元子与悟空；唐僧师徒与白马作远景小群像。袖里乾坤是本回标志，镇元子本相写得
具体。三处依据：

- 「头戴紫金冠，无忧鹤氅穿」
- 「相迎行者无兵器，止将玉麈手中捻」
- 「把袍袖迎风轻轻的一展，刷地前来，把四僧连马一袖子笼住」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 镇元子（本相） | 头戴紫金冠，穿无忧鹤氅；脚穿履鞋，丝带束腰；体如童子貌，面似美人颜；三缕须飘在颔下，鸦翎般黑发叠在鬓边；手无兵器，只捻一柄玉麈（再战时称“蝇帚”） | 现相诗 |
| 孙悟空 | 手执铁棒，“没高没低”乱打；顶上戴箍（自述）；毛脸雷公嘴（童子语）；虎裙、直裰本回未重写 | 交战段；童子语 |
| 唐僧师徒 | 唐僧倚松根坐，沙僧歇了担子打盹，八戒枕着石睡觉；白马在旁。衣冠本回未写 | 树下段 |

## 器物与环境

- 地点：路旁树林上空；师徒一夜只走了一百二十里，大仙一纵赶过九百余里。
- 时间：天明之后；天气原文未写，大仙踏祥光上天。
- 玉麈：麈尾类，明代小说中多指玉柄的拂尘式麈尾；袖：手摸是软的，钉钯筑上去比铁还硬。
- 悟空铁棒：两头金裹，所以敲人参树即落果。
- 现实中会动的：① 迎风鼓起的袍袖；② 流动的祥云；③ 玉麈毛、颔下三缕须与丝带。

## 排除项

- 变成百衲袍、吕公绦、手摇麈尾、轻敲渔鼓的行脚全真是空中现相之前的伪装；
  半空是紫金冠鹤氅本相。
- 原文只写玉麈、麈尾、蝇帚，不称拂尘，也无宝剑、权杖；“地书”“乾坤袋”是后世网文设定，
  袖里乾坤只用袍袖。
- 镇元子原文是童子貌、三缕须、乌发，不画白发白须老翁；“地仙之祖”之称见第26回，
  本回称大仙、与世同君。
- 清风、明月已先回观；七星鞭、布裹漆身、油锅、石狮子、柳树变身均是前后段，不入画。
- 袖笼的是四僧连马，不是只笼唐僧；悟空此刻尚未被缚。
