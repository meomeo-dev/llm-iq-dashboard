# 《西游记》第24回 万寿山大仙留故友　五庄观行者窃人参

底本：<https://zh.wikisource.org/wiki/西遊記/第024回>；读取日期：2026-10-19。

## 情节要点

1. 悟空等救下被绳绷在树上的八戒，前行见万寿山五庄观；观主镇元子赴弥罗宫听讲，留清风、
   明月看家。
2. 二童遵嘱敲两颗人参果款待唐僧，唐僧见其似婴孩，不敢吃，二童自食。
3. 八戒在厨房隔墙听见，流涎，央悟空去偷；第一颗敲落即入土，土地解说“遇金而落…遇土而入”。
4. 悟空再上树，一手使金击子，一手扯直裰襟作兜，得三果，三人各吃一个，八戒囫囵吞下。
5. 二童查数少了四个，到殿上辱骂唐僧；师徒被叫上殿，下回续。

## 选定场面

沿用已有题面的场面：人参园中，悟空攀上树，一手持金击子敲果，一手扯起直裰襟兜接。
园中只有悟空一人，八戒在厨房。一人一树，果子形态与动作原文都具体。三处依据：

- 「一只手使击子，一只手将锦布直裰的襟儿扯起来做个兜子等住」
- 「手脚乱动，点头幌脑，风过处似乎有声」（写枝头的果子）
- 「那叶儿却似芭蕉模样，直上去有千尺余高」

## 器物与环境

- 人参树：花园、菜园之后又一层门内；青枝绿叶，叶似芭蕉，高千尺余，根下围圆七八丈；
  果在向南的枝上。
- 人参果：状如三朝未满的婴孩，四肢五官俱全，尾间有蒂丁在枝头；遇金而落，落地即入土，
  故须兜接。
- 金击子：赤金长二尺，粗如手指，底端蒜头状，上有孔系绿绒绳，不是锤。
- 时间天气：原文未写；会动的：① 枝头果子手脚与头；② 芭蕉状叶片随风摆；③ 金击子的绿绒绳。

## 排除项

- 八戒、沙僧在厨房，清风、明月在殿上陪唐僧，土地要等第一颗果子失落后才被唤出；
  园中不画他们。
- 不画金箍棒敲果（棒打推树是第25回）；不画果子落地——第一颗落地即不见。
- 悟空共取四果：一颗入土，三颗入襟；树上此后余二十二个，树完好，推倒在下回。
- 镇元子此时不在观中；人参果不是人参根，也不是蟠桃。

## 现有题面核对

对象：第24回静态与动态题面。五庄观、后园古树、婴孩状果子、芭蕉叶、悟空撩襟兜果均有依据。
有误、无据或含后世说法之处如下：

- “金色的小锤”（静）与“金锤”“敲击果蒂”（动）：有误。金击子是二尺长的赤金细棍，不是锤；
  原文只写敲一下果子即落，未写敲果蒂。
- 树下的八戒探头探脑张望（静、动）：有误。八戒在厨房做饭，伸头探脑与流涎都在锅门前，
  时间在悟空动身之前，并未到树下。
- 头戴金箍、腰围虎皮裙：本回正文未写，见第14、20回，不与本回矛盾；本回明写的是锦布直裰。
- “高耸入云”：夸饰；原文是千尺余高、围圆七八丈。
- 动态“人参果随之左右摇荡下坠”：果子在枝头确会手脚乱动、点头幌脑，但被敲即落、落地入土，
  只可写到兜接前一瞬。
- 叶片“微风拂动”：有据（风过处果似有声）；“宽大”二字原文未写，只写似芭蕉。
