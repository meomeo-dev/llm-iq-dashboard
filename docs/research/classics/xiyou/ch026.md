# 《西游记》第26回 孙悟空三岛求方　观世音甘泉活树

底本：<https://zh.wikisource.org/wiki/西遊記/第026回>；读取日期：2026-10-19。

## 情节要点

1. 悟空向镇元子担保医活人参果树，唐僧给三日之限；悟空急整虎皮裙，驾筋斗云直上东洋大海。
2. 悟空先后访蓬莱三星、方丈东华帝君、瀛洲九老，皆答人参果树乃先天灵根，无方可医。
3. 悟空转到落伽山求观音。观音说净瓶底的甘露善治仙树灵苗，手托净瓶、白鹦哥前导，随悟空去五庄观。
4. 园中观音用杨柳枝蘸甘露，在悟空左手心画符；悟空握拳按树根得清泉，以玉盏舀出，扶正树后由观音洒水念咒。
5. 树复青绿，结二十三个人参果；观音、三星等赴人参果会，镇元子与悟空结拜。

## 选定场面

五庄观后园，观音用杨柳枝蘸净瓶甘露洒向已扶正的人参果树，悟空捧玉盏、八戒沙僧扶树。
取救树的一瞬：观音形象一眼可辨，净瓶、杨柳枝、玉盏、巨树各自有据，具名角色恰为四个，
并避开前面的追打与后面的宴席。三处依据：

- 「行者、八戒、沙僧扛起树来，扶得周正，拥上土」
- 「菩萨将杨柳枝细细洒上，口中又念着经咒」
- 「见那树果然依旧青绿叶阴森，上有二十三个人参果」

## 器物与环境

- 地点：万寿山五庄观后园。人参树居园中，叶似芭蕉，高千尺余，根下七八丈围圆（第24回），
  体量夸张，入画只需突出高大。时间天气原文未写。
- 器物：净瓶（甘露）、杨柳枝、白鹦哥（前导，园中是否在场未写）、树根下的清泉一汪；
  盛水用的是玉茶盏、玉酒盏（菩萨先说玉瓢，观里只有盏），二三十个茶盏、四五十个酒盏。
- 现实中会动的：① 柳枝洒出的甘露水珠；② 树根下涌出的清泉与玉盏中的水面；
  ③ 杨柳枝垂条与受水后舒展的枝叶（原文“叶长芽生，枝青果出”）。

## 排除项

- 悟空不戴凤翅紫金冠、不披黄金甲、不穿步云履：那是大闹天宫时的装束（第6回）。
- 观音本回无莲台、千手千眼；木吒、龙女留在紫竹林（“看守林中”），不随行。
- 洒水用杨柳枝蘸甘露，不是自瓶口倾倒；泉水不得盛于金、木、水、火、土之器，须玉器。
- 人参果形如三朝未满的婴孩，四肢五官齐全（第24回）；树上现有二十三个，不是三十个。
- 镇元子、唐僧、三星同在园中观看，属远景；八戒戏寿星在殿上，不在园中。
- 白龙马、乌巢禅师不在场；清风明月二童在园中数果，属配角，不入画。
