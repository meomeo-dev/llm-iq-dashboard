# 《西游记》第68回 朱紫国唐僧论前世　孙行者施为三折肱

底本：<https://zh.wikisource.org/wiki/西遊記/第068回>；读取日期：2026-10-19。

## 情节要点

1. 师徒洗净稀柿衕的污秽，值炎天到朱紫国；街上人争看三个徒弟的相貌，顽童抛瓦砖戏弄八戒，
   四人暂歇会同馆。
2. 唐僧入朝倒换关文，国王面黄肌瘦、形脱神衰；唐僧讲唐朝由来与魏征梦斩龙王的前事。
3. 悟空领八戒上街买调料，在鼓楼下见招医皇榜；他念咒使隐身法揭榜，吹出旋风吹散人群，
   把榜文折好揣进背对人群、嘴拄墙根的八戒怀里，自己先回馆。
4. 太监校尉发现榜不见了，见八戒怀里露出纸边，扯住不放；八戒立定如生根，供出师兄，
   众人拥到会同馆；悟空先赖后认，要国王亲来请。
5. 群臣到馆参拜，悟空端坐不动；入朝后国王见他相貌吓倒，悟空说自己会悬丝诊脉，
   拔三根毫毛变作金线。

## 选定场面

鼓楼下街边，八戒嘴拄墙根，怀里露出皇榜一角，被几个校尉、太监围住拉扯，他却立定如生根，
十来个人拉不动。具名角色只八戒一位，另有校尉、太监与围观百姓为群像；悟空已离开，不入画。
滑稽而无血腥，构图靠“拉扯与不动”成立。三处依据：

- 「把嘴拄着墙根，背着脸，死也不动」
- 「忽见猪八戒怀中露出个纸边儿来」
- 「这呆子立定脚，就如生了根一般，十来个人也弄他不动」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 八戒 | 黑脸，长嘴（“莲蓬嘴”），大耳，嘴一撅能吓倒人；身体粗壮，立定后纹丝不动。此时空手：碗盏已交悟空，钉钯在会同馆行李旁。衣色本回未写，前一回写皂直裰，兜底：暗青色直裰 | 街市段；鼓楼段；第18、67回 |
| 校尉、太监 | 太监是司礼监内臣，其中两位年老；校尉是锦衣校尉，原文称各十二名，到场数人。衣冠原著未写，兜底：太监圆领袍、戴帽，校尉短袍、戴巾帽，不画飞鱼服、绣春刀等影视锦衣卫造型 | 鼓楼段；会同馆段 |
| 围观百姓 | 街上“人物轩昂，衣冠齐整”，兜底：中原式短衣长袍，不画异域服饰 | 入城段 |

## 器物与环境

- 地点：朱紫国街市鼓楼下，皇榜张挂在楼下，榜上长文不入画；榜纸颜色、榜架形制原著未写，
  兜底：一张白纸黑字的榜，一角从八戒怀里露出。
- 街市：酒店、米铺、磨坊、绫罗杂货、茶房、面店、饭店；城头杏黄旗写“朱紫国”，不入画。
- 时令：开篇诗写海榴、荷叶、绿杨乳燕、行人摇扇避暑，值炎天。榜“才挂不上三个时辰”，
  具体时辰原文未写，兜底：白天。
- 风：旋风是悟空吹出，已在风过之后，不画旋风。
- 现实中会动的：① 校尉衣袍下摆与太监帽带随拉扯摆动；② 榜纸露出的一角被风吹得翻动；
  ③ 街边酒旗与行人手里的摇扇。

## 排除项

- 悟空隐身揭榜、吹旋风吹散人群是前一瞬，场面里悟空不在，不画隐形的悟空，也不画他躲在人堆里。
- 唐僧在朝、沙僧在馆，均不入画；八戒不持钉钯，不扯破榜文，不被拖行，也不坐地。
- 八戒称呼太监“奶奶”的玩笑不入画。
- 朱紫国不画成西域或异域风格；会同馆是官办驿馆，与翻译机构四夷馆是两个机构，本场面不画。
- 皇榜上的文字不要求可读。
- 86版第20集《孙猴巧行医》覆盖第68–71回，本场面在剧中如何处理未核对，不沿用影视造型。
  早期影视的黑猪八戒与白净短鼻的86版八戒，都不作本回依据，以底本“黑脸长嘴大耳”为准。
