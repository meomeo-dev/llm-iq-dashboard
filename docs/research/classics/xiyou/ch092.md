# 《西游记》第92回 三僧大战青龙山　四星挟捉犀牛怪

底本：<https://zh.wikisource.org/wiki/西遊記/第092回>；读取日期：2026-10-19。

## 情节要点

1. 悟空带八戒、沙僧夜至玄英洞口，变火焰虫飞进洞，见唐僧锁在后房檐柱上哭；解锁欲出，
   撞上巡更小妖，打死两个后冲出洞。
2. 八戒一钯筑碎石门，三妖披挂出战，三僧对三妖斗多时；群牛精绊倒八戒、擒走沙僧，悟空
   脱身。
3. 悟空上天求救，太白金星认出三妖是犀牛精，玉帝派斗牛宫的角木蛟、斗木獬、奎木狼、
   井木犴四木禽星下界。
4. 四星一到，三妖与小妖现出本相逃散；斗、奎二星扫洞救出唐僧，八戒、沙僧焚洞；悟空
   与井、角二星追入西海，龙王父子协擒（此段有妖被咬死、斩首、锯角，不入画）。
5. 犀角分献玉帝、府堂、灵山；府官免去灯油，师徒趁夜走脱。

## 选定场面

玄英洞口，夜里三更，月明如昼。八戒举钯一筑，把两扇石门筑得粉碎，碎石飞溅，门内牛头
小妖滚着往里逃；悟空、沙僧立在两侧，准备迎战。取“三僧大战”开场的出手瞬间：三僧对三妖
同框会超过具名上限，后续擒妖又带血，故不取。具名角色悟空、八戒、沙僧，另加牛头小妖群像。
三处依据：

- 「那呆子卖弄神通，举钯尽力筑去，把那石门筑得粉碎」
- 「此时约有三更时候，半天中月明如昼」
- 「偷油的贼怪！快送吾师出来也」

## 器物与环境

- 地点：青龙山玄英洞口，涧边石崖下一座石屋，两扇石门，门旁石碣刻六字洞名（第91回）。
  山在金平府东北，藤萝悬壁、松柏挺岩，有杜鹃黄莺（第91回山景）。
- 时间天气：正月十六夜（推算：十五夜唐僧被摄，悟空天明追到，斗到傍晚回寺，夜里复来；
  原文未直写日期），三更，月明如昼。
- 兵器：悟空铁棒、八戒九齿钉钯、沙僧降妖宝杖；门被筑破，碎石与烟尘四溅。
- 现实中会动的：① 石门碎裂飞出的石块与扬起的烟尘；② 涧水与崖上藤蔓、松枝；③ 三人
  衣摆、虎皮裙边与门内小妖枪上缨穗被气浪带起。

## 排除项

- 三妖王现身与对打、四木禽星、犀牛本相、太白金星、西海龙王、井木犴咬死、八戒砍头、
  锯角，都在其后，不入画；画面不出现血迹、断首、犀角。
- 悟空变火焰虫入洞、唐僧锁在檐柱、打死两个巡更小妖，在筑门之前，不入画。
- 八戒的戒刀是后文砍头所用，此刻不出现；悟空此刻不是火焰虫，也不使变化。
- 小妖是牛头鬼形，不画成犀牛；犀牛有“二角”，本场面不出现。
- 三徒直裰已是第90回新做的锦布直裰，不沿用八戒皂锦、沙僧黄锦的旧阶段说法。
- 1999年《西游记续集·观灯金平府》的犀牛精造型与西海三公主等原创内容，不沿用。
- 不画白天；不要求画面写出石碣上的洞名。
