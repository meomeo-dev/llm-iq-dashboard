# 《西游记》第13回 陷虎穴金星解厄　双叉岭伯钦留僧

底本：<https://zh.wikisource.org/wiki/西遊記/第013回>；读取日期：2026-10-19。

## 情节要点

1. 贞观十三年九月望前三日，唐王送玄奘出长安；一二日到法门寺，再经巩州、河州卫出边界。
2. 鸡鸣即行，起得太早，在双叉岭失足坠入坑中，寅将军（虎精）擒住三藏与两名从者；
   熊山君、特处士来访，两名从者被吃。
3. 天明，太白金星化老叟拂断绳索，指点行李马匹，化清风跨朱顶白鹤而去，留下简帖。
4. 三藏孤身上岭，被虎蛇围困；猎户刘伯钦赶到，群兽退走，他又以钢叉与一只斑斓虎相斗。
5. 在刘家留宿，三藏为伯钦亡父诵经超度，全家夜梦先人托生富贵之家。
6. 伯钦送到两界山半山而止，山脚传来「我师父来也」的喊声。

## 选定场面

刘伯钦叉斗斑斓虎：伯钦喝着「那业畜那里走」赶上去，虎转身抡爪扑来，伯钦举叉迎敌；
三藏坐在一旁吓得瘫软。辨识度高（回目点名「伯钦」），原文有现成的交手赋体，
可只画对峙的一瞬，不画叉穿虎心的结果。具名角色两个：刘伯钦、三藏，另有一虎。依据三处原文：

- 「头上戴一顶艾叶花斑豹皮帽」（伯钦出场）
- 「那虎见赶得急，转身抡爪扑来」
- 「这太保三股叉举手迎敌」

备选：太白金星化老叟解厄，化清风跨朱顶白鹤而去（装束与动势俱有原文，但人物只有金星与三藏）。

## 器物与环境

- 兵器：点钢三股叉（文中亦称钢叉）；弓箭毒药一囊；伯钦家墙上另有强弓硬弩，不在山坡。
- 地理：双叉岭是虎狼巢穴，在河州卫外；打虎在过了山坡之处，伯钦的草门楼山庄在其后。
- 时令：九月（出发写「季秋」），沿途木落、枫杨红叶坠，伯钦后园菊蕊堆黄；打虎时间在上岭后半日。
- 现实中会动的：① 狂风卷起的红尘；② 秋叶与草梢；③ 虎尾摆动。

## 排除项

- 寅将军、熊山君、特处士和太白金星属前一夜与清晨，不入画；伯钦所斗是寻常虎，不是寅将军。
- 悟空（第14回才出山）、白龙马与鞍辔（第15回）、金箍均不在场；两名从者已被吃，不画。
- 伯钦用三股钢叉与弓箭，不画成哨棒；他的母亲、妻子与「怪形恶相」的家僮在庄内，不在山坡。
- 虎被叉穿心、血流满地是结果，不画；只取交手一瞬。
- 两界山与石匣属本回末及第14回。
