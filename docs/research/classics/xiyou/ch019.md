# 《西游记》第19回 云栈洞悟空收八戒　浮屠山玄奘受心经

底本：<https://zh.wikisource.org/wiki/西遊記/第019回>；读取日期：2026-10-19。

## 情节要点

1. 悟空追妖精到福陵山云栈洞，妖精取九齿钉钯迎战，自报天蓬元帅下界，俗名猪刚鬣。
2. 悟空二打洞门，妖精说出受观音劝善、等候取经人，依令烧了洞府，被反绑揪耳带回高老庄。
3. 妖精拜唐僧为师，法名悟能；唐僧又为他戒荤起别名八戒。高老送金银不受，八戒讨了新鞋和褊衫。
4. 师徒西行：唐僧骑马，八戒担行李，悟空肩扛铁棒引路，过乌斯藏界，到浮屠山。
5. 乌巢禅师传《多心经》并说西行路径；悟空恼其言语，举棒捣巢，被莲花祥雾所阻。

## 选定场面

浮屠山树下：唐僧下马奉拜，乌巢禅师跳下树来搀扶，八戒、悟空侍立。原文对居所与周遭
鸟兽写得具体，禅师授经的一瞬静中有动。备选场面是云栈洞半山夜战（金箍棒对九齿钉钯）和
八戒反绑跪拜唐僧。依据三处原文：

- 「见香桧树前有一柴草窝，左边有麋鹿衔花，右边有山猴献果」
- 「树梢头有青鸾、彩凤齐鸣，玄鹤、锦鸡咸集」
- 「那禅师见他三众前来，即便离了巢穴，跳下树来」

## 器物与环境

- 山景：山南青松碧桧、山北绿柳红桃；山禽对语、仙鹤齐飞；诸花千样色；
  涧下绿水滔滔，崖前祥云朵朵。时节未写，白昼。
- 居所：香桧树前的柴草窝，禅师须“跳下树”，可知窝架在树上；左麋鹿、右山猴，树梢禽鸟聚集。
- 道具：白马与缰绳、八戒的行李担、悟空的铁棒；禅师所传《多心经》为口诵，无经卷。
- 现实中会动的：① 涧水奔流；② 崖前祥云飘移；③ 青鸾彩凤、仙鹤振翅，禅师衣袂随下树飘起。

## 排除项

- 沙僧第22回才入伙；禅师偈语里提到水怪的那一句只是预言，不入画。
- 八戒的旧梭布直裰已在第18回被挣破，此时不得再穿；八戒之名是唐僧本回所起。
- 乌巢禅师的身份（有说观音、太阳星君、大日如来）都是后人推测，原文无光环、腰佩等细节。
- 悟空捣乌巢、莲花祥雾阻棒，以及禅师化金光上巢，均在传经之后，不入此一瞬。
- 《心经》经文不入画。原文称五十四句、共二百七十字，通行玄奘译本为260字，题面不写字数。
- 钉钯、云栈洞战斗、高老庄宴席属本回前半，不混入。
