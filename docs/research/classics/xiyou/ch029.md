# 《西游记》第29回 脱难江流来国土　承恩八戒转山林

底本：<https://zh.wikisource.org/wiki/西遊記/第029回>；读取日期：2026-10-19。

## 情节要点

1. 八戒沙僧与黄袍怪在洞外半空斗三十回合，有六丁六甲等暗中相助，不分胜负。
2. 洞内一个妇人扶着定魂桩开口，自报是宝象国第三公主百花羞，十三年前中秋夜被妖风摄来，生了两个妖儿。
3. 公主修书托唐僧捎往宝象国，亲手解缚；又借梦见金甲神讨誓愿，劝黄袍怪放僧，让唐僧由后门脱身。
4. 师徒到宝象国，国王读信落泪；八戒在殿前变得八九丈高，奉旨去降妖，沙僧随后助战。
5. 八戒战不过，钻进草丛躲藏，沙僧被黄袍怪擒进洞去。

## 选定场面

波月洞内定魂桩前，公主为唐僧解开绳索，把封固停当的家书递到他手中。回目“脱难江流来国土”
即指此事；两个角色、一根桩、一封信，动作单纯，构图好控制。三处依据：

- 「我是那国王的第三个公主，乳名叫做百花羞」
- 「到桩前解放了唐僧，将书付与」
- 「三藏紧紧袖了家书，谢了公主，就往外走」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |

| 唐僧 | 被绳缠索绑在定魂桩上；获释后磕头称谢；斗笠、锡杖留在林中（第28回），衣着未写；将书袖入袖中 | 第28回；本回解缚段 |

## 器物与环境

- 地点：碗子山波月洞。洞门上横安白玉石板，镌“碗子山波月洞”，入口挂斑竹帘，洞内有石床与定魂桩；
  前门外小妖摇旗擂鼓助战，后门外是荆棘丛。灯火、石壁、桩的形制原文均未写。
- 时间：第28回写日暮林深，本场面是同一傍晚的洞内；洞外半空正在厮杀。
- 器物：定魂桩、绳索、一纸家书（封固停当）。
- 现实中会动的：① 解开后垂落的绳索；② 公主衣袖与递出的家书；
  ③ 洞口斑竹帘随气流轻摆（帘见第28回，摆动是常理推断，原文未写）。

## 排除项

- 公主前世是披香殿侍香玉女、黄袍怪是奎木狼，均第31回才说破；本回只称“妖魔”“黄袍郎”。
- 黄袍怪此刻与八戒沙僧在洞外半空厮杀，不在洞内；公主劝放唐僧是解缚之后的事。
- 悟空已被逐，不在场；八戒殿前变大、沙僧被擒是后半回，不入此场面。
- 唐僧不走前门：公主指后门，他躲进荆棘丛等徒弟；“百花羞”是乳名，信末也署此名。
- 国王与文武在宝象国，不在洞中；白龙马与行李不入画。
