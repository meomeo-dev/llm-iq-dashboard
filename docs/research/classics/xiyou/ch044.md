# 《西游记》第44回 法身元运逢车力　心正妖邪度脊关

底本：<https://zh.wikisource.org/wiki/西遊記/第044回>；读取日期：2026-10-19。

## 情节要点

1. 师徒过黑水河，西行至早春，远处传来如千万人呐喊的响声；悟空腾云看见一座城，城外
   沙滩上许多和尚在拽装满砖瓦木料的车，齐喊号子。
2. 悟空变作云水全真，向城门口两个少年道士打听：此城叫车迟国，二十年前大旱，虎力、
   鹿力、羊力三位大仙求雨有功，国王崇道灭僧，把僧人赐给道士家做苦工。
3. 悟空到沙滩，众僧误认监工跪倒；听众僧诉苦后，他回头打死两个道士，摔碎车辆，
   拔毫毛嚼碎，每个和尚发一截作护身。
4. 唐僧入城，宿智渊寺；夜半悟空见三清观道士禳星，吹风灭灯，带八戒、沙僧闯三清殿，
   变作三清吃供品，八戒把三清像丢进茅厕，小道士寻铃撞破。

## 选定场面

车迟国城外白昼：沙滩坡道上，五百僧众拽着堆满砖瓦木料的车爬向夹脊小路与两座大关；城门口
两个少年道士摇摇摆摆走来，僧众更加用力；悟空变作云水全真，左臂挂水火篮、手敲渔鼓，
迎着道士躬身问话。近景取悟空与道士相揖，远景取沙滩拽车。入画理由：拽车是回目所指的
“车力”“脊关”，僧众的窘迫与道士的光鲜对照鲜明。具名角色只有悟空一位，另有两位无名道士
与僧众群像。三处依据：

- 「那车子装的都是砖瓦、木植、土坯之类」
- 「虽是天色和暖，那些人却也衣衫蓝缕」
- 「左臂上挂着一个水火篮儿，手敲着渔鼓，口唱着道情词」

## 器物与环境

- 地点：车迟国城外一块沙滩空地；滩头上坡最高，有一道夹脊小路、两座大关，关下是直立
  壁陡的崖；城上祥光隐隐，城门有吊桥、三层门。
- 车：装砖瓦、木植、土坯。车制原著未写，兜底：木板双轮大车，车上堆砖瓦木料。
- 时令：早春，三阳转运，梅残数点雪，麦涨一川云，冰解山泉，杨柳舒青眼；天色和暖。
  时辰原文未写，入城时已太阳西坠，本图在此之前，兜底：白昼。
- 现实中会动的：① 拽车与行走扬起的沙尘；② 道士的锦绣衣袖与丝绦被春风吹动；③ 沙滩旁杨柳枝摇动、解冻山泉流淌。

## 排除项

- 三清殿变像偷供、八戒把三清像丢进茅厕，发生在当夜，并延续到第45回开头（撒溺留名）；
  本图是白昼，不画三清殿。
- 打死两个道士的头破血流不画；此刻悟空尚未取出铁棒。
- 唐僧、八戒、沙僧、白马在路旁等候，不入图。
- 虎力、鹿力、羊力三位大仙此段不出场，夜里才披法衣露面；沙滩上的是他们的徒弟。
- 车迟国是小说国名，一般认为取材于西域车师国；不画新疆实景或交河城。
- 悟空此时是变形后的云水全真，不是平日的猴相打扮；不画金箍棒与虎皮裙。
