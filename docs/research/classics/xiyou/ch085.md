# 《西游记》第85回 心猿妒木母　魔主计吞禅

底本：<https://zh.wikisource.org/wiki/西遊記/第085回>；读取日期：2026-10-19。

## 情节要点

1. 灭法国君臣光头上朝，国王把关文倒换后改国名为钦法国，送师徒西行。
2. 前面高山阻路，唐僧觉得心惊；悟空念四句“灵山只在汝心头”的颂子宽慰他，自己上半空
   看见悬崖边坐着一个妖精，身旁三四十个小妖正喷风嗳雾。
3. 悟空想让八戒先与妖精交手，谎称风雾是前村蒸饭斋僧的炊气，哄八戒去“化斋”；八戒变成
   矮瘦和尚，敲着木鱼走进小妖在路口摆的圈子阵，被围住扯拽，现出原身用钉钯筑退小妖。
4. 老妖亲自来战八戒，悟空暗中现身相助，老妖败回洞中；小妖献“分瓣梅花计”，选三个小妖
   变成老妖的样子，分别拖住三个徒弟，老妖在半空伸手抓走了唐僧，绑在后园树上。

## 选定场面

高山脚下的大路口，山势崔嵬，风雾已收、天色明净。八戒变成矮瘦和尚，一手托木鱼、一手敲槌，
嘴里哼着“上大人”，走进小妖围成的圈子；小妖们你扯衣服、他扯丝绦，推推拥拥。具名角色
一位：八戒（变化后），另有小妖群像；老妖、悟空、唐僧、沙僧不入画。八戒装模作样与小妖
扯作一团，喜剧而无血腥，也避开他现原身后的打斗。三处依据：

- 「变做个矮瘦和尚。手里敲个木鱼，口里哼阿哼的，又不会念经，只哼的是『上大人』」
- 「那怪物收风敛雾，号令群妖，在于大路口上，摆开一个圈子阵，专等行客」
- 「被群妖围住，这个扯住衣服，那个扯着丝绦，推推拥拥，一齐下手」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 猪八戒（变化后） | 矮瘦的和尚（个别整理本作“矮胖”，以底本为准），人形，不显长嘴大耳；手敲木鱼；衣着未写，只写小妖“扯住衣服”“扯着丝绦”，兜底：素色直裰，腰系丝绦，光头；钉钯此时藏在腰间（随后才“腰间掣钉钯”），不画在手中 | 本回 |
| 群妖 | 路口摆圈子阵，围住行客；崖边原有三四十个，画六至十个围成半圈即可；形貌原著未写，只称“山中得道的妖仙”，兜底：兽面人身的山野小妖，粗布短衣、各色不一，不披甲、不拿杵 | 本回 |
| 老妖、悟空、唐僧、沙僧 | 老妖听报后才执铁杵赶来；悟空等三人留在山下，不入画 | 本回 |

## 器物与环境

- 地点：高山路口，山势“崔巍”，松千干、竹几竿，怪石、峰岩，藤萝牵扯，溪涧生瑶草、香兰；
  路边是大路口，路面平坦。山名“隐雾山”要到第86回才点明，本回不写。
- 时间天气：国王早朝后辞行上路，白天；妖精已“收风敛雾”，风雾明净。季节承第84回为夏，
  本回未直写，不强加。
- 木鱼：原文“手里敲个木鱼”，形制未写，兜底：中空的圆形鱼纹木鱼，一手托着，一手持小
  木槌敲击；不画悬挂的长条鱼梆。
- “上大人”是旧时蒙童习字的字句，不是经文；只作口中哼唱，画面不写出字。
- 现实中会动的：① 山顶飘荡的云气；② 松竹枝叶与路边长草在微风里摆动；③ 木鱼槌的一下
  一下敲落，以及被扯动的衣襟与丝绦。

## 排除项

- 老妖（南山大王）不入画：他此刻不在圈中，听小妖报信后才执铁杵出来；本回诗里的獠牙
  利爪是悟空半空中看到的远景。豹子精的身份、南山大王名号、隐雾山折岳连环洞，都在第
  86回才点明，题面与评判标准不写。
- 八戒现出原身、掣钉钯乱筑，是下一刻，不入画；悟空在唐僧身后、毫毛变替身，也不入画。
- 小妖说“上蒸笼蒸熟吃”只是台词，不画蒸笼，也不画吃人。
- “分瓣梅花计”的三个假老妖、拿云手抓唐僧、后园树上绑着的樵子，都在后文。
- 不要把本回的“矮瘦和尚”与第82回的“黑胖和尚”混画；小妖也不是第86回里的锦绣花旗、
  铁背苍狼怪先锋。
- 央视版续集第12集《泪洒隐雾山》演豹子精一段，造型资料不全，不沿用。
