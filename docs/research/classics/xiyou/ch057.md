# 《西游记》第57回 真行者落伽山诉苦　假猴王水帘洞誊文

底本：<https://zh.wikisource.org/wiki/西遊記/第057回>；读取日期：2026-10-19。

## 情节要点

1. 悟空被逐后无处可去，回到唐僧马前求恕，又被念咒二十余遍，转往落伽山向观音
   诉苦；观音说本无松箍儿咒，留他在莲台下侍立。
2. 唐僧饥渴，遣八戒取水化斋，沙僧继去催水；“孙行者”（实为假的）捧磁杯献水，
   被拒后发怒，一棒打昏唐僧，抢走两个青毡包袱。
3. 八戒变食痨病黄胖和尚化得冷饭；二人救醒唐僧，沙僧驾云三昼夜去花果山讨包袱。
4. 沙僧在水帘洞见另一个“孙行者”高坐石台念通关文牒，称要自己取经；牵出假唐僧、
   假八戒、假沙僧，沙僧一杖打死假沙僧，被群猴围攻，逃往落伽山。
5. 沙僧在观音台下见到真悟空，举杖便打；观音令二人同往花果山辨真假。

## 选定场面

花果山水帘洞外，假悟空高坐石台，双手扯着一张纸朗读通关文牒；沙僧近前厉声质问，
假悟空抬头，群猴围拢。一纸文牒、一座石台、一群猴，不打斗，却点出“真假难辨”
的由头；具名角色只有假悟空与沙僧。三处依据：

- 「原来是孙行者高坐石台之上，双手扯着一张纸，朗朗的念道」
- 「师兄，师父的关文你念他怎的」
- 「众猴一齐围绕，把沙僧拖拖扯扯，拿近前来」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 假悟空 | 模样与真悟空一模一样：黄发、金箍、金睛火眼，绵布直裰，腰系虎皮裙，足踏麂皮靴，毛脸雷公嘴（此段全貌见第58回）。此刻“高坐”“双手扯着一张纸”，铁棒放在何处原文未写（后文才“抡金箍棒”），兜底：棒靠在石台边 | 开场段；第58回 |
| 沙僧 | 光头（第22回落发）、蓝靛脸、黄锦直裰，兵器降妖宝杖；项下骷髅已在第22回解化为阴风，不再挂。此刻“近前厉声高叫”，被拖到近前才“朝上行礼”；杖是否在手未写，兜底：杖持于手边 | 第22回；赴洞段 |
| 群猴 | “无数猴精”滔滔乱嚷，围绕拖扯沙僧；衣冠未写，兜底：寻常猕猴，不着衣甲 | 洞前段 |

## 器物与环境

- 地点：东胜神洲花果山水帘洞外，“高峰排戟，峻壁悬屏”，石台在洞前。水帘洞是遮
  挂洞门的瀑布（第1回、第58回），本回未写；可作背景，但不画成寻常洞口。
- 时令：承第56回端阳后（夏），本回未写季节与时刻；沙僧在云上飞了三昼夜才到。
- 器物：一张纸（通关文牒，第12回写成时用了通行宝印；牒上字迹以示意线条表现，
  不要求画出可辨认的文字）、石台。
- 现实中会动的：① 水帘洞瀑布的水流与水雾；② 假悟空手中纸页边缘、衣带与虎皮裙
  被山风吹动；③ 峰间云气与山上松枝。

## 排除项

- 假唐僧、假八戒、假沙僧和白马，是沙僧被拖到近前、假悟空发话后才由群猴牵出，
  不入图；沙僧一杖打死假沙僧、群猴围攻、剥皮煎炒、椰子酒葡萄酒均在后段。
- 真悟空此刻在落伽山；观音、木叉、善财、白鹦哥不入图；磁杯打唐僧、八戒变黄胖
  和尚是前段。
- 假悟空的真身六耳猕猴之名第58回如来才点出，本回只称“孙行者”“妖精”；外形与
  悟空相同，不加六耳或任何可分辨的标记。
- 石台上不画酒食器皿：“与群猴饮酒作乐”是第58回悟空与沙僧到时的画面。
