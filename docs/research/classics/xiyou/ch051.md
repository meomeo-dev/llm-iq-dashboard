# 《西游记》第51回 心猿空用千般计　水火无功难炼魔

底本：<https://zh.wikisource.org/wiki/西遊記/第051回>；读取日期：2026-10-19。

## 情节要点

1. 悟空空手败阵，疑是天上凶星思凡，上天查勘，诸天星宿无一下界；玉帝命他点将，
   悟空只请托塔李天王、哪吒与邓、张二雷公。
2. 哪吒出阵，变三头六臂，抛出六般兵器；魔王也变三头六臂，抛圈子将兵器尽数套走。
3. 火德星君放火，火具被套；黄河水伯以白玉盂倾水，水漫四野，没有灌进洞里。
4. 悟空与魔王走拳，又使毫毛分身，小猴也被圈子收回本相。
5. 悟空变麻苍蝇入洞，见火龙火马吊在后厅，金箍棒靠在东壁，现原身取棒打出洞门。

## 选定场面

金兜洞口，哪吒变三头六臂将六般兵器抛上半空，魔王同样三头六臂，一手抛起白森森的圈子，
要把漫天兵器套下。具名角色三位：哪吒、魔王、山坡上空手的悟空，另有云端二雷公为群像。
两个三头六臂的对垒与空中的圈子构成画面中心，出手瞬间明确，没有血腥结果。三处依据：

- 「将身一变，变作三头六臂，手持六般兵器，望妖魔砍来」
- 「一只手取出那白森森的圈子来，望空抛起」
- 「唿喇的一下，把六般兵器套将下来」

## 器物与环境

- 地点：金兜山金兜洞。洞门紧闭，崖下无精；两扇石门（第52回写被火气化灰）。
- 六般兵器：砍妖剑（前文称斩妖剑）、斩妖刀、缚妖索、降魔杵、绣球、火轮儿，一变十、百、千、万，
  如骤雨冰雹。火轮儿是抛出的兵器，不是脚踏的风火轮。
- 圈子：本回只写“白森森”，第50回写“亮灼灼白森森”，取出后抛空套物；第52回才写形如连珠镯，
  并揭晓是老君的金刚琢。
- 时令：原文未写季节与时辰。
- 现实中会动的：① 抛起后落向圈内的兵器；② 火轮儿的火焰与蟒形的缚妖索（第4回“如飞蟒”）；③ 雷公脚下的云气。

## 排除项

- 乾坤圈、混天绫、脚踏风火轮、火尖枪、莲花化身、荷叶裙赤腿，均属《封神演义》与后世造型；
  原著本回哪吒全身披挂，六般兵器如上。
- 圈子的来历、“青牛”身份要到第52回；本回不写“金刚琢”“老君”。
- 李天王、火德星君、水伯留在山南坡下与高峰，不在洞口；水火两阵在后，本场面不出现。
- 悟空此刻无棒，不是三头六臂，也不使分身；变苍蝇、取棒在末段。
- 唐僧、八戒、沙僧缚在洞内，不入画。1986版电视剧未拍金兜山一段，没有可沿用的影视定型。
