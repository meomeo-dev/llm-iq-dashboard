# 《西游记》第47回 圣僧夜阻通天水　金木垂慈救小童

底本：<https://zh.wikisource.org/wiki/西遊記/第047回>；读取日期：2026-10-19。

## 情节要点

1. 国王醒悟，出招僧榜，智渊寺设宴酬谢；五百脱命僧来交还毫毛。师徒出城，转眼入秋，夜里被通天河拦住，
   岸边石碑刻“通天河”三个篆字，另有“径过八百里，亘古少人行”十个小字。
2. 循鼓钹声到陈家庄，悟空、八戒、沙僧闯进厅堂，吓散念经的和尚，被唐僧训斥后在陈家吃斋。
3. 兄陈澄、弟陈清说灵感大王每年要一童男一童女，今年轮到陈清之子关保（七岁）与陈澄之女一秤金（八岁），
   正做“预修亡斋”。
4. 悟空变成关保，逼八戒变成一秤金替祭，两人坐上红漆丹盘，由后生抬桌在天井里试抬；门外已锣鼓喧天来催。

## 选定场面

陈家宅内夜里，悟空变的男童与八戒变的女童各坐一个红漆丹盘，四个后生抬着两张桌子在天井里走走再抬回；
悟空欢喜，八戒忧惧，陈澄、陈清在旁含泪。丹盘、桌、女童衣饰色彩明确，两位神通者扮作孩童的反差一眼可见。
三处依据：

- 「用两个红漆丹盘，请二位坐在盘内，放在桌上」
- 「四个后生抬起两张桌子，往天井里走走儿，又抬回放在堂上」
- 「身上穿一件红闪黄的纻丝袄，上套着一件官绿缎子棋盘领的披风」

## 器物与环境

- 地点：车迟国元会县陈家庄陈氏宅（庄在通天河东岸），厅堂与天井；门外竖幢幡，厅内先前有灯烛香烟。
- 时间天气：夜晚，来路诗写半空皎月；季节为秋，次回明说七月且已交白露。
- 器物：红漆丹盘两个，桌两张；丹盘与桌的尺寸原文未写，兜底：盘径能容一个孩童端坐。
- 现实中会动的：① 灯烛与火把的火苗；② 门外幢幡随风飘动；③ 厅里升起的香烟。

## 排除项

- 悟空、八戒此刻是孩童模样，不画猴脸、猪嘴；钉钯要到次回在庙里现原形时才掣出。
- 真关保与一秤金已被带进内宅，不与替身同台；唐僧、沙僧留在厅中，不入这一幅。
- 抬到灵感庙、供桌牌位、祭词、妖怪现身都在次回；这一幕只在宅内试抬。
- 灵感大王的原形是金鱼，到第49回才揭晓；本回只写“不见其形，只闻一阵香风”。
- 唐僧本回写作摘斗笠、抖褊衫、拖锡杖，未写袈裟、毗卢帽。
- “预修亡斋”是为将献祭的孩子预先做的斋事，不是平安斋、了场斋。
