# 《西游记》第90回 师狮授受同归一　盗道缠禅静九灵

底本：<https://zh.wikisource.org/wiki/西遊記/第090回>；读取日期：2026-10-19。

## 情节要点

1. 玉华州城外，黄狮精与六只狮精围战三僧，八戒被打倒拖走，悟空以身外身擒狻猊、白泽。
   次日悟空又以分身打死黄狮精，九头狮子（九灵元圣）趁隙腾至城楼，用九张口噙走唐僧、
   八戒与玉华王父子。
2. 再次日悟空、沙僧上竹节山，也被噙进九曲盘桓洞，悟空遭柳棍打捶，夜里脱身，掗死三个
   看守小妖，丁甲神押来竹节山土地，说破九头狮是太乙救苦天尊的坐骑。
3. 悟空赴东极妙岩宫请天尊；狮奴偷饮「轮回琼液」醉睡，走失了狮子。天尊带狮奴与悟空
   到竹节山，悟空叫阵引出狮子，天尊一喝，狮子伏地磕头，狮奴揪住项毛教训，天尊骑狮
   回宫。
4. 悟空救出众人烧洞；王府设宴，兵器造成，师徒传艺后辞行，八戒等领新做的锦直裰上路。

## 选定场面

竹节山九曲盘桓洞外的崖前，九头狮子追悟空赶到崖前，被天尊念咒喝破：它认出主人，四脚
伏地磕头；狮奴从旁跑来，一把揪住狮子项毛，拳头举起，只画举拳，不画击打；悟空立在
高崖上笑。具名角色悟空、太乙救苦天尊、狮奴，另有九头狮子。三处依据：

- 「你还敢这等大胆无礼，你死活也不知哩，这不是你老爷主公在此？」
- 「那妖认得是主人，不敢展挣，四只脚伏之于地，只是磕头」
- 「傍边跑过狮奴儿，一把挝住项毛」

## 器物与环境

- 地点：竹节山九曲盘桓洞外高崖前。山景「峰排突兀，岭峻崎岖」，「深涧下潺湲水漱，
  陡崖前锦绣花香」；洞门是两扇花斑石门，门楣石版刻字，不画字。
- 时间天气：原文未直写；悟空约寅时到东天门，往返妙岩宫后下界，大致拂晓后。天气
  未写，按晴天画，不强加季节。
- 云：天尊与悟空「踏云」而来，可在崖边留一缕云气。
- 现实中会动的：① 崖边云气缓缓飘散；② 山涧流水；③ 狮颈鬃毛与人物衣带、虎皮裙边。

## 排除项

- 狮奴「用拳着项上打够百十」是紧接着的动作，本场面只画揪毛举拳；天尊骑狮腾云回宫
  是再后一瞬，不画。
- 九头狮子不是第63回的九头虫：后者是万圣龙王驸马，羽族，用月牙铲，被二郎神的细犬
  咬去一个头；九灵元圣九头完好，没有细犬，不缺头。
- 洞内唐僧、八戒、沙僧、玉华王父子被捆，不入画；黄狮精被打死剥皮、六只活狮被杀、
  三个小妖被掗成肉饼，均不入画，不画血。
- 本回前半的九头狮噙人、柳棍打悟空、土地与丁甲神都不入画；第91回的金平府不出现。
- 86版未拍九头狮原身，只演人形；传世神像多画一大头加八小头如项链，本回原文写九个头各有一口，
  不采用。天尊不画成冕旒帝王像（青华大帝）。
- 八戒、沙僧在洞里，此刻不在崖前；八戒新做的青、红、茶褐锦直裰是本回结尾之事。
