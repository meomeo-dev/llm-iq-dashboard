# 《西游记》第55回 色邪淫戏唐三藏　性正修持不坏身

底本：<https://zh.wikisource.org/wiki/西遊記/第055回>；读取日期：2026-10-19。

## 情节要点

1. 旋风摄走唐僧，悟空师徒追到毒敌山琵琶洞；悟空变蜜蜂入洞，见女怪以人肉馍馍、邓沙馍馍
   相待，唐僧答“水高船去急，沙陷马行迟”，悟空现身动手。
2. 女怪使三股钢叉，又用倒马毒扎伤悟空的头，次日扎伤八戒的嘴唇；夜里缠唐僧不从，将他绑在廊下。
3. 观音化挑菜老妇现鱼篮相，说女怪是扎过如来手指的蝎子精，须请昴日星官。
4. 星官摸吹治好悟空、八戒的伤；悟空、八戒引怪出洞，星官现公鸡本相鸣叫，蝎子精现形，
   再叫一声酥软倒地，被八戒钉钯捣烂。
5. 师徒进洞救出唐僧，放走被摄女子，放火烧洞，西行。

## 选定场面

毒敌山石屏后的山坡上，悟空喊“昴宿何在”，昴日星官现出双冠子大公鸡的本相，昂首向追来的女怪
叫了一声，女怪当即现出蝎子本相。具名角色四位：星官（鸡身）、蝎子精、悟空、八戒。公鸡与蝎子的
体量与形象反差强烈，现形是一个明确瞬间，不画死亡。三处依据：

- 「现出本相，原来是一只双冠子大公鸡，昂起头来，约有六七尺高，对着妖怪叫了一声」
- 「那怪即时就现了本相，原来是个琵琶来大小的一个蝎子精」
- 「他那三股叉是生成的两只钳脚」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 昴日星官 | 此刻是本相：双冠子大公鸡，约六七尺高（按明尺折算约两米，与人齐或略高），昂首鸣叫；赞诗写花冠、绣颈、爪硬距长、目怒睛。羽色原著未写，兜底：红冠，金褐配黑绿的常见公鸡羽色，头顶并列两个冠。人形时的朝衣金缕在光明宫，不用 | 现形段与赞诗；光明宫段 |
| 蝎子精 | 本相是“琵琶来大小”的蝎子；人形时的三股叉是自身两只钳脚，尾上钩子唤倒马毒。体色原著未写，兜底：暗褐色，一对大钳、四对步足、上卷的尾节带钩；此刻不再握叉 | 观音指点段；现形段 |
| 悟空 | 金箍、直裰、虎皮裙；手持铁棒；头上被扎处经星官摸吹，已不麻不痒；与八戒一同退到石屏后，回头看 | 治伤段；引怪段 |
| 八戒 | 黑脸短毛、长嘴大耳；本回写“束一束皂锦直裰”，即黑色直裰，以本回为准；手执钉钯；嘴唇伤已经星官治好，不肿 | 次日出战段；治伤段 |
| 沙僧 | 在山坡下守白马与行李，不具名，只作远处小点 | 治伤段 |

## 器物与环境

- 地点：毒敌山。石屏青石光明，似个屏风；屏后两扇石门，门上六个大字“毒敌山琵琶洞”，
  门已被八戒筑碎。女怪是赶过石屏追悟空、八戒到山坡上的。
- 兵器：悟空铁棒，八戒钉钯；女怪的三股叉本相时即钳脚。
- 时令：夜后天明，事在次日；季节与天色原文未写。
- 现实中会动的：① 啼鸣时公鸡颈羽、尾羽的颤动与张开的喙；② 蝎子的尾钩与钳脚；
  ③ 山坡草丛与被震起的尘土。

## 排除项

- 原文称“蝎子精”，无“琵琶精”；“琵琶”只是洞名与体型比喻，不画弹琵琶、抱琵琶的美人（影视改编）。
- 第二声之后蝎子精“浑身酥软，死在坡前”与八戒捣烂是后续，不画；本场面只到现形。
- 星官此刻是公鸡，不画人形，不画半人半鸡；朝衣金缕是他在光明宫迎接悟空时的样子。
- 唐僧被绑在洞内，不在场；观音鱼篮现身、如来被扎指是前情，不入画。
- 悟空的头与八戒的嘴已愈，不画抱头、捂嘴；八戒衣色用皂（黑），不沿用第19回的青锦。
