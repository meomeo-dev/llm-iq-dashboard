# 《西游记》第60回 牛魔王罢战赴华筵　孙行者二调芭蕉扇

底本：<https://zh.wikisource.org/wiki/西遊記/第060回>；读取日期：2026-10-19。

## 情节要点

1. 土地说火焰山是五百年前悟空蹬倒老君炉、落下炉砖所化；要借真扇须找“大力王”牛魔王，
   他已弃罗刹女，入赘积雷山摩云洞的玉面公主。
2. 悟空在积雷山吓走玉面公主，与出洞的牛魔王论旧、斗棍百十回合不分胜负；有人来请
   赴宴，牛魔王骑辟水金睛兽往乱石山碧波潭去。
3. 悟空变螃蟹潜入碧波潭龙宫，在宴上被拿，编供词脱身，偷走拴在牌楼下的金睛兽。
4. 悟空变成牛魔王骑兽赶到芭蕉洞，诓罗刹女酒后吐出真扇、说出放大口诀（不知缩小法），
   扛扇而去；牛魔王宴散识破，手持罗刹女的双剑追向火焰山。

## 选定场面

骗得真扇之后，悟空离开芭蕉洞，踏祥云跳上高山，把杏叶大小的扇子吐出，念诀变成一丈二尺
长，只讨得放大之法、不知缩小口诀，只得扛在肩上找旧路而回。这是回目“二调芭蕉扇”的结局，
单人构图，扇子形制原文写得具体。宴席变蟹一幕主体是螃蟹，难以辨认是悟空，不取。三处依据：

- 「将扇子吐出来，演演方法」
- 「上有三十六缕红丝，穿经度络，表里相联」
- 「左右只是那等长短。没奈何，只得搴在肩上」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 悟空 | 本相：毛脸雷公嘴，戴金箍，穿直裰，围虎皮裙；扇子扛在肩上，喜形于色。第61回开头牛魔王赶上时，见的是“孙大圣”“肩膊上掮着那柄芭蕉扇，怡颜悦色而行”，可知此时已是本相 | 高山演扇段；第61回首句 |

## 器物与环境

- 地点：芭蕉洞外的高山上，翠云山一带；山下远方可见火焰山红光。时令原文未写。
- 芭蕉扇：罗刹女口中吐出时“只有一个杏叶儿大小”；捻柄上第七缕红丝念诀后长到一丈二尺；
  “祥光晃晃，瑞气纷纷”，扇面有三十六缕红丝穿经度络。扇形原文只称“芭蕉扇”，兜底画成
  芭蕉叶形的长柄大扇。
- 悟空的铁棒原文此段未提，可藏耳内不画；脚下祥云。
- 现实中会动的：① 扇面上的祥光与瑞气明暗流动；② 脚下祥云向两侧缓缓飘散；③ 三十六缕
  红丝的光泽沿扇面一明一灭。

## 排除项

- 宴席变蟹、偷辟水金睛兽、变牛魔王诓扇在此之前；牛魔王变八戒骗回扇子在第61回；均不入图。
- 不画扇火、灭火与火海中的悟空；扇灭火焰山在第61回。
- 悟空此刻不是牛魔王形，不长牛角；不骑金睛兽。
- 扇子不是杏叶大小，也不是能收进口中的小扇；不画罗刹女、牛魔王与唐僧师徒。
- 万圣龙王、九头虫之名第62回才出，与本图无关。
