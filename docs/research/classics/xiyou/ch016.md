# 《西游记》第16回 观音院僧谋宝贝　黑风山怪窃袈裟

底本：<https://zh.wikisource.org/wiki/西遊記/第016回>；读取日期：2026-10-19。

## 情节要点

1. 师徒抵观音禅院，二百七十岁的老僧求看宝贝，悟空取出唐僧的锦襕袈裟炫示。
2. 老僧骗得袈裟过夜，听从小和尚广谋之计，聚各房头搬柴围住禅堂，要烧死师徒。
3. 悟空化蜜蜂察知，上南天门向广目天王借辟火罩，罩住禅堂，自己坐上方丈房顶助风。
4. 黑风山黑风洞的妖怪见火来救，趁乱从方丈窃走袈裟；天明老僧因袈裟失踪撞墙而死。
5. 悟空问出黑大王的来历，驾筋斗云赴黑风山索讨。

## 选定场面

观音院夜火：悟空坐在方丈房顶捻诀吹风，辟火罩护住前面的禅堂，其余殿宇尽成火海。
火势、黑烟、屋顶人影和惊逃的僧众都有原文铺陈，一个瞬间即可成画，具名角色只需悟空一人。
依据三处原文：

- 「行者拿了，按着云头，径到禅堂房脊上，罩住了唐僧与白马、行李」
- 「他却去那后面老和尚住的方丈房上头坐着，保护那袈裟」
- 「转捻诀念咒，望巽地上吸一口气吹将去」

## 器物与环境

- 辟火罩：向广目天王所借，事后归还。原文只称“罩儿”，未写形状、颜色、材质。
- 建筑：前有禅堂（师徒所宿，门窗槅扇未被烧）、后有方丈（老僧居处，未着火）；
  寺中有三山门、钟鼓楼、浮屠塔；火起后殿宇全焚，墙壁红通通。
- 时间天气：二更起火，烧到五更天明；黑烟遮天，不见星斗；本回未写季节，不强加。
- 现实中会动的：① 烈焰与翻滚黑烟；② 自巽方吹来的风与火势同向，灰烬迸起；
  ③ 悟空衣摆、虎皮裙边与惊逃僧众的衣袂。

## 排除项

- 八戒（第19回入伙）、沙僧（第22回入伙）均不在场；白马在场，已被罩住。
- 放火的是金池长老一伙僧人，悟空只是吹风助势，不画成悟空持火把纵火。
- “金池长老”之名到第17回才出现，本回称老僧、院主、师祖，题面不用此名。
- 黑熊精随后才趁乱入方丈偷袈裟，本回未写其样貌，不入画；“黑熊精”亦非本回称呼。
- 辟火罩不得写成“火浣布（石棉）”或具体形制，那是后人联想。
- 观音、天王均不在场。第3回所得凤翅紫金冠、锁子甲、步云履不得出现：第14回出山时
  悟空赤条条，此后的衣着只有虎皮裙、直裰与金箍。
- 黑风山方位：叙述写观音院正南二十里，院主却说正东南，原文自相出入，题面不写方位。
