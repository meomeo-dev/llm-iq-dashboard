# 《西游记》第82回 姹女求阳　元神护道

底本：<https://zh.wikisource.org/wiki/西遊記/第082回>；读取日期：2026-10-19。

## 情节要点

1. 八戒下山凹探路，见两个女怪在井上打水，叫了声“妖怪”，被她们抡起抬水的杠子打了
   几下，抱头跑回；悟空教他变化了再去，讲些礼貌。
2. 八戒变成黑胖和尚，唱喏称“奶奶”，套出她们是奉洞中老夫人之命取水，要备素宴款待唐僧。
3. 三人尾随女怪到陷空山，见崖前牌楼写着“陷空山无底洞”，牌楼下大石正中有缸口大的洞，
   往下看极深，周围足有三百余里；悟空独自入洞，变苍蝇探得唐僧被关在东廊格子里。
4. 悟空先后变蟭蟟虫、饿老鹰，闹翻素筵；又教唐僧哄女妖去后花园，自己变成红桃，被女妖
   吞下后受制，女妖只得背着唐僧到洞口，交还八戒、沙僧。

## 选定场面

陷空山山凹的井边，八戒已变成黑胖和尚，摇摇摆摆走近，向两个女怪躬身唱个大喏。两个
女怪立在井台旁，杠子放下，没有举起；各戴一顶明显高耸的篾丝䯼髻。具名角色一位：八戒
（变化后），另有两个无名女怪作群像；悟空、沙僧留在山上，不入画。变化、行礼、对方惊喜
都是喜剧，没有打斗，也不涉及成亲一节。三处依据：

- 「见他头上戴一顶一尺二三寸高的篾丝䯼髻，甚不时兴」
- 「变做个黑胖和尚。摇摇摆摆，走近怪前，深深唱个大喏」
- 「把钉钯撒在腰里，下山凹，摇身一变」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 猪八戒（变化后） | 黑而胖的和尚，人形，不显长嘴大耳；僧衣颜色款式原著未写，兜底：素色僧衣、光头，不画袈裟与毗卢帽；钉钯“撒在腰里”（变小别在腰间），兜底：腰后露出一小截钯头，不扛在肩上 | 本回 |

| 孙悟空、沙僧 | 留在山上，不入画 | 本回 |

## 器物与环境

- 地点：陷空山山凹，沿小路走五六里处的井边（原文“井上打水”）。井口形制与水桶原著
  未写，兜底：石砌井台、木桶、井绳，不画现代水泵。山势高峻，松石丛生，见第81回末尾。
- 䯼髻：明代已婚妇女的发罩，原文说明是篾丝所编，高一尺二三寸，画成明显高耸的圆锥或
  筒形发罩，罩在顶发上，不画成凤冠、云髻。
- 杠子：原文只写“抬水的杠子”，兜底：一根粗木杠，两人合抬一只木桶，此刻放在井台边。
- 时间天气：白天（后文悟空说“青天白日”）；季节原文未直写，第80回为暮春，不强加。
- 现实中会动的：① 木桶里晃动的水面与溅起的水珠；② 山凹里随风摇摆的草木枝叶；
  ③ 僧衣下摆与女怪裙带的轻摆。

## 排除项

- 八戒挨打一幕在变化之前，此刻两个女怪没有举杠子，题面不写挨打。
- 无底洞牌楼、缸口洞、洞内的门楼、草亭、东廊、素筵，老夫人（金鼻白毛老鼠精）、唐僧、
  成亲、花园桃树、入腹各节，都在后文，不入画；题面与评判标准不写任何暧昧细节。
- 本回的“黑胖和尚”不是第85回的“矮瘦和尚”；此刻不画木鱼，也不画猪嘴。
- 䯼髻的夸张高度是原文写法，所查到的出土实物都不到十厘米高；题面按原文只写“明显高耸”，
  不写具体厘米，也不要求按实物比例缩小。
- 央视版《四探无底洞》对应第80–83回；资料中未见井边变化的造型，不以影视造型为据。
