# 《西游记》第34回 魔王巧算困心猿　大圣腾挪骗宝贝

底本：<https://zh.wikisource.org/wiki/西遊記/第034回>；读取日期：2026-10-19。回目“腾挪”一作“腾那”，正文亦作“腾那”。

## 情节要点

1. 两小妖试用悟空换给的假葫芦失败，悟空收回毫毛；小妖回洞谎称被蓬莱神仙调换，二魔点出
   五件宝贝去了两件，差巴山虎、倚海龙去压龙洞请“老母亲”带幌金绳。
2. 悟空变小妖骗二人带路，打死二人，又骗出九尾狐狸（老奶奶）打死，夺得幌金绳，变作老
   奶奶坐轿回莲花洞；因八戒一句“后面掬起猴尾巴”露了馅。
3. 二魔披挂与悟空空中斗三十回合；悟空用幌金绳套魔，二魔念松绳咒脱身，反把悟空套住，
   念紧绳咒擒回洞中。
4. 悟空锉断金圈脱身，毫毛换走幌金绳；变“者行孙”叫阵，被二魔用葫芦叫名装入；在葫芦里
   骗二魔揭帖，变蟭蟟虫飞出，又变小妖把真葫芦换到手。

## 选定场面

二魔悬在半空，把紫金红葫芦底朝天、口朝地，对准地面的“者行孙”叫名；悟空忍不住应声，
被吸向葫芦口。这是“叫名应声即装”规则的完整演示，两个角色，法宝姿势明确，取被吸的
一瞬，帖子要吸入后才贴，不入画。三处依据：

- 「那魔执了宝贝，跳在空中，把底儿朝天，口儿朝地」
- 「飕的被他吸进葫芦去，贴上帖儿」
- 「但绰个应的气儿，就装了去也」

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 银角（二魔） | 头戴凤盔，白胜腊雪；身披战甲，闪亮如精炼钢；腰束蟒龙筋带；粉皮靴，靴筒有梅花折；面如灌口真君般俊朗，身形威武似巨灵神；出战时持七星宝剑；出洞叫阵时手持葫芦，原文未写卸甲，也未写手中仍有剑 | 披挂诗赞；出门段 |

## 器物与环境

规则：持宝者站在高处或空中（原文三处用例如此），底朝天、口朝地叫名；对方应声即被吸入，不论名字真假，不应不装；
吸入后贴“太上老君急急如律令奉敕”帖，一时三刻化脓（小妖转述）；每件可装千人。

| 宝贝 | 本回归属 | 外形与用途（原文） |
| :-- | :-- | :-- |
| 紫金红葫芦 | 二魔自称“我的” | 只写色名；悟空毫毛所变假葫芦长一尺七寸（第33回），换给二魔的假葫芦与真品“一样无二”，可推真品相近 |
| 羊脂玉净瓶 | 老魔（金角）的 | 玉色净瓶，用法同葫芦；第35回在洞中放金光 |
| 七星剑 | 二魔“身边” | 出战所用；第35回由管家取给老魔 |
| 芭蕉扇 | 二魔“身边” | 第35回由老魔插于后项衣领，扇火 |
| 幌金绳 | 压龙洞老母亲 | 套人，念紧绳咒收紧、松绳咒放松；套颈时是一个金圈 |

- 地点：莲花洞外半空与地面；时辰、天气未写。
- 现实中会动的：① 葫芦口下被吸起的尘土与草叶（原文只写“飕的”，属推定）；
  ② 被吸起的悟空衣摆与虎皮裙；③ 空中云气。

## 排除项

- 葫芦只认应声，不认名字真假；悟空应的是自编的“者行孙”，仍被吸入。
- 悟空此刻不被绳缚，也不在葫芦中；被绳擒、锉金圈是此前，葫芦里的黑暗与逃出是之后。
- 银角没有“角”：原文写盔甲，“金角”“银角”是大王称号，原文无注解。
- 九尾狐、小妖、八戒、沙僧、唐僧不在场；老魔在洞内。底本称其“母亲”“老奶奶”，无“干娘”。
- 葫芦与净瓶上不写符文，不添字。
