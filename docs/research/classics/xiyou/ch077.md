# 《西游记》第77回 群魔欺本性　一体拜真如

底本：<https://zh.wikisource.org/wiki/西遊記/第077回>；读取日期：2026-10-19。

## 情节要点

1. 三魔与三徒在城东半山苦战至晚，八戒、沙僧先后被擒，悟空被大鹏两翅追上抓回，三人被绑，
   唐僧被带到殿下。
2. 夜里妖魔把四人装进蒸笼；悟空拔毫毛变假身，唤北海龙王敖顺化冷风护住锅底，抛瞌睡虫放倒
   烧火小妖，救出师父并牵马、取行李。
3. 师徒爬墙逃走时被魔王发觉，唐僧、八戒、沙僧重被擒获，唐僧被藏进锦香亭铁柜，城中传言他已被吃。
4. 悟空听信传言上灵山哭诉；如来讲出三魔来历，请文殊、普贤同往狮驼国。
5. 悟空佯败引三魔入佛光，文殊、普贤降伏青狮白象；如来把大鹏定在佛顶，大鹏皈依，悟空救出师徒。

## 选定场面

狮驼国城上空，如来金光里，大鹏被如来手往上一指，翅膊筋抽，飞不去，立在佛顶上现出本相；
悟空藏在金光影里不敢露面。具名角色三位：如来、大鹏、悟空；过去、未来、现在三尊佛像与
五百罗汉、三千揭谛作群像。收妖是本回独有的瞬间，无打斗血腥。三处依据：

- 「被佛爷把手往上一指，那妖翅膊上就了筋，飞不去」
- 「现了本相，乃是一个大鹏金翅雕」
- 「行者将身一闪，藏在佛爷爷金光影里，全然不见」

## 器物与环境

- 地点：狮驼国城上空（悟空所指“放黑气的”狮驼国）；半空中过去、未来、现在三尊佛像与
  五百罗汉、三千揭谛布散左右，把三魔围得水泄不通。
- 时令：悟空夜半离城，天明回到城边，故按白天作画；季节本回未写。
- 文殊、普贤抛出的莲花台与被降伏的青狮白象属前一瞬，不入画。
- 现实中会动的：① 如来身周金光的明灭；② 城中升起的黑气；③ 满天缥缈的瑞云。

## 排除项

- 蒸笼、北海龙王、瞌睡虫、爬墙、锦香亭铁柜均属前半，不入画。
- 青狮、白象是文殊、普贤坐骑，已被降伏；文殊、普贤与抛出的莲花台不入画，
  以免超过四个具名角色。
- 大鹏此刻是鸟形，不画人身持戟；不要把他画成九头鸟、孔雀或凤凰。
- 孔雀大明王菩萨只是如来讲的来历，不入画；如来也不持钵、不现五指山。
- 悟空不是被擒状态，也不画成捆在蒸笼里；不戴凤翅紫金冠、不披黄金甲。
- “六牙白象”不见于本回底本，不采。续集《如来收大鹏》与现代概念图均属改编，不沿用。
