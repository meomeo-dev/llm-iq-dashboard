# 《西游记》第62回 涤垢洗心惟扫塔　缚魔归主乃修身

底本：<https://zh.wikisource.org/wiki/西遊記/第062回>；读取日期：2026-10-19。

## 情节要点

1. 师徒秋末冬初行抵祭赛国，见金光寺僧人披枷戴锁乞化；僧人诉三年前一场血雨污了宝塔，
   国王疑僧盗宝，前两批僧人已被拷死。
2. 三藏依在法门寺立下的“见塔扫塔”之愿，沐浴更衣，夜里与悟空各持新笤帚上塔，逐层扫。
3. 扫到第十层三藏疲倦坐下；悟空上到第十二层，听见塔顶人声，
   在第十三层拦住猜拳吃酒的二妖。
4. 二妖供出：碧波潭万圣龙王与九头驸马下血雨污塔，偷走舍利子，又偷了王母的九叶灵芝。
5. 次日三藏穿袈裟入朝倒换关文，悟空坐八抬轿押妖赴朝；国王设宴，
   悟空与八戒押二妖往碧波潭。

## 选定场面

二更时分，金光寺塔内，三藏与悟空各持新笤帚，自下而上扫塔（原文写到第七层时已二更）。
具名角色两位：三藏、悟空。夜景、尘封的佛座与蛛网，动作安静，无打斗；三藏此刻不披袈裟、
不戴帽，服饰原文写得具体。三处依据：

- 「如此扫至第七层上，却早二更时分」
- 「三藏沐浴毕，穿了小袖褊衫，束了环绦，足下换一双软公鞋，手里拿一把新笤帚」
- 「层层门上琉璃灯，有尘无火；步步檐前白玉栏，积垢飞虫」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 唐僧 | 夜里沐浴后：小袖褊衫（僧人上衣，袖小）、环绦束腰、软公鞋，手持新笤帚。原文未写袈裟、毗卢帽（次日清晨才“穿了锦襕袈裟，戴了毘卢帽”）。公鞋式样未写，兜底：软底布鞋 | 沐浴后一句；入朝段 |
| 孙悟空 | 毛脸雷公嘴，身躯瘦小；金箍、绵布直裰、虎皮裙（次日“束一束虎皮裙，整一整绵布直裰”，夜里沿用）；手持新笤帚，金箍棒不出手 | 入朝段；“两人各持一把” |

## 器物与环境

- 塔：金光寺塔。僧人称“黄金宝塔”，赞诗称“五色琉璃塔”“凌云千尺塔”；悟空估“怕不有
  十三层”，后文二妖在第十三层，舍利子安第十三层塔顶宝瓶。材质两说并存，兜底：琉璃砖塔、
  十三层、顶有宝瓶、檐角挂金铎；层数不必逐层画出。
- 塔内：层层门上琉璃灯有尘无火；檐前白玉栏积垢飞虫；佛座前香烟断绝；窗棂外、神面前蛛网
  牵蒙；炉中鼠粪，盏内少油。寺门额“敕建护国金光寺”，不要求画字。
- 时令：秋末冬初（“野菊残英落，新梅嫩蕊生”“虹藏不见影，池沼渐生冰”）；塔上夜静风寒，
  “满天星月光辉”，二更。
- 笤帚：两把新笤帚，由僧人上街化来；式样未写，兜底：细竹枝或草茎束成的短柄笤帚。
- 现实中会动的：① 笤帚扫起的灰尘；② 窗棂外随风飘动的蛛网；
  ③ 檐角金铎（“金铎声传海上风”）。

## 排除项

- 第十三层拦住二妖、悟空掣棒拦门，在三更前后，是下一幕，不入画；二妖有“暴腮乌甲，尖嘴
  利牙”“滑皮大肚，巨口长须”两种相貌，底本未说哪个对应哪个，也不画。
- 八戒、沙僧和提灯笼的小和尚是捉妖之后才上塔，此刻塔上只有二人。
- 次日的锦襕袈裟、毘卢帽、朝堂与麒麟殿赐宴不入画；血雨、盗宝与碧波潭只是背景。
- 央视版第18集的塔与服装属改编，不依。
