# 《西游记》第39回 一粒丹砂天上得　三年故主世间生

底本：<https://zh.wikisource.org/wiki/西遊記/第039回>；读取日期：2026-10-19。
回目“丹砂”为底本用字，部分刊本作“一粒金丹天上得”；正文称丹为九转还魂丹、金丹。

## 情节要点

1. 三藏被八戒挑唆念紧箍咒，悟空答应在阳世医人，筋斗云上离恨天兜率宫求太上老君的丹药。
2. 老君与仙童执芭蕉扇搧火炼丹，防悟空偷丹；悟空软磨得一粒，含在颏下嗉袋里，被老君揪住。
3. 回寺后以清水灌丹，悟空嘴对嘴度一口气，国王复活；寺僧给他换布直裰、黄丝绦与旧僧鞋，
   国王与八戒各挑一担，随师徒进城。
4. 金銮殿上悟空定住百官，替“行童”念口供道破冤情；妖魔夺刀驾云逃走，又变作三藏模样，
   靠念紧箍咒辨出真假，八戒与沙僧在空中围攻。
5. 文殊菩萨乘彩云赶到，袖中取出照妖镜照出青毛狮原身，说明因果，放莲花罩收狮，骑其背回五台山。

## 选定场面

九霄彩云上，文殊菩萨举照妖镜，镜中现出青毛狮子，悟空收棒立在一旁，八戒、沙僧被招呼来看。
入画理由：狮子形貌有一首诗专门写定，镜子是单一显眼的法宝，三位具名角色可成一幅。三处依据：

- 「那菩萨袖中取出照妖镜，照住了那怪的原身」
- 「浑身三伏靛，四爪九秋霜」
- 「青毛生锐气，红眼放金光」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 文殊菩萨 | 从东北方一朵彩云里现身；相貌衣冠本回未写，只写袖中取出照妖镜；取常见菩萨相，不强加持物 | 引文1；“东北上一朵彩云”句 |
| 悟空 | 金箍；刚收棒上前施礼；衣冠沿用第14回起的虎皮裙、直裰；此前“忍着头疼”，紧箍咒已停 | 本回前段；第14回 |
| 青毛狮（镜中） | 眼如琉璃盏，头大如炼炒缸，双耳下垂，尾长如扫帚，青毛，红眼放金光，扁牙，圆须挺硬；身深靛蓝，四爪霜白 | 引文2、3；镜里观真像一首 |
| 八戒、沙僧 | 被悟空招呼来看镜；此前以钉钯、宝杖在空中围攻，此刻是否仍执兵器未写 | 围攻一段；招呼一句 |

## 器物与环境

- 地点：乌鸡国城上空的九霄云中，悟空为下棒而升至高处，文殊自东北方彩云中叫住他。
- 时间天气：白昼（清晨复活，行半日到城，此刻应在午后）；云色、风势原文未写。
- 照妖镜：形制、尺寸原文未写，只知可袖中携带；按常识作圆镜，不强加纹饰；镜中映的是狮子原形。
- 现实中会动的：① 彩云翻卷；② 镜面反射的光芒闪动；③ 镜中狮子红眼的金光明灭。

## 排除项

- 放莲花罩、文殊坐在狮背上驾祥光去五台山，是下一瞬，不与照妖镜同图；本图狮子只在镜中。
- 魔王在镜外此刻的形貌原文未写（先前变过三藏），不画魔王本体，也不画他手执夺来的刀。
- 文殊菩萨本回未写持剑、如意、经卷，也未写骑狮而来；不强加。
- 狮子名“狮猁王”，是文殊坐骑青毛狮子，已被骟，自身无兵器；狮驼岭的青毛狮子怪另是一说，
  不与本回混用。
- 老君、兜率宫、嗉袋噙丹、金銮殿定身法、假三藏、度气救王均是前段，不入此图。
- 悟空此刻是常人身量，不画三头六臂，也不画金箍棒打向狮子；八戒的钯、沙僧的杖不写成月牙铲。
- 国王、太子与百官此时都在下方殿上，不入空中场面。
