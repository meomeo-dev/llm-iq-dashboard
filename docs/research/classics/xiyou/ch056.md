# 《西游记》第56回 神狂诛草寇　道迷放心猿

底本：<https://zh.wikisource.org/wiki/西遊記/第056回>；读取日期：2026-10-19。

## 情节要点

1. 端阳前后，师徒翻山下坡，悟空晃棒惊马，马奔出二十里，唐僧被三十多名喽啰
   拦住，捆了吊在树上；悟空变成小和尚上前周旋，唐僧趁机骑马跑回旧路。
2. 悟空从耳中取出绣花针，变成碗口粗的铁棒插在地上，两个贼首抢夺不动；悟空
   随后两棒打死二人，喽啰四散，唐僧埋贼祝祷，悟空在坟前说狠话，师徒生隙。
3. 当晚借宿杨老汉庄，杨家逆子正是贼伙，四更领众回来；老汉开后门放走师徒。
4. 天明贼众追来被悟空杀散，悟空又割下杨子首级献给唐僧；唐僧念紧箍咒十余遍，
   逐他回去，悟空翻筋斗云而去。

## 选定场面

大路旁，悟空变成的少年小和尚把耳中绣花针一晃，变作碗口粗的铁棒插在地上，两个
贼首上前抢夺，纹丝不动，喽啰围观。取棒未挥出的一刻，无人倒地，不涉血腥；针变
棒的反差与贼首吃力的神态一目了然。三处依据：

- 「就拈在手中，幌了一幌，变作碗来粗细的一条棍子」
- 「两个贼上前抢夺，可怜就如蜻蜓撼石柱，莫想弄动半分毫」
- 「变做个干干净净的小和尚，穿一领缁衣，年纪只有二八」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 悟空（变作小和尚） | “干干净净的小和尚”，缁衣，年十六（二八），光头（贼用藤棍打的是其“光头”），蓝布包袱（背在肩上，取出针时曾放下）；手中是针变的碗口粗铁棒，即如意金箍棒。金箍、虎皮裙、直裰、雷公嘴脸变形后均原文未写（金箍、虎皮裙见第14回，真身全貌见第58回）；兜底：清秀少年僧，光头缁衣，不画金箍与虎皮裙 | 摇身一变段；打头段；第3回；第14回 |
| 两个贼首 | 一个青脸獠牙，一个暴睛圆眼；鬓边红发如飘火，颔下黄须似插针；头戴虎皮花磕脑，腰系貂裘彩战裙；一人执狼牙棒，一人肩横扢挞藤（藤棍）。“花磕脑”无注，兜底：虎皮纹头巾 | 贼首赞词 |
| 喽啰 | 三十多人，各执枪刀棍棒，一棒锣声后从路两边闪出；衣冠未写，兜底：粗布短衣、头缠布巾 | 拦路段 |
| 唐僧、八戒、沙僧 | 此刻都不在场：唐僧已被放下，跳上马顾自跑回旧路；八戒、沙僧留在后面坡上 | 放人段 |

## 器物与环境

- 地点：翻山后西坡下的一段平地，大路穿过，路旁草丛与吊过唐僧的树；山名未写。
- 时令：朱明时节，近端阳（熏风野兰、新竹、满山艾叶、盈涧蒲花、艳红石榴、溪柳
  阴浓、黄雀）；八戒说“天色将晚”，兜底：午后偏晚的暖色天光。
- 器物：碗口粗铁棒（本重一万三千五百斤，此刻不长大）、狼牙棒、扢挞藤棍、枪刀；
  悟空口称包袱里有马蹄金、粉面银是哄贼的话，画面不要画金银外露。
- 现实中会动的：① 熏风吹动的艾叶、蒲草、新竹与溪柳；② 贼首的战裙、貂裘毛边与
  悟空缁衣的衣角；③ 路面扬起的细尘与枝头惊飞的黄雀。

## 排除项

- 打死贼首、尸体、坟堆、割首级、杨老汉庄与杨家逆子都在后段；本图无人倒地无血。
- 棒此刻只有碗口粗细、立在地上；“井栏粗细、七八丈长短”是挥出那一棒时的样子。
- 唐僧被吊在树上是更早的一幕且他已走；不画吊人、不画唐僧、八戒、沙僧、白马。
- 悟空的雷公嘴、虎皮裙、紧箍不属变形后的小和尚；也不画紧箍咒、筋斗云。
- 贼首是人不是妖怪；杨老汉之子是夜里才现身的另一个贼，不是这两个贼首。
