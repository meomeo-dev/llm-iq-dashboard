# 《西游记》第31回 猪八戒义激猴王　孙行者智降妖怪

底本：<https://zh.wikisource.org/wiki/西遊記/第031回>；读取日期：2026-10-19。

## 情节要点

1. 八戒在花果山被群猴扛到洞口，谎称黄袍怪辱骂悟空，激得悟空整束锦直裰、虎皮裙，执铁棒，
   与八戒驾云西返，途中先下东海洗去身上的妖气。
2. 悟空在波月洞门前抓住公主的两个孩子，换出沙僧；让八戒、沙僧带孩子去宝象国殿前激怪，
   自己变作公主留在洞中。
3. 黄袍怪回洞，被悟空骗出口中的内丹舍利子，悟空一口吞下并现原身；洞中变三头六臂，
   一根棒晃成三根，打散群妖。
4. 老妖持宝刀赶出洞外，与悟空在碗子山顶斗五六十合，被一棍打得不见；悟空上天查勘，
   二十八宿缺奎木狼，玉帝将其贬往兜率宫烧火。
5. 悟空救出公主，三人缩地回城；悟空取紫金钵盂里的水喷退唐僧身上的虎形，国王设素筵送行。

## 选定场面

悟空与黄袍怪在碗子山顶的交锋：悟空双手举棍作“高探马”诱敌，妖怪见空隙挥刀砍向下路。
两个具名角色，兵器分明，云雾霞光有原文，取出手一瞬，不取其后“打得不见”的结果。
未选三头六臂打群妖：小妖无样貌描写，且原文紧接血腥描写。三处依据：

- 「这一场，在那山顶上，半云半雾的杀哩」
- 「双手举棍，使一个‘高探马’的势子」
- 「见有空儿，舞着宝刀，径奔下三路砍」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 孙悟空 | 猴形，火眼金睛（第32回同）；锦直裰、束紧的虎皮裙；金箍自第14回起套头（本回仅以“紧箍儿咒”提及，未写形状）；兵器称铁棒、生铁棒，即金箍棒；此段为单棒单身，非三头六臂 | 洞外整束段；交锋诗赞 |
| 黄袍怪（奎木狼） | 青靛脸、白獠牙、大口，红须赤发，金睛鬼眼，手色蓝靛；黄金铠甲，外斜披淡黄袍帐；持宝刀（蘸钢刀）；本回未重写样貌，沿用第28回诗赞；原文无狼头、狼尾之说 | 第28回诗赞；交锋段 |

底本本回作“锦直裰”，第14回作“绵布直裰”，题面只写“直裰”，不加织锦纹样。

## 器物与环境

- 地点：宝象国境内碗子山顶，波月洞在山下；时辰、天气未写。
- 云气：原文称“半云半雾”，诗赞写“刀起明霞亮、棒架彩云飘”。
- 现实中会动的：① 山顶半云半雾的流动；② 刀棒相交处的明霞与彩云；
  ③ 悟空的虎皮裙、直裰下摆与妖怪的袍帐随挥动而飘起。

## 排除项

- 三头六臂是洞内打群妖时的变身；与老妖交手时诗赞只写一条生铁棒，不画三头六臂或三根棒。
- 黄袍怪此刻是本形，不是第29回入朝的“俊俏文人”，也不是天神形貌的奎木狼。
- 八戒、沙僧此时在宝象国金銮殿上空，公主躲在僻静处，孩子已被带走，均不在山顶。
- 孩子被摔于殿阶、小妖“头如粉碎、血似水流”均有血腥描写，不入画。
- 悟空此时不戴凤翅紫金冠、不穿黄金甲（大闹天宫装束），不取影视中的红披风造型。
