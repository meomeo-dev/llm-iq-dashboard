# 《西游记》第94回 四僧宴乐御花园　一怪空怀情欲喜

底本：<https://zh.wikisource.org/wiki/西遊記/第094回>；读取日期：2026-10-19。

## 情节要点

1. 三徒入朝，悟空为师父侍立抱不平，国王命取绣墩让唐僧坐；三徒各自报来历，国王又惊
   又喜，婚期定在本月十二日。
2. 师徒移住御花园；唐僧责怪悟空，悟空说要等公主出来辨真假，唐僧以念紧箍咒相威胁。
3. 次日国王在御花园设宴：国王携唐僧上华夷阁，三徒在留春亭，教坊司奏乐；唐僧见壁上
   四面金屏，应国王之请依韵和了四首诗。
4. 八戒饮后喧哗，唐僧要打他二十禅杖，被陪宴官劝住；十二日公主托词怕徒弟丑恶，请国王
   遣走三徒。
5. 国王用印发还关文并赠金银；悟空留毫毛变身在驿，真身变蜜蜂飞入宫中，落在唐僧毘卢
   帽上。

## 选定场面

御花园华夷阁内，国王陪唐僧观园赏乐；唐僧见壁上四面金屏，应国王之请取笔和诗，国王大喜，
称赞末句。阁外的园景是本回最大的看点：彩石径、雕栏、曲水、凤台龙沼、牡丹亭与各色花木。
具名角色唐僧、国王两位，另有教坊司乐人、侍卫官与宫娥群像。三处依据：

- 「坐间见壁上挂着四面金屏，屏上画着春夏秋冬四景」
- 「长老欣然不辞，举笔而和」
- 「袖手高歌倚翠栏」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 唐僧 | 国王称他“驸马”，面貌未写，神情勉强，外喜内忧；宴上未写袈裟与毘卢帽（毘卢帽只在回末悟空落脚时提到，是另一瞬间）；兜底：素色僧衣，光头，不披袈裟、不戴帽；手执毛笔 | 本回 |

| 乐人、宫娥、侍卫官 | 教坊司奏乐、歌舞吹弹；乐器原文未写，兜底：笙、箫、琵琶、拍板；侍卫官捧文房四宝 | 本回 |

## 器物与环境

- 地点：天竺国御花园内永镇华夷阁，阁内壁上挂四面金屏，屏上春夏秋冬四景并有题诗（只
  画景与墨迹行款，不写字）；案上文房四宝。留春亭是三徒另席处，在园中另一处。
- 园景：彩石铺径、雕栏、夭桃、嫩柳、黄鹂，凤台龙沼、竹阁松轩、假山、曲水，牡丹亭、
  蔷薇架、茉藜槛、海棠畦；白梨红杏、芍药、蜀葵、杜鹃、含笑、凤仙、玉簪各色花。
- 时间天气：国王设宴次日的巳时前后，东风暖日，春景。
- 现实中会动的：① 曲水与龙沼里的流水、游鱼；② 柳条、花枝随风摇动与飘落的花瓣；
  ③ 炉香青烟与乐人的衣袖飘带。

## 排除项

- 悟空变蜜蜂落在毘卢帽上，在回末，且与第95回开头相接，不入画。
- 殿上三徒自报来历、国王下龙床挽手、八戒挨二十禅杖、唐僧扯住悟空、公主在昭阳宫，
  都是本回其他瞬间，不入画。
- 留春亭内的悟空、八戒、沙僧不入画；“四僧”同在御花园，但国王与唐僧一阁、三徒另在
  留春亭，不画成四人同席。
- 假公主、后妃不入画。
- 题诗与和诗不要求写出可辨文字，只画墨迹行款与四景画。
- 天竺不画印度式建筑与服饰，宫室衣冠按汉式（第93回唐僧自述）。
