# 《西游记》第5回 乱蟠桃大圣偷丹 反天宫诸神捉怪

底本：维基文库《西遊記》第005回 <https://zh.wikisource.org/wiki/西遊記/第005回>；读取日期：2026-10-19。

## 情节要点

1. 悟空受封齐天大圣后闲游结友，玉帝命其“权管”蟠桃园；土地告知三千六百株桃树分前、中、后三批，
   熟期三千、六千、九千年。
2. 悟空脱冠服爬树偷吃熟桃；一日变作二寸长的小人，睡在大树梢头浓叶下。
3. 王母设蟠桃胜会，七衣仙女各顶花篮来摘桃，寻不见大圣，自入林摘桃；红衣女摘下南枝上仅存的桃，
   枝条回弹惊醒悟空，悟空现本相，以定身法定住七仙女。
4. 悟空变赤脚大仙骗走真身，偷吃瑶池仙酒肴馔，又盗老君金丹，返回花果山。
5. 玉帝遣四大天王、李天王、哪吒等率十万天兵、布十八架天罗地网围山；悟空以分身法退敌，
   本回以天兵围山、次日再战收束。

## 选定场面

沿用现有题面的场面：蟠桃园中七衣仙女摘桃，二寸长的悟空正睡在她们头顶的梢头。取青衣女扯下南枝、
红衣女摘了桃、枝条将放回的一瞬：仙女不知，读者知情，构图有反差；七色衣裙辨识度高，具名角色
为悟空与红衣、青衣二仙女，其余五位作群像；无打斗。

- “变做二寸长的个人儿，在那大树梢头浓叶之下睡着了。”
- “只见向南枝上止有一个半红半白的桃子。”
- “青衣女用手扯下枝来，红衣女摘了，却将枝子望上一放。”

## 器物与环境

- 蟠桃园：王母亲手栽培，楼台馆舍上空“常见罩云霓”；园中有花亭；“无夏无冬”“四时不谢”，不强加季节。
- 桃树分区：前一千二百株花微果小，中一千二百株层花甘实，后一千二百株紫纹缃核。
- 摘桃当时：前树摘二篮（小桃）、中树摘三篮（中桃）；后树花果稀疏，只余几个毛蒂青皮的，大桃
  已被悟空吃尽；南枝仅存一个半红半白的桃。
- 会动的物件（动效候选）：1. 被扯下又放回的南枝回弹，枝叶摆动渐息（有据）；2. 云霓仙雾缓缓流动
  （有据）；3. 仙女衣带与花篮系带轻飘（衣带原文未写，属画面添加）。

## 排除项

- 仙女发现悟空：底本无此事；她们始终未看见他。
- 悟空现本相、持棒喝问、定身仙女：紧随其后的另一瞬，不并入此幅；此刻悟空睡着，手中无兵器。
- 悟空在树上戴冠着甲：冠服留在花亭。
- 七色改为赤橙黄绿青蓝紫：出自影视与民间说法，底本为红青素皂紫黄绿；董永七仙女、紫霞仙子与此无关。
- 摘桃时画满树硕果：与上述摘桃当时的树况不符。
- 本回后半：瑶池偷酒、盗老君金丹、十万天兵与天罗地网。

## 现有题面核对

- “天界桃林仙雾缭绕”：有据（“盈空常见罩云霓”）。
- “枝头挂满硕大的蟠桃”：与摘桃时点不符。底本是前树小桃、中树中桃，后树只余青皮小果，大桃已被
  吃尽，南枝仅一个半红半白的桃；“果压枝头”见于悟空初巡园之时。
- “七位仙女穿红、青、白、黑、紫、黄、绿七色衣裙”：衣色有据（素为白、皂为黑），底本只写“衣”，
  不写“裙”；顺序各版本略异，不影响画面。
- “提着花篮”：底本为“各顶花篮”，“提”与原字不同；稳妥写“带着花篮”或“顶着花篮”。
- “其中一位抬头惊讶地发现……睡着”：无据。仙女始终未发现悟空，是叙述告知读者；惊醒悟空的是红衣女
  放回枝条。
- “变成两寸来长的小猴人”：底本作“二寸长的个人儿”，未写猴相，“猴人”非原文。
- “树梢浓叶底下”：有据，且所在枝为南枝。
