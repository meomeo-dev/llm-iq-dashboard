# 《西游记》第91回 金平府元夜观灯　玄英洞唐僧供状

底本：<https://zh.wikisource.org/wiki/西遊記/第091回>；读取日期：2026-10-19。

## 情节要点

1. 师徒别了玉华城，五六日后到天竺国外郡金平府；慈云寺僧留他们过元宵，正月十三试灯，
   十五夜进城看金灯桥。
2. 府里年年在金灯桥点三盏金灯，用酥合香油，只点三夜；传说油干是佛收了灯，来年五谷
   丰登，二百四十家油户轮流为此破费。
3. 十五夜半空风响，风中现出三位佛身逼近金灯；唐僧上桥顶下拜，悟空急扯，灯光昏暗，
   唐僧被风摄走。
4. 悟空循腥风驾云向东北追到青龙山，四值功曹扮赶羊人报信：玄英洞里是辟寒、辟暑、
   辟尘三个妖精。
5. 悟空洞口叫阵，三妖率牛头小妖出战，斗一百五十合不分胜负；唐僧在洞内供出师徒名号，
   悟空看出三妖是犀牛精，夜里同八戒、沙僧再去。

## 选定场面

金灯桥上，元宵夜风起灯暗，风中现出三位佛身逼近金灯；唐僧跑上桥顶倒身下拜，悟空伸手
急扯，喝破是妖邪。这是本回由喜转灾的拐点，灯、桥、佛影、下拜与急扯同框，一眼可辨。
具名角色唐僧、悟空两位，另有四散的看灯人与寺僧群像，八戒、沙僧可作桥边小像。三处依据：

- 「少时，风中果现出三位佛身，近灯来了」
- 「慌得那唐僧跑上桥顶，倒身下拜」
- 「师父，不是好人，必定是妖邪也」

## 器物与环境

- 地点：金平府城内金灯桥（上古传留）。桥上三盏金灯，缸般大，上有玲珑两层楼阁，细金丝
  编成，内托琉璃薄片，光胜月色，油香扑鼻。
- 灯油：酥合香油；每缸里有四十九个灯草扎的大灯马，粗如鸡蛋、裹丝绵，三夜点完。
- 时间天气：正月十五夜，月亮刚从半空升起，满城灯火；风每年不到三更就来，来时看灯人
  四散。
- 街景：雪花灯、荷花灯、青狮灯、白象灯、鳌山灯、走马灯等；有跳舞、踩高跷、装鬼、
  骑象的人群。题面点两三样即可。
- 现实中会动的：① 金灯烛火与琉璃反光，风来时忽明忽暗；② 风中飘起的衣带与桥边灯穗；
  ③ 走马灯上旋转的剪影。

## 排除项

- 三妖的牛头鬼形与犀牛本相在洞口交战一段，桥上只是佛身；唐僧被摄走、悟空腾云追赶、
  四值功曹与三羊、青龙山，都在其后，不入画。
- 慈云寺、扫塔、后园赏景在桥前；酥合香油只是灯油，不画油桶与乳品。
- 不画成现代灯笼街与汤圆；灯型取原文清单。
- 三徒直裰已是第90回的新锦布直裰，不沿用旧阶段的八戒皂锦、沙僧黄锦。
- 1999年《西游记续集·观灯金平府》增写西海三公主等原创内容，不沿用。
- 不要求画面里写出桥名、灯上或桥上的字。
