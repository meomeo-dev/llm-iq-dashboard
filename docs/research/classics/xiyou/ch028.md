# 《西游记》第28回 花果山群妖聚义　黑松林三藏逢魔

底本：<https://zh.wikisource.org/wiki/西遊記/第028回>；读取日期：2026-10-19。

## 情节要点

1. 悟空被逐后跳过东洋大海回花果山，见山被二郎神率梅山兄弟放火烧坏，花草俱无，林树焦枯。
2. 七八个小猴跳出叩头，诉说被猎户捕杀之苦，余众只剩千把；马、流二元帅与崩、芭二将军迎悟空入洞。
3. 悟空作狂风打死千余猎户，令群猴剥衣、制靴，拼杂色旗为“齐天大圣”花旗，招魔聚兽。
4. 八戒化斋睡着，唐僧独入松林，误入金顶宝塔，被碗子山波月洞的黄袍怪绑上定魂桩。
5. 八戒沙僧寻到洞口，与黄袍怪在半空厮杀数十回合，不分胜负。

## 选定场面

悟空落下云头回到被烧毁的花果山，七八个小猴从坡前跳出，围住他叩头。这一刻只有悟空与群猴，
焦山与悲喜交集的反差一眼可辨；取相认一瞬，避开其后狂风打死猎户的血腥与剥衣制靴。三处依据：

- 「那山上花草俱无，烟霞尽绝；峰岩倒塌，林树焦枯」
- 「响一声，跳出七八个小猴，一拥上前，围住叩头」
- 「大圣爷爷，今日来家了？」

## 器物与环境

- 地点：花果山。悟空自东洋大海跳过，按落云头；山被二郎神放火烧毁，青石烧成土，碧砂化泥，
  洞外乔松倚倒，崖前土黑，路畔泥红，涧底泉干，只剩荒草与藤薜。
- 时令天气：原文未写；坡前有芳草，凹内有曼荆。“烟霞尽绝”，不画云霞。
- 器物：此刻无兵器出手，棒收在身边；花旗、猎户衣靴都在后面。
- 现实中会动的：① 来路东洋大海的潮浪（赞词“巨浪悠悠”）；② 悟空落下后收散的云头；
  ③ 焦坡上被风扬起的尘土与曼荆藤蔓。

## 排除项

- “重修花果山，复整水帘洞，齐天大圣”十四字花旗，是杀猎户后才竖起；此刻洞外无旗。
- 打死千余猎户、群猴剥衣制靴不入画；涧底泉干，此刻不画飞瀑，借龙王甘霖洗山在后。
- 唐僧、八戒、沙僧、黄袍怪都在西行路上，不在花果山；黄袍怪的奎木狼身份第31回才揭晓。
- 回目所称“黑松林”，正文只写“松林”；松林、宝塔属后半回，不入本场面。
- 二郎神与梅山兄弟是旧事，山上不见；悟空不穿紫金冠、黄金甲（大闹天宫旧装）。
