# 《西游记》第1回 灵根育孕源流出 心性修持大道生

底本：维基文库《西遊記》第001回 <https://zh.wikisource.org/wiki/西遊記/第001回>；读取日期：2026-10-19。

## 情节要点

1. 花果山顶仙石迸裂产卵，见风化为石猴，五官四肢俱全；目运金光惊动天庭，玉帝言“不足为异”。
2. 群猴顺涧上溯，见瀑布飞泉，约定能入内寻得源头而不伤身者拜为王；石猴应声跳入，见铁板桥与石碣，
   出洞后引群猴迁入，被拜为“美猴王”。
3. 三五百年后猴王忧死生，辞众乘筏渡海访仙；在南赡部洲剥取渔人衣裳穿上，学人礼、人话。
4. 八九年后渡西洋海到西牛贺洲，经樵夫指路入斜月三星洞，拜须菩提祖师，得姓孙、名悟空。

## 选定场面

石猴纵身跳入瀑布。这是全回最先出现、最易辨认的一瞬：动作单一明确，瀑布与山涧自带构图，石猴
无衣冠兵器，不易混入后世造型，水流、飞沫、水雾可直接作动效。此时叙述称“石猴”，尚未称王。

- “你看他瞑目蹲身，将身一纵，径跳入瀑布泉中。”
- “一派白虹起，千寻雪浪飞。”
- “桥下之水，冲贯于石窍之间，倒挂流出去，遮闭了桥门。”

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 石猴 | 猴形；无衣、无冠、无兵器、无头箍；毛色与体型底本未写，不强加；金光只见于出世之时 | 出世段仅写五官四肢俱全；千里眼回报时已言金光“将潜息”；穿人衣在渡海登岸之后 |
| 群猴 | 老少成群，猿猴、猕猴、马猴并有；拍手称好；胆小者伸头缩颈、抓耳挠腮（见石猴出洞后的二次入洞） | 瀑布段写群猴扶老携幼、呼兄唤弟一齐跑来；称王段列猿猴、猕猴、马猴 |

## 器物与环境

- 地点：花果山山涧源头，涧水奔流如“滚瓜涌溅”，尽头是一股瀑布飞泉。
- 时令天气：“天气炎热”，群猴先在松荫下玩耍，再到涧中洗澡；晴、云、雨均未写。
- 瀑布：诗赞作“白虹”“雪浪”，“真似挂帘帷”；水自桥下石窍冲出，倒挂遮住洞门，成水帘。
- 洞内（石猴入内才见，外望不见）：铁板桥、桥中间一块石碣（刻“花果山福地，水帘洞洞天”）、石房与
  石锅灶、石碗盆、石床凳；洞内无水无波。
- 会动的物件（动效候选）：1. 瀑布连续下泻；2. 瀑底飞溅水花、升腾水雾（诗云“冷气分青嶂”）；
  3. 涧水奔流的波纹。

## 排除项

- 晚于此刻的特征：人衣（渡海登岸后才穿）、直裰、虎皮裙与金箍（第14回）、凤翅紫金冠、黄金锁子甲、
  藕丝步云履、如意金箍棒（第3回）、筋斗云（第2回）；“孙悟空”之名要到本回末才得。
- 石碣与铁板桥在水帘之内，不是瀑布外的立碑或门匾；跳入时群猴尚未拜王。
- 石猴目运金光只在出世之时，不画成此刻放光的双眼；后文才有的“火眼金睛”亦不取。

## 现有题面核对

- “晴天”：底本只写“天气炎热”，未写晴；属合理推断，非明文。
- “白练似的瀑布”：底本为“白虹”“雪浪”，无“白练”；意近，可保留或改“白虹”。
- “浑身是毛、身形矫健”：第1回未写石猴有毛或体型，仅“五官俱备，四肢皆全”；毛为猴类常识，不冲突，
  但不是原著明文；“矫健”无据。
- “没有衣甲、兵器和头箍”：有据。“纵身跃入瀑布”：有据（将身一纵）。
- “涧边猴子抓耳挠腮观望”：“抓耳挠腮”在底本属石猴出洞后二次入洞的胆小猴；首次跳入时群猴是
  “拍手称扬”并等候。姿态可用，出处不同。
- “瀑布后面隐约露出铁板桥和石碑”：无据。桥与石碣在“遮闭了桥门”的水帘之内，入内才见，外望不见；
  “石碑”底本作“石碣”，位于桥中间。要画只能作透视内景，否则删去。
- 动态题面“水雾弥漫、飞溅水花”：由“雪浪飞”“冷气分青嶂”推得，可用。
