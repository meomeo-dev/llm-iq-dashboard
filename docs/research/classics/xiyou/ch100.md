# 《西游记》第100回 径回东土　五圣成真

底本：<https://zh.wikisource.org/wiki/西遊記/第100回>；读取日期：2026-10-19。

## 情节要点

1. 八大金刚送四众到长安，太宗在望经楼迎接，请唐僧骑御马入朝；洪福寺的松树枝头忽然向东。
2. 太宗设宴、撰《圣教序》；唐僧要诵经，在雁塔寺登台，八大金刚现身召回，师徒连马腾空西去。
3. 往返恰在八日之内，四众回到灵山，如来封唐僧旃檀功德佛、悟空斗战胜佛、八戒净坛使者、
   沙僧金身罗汉、白马八部天龙马。
4. 白马被引到后崖化龙池，退毛换角，生金鳞银须，飞出池子，盘绕在山门里的擎天华表柱上。
5. 悟空要唐僧念松箍儿咒，唐僧让他摸头，金箍已无；大众合掌念诸佛名号，全书终。

## 选定场面

灵山山门内，白龙飞出化龙池，盘绕在擎天华表柱上；唐僧与悟空站在柱下，悟空举手摸头，
金箍已无。诸佛菩萨罗汉列在后方作群像。五圣之中，只有白龙与无箍的悟空有具体形貌描写，
授职与名号只有名无形，所以取这一刻。悟空与唐僧对话的地点原文未写，兜底：同在山门内
华表柱旁。具名角色白龙、唐僧、悟空三位。三处依据：

- 「退了毛皮，换了头角，浑身上长起金鳞，腮颔下生出银须」
- 「飞出化龙池，盘绕在山门里擎天华表柱上」
- 「行者举手去摸一摸，果然无之」

## 人物造型

| 人物 | 本回阶段的样貌与衣冠 | 原文依据 |
| :-- | :-- | :-- |
| 白龙（八部天龙马） | 马皮褪尽，换了头角，浑身金鳞，腮颔下生银须，周身瑞气，“四爪祥云”（读作四足生祥云），飞出池子盘绕华表柱。龙角形制、爪数、身长未写，兜底：蛇形长身，双角，金鳞，银白长须，四足踏祥云，缠绕柱身 | 本回；第15回 |
| 唐僧 | 受封旃檀功德佛，但成佛后的身相与衣着原文未写，袈裟、毗卢帽未写。兜底：仍画取经僧形，素色僧袍，面容安详；不画成端坐莲台的大佛，不加大头光，不画袈裟与毗卢帽 | 本回 |
| 孙悟空 | 受封斗战胜佛；本回明写头上金箍已无。其余未写，兜底：猴面，头顶无箍无帽，直裰、虎皮裙沿用第14回，不画成金身佛像 | 本回；第14回 |
| 群像 | 诸佛、菩萨、罗汉、揭谛、比丘、优婆夷塞与各山神仙各归方位；面貌衣冠未写，画成远处小影，不求逐一可辨 | 本回 |

## 器物与环境

- 地点：灵鹫峰雷音寺山门内的擎天华表柱。华表一般是石柱，柱身盘龙，上端横插云板，顶有承露盘；
  原文只写“擎天华表柱”，兜底：八角石柱，顶有云板与承露盘，龙身缠绕。化龙池在后崖，远处小景或不画。
- 景物：灵鹫峰头聚霞彩，极乐世界集祥云；乔松古桧、翠柏修篁，五色梅与仙桃，另有凤、鸾、猿、
  鹿。取三五样入画即可。
- 时间天气：时辰未写，霞彩祥云满天，兜底：明亮的白昼。
- 现实中会动的：① 祥云缓缓流动；② 龙的银须与鬃毛随气流飘摆（龙身与华表不整体移动）；
  ③ 松柏枝叶与梅桃花瓣微摇、飘落。

## 排除项

- 回长安（望经楼、太宗、洪福寺向东的松树、《圣教序》、雁塔寺谈经）在前半回，不入画。
- 八戒的净坛使者、沙僧的金身罗汉只有封号，未写新形貌，本场面不画八戒、沙僧。
- 唐僧、悟空成佛后原文未写金身、莲台、佛光；影视与动画里的成佛金身造型属改编，不沿用。
- 86版初篇第25集把受封佛号提前演在取经之后，顺序与原著第100回不同；续篇终集止于雁塔寺，
  没有化龙与成佛，无影视造型可沿用。
- 金箍已去，不画紧箍，不画念松箍儿咒；画面不要求写出诸佛名号、授职长词与《圣教序》。
- 白龙是西海龙王之子所化（第15回），不是东海龙王；不画回马形，爪数原文未定，不强加五爪。
