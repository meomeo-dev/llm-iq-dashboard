# 《西游记》第99回 九九数完魔灭尽　三三行满道归根

底本：<https://zh.wikisource.org/wiki/西遊記/第099回>；读取日期：2026-10-19。

## 情节要点

1. 观音查看难簿，唐僧只受过八十难，不合九九之数，命揭谛传话，八大金刚把四众连马带经
   放落在通天河西岸。
2. 老鼋出水迎接，驮四众与马共五口回东岸；将近岸时问起当年托问寿数之事，唐僧没问，答不上，
   老鼋晃身沉水，经包衣物尽湿（第八十一难）。
3. 刚登岸又起风、雾、雷、电，是阴魔来夺经；唐僧按住经包，悟空抡铁棒护持，折腾一夜到天明。
4. 太阳高照，师徒把经移到高崖上开包晒晾，衣鞋同晒；渔人认出他们，陈澄来邀去陈家庄；
   收经时《佛本行经》有几卷被石粘破。
5. 陈家庄设斋，救生寺里塑了四众像；三更师徒悄悄离去，八大金刚在半空接引。

## 选定场面

通天河东岸的高崖上，风雾雷电过后日头高照，四众把浸湿的经卷摊开晒晾，衣鞋铺在崖边，
有人站、有人坐、有人跳。这是雷电与老鼋之后的平静一刻，也是本回独有的画面。
具名角色唐僧、悟空、八戒、沙僧四位，白龙马可作崖下小影；渔人与陈家庄人在晒经途中
才到，不入画。三处依据：

- 「却移经于高崖上，开包晒晾」
- 「他们又将衣鞋都晒在崖傍，立的立，坐的坐，跳的跳」
- 「至今彼处晒经之石尚存」

## 器物与环境

- 地点：通天河东岸（老鼋驮渡后登岸处）临河高崖，崖下是宽阔的通天河（第49回写河界八百里）。
  崖形原文未写，兜底：一块平整的大岩石平台伸向河面，即后世所称晒经石。
- 经卷：共五千零四十八卷，一部分由马驮，另一担由八戒挑（第98回）；浸水后拆包摊开。
  原文说收经时“经尾”沾破，可见是有头有尾的卷子；兜底：卷轴与线装册页混摆，字迹不求可辨。
- 时间天气：一夜风雾雷电后天明，随后日头高照，晴；季节未直写，承第96回春尽夏初；河面已
  不是第48–49回的冰封。
- 同晒之物：衣、鞋、鞍辔，铺在崖边。
- 现实中会动的：① 河面波光与崖下浪花；② 经页边角与摊开的衣袍被风轻轻掀动；
  ③ 湿经与湿衣上蒸起的水汽。

## 排除项

- 老鼋驮渡与沉水、夜里风雾雷电的阴魔夺经，都在晒经之前；本场面是白昼放晴，不画老鼋
  露头，不画雷电。
- 渔人、陈澄、陈家庄、救生寺塑像在晒经之后；《佛本行经》被石粘破是收经时的事，不要求
  画破页。
- 86版初篇第25集把“老龟沉河”放在传经之后的回程，顺序与原著不同；两篇分集梗概均未见
  晒经，无影视造型可沿用。
- 青海玉树通天河畔的“晒经台”（岩石旁古柏挂经幡）是后世景点，与原著“高崖”无关，不沿用。
- 衣鞋晒出不等于人物裸身，不画裸露；也不画成寺院里逐页翻晒的六月六晒经场景。
