# 四大名著候选题考证与撰写规范

本目录存放 `src/core/classics/` 四部名著逐回候选题的考证笔记，并规定题面、评判标准与实测的写法。
每回对应一条静态候选 `<book>-NNN` 与一条动态候选 `<book>-anim-NNN`，两条描绘同一场面。

## 考证笔记

每回一份 `docs/research/classics/<book>/chNNN.md`（NNN 为三位回数），不超过 80 行，结构如下：

1. 标题：`# 《书名》第N回 回目原文`（回目照底本，用简体）。
2. 底本链接与读取日期。
3. `## 情节要点`：3–6 条，以今语转述。
4. `## 选定场面`：选哪一场、为何适合入画；引原文不超过三句，每句不超过 40 字。
5. `## 人物造型`：表格，列人物、本回阶段的样貌与衣冠、原文依据。
6. `## 器物与环境`：法宝兵器、建筑地理、时令天气。
7. `## 排除项`：本回不得出现的后世改编造型，或属于其他回目阶段的特征。
8. `## 检索记录`：表格，5–10 行，每行一轮检索，列检索内容、来源 URL、结论。

原著引文只取维基文库底本；现代资料只记事实结论，不照录行文。

## 题面

静态题面：

- 开头固定为「生成一幅 SVG 插画，描绘《书名》第X回<场面>的场面：」，X 用汉字数字。
- 正文以 100–180 字为宜，写全排除项与方位时可放宽，不超过 220 字：地点、时间与天气；具名角色
  不超过四个，可另加群像；人物按本回阶段写明样貌与衣冠，不只写名字；写明核心动作、关键器物与
  一处构图提示。
- 只写原著有据的细节；原著没写的衣色、季节不强加。
- 打斗只画出手的瞬间，不画血腥结果。
- 不要求在画面里写出可辨认的长段文字。
- 评判标准里扣分、而按常识作画又容易画进去的项目（影视或戏曲造型、他回人物与器物、
  人物整体移动等），题面须明写排除；同一回的静态与动态题面各自写全，不互相省略。
- 方位写成画面上的左右（“画面左侧”），不写“某人的左边”。

动态题面：

- 开头固定为「生成一幅带纯内联 SVG 动画（使用 SMIL 或内联 CSS @keyframes）的矢量插画，
  描绘《书名》第X回<场面>的动态场面：」。
- 场面与静态题面一致，正文压缩到 80–140 字为宜，写全排除项时可放宽，不超过 190 字。
- 随后写「动效要求：1. …；2. …；3. …。」，列 2–3 项。每项写明哪个物件、怎么动、往复还是循环；
  只让现实中会动的东西动，人物与建筑主体不整体漂移。
- 结尾固定为「严格遵守合法 XML 规范。」

标签写作 `第N回 场面短名`（短名 4–8 字，N 用阿拉伯数字），动态候选在其后加「（动态）」。

## 评判标准

每条候选的 `PromptStandard` 逐条手写，不由程序拼接：

- `coreKey`：本回场面的鉴别维度，不超过 40 字。
- `groundTruth`：原著事实，包括回目、人物在本回阶段的样貌、器物与环境，可短引原文。
- `evaluationCriteria`：分「满分：」与「扣分：」两段，扣分项点名本回最容易混入的错误。
  动态候选另写动态判据：所列动效平滑循环、由 SMIL 或内联 CSS 驱动；纯静态画面、使用
  JavaScript、XML 解析出错均扣分。
- `referenceSource`：`<章回地址> · docs/research/classics/<book>/chNNN.md`。

英文标签与英文标准放在 `src/core/prompts/i18n/`，由中文逐条翻译，不含 CJK 字符。

## /tmp 生图实测

每回写成后实测，最多优化三轮，取最好的一版定稿：

1. 用 `mktemp -d /tmp/pelican-<book>-chNNN-XXXXXX` 建临时目录。
2. 只读题面、不看标准，按题面手写静态与动态 SVG 各一幅。
3. 用 `xmllint --noout` 检查 XML；用浏览器渲染静态首帧与动态多帧帧序条。
4. 读取评判标准对照判定：画面能否还原原著场面，题面有无歧义、缺漏或与原著不符之处，
   动效能否实现、是否确实在动。
5. 问题落到题面修改上再测；通过或满三轮后清理临时目录。
