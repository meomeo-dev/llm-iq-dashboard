## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 8 世纪末始建；821 年阿格拉布王朝埃米尔 Ziyadat Allah I 重建完成（塔门上有 821 年铭文石板）；1722 年修复北翼与东翼 |
| 尺寸 | 近似正方形围合，边长约 38 m；墙高约 11 m |
| 平面 | 四角为圆形角塔，各边中段有半圆形突出塔；南面正中一座矩形凸出的门楼，门廊用古罗马石柱；门楼上方有帆拱承托的穹顶室；内院为矩形，四面带拱廊；底层 33 间窄室环绕院落，上层三面有房间；上层有祈祷厅 |
| 瞭望塔 | 东南角一座圆柱形高塔，兼作灯塔 |
| 材料 | 石砌 |
| 状态 | 保存完整；作为「苏塞麦地那」组成部分于 1988 年列入世界遗产；现为古迹开放参观 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座方方正正的小堡垒，四角圆塔、四边中段半圆塔，东南角拔起一根细高的圆柱形瞭望塔。
- 南面一座带古柱门廊的方形门楼，内院四面拱廊、两层小室。
- 周围是麦地那的平顶白房子，一角露出海面。
