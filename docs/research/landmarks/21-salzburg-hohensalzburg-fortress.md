# 21 萨尔茨堡 – 霍亨萨尔茨堡要塞（Hohensalzburg Fortress / Festung Hohensalzburg）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1077 年始建；1106–1147 年完成主体；1462 年加环墙与四座塔；1495–1519 年大扩建；1620–1645 年近代化；1681 年北侧 Kuenburg 棱堡完工 |
| 尺寸 | 长 250 m，宽 150 m；建筑面积逾 7,000 m²，含棱堡逾 14,000 m²；外环墙周长约 450 m；主体 Hoher Stock 平面 22 × 33 m；Kuenburg 棱堡墙高 30 m、厚数米 |
| 位置 | 老城南侧 Festungsberg 山顶，海拔 506 m |
| 材料 | 几乎全部用山体自产的白云岩（dolomite）砌筑 |
| 组成 | 中央主体 Hoher Stock（1077 年核心）；Krautturm（内藏 1502 年机械管风琴）、Glockenturm、Trompeterturm 等塔加固环墙；北侧 Kuenburg 棱堡、南侧 Hasengraben 棱堡、东侧 Nonnberg 棱堡；院内 Georg 礼拜堂与水窖 |
| 交通 | 1892 年通登山缆车（Festungsbahn）；1515 年有记载的货运斜坡轨道 Reisszug |
| 军事史 | 1525 年农民战争围攻未破；1861 年退出军事用途；20 世纪初曾作监狱 |
| 状态 | 博物馆与观光地，2016 年起属萨尔茨堡州；1996 年作为「萨尔茨堡历史中心」组成部分列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座长条形的白色要塞盘踞在陡峭的山顶，由多重环墙与角上的塔楼围出几进院落，中央是一栋
  高大的方正主楼。
- 北侧探出一座又高又厚的棱堡，墙面几乎垂直；山坡上一条笔直的缆车轨道从山脚直通要塞。
- 山脚下是密集的老城坡屋顶与一段河面。
