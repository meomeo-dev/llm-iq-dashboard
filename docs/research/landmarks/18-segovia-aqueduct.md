# 18 塞哥维亚 – 古罗马水道桥（Aqueduct of Segovia）

- Wikidata：Q244947
- 参考条目：<https://en.wikipedia.org/wiki/Aqueduct_of_Segovia>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 公元 1 世纪罗马时期；具体年代有争议，传统说法为图密善时期，2016 年考古证据指向 112 年之后 |
| 长度 | 输水系统全长 15 km；城内高架段约 728 m，坡度 1% |
| 高度 | 阿索格霍广场处最高 28.5 m（含约 6 m 基础） |
| 拱 | 共 167 孔：75 孔单层拱、44 组双层拱（88 孔）、4 孔单层拱 |
| 结构 | 花岗岩条石干砌，不用砂浆；最高段为上下两层拱，上层墩柱比下层窄 |
| 壁龛 | 顶部保留两个壁龛，一个现放圣母像，另一个已空 |
| 材料 | 灰色花岗岩琢石 |
| 修复 | 1072 年受损，天主教双王时期重砌 36 孔；2006 年列入世界古迹观察名单 |
| 状态 | 使用至 1973 年；1985 年作为「塞哥维亚老城与水道桥」列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一道笔直的灰色花岗岩拱桥横穿老城广场，最高段是上下两层半圆拱叠置，上层墩柱比下层窄。
- 向两端延伸时高度逐渐降低，双层拱过渡为单层拱，最后没入地面。
- 石块为干砌的条石，每块边缘可见，不用砂浆；墩柱有微微的收分。
- 底座为广场铺地与两侧的浅色老房子，房子高度不到桥高的三分之一。
