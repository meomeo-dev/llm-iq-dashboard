# 10 开普敦 – 桌山（Table Mountain）

- Wikidata：Q213360
- 参考条目：<https://en.wikipedia.org/wiki/Table_Mountain>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 类型 | 自然地标：平顶山，顶部为平坦的高原 |
| 高度 | 最高点 1,084.6 m（Maclear's Beacon） |
| 平顶 | 山顶平台两端相距约 3 km，四周为陡直的砂岩崖壁 |
| 侧峰 | 东侧魔鬼峰，西侧狮头山，两峰相距约 5.2 km |
| 岩石 | 石英质砂岩（桌山砂岩），下部为紫红色泥岩层，基底为开普花岗岩 |
| 云象 | 东南风把湿气推上山坡时，平顶上会铺开一层被称为「桌布」的云 |
| 缆车 | 1929 年开通；下站海拔 302 m，上站 1,067 m；1996–1997 年换为旋转车厢 |
| 植被 | 凡波斯（fynbos）灌丛，桌山一带约 1,500 种植物 |
| 保护 | 1998 年设桌山国家公园，由南非国家公园局管理；属世界遗产开普植物区；2011 年入选世界新七大自然奇观 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座顶部完全平直的山，平顶宽度远大于山高，四周是近乎垂直的砂岩崖壁，崖壁灰褐色带水平层理，山脚为绿色灌丛坡。
- 左右各有一座侧峰：一侧是尖锐的独立山峰，另一侧是圆锥形的矮峰。
- 平顶上可以铺一层薄薄的白云，像一块从边缘垂下的桌布。
- 一条缆车索道从山脚斜拉到崖顶，挂着一个小圆车厢；底座保留山脚下的城区与一小段海湾。
