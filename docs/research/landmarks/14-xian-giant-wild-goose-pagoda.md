# 14 西安 – 大雁塔（Giant Wild Goose Pagoda）

- Wikidata：Q1047061
- 参考条目：<https://en.wikipedia.org/wiki/Giant_Wild_Goose_Pagoda>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 652 年唐高宗时期为玄奘所建，初为五层；约 704 年武则天时期改建为七层楼阁式；930–933 年、1466 年（明成化）修缮，1604 年（明万历）加砌外壁 |
| 层数 | 七层 |
| 尺寸 | 总高 64.1 m（含台基）；台基高约 4.2 m，南北宽约 48.8 m；底层塔身边长 25 m |
| 形状 | 方形楼阁式砖塔，整体呈锥形收分 |
| 立面 | 每层四面各开一个券门；砖砌出仿木的方柱、阑额与斗拱，层间以叠涩檐分隔；门楣有石刻佛像 |
| 材料 | 灰褐色砖 |
| 倾斜 | 1996 年倾斜约 1 m，1997 年起通过封井治理，2006 年已回倾 9.4 mm |
| 位置 | 西安南郊大慈恩寺内 |
| 状态 | 寺院与旅游景点，可登塔；1961 年全国重点文物保护单位；2014 年作为「丝绸之路：长安—天山廊道」组成部分列入世界遗产 |
| 管理 | 1983 年起由西安市文物园林局管理 |

塔门两侧有唐代碑刻，属文字，题面不要求写出。

## 视觉要点（自撰，供题面与评分细则使用）

- 一座方形的七层砖塔立在宽阔的方形台基上，塔身自下而上逐层收窄，整体像一个瘦长的四棱锥。
- 每层四面正中各开一个圆拱券门，层与层之间由一圈层层出挑的砖砌短檐分隔。
- 砖面上用浅浮雕线条表现仿木的方柱与斗拱；塔顶为一个小尖顶。
- 通体灰褐色；底座为寺院庭院，点缀几棵松柏与一座低矮的殿宇屋顶。
