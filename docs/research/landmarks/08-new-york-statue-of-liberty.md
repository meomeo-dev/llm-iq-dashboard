# 08 纽约 – 自由女神像（Statue of Liberty）

- Wikidata：Q9202

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 落成 | 1886 年 10 月 28 日 |
| 设计者 | 雕塑家 Frédéric Auguste Bartholdi（1834–1904）；结构工程师 Gustave Eiffel（1832–1923）；基座建筑师 Richard Morris Hunt（1828–1895） |
| 尺寸 | 铜像自脚跟到火炬 46 m；含基座与基础总高 93 m，铜像与基座高度大致相等 |
| 材料 | 铜皮包在铁骨架上；原为红棕色，落成后二十年内氧化为绿色铜锈 |
| 造型 | 身披长袍的女性形象；右手高举火炬，左臂抱一块碑板，头戴七道光芒的冠冕，脚下踩着断裂的锁链 |
| 基座 | 截头金字塔形，底边 62 英尺见方，顶边 39.4 英尺；混凝土外贴花岗岩；坐落在十一角星形的旧堡垒平台上 |
| 位置 | 纽约港自由岛 |
| 所有权 | 美国国家公园管理局（1933 年起） |
| 遗产 | 1984 年列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 青绿色铜锈的女性立像：右臂高举火炬，左臂抱一块碑板贴在身侧，头戴七道放射状光芒的冠冕，长袍垂到脚面。
- 立像站在灰褐色花岗岩的截头金字塔形高基座上，基座下是星形的堡垒平台；立像与基座高度大致相等。
- 底座是一小块岛屿，四周环水。
- 火炬火焰可以画成金色。
