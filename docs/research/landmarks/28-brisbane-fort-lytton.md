# 28 布里斯班 – 利顿堡（Fort Lytton）

- Wikidata：Q25182614
- 参考条目：<https://en.wikipedia.org/wiki/Fort_Lytton>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1880–1882 年，设计者 Peter Scratchley（1835–1885） |
| 位置 | 布里斯班河口南岸 Lytton，周围原为约 2.6 km² 的军事用地 |
| 平面 | 五角形土堤堡垒，隐藏在草坡堤岸之后，四周环绕注水的壕沟 |
| 尺寸 | 建筑、炮位坑、隧道等嵌在五角形土堤中，占地近 1 ha |
| 材料 | 土堤覆草 |
| 组成 | 炮位（初为两门 80 磅与两门 64 磅前装炮，后换 6 英寸隐显炮与速射炮）、弹药库、隧道、遥控水雷阵地、营房与训练场 |
| 军事史 | 1882–1965 年服役，为布尔战争、一战、二战的训练基地；二战时为河口内防线的一部分 |
| 状态 | 1988 年移交昆士兰州政府，1990 年设立 Fort Lytton 国家公园；列入昆士兰遗产名录；由 Fort Lytton 历史协会运营，周日与公共假日开放 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座低矮的五角形绿色土堤趴在河口岸边，几乎看不出是堡垒，四周一圈注水的壕沟。
- 土堤朝河的几面嵌着圆形的灰色炮位坑，堤内是空旷的操场与几栋低矮的营房。
- 一侧是宽阔的河口水面。
