# 25 平遥 – 平遥城墙（Pingyao City Walls）

- Wikidata：Q1080216（平遥古城）
- 参考条目：<https://en.wikipedia.org/wiki/Pingyao>、
  <https://zh.wikipedia.org/wiki/平遥城墙>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 现存城墙为 1370 年（明洪武三年）在旧城基础上大规模重修；15 世纪起多次修缮 |
| 尺寸 | 周长约 6.4 km（英文条目记 6,163 m）；高约 12 m；顶宽平均 3.5 m；围合面积约 2.25 km² |
| 材料 | 墙体夯土，外侧包砌，顶部青砖铺墁 |
| 设施 | 敌楼 72 座，约每 50 m 一座；垛口 3,000 余个；城门 6 座（南北各一、东西各二），东西门外有瓮城；角楼 4 座；东门上有魁星楼，东南角有点将台 |
| 护城河 | 宽 4 m、深 4 m |
| 修复 | 1979 年起系统修复；2004 年南门附近一段坍塌，2005 年重修 |
| 状态 | 1988 年全国重点文物保护单位；1997 年「平遥古城」列入世界遗产；城内为居民区与旅游区 |

条目正文未记载包砌材料与颜色的细节；题面中的「青灰色砖面」按通行认知写入，只作色彩指令，
不进评分细则的事实项。

## 视觉要点（自撰，供题面与评分细则使用）

- 一圈方正的青灰色城墙围住密集的灰瓦院落，墙顶每隔一段立一座带坡顶的敌楼，四角各一座角楼。
- 城门外套着方形的瓮城，墙外一圈窄窄的护城河。
- 俯视时墙顶的马道、垛口与敌楼的节奏最抢眼。
