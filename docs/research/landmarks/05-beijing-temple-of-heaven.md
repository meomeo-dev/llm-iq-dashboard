# 05 北京 – 天坛祈年殿（Temple of Heaven, Hall of Prayer for Good Harvests）

- Wikidata：Q125445（天坛建筑群）
- 参考条目：<https://en.wikipedia.org/wiki/Temple_of_Heaven>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 建筑群 1420 年（明永乐）；祈年殿 1889 年雷击焚毁，数年后按原制重建 |
| 尺寸 | 祈年殿直径 36 m，高 38 m，高径比约 1:1 |
| 形状 | 圆形大殿，三重檐攒尖顶，顶端鎏金宝顶 |
| 屋面 | 深蓝色琉璃瓦，象征天 |
| 台基 | 三层圆形汉白玉台基 |
| 结构 | 全木结构，不用钉子；内柱 4 根象征四季，中层 12 根象征十二月，外层 12 根象征十二时辰 |
| 其他建筑 | 皇穹宇为单檐圆殿，外有回音壁；圜丘坛为三层圆形石台 |
| 用途 | 1918 年起为公园；现为公园与博物馆 |
| 遗产 | 1998 年列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 三层白色圆形台基逐级收小，每层带栏杆，正面有台阶。
- 台基上是圆形大殿：朱红色的柱廊与门窗，其上三重深蓝色圆形屋檐由下而上逐层缩小，最上层收成尖顶，顶端一颗金色宝顶。
- 殿身高度与直径大致相当，整体呈圆润的塔状。
- 底座保留一段笔直的石板甬道与几棵深绿色的柏树。
