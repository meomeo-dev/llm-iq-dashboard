# 01 巴黎 – 埃菲尔铁塔（Eiffel Tower）

- Wikidata：Q243
- 参考条目：<https://en.wikipedia.org/wiki/Eiffel_Tower>、
  <https://en.wikipedia.org/wiki/Maurice_Koechlin>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1889 年 3 月 31 日竣工，同年 5 月 15 日为世界博览会开放 |
| 设计者 | Maurice Koechlin（1856–1946）、Émile Nouguier、Stephen Sauvestre；公司主 Gustave Eiffel（卒于 1923） |
| 高度 | 含天线 330 m，建筑高度 300 m；顶层观景台 276 m；第一层平台约 57 m |
| 基底 | 正方形，边长 125 m；高宽比约 2.4 : 1 |
| 结构 | 锻铁格构塔，四条塔脚向上收拢汇成一根塔身；塔脚之间有装饰性拱 |
| 平台 | 三层可上人平台，第一、二层为环形楼面，顶层为小观景台，其上为天线 |
| 曲线 | 外轮廓按风阻计算，呈内凹的指数曲线，不是直线锥 |
| 材料 | 锻铁约 7,300 吨，18,038 个构件，约 250 万铆钉 |
| 颜色 | 官方色「埃菲尔铁塔棕」，自下而上分三段由深到浅 |
| 环境 | 位于战神广场一端，塞纳河在西北侧，河对岸为特罗卡德罗 |
| 所有权 | 巴黎市；由 SETE 运营 |
| 遗产 | 1964 年历史古迹；1991 年随「巴黎塞纳河畔」列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 四条弧形塔脚立在正方形基底四角，塔脚之间有装饰拱。
- 第一、二层平台把塔身分成三段，塔身向上急剧收窄成细长尖顶，顶端有小观景台与天线。
- 通体单一暖棕色，可自下而上略浅；不画夜间灯光。
- 底座只保留战神广场的绿色草坪条带与一小段塞纳河水面。
