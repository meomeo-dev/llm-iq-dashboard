## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 907 年（五代）动工，961 年（宋）完成；上部层数于明崇祯年间（1628–1644）增建 |
| 尺寸 | 高 47 m，七层，八角形平面；总重约 7,000 吨 |
| 材料 | 砖砌，仿木构楼阁式 |
| 倾斜 | 倾角约 3°，塔顶与塔底水平偏移 2.32 m；原因是承重柱开裂与半岩半土的基础 |
| 加固 | 1957 年向地基灌注混凝土加固，施工中发现藏有佛经的石函 |
| 位置 | 虎丘山顶，原云岩寺范围内，现属虎丘公园 |
| 状态 | 江苏省重点文物保护单位；2010 年 9 月起不再开放登塔 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座八角形的七层砖塔立在山顶，整体向一侧明显倾斜，塔顶偏离塔底约一个塔身宽度的十分之一。
- 每层八面各有券门或壁龛相间，层间由砖砌出挑的短檐分隔，檐下有仿木的斗拱线条。
- 塔身自下而上逐层略微收窄；顶部为一个小尖顶。
- 塔立在长满树木的小山上，底座表现山坡、石阶与山脚的一段水面。
