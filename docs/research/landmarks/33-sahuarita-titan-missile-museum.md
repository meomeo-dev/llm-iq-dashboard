# 33 萨瓦里塔 – 泰坦导弹博物馆（Titan Missile Museum）

- Wikidata：Q795302
- 参考条目：<https://en.wikipedia.org/wiki/Titan_Missile_Museum>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 原址 | 美国空军泰坦 II 洲际导弹发射设施 571-7，亚利桑那州萨瓦里塔，图森以南约 40 km |
| 建成 | 1963 年；1963–1984 年值班，按 1981 年导弹更新政策退役 |
| 地下设施 | 三层发射控制中心，3 t 重的防爆门；八层发射井，钢筋混凝土井壁厚达 2.4 m（8 ft）；井与控制中心之间以电缆通道与通道相连 |
| 导弹 | 泰坦 II，高 31.4 m（103 ft），展示品不装燃料与弹头，再入飞行器为切开孔洞的惰性替代品 |
| 井盖 | 按美苏协议永久固定在半开位置 |
| 地面 | 燃料与控制车辆的硬化停放场、天线塔、入口门斗、设备电梯、展出的发动机 |
| 状态 | 1994 年列为国家历史地标；由非营利机构 Arizona Aerospace Foundation 运营；冷战后期仅存的两处泰坦 II 发射设施之一，唯一可参观完整洲际导弹的地点 |

条目正文未记载导弹与井壁的颜色；题面中的「灰绿色导弹」「灰白混凝土」按通行认知写入，只作
色彩指令，不进评分细则的事实项。

## 视觉要点（自撰，供题面与评分细则使用）

- 沙漠里一片围着铁丝网的平地，地面只有几座低矮的方盒子、一座天线塔和一块半开的巨大混凝土井盖。
- 底座切开一个剖面：井盖之下是一口深深的圆筒形发射井，一枚细长的导弹立在井中；旁边是三层的地下控制中心，用一条斜通道与井相连。
