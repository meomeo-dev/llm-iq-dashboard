# 20 乌尤尼 – 乌尤尼盐沼（Salar de Uyuni）

- Wikidata：Q76122
- 参考条目：<https://en.wikipedia.org/wiki/Salar_de_Uyuni>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 类型 | 自然地标：世界最大的盐沼 |
| 面积 | 10,582 km² |
| 海拔 | 3,656–3,663 m，全域高差不到 1 m |
| 盐壳 | 平均厚 8 m；旱季表面呈六边形盐壳多边形 |
| 镜面 | 12 月至次年 4 月雨季，薄水层形成约 129 km 宽的镜面 |
| 印加瓦西岛 | 盐沼中的火山残丘，长满巨型仙人掌，可高达约 12 m |
| 图努帕火山 | 位于盐沼西缘 |
| 火车墓地 | 乌尤尼镇外 3 km，废弃的矿业时代机车 |
| 盐砖建筑 | 边缘有以盐砖砌成的旅馆；原盐沼中央的旅馆 2002 年因污染拆除 |
| 资源 | 锂储量约 2,300 万吨；地方社区历来反对外资开采 |
| 保护 | 国际地质科学联合会地质遗产地；由玻利维亚管理，盐业合作社采盐 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一片一望无际的纯白盐壳，表面铺满大小相近的六边形多边形，边缘微微隆起成细脊。
- 盐沼中部一座深褐色的小岛，岛上立着几十根高瘦的仙人掌。
- 远缘一座平缓的火山轮廓，山体赭红带一点残雪。
- 近处可留一片薄水，倒映出天空与岛的镜像；边缘点缀一辆小越野车与几只火烈鸟。
