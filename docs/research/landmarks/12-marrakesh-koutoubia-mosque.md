# 12 马拉喀什 – 库图比亚清真寺（Koutoubia Mosque）

- Wikidata：Q1137533
- 参考条目：<https://en.wikipedia.org/wiki/Kutubiyya_Mosque>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 第一座寺 1147 年始建；现存第二座寺 1158–1195 年；宣礼塔约 1195 年完成 |
| 建造者 | 穆瓦希德王朝哈里发 Abd al-Mu'min 创建，Ya'qub al-Mansur 完成 |
| 宣礼塔 | 总高 77 m，主塔身 55.68 m；方形，边长 12.81 m；高宽比略大于 5:1 |
| 塔身分段 | 方形主塔身占总高约五分之四；其上为一座更小的方形灯塔，顶为带凹槽的穹顶与铜制尖饰 |
| 尖饰 | 三颗由大到小的铜球，最大直径约 2 m |
| 塔身装饰 | 四面各不相同的盲拱与盲拱廊；主塔身顶部一圈白绿两色的瓷砖带；顶缘为阶梯状雉堞；小塔身有 sebka 菱格纹板 |
| 塔内 | 六个上下叠置的房间，以宽坡道相连 |
| 祈祷厅 | 多柱式，宽约 90 m，进深 57–66 m，17 道纵向廊道，百余根砖柱；外部为绿色瓦的坡屋顶 |
| 庭院 | 宽 45 m，深 23 m，中央有净身泉，种有成排树木 |
| 材料 | 砖与砂岩砌筑，宣礼塔为毛石砌 |
| 环境 | 位于麦地那西南，东距不眠广场约 200 m；四周为广场与玫瑰园；第一座寺的遗址在广场上可见 |
| 状态 | 现役清真寺；2023 年地震受损，2024 年 3 月修复后重开 |

塔身有库法体铭文与彩绘，属文字，题面不要求写出。

## 视觉要点（自撰，供题面与评分细则使用）

- 一座方形的赭红色宣礼塔高高立起，主塔身占总高约五分之四，顶缘一圈阶梯状雉堞，雉堞下一条白绿相间的瓷砖带。
- 主塔身之上是一座更小的方形小塔，四面有菱格纹板，顶上一个带凹槽的小穹顶，穹顶上串着三颗由大到小的金铜色圆球。
- 塔身四面各有不同的盲拱图案，用浅浮雕的线条表现，不写文字。
- 塔脚下是低矮宽阔的祈祷厅，绿色瓦的坡屋顶成排；旁边是带净身泉与成排树木的庭院。
- 底座为广场与玫瑰园，点缀几棵棕榈，远端留出第一座寺的柱基遗址。
