# 03 布拉格 – 查理大桥（Charles Bridge）

- Wikidata：Q204871
- 参考条目：<https://en.wikipedia.org/wiki/Charles_Bridge>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1357 年动工，1402 年完成 |
| 设计者 | Peter Parler（14 世纪） |
| 尺寸 | 长 515.8 m，宽 9.5 m；16 孔拱，最大跨 13.4 m |
| 材料 | 波希米亚砂岩，色调偏深的灰褐 |
| 桥塔 | 老城端一座哥特式桥塔（1648 年受损，1874–1883 年修复）；小城端一组哥特式桥塔 |
| 雕像 | 桥栏两侧共 30 组以巴洛克风格为主的圣人雕像，1683–1714 年陆续立起；1965 年起原件全部换为复制品 |
| 用途 | 1978 年起仅供步行 |
| 环境 | 跨伏尔塔瓦河，连接布拉格城堡一侧与老城；位于历代波希米亚国王加冕路线上 |
| 遗产 | 世界遗产（布拉格历史中心）；国家文化古迹 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座又长又矮的石拱桥，多孔半圆拱架在粗壮的桥墩上，桥面几乎水平，桥身远长于桥高。
- 老城端立一座高耸的哥特式方形桥塔，陡坡屋顶带角部小尖塔；对岸端是一高一矮的两座塔。
- 桥栏两侧等距立着深色的雕像剪影，不需要辨认身份。
- 石材为深灰褐色；底座保留伏尔塔瓦河水面，远端可点缀城堡所在的小山轮廓。
