# 城市地标题库：选择规则与净室流程

题库 `landmarks-v1`（静态）与 `landmarks-anim-v1`（动态）共用同一份四十景数据，以「城市 – 地标」为单位，要求模型以微缩景观（miniature diorama）
风格画出地标的 SVG。本文件是准入规则与制作流程的唯一依据，每个地标的事实表与判定
记录放在同目录下 `NN-<city>-<landmark>.md`。

## 许可边界

- 代码仓 MIT，数据仓 CC BY 4.0。两者都允许下游商用，因此题库只收录**没有任何剩余
  权利**的地标，不依赖免责声明兜底。
- 事实来源只取 Wikidata（CC0）的结构化字段与 Wikipedia 条目中的事实；不复制条目
  正文，不照搬任何榜单的选择与排序，不存储任何照片或图片链接。

## 准入规则（七条全部满足才收录）

| # | 规则 | 判定方法 |
| :-- | :-- | :-- |
| 1 | 版权已过期或不受版权 | 建于 1900 年前，或全部设计者去世已超过 70 年；仍在扩建的作品不收。另有两款：a 款，所在国成文法无条件允许对建筑作图并商用（见下方国家清单）；b 款，退役舰船、潜艇、导弹等实用物品不受版权，只核第 2 条 |
| 2 | 外形无商标或品牌主张 | 核对 Getty / Adobe 受限清单与条目中的商标记载 |
| 3 | 不以真实人物为主体 | 肖像雕塑、陵墓、纪念堂一律不收 |
| 4 | 所在国无文物图像权 | 意大利、希腊、埃及的文物整体不收 |
| 5 | 主权与政治中立 | 无主权争议、无政治功能、无宗教归属争议、无民族或殖民创伤 |
| 6 | 全程纯文字 | 题面与评分细则只有文字，仓库不存参考图 |
| 7 | 宁缺毋滥 | 前六条任何一条需要写「附注」「附条件」「待核实」才能通过的，一律不收；靠题面省略某个构件、只画一部分来规避的不算通过；宁可少一景，也不硬加 |

补充约束：题面只写城市，不写国家；不出现旗帜、徽记、标语；城市名用 Wikidata 英文
主标签对应的通行中文名；有夜间灯光版权的地标只画日景。

第 1 条 a 款只认下列成文法，均无条件允许商用，不是判例或默许：美国 17 U.S.C. §102(a)(8)
（1990 年 12 月 1 日前建成的建筑无建筑作品版权）、§105（联邦政府作品无版权）、§120(a)
（对公共可见建筑作图不侵权）；英国 CDPA s.62（对建筑作图不附任何条件）；加拿大版权法
s.32.2(1)(b)；澳大利亚版权法 s.65–68。其他国家的全景自由条款附有非商用或仅限特定作品等
条件，不纳入 a 款。b 款下飞机一律不收：波音、洛克希德等厂商对机型外形有商标授权计划，
触第 2 条；舰船、潜艇与导弹由海军或国家设计，无此主张。

第 4 条已核实的国家：意大利（文化遗产法第 107–108 条）、希腊（3028/2002 号法）。法国只限
《遗产法典》L.621-42 条所列的 21 处国家领地（domaines nationaux，含默东、凡尔赛、枫丹白露、
尚博尔等），名单外的古迹不受限。埃及、墨西哥（INAH 对考古遗址图像的商业使用许可）、秘鲁
待核实，核实前一律按不收处理。

### 第 5 条的判定方法

| 类别 | 判定 | 例子（均不收） |
| :-- | :-- | :-- |
| 主权争议 | Wikidata `country`（P17）多值，或位于争议领土、跨国界 | 耶路撒冷西墙与圆顶清真寺、直布罗陀巨岩、尼亚加拉瀑布、伊瓜苏瀑布、维多利亚瀑布 |
| 政治功能 | 议会、总统府、王宫（仍在使用）、政党机关、市政厅、纪念堂、阅兵场 | 白宫、克里姆林宫、天安门、曼谷大皇宫、布达佩斯国会大厦 |
| 宗教归属争议 | 近三十年有改宗、归属诉讼或多教派主张 | 圣索菲亚、阿约提亚、圣殿山 |
| 民族或殖民创伤 | 殖民纪念物、种族隔离遗迹、战争纪念、原住民圣地 | 靖国神社、拉什莫尔山、罗兹雕像、乌鲁鲁 |
| 分离与统一 | 象征分裂或统一的构筑物与场所 | 板门店、柏林墙遗迹、勃兰登堡门 |

现役宗教建筑本身可收（如清真寺、佛寺、教堂），只要归属没有争议；已改为博物馆或公园的
宫殿可收（如故宫、美泉宫）。

## 选择方法

- **候选来源**：Wikidata 中 `instance of`（P31）属于旅游景点、建筑、山峰等子类，且
  `located in`（P131）落在目标城市的条目，按 `sitelinks` 数（被多少种语言的维基百科
  收录）排序，取前列作为该城市的候选。排序只作机械代理指标，不代表任何榜单的编辑判断。
- **大洲配额**：每批十景以欧洲 3、亚洲 3、非洲 1、北美 1、南美 1、大洋洲 1 为目标；
  替换落选者时允许偏差一景；同一城市在整套题库中只出现一次。
- **类型平衡**：每批至少含一处自然地标、一处桥梁或塔楼、一处宗教或宫殿建筑，避免整批
  都是同一类轮廓。
- **入选理由**：每景事实表的准入判定表即入选理由；被放弃的候选与放弃原因记录在本文件
  末尾的「已放弃候选」表，避免重复评估。
- **主题批次**：一批可以设主题（如第三批的军事工程）。主题批次先满足主题，大洲配额退为次要；
  主题下无法满足七条的类别整批留空，不以放宽规则补足。航空与核能工业建筑在现行第 1 条下
  无一入选：航空建筑仅默东 Hangar Y 早于 1900 年，但默东为国家领地；核能建筑的设计者
  均卒于 1956 年之后。
- **事实表门槛**：条目至少要给出年代、尺寸（高度或跨度）与材料三项可核对事实，否则
  写不出评分细则，放弃该候选。
- **留证**：事实表记录 Wikidata QID、参考条目 URL 与读取日期。

## 净室流程（每个地标独立执行）

1. 读取该地标的 Wikipedia 条目与 Wikidata 条目，只摘结构化事实到事实表。
2. 逐条填写六项准入判定，任一不满足即放弃并换下一个候选。
3. 合上条目，只看事实表，用自己的话写题面描述与评分细则。
4. 题面末尾附统一的渲染层段落（构图、光影与材质、远近层次、微缩细节、氛围、风格），逐字相同。

## 题面设计

题面采用固定骨架，静态版十三段、动态版在氛围之后多一段【动态】，顺序不变，由
`src/core/prompts/landmarks.ts` 的 `composeLandmarkPrompt` 统一拼接；每条全文上限静态 2000 字、
动态 2400 字：

| 段 | 内容 | 来源 |
| :-- | :-- | :-- |
| 主体 | 城市 + 地标 + 时间限定 + 「作为一件微缩模型」 | 每景各异 |
| 结构 | 按 ①②③ 编号，自下而上或由近及远列出构件、子构件与相对位置 | 每景各异，取自事实表 |
| 比例 | 高宽比、分段高度、主次高度关系、陈设与主体的尺寸上限 | 每景各异，取自事实表 |
| 材质与色彩 | 材料质感、受光面与背光面的处理、色板建议值（十六进制） | 每景各异；色板为本仓库建议值 |
| 环境与微缩细节 | 底座上的场景陈设：地面、水面、树木、小船、小车等 | 每景各异；陈设为自撰 |
| 优先级说明 | 渲染层只规定画法，与前五段有出入时以前五段为准，不添加前五段没写的物件、材质或效果 | 各景逐字相同 |
| 构图与镜头 | 圆形展示底座，顶面即环境段描述的地面或水面；约 30° 俯视四分之三视角，主体段指定方向时从之；主体最长边约占画面 70% | 各景逐字相同 |
| 光影与材质 | 左上 45° 漫射顶光、三档明度加亮边暗边；质感按材质段来，本段只按光滑 / 粗糙 / 反光规定高光做法；表面细节只画受光面；悬出与相接处环境光遮蔽；地面投影 | 各景逐字相同 |
| 远近层次 | 以主体位置为基准分近中远：主体那层最实，比主体近的偏深清晰，比主体远的提亮、降饱和、边缘变软 | 各景逐字相同 |
| 微缩细节 | 只画环境段写到的陈设，每件按可凑近看的小模型刻画，重复构件成排铺满，成组的两种以上尺寸 | 各景逐字相同 |
| 氛围 | 时间天气季节从主体段；底座以外只画柔和渐变、无景物；模型比底座与背景更实；暗部不发黑 | 各景逐字相同 |
| 动态（仅动态版） | 主体静止；只动环境段里现实中本来会动的东西，按其现实动法；没有则整幅静止；不为动画添加物件、光效或天气；SMIL 或内联 CSS 循环，4–12 秒缓入缓出，绕自身轴点，动画元素不超过十二个 | 各景逐字相同 |
| 风格与绘制技法 | miniature diorama、体量来自明暗面、细节密而有序、线性与径向渐变、允许 filter 做投影与远处模糊、defs / use / pattern 复用、无位图与外部引用 | 各景逐字相同 |
| 禁止 | 文字、旗帜、徽记、标语、真实人物、脚本与交互 + 该景特有排除项 | 前半相同，后半各异 |

- 地标本身的结构、比例与颜色只取自事实表；色板建议值、陈设、光影属于渲染层指令，
  不是事实陈述。评分细则（`standard`）另记数字事实与扣分项。
- 结构段考察模型按文字还原分层构件的能力，比例段考察尺度控制，禁止段针对最常见的误画。
