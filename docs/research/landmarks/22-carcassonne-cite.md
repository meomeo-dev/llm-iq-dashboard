## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 高卢-罗马时期建城，333 年前已有罗马城墙；12–13 世纪子爵与法国王室（1226 年起）加建；1853–1879 年 Eugène Viollet-le-Duc（1814–1879）主持修复，其后 Paul Boeswillwald（1844–1931）、Henri Nodet（1855–1940）续修，1913 年完成 |
| 尺寸 | 双重城墙总长近 3 km；内墙（罗马）周长约 1,070 m、厚 2–3 m；中世纪墙高 10–12 m；共 52 座塔，罗马塔直径 4.5–7 m、高 11.65–13.70 m；面积 11 ha |
| 材料 | 当地砂岩（grès / molasse de Carcassonne）；罗马段为大石块加极硬砂浆，夹规则的砖层 |
| 组成 | 内外两圈城墙，中间为空地（lices）；伯爵城堡（12 世纪，1240–1250 年加固）平面为南北向长方形，9 座塔，方形的 Pinte 瞭望塔为全城最高；纳博讷门约 1280 年建，由两座大塔夹持；城内有圣纳泽尔大教堂 |
| 屋顶 | Viollet-le-Duc 为塔楼加了锥形石板瓦顶，与当地平缓的陶瓦屋顶不同 |
| 位置 | 奥德河右岸，城市东南部的高地上 |
| 状态 | 城堡、城墙与塔属国家，由国家古迹中心管理；城内仍有居民；1926 年列为历史古迹，1997 年列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一片高地上套着两圈城墙的椭圆形古城，塔楼密布，每座塔都戴着深色的锥形尖顶。
- 两圈墙之间空出一条环形的空地；东侧一座由两座大塔夹持的城门。
- 城内西侧是带自己护城壕与塔楼的伯爵城堡，城内其余是密集的陶瓦屋顶与一座教堂。
- 山脚下是河面与一座多孔石桥。
