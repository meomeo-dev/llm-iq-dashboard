# 09 里约热内卢 – 面包山（Sugarloaf Mountain）

- Wikidata：Q210722
- 参考条目：<https://en.wikipedia.org/wiki/Sugarloaf_Mountain>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 类型 | 自然地标：花岗岩与石英构成的独立岩峰（bornhardt，陡壁岩丘） |
| 高度 | 高出海港 396 m |
| 位置 | 瓜纳巴拉湾口的半岛上，三面临水 |
| 邻峰 | 乌尔卡山，高 220 m，约为面包山的一半 |
| 缆车 | 1912 年开通，分两段，全长 1,400 m，先到乌尔卡山再到山顶；现用车厢 2009 年更换，每厢 65 人，约 3 分钟登顶 |
| 攀岩 | 有 270 余条攀岩路线 |
| 保护 | 2006 年设立面包山与乌尔卡山自然纪念地；2012 年作为「里约热内卢：山海之间的卡里奥卡景观」列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座陡壁圆顶的灰色花岗岩独峰从海水中直接拔起，顶部浑圆，四壁近乎垂直，山脚与缝隙处有绿色植被。
- 旁边一座约一半高度的矮山，两山之间和矮山与岸边之间各架一条缆车索道，索道上挂着小缆车。
- 峰体立在海湾口的小半岛上，三面环水。
- 底座保留一小段沙滩与岸边的低矮城区。
