# 30 旧金山 – 福特角要塞（Fort Point）

- Wikidata：Q1438659
- 参考条目：<https://en.wikipedia.org/wiki/Fort_Point,_San_Francisco>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1853–1861 年，美国陆军工程兵团设计建造；原址为 1794 年西班牙土坯炮台 |
| 位置 | 金门海峡南岸岬角，施工时把悬崖从 27 m 削到 4.6 m，使最低一层火炮贴近水面 |
| 类型 | 砖砌海岸要塞（第三体系），美国西海岸唯一一座 |
| 尺寸 | 高 20 m（Wikidata）；占地约 1 ha（Wikidata）；墙厚约 2.1 m（7 英尺） |
| 结构 | 四层：三层带炮窗的炮廊（casemate）加屋顶露天炮位层；1900 年前拆除全部 103 门滑膛炮 |
| 材料 | 砖砌，花岗岩基础；1869 年建花岗岩海堤 |
| 军事史 | 从未开火作战；二战时驻海岸炮兵守卫水雷区与反潜网；1970 年退役 |
| 状态 | 1970 年 10 月 16 日设为国家历史遗址，国家公园管理局管理；占地 12 ha 的保护区 |
| 环境 | 1933–1937 年金门大桥的南引桥从要塞上方跨过，桥的设计曾为保留要塞而修改 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座方正厚重的红砖要塞贴着水面立在岬角上，临水的三面每层都开着一排排拱形炮窗，屋顶是平台。
- 要塞背后是陡坡，前方是海峡的水面与花岗岩海堤。
