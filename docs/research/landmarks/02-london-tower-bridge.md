# 02 伦敦 – 塔桥（Tower Bridge）

- Wikidata：Q83125
- 参考条目：<https://en.wikipedia.org/wiki/Tower_Bridge>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1886 年 4 月动工，1894 年 6 月 30 日通车 |
| 设计者 | 建筑师 Horace Jones（卒于 1887，动工次年去世）；工程师 John Wolfe Barry、Henry Marc Brunel |
| 尺寸 | 总长 290 m（含桥台）；中央开合跨 61 m；桥塔高 65 m；高架人行道距高潮水面 44 m |
| 桥塔 | 两座主塔立于河中桥墩，维多利亚哥特式，四角为八边形钢柱；两岸各有一座较小的桥台塔 |
| 结构 | 中央为双叶开合桥（bascule），两侧为悬索跨；高架人行道原为悬臂，1960 年改为悬吊 |
| 开合 | 两片桥叶各约 1,070 吨，配重平衡，开启角 82°，约 5 分钟升起 |
| 材料 | 钢骨架约 11,000 吨，外包康沃尔花岗岩与波特兰石 |
| 颜色 | 钢构为蓝色配白色（2008–2012 年修复时恢复）；石材为灰白色 |
| 环境 | 泰晤士河，北岸紧邻伦敦塔，位于伦敦池水域 |
| 所有权 | 伦敦金融城公司，City Bridge Foundation 运营 |
| 遗产 | 一级登录建筑（1949 年南段，1973 年其余部分） |

## 视觉要点（自撰，供题面与评分细则使用）

- 两座哥特式石塔立在河中桥墩上，塔顶为尖顶与小尖塔，塔高与中央跨宽度大致相当。
- 两塔顶部之间架着两条平行的高架人行道，位置约在塔高三分之二处。
- 两塔之间是可开合的双叶桥面，可画成合拢或微微抬起；两侧为悬索跨，连到岸上的小塔。
- 钢构为蓝色配白色细节，石材为灰白色；底座保留泰晤士河水面，北岸可点缀伦敦塔的一角。
