# 17 布达佩斯 – 渔人堡（Fisherman's Bastion）

- Wikidata：Q493117
- 参考条目：<https://en.wikipedia.org/wiki/Fisherman%27s_Bastion>、
  <https://en.wikipedia.org/wiki/Frigyes_Schulek>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1895–1902 年 |
| 设计者 | Frigyes Schulek（1841–1919） |
| 风格 | 新罗马式 |
| 塔楼 | 七座尖顶石塔，象征 895 年建国的七位部族首领 |
| 尺寸 | 主立面长约 140 m |
| 构成 | 观景平台、台阶、廊道与连拱廊；台阶用花岗岩 |
| 材料 | 浅色石材 |
| 位置 | 布达城堡山，俯瞰多瑙河，紧邻马加什教堂 |
| 雕像 | 堡前有 1906 年落成的圣伊什特万一世骑马铜像（Alajos Stróbl） |
| 修复 | 二战围城严重受损，1953 年修复完成 |
| 状态 | 公共观景平台；世界遗产「布达佩斯多瑙河两岸、布达城堡区与安德拉什大街」 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一道沿山崖边缘展开的浅色石砌观景长廊，正面是一排连续的圆拱廊，廊上一圈带小柱的栏杆。
- 长廊上等距立着七座圆锥形尖顶的圆塔，中央一座最高最粗，两侧的逐渐矮小，塔身开小拱窗。
- 长廊前方有两道对称的宽大台阶从坡下折返而上，台阶两侧为圆拱的墙洞。
- 长廊后方可露出一座教堂的尖塔与彩色瓦屋顶作背景；堡下是山坡与多瑙河水面。
- 广场上不放任何雕像。
