# 19 蒙特利尔 – 圣母大教堂（Notre-Dame Basilica of Montreal）

- Wikidata：Q887686
- 参考条目：<https://en.wikipedia.org/wiki/Notre-Dame_Basilica_(Montreal)>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 主体 1824–1829 年；立面 1865 年完成 |
| 设计者 | James O'Donnell，施工期间去世；室内由 Victor Bourgeau 于 1872–1879 年设计 |
| 双塔 | 西塔「坚毅」1841 年、东塔「节制」1843 年完成，高 60 m |
| 风格 | 哥特复兴式 |
| 材料 | 本地灰色石灰岩 |
| 室内 | 深蓝色拱顶饰金色星辰，大量木雕；1891 年卡萨旺管风琴 |
| 位置 | 老城兵器广场南侧 |
| 状态 | 现役天主教宗座圣殿（1982 年）；加拿大国家历史遗址（1989 年） |

## 视觉要点（自撰，供题面与评分细则使用）

- 灰色石灰岩的哥特复兴式正立面，两座方形塔楼对称并立，塔顶平直，四角各有小尖饰，塔身开高瘦的尖拱窗。
- 立面中央三座尖拱门廊，门廊上方一排壁龛，龛内为雕像剪影；再上是带尖拱的连拱装饰带与一圈雉堞。
- 塔楼之间的中段比塔矮，屋脊在两塔之间形成凹口。
- 门前是广场与一小片草地；教堂后方可露出长长的中厅屋顶。
