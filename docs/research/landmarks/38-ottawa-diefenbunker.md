# 38 渥太华 – 迪芬碉堡（Diefenbunker / CFS Carp）

- Wikidata：Q5010827
- 参考条目：<https://en.wikipedia.org/wiki/Diefenbunker>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1959–1961 年，加拿大基础公司（Foundation Company of Canada）承建，工程负责人 Ed Churchill 中校；1958 年由总理迪芬贝克批准 |
| 位置 | 安大略省卡普村，渥太华市中心以西约 30 km，原为废弃砾石坑 |
| 规模 | 地下四层钢筋混凝土碉堡；建筑面积逾 9,300 m²；混凝土 32,000 t，钢材 5,000 t；358 个房间 |
| 防护 | 可抵御 1.8 km 外 5 百万吨级核爆；爆炸隧道内设垂直于隧道的门以削减冲击波；地面巨型防爆门；空气过滤系统 |
| 功能 | 核战后维持政府运转的中央紧急政府总部，可容纳 565 人生活一个月；最底层有加拿大银行金库；设 CBC 应急广播室 |
| 状态 | 1994 年退役并列为加拿大国家历史遗址；1998 年起作为博物馆「迪芬碉堡：加拿大冷战博物馆」开放，非营利慈善机构运营 |

## 视觉要点（自撰，供题面与评分细则使用）

- 地面上只有一座不起眼的入口小楼和一片草丘；底座切开后露出地下四层的巨大混凝土盒子。
- 一条长长的爆炸隧道从入口斜向通到碉堡，隧道里有几道厚门；碉堡内部一层层的走廊与房间。
