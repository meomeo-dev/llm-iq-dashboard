# 04 伊斯坦布尔 – 加拉塔塔（Galata Tower）

- Wikidata：Q91274
- 参考条目：<https://en.wikipedia.org/wiki/Galata_Tower>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1348 年由热那亚殖民地建为瞭望塔 |
| 尺寸 | 建筑高度 62.59 m；观景台高 51.65 m；外径 16.45 m，内径 8.95 m，墙厚 3.75 m |
| 层数 | 共 11 层（含地下室、地面层与夹层） |
| 形状 | 圆柱形石塔，顶部为圆锥屋顶；原锥顶 1862 年前已失，1965–1967 年修复时按历史形制重建 |
| 材料 | 石砌 |
| 观景 | 顶部有 360° 环形观景台 |
| 用途 | 历任瞭望塔、监狱、火警瞭望（1717 年起）；现为博物馆，2024 年 5 月重新开放 |
| 环境 | 位于贝伊奥卢区加拉塔坡地，俯瞰金角湾与卡拉柯伊岸线 |
| 所有权 | 土耳其基金会总局 |
| 遗产 | 世界遗产预备名单（热那亚海上贸易网络） |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座细高的圆柱形石塔，高度约为直径的四倍，浅灰米色石砌，塔身开少量小窗。
- 塔身接近顶部处略微外扩成一圈环形观景廊，廊下是一排连续的拱窗。
- 顶部是深灰色的圆锥屋顶，锥尖带一个小尖饰。
- 塔立在坡地上，底座用几排错落的小房子和一小段金角湾水面交代位置。
