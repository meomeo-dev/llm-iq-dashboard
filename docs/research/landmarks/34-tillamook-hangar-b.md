# 34 蒂拉穆克 – 飞艇机库 B（Tillamook Hangar B）

- Wikidata：Q7802237（Tillamook Air Museum）
- 参考条目：<https://en.wikipedia.org/wiki/Tillamook_Air_Museum>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1942 年由美国海军为蒂拉穆克海军航空站建造，可容纳六艘软式飞艇 |
| 尺寸 | 长 327 m（1,072 ft），宽 90 m（296 ft），高 59 m（192 ft）；占地逾 2.8 ha；两端分段大门高 37 m（120 ft），每扇重 27 t，沿轨道滑动 |
| 材料 | 木结构，世界最大的无柱木结构建筑 |
| 历史 | 同场的机库 A 于 1992 年 8 月 22 日失火焚毁；1992 年起作为博物馆，1994 年起由蒂拉穆克湾港务局运营蒂拉穆克航空博物馆 |
| 状态 | 列入美国国家史迹名录（U.S. Naval Air Station Dirigible Hangar B）；2025 年 12 月风暴损毁一段屋面，修复中 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座长得不可思议的木结构机库趴在平坦的牧场上，横截面是一个高高的圆拱，两端各一排高大的分段门。
- 建筑之大让旁边的停车场、小车和奶牛都成了点。
