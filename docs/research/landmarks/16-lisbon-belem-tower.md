# 16 里斯本 – 贝伦塔（Belém Tower）

- Wikidata：Q215003
- 参考条目：<https://en.wikipedia.org/wiki/Bel%C3%A9m_Tower>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 约 1514–1519 年 |
| 设计者 | Francisco de Arruda（16 世纪） |
| 用途 | 特茹河口的防御工事，兼作航海出发与迎归的仪式性门户；现为博物馆 |
| 结构 | 四层方形塔楼，高 30 m，宽约 12 m；塔前向河中伸出一座不规则六边形的低矮棱堡 |
| 棱堡 | 下层墙上有 17 个炮眼；顶面为平台 |
| 风格 | 曼努埃尔式，带摩尔风格影响 |
| 装饰 | 浑天仪、绞绳纹、基督骑士团十字、带圆顶小穹的圆柱形角楼、犀牛形滴水兽、圣母子壁龛、南立面七拱凉廊、肋拱顶 |
| 材料 | 里斯本本地 lioz 石灰岩，米白色 |
| 位置 | 特茹河北岸，原立于近岸小岛，现与河岸相连 |
| 所有权 | 葡萄牙政府 |
| 遗产 | 1983 年与热罗尼莫斯修道院一起列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座米白色石灰岩的方形四层塔楼立在河岸边，四角各有一座带圆顶小穹的圆柱形角楼。
- 塔楼朝河的一面第二层是一排连续的尖拱凉廊，上方一圈栏杆；顶层收小，四角再各一座小角楼。
- 塔前向河中伸出一座低矮的六边形棱堡，顶面为平台，边缘一圈带绞绳纹的女儿墙与几座小角楼，墙下一排炮眼。
- 墙面点缀浮雕般的绞绳纹与几个小圆球纹样；底座为特茹河水面与一小段河岸草坪。
