# 37 沃尔 – 民兵导弹发射井 Delta-09（Minuteman Missile National Historic Site）

- Wikidata：Q3315665
- 参考条目：<https://en.wikipedia.org/wiki/Minuteman_Missile_National_Historic_Site>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 发射设施 Delta-09 建于 1963 年；1963–1991 年值班近 30 年，依 1991 年《削减战略武器条约》撤出，第 44 导弹联队 1994 年解散，仅保留 Delta-01 与 Delta-09 |
| 位置 | 南达科他州沃尔镇以东约 9.7 km（6 mi），90 号州际公路 116 出口西南约 800 m；场地 1.6 英亩（约 6,000 m²） |
| 发射井 | 地下发射筒直径 3.7 m（12 ft），深 24.4 m（80 ft），钢筋混凝土加钢板内衬 |
| 井盖 | 90 t 的井盖沿轨道推开一部分后焊死在轨道上；井口加装玻璃观察罩，供游客与条约核查卫星确认其不可用 |
| 展品 | 井内陈列一枚未装弹的民兵 II 导弹 |
| 配套 | Delta-01 发射控制设施在东南约 17 km 处：地面支援楼与埋深 9.4 m 的发射控制舱，以电梯相连 |
| 状态 | 1999 年 11 月 29 日设立国家历史遗址，国家公园管理局管理；Delta-09 可自行参观地面 |

条目正文未记载导弹与井盖的颜色；题面中的「白色弹体」「灰绿井盖」按通行认知写入，只作色彩
指令，不进评分细则的事实项。

## 视觉要点（自撰，供题面与评分细则使用）

- 草原上一小块围着铁丝网的砾石场地，地面只有一块推开一半的厚井盖和井口上的玻璃罩。
- 底座切开后露出一口细长的发射井，井壁极厚，一枚白色导弹立在井中，弹头几乎顶到玻璃罩。
