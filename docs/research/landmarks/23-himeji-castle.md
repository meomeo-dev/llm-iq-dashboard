## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1333 年筑砦；1581 年丰臣秀吉建三层天守；1601–1609 年池田辉政全面重建成今貌；1617–1618 年本多忠政增建西之丸等 |
| 大天守 | 建筑本体高 46.4 m，立于海拔 45.6 m 的姬山上，顶部海拔 92 m；外观五层，内部地上六层、地下一层；一层面积 554 m²；东西两根通柱 |
| 连立式 | 东、西、乾三座小天守以渡橹相连，与大天守围成中庭 |
| 屋顶装饰 | 南北面有千鸟破风（三角形），东西面有唐破风（弧形）；屋脊两端置鯱 |
| 外观 | 木构，外墙与檐下全部白灰抹面（故称白鹭城）；灰色陶瓦；石垣呈扇形曲线（扇の勾配） |
| 规模 | 现存建筑 83 栋；城门现存 21 座，菱之门为最大的橹门，长 17.5 m、宽 6.9 m、高 11.7 m；最高石垣 26 m；约 1,000 个射孔；三重护城河，平均宽 20 m、深约 2.7 m；从菱之门到天守直线 130 m、实际路径 325 m 的螺旋路线 |
| 修缮 | 昭和大修（1956–1964）将大天守落架解体后按原样复原；平成大修（2009–2015）重铺屋瓦、重做白灰 |
| 状态 | 国宝（大天守、三小天守与渡橹）；1993 年列入世界遗产；姬路市所有 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座通体雪白、五层屋檐层层出挑的大天守立在弧形收分的石垣上，三座小天守由带屋顶的廊桥连成一圈。
- 屋檐上交替出现三角形与弧形的山花，屋脊两端各立一只鯱。
- 下方是层层叠叠的白墙、带射孔的土塀与曲折的城门，外围一圈水面护城河。
