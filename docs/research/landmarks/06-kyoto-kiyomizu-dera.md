## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 创建 | 778 年 |
| 现存本堂 | 1629 年火灾后于 1633 年重建，德川家光捐建 |
| 舞台 | 本堂前伸出山坡的木造舞台，高出坡面约 13 m，由高大木柱支撑，整体不用一根钉子 |
| 屋面 | 桧皮葺（桧树皮），2020 年前完成整体修缮 |
| 其他建筑 | 三重塔（1632 年）；音羽瀑布分三道落入池中；仁王门为室町时代建筑 |
| 环境 | 位于东山山麓，面向京都市区，四周为樱与枫 |
| 所属 | 北法相宗 |
| 遗产 | 1994 年作为「古都京都的文化财」列入世界遗产 |

## 视觉要点（自撰，供题面与评分细则使用）

- 本堂坐在陡坡上，前方是一片宽大的木造舞台悬挑出山坡，舞台下方是密集的高大木柱与横梁组成的格架。
- 本堂屋顶为大面积的灰褐色桧皮葺歇山顶，屋脊舒展，出檐深远；木构为不上漆的深褐色。
- 坡面上点缀枫树或樱树，舞台下方和四周表现山坡地势。
- 远处可点缀一座朱红色的三重塔作为背景。
