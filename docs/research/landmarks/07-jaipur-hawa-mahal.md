# 07 斋浦尔 – 风之宫殿（Hawa Mahal）

- Wikidata：Q836531
- 参考条目：<https://en.wikipedia.org/wiki/Hawa_Mahal>（读取日期 2026-09-29）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1799 年，由 Sawai Pratap Singh 建造 |
| 设计者 | Lal Chand Ustad（18 世纪） |
| 尺寸 | 高约 15 m，五层，整体呈金字塔形收分 |
| 立面 | 953 个小窗（jharokha），半八边形的凸窗成排排列，形成蜂巢状纹理 |
| 材料 | 红、粉、黄、黑砂岩配石灰；立面以粉红为主 |
| 进深 | 上三层只有一间房的进深，一、二层设有院落 |
| 风格 | 拉杰普特与莫卧儿风格融合：穹形小亭、凹槽柱、莲花与花卉纹、石雕镂空 |
| 用途 | 原为王室女眷隔窗观街之处；现由拉贾斯坦邦考古部门管理，院内设博物馆 |
| 位置 | 城市宫殿边缘，正面朝向大街 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一面宽阔的粉红色砂岩立面，五层由下而上逐层收窄，整体像一顶宽底的冠冕。
- 立面布满成排的半八边形凸窗，每个小窗带镂空的石格栅与小圆顶檐，形成蜂巢般的纹理。
- 顶层缀有一排小穹顶亭子；立面几乎是一道薄墙，只有一间房的进深。
- 底座保留门前的一条街道和粉红色的沿街矮房。
