# 26 斋沙默尔 – 斋沙默尔城堡（Jaisalmer Fort）

- Wikidata：Q1479337
- 参考条目：<https://en.wikipedia.org/wiki/Jaisalmer_Fort>（读取日期 2026-10-01）

## 事实表

| 字段 | 事实 |
| :-- | :-- |
| 建成 | 1156 年由 Rawal Jaisal 创建；99 座堡垒中的 92 座于 1633–1647 年重建 |
| 位置 | Trikuta 山上，高出周围约 76 m |
| 尺寸 | 长约 460 m，宽约 230 m；外墙高 4.6 m；内圈周长约 4 km；三重城墙 |
| 材料 | 黄色砂岩（故称金色城堡） |
| 组成 | 99 座圆形堡垒（bastion）；朝城镇一侧四道城门；城内有 Raj Mahal 宫殿、七座耆那教神庙、Laxminath 神庙与多座商人宅邸 |
| 现状 | 活着的城堡，约 4,000 名居民，占老城人口近四分之一；印度考古调查局管理；2013 年作为「拉贾斯坦邦山地城堡」组成部分列入世界遗产 |
| 保护 | 地基为软弱沉积岩，渗水导致局部坍塌，世界古迹基金会多次列入观察名单 |

## 视觉要点（自撰，供题面与评分细则使用）

- 一座通体金黄的砂岩城堡盘踞在沙漠中的孤山上，三重城墙层层而上，墙上密密排着几十座半圆形的堡垒。
- 城墙之上是挤满的平顶黄色房屋与几座带尖顶的神庙，整座城堡像从山体里长出来。
- 山脚下是同色的低矮城镇与沙地。
