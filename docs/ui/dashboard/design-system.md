# 鹈鹕看板设计系统 v1

本规范适用于鹈鹕基准看板的 Web 深色界面，包括时间线、题库、配置、
模型指纹、作品查看和设备配对。通用控件的选型、状态与验收见
[组件规范](ui-elements-kit.md)，各路由的具体状态见
[UX 状态地图](../UX_STATE_MAP.md)。

## 设计原则

1. **以作品为视觉中心。** 页面和面板使用冷灰背景。保留作品原有的颜色，
   白色作品画布也属于深色界面的一部分。蓝色用于主要操作、选择、键盘焦点及现在线。
2. **先读出结果，再看颜色。** 状态带文字或可访问名称。在同一行或同一张卡片中，
   优先把语义色集中在一个状态标记。相同颜色的状态仍须保留各自的含义。
3. **保护比较关系。** 相同类型的作品使用一致的画框；成功和失败保持相同的占位。
   狭窄视口下，保留时间线与矩阵的横向滚动，在容器内展示宽数据。

## 设计基础

[Token 源文件](../../../src/app/tokens.css)定义运行时值，
由[全站样式入口](../../../src/app/globals.css)加载。组件消费语义角色；
`--palette-*` 基础色在 Token 文件内复用。定义实心背景时，须一起定义与它配对的文字色。

| 角色 | Token | 用法 |
| --- | --- | --- |
| 背景与层次 | `--bg`、`--surface`、`--surface-hi`、`--surface-hover` | 页面、面板、抬升面板、悬停项 |
| 画布与遮罩 | `--canvas-bg`、`--backdrop-bg` | 作品画框、模态浮层遮罩 |
| 边线 | `--border`、`--border-subtle`、`--border-focus` | 容器分隔、弱分隔、需要加强的轮廓 |
| 文字 | `--text`、`--text-dim`、`--text-faint` | 正文、可读说明、低强调装饰或禁用态 |
| 操作与焦点 | `--accent`、`--accent-hover`、`--focus-ring` | 主要操作、选择与键盘焦点；实心强调底配 `--text-on-accent` |
| 状态 | `--ok`、`--warn`、`--err` | 状态文字与图标；`-tint` 用于浅底，`-border` 用于描边 |
| 危险操作 | `--err-tint`、`--err`、`--text-on-danger` | 默认用淡红底；悬停使用红底和配对文字 |

`--text-on-solid` 保留给现有白色标记。新增实心控件使用对应的前景角色。
普通正文、表单提示和按钮文字的对比度验收目标为 4.5:1；对实心按钮分别检查默认与
悬停背景。键盘焦点环应可见，并与错误边框同时显示。

| 类别 | 用法 |
| --- | --- |
| 排版 | 界面用 `--font-sans`，标识符用 `--font-mono`，对齐数列用 `tabular-nums`；标题用 `--text-lg` / `--text-xl`，正文用 `--text-base` / `--text-md`，密集标签用 `--text-sm` / `--text-xs`；`--text-2xs` 留给次要刻度与标记 |
| 间距 | 用 `--space-*`；从控件内部的紧凑间距过渡到区块间距，页面级间距用 `--gap` |
| 控件 | 用 `--radius-*` 与 `--control-height-*`；胶囊用 `--radius-pill` |
| 浮层 | 用 `--z-*` 与 `--shadow-*`；先确认叠层职责，再选既有层级 |
| 响应式 | 标准断点为 640、900、1200 px；对应的最小宽度写 641、901、1201 px |

## 产品模式

| 模式 | 约束与实现 |
| --- | --- |
| 调用结果 | `ok` 用成功色，`no-svg` 用警告色，`error` 和 `timeout` 用错误色。文字、筛选和统计分别保留四种结果；成功指生成有效作品，与作品评审结论分开。 |
| 模型指纹 | `consistent`、`inconsistent`、`inconclusive`、`not-comparable` 分别显示名称；证据不足和不可比较都可用警告色，仍须分别说明原因。 |
| 时间线与文件夹 | 轴和矩阵共用时间坐标；按固定列宽呈现一轮，密集区可展开。保持强度槽位与空槽关系，几何见 [轨道常量](../../../src/app/components/timeline/track-layout.ts)和[看板布局 Token](../../../src/app/globals.css)。 |
| 作品对比 | 对齐卡片表头、画框和页脚；缺图时保留画框并说明原因。沿用 [作品卡片](../../../src/app/components/card/PelicanCard.tsx) 的状态与媒体边界。 |
| 无记录、筛选无结果 | 说明当前范围内缺少什么；有适用操作时给出切换日期或清除筛选。执行错误和超时显示可诊断原因。 |

时间线几何涉及页面、布局计算和导出。改动相关数值时同步核对
[导出布局](../../../src/app/components/export/timeline-svg.ts)。导出从根元素读取语义色，
调色时核对[导出配色](../../../src/app/components/export/export-image.ts)中的回退值。

## 预览与维护

鹈鹕 v1 的 [Chameleon 静态目录](../design-system/index.html)包含设计基础、共享组件、
产品模式、交互演示与 Token 导出。目录由 Chameleon 的 `llm-iq-dashboard` 系统构建，
同步看板源码中的 Token 和共享组件样式。在本仓库根目录启动静态预览：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/ui/design-system
```

打开 [静态目录预览](http://127.0.0.1:4173/)。

启动本地开发看板：

```bash
pnpm dev --port 3001
```

打开 [组件预览](http://127.0.0.1:3001/design-system)。色样和字阶读取实际 CSS；
组件示例复用产品原语，使用固定样例数据。可以打开对话框和抽屉、验证表单状态，
并通过确认操作在调用表格和空状态之间切换。此路由仅在开发环境提供。

新界面先选[组件规范](ui-elements-kit.md)中的原语，再组合业务模式。
业务模块负责数据和状态文案，原语负责通用交互与样式。新增或改动共享变体时，
同步更新组件规范和可验证的样例。

```bash
pnpm check:ui
```

静态检查覆盖样式中的颜色字面量、字号、断点、变量和选择器归属，
以及 JSX 静态内联样式。交互验收使用窄屏和宽屏，确认正文对比度、键盘焦点、
浮层退出及表格溢出行为；运行时样例的具体检查项见[组件规范](ui-elements-kit.md)。
